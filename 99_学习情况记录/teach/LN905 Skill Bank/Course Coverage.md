# LN905 Course Coverage

> [!summary] 结论
> Weeks 1–4 并不是只教了少量“万能句”。课程同时训练了四层：**获得信息**（Listening/Reading）、**把信息变成 meaning/evidence map**、**用 writer-led argument 写作**、**在口头 interaction 中清楚表达和共同建构**。本次共核验 116 份相关材料，并把真正可复用的动作和语言重建为 275 张卡。主题事实、课堂活动和技能卡分开保存，避免把卡片盒灌成课件目录。

> [!important] 最终考试内容范围（穷尽列表）
> 只有 **Social Media、Gender、Demographics、Climate Change** 四个 topic。它们不是四个例子，而是完整范围；之后新建的练习材料、卡片例句、callback、recall 和模拟都必须落在其中一个 topic 内。课件审计表可以保留其他课堂载体或正式 coursework 的历史名称，但它们不得进入最终考试训练。官方 [[07_Programme/01_LN905_LSE-language-class/PDF/05_Paper-C-Speaking-and-Listening/Instructions for Examiners.pdf|Instructions for Examiners]] 也明确列出这四个 topic。

## 课程真正教了什么

### Week 1 · 从“会写句子”进入“回答学术问题”

- Academic Writing：分析 task verb、拆 sub-questions、限定 scope、定义 contested terms；用 context → thesis → approach 写 introduction，用 synthesis → thesis → implication 写 conclusion；区别 LSE essay 与 IELTS 式泛泛讨论。
- Paper A/B/C：认识三张考卷的输入、时间、输出与评分标准；Listening 开始练 main point/support 选择，Reading 开始练 three-source task，Speaking 开始练 1–2 分钟 presentation 和 group contribution。
- Topic/interaction：Social Media 的定义、privacy 与 well-being 争议；预测再验证、比较多个 talk 的 claim/evidence；讨论中提问、倾听、举例和纳入他人。

### Week 2 · 准确使用来源，而不是改几个同义词

- Academic Writing：合格 paraphrase 同时改变词汇和句法但保留 proposition；direct quotation 的用途和标记；reporting verbs 的 stance；CRAAP、annotated bibliography、description/analysis/evaluation；source synthesis 与 writer voice。
- Paper A/B：准确区分 speaker、quoted person、research data 与个人经验；多来源不是逐篇复述，而要说明共同点、差异和共同机制。
- Topic/interaction：Gender norms、stereotypes 与 privilege；question-led/active reading；Academic Interaction 七个角色和具体 source evaluation。

### Week 3 · 从来源总结升级为 writer-led argument

- Academic Writing：Justification、Rebuttal、Synthesis、Thematic 四种结构；paragraph unity/coherence/development；effective topic sentence；Toulmin claim–grounds–warrant–backing–qualifier–rebuttal；cohesion、reference chain、parallelism；writer-led topic sentence、reporting noun/gerund、evaluative language、literature-as-evidence。
- Paper A/B：critical summary 内整合评价；三源 meaning/evidence map；按 writer theme 而非 author order 组织；figure description 与 implication 分开。
- Topic/interaction：Demographics 中的 population growth/decline、ageing 与 policy framing；听后 mind map、source preview、图表读法与 group synthesis。

### Week 4 · 校准 claim，压缩语言，并在真实语流中表达

- Academic Writing：finding → claim 的 strength ladder；hedging/boosting；study-specific past 与 general present；active/passive 的信息焦点；nominalisation 的用途与 noun-cluster 风险；concise writing。
- Climate Change：framing 的 problem/cause/judgement/remedy 功能及 gain/loss、individual/collective、present/future、local/global 维度；misinformation/disinformation、SQ3R、inoculation/debunking；jigsaw listening 后按 solution–benefit–challenge 合成信息。
- Discussion/Pronunciation：共同决策、礼貌打断/反对/澄清/总结；口头 idioms 的实际功能；音位、schwa、connected speech、word/sentence stress、chunking 与 presentation intelligibility。

## Assessment capability tree

1. **Task interpretation**：知道题目要求什么判断、几个部分、什么 scope。
2. **Input acquisition**：Listening 识别 signposts 和 evidence type；Reading question-led 检索 proposition。
3. **Meaning/evidence map**：记录 proposition、owner、role、scope、relation。
4. **Controlling answer**：形成 specific, focused, supportable thesis。
5. **Organisation**：选择 macro structure、paragraph functions 与 topic-sentence narrative。
6. **Source transformation**：quote/paraphrase/summary 准确分工，保留 ownership/certainty/scope/causality。
7. **Reasoning and synthesis**：claim–grounds–warrant，跨来源 similarity/difference/complementarity/tension。
8. **Writer voice and evaluation**：writer-led claim、literature-as-evidence、具体评价 evidence/method/scope/implication。
9. **Language control**：cohesion、claim strength、academic register、passive/nominalisation/concision、reporting/evaluative lexicon。
10. **Timed completion and interaction**：完整产出、revision priority；Paper C presentation、listen–build–challenge–repair 与 intelligible delivery。

## 抽取边界

- **制卡**：课程明确教过、之后可在新材料中独立调用的动作、句式、词义差别、discussion function 或 pronunciation decision。
- **进词库/材料证据**：四个考试话题的概念、专有词、单篇文章的事实与论点。它们用于理解和练习，但不是通用写作技能。
- **只作课堂证据**：sample answer、feedback、worksheet question、角色扮演情境。它们证明技能怎样被教，不各自制造新技能。
- **排除**：纯行政说明、视频链接运输页、人物/游戏规则、Hong Shao Rou 课堂载体、Everyday English。
- 同功能的近义句保留在一张卡的 variants；只有意义、使用条件或风险真正不同才分卡。
