# `Whole-output revision: one pass for argument, one for language.`

> [!question] 正面
> `Whole-output revision: one pass for argument, one for language.`

> [!answer]- 反面
> **功能**：避免边改句子边丢失全文结构。
>
> **适用时机**：完整 draft 后。
>
> **边界**：第一遍不陷入措辞；第二遍不重写 thesis。
>
> **例句/例子**：Pass 1 checks question, thesis, paragraph jobs and evidence roles; pass 2 checks clarity, grammar and concision.
>
> **可替换形式或操作提示**：可再做 citation/formality quick check。
>
