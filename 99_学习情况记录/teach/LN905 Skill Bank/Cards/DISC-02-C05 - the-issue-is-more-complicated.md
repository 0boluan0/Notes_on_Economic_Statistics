# `The issue is more complicated than it first appears.`

> [!question] 正面
> `The issue is more complicated than it first appears.`

> [!answer]- 反面
> **功能**：提醒讨论存在多因素、情境差异或无法压成单一答案。
>
> **适用时机**：前面的 claim 过度二元化，而你能指出具体复杂性时。
>
> **边界**：下一句必须说出复杂在哪里；不能用 complexity 逃避结论。
>
> **例句**：`The issue is more complicated than it first appears because population decline has different effects across regions and age groups.`
>
