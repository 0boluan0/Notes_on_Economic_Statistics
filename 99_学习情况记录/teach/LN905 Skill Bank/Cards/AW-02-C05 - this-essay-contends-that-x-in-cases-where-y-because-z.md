# `Governments should use A when X, B when Y, and C when Z.`

> [!question] 正面
> `Governments should use A when X, B when Y, and C when Z.`

> [!answer]- 反面
> **功能**：按政策目标给工具分工；也可压缩成一句直接回答 `Should governments use X?`。
>
> **适用时机**：真实题目要求判断政府是否应采用某政策，或要求在多个政策工具之间作条件式选择时。
>
> **边界**：X/Y/Z 必须先由 source map 证明；这是“目标匹配”，不是未经证据支持的总体效果排名。
>
> **四主题例句**：`Governments should support longer working lives when labour shortages are the objective, fertility measures when family constraints are central, and context-sensitive migration policies when additional workers are required.`
>
> **真实题型变体**：只回答 yes/no 时用 `Governments should use A when X, but should not rely on it alone when Y.`；解释某工具为何适合某目标时用 `A may be preferable when X is the objective because Y, although this does not establish that A is generally more effective than B.`
>
