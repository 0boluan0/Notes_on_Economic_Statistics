# `This evidence therefore supports X, while leaving open whether Y.`

> [!question] 正面
> `This evidence therefore supports X, while leaving open whether Y.`

> [!answer]- 反面
> **功能**：结束一个证据段：先写整段证据支持的判断 X，再保留仍未解决的问题 Y，并把段落接回全文立场。
>
> **适用时机**：已经写完两项或以上相关证据，需要一句段尾 payoff，而不是继续复述案例时。
>
> **边界**：X 必须是本段真正证明的判断，不能重复数字；Y 必须确实未解决，不能凭空加入新问题。一个证据段最多调用一次。
>
> **四主题例句**：`This evidence therefore supports targeted responses to harmful social-media practices, while leaving open whether restrictions improve well-being across all user groups.`
>
> **无未决问题时的短变体**：`This evidence supports X, suggesting Y.` 其中 Y 只回扣 thesis 的相关部分，不引入新政策。
>
