# `Use examples to illustrate a general argument, then return to the argument.`

> [!question] 正面
> `Use examples to illustrate a general argument, then return to the argument.`

> [!answer]- 反面
> **功能**：让案例服务 abstract claim。
>
> **适用时机**：加入 country、company 或 personal example 时。
>
> **边界**：example 不能成为未经证明的 generalization。
>
> **例句/例子**：After a country example, state what mechanism it illustrates and whether it is transferable.
>
> **可替换形式或操作提示**：结构：claim → example → interpretation。
>
