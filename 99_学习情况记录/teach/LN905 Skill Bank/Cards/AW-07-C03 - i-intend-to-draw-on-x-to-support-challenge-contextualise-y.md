# `I intend to draw on X to support / challenge / contextualise Y.`

> [!question] 正面
> `I intend to draw on X to support / challenge / contextualise Y.`

> [!answer]- 反面
> **功能**：明确来源在自己论证中的 intended use。
>
> **适用时机**：annotated bibliography 或 essay planning 时。
>
> **边界**：不能只写“this source is useful”；要说明服务哪个 claim。
>
> **例句/例子**：`I intend to draw on the longitudinal evidence to qualify claims based on cross-sectional correlations.`
>
> **可替换形式或操作提示**：`This source will be used to...`。
>
