# `Use `...` for omission and `[ ]` for a necessary change inside a quotation.`

> [!question] 正面
> `Use `...` for omission and `[ ]` for a necessary change inside a quotation.`

> [!answer]- 反面
> **功能**：保持 quotation 准确同时与句法衔接。
>
> **适用时机**：必须删去无关词或调整字母/代词时。
>
> **边界**：不能用省略号改变原意，也不能用方括号悄悄改 claim。
>
> **例句/例子**：`The author argues that “platform design ... shapes user attention”.`
>
> **可替换形式或操作提示**：逐字核对原文和 citation。
>
