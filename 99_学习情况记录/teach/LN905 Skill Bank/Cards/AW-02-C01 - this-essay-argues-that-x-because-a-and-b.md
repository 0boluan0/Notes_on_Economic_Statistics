# `This essay argues that X because A and B.`

> [!question] 正面
> `This essay argues that X because A and B.`

> [!answer]- 反面
> **功能**：直接给出 controlling answer，并预告最主要的理由。
>
> **适用时机**：introduction 的 context 已经建立，准备回答题目时。
>
> **边界**：A、B 必须是正文真正展开的理由；不能承诺未写内容。
>
> **例句/例子**：`This essay argues that demographic ageing creates fiscal pressure mainly because it narrows the tax base and raises care expenditure.`
>
> **可替换形式或操作提示**：`This essay contends/maintains that...`。
