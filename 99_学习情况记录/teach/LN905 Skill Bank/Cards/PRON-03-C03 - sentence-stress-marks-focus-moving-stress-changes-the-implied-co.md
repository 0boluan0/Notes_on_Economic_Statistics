# `Sentence stress marks focus; moving stress changes the implied correction.`

> [!question] 正面
> `Sentence stress marks focus; moving stress changes the implied correction.`

> [!answer]- 反面
> **功能**：让口头 argument 的 contrast 清楚。
>
> **适用时机**：纠正、限定或强调 `some/not/only` 时。
>
> **边界**：不要全句每词重读。
>
> **例句/例子**：`SOME users are affected` differs from `some USERS are affected.`
>
> **可替换形式或操作提示**：先决定 new/contrastive information。
>
