# `Question → provisional answer → paragraph functions → evidence roles → prose.`

> [!question] 正面
> `Question → provisional answer → paragraph functions → evidence roles → prose.`

> [!answer]- 反面
> **功能**：固定自上而下写作的考试顺序。
>
> **适用时机**：拿到 Paper B/assignment 材料时。
>
> **边界**：不能从 source 1 第一行直接开始写正文；每一步都要服务上一层。
>
> **例句/例子**：A question on climate communication leads to a conditional thesis, then mechanism/limitation paragraphs, then selected studies, then sentences.
>
> **可替换形式或操作提示**：Paper A 的 input route 不同，但有 map 后也进入同一链。
