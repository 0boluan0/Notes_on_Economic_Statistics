# `Thematic: thesis → theme 1 → theme 2 → theme 3 → conclusion.`

> [!question] 正面
> `Thematic: thesis → theme 1 → theme 2 → theme 3 → conclusion.`

> [!answer]- 反面
> **功能**：按题目中的机制、结果或维度组织材料。
>
> **适用时机**：三份来源围绕同一问题提供跨来源主题时。
>
> **边界**：每个 theme 必须推进同一 thesis，避免成为三个互不相干的小作文。
>
> **例句/例子**：Organise demographic responses by labour supply, fertility and immigration rather than by Source A/B/C.
>
> **可替换形式或操作提示**：topic sentences 应让读者仅看段首就看见这条路径。
