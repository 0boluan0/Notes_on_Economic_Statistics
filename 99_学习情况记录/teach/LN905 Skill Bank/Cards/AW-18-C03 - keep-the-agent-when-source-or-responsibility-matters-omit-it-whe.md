# `Keep the agent when source or responsibility matters; omit it when obvious or unimportant.`

> [!question] 正面
> `Keep the agent when source or responsibility matters; omit it when obvious or unimportant.`

> [!answer]- 反面
> **功能**：用 active/passive 选择信息焦点，而非追求“更学术”。
>
> **适用时机**：改写句子或 methods/reporting 时。
>
> **边界**：不能用 passive 隐藏需要明确的责任或 source ownership。
>
> **例句/例子**：`The researchers measured use` foregrounds the researchers; `Use was measured weekly` foregrounds the method.
>
> **可替换形式或操作提示**：先问读者此处最需要看见谁/什么。
>
