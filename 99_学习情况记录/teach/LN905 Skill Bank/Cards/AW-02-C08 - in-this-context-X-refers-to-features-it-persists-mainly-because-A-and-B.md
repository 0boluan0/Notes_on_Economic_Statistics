# `In this context, X refers to [defining features]; it persists mainly because A and B.`

> [!question] 正面
> `In this context, X refers to [defining features]; it persists mainly because A and B.`

> [!answer]- 反面
> **功能**：回答 `What is X, and why does it occur/persist?`，先给可操作定义，再交代主要原因与正文路线。
>
> **适用时机**：题目同时要求定义一个有争议的概念并解释其原因时。
>
> **边界**：定义必须服务当前题目，A/B 必须来自材料；若现象不是持续状态，把 `persists` 改为 `occurs` 或题目要求的动词。
>
> **例句**：`In this context, climate disinformation refers to deliberately false or misleading claims about climate change; it persists mainly because political interests and online amplification reward such messages.`
>
> **可替换形式或操作提示**：先填 `definition / cause A / cause B` 三个内容槽，再选择 `persists / occurs / spreads`。
>
