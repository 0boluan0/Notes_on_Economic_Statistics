# `The conclusion seems unfounded because X.`

> [!question] 正面
> `The conclusion seems unfounded because X.`

> [!answer]- 反面
> **功能**：指出结论缺少充分依据。
>
> **适用时机**：grounds 不足、warrant 不成立或 scope 过宽时。
>
> **边界**：`unfounded` 很强；若只是不完整，用 `insufficiently supported`。
>
> **例句/例子**：`The conclusion seems unfounded because the evidence is drawn from one self-selected sample.`
>
> **可替换形式或操作提示**：`The claim is questionable because...`。
>
