# `Group citations only when the sources support the same proposition.`

> [!question] 正面
> `Group citations only when the sources support the same proposition.`

> [!answer]- 反面
> **功能**：简洁呈现 literature consensus。
>
> **适用时机**：多个研究真正共同支持一句话时。
>
> **边界**：不能把互相冲突的来源堆在同一括号里。
>
> **例句/例子**：`Context shapes platform effects (A, 2022; B, 2023; C, 2024).`
>
> **可替换形式或操作提示**：可用 `recent research` 或 `a body of literature`，但要有实际 citations。
>
