# `X provides a basis for Y / highlights the need to Y.`

> [!question] 正面
> `X provides a basis for Y / highlights the need to Y.`

> [!answer]- 反面
> **功能**：说明某项研究为什么与下一步判断、政策或研究有关。
>
> **适用时机**：从 evidence 转向 implication，但不想把 evidence 直接写成命令或确定结论时。
>
> **边界**：provides a basis for 表示提供依据，不表示已经充分证明；highlights the need to 也必须与证据范围相称。
>
> **例句**：`The persistence of climate misinformation highlights the need to evaluate communication strategies, not only message reach.`
>
