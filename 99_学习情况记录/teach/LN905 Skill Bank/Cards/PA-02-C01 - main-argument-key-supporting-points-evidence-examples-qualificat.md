# `Main argument → key supporting points → evidence/examples → qualifications.`

> [!question] 正面
> `Main argument → key supporting points → evidence/examples → qualifications.`

> [!answer]- 反面
> **功能**：给笔记建立信息层级。
>
> **适用时机**：听完一段或整理 notes 时。
>
> **边界**：不能把 vivid joke/example 记得最详细却漏掉 central claim。
>
> **例句/例子**：Write one line for the thesis, three lines for supports and subordinate bullets for evidence.
>
> **可替换形式或操作提示**：minor detail 只有在支持 evaluation 时才保留。
>
