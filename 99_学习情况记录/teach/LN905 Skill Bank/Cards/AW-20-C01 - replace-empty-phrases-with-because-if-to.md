# `due to the fact that → because; in the event that → if; for the purpose of → to`

> [!question] 正面
> `due to the fact that → because; in the event that → if; for the purpose of → to`

> [!answer]- 反面
> **功能**：删除不增加意义的空短语，让句子更短更直接。
>
> **适用时机**：整篇 revision 时检查多词结构能否被一个准确词替换。
>
> **边界**：简洁不能删掉必要的 scope、source、certainty 或 logical relation。
>
> **例句**：`Policies are revised because emissions targets are missed, not due to the fact that targets are missed.`
>
