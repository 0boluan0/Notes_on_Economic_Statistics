# `I'd like to build on that point. / Following on from what you said, X.`

> [!question] 正面
> `I'd like to build on that point. / Following on from what you said, X.`

> [!answer]- 反面
> **功能**：明确说明新发言与前一位 speaker 的观点怎样相连。
>
> **适用时机**：你要补充 evidence、implication 或另一层 explanation，而不是另开话题时。
>
> **边界**：后续内容必须真的建立在前一点上；若是转题，应明确标示 shift。
>
> **例句**：`I'd like to build on that point: unequal housework may also affect promotion opportunities.`
>
