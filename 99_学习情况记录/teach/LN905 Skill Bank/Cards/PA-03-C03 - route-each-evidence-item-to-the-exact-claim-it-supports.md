# `Route each evidence item to the exact claim it supports.`

> [!question] 正面
> `Route each evidence item to the exact claim it supports.`

> [!answer]- 反面
> **功能**：避免把 lecture 的所有细节平铺。
>
> **适用时机**：planning critical summary 时。
>
> **边界**：evidence 不能因为同一 topic 就支持任意 claim。
>
> **例句/例子**：Housework evidence supports the family-benefit branch, not the workplace-performance claim.
>
> **可替换形式或操作提示**：一项 evidence 可支持多个 claim，但要写清不同 relation。
>
