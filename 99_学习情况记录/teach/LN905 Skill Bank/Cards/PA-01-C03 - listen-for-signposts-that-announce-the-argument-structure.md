# `Listen for signposts that announce the argument structure.`

> [!question] 正面
> `Listen for signposts that announce the argument structure.`

> [!answer]- 反面
> **功能**：用 speaker language 找 main claim、support、contrast、example 和 conclusion。
>
> **适用时机**：lecture 第一遍和笔记整理时。
>
> **边界**：signpost 只是路线提示；仍需判断后面的 proposition 是什么。
>
> **例句/例子**：`My first point...`, `however...`, `for example...`, `to conclude...`。
>
> **可替换形式或操作提示**：在 notes 中用箭头或缩写标关系。
>
