# `What this contrast implies is that X.`

> [!question] 正面
> `What this contrast implies is that X.`

> [!answer]- 反面
> **功能**：把比较结果提升为 writer inference。
>
> **适用时机**：已经呈现两个不同 pattern，需要说明它们对 thesis 的意义时。
>
> **边界**：X 必须由 contrast 合理推出，certainty 可用 `may imply` 调低。
>
> **例句/例子**：`What this contrast implies is that aggregate population size is a poor guide to regional labour pressure.`
>
> **可替换形式或操作提示**：`Taken together, these differences suggest that...`。
