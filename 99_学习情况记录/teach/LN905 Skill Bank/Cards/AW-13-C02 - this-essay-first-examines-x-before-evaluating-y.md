# `This essay first examines X before evaluating Y.`

> [!question] 正面
> `This essay first examines X before evaluating Y.`

> [!answer]- 反面
> **功能**：给读者清楚但不过度机械的 roadmap。
>
> **适用时机**：题目多部分，段落路线需要提前交代时。
>
> **边界**：正文必须按承诺执行；短 Paper B 不需要逐段预告所有细节。
>
> **例句/例子**：`This essay first defines harmful use before evaluating the mechanisms identified across the three sources.`
>
> **可替换形式或操作提示**：`The discussion proceeds by...`。
>
