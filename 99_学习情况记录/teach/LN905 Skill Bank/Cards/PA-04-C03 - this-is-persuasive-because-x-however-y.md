# `This is persuasive because X; however, Y.`

> [!question] 正面
> `This is persuasive because X; however, Y.`

> [!answer]- 反面
> **功能**：在 summary 内整合 strength 与 limitation。
>
> **适用时机**：一个 key claim 有支持也有限制时。
>
> **边界**：X/Y 都要针对实际 evidence，不能用无依据 personal agreement。
>
> **例句/例子**：`This is persuasive because it draws on research evidence; however, the lecture gives little detail about the study design.`
>
> **可替换形式或操作提示**：也可先 limitation 后 counter-strength。
>
