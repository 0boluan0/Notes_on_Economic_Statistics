# `This is evidenced / exemplified / supported by X.`

> [!question] 正面
> `This is evidenced / exemplified / supported by X.`

> [!answer]- 反面
> **功能**：明确 reason 后给 evidence。
>
> **适用时机**：口头 presentation 需要连接 claim 与 example/data 时。
>
> **边界**：exemplified 仅表示例证；evidenced/supported 责任更强。
>
> **例句/例子**：`This is exemplified by differences between active messaging and passive browsing.`
>
> **可替换形式或操作提示**：`A clear example is...`; `Evidence to support this includes...`。
