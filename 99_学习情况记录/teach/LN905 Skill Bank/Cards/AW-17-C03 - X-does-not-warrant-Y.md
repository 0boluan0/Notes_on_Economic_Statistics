# `X does not establish Y; it supports only the more limited conclusion that Z.`

> [!question] 正面
> `X does not establish Y; it supports only the more limited conclusion that Z.`

> [!answer]- 反面
> **功能**：不仅拦住过强结论 Y，还明确写出材料真正允许保留的最强结论 Z。
>
> **适用时机**：案例被扩大成普遍结论、`unknown` 被写成失败，或作者建议被改写成比较效果证据时。
>
> **边界**：X/Y/Z 都必须具体；Z 不能只是 Y 的软化同义词，而要对应来源实际支持的 proposition。
>
> **四主题例句**：`A short-term decline in emissions does not establish that a climate policy will remain effective; it supports only the more limited conclusion that the policy produced a short-term change.`
>
> **真实写作变体**：`A’s claim that X does not imply Y; it supports only Z.`；`The fact that X remains unknown does not establish Y; it supports only the conclusion that Z remains uncertain.`
>
