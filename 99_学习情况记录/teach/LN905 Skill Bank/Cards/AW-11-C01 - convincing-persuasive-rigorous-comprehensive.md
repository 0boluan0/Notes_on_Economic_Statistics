# `convincing / persuasive / rigorous / comprehensive`

> [!question] 正面
> `convincing / persuasive / rigorous / comprehensive`

> [!answer]- 反面
> **功能**：按证据质量说明一项研究或论证为什么强。
>
> **适用时机**：评价 method、coverage 或 reasoning 时。
>
> **边界**：这些词不是通用 praise：rigorous 指方法严谨；comprehensive 指覆盖广；persuasive/convincing 指论证效果。
>
> **例句/例子**：`The longitudinal design provides more convincing evidence than a single anecdote.`
>
> **可替换形式或操作提示**：`a thorough/systematic investigation`; `a cogent case`。
>
