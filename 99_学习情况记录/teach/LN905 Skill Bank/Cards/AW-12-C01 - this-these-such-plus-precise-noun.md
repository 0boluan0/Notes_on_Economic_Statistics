# `This / These / Such + precise noun`

> [!question] 正面
> `This / These / Such + precise noun`

> [!answer]- 反面
> **功能**：用明确名词指回上一句的 finding、evidence、pattern、limitation 或 outcome。
>
> **适用时机**：需要承接前文并继续解释，而孤立的 this 会让读者猜指代时。
>
> **边界**：名词必须准确概括所指内容；不要用 this fact 把仍有争议的 claim 偷写成事实。
>
> **例句**：`Women reported more unpaid care work. This pattern helps explain unequal employment outcomes.`
>
