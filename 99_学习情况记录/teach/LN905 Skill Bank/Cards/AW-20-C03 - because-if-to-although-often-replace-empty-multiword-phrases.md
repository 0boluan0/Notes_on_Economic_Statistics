# `because / if / to / although often replace empty multiword phrases.`

> [!question] 正面
> `because / if / to / although often replace empty multiword phrases.`

> [!answer]- 反面
> **功能**：用短结构删掉不增加意义的文字。
>
> **适用时机**：proofreading 发现 `due to the fact that` 等表达时。
>
> **边界**：不能删掉 scope、contrast 或 causal nuance。
>
> **例句/例子**：`Due to the fact that the sample was small` → `Because the sample was small`。
>
> **可替换形式或操作提示**：`in the event that` → `if`; `for the purpose of` → `to`。
>
