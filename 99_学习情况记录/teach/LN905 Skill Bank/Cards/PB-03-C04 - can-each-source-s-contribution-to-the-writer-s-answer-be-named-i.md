# `Can each source’s contribution to the writer’s answer be named in one phrase?`

> [!question] 正面
> `Can each source’s contribution to the writer’s answer be named in one phrase?`

> [!answer]- 反面
> **功能**：检查 source use 是否有功能而非装饰。
>
> **适用时机**：outline 或 revision 时。
>
> **边界**：`provides information` 太泛；要写 defines/supports/qualifies/challenges/explains。
>
> **例句/例子**：A defines privacy, B supplies surveillance evidence, C qualifies the effect by user agency.
>
> **可替换形式或操作提示**：不能把 citation count 当 synthesis。
>
