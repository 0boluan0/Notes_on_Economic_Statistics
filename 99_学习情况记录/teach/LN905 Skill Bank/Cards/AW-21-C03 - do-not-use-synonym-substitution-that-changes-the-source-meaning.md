# `Do not use synonym substitution that changes the source meaning.`

> [!question] 正面
> `Do not use synonym substitution that changes the source meaning.`

> [!answer]- 反面
> **功能**：避免为了“换词”牺牲准确性。
>
> **适用时机**：寻找同义词时。
>
> **边界**：academic paraphrase 不要求每个词不同；精确术语可以重复。
>
> **例句/例子**：Keep `correlation` rather than replacing it with `causal connection`.
>
> **可替换形式或操作提示**：meaning first, lexical distance second。
>
