# `X occurs mainly because A and B; addressing it therefore requires C and D.`

> [!question] 正面
> `X occurs mainly because A and B; addressing it therefore requires C and D.`

> [!answer]- 反面
> **功能**：让一个 thesis 同时回答 `Why?` 与 `What can be done?`，使两部分都获得正文篇幅。
>
> **适用时机**：题目明确包含 causes/reasons 和 solutions/responses 两部分时。
>
> **边界**：C/D 必须回应 A/B 的原因机制；不能用一句空泛 solution 收尾，也不能只展开 why 部分。
>
> **例句**：`Climate misinformation persists mainly because repeated false claims interact with prior beliefs; addressing it therefore requires both preventive communication and effective correction.`
>
