# Gender extracts 的核心机制

用户已从最初把背景或例子当作中心主张，进展到能够识别三篇材料的核心功能：prescriptive stereotypes 通过惩罚违规者形成约束，日常隐性沟通反复强化期待，而 confirmation bias 与 backlash 帮助解释刻板印象为何在社会角色变化后仍然持续。这使后续教学可以从逐篇理解转向跨文本因果链与 synthesis。

## Evidence

- 对 Extract 1 的修正：`要求男女按刻板印象行事，不遵守的人会被惩罚`
- 对 Extract 2 的识别：`日常的隐形期待`
- 对 Extract 3 机制的正确匹配：`confirmation bias` 与 `backlash`

## Implications

- 下一步训练 Extract 2 → Extract 1 → Extract 3 之间的传递、规范化、惩罚与维持关系。
- 继续要求先写 writer-led causal claim，再放入来源，而不是按 Extract 1/2/3 顺序摘要。
