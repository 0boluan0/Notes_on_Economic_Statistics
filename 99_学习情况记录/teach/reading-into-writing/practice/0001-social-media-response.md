# Social Media：Reading into Writing 电脑答题

材料：[[0001-social-media-source-pack.pdf|打印版三篇 extracts]]

**Question:** *Last year, 3.96 billion people used social media, which is more than half the world's population. Is this cause for concern?*

> [!important] 这份文件怎么用
> 先在打印材料上完成 Step 1，再按顺序填写 Step 2–5，之后才开始写全文。你的目标不是总结三篇文章，而是借三篇文章回答问题。

## 评分目标

| Reading | Writing |
|---|---|
| 选择真正支持论点的内容；建立跨文本联系；准确概括和改写 | 直接回答问题；形成清楚递进的论证；使用准确、合适的学术语言 |

> [!tip] 从 descriptive 到 analytical
> **Descriptive:** 分别报告三位作者说了什么。  
> **Analytical:** 先提出自己的判断，再让不同来源相互支持、限制或解释，最后说明这组证据怎样改变你对题目的回答。

## 120 分钟路线

| 时间 | 动作 | 到点必须产出 |
|---|---|---|
| 0–30 分钟 | 阅读并在打印材料上批注 | 每篇 1 个 central claim；总共 6–9 个可用点 |
| 30–45 分钟 | 完成 Step 2–5 | 1 个明确 thesis；3 个段落任务；每段至少 1 个跨文本关系 |
| 45–105 分钟 | 写约 600 词 | 完整初稿，训练目标 580–620 词 |
| 105–120 分钟 | 按 Step 8 检查 | 内容、引用、结构、语言各检查一遍 |

## Step 1｜在打印材料上做有目的的批注

只使用四种标记，避免逐句划线：

- `C`：作者的核心 claim
- `E`：能支持论点的 evidence / example / mechanism
- `Q`：qualification、限制、适用范围或不确定性
- `X`：能与另一篇 extract 建立关系的内容，并在旁边写 `X1`、`X2` 或 `X3`

读完每篇后，在纸张顶部用不超过 20 个英文单词写：`This source helps answer the question by ...`

## Step 2｜先压缩三篇材料

不要抄原句。每格只写能帮助你作决定的内容。

| Source | Central claim（≤20 English words） | 最值得使用的机制或证据 | 关键限制 / scope | 放入哪一段？ |
|---|---|---|---|---|
| Extract 1 — Kross et al. (2021) |  |  |  |  |
| Extract 2 — Ortiz-Ospina (2019) |  |  |  |  |
| Extract 3 — Lee & Hancock (2024) |  |  |  |  |

完成后删掉任何不能帮助你回答 *cause for concern* 的细节。材料重要，不等于必须写进作文。

## Step 3｜决定你到底要回答什么

### 3.1 选择总体判断

- [ ] Yes
- [ ] Qualified yes
- [ ] Mostly no
- [ ] 其他：

### 3.2 给 *concern* 一个判断标准

本题中的 *concern* 对我主要意味着（只选最重要的 1–2 项）：

- [ ] 平均负面影响足够大
- [ ] 即使平均效应小，仍存在严重机制或高风险群体
- [ ] 证据足够支持因果判断
- [ ] 问题需要政策或个人行为干预
- [ ] 其他：

### 3.3 Thesis builder

只填意思，先不追求漂亮句子：

- **Verdict:** Widespread social media use is / is not / is only conditionally a cause for concern because ...
- **Main reason:**
- **Necessary qualification:**
- **Road map — 后文三个判断依次是：** ① ___；② ___；③ ___。

> [!check] Thesis 三项测试
> 读者能否只看 thesis 就知道：你的明确答案、最主要理由、以及答案成立的条件或限制？缺任何一项，先不要开始正文。

## Step 4｜把来源组成三组证据，而不是三篇摘要

下面是推荐的论证路线；如你的 thesis 不适合，可以改写“段落任务”，但每段仍要完成一个判断。

| 段落任务 | 我的 analytical claim | 哪两个来源发生什么关系？ | 最小必要证据 | 这对题目意味着什么？ |
|---|---|---|---|---|
| P1：解释为何可能值得担忧 |  | E__ ___ **supports / explains / qualifies / challenges** E__ ___ |  |  |
| P2：判断影响的大小与因果证据 |  | E__ ___ **supports / explains / qualifies / challenges** E__ ___ |  |  |
| P3：解释差异并得出应对含义 |  | E__ ___ **supports / explains / qualifies / challenges** E__ ___ |  |  |

> [!warning] 不是 synthesis 的写法
> `Kross says ... Ortiz-Ospina says ... Lee and Hancock say ...` 只是把三个摘要放在一起。  
> 真正的 synthesis 必须说清楚关系：第二个来源是在 **supporting、qualifying、challenging**，还是 **explaining** 第一个来源。

## Step 5｜给每个主体段装上“推理链”

在写全文前，每段先完成这五格。若第 4 或第 5 格写不出来，说明你还在堆材料，没有形成论证。

### Body paragraph 1

1. **My claim — 本段由我作出的判断：**
2. **Source A — 只写支持该判断的改写内容：**
3. **Source B relationship — 它如何支持 / 限制 / 解释 / 反驳 A：**
4. **My analysis — 两份材料放在一起后能推出什么，不能推出什么：**
5. **Link to question — 因此，这使 social media 在何种意义上值得或不值得担忧：**

### Body paragraph 2

1. **My claim：**
2. **Source A：**
3. **Source B relationship：**
4. **My analysis：**
5. **Link to question：**

### Body paragraph 3

1. **My claim：**
2. **Source A：**
3. **Source B relationship：**
4. **My analysis：**
5. **Link to question：**

## Step 6｜600 词结构与字数预算

| 部分 | 建议字数 | 必须完成的工作 |
|---|---:|---|
| Introduction | 70–80 | 简短设定争议；明确 thesis；预告三个判断 |
| Body 1 | 150–155 | claim → 两份来源的关系 → 自己的判断 → 回答题目 |
| Body 2 | 150–155 | claim → 两份来源的关系 → 自己的判断 → 回答题目 |
| Body 3 | 150–155 | claim → 两份来源的关系 → 自己的判断 → 回答题目 |
| Conclusion | 60–70 | 回答问题；综合三段判断；不加入新证据 |

只读五个段落的第一句：如果它们不能独立组成一条清楚的论证路线，先修改 topic sentences。

## Step 7｜来源归属速查

- `Kross et al. (2021) argue that ...` / `... (Kross et al., 2021).`
- `Ortiz-Ospina (2019) suggests that ...` / `... (Ortiz-Ospina, 2019).`
- `Lee and Hancock (2024) find that ...` / `... (Lee & Hancock, 2024).`
- 如果使用 Extract 3 中的 Beyens 研究：`Beyens et al. (2021, cited in Lee & Hancock, 2024) ...`

> [!warning] Secondary referencing
> 你只读了这三份 extracts。不要把 extract 内引用的研究写成自己直接读过的原始来源。

## Step 8｜最后 15 分钟按这个顺序检查

### 8.1 Task fulfilment（3 分钟）

- [ ] Introduction 和 conclusion 都能被直接划出一句对题目的回答。
- [ ] 全文讨论的是“是否值得担忧”，而不只是罗列 social media 的优缺点。

### 8.2 Text use and synthesis（5 分钟）

- [ ] 三份 extracts 都被用于支撑我的论点，而不是为了“全部提到”而硬塞进去。
- [ ] 每个主体段先出现我的 claim，再出现来源。
- [ ] 我至少清楚写出了三个跨文本关系，而不是连续报告作者观点。
- [ ] 我没有把 correlation 写成 causation，也没有丢掉来源中的 qualification。
- [ ] 所有来源归属和 secondary references 都准确。

### 8.3 Structure（3 分钟）

- [ ] 每段只有一个主要任务，段落顺序与 thesis 的 road map 一致。
- [ ] 每段最后都把证据拉回题目，而不是停在 source summary。
- [ ] Conclusion 没有加入新材料。

### 8.4 Language（4 分钟）

- [ ] 检查主谓一致、冠词、单复数、句号和过长句。
- [ ] 删除重复意思和空泛开头，让字数接近 600。
- [ ] 保留准确、自然的句子，不为展示“高级词汇”而冒险。
