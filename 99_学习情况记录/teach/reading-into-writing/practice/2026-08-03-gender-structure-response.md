# Gender：从三篇材料到一个 analytical paragraph

材料：[[2026-08-03-gender-structure-source-pack.pdf|打印版 source pack]]

**Question:** *“Gender bias at work is sustained mainly by organisations rather than by individuals.” To what extent do you agree?*

> [!important] 今日唯一重点
> 不按 Extract 1、2、3 依次摘要。先形成自己的段落判断，再让至少两篇材料发生明确关系，并用第三篇材料限定这个判断。

## 55 分钟路线

| 时间 | 必须产出 |
|---|---|
| 0–15 分钟 | 打印阅读；每篇只标 `C` claim、`E` evidence、`L` limitation、`X` cross-text link |
| 15–25 分钟 | 完成下面的三文压缩和关系判断 |
| 25–30 分钟 | 写出一个可争论的 paragraph claim |
| 30–50 分钟 | 写 180–220 词 analytical paragraph |
| 50–55 分钟 | 检查来源关系、evaluation 和句子准确性 |

## 2｜先决定关系，再写段落

- **我的判断：** Gender bias at work is sustained mainly by ___ because ___; however, ___ means that this claim should be limited to ___.
- **Source A 提供：** mechanism / empirical evidence / scope / counterargument
- **Source B 与 A 的关系：** supports / explains / qualifies / challenges
- **Source C 改变了什么：** 它使我的结论更强、更弱，还是只适用于更窄的情况？
- **我能从证据推出什么：**
- **我不能从证据推出什么：**

> [!warning] Evaluation 不是另加一句个人意见
> 评价必须指出某项 evidence 能否支持对应 claim。可以检查研究设计、effect size、generalisability、causal direction 或文章本身承认的 scope。

## 3｜Paragraph reasoning chain

写之前只填功能，不写完整答案：

1. **My analytical claim：**
2. **Source A — 与 claim 直接相关的内容：**
3. **Source B — 它与 A 的具体关系：**
4. **Evaluation — 证据能推出什么、不能推出什么：**
5. **Source C / qualification — 它如何修正我的判断：**
6. **Link back to the question：**

## Response（180–220 words）



## 最后五分钟

- 我的第一句是自己的判断，不是某位作者的摘要。
- 至少两篇来源在同一条推理链里发生了明确关系。
- 我没有把相关性、理论模型或短视频实验写成普遍因果证明。
- evaluation 紧跟它评价的 evidence，没有漂成个人观点。
- 最后一句明确回答 organisations 与 individuals 的相对作用。
