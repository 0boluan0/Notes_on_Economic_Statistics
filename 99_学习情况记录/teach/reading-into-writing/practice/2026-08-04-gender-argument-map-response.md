# Gender：限定 thesis 与三段 argument map

材料：[[2026-08-04-gender-argument-map-source-pack.pdf|打印版 source pack]]

**Question:** *To what extent does evidence from Norway show that mandatory corporate-board gender quotas are an effective way to advance workplace gender equality?*

> [!important] 今日唯一重点
> 先限定“effective”到底指 firm value、board representation，还是 wider workplace equality；再让三个段落分别承担不同功能。这是 AI 引导练习，不是完整模拟，我不会提前给 thesis 或 model paragraph。

> 如果后续研究无法证明价值下降，你只能撤回“配额造成可靠成本”；不能因此直接断言配额提高了企业价值或实现了广泛平等。

## 最后检查

- thesis 明确区分 board representation、firm value 与 wider workplace equality。
- 三段各做一件不同的事，而不是三篇来源依次摘要。
- Eckbo 被用作对 Ahern 的方法论回应，而不是独立的“另一种观点”。
- 我没有把 statistically insignificant 写成 proof of no effect 或 positive effect。
- evaluation 紧跟它评价的 evidence 或 warrant。
