# **巴塞尔协议 2.5 主要内容**

  

巴塞尔协议2.5是在2008年金融危机后针对市场风险资本充足要求做出的修正，2011年开始实施 。其主要增加了以下三项内容：**压力风险价值度（Stressed VaR）**、**增量风险计提（IRC）和综合风险计量（CRM）** 。压力VaR要求银行除了正常VaR外，还要计算基于危机期间市场数据的VaR，通常远高于平时VaR ；IRC主要针对交易账簿中的信用风险（包括违约和评级迁移）在1年期、99.9%置信度下计算资本要求 ；CRM则针对相关交易账户（如CDO等证券化产品）在危机情形下的相关性风险，用类似IRC的1年、99.9%VaR方式进行计量，同时可替代对相关产品的增量风险和特定风险计提 。此外，巴塞尔III又增加了对场外衍生品对手风险价值调整（CVA）损失的资本要求 。

- **压力VaR**：即用金融危机时期（如2008–09年）250个交易日的市场数据计算未来10天、99%置信度的VaR 。因为采用了极端情况下的数据，压力VaR通常远大于平时VaR，实践中多为后者的2–4倍 。监管部门还要求将压力VaR与正常VaR结合计算资本，通常要求压力VaR所用历史样本能够反映资产组合的极端亏损情况 。
    
- **增量风险计提（IRC）**：原本的违约风险资本（IDRC）只考虑违约风险，而2007–08年危机显示，信用评级迁移、利差上升、流动性丧失等因素也会带来重大损失。因此IRC要求银行对交易账簿中所有信用相关头寸，以1年展望期、99.9%置信度计算VaR资本 。例如，某债券头寸10天VaR在普通情况下需资本1个单位，但在IRC标准下约需6–7个单位 。银行可在1年内对组合进行调整，违约损失由此部分得到缓解；但在IRC范围内，还必须考虑到评级迁移等非违约风险。
    
- **综合风险计量（CRM）**：针对相关性交易账户（如CDO类证券化产品组合）推出的一种资本计量方式 。在这些产品中，个别资产表现良好并不能降低整体损失风险，因为在相关性急剧上升时可能出现多个资产同时大幅贬值 。CRM采用与IRC相同的1年、99.9%VaR计算框架，并额外考虑如隐含相关性、流动性基差、资本结构等风险因子 。监管通常要求对再证券化产品（如CDO）按标准法计提资本（或直接100%扣除），即大幅高于普通证券化产品 。
    

  

**练习题**

1. **理解题**：简述压力VaR与普通VaR的区别，以及引入压力VaR的目的。
    
    **答案**：压力VaR与普通VaR在计算方法上相同，但压力VaR使用发生重大市场压力时期（如金融危机）的历史数据样本 。由于采用极端行情样本，压力VaR通常显著高于普通VaR（多数银行压力VaR约为VaR的2–4倍） 。引入压力VaR的目的是防止风险低估，在极端市场波动时仍能保持足够资本缓冲。
    
2. **理解题**：什么是增量风险计提（IRC）？它解决了什么问题？
    
    **答案**：增量风险计提（IRC）是巴塞尔2.5针对交易账簿信用风险推出的资本计提方法。与只考虑违约风险的IDRC不同，IRC将期限扩大到1年、置信度提高到99.9%，并涵盖评级迁移、利差扩张和流动性风险 。它解决了2007–08年信用市场危机中损失主要来自信用评级变化和流动性消失的问题，提高了交易结构性信用产品的资本要求 。
    
3. **计算题**：某银行交易组合的10天99%VaR为50万元，监管规定压力VaR至少为该VaR的2倍，试计算压力VaR及由此产生的市场风险资本。
    
    **答案**：压力VaR至少是普通VaR的2倍，因此压力VaR = 50万元 × 2 = 100万元 。相应的市场风险资本在基于VaR法的计算框架下也翻倍，约为100万元（具体还需加上其他附加项目）。
    
4. **计算题**：某债券头寸在交易账簿上的10天99%VaR需资本1万元，而相同头寸在银行账簿上按一年99.9%VaR计算需资本6万元。根据增量风险计提（IRC），该债券在交易账簿上需要计提多少资本？
    
    **答案**：根据IRC要求，交易账簿信用风险资本应按一年、99.9%的VaR计算。在本例中，该债券的一年99.9%VaR资本为6万元 ，因此IRC要求该头寸计提约6万元资本（远高于普通VaR情况下的1万元）。
    

  

# **巴塞尔协议 3 核心要求**

  

巴塞尔3在2022年全球落实（最终2019年完成过渡）后，提高了银行资本质量和流动性监管标准 。其核心内容包括资本构成及比例要求、资本保全和逆周期缓冲、杠杆率、流动性指标（LCR、NSFR）以及对手风险资本（CVA）等。

- **资本构成与比例**：一级资本主要包括**核心一级资本（Common Equity Tier1）和补充一级资本（Additional Tier1）**，二级资本则为期限较长的次级债等 。巴塞尔3规定：核心一级资本充足率（CET1/RWA）最低为4.5%，一级资本（Tier1）最低为6%，总体资本（Tier1+Tier2）最低为8% 。各国监管可在此基础上提高要求。
    
- **资本保全缓冲和逆周期缓冲**：为了使银行在正常情况下持有额外资本缓冲以吸收潜在损失，巴塞尔3要求建立资本保全缓冲，即在4.5%的核心一级资本之外再额外持有2.5% RWA的CET1 。因此正常情况下CET1实际要求达到7% 。此外，各国可根据信贷增长周期设定最高2.5%的逆周期缓冲（同样以CET1计），在经济过热时加码要求，经济下行时可释放缓冲 。例如，瑞士对两大银行要求CET1达到10%的做法，就是加大了本国的资本要求。
    
- **杠杆率监管指标**：杠杆率是非风险加权指标，定义为一级资本与整体风险暴露（包括表内资产、衍生品及表外风险敞口）的比率。巴塞尔3要求杠杆率不低于3% 。公式为：
    
    $$ \text{杠杆率} ;=; \frac{\text{一级资本}}{\text{总风险暴露}} ;\ge;3%. $$
    
    该指标防止银行过度使用杠杆而风险暴露过高。
    
- **流动性监管指标（LCR 与 NSFR）**：为防范流动性风险，巴塞尔3引入两个指标 。**流动性覆盖率（LCR）**要求银行持有的高质量流动性资产（HQLA）至少覆盖未来30天的净现金流出额（30天内预期现金流出减流入），保证在短期压力下能自我供给流动性。公式为：
    
    $$ \text{LCR} ;=; \frac{\text{高质量流动性资产}}{\text{未来30天净现金流出}} ;\ge;100%. $$
    
    **净稳定资金比率（NSFR）**要求银行持有足够稳定的资金来源以支持一年期的资金需求，计算为可用稳定资金（ASF）与所需稳定资金（RSF）的比率，要求不低于100% 。
    
- **对手信用风险资本（CVA）**：巴塞尔3针对场外衍生品对手方信用风险引入了CVA资本计提机制 。CVA是预期损失，由对手可能违约而导致的利润调整。其关键参数包括敞口（Exposure）、违约损失率（LGD）、对手信用利差和期限等，计算方式类似市场风险VaR 。
    

  

**练习题**

1. **理解题**：说明一级资本与核心一级资本的区别，以及巴塞尔3对CET1、Tier1和总资本的最低要求。
    
    **答案**：核心一级资本（CET1）主要指普通股和留存收益等最优质资本，是吸收损失能力最强的资本；补充一级资本和二级资本则包括非累积优先股、长期次级债等 。巴塞尔3规定：CET1/RWA ≥ 4.5%，一级资本（含CET1和AT1）≥6%，总体资本（Tier1+Tier2）≥8% 。此外，还需留存2.5%的CET1作为资本保全缓冲，使正常情况下CET1要求提高到7% 。
    
2. **理解题**：LCR和NSFR指标的不同之处是什么？
    
    **答案**：LCR（流动性覆盖率）关注短期流动性风险，要求高质量流动资产覆盖未来30天的净现金流出，其公式是高质量流动资产÷30天净现金流出≥100% ；NSFR（净稳定资金比率）关注中长期资金稳定性，要求可用稳定资金（ASF）覆盖一年内所需稳定资金（RSF）≥100% 。简单来说，LCR确保30天内流动性充足，NSFR确保长期资金来源稳定。
    
3. **计算题**：某银行在正常环境下持有高质量流动资产100亿元，未来30天预计净现金流出80亿元。计算其LCR，并判断是否符合Basel III要求。
    
    **答案**：根据LCR公式，LCR = 100/80 = 1.25，即125%，高于100%的要求。因此该银行符合LCR监管标准。
    
4. **计算题**：某银行可用稳定资金（ASF）总额为200亿元，表内外资产所需稳定资金（RSF）总额为180亿元。计算其NSFR，并判断是否符合Basel III要求。
    
    **答案**：NSFR = 200/180 ≈ 1.111，即111.1%，大于100%的下限，因此该银行符合NSFR要求。
    

  

# **全球系统重要性银行（G-SIBs）与地区系统重要性银行（D-SIBs）**

  

**全球系统重要性银行（G-SIBs）**是由巴塞尔委员会每年公布的全球性大行名单，评定标准包括规模、互联性、业务复杂度等。G-SIB所在的分级（常见有5个分位）决定其额外资本附加。巴塞尔3要求G-SIB持有额外**1%–3.5%**的CET1缓冲（按风险加权资产计） 。例如，2014年排名前列的摩根大通、汇丰等G-SIB，基本CET1要求4.5%，加2.5%资本缓冲后为7%，再加大约2.5%的GSIB附加，使其最低CET1要求达到9.5% 。同时，这些银行的整体资本（含Tier2）和杠杆率要求也更高（如总资本达13% RWA级别）。

  

**地区系统重要性银行（D-SIBs）**由各国监管机构自行指定，指对本国金融体系具有重要意义的银行。D-SIB需满足与G-SIB类似的附加要求，如额外资本缓冲、更多信息披露及压力测试等 。例如，美国规定资产超过500亿美元的银行被认定为D-SIB 。D-SIB的附加资本比例由各国决定，一般在0%–2.5%范围内。

  

**练习题**

1. **理解题**：什么是全球系统重要性银行（G-SIB）？G-SIB附加资本的主要决定因素有哪些？
    
    **答案**：G-SIB是指对全球金融体系具有重大影响的国际性银行，根据规模、国际互联性、替代性程度、复杂度和跨境活动等指标评估并排名 。根据排名高低，这类银行需要持有额外1%–3.5%的核心一级资本缓冲 。排名越高（影响越大），额外资本要求越高。例如在2014年排名前列的银行其额外要求约为2.5% 。
    
2. **理解题**：D-SIB与G-SIB有何不同？
    
    **答案**：D-SIB是指对某个国家金融体系具有系统性重要性的银行，由该国监管机构根据本国标准认定 。D-SIB主要关注国内影响，附加要求通常由本国制定（如美国规定资产>500亿美元为D-SIB ）。相对G-SIB，D-SIB的评级标准和附加资本比例可变，但一般也要求额外持有资本缓冲并加强披露和压力测试 。
    
3. **计算题**：假设某全球系统重要性银行的基本CET1要求为4.5%，资本保全缓冲2.5%，其被评定需要额外1.5%的GSIB附加。问该银行的最低CET1资本充足率要求是多少？
    
    **答案**：最低CET1要求 = 4.5%（基本要求）+ 2.5%（资本保全缓冲）+ 1.5%（GSIB附加） = **8.5%**。
    
4. **计算题**：某地区系统重要性银行被要求持有额外2%的风险加权资产资本缓冲。如果其风险加权资产总额为1000亿元人民币，则该银行需要额外持有多少资本？
    
    **答案**：额外资本 = 1000亿元 × 2% = **20亿元**。
    

  

# **未定可转换债券、美国Dodd-Frank法案及其他监管制度**

  

**未定可转换债券（CoCo）****是特殊的次级债券，在触发条件发生时自动转换为股权** **。触发条件通常与发行银行资本充足水平挂钩，如一级资本比率跌破预定阈值** **。转换后债券本金按固定转换比率换算为普通股。其关键因素是****转换比率**（即每份债券转换为多少股）和**触发条件** 。例如，一般触发条件可设为CET1比率低于规定值，或股价与账面价值比率低于某一水平 。

  

**美国Dodd-Frank法案**（2010年通过）旨在防范“太大而不能倒”风险并保护消费者。其核心内容包括：成立**金融稳定监管委员会（FSOC）和金融研究办公室等新机构负责系统性风险监管；引入沃尔克规则**限制银行自营交易和对冲基金、私募基金投资；推动场外衍生品集中清算；要求系统重要机构制定**“生前遗嘱”**（清算计划）；提高系统重要性机构的资本要求；禁止对信用评级的过度依赖；要求资产发行方保留一定的利益（“自留份额”）等 。例如，沃尔克规则规定银行持有的对冲基金和私募基金投资不得超过一级资本的3% ；对大型机构实行更严格的破产清算程序（FDIC接管） 。

  

**其他国家监管制度**：英、美等国也推出类似改革。英国的Vickers报告（2011）导致2013年的《金融服务（银行改革）法》，要求银行实行业务隔离（ring-fencing）等；欧盟Liikanen报告（2012）建议分拆银行自营业务 。各国监管普遍关注问题包括：推广场外衍生品集中清算、限制自营交易（或至少隔离高风险业务）、制定生前遗嘱、加强金融机构高管薪酬监管等 。

  

**练习题**

1. **理解题**：什么是未定可转换债券？其转换条件通常包括哪些要素？
    
    **答案**：未定可转换债券是一种特殊的资本工具，当发行银行触及预定财务困难条件时，债券自动转换为普通股 。转换通常由**转换比率**（每单位债券可转换的股数）和**触发条件**决定。触发条件常设为一级资本充足率低于某一阈值，或股票市值与资产账面价值比率低于一定水平 。一旦触发，债券本金按转换比率换成股本，从而加强银行资本。
    
2. **理解题**：简要说明Dodd-Frank法案的主要监管措施中，FSOC和沃尔克规则的作用。
    
    **答案**：Dodd-Frank法案建立了**金融稳定监督委员会（FSOC）**，负责识别和评估系统性风险，对大型金融机构提出更严格的资本和杠杆要求 。同时引入了**沃尔克规则**，禁止银行进行自营交易并限制其对对冲基金和私募基金的投资，防止银行承担过度高风险业务 。此外，法案赋予监管机构（如FDIC）对大型金融机构进行有序清算的权限，以降低未来政府救助的需要 。
    
3. **计算题**：某银行发行一只面值1000万元、转换比率为0.01的未定可转换债券。当该行触发转换条件时，问该债券将转换为多少普通股？
    
    **答案**：转换后新增股本数量 = 1000万元 × 0.01 = **10万股**。
    
4. **计算题**：根据沃尔克规则，银行持有的对冲基金和私募基金投资总额不得超过一级资本的3%。如果某银行一级资本为50亿元人民币，则其最多可投资对冲基金和私募基金的金额为多少？
    
    **答案**：根据规定，最大投资额 = 50亿元 × 3% = **1.5亿元**。
