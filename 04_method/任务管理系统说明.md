# 任务管理系统说明

## 系统功能介绍

这是一个基于 Obsidian 的任务和 DDL 管理系统，帮助你每天早上自动汇总未完成的任务和后续的截止日期，并按照优先级顺序输出。系统支持简单的任务添加和进度修改，内容存储在每天的日记中。

## 核心功能

### 1. 自动任务汇总
- 每天打开 Obsidian 时，日记会自动汇总未完成的任务
- 任务按照优先级（高→中→低）和截止日期（近→远）排序
- DDL 倒计时显示即将到来的截止日期

### 2. 快速任务添加
- 使用 QuickAdd 插件快速添加任务
- 支持自定义任务标题、截止日期、优先级和技能标签
- 任务自动保存到当天的日记中

### 3. 任务分类和筛选
- 按技能维度筛选任务（数学/编程/论文/英语）
- 支持任务状态跟踪（待开始/进行中/已完成/已取消）
- 使用标签系统管理任务类型（#任务 / #DDL）

## 使用方法

### 1. 查看任务汇总
每天的日记（位于 `99_学习情况记录/` 文件夹）会自动显示：
- **未完成任务列表** - 所有未完成的任务，按优先级和截止日期排序
- **DDL倒计时** - 即将到来的截止日期，只显示未来的任务

### 2. 快速添加任务

#### 方法一：使用 QuickAdd 命令
1. 打开命令面板（Cmd/Ctrl + P）
2. 搜索并选择 "QuickAdd: 添加任务"
3. 按照提示输入任务信息：
   - 任务标题：简洁描述任务内容
   - 截止日期：格式 YYYY-MM-DD（如 2026-02-15）
   - 优先级：高/中/低
   - 技能：选择任务所属的技能领域（可多选）

#### 方法二：手动添加任务
在日记中直接添加任务，格式如下：
```markdown
- [ ] 任务标题 📅 2026-02-15 🔼 高
  - 技能：数学/编程
  - 状态：进行中
  - 标签：#任务 #数学
```

### 3. 更新任务状态
- **标记为完成**：点击任务前面的复选框
- **修改状态**：编辑任务的 "状态" 字段（待开始/进行中/已完成/已取消）
- **删除任务**：直接删除任务段落

### 4. 查询和筛选任务

#### 使用 Dataview 查询
在任意笔记中可以使用 Dataview 查询任务，例如：

```dataview
TASK
WHERE !completed
AND contains(text, "#数学")
AND due >= date("2026-01-01")
SORT due ASC
```

#### 筛选条件说明
- `!completed`：未完成任务
- `contains(text, "#数学")`：包含特定技能标签
- `due >= date("2026-01-01")`：截止日期在特定日期之后
- `priority = "高"`：高优先级任务

## 系统配置

### 1. 模板文件
- **日记模板**：`00_inbox/日记模版.md` - 包含任务汇总功能
- **任务模板**：`00_inbox/新建任务模板.md` - 任务格式参考
- **添加脚本**：`00_inbox/quickadd任务添加.js` - QuickAdd 脚本

### 2. 插件配置
确保以下插件已启用：
- **Dataview** - 数据查询和展示
- **QuickAdd** - 快速添加功能
- **Tasks** - 任务管理

### 3. 快捷键配置
可以为 QuickAdd 命令设置快捷键：
1. 打开设置 → 快捷键
2. 搜索 "QuickAdd: 添加任务"
3. 设置你喜欢的快捷键（如 Cmd/Ctrl + Shift + T）

## 任务格式规范

### 必填字段
- **任务标题**：清晰描述任务内容
- **截止日期**：使用 📅 符号 + YYYY-MM-DD 格式（如 📅 2026-02-15）
- **优先级**：使用 🔼 符号 + 高/中/低（如 🔼 高）
- **技能**：至少选择一个技能标签

### 可选字段
- **状态**：待开始/进行中/已完成/已取消（默认：待开始）
- **标签**：自定义标签（如 #紧急 #重要）

### 技能标签
支持的技能维度：
- **数学**：数学相关任务
- **编程**：编程和 CS 相关任务
- **论文**：论文写作和研究任务
- **英语**：英语学习和考试任务

### 任务格式示例
```markdown
- [ ] 完成数学作业 📅 2026-02-01 🔼 高
  - 技能：数学
  - 状态：进行中
  - 标签：#任务 #数学

- [ ] 写论文大纲 📅 2026-02-10 🔼 高
  - 技能：论文
  - 标签：#DDL #论文
```

## 常见问题

### 1. 任务没有显示在汇总中
- 检查任务格式是否正确
- 确保任务包含 #任务 或 #DDL 标签
- 检查截止日期格式是否正确（YYYY-MM-DD）

### 2. QuickAdd 命令不工作
- 检查 QuickAdd 插件是否已启用
- 确认脚本路径是否正确（`00_inbox/quickadd任务添加.js`）
- 检查控制台是否有错误信息（按 Cmd/Ctrl + Shift + I）

### 3. Dataview 查询性能慢
- 减少查询的范围和复杂度
- 避免在大文件夹中进行全局查询
- 定期清理已完成的任务
