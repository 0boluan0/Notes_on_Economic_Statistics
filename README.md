# 数学、经济与计算机科学知识库

以共享知识原子为基础，组织连续课程阅读与知识关系。

## 阅读入口

- `00_Knowledge/`：可独立理解、回忆和应用的知识原子，以及同名主题 Canvas。
- `01_Math/`、`02_Economy/`、`03_Computer_Science/`：课程笔记与连续阅读路径。
- [知识原子 Base](00_Knowledge/知识原子.base)：查询定义入口和共享原子。

从课程总览或连续阅读页开始，正文会嵌入需要的共享原子；主题 Canvas 用来查看概念、条件、推论与方法之间的联系。每个原子末尾保留来源及核验说明。受限访问的课程讲义以文献形式引用。

建议下载或克隆仓库后，用 Obsidian 打开文件夹，以使用双链、嵌入、Canvas 和 Base。首次打开可使用默认配置，再按需要设置阅读界面。

## 公开内容与本地记录

本仓库发布通用知识、课程解释和关系导航。个人学习进度、掌握记录、复习日程、学校事务和本机应用状态保留在本地私有区；具体边界见 `.gitignore` 与 `AGENTS.md`。
