# Euclidean algorithm
<!-- bilingual-en:end -->

*欧几里得算法*

<!-- bilingual-en:start -->
The **Euclidean algorithm** finds the [[最大公因数|greatest common divisor]] by replacing a pair of integers with a pair having the same common divisors and a smaller second entry. Instead of listing factors, it repeatedly asks what is left after taking complete multiples of the second number from the first. One calculation rule does the work, and two different arguments justify it: the answer is preserved, and the process must finish.
<!-- bilingual-en:end -->

**欧几里得算法**通过替换整数对来寻找[[最大公因数]]：新数对保留相同公因数，同时缩小第二个数。它无须列出因子，而是反复问：从第一个数中取走第二个数的整倍数后，还剩多少？计算依靠一条更新规则，而正确使用它需要两条不同论证：答案保持不变，过程必定结束。

<!-- bilingual-en:start -->
To compute $\gcd(a,b)$, first take absolute values. While the second value is nonzero, perform [[带余除法|division with remainder]] and replace the dividend–divisor pair by the divisor–remainder pair. When the second value becomes zero, the first is the answer.
<!-- bilingual-en:end -->

要算 $\gcd(a,b)$，先把输入换成绝对值；在第二个数不为零时做一次[[带余除法]]，再把“被除数、除数”换成“除数、余数”。第二个数变成零时，第一个数就是答案。

<!-- bilingual-en:start -->
Let the original inputs $a,b$ be arbitrary integers, and initialize the working values as $x=|a|$, $y=|b|$. For nonzero input pairs, the target is the greatest positive common divisor; at $(0,0)$ we use the [[最大公因数#Signs, zero and coprimality|separate zero-pair convention]]. While $y>0$, division with remainder gives integers $q,r$ such that $x=qy+r$ and $0\le r<y$. Replace $(x,y)$ simultaneously by $(y,r)$:
<!-- bilingual-en:end -->

原输入 $a,b$ 可以是任意整数，工作变量初始取 $x=|a|$、$y=|b|$。输入不全为零时，目标是最大正公因数；输入为 $(0,0)$ 时采用[[最大公因数#Signs, zero and coprimality|单独的双零约定]]。当 $y>0$ 时，带余除法给出整数 $q,r$，满足 $x=qy+r$、$0\le r<y$；随后同时把 $(x,y)$ 换成 $(y,r)$：

$$
(x,y)\longmapsto(y,x\bmod y),\quad y>0.
$$

<!-- bilingual-en:start -->
Here $x\bmod y$ denotes the nonnegative remainder, not the quotient. Both expressions on the right use the old pair. In an implementation, compute the remainder before overwriting either input, or use a simultaneous assignment. When $y=0$, return $x$ without evaluating any remainder with divisor zero.
<!-- bilingual-en:end -->

这里 $x\bmod y$ 表示非负余数，不是商；右侧使用的都是更新前的数值。实现时应先保存余数，再覆盖原变量，或者使用同时赋值。当 $y=0$ 时直接返回 $x$，不计算任何除数为零的余数。

<!-- bilingual-en:start -->
## A complete calculation
<!-- bilingual-en:end -->

*一遍完整计算*

<!-- bilingual-en:start -->
For example, $(30,22)\to(22,8)\to(8,6)\to(6,2)\to(2,0)$ gives $\gcd(30,22)=2$. If the second input is already zero, return the first immediately; $(0,0)$ returns zero under the vault's convention.
<!-- bilingual-en:end -->

例如 $(30,22)\to(22,8)\to(8,6)\to(6,2)\to(2,0)$，所以 $\gcd(30,22)=2$。若初始第二个数已是 $0$，直接返回第一个数；$(0,0)$ 按本库约定返回 $0$。

<!-- bilingual-en:start -->
Each arrow in that example comes from one division equation. The quotient records how many complete multiples were removed; the remainder becomes the next divisor.
<!-- bilingual-en:end -->

例子中的每个箭头都来自一条除法等式。商记录取走了多少个整倍数，余数则成为下一轮的除数。

<!-- bilingual-en:start -->
| Current pair | Division equation | Next pair |
|---|---|---|
| $(30,22)$ | $30=1\cdot22+8$ | $(22,8)$ |
| $(22,8)$ | $22=2\cdot8+6$ | $(8,6)$ |
| $(8,6)$ | $8=1\cdot6+2$ | $(6,2)$ |
| $(6,2)$ | $6=3\cdot2+0$ | $(2,0)$ |
<!-- bilingual-en:end -->

| 当前数对 | 除法等式 | 下一数对 |
|---|---|---|
| $(30,22)$ | $30=1\cdot22+8$ | $(22,8)$ |
| $(22,8)$ | $22=2\cdot8+6$ | $(8,6)$ |
| $(8,6)$ | $8=1\cdot6+2$ | $(6,2)$ |
| $(6,2)$ | $6=3\cdot2+0$ | $(2,0)$ |

> [!example] Return the first coordinate · 返回第一个坐标
> <!-- bilingual-en:start -->
> The final state is $(2,0)$. The zero remainder tells us to stop; the answer is $2$, the first coordinate. Returning the last remainder would incorrectly return zero for this nonzero input pair.
> <!-- bilingual-en:end -->
>
> 终态为 $(2,0)$。余数为零是停止信号，答案是第一个坐标 $2$；若误把最后一个余数当答案，就会为这组非零输入错误返回零。

## Preservation and termination
<!-- bilingual-en:end -->

## 为什么结果不变，而且一定结束

<!-- bilingual-en:start -->
Write $x=qy+r$. Every common divisor of $x,y$ divides $r=x-qy$, and every common divisor of $y,r$ divides $x=qy+r$. Thus the pairs have the same common divisors and each step preserves $\gcd(x,y)=\gcd(a,b)$. At exit, $y=0$, so the [[不变量与部分正确性|invariant together with the exit condition]] yields $x=\gcd(a,b)$.
<!-- bilingual-en:end -->

写 $x=qy+r$。共同整除 $x,y$ 的数也整除 $r=x-qy$；反过来，共同整除 $y,r$ 的数也整除 $x=qy+r$。两对数的公因子集合相同，因而每步保持 $\gcd(x,y)=\gcd(a,b)$。退出时 $y=0$，这个[[不变量与部分正确性|不变量与退出条件]]合起来给出 $x=\gcd(a,b)$。

<!-- bilingual-en:start -->
The common-divisor argument can be checked entirely through integer witnesses. If $d\mid x$ and $d\mid y$, write $x=du$, $y=dv$ with integers $u,v$; then $r=x-qy=d(u-qv)$, so $d\mid r$. Conversely, if $y=dv$ and $r=dw$, then $x=qy+r=d(qv+w)$, so $d\mid x$. This proves equality of the common-divisor sets, not just equality of one observed factor.
<!-- bilingual-en:end -->

公因子论证可以完全展开为整数系数。若 $d\mid x$ 且 $d\mid y$，写成 $x=du$、$y=dv$，其中 $u,v$ 为整数，那么 $r=x-qy=d(u-qv)$，所以 $d\mid r$。反过来，若 $y=dv$、$r=dw$，则 $x=qy+r=d(qv+w)$，所以 $d\mid x$。这证明的是整个公因子集合相等，不只是碰巧有一个相同因子。

<!-- bilingual-en:start -->
Initially, taking absolute values preserves the original gcd. Each completed update stays in the nonnegative integer state space and preserves that same gcd. At an exit, $y=0$, so $\gcd(x,0)=x$. If the original inputs are not both zero, no update reaches $(0,0)$: its new first coordinate is the old positive $y$. Hence the returned $x$ is positive in that case. The initial $(0,0)$ case takes no steps and returns the agreed value $0$.
<!-- bilingual-en:end -->

初始取绝对值保持原 gcd；每次完成更新后仍是非负整数状态，且保持同一个 gcd。退出时 $y=0$，所以 $\gcd(x,0)=x$。若原输入不全为零，就不会通过更新到达 $(0,0)$，因为新第一个坐标是原来为正的 $y$，因此此时返回的 $x$ 为正。初态为 $(0,0)$ 则一步也不执行，直接返回约定值 $0$。

<!-- bilingual-en:start -->
Termination is a separate obligation. Whenever $y>0$, the new second value satisfies $0\le r<y$, making $y$ a strictly decreasing nonnegative-integer [[秩函数与终止证明|ranking function]]. It cannot decrease forever. Preserving the gcd ensures the answer is correct; decreasing the remainder ensures the computation finishes.
<!-- bilingual-en:end -->

正确性还差“能否退出”：每次 $y>0$ 时，新第二个数满足 $0\le r<y$，所以 $y$ 是严格下降的非负整数[[秩函数与终止证明|秩函数]]。它不可能无限下降，算法必定结束。两条理由要分别说清楚：gcd 不变保证没算错，余数变小保证算得完。

<!-- bilingual-en:start -->
More explicitly, each strict drop between integers is at least one. After $k$ updates, the second coordinate is at most $|b|-k$ and is still nonnegative, so there cannot be more than $|b|$ updates. This coarse bound suffices for termination; it is not a claim about the cost of each integer division or an optimal running-time estimate. The computation assumes exact integer arithmetic.
<!-- bilingual-en:end -->

更明确地，整数之间每次严格下降至少减少一。执行 $k$ 次更新后，第二坐标至多为 $|b|-k$，但仍非负，所以不可能超过 $|b|$ 次更新。这个粗界已经足以证明终止，并没有声称每次整数除法的代价，也不是最优运行时间估计；计算模型采用精确整数运算。

## Ordering, signs and zero inputs
<!-- bilingual-en:end -->

*大小顺序、符号与零输入*

<!-- bilingual-en:start -->
There is no need to put the larger input first. If $0\le x<y$, the quotient is zero and the remainder is $x$, so the next pair is $(y,x)$. For example, $(8,22)\to(22,8)$ is a valid first step. The first coordinate increases here, but the second decreases from $22$ to $8$; this is why the termination proof tracks the second coordinate.
<!-- bilingual-en:end -->

无须预先把较大输入放在前面。当 $0\le x<y$ 时，商为零、余数为 $x$，下一对就是 $(y,x)$。例如 $(8,22)\to(22,8)$ 是合法第一步；第一坐标在这里增大了，但第二坐标由 $22$ 降为 $8$，因此终止证明跟踪的是第二坐标。

<!-- bilingual-en:start -->
A negative input such as $(-30,22)$ first becomes $(30,22)$ and gives the same answer $2$. For $(0,7)$, the equation $0=0\cdot7+0$ gives one update to $(7,0)$ and returns $7$. For $(7,0)$, the algorithm returns $7$ immediately. The two-zero case also returns immediately, using the explicitly stated convention rather than a division by zero.
<!-- bilingual-en:end -->

负输入如 $(-30,22)$ 先变成 $(30,22)$，得到同一答案 $2$。对 $(0,7)$，等式 $0=0\cdot7+0$ 给出一步更新 $(7,0)$，返回 $7$；对 $(7,0)$ 则立即返回 $7$。双零输入也立即返回，依据明确约定，而不是做除以零的运算。

<!-- bilingual-en:start -->
If the coefficients expressing the gcd in terms of the inputs are also needed, use the [[扩展欧几里得算法|extended Euclidean algorithm]] to track each remainder's coefficients; prime factorization is still unnecessary.
<!-- bilingual-en:end -->

若还要知道“哪两个整数系数能组合出 gcd”，继续使用[[扩展欧几里得算法]]，记录每个余数相对于原输入的系数即可，不需要重新分解素因数。
