# 欧几里得算法反复用除数和余数替换原数对来求最大公因数
<!-- bilingual-en:start -->
*The Euclidean algorithm repeatedly replaces a pair by its divisor and remainder to find the gcd*
<!-- bilingual-en:end -->

要算 $\gcd(a,b)$，先把输入换成绝对值；在第二个数不为零时做一次[[带余除法]]，再把“被除数、除数”换成“除数、余数”。第二个数变成零时，第一个数就是答案。
<!-- bilingual-en:start -->
To compute $\gcd(a,b)$, first take absolute values. While the second value is nonzero, perform [[带余除法|division with remainder]] and replace the dividend–divisor pair by the divisor–remainder pair. When the second value becomes zero, the first is the answer.
<!-- bilingual-en:end -->

$$
(x,y)\longmapsto(y,x\bmod y),\quad y>0.
$$

例如 $(30,22)\to(22,8)\to(8,6)\to(6,2)\to(2,0)$，所以 $\gcd(30,22)=2$。若初始第二个数已是 $0$，直接返回第一个数；$(0,0)$ 按本库约定返回 $0$。
<!-- bilingual-en:start -->
For example, $(30,22)\to(22,8)\to(8,6)\to(6,2)\to(2,0)$ gives $\gcd(30,22)=2$. If the second input is already zero, return the first immediately; $(0,0)$ returns zero under the vault's convention.
<!-- bilingual-en:end -->

## 为什么结果不变，而且一定结束
<!-- bilingual-en:start -->
*Why the target is preserved and the procedure terminates*
<!-- bilingual-en:end -->

写 $x=qy+r$。共同整除 $x,y$ 的数也整除 $r=x-qy$；反过来，共同整除 $y,r$ 的数也整除 $x=qy+r$。两对数的公因子集合相同，因而每步保持 $\gcd(x,y)=\gcd(a,b)$。退出时 $y=0$，这个[[不变量与部分正确性|不变量与退出条件]]合起来给出 $x=\gcd(a,b)$。
<!-- bilingual-en:start -->
Write $x=qy+r$. Every common divisor of $x,y$ divides $r=x-qy$, and every common divisor of $y,r$ divides $x=qy+r$. Thus the pairs have the same common divisors and each step preserves $\gcd(x,y)=\gcd(a,b)$. At exit, $y=0$, so the [[不变量与部分正确性|invariant together with the exit condition]] yields $x=\gcd(a,b)$.
<!-- bilingual-en:end -->

正确性还差“能否退出”：每次 $y>0$ 时，新第二个数满足 $0\le r<y$，所以 $y$ 是严格下降的非负整数[[秩函数与终止证明|秩函数]]。它不可能无限下降，算法必定结束。两条理由要分别说清楚：gcd 不变保证没算错，余数变小保证算得完。
<!-- bilingual-en:start -->
Termination is a separate obligation. Whenever $y>0$, the new second value satisfies $0\le r<y$, making $y$ a strictly decreasing nonnegative-integer [[秩函数与终止证明|ranking function]]. It cannot decrease forever. Preserving the gcd ensures the answer is correct; decreasing the remainder ensures the computation finishes.
<!-- bilingual-en:end -->

若还要知道“哪两个整数系数能组合出 gcd”，继续使用[[扩展欧几里得算法]]，记录每个余数相对于原输入的系数即可，不需要重新分解素因数。
<!-- bilingual-en:start -->
If the coefficients expressing the gcd in terms of the inputs are also needed, use the [[扩展欧几里得算法|extended Euclidean algorithm]] to track each remainder's coefficients; prime factorization is still unnecessary.
<!-- bilingual-en:end -->
