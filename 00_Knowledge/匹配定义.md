# Matchings
<!-- bilingual-en:end -->

*匹配*

<!-- bilingual-en:start -->
A **matching** chooses pairs without using any object twice. In a graph, the pairs are edges and the objects are their endpoints. Many possible edges can meet at a vertex, but at most one of them may be selected for the matching. This is the rule behind assigning each student at most one project and each project at most one student.
<!-- bilingual-en:end -->

**匹配**选择一组配对，同时不重复使用任何对象。在图中，配对是边，对象是边的端点。一个顶点可以接触许多候选边，但匹配至多选择其中一条。这就是每名学生至多得到一个项目、每个项目至多分给一名学生的规则。

> [!example] All selected edges must fit together · 选中的边必须能同时成立
> <!-- bilingual-en:start -->
> Suppose a student–project graph contains the edges $(a,1),(b,2),(b,1)$. Here $(a,1)$ denotes the undirected edge between student $a$ and project $1$. The set $\{(a,1),(b,2)\}$ is a matching: its four endpoints are distinct. The set $\{(a,1),(b,1)\}$ is not, because it uses project $1$ twice. Each chosen edge exists in the graph, but that check alone does not prevent conflicts between choices.
> <!-- bilingual-en:end -->
>
> 假设学生—项目图含有边 $(a,1),(b,2),(b,1)$，其中 $(a,1)$ 表示学生 $a$ 与项目 $1$ 之间的无向边。集合 $\{(a,1),(b,2)\}$ 是匹配，因为四个端点互不相同；集合 $\{(a,1),(b,1)\}$ 不是，因为它两次使用项目 $1$。每条选中边都存在，只能保证单独选择合法，还不能排除选择之间的冲突。

## The condition on an edge set
<!-- bilingual-en:end -->

*边集合需要满足什么条件*

<!-- bilingual-en:start -->
Let $G=(V,E)$ be a finite [[图类型的建模边界|simple undirected graph]]: each edge is an unordered pair of distinct vertices, with no loops or parallel copies. A subset $M\subseteq E$ is a **matching** precisely when distinct selected edges have no common endpoint:
<!-- bilingual-en:end -->

设 $G=(V,E)$ 是有限[[图类型的建模边界|简单无向图]]：每条边是两个不同顶点组成的无序对，没有自环或平行副本。子集 $M\subseteq E$ 称为**匹配**，当且仅当不同的选中边没有公共端点：

$$e\cap f=\varnothing\qquad\text{for every }e,f\in M\text{ with }e\ne f.$$

<!-- bilingual-en:start -->
Equivalently, each vertex is incident to at most one selected edge. If two selected edges shared a vertex, that vertex would violate this bound; if a vertex were incident to two selected edges, those edges would share an endpoint. Thus in the subgraph $(V,M)$, every vertex has [[度数、入度与出度|degree]] zero or one. If we retain only the covered vertices instead, every retained vertex has degree exactly one. These are two ways to display the same selected edge set.
<!-- bilingual-en:end -->

等价地，每个顶点至多接触一条选中边。若两条选中边有公共顶点，该顶点就违反这个上限；若某顶点接触两条选中边，那两条边就共享端点。因此，在子图 $(V,M)$ 中，每个顶点的[[度数、入度与出度|度数]]为零或一；若画图时只保留被覆盖的顶点，则每个留下的顶点度数恰好为一。这是同一个所选边集的两种画法。

<!-- bilingual-en:start -->
No bipartition is required for this definition. In a triangle with edges $ab,bc,ca$, any single edge is a matching, even though the triangle is not bipartite. The empty edge set is also a matching in every graph in this scope, including the graph with no vertices: there are no conflicting selected edges.
<!-- bilingual-en:end -->

这个定义不要求二分划分。三角形的边为 $ab,bc,ca$ 时，任意单边都是匹配，尽管三角形不是二分图。空边集也是本范围内任何图的匹配，包括没有顶点的图，因为没有相互冲突的选中边。

## Covered vertices and matching size
<!-- bilingual-en:end -->

*被覆盖的顶点与匹配大小*

<!-- bilingual-en:start -->
A vertex is **covered**, **matched**, or **saturated** by $M$ if it is an endpoint of a selected edge. Otherwise it is **uncovered** or **unmatched**. Coverage is relative to the particular matching, not just to the original graph. On the path $a-b-c$, the matching $\{ab\}$ covers $a,b$ and leaves $c$ unmatched, even though $c$ is adjacent to $b$.
<!-- bilingual-en:end -->

若顶点是某条所选边的端点，就称它被 $M$ **覆盖**，也称已匹配或已饱和（covered、matched、saturated）；否则称未覆盖或未匹配（uncovered、unmatched）。覆盖取决于具体匹配，不只取决于原图。在路径 $a-b-c$ 上，匹配 $\{ab\}$ 覆盖 $a,b$，却留下 $c$ 未匹配，即使 $c$ 邻接 $b$。

<!-- bilingual-en:start -->
The **size** $|M|$ counts selected edges, not covered vertices. If $|M|=k$, each edge contributes two different endpoints, and the matching condition prevents overlap between these pairs. Hence the covered set is the disjoint union of those $k$ pairs and has exactly $2k$ vertices:
<!-- bilingual-en:end -->

**大小** $|M|$ 数的是选中边，不是被覆盖顶点。若 $|M|=k$，每条边贡献两个不同端点，匹配条件又使不同边的端点不重叠。因此，被覆盖集合是这 $k$ 个两元素集合的不交并，恰有 $2k$ 个顶点：

$$\left|\bigcup_{e\in M}e\right|=2|M|.$$

<!-- bilingual-en:start -->
An isolated vertex is never covered by a matching because no graph edge touches it. The count also gives $|M|\le \lfloor |V|/2\rfloor$, where the floor symbol means the greatest integer at most $|V|/2$. In a [[二分图|bipartite graph]] with a specified split $L,R$, each selected edge contributes one different vertex on each side, so a matching of size $k$ covers exactly $k$ vertices in $L$ and $k$ in $R$.
<!-- bilingual-en:end -->

孤立顶点没有任何图边与之相接，因此永远不能被匹配覆盖。计数还给出 $|M|\le\lfloor |V|/2\rfloor$，其中向下取整符号表示不超过 $|V|/2$ 的最大整数。在已指定两侧 $L,R$ 的[[二分图]]中，每条选中边在每侧各贡献一个不重复顶点，所以大小为 $k$ 的匹配恰好覆盖 $L$ 中 $k$ 点与 $R$ 中 $k$ 点。

## Matching edges and independent vertices
<!-- bilingual-en:end -->

*匹配选边，独立集选点*

<!-- bilingual-en:start -->
An [[图的独立集|independent set]] selects vertices with no edge between two selected vertices. A matching selects edges with no shared endpoint. On $a-b-c$, the vertex set $\{a,c\}$ is independent, while the edge set $\{ab\}$ is a matching. The two-edge set $\{ab,bc\}$ is not a matching because both edges use $b$. Moreover, the covered vertices of $\{ab\}$ are $\{a,b\}$, which are adjacent and therefore not independent. The objects being selected and the forbidden conflicts are different.
<!-- bilingual-en:end -->

[[图的独立集|独立集]]选择顶点，要求所选顶点之间没有边；匹配选择边，要求所选边之间没有公共端点。在 $a-b-c$ 上，顶点集 $\{a,c\}$ 是独立集，边集 $\{ab\}$ 是匹配。两边集 $\{ab,bc\}$ 不是匹配，因为两条边都使用 $b$。而 $\{ab\}$ 覆盖的顶点为 $\{a,b\}$，它们恰好相邻，因此并不是独立集。两种概念所选对象与禁止的冲突不同。

## Feasibility comes before coverage or optimality
<!-- bilingual-en:end -->

*先判断合法，再问覆盖与最优*

<!-- bilingual-en:start -->
In a [[二分图配对关系|bipartite pairing model]], the allowed edge set is input data, and a matching is a choice that uses each endpoint at most once. Its definition does not require every object to be assigned, nor does it require the largest possible number of pairs. [[左侧覆盖与完美匹配|Left coverage and perfectness]] specify who must be covered; [[极大与最大匹配|maximality and maximum size]] compare a matching with other choices. These additional requirements do not alter the endpoint condition itself.
<!-- bilingual-en:end -->

在[[二分图配对关系|二分图配对模型]]中，允许边集是输入信息，匹配是每个端点至多使用一次的选择。定义不要求全部对象都被分配，也不要求配对数尽可能多。[[左侧覆盖与完美匹配|左侧覆盖与完美性]]规定谁必须被覆盖；[[极大与最大匹配|极大性与最大大小]]把匹配与其他选择比较。这些附加要求都不改变端点条件本身。

<!-- bilingual-en:start -->
For a loopless undirected multigraph, the same endpoint rule can be used while treating parallel edges as distinct choices. At most one of two parallel edges can belong to a matching because they share endpoints. The two-endpoints count remains valid. Self-loops are excluded from this convention: pairing a vertex with itself is not an allowed matching edge here.
<!-- bilingual-en:end -->

对于无自环的无向多重图，可以把平行边视为不同选择，同时沿用端点规则。两条平行边共享端点，因此匹配至多选择其中一条；每边覆盖两个顶点的计数仍成立。本卡约定排除自环：把顶点与自身配对，不是这里允许的匹配边。

> [!question]- Do existing edges automatically form a matching? · 边都存在，就一定是匹配吗？
> <!-- bilingual-en:start -->
> No. Every selected edge must belong to $E$, and no vertex may occur in two selected edges. For example, the three edges of a triangle all exist but cannot be selected together as a matching. The empty selection passes both requirements.
> <!-- bilingual-en:end -->
>
> 不一定。每条选中边必须属于 $E$，还必须没有顶点出现在两条选中边中。例如三角形的三条边都存在，却不能一起构成匹配；空选择则同时满足这两项要求。
