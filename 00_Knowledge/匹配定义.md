# 匹配是端点互不重复的边集

<!-- bilingual-en:start -->
*A matching is a set of edges with no repeated endpoint*
<!-- bilingual-en:end -->

> [!summary] 原子定义
> 在图 $G=(V,E)$ 中，matching 是边集 $M\subseteq E$，其中任意两条边都不共享端点。它表达“一项资源至多分给一个对象、一个对象也至多接受一项资源”。
>
> <!-- bilingual-en:start -->
> In a graph $G=(V,E)$, a matching is an edge set $M\subseteq E$ in which no two edges share an endpoint. It represents the rule that each resource can serve at most one object and each object can receive at most one resource.
> <!-- bilingual-en:end -->

顶点若接触某条 $M$ 中的边，就称为 covered、matched 或 saturated；否则称为 uncovered 或 unmatched。matching 的大小是 $|M|$，也就是被选中的边数。因为每条边覆盖两个不同顶点，一个大小为 $k$ 的 matching 恰好覆盖 $2k$ 个顶点。
<!-- bilingual-en:start -->
A vertex incident to an edge of $M$ is covered, matched, or saturated; otherwise it is uncovered or unmatched. The size of the matching is $|M|$, the number of selected edges. Since every edge covers two distinct vertices, a matching of size $k$ covers exactly $2k$ vertices.
<!-- bilingual-en:end -->

在学生—项目图中，$\{(a,1),(b,2)\}$ 是 matching；$\{(a,1),(b,1)\}$ 不是，因为项目 $1$ 被重复使用。只检查边是否存在还不够，选出的边之间还必须满足端点互斥。
<!-- bilingual-en:start -->
In a student–project graph, $\{(a,1),(b,2)\}$ is a matching, whereas $\{(a,1),(b,1)\}$ is not because project $1$ is used twice. It is not enough for each selected edge to exist; the selected edges must also be endpoint-disjoint.
<!-- bilingual-en:end -->

matching 只定义一个合法边集，不自动要求覆盖谁，也不自动表示它已经尽可能大。覆盖范围见 [[左侧覆盖与完美匹配|left-covering 与 perfect 的区别]]；相对大小见 [[极大与最大匹配|maximal 与 maximum 的区别]]。
<!-- bilingual-en:start -->
A matching is merely a feasible edge set. It does not automatically specify whom it must cover or whether it is as large as possible. See [[左侧覆盖与完美匹配|left-covering versus perfect matchings]] for coverage and [[极大与最大匹配|maximal versus maximum matchings]] for relative size.
<!-- bilingual-en:end -->

> [!question]- 回忆与辨别
> 三条选中边都存在于原图中，是否足以说明它们构成 matching？
>
> **答案：** 不足。还必须检查任意两条边都不共享端点。
