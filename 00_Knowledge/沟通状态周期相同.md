# Communicating states have the same period
<!-- bilingual-en:end -->
*互通状态共享同一个周期*

<!-- bilingual-en:start -->
If a Markov chain can travel from one state to another and back, the possible return lengths at those states cannot have different periods. The routes joining them let us convert a return at one state into a return at the other. This is why we can speak of the period of a whole communicating class, rather than recomputing an unrelated number for each state.
<!-- bilingual-en:end -->

若 Markov 链能从一个状态到另一个状态，再走回来，那么这两个状态的可能回返步数就不能有不同的周期。连接它们的往返路线，可以把某个状态的一次回返转化成另一个状态的回返。因此，我们能谈一个沟通类的共同周期，而不用给每个状态分别定义互不相关的数字。

<!-- bilingual-en:start -->
Two states [[马氏链沟通类|communicate]] if each is reachable from the other with positive probability in finitely many steps. A state's [[状态周期|period]] is the greatest positive integer dividing all of its possible positive return lengths. Here the chain uses one [[DTMC时间齐次转移核|time-homogeneous transition rule]] on a finite or countable state space.
<!-- bilingual-en:end -->

两个状态在有限步内有双向的正概率路线，就称它们[[马氏链沟通类|互通]]。一个状态的[[状态周期|周期]]，是能整除它全部可能正回返步数的最大正整数。这里考虑有限或可数状态空间、使用同一套[[DTMC时间齐次转移核|时间齐次转移规则]]的链。

> [!example] A common period even with an exit · 有出口，仍有共同周期
> <!-- bilingual-en:start -->
> Consider the row matrix below, with states $0,1,2$:
> <!-- bilingual-en:end -->
>
> 考虑状态 $0,1,2$ 的行随机矩阵：
>
> $$P=\begin{pmatrix}0&1/2&1/2\\1/2&0&1/2\\0&0&1\end{pmatrix}.$$
>
> <!-- bilingual-en:start -->
> States $0$ and $1$ communicate. A return to either one must alternate between them for an even number of steps; moving to $2$ prevents any later return. A return after $2k$ steps is possible with probability $(1/2)^{2k}>0$ for every positive integer $k$, and odd returns are impossible. Both periods are two, even though the class $\{0,1\}$ has an exit and a return is not certain.
> <!-- bilingual-en:end -->
>
> 状态 $0$ 与 $1$ 互通。要返回其中一个，就必须在两者间交替走偶数步；一旦去到 $2$，便再也回不来。对每个正整数 $k$，$2k$ 步回返的概率为 $(1/2)^{2k}>0$，奇数步则不可能返回。两个周期都为二，尽管类 $\{0,1\}$ 有出口，而且不保证最终一定返回。

> [!abstract] The class-property theorem · 周期的类性质
> <!-- bilingual-en:start -->
> In a finite or countable time-homogeneous Markov chain, any two distinct communicating states $i,j$ have nonempty positive return sets and satisfy $d(i)=d(j)$. Consequently, a communicating class whose states admit positive-time returns has one common period. The class need not be [[闭沟通类|closed]], and the states need not be [[常返与暂态|recurrent]].
> <!-- bilingual-en:end -->
>
> 在有限或可数状态的时间齐次 Markov 链中，任意两个不同的互通状态 $i,j$ 都具有非空正回返集合，并满足 $d(i)=d(j)$。所以，只要类内状态允许正时刻回返，一个沟通类就有共同周期。该类不必是[[闭沟通类]]，状态也不必[[常返与暂态|常返]]。

## Turn one state's returns into the other's
<!-- bilingual-en:end -->
*怎样把一个状态的回返接到另一个状态上*

<!-- bilingual-en:start -->
Choose a positive-probability route of $r\ge1$ steps from $i$ to $j$, and one of $s\ge1$ steps back from $j$ to $i$. These positive integers exist because the states are distinct and communicate. Concatenating the routes gives a positive-probability return of length $r+s$ at $i$; reversing their order gives one at $j$. Thus both periods are defined under the course's nonempty-return-set convention.
<!-- bilingual-en:end -->

选一条从 $i$ 到 $j$ 的正概率路线，长为 $r\ge1$ 步；再选一条从 $j$ 回 $i$ 的正概率路线，长为 $s\ge1$ 步。两个状态不同且互通，所以这样的正整数存在。把两段接起来，得到 $i$ 的一条 $r+s$ 步正概率回返；交换两段先后，也得到 $j$ 的回返。因此，按本课程要求回返集合非空的口径，两者周期都有定义。

<!-- bilingual-en:start -->
Now let $t\ge1$ be **any** possible return length at $j$. Travel from $i$ to $j$, make that $t$-step return to $j$, and travel back to $i$. [[DTMC转移复合|Transition composition]] gives a positive contribution
<!-- bilingual-en:end -->

再取 $j$ 的**任意一个**可能正回返步数 $t\ge1$。先从 $i$ 到 $j$，在 $j$ 做这次 $t$ 步回返，再回到 $i$。由[[DTMC转移复合]]，这条拼接路线提供一个正的概率贡献：

$$p_{ii}^{(r+t+s)}\ge p_{ij}^{(r)}p_{jj}^{(t)}p_{ji}^{(s)}>0.$$

<!-- bilingual-en:start -->
Since $d(i)$ [[整除|divides]] every return length at $i$, it divides both $r+s$ and $r+t+s$. It therefore divides their difference $t$. This holds for every positive return length $t$ at $j$, so $d(i)$ is a common divisor of that whole set, and $d(i)\le d(j)$. Interchanging $i$ and $j$ gives $d(j)\le d(i)$. Hence the periods are equal.
<!-- bilingual-en:end -->

因为 $d(i)$ [[整除]] $i$ 的每个回返步数，它同时整除 $r+s$ 与 $r+t+s$，也就整除二者之差 $t$。这对 $j$ 的每个正回返步数都成立，因此 $d(i)$ 是它们的一个公因子，必有 $d(i)\le d(j)$。交换 $i,j$ 的角色又得到 $d(j)\le d(i)$，于是周期相等。

<!-- bilingual-en:start -->
The argument uses only a few finite routes. It does not require a finite total number of states, a stationary distribution, certain return or an assumption excluding exits. That is why it applies to a communicating class inside a larger chain as well.
<!-- bilingual-en:end -->

证明只使用几条有限长度路线，不要求状态总数有限、不要求存在平稳分布、不要求必然返回，也不要求没有出口。因此，它同样适用于较大链内部的某个沟通类。

## The singleton exception and the practical consequence
<!-- bilingual-en:end -->
*单点例外与实际用法*

<!-- bilingual-en:start -->
A lone state can form a communicating class merely because zero steps reach itself. If it has no positive-time return, this course leaves its period undefined; the theorem does not assign it a period. A singleton with a positive self-loop has period one. Thus the empty-return convention must be handled before saying that every class has a period.
<!-- bilingual-en:end -->

一个孤立于其他互通关系的状态，仅凭零步可达自身，也可以构成单点沟通类。若它没有正时刻回返，本课程将周期记为未定义，定理不会替它赋值。若单点具有正自环，则周期为一。因此，说“每个类都有周期”之前，必须处理空回返集合的约定。

<!-- bilingual-en:start -->
For an [[不可约链|irreducible chain]], all states communicate, so the common period can be found at whichever state is easiest to inspect. An irreducible one-state chain must stay at its sole state and has period one. For larger irreducible chains, the theorem gives nonempty return sets. In particular, proving one state's period is one proves aperiodicity throughout the irreducible chain; it does not by itself supply every condition for [[有限链逐步收敛|distributional convergence]].
<!-- bilingual-en:end -->

[[不可约链]]的全部状态互通，因此可以选最容易检查的状态计算共同周期。不可约链若只有一个状态，就必须留在唯一状态，周期为一；若有多个状态，定理保证各个回返集合非空。特别地，在不可约链里证明一个状态周期为一，就证明了整条链的非周期性；但这本身并未提供[[有限链逐步收敛|分布收敛]]所需的全部条件。
