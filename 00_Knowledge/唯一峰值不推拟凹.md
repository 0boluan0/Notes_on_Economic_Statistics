# A unique peak and quasiconcavity
<!-- bilingual-en:end -->

*唯一峰值与拟凹性*

<!-- bilingual-en:start -->
A unique peak identifies where the largest output occurs. [[拟凹函数|Quasiconcavity]] additionally controls every lower threshold: the inputs reaching that threshold must form a [[凸集|convex set]]. A function can have just one highest point while some lower qualifying region has inward gaps.
<!-- bilingual-en:end -->

唯一峰值确定了最大输出在哪里取得。[[拟凹函数|拟凹性]]还控制每个较低门槛：达到该门槛的输入必须组成[[凸集]]。一个函数可以只有一个最高点，但某个较低的达标区域仍向内凹陷。

<!-- bilingual-en:start -->
## Locate the unique maximum first
<!-- bilingual-en:end -->

*先确定唯一全局最大点*

<!-- bilingual-en:start -->
Work on the whole plane $U=\mathbb R^2$ and define the real-valued function below. Absolute value makes each radicand nonnegative; $\sqrt{\cdot}$ denotes its nonnegative square root. Thus every point of this convex domain is allowed.
<!-- bilingual-en:end -->

取整个平面 $U=\mathbb R^2$，定义下面的实值函数。绝对值使根号内非负，$\sqrt{\cdot}$ 表示非负平方根，因此这个凸定义域里的每一点都可代入。

$$f(x,y)=-\sqrt{|x-1|}-\sqrt{|y-1|}.$$

<!-- bilingual-en:start -->
Each square root is nonnegative, so their negative sum is at most zero. It equals zero only if both roots are zero. The first vanishes exactly when $x=1$, and the second exactly when $y=1$. Hence $(1,1)$ gives value 0 and every other input gives a strictly negative value: this is a unique [[局部极值与绝对极值|global maximizing input]]. The input is the point $(1,1)$; the maximum value is the real number 0.
<!-- bilingual-en:end -->

两个平方根都非负，取负再相加就不超过零。要使结果等于零，两个根号必须同时为零；第一个恰在 $x=1$ 时为零，第二个恰在 $y=1$ 时为零。因此 $(1,1)$ 取值 0，其他输入严格小于零，这就是唯一的[[局部极值与绝对极值|全局最大点]]。取得最大值的输入是点 $(1,1)$，最大值则是实数 0。

令 $f(x,y)=-\sqrt{|x-1|}-\sqrt{|y-1|}$。它处处非正，且仅 $(1,1)$ 取零，因此有唯一全局最大点。

<!-- bilingual-en:start -->
## A lower threshold reveals the failure
<!-- bilingual-en:end -->

*较低门槛暴露问题*

<!-- bilingual-en:start -->
Now lower the threshold to $-1$. The [[上轮廓集|upper contour set]] contains inputs whose outputs are at least $-1$. Multiplying by $-1$ reverses the comparison, giving
<!-- bilingual-en:end -->

现在把门槛降到 $-1$。[[上轮廓集]]包含输出至少为 $-1$ 的输入；两边乘以 $-1$ 时不等号反向，所以

$$C_{-1}^+=\{(x,y)\in\mathbb R^2:\sqrt{|x-1|}+\sqrt{|y-1|}\le1\}.$$

<!-- bilingual-en:start -->
Take $a=(1,0)$ and $b=(0,1)$. At either point one root is 0 and the other is 1, so $f(a)=f(b)=-1$; both points qualify, including equality. Their midpoint is $z=(1/2,1/2)$. Each root there is $\sqrt{1/2}$, so
<!-- bilingual-en:end -->

取 $a=(1,0)$、$b=(0,1)$。两个点处都是一个根号为 0、另一个为 1，因此 $f(a)=f(b)=-1$，恰好等于门槛，也都达标。中点为 $z=(1/2,1/2)$，两个根号都等于 $\sqrt{1/2}$，于是

$$f(z)=-2\sqrt{1/2}=-\sqrt2<-1.$$

<!-- bilingual-en:start -->
The strict inequality holds because $\sqrt2>1$, as follows by comparing their nonnegative squares, 2 and 1. The midpoint is in the domain but is not in $C_{-1}^+$. Thus this upper set is not convex, and the [[拟凹性线段判据|minimum-endpoint comparison]] fails.
<!-- bilingual-en:end -->

严格不等式来自 $\sqrt2>1$：比较两者的非负平方 2 与 1 即可。中点属于定义域，却不属于 $C_{-1}^+$，所以该上轮廓集不凸，[[拟凹性线段判据|最小端点比较]]也失败。

<!-- bilingual-en:start -->
The function has a unique maximum of zero, but two inputs at level minus one have a midpoint below that threshold. Its [[上轮廓集|upper contour set]] is therefore nonconvex. Quasiconcavity constrains every threshold region rather than just the location of the highest point.
<!-- bilingual-en:end -->

但是 $f(1,0)=f(0,1)=-1$，而中点值 $f(1/2,1/2)=-\sqrt2<-1$，故门槛 $-1$ 的[[上轮廓集]]不凸。拟凹性要求每个高度的达标区域凸，不只要求最高点唯一。

<!-- bilingual-en:start -->
## What the counterexample establishes
<!-- bilingual-en:end -->

*这个反例说明了什么*

> [!warning] A good top set is not enough · 最高层通过还不够
> <!-- bilingual-en:start -->
> Here the threshold-zero set is the singleton $\{(1,1)\}$, which is convex; every positive-threshold set is empty and convex too. Nevertheless, threshold $-1$ fails. To prove quasiconcavity one must cover all thresholds; to disprove it one failed threshold and one failed segment suffice.
> <!-- bilingual-en:end -->
>
> 本例门槛 0 的集合是单点 $\{(1,1)\}$，确实凸；所有正门槛的集合也都是凸的空集。但门槛 $-1$ 失败。证明拟凹须覆盖所有门槛；否定拟凹，只需一个失败门槛和一条失败线段。

<!-- bilingual-en:start -->
This does not prevent a quasiconcave function from having a unique maximum. It refutes the proposed sufficient condition “unique maximum implies quasiconcavity.” The stronger one-dimensional [[一维单峰函数拟凹性|rise-then-fall condition]] controls the whole shape. In several dimensions, locating a highest point supplies no comparable ordering of every segment.
<!-- bilingual-en:end -->

这不妨碍拟凹函数拥有唯一最大点；它否定的是“唯一最大点推出拟凹”这一充分条件。较强的一维[[一维单峰函数拟凹性|先非减后非增条件]]控制整个形状，而在多维中，定位最高点并没有给出每条线段上的类似排序。
