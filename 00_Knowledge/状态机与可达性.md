# State machines and reachability
<!-- bilingual-en:end -->

状态机与可达性

<!-- bilingual-en:start -->
A **state machine** describes a process one allowed step at a time. A state records the information we need now; a transition says which next states are allowed. **Reachability** asks whether a particular state can actually be reached from the chosen start. This gives a precise way to separate a possible configuration from one that the process can produce.
<!-- bilingual-en:end -->

**状态机**把过程描述成一次次允许的步骤。状态记录当前需要知道的信息，转移规定下一步允许去哪些状态。**可达性**问的是：从选定起点出发，过程是否真的能到达某个状态。这使“可以写出的配置”与“过程能够产生的配置”有了精确区别。

<!-- bilingual-en:start -->
> [!example] Example
> Take four states $S=\{0,1,2,3\}$, start at $0$, and allow exactly
> 
> $$0\to1,\qquad1\to0,\qquad1\to2,\qquad3\to2.$$
> 
> The sequence $0,1,0,1,2$ is a legal execution. State $2$ is reachable, but state $3$ is not: no legal step leads from the start's reachable region to $3$. The outgoing arrow $3\to2$ does not help us reach $3$. State $1$ has a choice of successors, while $2$ has no successor.
<!-- bilingual-en:end -->

> [!example] 例子
> 取四个状态 $S=\{0,1,2,3\}$，起点为 $0$，只允许
> 
> $$0\to1,\qquad1\to0,\qquad1\to2,\qquad3\to2.$$
> 
> 序列 $0,1,0,1,2$ 是合法执行。状态 $2$ 可达，状态 $3$ 不可达：没有合法步骤能从起点可达的区域进入 $3$。从 $3$ 出发的箭头 $3\to2$ 并不能帮助到达 $3$。状态 $1$ 可以选择不同后继，状态 $2$ 则没有后继。

## The model and its executions
<!-- bilingual-en:end -->

状态、起点与合法执行

<!-- bilingual-en:start -->
> [!definition] The state-machine model
> A state machine describes a step-by-step process by a set of states, a designated start state, and an allowed transition relation $q\to r$. An execution is a sequence beginning at the start state whose consecutive states obey the transition relation. A state is reachable exactly when it appears in at least one such execution.
<!-- bilingual-en:end -->

> [!definition] 状态机模型
> 状态机用三部分描述逐步过程：状态集合、指定起点、允许的转移关系 $q\to r$。执行是从起点开始且每一对相邻状态都满足转移关系的序列；某状态可达，当且仅当它出现在至少一条这样的执行中。

<!-- bilingual-en:start -->
Formally, choose a set $S$ of states, a start state $s_0\in S$, and a set $T$ of **ordered pairs** $(q,r)$ of states. An ordered pair records the direction: $(q,r)\in T$ means that a step from $q$ to $r$ is allowed; we write $q\to r$. Writing $T\subseteq S\times S$ is shorthand for saying that every pair in $T$ has both entries in $S$. Since the start belongs to $S$, this model has at least one state; $S$ itself may be finite or infinite. The transition set may be empty.
<!-- bilingual-en:end -->

形式上，选定状态集合 $S$、起始状态 $s_0\in S$，以及由状态的**有序对** $(q,r)$ 组成的集合 $T$。有序对保留方向：$(q,r)\in T$ 表示允许从 $q$ 走到 $r$，记为 $q\to r$。$T\subseteq S\times S$ 只是简写，表示 $T$ 中每对的两个成员都属于 $S$。起点必须属于 $S$，所以这种模型至少有一个状态；$S$ 可以有限，也可以无限。转移集合可以为空。

<!-- bilingual-en:start -->
A finite execution has the form

$$s_0,q_1,\ldots,q_k,\qquad k\ge0,$$

with every adjacent pair an allowed transition. Here $k$ is a nonnegative integer counting **transitions**, so the execution has $k+1$ state entries. Repeated states are allowed. The one-entry execution $(s_0)$ makes the start reachable in zero steps. Every finite prefix of an infinite execution is also an execution. A state appearing in an infinite execution appears at some finite index; reachability does not include an extra state obtained only as a limit after infinitely many steps.
<!-- bilingual-en:end -->

有限执行可以写成

$$s_0,q_1,\ldots,q_k,\qquad k\ge0,$$

并要求每对相邻状态构成允许转移。这里 $k$ 是非负整数，数的是**转移次数**，所以序列包含 $k+1$ 个状态项。状态可以重复出现。只含一项的执行 $(s_0)$ 表明起点零步可达。无限执行的每个有限前缀也是执行。无限执行中出现的状态总是在某个有限下标处出现；可达性不额外包含“无限步之后才取极限得到”的状态。

<!-- bilingual-en:start -->
A finite execution need not be finished: $(0,1)$ above is a valid prefix even though further moves are possible. A **terminal state** has no outgoing transition; in the example this is $2$. An infinite execution such as $0,1,0,1,\ldots$ is also allowed by this model. Thus “a terminal state is reachable” does not mean that every execution must terminate. Proving that every continuing execution eventually stops is a separate [[秩函数与终止证明|termination argument]].
<!-- bilingual-en:end -->

有限执行不一定已经结束：例中的 $(0,1)$ 是合法前缀，即使后面还能继续走。**终止状态**是没有出边的状态，例中为 $2$。模型也允许 $0,1,0,1,\ldots$ 这样的无限执行。因此，“某个终止状态可达”不等于“每条执行都会终止”。证明所有持续执行最终都会停下来，需要另外的[[秩函数与终止证明|终止性论证]]。

## Choosing what a state records
<!-- bilingual-en:end -->

状态需要记录什么

<!-- bilingual-en:start -->
For a register program, a state may be the tuple of all register values, and each program rule defines allowed transitions. A tuple does not become reachable merely because it satisfies some algebraic equation; there must be a legal path to it from the designated start state.
<!-- bilingual-en:end -->

一个寄存器程序的状态可以是全部寄存器值组成的元组；每条程序规则定义允许的转移。一个数值元组即使代数上满足某个方程，也不因此可达：还必须存在从指定初态按合法规则到达它的路径。

<!-- bilingual-en:start -->
For a program, the stored data may need to include the current instruction or stage as well as numerical registers. The state must determine which transitions are permitted, although it need not determine a unique successor. A state-machine execution describes a process; it does not assign probabilities to its alternatives. The reachable-set definition therefore does not require a probability model.
<!-- bilingual-en:end -->

对于程序，除了数值寄存器，状态还可能需要记录当前指令或阶段。给定状态应能确定允许哪些转移，但不必确定唯一后继。状态机执行描述过程，并不自动为不同选择赋予概率；可达集合的定义因此不需要概率模型。

## Boundaries
<!-- bilingual-en:end -->

## 边界

<!-- bilingual-en:start -->

&nbsp;
**1.** The transition relation may be nondeterministic: a state can have several successors without invalidating the model, and reachability still means existence of an execution.<br>
**2.** Membership in the state space does not imply reachability. Correctness arguments usually constrain reachable states, but must justify how the constraint propagates from the start state.<br>
<!-- bilingual-en:end -->

- 转移关系可以是非确定的：一个状态允许多个后继并不会破坏模型，可达性仍按“存在一条执行”定义。
- 状态空间中的对象不等于可达状态。正确性证明通常只需约束可达状态，但必须给出把约束从起点传到所有可达状态的理由。

<!-- bilingual-en:start -->
> [!question]- Check the predecessor
> A state $r$ belongs to the state space, and some state $q$ satisfies $q\to r$. Is that enough to prove $r$ reachable?
>
> **Answer:** No. One must also show that $q$ is reachable. Only then can the transition be appended to a legal execution beginning at the designated start state.
<!-- bilingual-en:end -->

> [!question]- 回忆与应用
> 一个状态 $r$ 属于状态集合，并且存在某个状态 $q$ 满足 $q\to r$。这足以证明 $r$ 可达吗？
>
> **答案：** 不足。还要证明 $q$ 本身可达；只有把该转移接到一条从指定起点开始的合法执行上，才能推出 $r$ 可达。
