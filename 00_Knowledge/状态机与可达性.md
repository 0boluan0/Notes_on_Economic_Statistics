# 状态机由状态起点与转移定义而可达性只看合法执行
<!-- bilingual-en:start -->
*A state machine is defined by states, a start state, and transitions, while reachability concerns only legal executions*
<!-- bilingual-en:end -->

> [!summary] 原子模型
> 状态机用三部分描述逐步过程：状态集合、指定起点、允许的转移关系 $q\to r$。执行是从起点开始且每一对相邻状态都满足转移关系的序列；某状态可达，当且仅当它出现在至少一条这样的执行中。
> <!-- bilingual-en:start -->
> A state machine describes a step-by-step process by a set of states, a designated start state, and an allowed transition relation $q\to r$. An execution is a sequence beginning at the start state whose consecutive states obey the transition relation. A state is reachable exactly when it appears in at least one such execution.
> <!-- bilingual-en:end -->

一个寄存器程序的状态可以是全部寄存器值组成的元组；每条程序规则定义允许的转移。一个数值元组即使代数上满足某个方程，也不因此可达：还必须存在从指定初态按合法规则到达它的路径。
<!-- bilingual-en:start -->
For a register program, a state may be the tuple of all register values, and each program rule defines allowed transitions. A tuple does not become reachable merely because it satisfies some algebraic equation; there must be a legal path to it from the designated start state.
<!-- bilingual-en:end -->

## 边界
<!-- bilingual-en:start -->
*Boundary*
<!-- bilingual-en:end -->

- 转移关系可以是非确定的：一个状态允许多个后继并不会破坏模型，可达性仍按“存在一条执行”定义。
- 状态空间中的对象不等于可达状态。正确性证明通常只需约束可达状态，但必须给出把约束从起点传到所有可达状态的理由。
<!-- bilingual-en:start -->

**1.** The transition relation may be nondeterministic: a state can have several successors without invalidating the model, and reachability still means existence of an execution.<br>
**2.** Membership in the state space does not imply reachability. Correctness arguments usually constrain reachable states, but must justify how the constraint propagates from the start state.<br>
<!-- bilingual-en:end -->

> [!question]- 回忆与应用
> 一个状态 $r$ 属于状态集合，并且存在某个状态 $q$ 满足 $q\to r$。这足以证明 $r$ 可达吗？
>
> **答案：** 不足。还要证明 $q$ 本身可达；只有把该转移接到一条从指定起点开始的合法执行上，才能推出 $r$ 可达。
> <!-- bilingual-en:start -->
> A state $r$ belongs to the state space, and some state $q$ satisfies $q\to r$. Is that enough to prove $r$ reachable?
>
> **Answer:** No. One must also show that $q$ is reachable. Only then can the transition be appended to a legal execution beginning at the designated start state.
> <!-- bilingual-en:end -->
