# 序贯理性要求给定每个信息集的信念与他人续局策略，玩家从该信息集起的完整续局策略最大化条件期望收益
<!-- bilingual-en:start -->
*Sequential rationality requires a player's complete continuation strategy from every information set to maximize conditional expected payoff, given beliefs there and the other players' continuation strategies.*
<!-- bilingual-en:end -->

> [!summary] 核心要求
> 序贯理性把每个信息集都当成“现在真的走到这里”的条件决策问题。给定该处的[[信息集信念|belief]]和其他玩家此后的策略，行动者必须愿意执行候选策略规定的整个续局计划；均衡路径外的信息集也不能免检。
> <!-- bilingual-en:start -->
> *Core requirement*
>
> Sequential rationality treats every information set as a conditional decision problem in which the game has actually arrived there. Given the [[信息集信念|belief]] at that point and the other players' continuation strategies, the decision-maker must be willing to follow the candidate strategy's entire continuation plan. Off-path information sets are not exempt.
> <!-- bilingual-en:end -->

## 条件最优性
<!-- bilingual-en:start -->
*Conditional optimality*
<!-- bilingual-en:end -->

给定[[策略信念评估|assessment]] $(\sigma,\mu)$，对玩家 $i$ 的每个信息集 $I\in\mathcal H_i$，令
<!-- bilingual-en:start -->
Given an [[策略信念评估|assessment]] $(\sigma,\mu)$, for each information set $I\in\mathcal H_i$ of player $i$, let
<!-- bilingual-en:end -->

$$
U_i(\sigma_i',\sigma_{-i}\mid I,\mu(\cdot\mid I))
$$

表示：条件于 $I$ 已到达，用 $\mu(\cdot\mid I)$ 对集合内可能节点加权，其他玩家按 $\sigma_{-i}$ 继续，而玩家 $i$ 从 $I$ 起使用续局策略 $\sigma_i'$ 时的期望收益。序贯理性要求
<!-- bilingual-en:start -->
denote the expected payoff conditional on reaching $I$, where $\mu(\cdot\mid I)$ weights the possible nodes in the information set, the other players continue according to $\sigma_{-i}$, and player $i$ uses continuation strategy $\sigma_i'$ from $I$ onward. Sequential rationality requires
<!-- bilingual-en:end -->

$$
\sigma_i|_I
\in
\arg\max_{\sigma_i'\in\Sigma_i(I)}
U_i(\sigma_i',\sigma_{-i}\mid I,\mu(\cdot\mid I))
$$

对所有 $i$ 与 $I\in\mathcal H_i$ 成立。$\Sigma_i(I)$ 包含从 $I$ 起当前及后续信息集上的完整可行计划；玩家在到达 $I$ 以前已经发生的行动不再是此处可改的选择。
<!-- bilingual-en:start -->
for every $i$ and every $I\in\mathcal H_i$. $\Sigma_i(I)$ contains complete feasible plans at the current and all subsequent information sets from $I$ onward. Actions taken before reaching $I$ have already occurred and are not choices that can be revised at this point.
<!-- bilingual-en:end -->

## 不是只检查当前一个按钮
<!-- bilingual-en:start -->
*It is not merely a check of the current move.*
<!-- bilingual-en:end -->

在最简单的两阶段[[信号博弈]]里，接收者在观察信号后只行动一次，序贯理性可退化为“该行动是 belief 下的最佳反应”。在更长的动态博弈里，玩家此后还可能再次行动，因此必须比较从当前信息集起的整套 continuation strategy，而不是只比较眼前一步后假定自己的未来行为固定。
<!-- bilingual-en:start -->
In the simplest two-stage [[信号博弈|signaling game]], the receiver acts only once after observing the signal, so sequential rationality reduces to requiring that action to be a best response under the belief. In a longer dynamic game, the player may act again later. One must therefore compare complete continuation strategies from the current information set rather than compare only the immediate move while holding the player's future behavior fixed.
<!-- bilingual-en:end -->

同理，发送者的每一种类型都必须比较所有可发送信号及其后果。只验证接收者最优、却没有验证某一类型是否愿意模仿另一类型，仍未完成序贯理性检查。
<!-- bilingual-en:start -->
Likewise, every sender type must compare all available signals and their consequences. Verifying only the receiver's optimality, without checking whether one type wants to imitate another, does not complete the sequential-rationality test.
<!-- bilingual-en:end -->

## 路径外也必须最优
<!-- bilingual-en:start -->
*Optimality is required off path as well.*
<!-- bilingual-en:end -->

一个信息集在候选策略下概率为零，只说明它不会按计划发生，不说明该处可以规定非理性行动。必须先假设它已经发生，再用指定的[[路径外信念]]计算续局最佳反应。这与[[可信威胁]]的直觉一致，但信息集可能含多个节点，不能像完美信息子博弈那样任意挑一个节点收益。
<!-- bilingual-en:start -->
An information set having zero probability under the candidate strategy means only that it will not occur as planned; it does not permit an irrational action there. One must suppose that the information set has been reached and use the specified [[路径外信念|off-path belief]] to calculate a best continuation response. This matches the intuition behind [[可信威胁|credible threats]], but an information set may contain several nodes, so one cannot simply select the payoff at an arbitrary node as in a perfect-information subgame.
<!-- bilingual-en:end -->

序贯理性本身并不判断 belief 是否可信。只要人为选择一份 belief，某个奇怪续局也可能成为最佳反应；因此它必须与[[路径上一致性]]结合才形成[[完美贝叶斯均衡|弱 PBE]]，而[[序贯均衡]]还会约束路径外 belief 的来源。
<!-- bilingual-en:start -->
Sequential rationality by itself does not determine whether a belief is credible. With a suitably chosen belief, an unusual continuation may become a best response. Sequential rationality must therefore be combined with [[路径上一致性|on-path consistency]] to form a [[完美贝叶斯均衡|weak PBE]], while [[序贯均衡|sequential equilibrium]] also constrains the origin of off-path beliefs.
<!-- bilingual-en:end -->

> [!example] 为什么 Nash 最优还不够
> 若开局行动让接收者的信息集永不达到，接收者在那里规定什么都不改变 ex-ante Nash 收益。但序贯理性会条件于该信息集已经到达，再按 belief 比较接收者的行动；严格较差的路径外行动会被排除。
> <!-- bilingual-en:start -->
> *Why Nash optimality is not enough*
>
> If an initial action makes the receiver's information set unreachable, the receiver's prescription there does not affect ex-ante Nash payoffs. Sequential rationality instead conditions on that information set having been reached and compares the receiver's actions under the stated belief, eliminating a strictly inferior off-path action.
> <!-- bilingual-en:end -->

> [!question]- 自检
> 候选策略在均衡路径上无人愿意偏离，但接收者在一个零概率信息集上选择了 belief 下严格较差的行动。该 assessment 是否序贯理性？
>
> **答案：** 不是。序贯理性逐信息集检查条件最优性，不因信息集位于路径外而豁免。
> <!-- bilingual-en:start -->
> *Self-check*
>
> No one wants to deviate along the equilibrium path, but the receiver chooses a strictly inferior action under the belief at a zero-probability information set. Is the assessment sequentially rational?
>
> **Answer:** No. Sequential rationality tests conditional optimality at every information set; an information set is not exempt merely because it is off path.
> <!-- bilingual-en:end -->
