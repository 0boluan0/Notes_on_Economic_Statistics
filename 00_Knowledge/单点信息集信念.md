# 单点信息集仍属于信念系统，其唯一信念对唯一节点赋概率一，通常只是不必单独报告
<!-- bilingual-en:start -->
*A singleton information set still belongs to the belief system; its unique belief assigns probability one to its sole node, so it usually need not be reported separately.*
<!-- bilingual-en:end -->

若信息集只有一个节点 $I=\{x\}$，则 $\Delta(I)$ 中只有一个概率分布：
<!-- bilingual-en:start -->
If an information set contains only one node, $I=\{x\}$, then $\Delta(I)$ contains only one probability distribution:
<!-- bilingual-en:end -->

$$
\mu(x\mid I)=1.
$$

因此，单点信息集不是“没有信念”，而是信念没有自由度。
<!-- bilingual-en:start -->
Thus a singleton information set does not have “no belief”; rather, its belief has no degree of freedom.
<!-- bilingual-en:end -->

## 形式上仍由信念系统覆盖
<!-- bilingual-en:start -->
*It is still formally covered by the belief system.*
<!-- bilingual-en:end -->

信念系统为每个信息集指定其节点上的概率分布。这个定义同样覆盖单点信息集，只是唯一可行分布已经由概率公理决定，不需要额外求解。
<!-- bilingual-en:start -->
A belief system assigns a probability distribution over the nodes of every information set. The definition also covers singleton information sets, but probability axioms already determine the only feasible distribution, so there is nothing further to solve.
<!-- bilingual-en:end -->

## 不报告不等于不存在
<!-- bilingual-en:start -->
*Omission from a solution does not imply nonexistence.*
<!-- bilingual-en:end -->

解答通常只报告含多个节点、需要比较节点可能性的信念。省略单点信息集的 $\mu=1$ 是记号简化，不是把它排除在 assessment 之外。即使该单点信息集以零概率到达，其内部信念仍唯一；路径外到达只影响 Bayes 一致性怎样约束信念，并不会创造第二种分布。
<!-- bilingual-en:start -->
Solutions usually report only beliefs at multi-node information sets where relative likelihoods must be assessed. Omitting $\mu=1$ at a singleton is a notational convenience, not an exclusion from the assessment. Even if the singleton information set is reached with zero probability, its internal belief remains unique: off-path reachability changes how Bayes consistency constrains beliefs, but it cannot create a second distribution on a one-node set.
<!-- bilingual-en:end -->
