# Maximal and maximum matchings
<!-- bilingual-en:end -->

*极大匹配与最大匹配*

<!-- bilingual-en:start -->
“No more edges fit” can mean two different things. Perhaps no edge can be added while keeping every current choice. Or perhaps no alternative choice of edges could produce more pairs. A **maximal matching** satisfies the first condition; a **maximum matching** satisfies the second. The distinction matters whenever improving an assignment requires undoing an earlier choice.
<!-- bilingual-en:end -->

“不能再配更多”可能有两种意思：保留当前全部选边时，再也加不进一条边；或者即使重新选择，也不可能得到更多配对。**极大匹配**满足前者，**最大匹配**满足后者。只要改进分配可能需要撤销旧选择，这一区别就很重要。

> [!example] A four-vertex path · 四顶点路径
> <!-- bilingual-en:start -->
> Let the only edges be $v_1v_2,v_2v_3,v_3v_4$, where $v_iv_j$ denotes an undirected edge. The matching $M=\{v_2v_3\}$ selects the middle edge. Each remaining edge shares an endpoint with it, so no edge can be added: $M$ is maximal. Yet $M'=\{v_1v_2,v_3v_4\}$ has two disjoint edges, so $M$ is not maximum. Four vertices suffice for the distinction; fewer than four cannot support a matching of size two.
> <!-- bilingual-en:end -->
>
> 设图中只有边 $v_1v_2,v_2v_3,v_3v_4$，其中 $v_iv_j$ 表示一条无向边。匹配 $M=\{v_2v_3\}$ 只选中间边，剩下每条边都与它共享端点，因此不能再加边，$M$ 是极大的。但 $M'=\{v_1v_2,v_3v_4\}$ 有两条端点不重合的边，所以 $M$ 不是最大的。四个顶点已经足以体现区别；少于四个顶点不可能容纳大小为二的匹配。

## Inclusion versus number of edges
<!-- bilingual-en:end -->

*集合包含关系与边数的区别*

<!-- bilingual-en:start -->
Let $G=(V,E)$ be a finite [[图类型的建模边界|simple undirected graph]]. A [[匹配定义|matching]] $M\subseteq E$ contains no two edges with a common endpoint, and its size $|M|$ is its number of edges. The two definitions compare $M$ with other matchings in different ways:
<!-- bilingual-en:end -->

设 $G=(V,E)$ 是有限[[图类型的建模边界|简单无向图]]。[[匹配定义|匹配]] $M\subseteq E$ 中任意两条边没有公共端点，大小 $|M|$ 就是边数。两个定义以不同方式把 $M$ 与其他匹配比较：

$$\begin{aligned}
M\text{ is maximal}
&\iff \text{there is no matching }M'\text{ with }M\subsetneq M',\\
M\text{ is maximum}
&\iff |M'|\le |M|\text{ for every matching }M'.
\end{aligned}$$

<!-- bilingual-en:start -->
Here $M\subsetneq M'$ means that every edge of $M$ is retained and at least one new edge is added. A larger matching need not contain the old one: in the path example, the two-edge matching discards the middle edge. “Maximum” concerns cardinality, not total weight, and it does not imply that the maximizing edge set is unique.
<!-- bilingual-en:end -->

其中 $M\subsetneq M'$ 表示保留 $M$ 的每条边，并至少新增一条边。边数更多的匹配却不一定包含旧匹配：路径例中的两边匹配撤掉了中间边。“最大”在这里指基数，即边数，不是总权重；它也不意味着达到最大边数的边集唯一。

<!-- bilingual-en:start -->
## How to check maximality locally
<!-- bilingual-en:end -->

*怎样直接检查极大性？*

<!-- bilingual-en:start -->
A matching is maximal exactly when no graph edge joins two vertices that it leaves unmatched. If such an edge exists, adding it creates no endpoint conflict. Conversely, if a strictly larger matching containing $M$ existed, any new edge in it would have both endpoints unmatched by $M$, so that edge alone could have been added. Thus checking one-edge extensions is enough to test inclusion-maximality.
<!-- bilingual-en:end -->

匹配极大，当且仅当图中没有一条边连接两个尚未被它匹配的顶点。若存在这样的边，加入它不会产生端点冲突。反过来，若存在严格包含 $M$ 的匹配，则其中任意一条新增边的两端都没有被 $M$ 匹配，因此单独加这条边就已经可行。所以，检查能否直接加一条边，足以判断包含意义下的极大性。

<!-- bilingual-en:start -->
Equivalently, the unmatched vertices form an [[图的独立集|independent set]]. They need not be isolated: in the path example, $v_1$ and $v_4$ both have neighbors, but neither can be matched without displacing the middle edge. Starting with the empty matching and repeatedly adding any edge with two unmatched endpoints eventually produces a maximal matching because the graph is finite. That stopping rule alone does not prove maximum size.
<!-- bilingual-en:end -->

等价地，未匹配顶点构成[[图的独立集|独立集]]。它们不必是孤立点：路径例中的 $v_1,v_4$ 都有邻点，却都无法在保留中间边的同时得到配对。从空匹配开始，反复加入两端都未匹配的边，因图有限，最终会停在一个极大匹配。仅凭这一停止规则，不能证明边数已经最大。

<!-- bilingual-en:start -->
## Why maximum implies maximal
<!-- bilingual-en:end -->

*为什么最大一定极大？*

<!-- bilingual-en:start -->
If a maximum matching were not maximal, an edge could be added, producing a matching with $|M|+1$ edges. This contradicts maximum cardinality. The converse fails by the four-vertex path. For that path, the two-edge matching really is maximum: each selected edge consumes two distinct vertices, so four vertices allow at most two edges. This counting bound proves optimality without needing to try every matching.
<!-- bilingual-en:end -->

若最大匹配不是极大的，就能再加入一条边，得到大小为 $|M|+1$ 的匹配，与最大基数矛盾。反向不成立，四顶点路径已经给出反例。该路径中的两边匹配确实最大：每条选中边要占用两个不同顶点，四个顶点至多容纳两条边。这个计数上界已证明最优，无需试遍所有匹配。

<!-- bilingual-en:start -->
More generally, a [[左侧覆盖与完美匹配|perfect matching]] in a finite graph is maximum because it uses every vertex and has $|V|/2$ edges. A maximum matching need not be perfect: on a triangle, any single edge is maximum, while one vertex must remain unmatched. There are three different maximum matchings there. On an edgeless graph the empty matching is both maximal and maximum; it is perfect only when there are no vertices. These examples keep coverage, inclusion and size separate.
<!-- bilingual-en:end -->

一般地，有限图中的[[左侧覆盖与完美匹配|完美匹配]]覆盖全部顶点，有 $|V|/2$ 条边，因此一定最大。但最大匹配未必完美：三角形上任意一条边构成最大匹配，却必然留下一个未匹配顶点，而且有三种不同的最大匹配。无边图的空匹配既极大又最大；只有顶点集也为空时才完美。这些例子把覆盖范围、集合包含与边数分开。

## Improvement may require reassignment
<!-- bilingual-en:end -->

*改进可能需要重新分配*

<!-- bilingual-en:start -->
In the path example, walk from $v_1$ to $v_4$: the edges are unselected, selected, unselected, and both endpoints are unmatched. This is an [[增广路定义|augmenting path]]. [[增广路对称差|Flipping it]] removes $v_2v_3$ and inserts $v_1v_2,v_3v_4$, increasing the size from one to two. The new matching improves cardinality by replacing edges, not by containing the old edge set.
<!-- bilingual-en:end -->

在路径例中从 $v_1$ 走到 $v_4$，依次经过未选、已选、未选边，且两端都未匹配，所以这是一条[[增广路定义|增广路]]。[[增广路对称差|翻转]]会撤去 $v_2v_3$，加入 $v_1v_2,v_3v_4$，大小从一增加到二。新匹配通过换边提高基数，而不是包含旧边集。

<!-- bilingual-en:start -->
For finite graphs, [[Berge最大匹配定理|Berge's theorem]] says that a matching is maximum exactly when no augmenting path exists. Maximality checks only whether an augmenting path consisting of one edge exists; it does not rule out longer ones. The theorem is one route to an optimality proof, while a matching upper bound met by the construction is another.
<!-- bilingual-en:end -->

对有限图，[[Berge最大匹配定理|Berge 定理]]说明，匹配最大当且仅当不存在增广路。极大性只排除了由单独一条边组成的增广路，没有排除更长的增广路。该定理是一种最优性证明途径；构造达到匹配大小的上界，也是另一种途径。

> [!warning] Size is not weight · 边数不是权重
> <!-- bilingual-en:start -->
> Give the middle edge of the four-vertex path weight $100$ and each end edge weight $1$. The two-edge matching has greater cardinality but total weight $2$, whereas the one-edge matching has weight $100$. Maximizing total weight is a different objective. In this card, “maximum” always means maximum number of edges in a finite graph.
> <!-- bilingual-en:end -->
>
> 给四顶点路径的中间边权重 $100$，两端边各为 $1$。两边匹配的基数更大，但总权重为 $2$；一条中间边的权重却为 $100$。最大化总权重是另一个目标。本卡的“最大”始终指有限图中的最大边数。
