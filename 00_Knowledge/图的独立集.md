# Independent vertex sets
<!-- bilingual-en:end -->

*图的独立集*

<!-- bilingual-en:start -->
An **independent set** is a selection of vertices with no edge joining two selected vertices. In a conflict model, it is one group whose members can share a resource as far as the recorded pairwise conflicts are concerned. “Independent” here describes edges in a graph; it is not probabilistic independence.
<!-- bilingual-en:end -->

图的**独立集**是这样选出的一组顶点：所选顶点之间没有边。在冲突模型中，它表示只考虑图中已记录的成对冲突时，可以共享资源的一组对象。这里的“独立”描述图的边，不是概率中的事件独立。

<!-- bilingual-en:start -->
Take the three-vertex chain $a-b-c$, whose only edges are $ab$ and $bc$. The set $\{a,c\}$ is independent: the route through $b$ does not create a direct edge $ac$. The set $\{a,b\}$ is not independent because it contains both ends of $ab$.
<!-- bilingual-en:end -->

取三个顶点构成的链 $a-b-c$，仅有边 $ab$ 和 $bc$。集合 $\{a,c\}$ 是独立集：经过 $b$ 的路线不会凭空生成直接边 $ac$。集合 $\{a,b\}$ 不是独立集，因为它包含边 $ab$ 的两个端点。

<!-- bilingual-en:start -->
## The condition on a set of vertices
<!-- bilingual-en:end -->

*顶点集合需要满足什么条件*

<!-- bilingual-en:start -->
Work first with a finite [[图类型的建模边界|simple undirected graph]] $G=(V,E)$: $V$ is its vertex set, and edges join distinct unordered pairs without repetitions. A subset $S\subseteq V$ is **independent** (also called **stable**) precisely when
<!-- bilingual-en:end -->

先考虑有限[[图类型的建模边界|简单无向图]] $G=(V,E)$：$V$ 是顶点集合，边连接不同顶点组成的无序对，没有重复边。子集 $S\subseteq V$ 称为**独立集**，也称稳定集，当且仅当

$$\text{for every distinct }u,v\in S,\quad \{u,v\}\notin E.$$

<!-- bilingual-en:start -->
Only edges with both endpoints in $S$ matter. Edges from $S$ to vertices outside $S$ are allowed. The empty set and every one-vertex set are independent in a simple graph. The whole set $V$ is independent exactly when the graph has no edges.
<!-- bilingual-en:end -->

只检查两个端点都在 $S$ 中的边；从 $S$ 连到外部顶点的边是允许的。在简单图中，空集和任何单点集都是独立集。整个 $V$ 是独立集，当且仅当图没有边。

> [!note] Independent does not mean isolated / 独立不等于孤立
> <!-- bilingual-en:start -->
> In the chain above, $a$ and $c$ each have a neighbor, yet $\{a,c\}$ is independent. Neither selected vertex needs to be isolated in the whole graph.
> <!-- bilingual-en:end -->
>
> 上例中，$a,c$ 都各有邻点，但 $\{a,c\}$ 仍是独立集；独立集中的顶点不必在整张图中孤立。

## Size is an additional question
<!-- bilingual-en:end -->

*大小是另一个问题*

<!-- bilingual-en:start -->
The definition does not ask for the largest possible set. For a finite graph, the **independence number** $\alpha(G)$ is the largest size of an independent vertex set; a largest set exists because there are only finitely many subsets. In the chain, $\alpha(G)=2$. A set that cannot be enlarged by adding vertices is called **maximal**; it need not have maximum size. For example, $\{b\}$ cannot be enlarged in this chain, but $\{a,c\}$ is larger.
<!-- bilingual-en:end -->

定义本身不要求选得最多。有限图的**独立数** $\alpha(G)$ 是独立顶点集的最大大小；因为顶点子集只有有限多个，最大值确实能取到。在这条链上，$\alpha(G)=2$。不能再通过加入顶点扩大的独立集称为**极大**独立集，不一定是大小最大的独立集。例如 $\{b\}$ 已不能扩大，但 $\{a,c\}$ 更大。

<!-- bilingual-en:start -->
An independent set with $s$ vertices proves $\alpha(G)\ge s$; it does not prove that no larger independent set exists. This distinction matters when independent-set sizes are used in coloring bounds.
<!-- bilingual-en:end -->

找到大小为 $s$ 的独立集，只能证明 $\alpha(G)\ge s$，不能证明不存在更大的独立集。在用独立集大小估计着色所需颜色数时，要特别留意这一方向。

<!-- bilingual-en:start -->
## If the graph model permits loops or parallel edges
<!-- bilingual-en:end -->

*允许自环或平行边时*

<!-- bilingual-en:start -->
For an undirected multigraph, use the explicit condition “no edge has both endpoints in $S$.” Parallel edges do not change which vertex pairs can be selected together. A vertex carrying a loop cannot belong to such an independent set: the loop has both endpoints there. Thus the automatic singleton statement above depends on the loop-free hypothesis. If $V=\varnothing$, its only subset is independent and $\alpha(G)=0$.
<!-- bilingual-en:end -->

对无向多重图，采用明确的条件：“不存在两个端点都在 $S$ 内的边。”平行边不会改变哪些顶点对能够同时选入；带自环的顶点则不能选入，因为自环的两个端点都在那里。因此，前面“任何单点集都独立”依赖没有自环的假设。若 $V=\varnothing$，唯一的子集就是独立的空集，并有 $\alpha(G)=0$。
