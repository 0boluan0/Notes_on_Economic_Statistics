# 列表推导式按从左到右嵌套的 for 与 if 规则一次构造新列表
<!-- bilingual-en:start -->
*A list comprehension constructs a new list at once by nesting its for and if clauses from left to right*
<!-- bilingual-en:end -->

> [!summary] 原子规则
> 列表推导式把“遍历—筛选—变换”写成一个新列表的构造表达式。多个 **for** 与 **if** 子句按从左到右的嵌套循环解释；每次到达最内层时，最前面的结果表达式才求值并追加到新列表。

~~~python
pairs = [(x, y)
         for x in range(3)
         for y in range(x)
         if (x + y) % 2 == 0]
~~~

它与下面的执行顺序相同：

~~~python
pairs = []
for x in range(3):
    for y in range(x):
        if (x + y) % 2 == 0:
            pairs.append((x, y))
~~~

列表推导式会在表达式完成前构造出整个列表。除最左侧 **for** 的可迭代表达式外，推导式主体运行在一个隐式的嵌套作用域中；循环目标名称不会泄漏并覆盖外围同名变量。

它适合结果确实是一张列表、转换关系简短且没有依赖副作用的情形。如果有复杂分支、异常处理、提前退出，或每一步都需要解释，显式循环更容易读，也更容易调试。选择推导式不是为了少写几行，而是为了让“由哪些输入产生哪些元素”一眼可见。

> [!question]- 自检
> **[f(x, y) for x in xs for y in ys(x) if keep(x, y)]** 中，哪个循环在内层？
>
> **答案：** **for y in ys(x)** 在内层；顺序等价于先遍历每个 **x**，再对该 **x** 遍历 **y**，通过条件后才计算 **f(x, y)**。
