# 单期自融资持仓的简单收益率按期初价值权重线性聚合
<!-- bilingual-en:start -->
*A one-period self-financing portfolio aggregates simple returns using initial-value weights*
<!-- bilingual-en:end -->

期初建仓后持有至期末，期间不追加或取走外部资金，全部现金流和融资成本已纳入相应资产的简单总回报，且没有遗漏的费用时，组合回报为
<!-- bilingual-en:start -->
For positions held from the beginning to the end of a period without external cash flows, with distributions and financing included in the relevant simple total returns and no omitted fees, the portfolio return is
<!-- bilingual-en:end -->

$$R_p=\sum_iw_iR_i=w^\top R.$$

这是财富核算恒等式：$W_1=\sum_iV_{i0}(1+R_i)=W_0[1+\sum_iw_iR_i]$，再代入 $R_p=(W_1-W_0)/W_0$。不需要资产独立，也不需要正态分布。
<!-- bilingual-en:start -->
The identity follows by adding terminal position values and dividing the change in wealth by initial wealth. It requires neither independence nor normality.
<!-- bilingual-en:end -->

例如权重 $(0.6,0.4)$、本期实现回报 $(10\%,-5\%)$，则 $R_p=0.6(0.10)+0.4(-0.05)=4\%$。这是本期实际结果；期初尚未实现的 $R_i$ 是随机变量，取期望后才得到[[组合均值与方差|期望组合收益]]。
<!-- bilingual-en:start -->
Weights $(0.6,0.4)$ and realized returns $(10\%,-5\%)$ produce a realized portfolio return of $4\%$. Before the period ends, returns are random; [[组合均值与方差|taking expectations]] yields expected portfolio return.
<!-- bilingual-en:end -->

公式中的权重是**期初价值权重**。多期再平衡要逐期核算并复利连接；一般不能拿一个期初权重向量乘整个多期收益。资产的对数收益也不能直接按同一公式加权成组合对数收益。
<!-- bilingual-en:start -->
These are initial-value weights. Rebalanced multi-period investments require period-by-period accounting and compounding. Asset log returns generally do not aggregate into portfolio log return with the same weighted-sum formula.
<!-- bilingual-en:end -->
