# Equivalence relations
<!-- bilingual-en:end -->

*等价关系*

<!-- bilingual-en:start -->
An **equivalence relation** tells us when two objects count as the same for a chosen purpose. The objects need not be identical: the integers $1$, $4$ and $7$ are different, but they have the same remainder when divided by $3$. An equivalence relation makes such grouping consistent: every object belongs with itself, the comparison works in either direction, and two successful comparisons can be joined.
<!-- bilingual-en:end -->

**等价关系**说明：按照选定的比较标准，哪些对象可以归为同一类。对象本身不必相同：整数 $1$、$4$、$7$ 并不相等，但除以 $3$ 都余 $1$。等价关系让这种分类保持一致：每个对象都与自己同类，比较方向可以反过来，两次成立的比较还能接起来。

<!-- bilingual-en:start -->
## A rule for comparing two objects
<!-- bilingual-en:end -->

*比较两个对象的规则*

<!-- bilingual-en:start -->
Let $A$ be the set of objects under consideration; it can be finite or infinite. A **binary relation on $A$** specifies which ordered pairs $(a,b)$ of elements of $A$ satisfy a rule. Formally, it is a subset $R\subseteq A\times A$, where $A\times A$ means all such ordered pairs. Write $aRb$, or $a\sim b$, when $(a,b)$ is included. The symbol $\sim$ only records the chosen rule; using it does not by itself establish any of the properties below.
<!-- bilingual-en:end -->

设 $A$ 是所讨论对象组成的集合，可以有限，也可以无限。**$A$ 上的二元关系**指定：由 $A$ 中两个元素组成的哪些有序对 $(a,b)$ 满足某条规则。形式上，它是子集 $R\subseteq A\times A$；$A\times A$ 表示这些有序对的全体。若 $(a,b)$ 被包括在关系中，就写作 $aRb$ 或 $a\sim b$。符号 $\sim$ 只记录选定的规则，并不自动保证下面的性质。

> [!important] The three requirements · 三项要求
> <!-- bilingual-en:start -->
> A relation $\sim$ on $A$ is an equivalence relation when all three conditions hold:
>
> - **Reflexive:** $a\sim a$ for every $a\in A$.
> - **Symmetric:** if $a\sim b$, then $b\sim a$, for every $a,b\in A$.
> - **Transitive:** if $a\sim b$ and $b\sim c$, then $a\sim c$, for every $a,b,c\in A$.
>
> These are requirements for all eligible elements, not just a few successful examples.
> <!-- bilingual-en:end -->
>
> $A$ 上的关系 $\sim$ 同时满足以下三条，就叫等价关系：
>
> - **自反性：**对每个 $a\in A$，都有 $a\sim a$。
> - **对称性：**对任意 $a,b\in A$，若 $a\sim b$，则 $b\sim a$。
> - **传递性：**对任意 $a,b,c\in A$，若 $a\sim b$ 且 $b\sim c$，则 $a\sim c$。
>
> 这些要求覆盖所有符合范围的元素，不能只用几个成立的例子代替证明。

## Checking the remainder example
<!-- bilingual-en:end -->

*逐步检查余数例子*

<!-- bilingual-en:start -->
On $\mathbb Z$, the set of all integers, declare $a\sim b$ when $a-b$ is an integer multiple of $3$. This is [[同余|congruence modulo 3]], equivalently having the same remainder after division by $3$. For example, $7\sim1$ because $7-1=2\cdot3$, whereas $7\not\sim2$ because $5$ is not a multiple of $3$.
<!-- bilingual-en:end -->

在全体整数的集合 $\mathbb Z$ 上，规定：当 $a-b$ 是 $3$ 的整数倍时，$a\sim b$。这就是[[同余|模 3 同余]]，也等价于除以 $3$ 后余数相同。例如 $7\sim1$，因为 $7-1=2\cdot3$；但 $7\not\sim2$，因为 $5$ 不是 $3$ 的整数倍。

<!-- bilingual-en:start -->
Reflexivity follows from $a-a=0=3\cdot0$. For symmetry, if $a-b=3k$ for an integer $k$, then $b-a=3(-k)$, also an integer multiple of $3$. For transitivity, if $a-b=3k$ and $b-c=3\ell$ for integers $k,\ell$, then $a-c=3(k+\ell)$. These arguments work for every integer involved, including negative integers, so they verify the relation on all of $\mathbb Z$. Symmetry does not require $a=b$: it allows $1\sim4$ and $4\sim1$ together.
<!-- bilingual-en:end -->

自反性来自 $a-a=0=3\cdot0$。对称性则是：若 $a-b=3k$，其中 $k$ 为整数，那么 $b-a=3(-k)$ 仍是 $3$ 的整数倍。传递性是：若 $a-b=3k$ 且 $b-c=3\ell$，其中 $k,\ell$ 都是整数，那么 $a-c=3(k+\ell)$。这些论证对所有涉及的整数都成立，也包括负整数，因此核实了整个 $\mathbb Z$ 上的关系。对称性不要求 $a=b$，它允许 $1\sim4$ 与 $4\sim1$ 同时成立。

## The class containing an object
<!-- bilingual-en:end -->

*一个对象所属的等价类*

<!-- bilingual-en:start -->
Once $\sim$ is an equivalence relation, the **equivalence class** of $a\in A$ is the set of every object related to it:
<!-- bilingual-en:end -->

当 $\sim$ 是等价关系时，元素 $a\in A$ 的**等价类**收集与它有关系的全部对象：

$$[a]=\{x\in A:a\sim x\}.$$

<!-- bilingual-en:start -->
The brackets denote the whole subset, while $a$ is one representative of that subset. For the remainder example, $[1]=\{\ldots,-5,-2,1,4,7,\ldots\}$, and $[4]=[1]$. Choosing $4$ instead of $1$ as the representative does not change the class. There are exactly three distinct classes, represented by $0$, $1$ and $2$; each integer belongs to exactly one of them.
<!-- bilingual-en:end -->

方括号表示整个子集，而 $a$ 是这个子集的一个代表。在余数例中，$[1]=\{\ldots,-5,-2,1,4,7,\ldots\}$，并且 $[4]=[1]$。用 $4$ 代替 $1$ 作为代表，不会改变这个类。恰好有三个不同的类，可分别用 $0$、$1$、$2$ 代表；每个整数恰好属于其中一个。

<!-- bilingual-en:start -->
In general, the distinct classes form a **partition** of $A$: nonempty pieces that do not overlap and together cover $A$. Reflexivity places $a$ in $[a]$, so every element is covered. To see why classes cannot overlap partially, suppose $z\in[a]\cap[b]$. Then $a\sim z$ and $b\sim z$, so symmetry and transitivity give $a\sim b$. For any $x\in[a]$, $b\sim a\sim x$ gives $x\in[b]$; reversing the roles gives the opposite inclusion. Hence $[a]=[b]$. A class therefore contains all the equivalent objects, not an arbitrarily selected subset.
<!-- bilingual-en:end -->

一般地，不同等价类构成 $A$ 的一个**划分**：每块非空，块与块不重叠，合起来覆盖 $A$。自反性保证 $a\in[a]$，所以每个元素都被覆盖。为什么两个类不能只重叠一部分？若 $z\in[a]\cap[b]$，则 $a\sim z$、$b\sim z$，由对称性和传递性得到 $a\sim b$。对任意 $x\in[a]$，有 $b\sim a\sim x$，所以 $x\in[b]$；反过来同理，因此 $[a]=[b]$。等价类必须收齐所有等价对象，不能任意挑选其中一部分。

## Connectivity is another example
<!-- bilingual-en:end -->

*连通性也是一个例子*

<!-- bilingual-en:start -->
For an undirected graph, relate two vertices when one is [[图距离与可达性|reachable]] from the other. A zero-length path gives reflexivity, reversing a path gives symmetry, and joining two routes gives transitivity; [[游走去环得到路径|removing repeated detours]] leaves a path if needed. The classes are the vertex sets of the [[无向图连通分量|connected components]]. With vertices $a,b,c,d$ and only the undirected edges $\{a,b\}$ and $\{b,c\}$, the classes are $\{a,b,c\}$ and $\{d\}$. Direct adjacency is a different relation: $a$ and $c$ are in the same class even though no edge joins them directly.
<!-- bilingual-en:end -->

在无向图中，规定两个顶点之间[[图距离与可达性|存在可达路线]]时有关系。零长度路径给出自反性，反向走同一条路径给出对称性，拼接两段路线给出传递性；必要时[[游走去环得到路径|删除重复绕行段]]便得到路径。等价类就是[[无向图连通分量|连通分量]]的顶点集。若顶点为 $a,b,c,d$，只有无向边 $\{a,b\}$、$\{b,c\}$，则两个类为 $\{a,b,c\}$ 与 $\{d\}$。直接相邻是另一种关系：$a,c$ 没有直接相连的边，仍然属于同一类。

> [!warning] Being close need not be an equivalence · 接近未必构成等价关系
> <!-- bilingual-en:start -->
> On the real numbers, define $x\approx y$ to mean $|x-y|<1$. This rule is reflexive and symmetric, but $0\approx3/4$ and $3/4\approx3/2$ while $0\not\approx3/2$. It fails transitivity, so its “close to $x$” sets cannot be treated as equivalence classes. Likewise, one-way reachability in a directed graph need not be symmetric; the undirected example above uses reversibility of paths.
> <!-- bilingual-en:end -->
>
> 在实数上规定 $x\approx y$ 表示 $|x-y|<1$。这条规则自反且对称，但 $0\approx3/4$、$3/4\approx3/2$，却有 $0\not\approx3/2$。它不满足传递性，因此不能把“与 $x$ 接近”的集合当作等价类。同样，有向图里的单向可达未必对称；上面的无向图例子用到了路径可以反向行走。

## The empty set
<!-- bilingual-en:end -->

*空集合边界*

<!-- bilingual-en:start -->
We allow $A=\varnothing$. Its only relation is the empty relation, because there are no ordered pairs to include. All three conditions hold: there is no element or tuple that could violate them. There are no equivalence classes, since there is no $a\in A$ to represent one. The resulting partition is the empty family of blocks, not a family containing one empty block. If $A$ is nonempty, by contrast, every class contains its representative and is nonempty.
<!-- bilingual-en:end -->

这里允许 $A=\varnothing$。它上面唯一的关系是空关系，因为没有有序对可供选入。三项条件都成立：没有任何元素或元组能够违反它们。此时没有等价类，因为不存在 $a\in A$ 可以作为代表；所得划分是没有任何块的空族，不是“包含一个空块”的族。相反，只要 $A$ 非空，每个等价类都包含其代表，因此非空。
