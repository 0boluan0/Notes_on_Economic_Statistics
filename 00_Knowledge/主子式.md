# 主子式是同时保留同一组行列下标所得方阵的行列式

<!-- bilingual-en:start -->
*A principal minor is the determinant of the submatrix retaining the same row and column index set*
<!-- bilingual-en:end -->

对 $n\times n$ 矩阵 $A$ 和非空下标集 $I\subseteq\{1,\ldots,n\}$，同时保留 $I$ 中的行、列得到主子矩阵 $A_{I,I}$；它的行列式 $\det A_{I,I}$ 是主子式。子矩阵是矩阵，主子式是数。

三阶矩阵的二阶主子式对应 $I=\{1,2\},\{1,3\},\{2,3\}$。有 $\binom nk$ 个 $k$ 阶主子式，所有非空阶共 $2^n-1$ 个。行列保留不同下标得到一般子矩阵，其行列式不一定是主子式。[[顺序主子式]]进一步限定下标必须从 $1$ 连续开始。

<!-- bilingual-en:start -->
A principal submatrix uses the same nonempty index set for rows and columns; its determinant is a principal minor. These are different object types. The order-$k$ count is the binomial coefficient, and all nonempty orders give $2^n-1$ minors. [[顺序主子式|Leading principal minors]] impose the additional initial-index restriction.
<!-- bilingual-en:end -->
