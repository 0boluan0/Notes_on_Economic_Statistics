# Edgeworth box 用资源约束表示两人两商品的可行配置
<!-- bilingual-en:start -->
*The Edgeworth box represents feasible two-person two-good allocations through resource constraints*
<!-- bilingual-en:end -->

> [!summary] 原子模型
> 两人纯交换经济没有生产，只有初始禀赋的重新分配。若两种商品的总禀赋为 $(\bar x,\bar y)$，没有丢弃资源时任一配置满足
> $$x_A+x_B=\bar x,\qquad y_A+y_B=\bar y.$$
> Edgeworth box 的宽和高是两种商品的总量；箱内一点从左下原点读出 A 的消费，从右上原点反向读出 B 的消费，因此一个点同时表示两人的完整配置。
> <!-- bilingual-en:start -->
> In a pure-exchange economy, the box dimensions are the aggregate endowments. Opposite origins let one point encode both consumers' bundles, with each good's allocations adding to its aggregate endowment when no resources are discarded.
> <!-- bilingual-en:end -->

初始禀赋 $\omega=(\omega_A,\omega_B)$ 是交易前的所有权分布，只是可行集中的一个点；最终配置 $x=(x_A,x_B)$ 是交易后的消费分配。把禀赋点和最终配置混为一谈，会把“有多少资源”与“谁最终持有资源”混成同一个问题。

更一般地，允许免费丢弃时，可行性写成逐商品不等式
$$
\sum_i x_i^g\le \sum_i\omega_i^g.
$$
标准 Edgeworth box 通常画出资源全部分配的等号情形。若所有人对尚未分配的商品单调，且至少有人严格偏好多得到它，Pareto 有效配置也会用尽该商品；局部非饱和本身并不保证每一种剩余商品都值得增加。但“箱内”本身只表示资源可行，既不保证每个人愿意从禀赋点走到那里，也不保证该点有效或能由价格支持。

> [!question]- 自检
> 箱内一点为什么不能只理解为 A 的消费束？
>
> **答案：** 因为总资源固定。A 从左下角读到的数量一旦确定，B 从右上角读到的剩余数量也同时确定；同一点编码的是完整社会配置。
