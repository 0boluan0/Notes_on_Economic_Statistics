# Stars and bars
<!-- bilingual-en:end -->
*隔板法*

<!-- bilingual-en:start -->
Stars and bars counts how many ways a fixed total can be split into **nonnegative whole-number amounts assigned to distinct places**. For example, distribute three identical tokens between boxes A and B. We record only the number in each box. The possibilities are $(0,3)$, $(1,2)$, $(2,1)$, and $(3,0)$.

Write each token as a star and put a bar between the amounts for A and B. Those four allocations become `|***`, `*|**`, `**|*`, and `***|`. Choosing an allocation is now the same as choosing where the bar goes. A bar at an end means one box is empty.
<!-- bilingual-en:end -->
隔板法数的是：把一个固定总数分成**分配给不同位置的非负整数数量**，共有多少种方式。例如，把三个相同的筹码分给 A、B 两个盒子，只记录每盒的数量，就有 $(0,3)$、$(1,2)$、$(2,1)$、$(3,0)$ 四种可能。

把每个筹码写成一颗星，在 A、B 的数量之间放一块隔板，这四种分配就变成 `|***`、`*|**`、`**|*`、`***|`。选一种分配，等价于选隔板放在哪里。隔板在端点，表示其中一个盒子为空。

<!-- bilingual-en:start -->
## Encoding an allocation
<!-- bilingual-en:end -->
*把分配编码成星与隔板*

<!-- bilingual-en:start -->
Let $n\ge0$ be the total number of identical units and $k\ge1$ the number of labelled boxes; both are integers. Let the nonnegative integer $x_i$ be the amount assigned to box $i$. We want to count the ordered tuples $(x_1,\ldots,x_k)$ satisfying $x_1+\cdots+x_k=n$. A tuple is ordered because changing which box receives an amount can change the allocation.

Write $x_1$ stars, then a bar, then $x_2$ stars, and continue. There are $n$ stars and $k-1$ bars. For example, $(2,0,3)$ becomes `**||***`; adjacent bars encode an empty box. Conversely, count the stars before, between, and after the bars to recover every box's amount. This is a [[双射计数|bijection]]: each allocation has exactly one encoding and each string decodes to exactly one allocation.
<!-- bilingual-en:end -->
设整数 $n\ge0$ 是相同单位的总数，整数 $k\ge1$ 是有标号盒子的个数，用非负整数 $x_i$ 表示第 $i$ 个盒子分到的数量。要数的就是满足 $x_1+\cdots+x_k=n$ 的有序元组 $(x_1,\ldots,x_k)$。这里“有序”是因为改变哪个盒子收到某个数量，可能改变分配。

先写 $x_1$ 颗星，再写一块隔板，然后写 $x_2$ 颗星，依此类推。共有 $n$ 颗星和 $k-1$ 块隔板。例如，$(2,0,3)$ 对应 `**||***`，相邻隔板表示空盒子。反过来，数出第一块隔板前、隔板之间、最后一块隔板后的星数，就恢复了各盒数量。这构成[[双射计数]]所要求的一一对应：每个分配只有一种编码，每个字符串也只解码出一种分配。

> [!important] Counting the bar positions / 选择隔板的位置
> <!-- bilingual-en:start -->
> There are $n+k-1$ symbol positions. Choose $k-1$ of them for bars; the rest must be stars. The [[组合数|binomial coefficient]] counts this subset of positions, giving
> <!-- bilingual-en:end -->
> 总共 $n+k-1$ 个符号位置，选出 $k-1$ 个放隔板，其余位置只能放星。用[[组合数]]数这个位置子集，得到
>
> $$
> \boxed{\#\{(x_1,\ldots,x_k):x_i\in\mathbb Z_{\ge0},\ \textstyle\sum_i x_i=n\}
> =\binom{n+k-1}{k-1}}.
> $$
>
> <!-- bilingual-en:start -->
> The symbol $\#$ means “number of elements,” and $\mathbb Z_{\ge0}$ denotes the nonnegative integers. The formula assumes $n\ge0$ and $k\ge1$.
> <!-- bilingual-en:end -->
> 符号 $\#$ 表示“元素个数”，$\mathbb Z_{\ge0}$ 表示非负整数。公式要求 $n\ge0$、$k\ge1$。

<!-- bilingual-en:start -->
If $n=0$, all boxes are empty and the all-bar string is unique, so the count is $\binom{k-1}{k-1}=1$. If $k=1$, there are no bars and the only allocation puts all $n$ units in that box, so the count is $\binom n0=1$. Zero boxes are outside this formula: there is one empty allocation when the total is zero, and none when the total is positive.
<!-- bilingual-en:end -->
若 $n=0$，所有盒子都空着，只有一种全是隔板的字符串，因此数量为 $\binom{k-1}{k-1}=1$。若 $k=1$，没有隔板，只能把全部 $n$ 个单位分给唯一的盒子，因此数量为 $\binom n0=1$。零个盒子不在公式范围内：总数为零时有一种空分配，总数为正时没有分配。

<!-- bilingual-en:start -->
## Shifting lower bounds
<!-- bilingual-en:end -->
### 下界必须先平移

<!-- bilingual-en:start -->
If every box must receive at least one unit, reserve one for each box first. Set $y_i=x_i-1$; then $y_i\ge0$ and $\sum_i y_i=n-k$. Provided $n\ge k$, the number of allocations is
<!-- bilingual-en:end -->
若每个盒子至少收到一个单位，先给每盒预留一个。令 $y_i=x_i-1$，就有 $y_i\ge0$、$\sum_i y_i=n-k$。当 $n\ge k$ 时，分配数量为

$$
\binom{(n-k)+k-1}{k-1}=\binom{n-1}{k-1}.
$$

<!-- bilingual-en:start -->
If $n<k$, there are not enough units to meet the minimums, so the count is zero. For example, $x_1+x_2+x_3=7$ with each $x_i\ge1$ leaves four units after the three reservations. There are $\binom62=15$ allocations.

More generally, for integer solutions with fixed integer lower bounds $x_i\ge a_i$, set $y_i=x_i-a_i$ and $N=n-\sum_i a_i$. If $N\ge0$, the answer is $\binom{N+k-1}{k-1}$; if $N<0$, it is zero. Subtracting the lower bounds is reversible, so it does not lose or duplicate solutions.
<!-- bilingual-en:end -->
若 $n<k$，单位总数连最低要求都不够，数量就是零。例如，$x_1+x_2+x_3=7$ 且各 $x_i\ge1$，预留三个单位后还剩四个，因此共有 $\binom62=15$ 种分配。

更一般地，若求整数解，固定整数下界为 $x_i\ge a_i$，就令 $y_i=x_i-a_i$，并记 $N=n-\sum_i a_i$。若 $N\ge0$，答案为 $\binom{N+k-1}{k-1}$；若 $N<0$，答案为零。减去各个下界的变换可以逆转，因此不会遗漏或重复解。

> [!warning] Check what one outcome records / 先确定一种结果记录什么
> <!-- bilingual-en:start -->
> The basic formula counts amounts in labelled boxes, with no upper limits. If three tokens are individually distinguishable, assigning each one to A or B gives $2^3=8$ assignments, even though there are only four count tuples. The tuple $(1,2)$ then represents three different assignments. Count tuples need not be equally likely in a random experiment.
>
> Removing box labels, recording an internal order, or imposing upper bounds changes the problem. A shift removes lower bounds but does not remove upper bounds. Those may require subtracting forbidden allocations using [[容斥原理|inclusion–exclusion]], or encoding the permitted amounts with [[普通生成函数|ordinary generating functions]].
> <!-- bilingual-en:end -->
> 基本公式数的是有标号盒子的数量分配，没有容量上限。若三个筹码可以彼此区分，把每个筹码分给 A 或 B 共有 $2^3=8$ 种具体分配，虽然数量元组仍只有四个。其中 $(1,2)$ 就代表三种具体分配。因此在随机实验中，这些数量元组也不一定等可能。
>
> 取消盒子的标号、记录盒内顺序，或者增加容量上限，都会改变问题。平移能去掉下界，不能去掉上界；有上界时，可能需要用[[容斥原理]]扣除违规分配，或用[[普通生成函数]]编码各个允许的数量。
