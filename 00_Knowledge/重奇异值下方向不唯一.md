# Repeated singular values and basis freedom
<!-- bilingual-en:end -->

*重奇异值对应的基选择自由*

<!-- bilingual-en:start -->
If a matrix stretches every direction in a plane by the same amount, nothing in that action singles out a first axis in the plane. A [[奇异值|singular value]] repeated more than once creates this freedom: the associated [[奇异向量|singular vectors]] can be replaced by a different orthonormal basis of the same subspace. For a positive value, the input and output changes must still match.
<!-- bilingual-en:end -->

如果矩阵把一个平面内的每个方向都伸缩相同倍数，这个作用就没有指定平面内哪条轴应该排第一。某个[[奇异值]]重复出现时，便有这种自由：相应[[奇异向量]]可以改用同一子空间中的另一组标准正交基。对正值，输入与输出两侧的改动仍必须配对。

> [!example] The identity does not select a first axis / 单位映射不会选定第一条轴
> <!-- bilingual-en:start -->
> For $A=I_2$, the [[单位矩阵|identity]], both singular values are 1. Besides $U=V=I_2$, use the [[正交矩阵|orthogonal matrix]]
>
> $$Q=\frac15\begin{bmatrix}3&-4\\4&3\end{bmatrix},\qquad U=V=Q,\qquad U I_2 V^T=QQ^T=I_2.$$
>
> Here $T$ denotes [[矩阵转置|transpose]]. The first input direction has changed from $(1,0)^T$ to $(3/5,4/5)^T$. Both decompositions describe the same map. If only $U$ changes to $Q$ while $V$ stays $I_2$, the product is $Q$, so the map changes.
> <!-- bilingual-en:end -->
>
> 对[[单位矩阵]] $A=I_2$，两个奇异值均为1。除了 $U=V=I_2$，还可同时取显示的[[正交矩阵]] $Q$，因为 $QQ^T=I_2$。这里 $T$ 表示[[矩阵转置|转置]]。第一输入方向由 $(1,0)^T$ 变成 $(3/5,4/5)^T$，但映射没变。若只把 $U$ 改成 $Q$ 而保持 $V=I_2$，乘积就成为 $Q$，不再是原映射。

<!-- bilingual-en:start -->
## An equal positive block
<!-- bilingual-en:end -->

*同一个正奇异值的完整块*

<!-- bilingual-en:start -->
Let $A$ be a real or complex $m\times n$ matrix and let $\sigma>0$ occur exactly $k\ge2$ times. Let $J$ include **all** those occurrences. Write $U_J$ and $V_J$ for their output and input columns, of sizes $m\times k$ and $n\times k$. Their columns are [[标准正交组|orthonormal]], meaning unit length and mutually perpendicular. This block contributes $\sigma U_JV_J^*$ to the matrix, where $*$ is [[矩阵转置|conjugate transpose]].
<!-- bilingual-en:end -->

设 $A$ 为实或复 $m\times n$ 矩阵，$\sigma>0$ 恰好重复 $k\ge2$ 次。用 $J$ 收集该值的**全部**位置，$U_J$、$V_J$ 分别取这些位置的输出与输入列，尺寸为 $m\times k$、$n\times k$。各组列都是[[标准正交组]]，即长度为1且彼此垂直。该块对矩阵的贡献为 $\sigma U_JV_J^*$，其中 $*$ 是[[矩阵转置|共轭转置]]。

<!-- bilingual-en:start -->
For any $k\times k$ [[Unitary 矩阵|unitary matrix]] $Q$, meaning $Q^*Q=QQ^*=I_k$, replace both bases by $U_JQ$ and $V_JQ$. Over the reals use an orthogonal $Q$. Then
<!-- bilingual-en:end -->

任取 $k\times k$ 的 [[Unitary 矩阵|酉矩阵]] $Q$，即 $Q^*Q=QQ^*=I_k$，把两侧基同时换成 $U_JQ$ 与 $V_JQ$；实数情形取正交 $Q$。于是

$$
(U_JQ)(\sigma I_k)(V_JQ)^*=\sigma U_JQQ^*V_J^*=\sigma U_JV_J^*.
$$

<!-- bilingual-en:start -->
Multiplying by $Q$ mixes the old basis columns without changing their span or orthonormality. Since the stretch is the same in every direction of this block, the mixing cancels. For example, in the [[对角矩阵|diagonal matrix]] $A=\operatorname{diag}(4,4,1)$ the first two directions can mix this way, while the direction with stretch 1 cannot be freely mixed into that block.
<!-- bilingual-en:end -->

乘 $Q$ 是把旧基的列重新组合，不改变张成空间与标准正交性。由于这个块内各方向的伸缩相同，左右两次混合会抵消。例如[[对角矩阵]] $A=\operatorname{diag}(4,4,1)$ 的前两个方向可以这样混合，而伸缩量为1的方向不能随意混入该块。

<!-- bilingual-en:start -->
## The subspaces remain determined
<!-- bilingual-en:end -->

*确定的是子空间与配对映射*

<!-- bilingual-en:start -->
The input columns span the [[特征空间|eigenspace]] of $A^*A$ for $\sigma^2$; the output columns span the eigenspace of $AA^*$ for the same value. These full eigenspaces are determined by $A$. Once an input basis is chosen, the positive pairing $AV_J=\sigma U_J$ determines its output basis. Thus if another input basis is $V_JQ$, its paired output basis must be $U_JQ$. The two sides cannot rotate independently.
<!-- bilingual-en:end -->

输入列张成 $A^*A$ 对应 $\sigma^2$ 的[[特征空间]]，输出列张成 $AA^*$ 对应同一值的特征空间。这两个完整特征空间由 $A$ 确定。选定输入基后，正配对方程 $AV_J=\sigma U_J$ 就确定输出基；所以新输入基若为 $V_JQ$，配对输出基必须为 $U_JQ$，两侧不能独立旋转。

<!-- bilingual-en:start -->
The [[标准正交基投影公式|orthogonal projectors]] $V_JV_J^*$ and $U_JU_J^*$ do not change with this choice. Neither does the whole block contribution. These are useful comparison objects when two programs report different columns. Subspace-angle comparisons, often expressed by principal angles, serve the same purpose: they compare spaces rather than requiring arbitrary basis columns to agree. Comparing just one selected column inside a repeated block can miss this distinction.
<!-- bilingual-en:end -->

[[标准正交基投影公式|正交投影矩阵]] $V_JV_J^*$ 与 $U_JU_J^*$ 不随选基改变，整块对原矩阵的贡献也不变。两个程序返回不同列时，可以比较这些对象；常用主角度进行的子空间夹角比较也是在比较空间，而非要求任意选择的基逐列一致。只比较重值块中的某一列，容易忽略这一区别。

> [!warning] Equal values and nearby values are different / 相等与接近不是一回事
> <!-- bilingual-en:start -->
> Unequal positive singular values do not permit an arbitrary exact block rotation; each simple value has only [[奇异向量共同相位|paired phase freedom]]. Very close values can nevertheless give individually sensitive directions under perturbation. A cluster subspace may be better determined **if it is separated from the rest of the spectrum**; collecting columns alone does not guarantee stability. [[SVD零块补基不唯一|Zero blocks]] have the stronger freedom of independent left and right completions.
> <!-- bilingual-en:end -->
>
> 不相等的正奇异值不能任意作精确块旋转，每个简单值只有[[奇异向量共同相位|共同相位自由]]。但非常接近的值在扰动下可能产生敏感的逐列方向；**若这一簇与其余谱分离**，整簇子空间可能比单列更稳定，并非把列放在一起就自动稳定。[[SVD零块补基不唯一|零块]]则允许更强的左右独立补基自由。

## 来源与核验

<!-- bilingual-en:start -->
- [Axler, *Linear Algebra Done Right*, 7.65 and 7.70–7.74, PDF pp.285, 287–288](https://linear.axler.net/LADR4e.pdf#page=285): eigenspace multiplicity and orthonormal SVD construction. The common-unitary freedom, fixed projectors and examples are derived above by matrix multiplication.
- [LAPACK, detailed SVD error bounds](https://netlib.org/lapack/lug/node97.html): distinguishes individual-vector gaps from separation of a cluster from the remaining spectrum. Only that conditional sensitivity conclusion is used here.
<!-- bilingual-en:end -->

- Axler 第7.65及7.70–7.74条核对特征空间重数与标准正交构造；共同酉变换自由、固定投影及例子由正文矩阵乘法推导。
- LAPACK 详细 SVD 误差界区分逐个方向的间隔与整簇对其余谱的间隔；这里只采用带分离条件的敏感性结论。
