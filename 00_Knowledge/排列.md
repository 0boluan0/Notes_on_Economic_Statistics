# Permutations without repetition
<!-- bilingual-en:end -->
*无重复排列*

<!-- bilingual-en:start -->
A **permutation without repetition** places distinct objects into positions where order matters, using each chosen object at most once. If we assign a captain and a deputy, “Ada is captain, Bo is deputy” differs from “Bo is captain, Ada is deputy”. The same two people appear, but the positions carry different roles.
<!-- bilingual-en:end -->

**无重复排列**把不同对象放进有先后或角色区别的位置，每个选中的对象最多使用一次。分配队长和助理时，“Ada 当队长、Bo 当助理”与“Bo 当队长、Ada 当助理”是两个结果：人相同，位置代表的职责不同。

<!-- bilingual-en:start -->
Suppose the available people are $A,B,C$, and one person cannot hold both roles. Write $(x,y)$ for captain $x$ and deputy $y$. The complete list is
<!-- bilingual-en:end -->

假设候选人为 $A,B,C$，同一人不能兼任两职。用 $(x,y)$ 表示队长是 $x$、助理是 $y$。全部结果为

$$(A,B),(A,C),(B,A),(B,C),(C,A),(C,B).$$

<!-- bilingual-en:start -->
There are three choices for the captain, and two remaining choices for the deputy after any captain is chosen. That gives $3\times2=6$ outcomes. The available names change after the first choice, but the number of remaining names is always two; this is the [[乘法法则|generalised product rule]] in action.
<!-- bilingual-en:end -->

队长有三种选择，每选定一人，助理都剩两种选择，所以共有 $3\times2=6$ 个结果。第一步之后，剩余候选人的名字会变，但人数始终是二，这正是[[乘法法则|广义乘法法则]]的使用方式。

> [!abstract] Filling $k$ different positions · 填满 $k$ 个不同位置
> <!-- bilingual-en:start -->
> Let $n$ be the number of distinct available objects and $k$ the number of positions to fill, where $n,k$ are integers with $0\le k\le n$. A **$k$-permutation** is an ordered list of $k$ different objects. Write $P(n,k)$ for the number of these lists. There are $n,n-1,\ldots,n-k+1$ choices at the successive positions, so
> <!-- bilingual-en:end -->
>
> 设 $n$ 为不同候选对象的个数，$k$ 为要填的位置数，二者为满足 $0\le k\le n$ 的整数。一个 **$k$ 排列**就是由 $k$ 个不同对象组成的有序列表。用 $P(n,k)$ 记这样的列表数。逐个位置的可选数量为 $n,n-1,\ldots,n-k+1$，因此
>
> $$P(n,k)=n(n-1)\cdots(n-k+1)=\frac{n!}{(n-k)!}.$$

<!-- bilingual-en:start -->
The factorial $n!$ means $n(n-1)\cdots2\cdot1$ for $n\ge1$, with $0!=1$. Dividing $n!$ by $(n-k)!$ cancels the unused trailing factors. When $k=n$, every object is used, so a permutation of the whole set has count $P(n,n)=n!$. The notation $P(n,k)$ here is a count, not a probability.
<!-- bilingual-en:end -->

对 $n\ge1$，阶乘 $n!$ 表示 $n(n-1)\cdots2\cdot1$，并约定 $0!=1$。将 $n!$ 除以 $(n-k)!$，就是约去没有用到的尾部因子。当 $k=n$ 时，全部对象都用上，整个集合的排列数为 $P(n,n)=n!$。这里的 $P(n,k)$ 是数量记号，不是概率。

> [!example] Gold, silver and bronze · 金、银、铜牌
> <!-- bilingual-en:start -->
> With eight distinct contestants and no ties, each medal goes to a different person. The result records three roles, so the number of podiums is $P(8,3)=8\cdot7\cdot6=336$. This counts possible results; it does not assume that every result has the same chance.
> <!-- bilingual-en:end -->
>
> 八名不同选手、没有并列名次，三枚奖牌各由不同的人获得。结果记录三个不同角色，所以领奖顺序有 $P(8,3)=8\cdot7\cdot6=336$ 种。这是在数可能结果，并没有假定它们的概率相同。

<!-- bilingual-en:start -->
The boundary $k=0$ has one result: the empty list. Thus $P(n,0)=1$, including $P(0,0)=1$; a product with no factors has value one. If $k>n$ for nonnegative integers $n,k$, there is no valid list and its count is zero. The factorial quotient above is only for $k\le n$, since it would otherwise ask for a negative factorial. Negative or noninteger numbers of positions are outside this model.
<!-- bilingual-en:end -->

当 $k=0$ 时，只有空列表这一个结果，因此 $P(n,0)=1$，也包括 $P(0,0)=1$；没有因子的空乘积取值为一。若非负整数 $n,k$ 满足 $k>n$，则没有合法列表，数量为零。上面的阶乘商仅用于 $k\le n$，否则会出现负数的阶乘。负数或非整数的位置数不属于这个模型。

## When the objects change
<!-- bilingual-en:end -->
## 公式不自动覆盖的情形

<!-- bilingual-en:start -->
If only the selected members matter, exchanging their positions describes the same result: use a [[组合数|combination]]. If the same object may appear again, an ordered list of length $k\ge1$ from $n$ available objects has $n^k$ possibilities when every position allows every object. There is still one empty list when $k=0$, even if no objects are available.
<!-- bilingual-en:end -->

如果只关心选中了哪些成员，交换位置仍是同一个结果，应使用[[组合数]]。如果允许同一对象再次出现，并且每个位置都允许全部 $n$ 个对象，那么长度 $k\ge1$ 的有序列表有 $n^k$ 种；当 $k=0$ 时仍有唯一的空列表，即使没有可用对象也是如此。

<!-- bilingual-en:start -->
If repeated labels are indistinguishable, listing them as distinct objects can overcount. The letters $A,A,B$ have only the three visible arrangements $AAB,ABA,BAA$, whereas marking the two $A$s with different labels would give six. The [[除法法则|division rule]] corrects this only after we establish the number of descriptions per visible arrangement. For circular arrangements, we must also say whether rotations, or reflections, describe the same result. These are changes to the [[计数对象|counting object]], not automatic variants of the linear-list formula.
<!-- bilingual-en:end -->

如果重复标签无法区分，把它们当作不同对象会重计。字母 $A,A,B$ 只有 $AAB,ABA,BAA$ 三个可见排列；若给两个 $A$ 加上不同标签，则会得到六个。必须先说明每个可见排列有几份描述，才能用[[除法法则]]修正。圆形排列还须说明旋转、反射是否视为同一个结果。这些都改变了[[计数对象]]，不能自动套用线性列表公式。
