# Byte-pair encoding
<!-- bilingual-en:end -->

*字节对编码*

<!-- bilingual-en:start -->
Byte-pair encoding builds larger token units by repeatedly merging frequent adjacent pairs. Tokenizer training starts from base units, counts pairs in the current tokenization, selects a pair, replaces occurrences according to the implementation’s merging rules, and records the merge. Overlapping occurrences have to be resolved. The corpus is retokenized before the next pair count.
<!-- bilingual-en:end -->

字节对编码（byte-pair encoding，BPE）把经常相邻的小单位合并成较大的词元。训练从基础单位开始，在当前切分下计数，选出高频相邻对，按实现的次序合并出现处并记录这条规则。相邻对若彼此重叠，需要依次处理。下一轮依据新边界重新计数。

<!-- bilingual-en:start -->
## Applying learned merges
<!-- bilingual-en:end -->

*应用学到的合并规则*

<!-- bilingual-en:start -->
At ordinary encoding time, the learned merge ranks determine which adjacent merges can be applied to the new input. A string absent during training can be decomposed with these same rules. Adding a vocabulary item is a tokenizer-training event. Its [[00_Knowledge/词元编号|token ID]] later selects its own embedding row.
<!-- bilingual-en:end -->

编码新文本时，分词器按已有合并规则及其优先级处理相邻单位。训练时没见过的整词也可切成现有片段。新词元在训练分词器时加入词表。模型随后通过它的[[00_Knowledge/词元编号|编号]]读取它自己的嵌入行。

<!-- bilingual-en:start -->
If the rules first merge `u + g` and then `h + ug`, the string `pughug` becomes `p / ug / hug`. The later rule can act only where the earlier rule has already built `ug`. Giving BPE a full byte alphabet additionally establishes [[00_Knowledge/字节级分词覆盖|coverage by bytes]].
<!-- bilingual-en:end -->

若先学 `u + g → ug`，再学 `h + ug → hug`，则 `pughug` 会得到 `p / ug / hug`。后一条规则只有在 `ug` 已形成的位置才能应用。选择全字节表作为基础单位，还能获得[[00_Knowledge/字节级分词覆盖|按字节回退的覆盖性]]。
