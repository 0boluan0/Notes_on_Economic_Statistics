# 聚类验证是用内部几何、优化与重采样稳定、外部标签和实际用途等不同证据检查分组结果
<!-- bilingual-en:start -->
*Cluster validation evaluates a partition using distinct evidence about internal geometry, optimisation and resampling stability, external labels, and practical utility*
<!-- bilingual-en:end -->

> [!summary] 原子定义
> 聚类验证是把一个分区放到几类不同证据下检查：内部指标看算法所偏好的几何，重复初值看求解器，重采样看样本扰动下的可重复性，外部标签看与另一分组的一致，应用验证才看结果能否支持决定。它们分别回答不同问题。
> <!-- bilingual-en:start -->
> Cluster validation examines a partition using different kinds of evidence: internal indices inspect the favoured geometry, repeated starts the optimiser, resampling repeatability under sample perturbation, external labels agreement with another partition, and application validation whether the result supports a decision. These are different questions.
> <!-- bilingual-en:end -->

## 五种“表现好”不能互相偷换

1. **内部几何：** WCSS、[[轮廓系数]]等只使用当前数据与距离，能说明分区是否满足某种紧密—分离准则，不能提供独立证据。
2. **优化稳定：** K-means 换 seeds 后是否得到近似同一分区，检查的是局部解风险；它不等于换样本后仍稳定。
3. **重采样稳定：** 对样本、合理预处理和算法选择做 bootstrap/subsampling，再比较共同对象的分区。比较量必须不受簇编号置换影响，并应查看各簇而不只看全局平均。
4. **外部一致：** 若有事先定义的参考标签，可用 adjusted Rand index 等比较分区。高一致只说明接近该参考；参考标签本身不一定是聚类应恢复的结构。
5. **实际效用：** 分组是否带来可重复的决策收益、解释或后续预测，要在未用于制造该分组的结果上检查，并考虑实施成本。

高稳定也可能来自算法很僵硬、数据中存在强烈但无关的尺度方向，甚至来自总是返回一个簇。稳定性是必要证据之一，不是现实类别的证明。

## 验证必须重走完整分析路径

重采样时若只重跑最后一步，而标准化、变量筛选或降维仍由全数据固定，结果会低估流程不确定性。应从 [[聚类表示|表示]]、[[聚类尺度|尺度]]到簇数选择一起重走，再用 label-permutation-invariant 指标比较。

新数据复现还要求说明怎样分配新对象。K-means 可以按最近已定中心给出一个归类规则；普通层次树主要描述训练样本，本身没有自动的新样本 assignment rule。若另训分类器去复制旧簇标签，那是在验证一个新增的归类系统，应把它明确写出来。

> [!question]- 自检
> 同一数据用 100 个不同随机 seeds 跑 K-means，95 次得到相同结果。是否已经证明这些簇能在另一个城市复现？
>
> **答案：** 没有。这只说明当前样本和流程下的优化结果对初始化较稳定；它没有改变样本、城市、测量或预处理，也没有检查外部效用。

## 来源与核验

- von Luxburg (2010), [*Clustering Stability: An Overview*](https://arxiv.org/abs/1007.1075)：核对稳定性概念、不同 $K$ 都可能稳定以及稳定不等同于正确结构的边界。
- Ben-Hur, Elisseeff & Guyon (2002), [*A Stability Based Method for Discovering Structure in Clustered Data*](https://pubmed.ncbi.nlm.nih.gov/11928511/)：核对通过子样本聚类一致性评估结构的框架。
- [scikit-learn, clustering performance evaluation](https://scikit-learn.org/stable/modules/clustering.html#clustering-performance-evaluation)：核对 ARI/AMI 的标签置换不变性、外部标签需求和内部指标局限。
- [[多元数据诊断]]：复用数据来源、测量、缺失和异常结构可能支配所有下游分组的本地检查。
