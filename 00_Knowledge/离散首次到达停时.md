# First entrance times in discrete time
<!-- bilingual-en:end -->

*离散时间的首次到达*

<!-- bilingual-en:start -->
If a process is observed at integer times, its **first entrance into a target set** can be detected when it happens. To know whether a queue has ever reached three customers by observation two, inspect observations zero, one and two. No later queue length is needed. This is why first entrance supplies a stopping time whenever the current state is actually observable.
<!-- bilingual-en:end -->

若在整数时刻观察一个过程，**首次进入目标集合**可以在发生时认出来。例如要判断截至第二次观测队列是否曾达到三人，只需检查零、一、二时刻的队长，无须查看之后的队长。因此，只要当前状态确实可观察，首次到达就能构成停时。

<!-- bilingual-en:start -->
A [[滤过定义|filtration]] $(\mathcal F_n)_{n\ge0}$ specifies the information available at observation $n$. An [[适应过程|adapted process]] $X=(X_n)_{n\ge0}$ has its time-$n$ state measurable with respect to $\mathcal F_n$. A [[停时定义|stopping time]] $T$ requires $\{T\le n\}\in\mathcal F_n$: the available information decides whether stopping has already happened.
<!-- bilingual-en:end -->

[[滤过定义|滤过]] $(\mathcal F_n)_{n\ge0}$ 规定第 $n$ 次观察时拥有的信息。[[适应过程]] $X=(X_n)_{n\ge0}$ 的当前状态对 $\mathcal F_n$ 可测。[[停时定义|停时]] $T$ 则要求 $\{T\le n\}\in\mathcal F_n$，也就是当前信息能够判断是否已经停止。

> [!abstract] First entrance into a measurable target · 首次进入可测目标
> <!-- bilingual-en:start -->
> Let $(E,\mathcal E)$ be the state space and its measurable sets, and let $X$ be an $E$-valued adapted process. For a fixed target $A\in\mathcal E$, define
> $$\tau_A=\inf\{n\ge0:X_n\in A\},\qquad \inf\varnothing=\infty.$$
> Then $\tau_A$ is a stopping time. Here $\inf$ selects the first eligible integer; the empty-set convention covers paths which never enter. For real observations, measurable targets include intervals such as $[3,\infty)$; for a finite state space with all subsets measurable, any fixed subset is allowed.
> <!-- bilingual-en:end -->
>
> 设 $(E,\mathcal E)$ 表示状态空间及其中的可测集合，$X$ 是取值于 $E$ 的适应过程。对预先固定的目标 $A\in\mathcal E$，按上式定义 $\tau_A$，它就是停时。$\inf$ 选出第一个符合条件的整数，空集约定处理永远没有进入的路径。实数观测的可测目标包括 $[3,\infty)$ 等区间；有限状态空间若允许全部子集为可测集，则任意固定子集都能作为目标。

> [!example] Observed queue lengths · 逐次观察队长
> <!-- bilingual-en:start -->
> For the observed values $X_0=2,X_1=1,X_2=4,X_3=3$ and target $A=\{3,4,5,\ldots\}$, the first entrance is $\tau_A=2$. At time one the answer to “has it entered?” is no; at time two it is yes. The value four counts because the target is “at least three”, not exactly three. With target $\{3\}$, these same observations first hit at time three instead.
> <!-- bilingual-en:end -->
>
> 若观察值依次为 $X_0=2,X_1=1,X_2=4,X_3=3$，目标是 $A=\{3,4,5,\ldots\}$，那么 $\tau_A=2$。时刻一尚未进入，时刻二已经进入。队长四也算，因为目标是“至少三人”，不是“恰好三人”；若目标改为 $\{3\}$，同一段观察的首次到达便是时刻三。

<!-- bilingual-en:start -->
## The proof only uses the observed past
<!-- bilingual-en:end -->

## 证明只使用已经发生的历史

<!-- bilingual-en:start -->
The statement “entered by $n$” means that at least one of observations $0,\ldots,n$ was in the target:
$$\{\tau_A\le n\}=\bigcup_{k=0}^n\{X_k\in A\}.$$
Adaptation and measurability of $A$ give $\{X_k\in A\}\in\mathcal F_k$. Since information grows, $\mathcal F_k\subseteq\mathcal F_n$ for $k\le n$. The right-hand side is a finite union of events in the [[σ-代数|sigma-algebra]] $\mathcal F_n$, so it is in $\mathcal F_n$. This is precisely the stopping-time test.
<!-- bilingual-en:end -->

“截至 $n$ 已进入”表示零到 $n$ 的某次观察位于目标内，因此等于上式的有限并。适应性与 $A$ 的可测性保证 $\{X_k\in A\}\in\mathcal F_k$。信息递增又给出 $\mathcal F_k\subseteq\mathcal F_n$。右侧是[[σ-代数]] $\mathcal F_n$ 内事件的有限并，仍然在其中，恰好满足停时判据。

<!-- bilingual-en:start -->
One can also identify the exact first-entrance branch:
$$\{\tau_A=n\}=\{X_0\notin A,\ldots,X_{n-1}\notin A,\ X_n\in A\}.$$
For $n=0$, there are no earlier observations to exclude, so this is just $\{X_0\in A\}$. The proof uses neither Markov dynamics nor independent observations. Dependence between the queue lengths does not invalidate it.
<!-- bilingual-en:end -->

也可以直接描述恰好首次进入的分支：此前全在目标之外，当前在目标内。$n=0$ 时没有更早的观察需要排除，所以事件就是 $\{X_0\in A\}$。整个证明既不使用 Markov 动态，也不要求观察彼此独立；队长之间存在依赖，并不会破坏这个结论。

## Initial hits, positive returns and non-arrival
<!-- bilingual-en:end -->

*零时刻、正回返与永不到达*

<!-- bilingual-en:start -->
Because the definition starts at $n=0$, a path beginning in $A$ has $\tau_A=0$. If the question instead asks for the first visit after at least one step, define
$$\tau_A^+=\inf\{n\ge1:X_n\in A\}.$$
This is also a stopping time: $\{\tau_A^+\le0\}=\varnothing$, and for $n\ge1$ use the union from $k=1$ to $n$. The two variables answer different questions, especially for a return to the initial state. Their probabilities and expectations need not agree.
<!-- bilingual-en:end -->

定义从 $n=0$ 开始，因此初态已经在 $A$ 中时，$\tau_A=0$。若问的是至少走一步后的首次访问，就改用 $\tau_A^+$。它同样是停时：零时刻已停止的事件为空，$n\ge1$ 时改用从一到 $n$ 的有限并。特别在返回初态的问题里，两种时间回答不同问题，概率与期望也未必相同。

<!-- bilingual-en:start -->
If the process never enters, the value is infinity and the information test still holds. Being a stopping time does not prove eventual arrival, nor a finite mean waiting time; the [[必达不推有限期望|finite-hit versus finite-mean boundary]] addresses that separate issue. Any [[命中概率第一步方程|hitting-probability equation]] or [[期望命中时间方程|mean-hitting-time equation]] must use the same target and the same choice of whether time zero counts.
<!-- bilingual-en:end -->

过程永不进入时，取值无穷，信息判据仍然成立。停时性质不证明最终必达，更不证明平均等待时间有限；[[必达不推有限期望]]处理的是另一个边界。使用[[命中概率第一步方程]]或[[期望命中时间方程]]时，必须保持同一个目标，并一致说明是否把零时刻计入。

> [!warning] Discrete observations are the scope of this proof · 本证明针对离散观察
> <!-- bilingual-en:start -->
> The finite union above cannot be copied over every real time. In continuous time, hitting results depend on path regularity, the target set and the filtration. Also, a first hit detected on a sampled grid can differ from the first crossing between observations. Finally, replacing “first” by “last” changes the information requirement; see [[末次到达通常非停时|last visits and future information]].
> <!-- bilingual-en:end -->
>
> 不能把上面的有限并原样改成对所有实数时刻取并。连续时间的命中结论还要考虑路径正则性、目标集合与滤过条件；离散采样首次发现到达，也可能不同于两次观察之间的首次越界。把“首次”换成“末次”同样会改变信息要求，见[[末次到达通常非停时]]。
