# Identity matrix
<!-- bilingual-en:end -->

*单位矩阵*

<!-- bilingual-en:start -->
The **identity matrix** is the matrix that leaves every input vector unchanged. It plays the role that 1 plays in ordinary multiplication: multiplying by it makes no change, provided the dimensions match. Its diagonal entries are 1 and every other entry is 0. The size is part of the notation: $I_n$ has $n$ rows and $n$ columns.
<!-- bilingual-en:end -->

**单位矩阵**会让每个输入向量保持原样。它在矩阵乘法中的作用，类似普通乘法中的1：尺寸匹配时，乘它不会改变结果。它的对角线元素为1，其余元素全为0；尺寸也是记号的一部分，$I_n$ 有 $n$ 行、$n$ 列。

$$
I_2=\begin{pmatrix}1&0\\0&1\end{pmatrix},\qquad
I_3=\begin{pmatrix}1&0&0\\0&1&0\\0&0&1\end{pmatrix}.
$$

<!-- bilingual-en:start -->
## Why the coordinates stay the same

In [[矩阵乘法|matrix multiplication]], an output coordinate is a row of the matrix multiplied against the input column. For $I_3$, the first row selects the first coordinate, the second row selects the second, and the third selects the third:
<!-- bilingual-en:end -->

## 为什么坐标保持不变

在[[矩阵乘法]]中，一个输出坐标由矩阵的一行与输入列相乘得到。$I_3$ 的第一行只选出第一个坐标，第二行选第二个，第三行选第三个：

$$
I_3\begin{pmatrix}a\\b\\c\end{pmatrix}
=\begin{pmatrix}1a+0b+0c\\0a+1b+0c\\0a+0b+1c\end{pmatrix}
=\begin{pmatrix}a\\b\\c\end{pmatrix}.
$$

<!-- bilingual-en:start -->
The letters $a,b,c$ stand for any real or complex numbers. In dimension $n$, the same row-by-row argument proves $I_nx=x$ for every $n$-coordinate column $x$. Conversely, if a square matrix leaves every vector unchanged, apply it to each vector with one coordinate equal to 1 and the others 0. Each such input selects one matrix column, so those columns must be exactly the columns of $I_n$. This characterizes the identity matrix uniquely.
<!-- bilingual-en:end -->

$a,b,c$ 可以是任意实数或复数。在 $n$ 维中，同样逐行计算便证明：对每个有 $n$ 个坐标的列向量 $x$，都有 $I_nx=x$。反过来，若一个方阵保持每个向量不变，就分别输入“一个坐标为1、其余为0”的向量；每次都会选出矩阵的一列。因此各列必须与 $I_n$ 完全相同，这也唯一确定了单位矩阵。

> [!example] The two sides may need different sizes / 两边可能需要不同尺寸
> <!-- bilingual-en:start -->
> If $A=\begin{pmatrix}1&2&3\\4&5&6\end{pmatrix}$, then $A$ has two rows and three columns. Left multiplication needs $I_2$, while right multiplication needs $I_3$: $I_2A=A=AI_3$. Neither $I_3A$ nor $AI_2$ is a defined matrix product, because the inner dimensions do not match. In general, for $A$ of size $m\times n$, use $I_mA=A=AI_n$.
> <!-- bilingual-en:end -->
>
> 若 $A=\begin{pmatrix}1&2&3\\4&5&6\end{pmatrix}$，则它有两行三列。左乘需要 $I_2$，右乘需要 $I_3$：$I_2A=A=AI_3$。$I_3A$ 与 $AI_2$ 的内侧尺寸不匹配，矩阵乘积没有定义。一般地，$m\times n$ 的 $A$ 满足 $I_mA=A=AI_n$。

<!-- bilingual-en:start -->
## Reading an identity in a larger formula

For a square matrix $A$, an [[逆矩阵|inverse]] $A^{-1}$ undoes its action: $A^{-1}A=AA^{-1}=I$. Here $T$ denotes [[矩阵转置|transpose]], so a tuple with superscript $T$ is a column. The symbol $I$ says that the combined transformation leaves every vector unchanged; it does not say that every entry of the product is 1. For example, the all-ones matrix $J=\begin{pmatrix}1&1\\1&1\end{pmatrix}$ sends $(2,3)^T$ to $(5,5)^T$ and is not $I_2$.

An identity matrix is always square. A rectangular array with a few diagonal ones may copy some coordinates or add zeros, but it cannot be the identity on one fixed space of all input and output vectors. Keep the size when reading formulas such as $Q^TQ=I_r$ and $QQ^T=I_m$: the two assertions concern different spaces and need separate justification.
<!-- bilingual-en:end -->

## 读懂较大公式中的单位矩阵

对方阵 $A$，[[逆矩阵]] $A^{-1}$ 撤销它的作用：$A^{-1}A=AA^{-1}=I$。这里上标 $T$ 表示[[矩阵转置|转置]]，把横写的坐标组记成列向量。$I$ 表示两次变换合起来保持每个向量不变，不表示乘积中的每个元素都为1。例如全1矩阵 $J=\begin{pmatrix}1&1\\1&1\end{pmatrix}$ 会把 $(2,3)^T$ 变成 $(5,5)^T$，它不是 $I_2$。

单位矩阵总是方阵。长方数组中的若干对角线1可以复制部分坐标或添零，却不能作为同一个固定输入输出空间上的恒等操作。读 $Q^TQ=I_r$、$QQ^T=I_m$ 这类公式时应保留尺寸：两个断言涉及不同空间，需要分别论证。
