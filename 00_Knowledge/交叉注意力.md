# 交叉注意力是查询来自一组表示而键和值来自另一组表示的注意力读取

<!-- bilingual-en:start -->
*Cross-attention draws queries from one representation source and keys and values from another*
<!-- bilingual-en:end -->

交叉注意力让一个表示来源发出查询，从另一组提供键和值的表示中读取信息。它仍按[[注意力读取|查询—键匹配决定权重，再汇总值]]；与[[自注意力]]的区别在于来源分开，而不是两个来源必须长度不同。

<!-- bilingual-en:start -->
Cross-attention lets one representation source issue queries that read from another source supplying keys and values. It still uses [[注意力读取|query–key compatibility to weight and aggregate values]]. Its distinction from [[自注意力|self-attention]] is the separation of sources, without requiring different sequence lengths.
<!-- bilingual-en:end -->

## 查询位置读取记忆位置

<!-- bilingual-en:start -->
*Query positions read from memory positions*
<!-- bilingual-en:end -->

省略 batch，记查询来源为 $X\in\mathbb R^{n_q\times d_x}$，被读取的记忆来源为 $Y\in\mathbb R^{n_k\times d_y}$。以一般线性投影记法表示：

<!-- bilingual-en:start -->
Omit the batch dimension. Let $X\in\mathbb R^{n_q\times d_x}$ be the query source and $Y\in\mathbb R^{n_k\times d_y}$ the memory source being read. Using general linear-projection notation:
<!-- bilingual-en:end -->

$$
Q=XW_Q,\qquad K=YW_K,\qquad V=YW_V,
$$

$$
W_Q\in\mathbb R^{d_x\times d_k},\quad
W_K\in\mathbb R^{d_y\times d_k},\quad
W_V\in\mathbb R^{d_y\times d_v}.
$$

查询和记忆的原始宽度 $d_x,d_y$ 可以不同，但做点积之前，Q/K 必须投影到同一宽度 $d_k$。采用[[缩放点积注意力]]时，分数和权重形状为 $n_q\times n_k$，输出为 $n_q\times d_v$；每个 query 位置得到一个读出。

<!-- bilingual-en:start -->
The original query and memory widths $d_x,d_y$ may differ, but Q/K must have a common width $d_k$ before taking dot products. With [[缩放点积注意力|scaled dot-product attention]], scores and weights have shape $n_q\times n_k$, and the output has shape $n_q\times d_v$: one readout per query position.
<!-- bilingual-en:end -->

## 编码器—解码器中的例子

<!-- bilingual-en:start -->
*An encoder–decoder example*
<!-- bilingual-en:end -->

原始 [[Transformer解码器|Transformer decoder]] 用自身的表示提供 query，用 [[Transformer编码器|encoder]] 的输出提供 key 和 value。若本次计算含 2 个目标侧 query 位置和 3 个来源位置，权重矩阵就是 $2\times3$。每行分别在 3 个来源位置上归一化，最后得到 2 个目标侧读出；来源长度不会变成输出行数。

<!-- bilingual-en:start -->
In the original [[Transformer解码器|Transformer decoder]], decoder representations supply queries while [[Transformer编码器|encoder]] outputs supply keys and values. If a computation includes two target-side query positions and three source positions, its weight matrix is $2\times3$. Each row normalizes across the three source positions, producing two target-side readouts. The source length does not determine the number of output rows.
<!-- bilingual-en:end -->

来源输入可供完整读取，与目标侧不得使用未来目标信息是不同要求。交叉注意力的定义本身不规定因果掩码；生成架构必须保证发出 query 的表示和所读取记忆只包含该预测允许使用的信息。

<!-- bilingual-en:start -->
Full access to a source input and exclusion of future target information are separate requirements. Cross-attention's definition does not prescribe a causal mask. A generative architecture must ensure that both the query representations and the memory contain only information permitted for the prediction.
<!-- bilingual-en:end -->

## 来源与核验

<!-- bilingual-en:start -->
*Sources and verification*
<!-- bilingual-en:end -->

- [Vaswani et al. (2017), *Attention Is All You Need*](https://arxiv.org/html/1706.03762v7)，§3.2.3 的 encoder–decoder attention：支持 decoder 提供 query、encoder 输出提供 key/value 的来源区分；§3.2.1、§3.2.2 支持注意力与投影公式。本卡的 $d_x,d_y$ 是一般投影记法；原始 Transformer 的对应两种宽度均为 $d_{\mathrm{model}}$。$2\times3$ 例子由查询数与记忆位置数直接确定。
  <!-- bilingual-en:start -->
  Encoder–decoder attention in Section 3.2.3 identifies decoder queries and encoder-output keys and values. Sections 3.2.1 and 3.2.2 supply the attention and projection formulas. The $d_x,d_y$ notation is a generalization; both corresponding widths in the original Transformer equal $d_{\mathrm{model}}$. The $2\times3$ example follows from the query and memory counts.
  <!-- bilingual-en:end -->
