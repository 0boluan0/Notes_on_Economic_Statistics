# 累积函数把从固定起点到可变终点的定积分作为函数值
<!-- bilingual-en:start -->
*An accumulation function assigns each endpoint the integral from a fixed starting point*
<!-- bilingual-en:end -->

固定起点 $a$，让终点 $x$ 改变，定义
$$G(x)=\int_a^x f(t)\,dt.$$
这就是由 $f$ 产生的**累积函数**；定义域限于从 $a$ 到 $x$ 的整段积分都存在的终点。$t$ 是内部积分变量，$x$ 是这一个新函数的输入，而且 $G(a)=0$。
<!-- bilingual-en:start -->
Fix the starting point and vary the endpoint. The resulting integral defines a new function on endpoints for which the entire intervening integral exists. The internal variable is a dummy variable, the endpoint is the input, and accumulation at the starting point is zero.
<!-- bilingual-en:end -->

例如 $G(x)=\int_0^x2t\,dt=x^2$。即使 $x<0$，有向积分仍给出正的 $x^2$：负的函数值与反向积分各带一次负号。若 $f$ 连续，[[积分求导定理]]说明 $G'=f$；这是定义之后得到的定理，而不是定义本身。
<!-- bilingual-en:start -->
Integrating $2t$ from zero gives $x^2$, including negative endpoints: negative heights and reversed orientation contribute two sign changes. For continuous integrands, the [[积分求导定理|differentiation theorem]] proves that the new function has derivative equal to the integrand; this is a consequence, not the definition itself.
<!-- bilingual-en:end -->
