# 终端复用让一个交互界面访问和管理多个伪终端
<!-- bilingual-en:start -->
*Terminal multiplexing lets one interface access and manage multiple pseudo-terminals.*
<!-- bilingual-en:end -->

终端复用器让用户从一个屏幕切换或并排访问多个终端程序，而不把它们合并成一个进程。在 tmux 中，server 管理会话和伪终端，client 显示并连接到会话；显示端与管理端是不同进程。
<!-- bilingual-en:start -->
A terminal multiplexer lets one screen switch between or display several terminal programs without merging them into one process. In tmux, a server manages sessions and pseudo-terminals while clients display and attach to sessions. Display and management run in separate processes.
<!-- bilingual-en:end -->

Tmux 的工作对象依次是 session（会话）、window（窗口）、pane（窗格）：会话链接一个或多个窗口，窗口可划分成多个窗格，每个窗格提供一个伪终端。窗口也可链接到多个会话，因此这不必是严格的独占目录树。
<!-- bilingual-en:start -->
Tmux uses sessions, windows, and panes: a session links one or more windows, and a window can be split into panes, each providing a pseudo-terminal. Windows can be linked to multiple sessions, so this is not necessarily an exclusive ownership tree.
<!-- bilingual-en:end -->

分屏改善同时观察，detach／attach 则改变 client 与会话的连接。要判断断线后任务是否仍可用，必须再看[[tmux会话保持边界]]，不能仅凭屏幕上有多个标签页作判断。
<!-- bilingual-en:start -->
Splitting improves simultaneous observation, while detach and attach change the client's connection to a session. To determine whether work survives disconnection, apply [[tmux会话保持边界|tmux session-lifetime boundaries]] rather than merely noticing multiple tabs.
<!-- bilingual-en:end -->
