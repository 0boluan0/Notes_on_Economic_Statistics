# Monotonicity of stopping-time information
<!-- bilingual-en:end -->

*停时信息单调性*

<!-- bilingual-en:start -->
Knowing the first coin toss does not stop being useful when a third toss has been observed. **Stopping-time information is monotone in the same sense:** if one observation rule always stops no later than another, every event decidable at the earlier stop is also decidable at the later stop. The comparison is between the information available under two rules, even when their stopping times vary between outcomes.
<!-- bilingual-en:end -->

看到第三次抛硬币的结果时，第一次抛掷的结果仍然是已知的。**停时信息具有同样的单调性：**如果一个观察规则在每条路径上都不晚于另一个规则停止，那么较早停止时已经能判断的事件，在较晚停止时仍然能判断。比较的是两个规则所带来的信息，即使它们的停止时刻会随结果而改变。

<!-- bilingual-en:start -->
A [[滤过定义|filtration]] $(\mathcal F_n)_{n\ge0}$ records the events observable by each integer time $n$. A [[停时定义|stopping time]] is a rule whose decision to stop by $n$ uses only $\mathcal F_n$. For a stopping time $U$, the [[停时信息集|stopped sigma-algebra]] $\mathcal F_U$ contains the events $A$ for which $A\cap\{U\le n\}\in\mathcal F_n$ for every $n$; all events are taken in the same ambient sigma-algebra $\mathcal F$. The intersection says: on the paths already stopped by $n$, can we decide $A$ by then?
<!-- bilingual-en:end -->

[[滤过定义|滤过]] $(\mathcal F_n)_{n\ge0}$ 记录每个整数时刻 $n$ 已能观察到的事件。[[停时定义|停时]]要求“是否在 $n$ 之前或恰好在 $n$ 停止”只使用 $\mathcal F_n$ 中的信息。对停时 $U$，[[停时信息集]] $\mathcal F_U$ 收集满足所有 $n$ 都有 $A\cap\{U\le n\}\in\mathcal F_n$ 的事件 $A$，并且全部事件都属于同一个环境σ代数 $\mathcal F$。这个交集是在问：对于到 $n$ 已经停止的路径，届时能否判断 $A$？

> [!important] Earlier information remains available · 较早的信息仍然可用
> <!-- bilingual-en:start -->
> Let $S,T$ be stopping times for the same filtration, with values in $\{0,1,2,\ldots\}\cup\{\infty\}$. If $S(\omega)\le T(\omega)$ for every outcome $\omega$, then $\mathcal F_S\subseteq\mathcal F_T$. The symbol $\subseteq$ allows equality; waiting longer need not reveal anything new.
> <!-- bilingual-en:end -->
>
> 设 $S,T$ 是同一滤过下的停时，取值于 $\{0,1,2,\ldots\}\cup\{\infty\}$。若每个结果 $\omega$ 都满足 $S(\omega)\le T(\omega)$，则 $\mathcal F_S\subseteq\mathcal F_T$。符号 $\subseteq$ 允许相等；等得更久并不一定获得新信息。

<!-- bilingual-en:start -->
For example, toss independent fair coins. Let $S=1$, and let $T$ be the first head, with a forced stop at toss $3$ if necessary. Then $1\le T\le3$. The event “the first toss was a head” is known at both stops. But “the second toss was a head” is not in $\mathcal F_T$: on the branch where the first toss is a head, the rule has already stopped before seeing the second toss. Thus $\mathcal F_T$ is not automatically all the information at the largest possible time $3$.
<!-- bilingual-en:end -->

例如连续抛独立公平硬币。令 $S=1$，$T$ 为首次正面出现的时刻，若到第三次仍未出现就强制在第三次停止。于是 $1\le T\le3$。“第一次是正面”在两个停止规则下都已知，但“第二次是正面”不属于 $\mathcal F_T$：第一次就是正面的分支在第二次抛掷前已经停止。因此，$\mathcal F_T$ 不会自动等于最大可能时刻 $3$ 的全部信息。

<!-- bilingual-en:start -->
## Why the inclusion holds
<!-- bilingual-en:end -->

## 证明

<!-- bilingual-en:start -->
Take an event $A\in\mathcal F_S$. Fix a deterministic $n$. If the later rule has stopped by $n$, the earlier rule has stopped too: $\{T\le n\}\subseteq\{S\le n\}$. Consequently,
<!-- bilingual-en:end -->

取事件 $A\in\mathcal F_S$，固定一个确定时刻 $n$。如果较晚的规则到 $n$ 已停止，较早的规则也必然已停止，即 $\{T\le n\}\subseteq\{S\le n\}$。因此，

$$
A\cap\{T\le n\}=(A\cap\{S\le n\})\cap\{T\le n\}.
$$

<!-- bilingual-en:start -->
The first event on the right belongs to $\mathcal F_n$ by the definition of $\mathcal F_S$. The second belongs to $\mathcal F_n$ because $T$ is a stopping time. A sigma-algebra is closed under intersections, so the left side is in $\mathcal F_n$. This holds for every $n$, which is exactly the test for $A\in\mathcal F_T$. No expectation, independence, or integrability assumption is involved.
<!-- bilingual-en:end -->

右边第一个事件由 $\mathcal F_S$ 的定义属于 $\mathcal F_n$；第二个事件因为 $T$ 是停时而属于 $\mathcal F_n$。σ代数对交集封闭，因此左边也属于 $\mathcal F_n$。这对每个 $n$ 都成立，恰好就是 $A\in\mathcal F_T$ 的检验条件。证明没有使用期望、独立性或可积性假设。

<!-- bilingual-en:start -->
The same proof works in continuous time using the definition $A\cap\{U\le t\}\in\mathcal F_t$ for every real $t\ge0$: simply fix $t$ in the displayed intersection. This inclusion itself needs no right-continuity assumption. Keep the pointwise order and the same ambient sigma-algebra; changing versions only on null sets is a separate issue if the filtration is not completed.
<!-- bilingual-en:end -->

连续时间采用“对每个实数 $t\ge0$ 都有 $A\cap\{U\le t\}\in\mathcal F_t$”的定义时，同一个证明仍然适用，只需在交集等式中固定 $t$。这个包含关系本身不需要右连续假设。这里始终使用逐路径的先后关系和同一个环境σ代数；如果滤过没有完备化，仅在零概率集合上更换版本则需要另外处理。

<!-- bilingual-en:start -->
## What this gives optional sampling
<!-- bilingual-en:end -->

## 在可选抽样中的作用

<!-- bilingual-en:start -->
For a [[鞅定义|martingale]] $M_n$, the expression $E[M_T\mid\mathcal F_S]$ asks for the terminal value predicted from information available at the earlier stop. The inclusion supplies the information order needed for [[塔式法则|iterated conditioning]]. It does not prove that $M_T$ is integrable or that this prediction equals $M_S$. Those are conclusions of [[可选停止条件|optional sampling under its stated conditions]].
<!-- bilingual-en:end -->

对于[[鞅定义|鞅]] $M_n$，$E[M_T\mid\mathcal F_S]$ 表示使用较早停止时的信息预测终值。信息包含关系提供了[[塔式法则|迭代条件化]]所需的先后结构，却不能证明 $M_T$ 可积，也不能单独证明预测值等于 $M_S$；这些结论要在[[可选停止条件|可选抽样的完整条件]]下得到。
