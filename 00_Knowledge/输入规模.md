# Input size
<!-- bilingual-en:end -->

*输入规模*

<!-- bilingual-en:start -->
How big is an input? A list containing eight numbers has eight entries, while the number eight itself needs four binary digits, `1000`. The phrase **input size** tells us which kind of size we are counting before we ask how the work grows.
<!-- bilingual-en:end -->

一个输入有多大？装着八个数的列表有八个元素；整数八本身却用四个二进制数字 `1000` 表示。**输入规模**先说清楚我们数的是哪一种大小，再讨论工作量怎样增长。

<!-- bilingual-en:start -->
Input size measures how large a valid input is and supplies the variables of a cost function. Before writing $T(n)$, specify whether $n$ counts list elements, string characters, encoding bits, or something else. Size need not equal an input's numerical value or be a single parameter.
<!-- bilingual-en:end -->

输入规模是描述一个合法输入有多大的度量；它决定成本函数的自变量。使用 $T(n)$ 前必须说明 $n$ 是列表元素数、字符串长度、整数的编码位数，还是别的量。规模不是固定等于输入的数值，也不必只有一个参数。

<!-- bilingual-en:start -->
Here $T(n)$ names the cost associated with size $n$ under the chosen input case and [[算法成本模型|cost model]]. A binary digit, or bit, is one 0 or 1. In the formula below, $\log_2 N$ asks which power of 2 equals $N$, and $\lfloor u\rfloor$ is the greatest integer no larger than $u$.
<!-- bilingual-en:end -->

这里 $T(n)$ 表示在选定输入情形与[[算法成本模型]]下，规模为 $n$ 时的成本。一个二进制位（bit）就是一个 0 或 1；下式中的 $\log_2 N$ 问的是 2 的多少次方等于 $N$，而 $\lfloor u\rfloor$ 是不超过 $u$ 的最大整数。

> [!example] The same value, two size measures · 同一个数，两种规模
> <!-- bilingual-en:start -->
> Imagine a loop that visits the integers from 0 through $N-1$ once. It makes $N$ visits. For $N=7$, the representation is `111`: three bits but seven visits. For $N=8$, the representation is `1000`: four bits and eight visits. In general, a $b$-bit positive integer satisfies $2^{b-1}\le N<2^b$. Counting visits is therefore linear in the numerical value $N$, but grows exponentially with the bit-length parameter $b$. This counts visits, not the cost of arbitrary-precision arithmetic.
> <!-- bilingual-en:end -->
>
> 设一个循环依次访问从 0 到 $N-1$ 的整数，共访问 $N$ 次。$N=7$ 的二进制表示是 `111`，三位却有七次访问；$N=8$ 的表示是 `1000`，四位且有八次访问。一般地，正整数占 $b$ 位意味着 $2^{b-1}\le N<2^b$。所以访问次数对数值 $N$ 是线性的，对位数参数 $b$ 则呈指数增长。这里数的是访问次数，并未把任意精度算术的成本算作常数。

<!-- bilingual-en:start -->
For the usual binary encoding of a nonnegative integer $N$, its bit length is $b=\lfloor\log_2N\rfloor+1$ for $N\ge1$, with one bit for zero. An algorithm taking $N$ iterations is linear in the value but can be exponential in its bit length. For two independently sized lists, retain $T(m,n)$, or explain a reduction after declaring a relation such as $m=n$ or a new size measure such as total input length.
<!-- bilingual-en:end -->

对非负整数 $N$ 的通常二进制编码，位数为 $b=\lfloor\log_2N\rfloor+1$（$N\ge1$；$N=0$ 用一位）。因此执行 $N$ 轮的算法是按数值 $N$ 线性，却可能按位数 $b$ 指数增长。若输入是两个独立长度为 $m,n$ 的列表，就保留 $T(m,n)$；也可在声明两者关系（如 $m=n$），或明确采用总长度等新规模后，说明怎样合并参数。

<!-- bilingual-en:start -->
Two lists need not share one length. Pairing each of two entries with each of three entries creates six pairs: the count is $mn$ when the lengths are $m$ and $n$. Calling both lengths $n$ would silently add an assumption. A size measure is a description of allowed inputs, not permission to discard an independent parameter.
<!-- bilingual-en:end -->

两个列表不必同样长。把两项中的每一项与三项中的每一项配对，会得到六对；长度分别为 $m,n$ 时就是 $mn$。若把两者都叫作 $n$，就悄悄加上了一个假设。规模度量是在描述允许的输入，并不允许随意丢掉独立参数。

<!-- bilingual-en:start -->
Element count alone may be insufficient: comparisons of arbitrarily long integers or strings also depend on their lengths. The [[算法成本模型|cost model]] determines whether an element occupies a fixed-size machine word. For sorting, record these choices in the [[排序复杂度口径|sorting complexity contract]].
<!-- bilingual-en:end -->

仅给元素个数仍可能不够：若元素是任意长整数或字符串，一次比较的成本还取决于元素长度。是否把元素视为一个固定大小的机器字，由[[算法成本模型]]决定；排序时把这些约定汇总在[[排序复杂度口径]]。
