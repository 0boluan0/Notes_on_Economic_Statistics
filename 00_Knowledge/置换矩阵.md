# Permutation matrices
<!-- bilingual-en:end -->
*置换矩阵*

<!-- bilingual-en:start -->
A **permutation matrix** changes the order of entries without changing their values. Multiplying a column vector by it moves its coordinates to new positions; multiplying a matrix on the left moves whole rows. The matrix records which old position each new position copies.
<!-- bilingual-en:end -->

**置换矩阵**改变元素的顺序，不改变它们的值。用它乘一个列向量，会把坐标移动到新位置；从左侧乘矩阵，则移动整行。矩阵记录的是：每个新位置从哪个旧位置取内容。

<!-- bilingual-en:start -->
For a positive integer $n$, rearrange the rows of the [[单位矩阵|identity matrix]] $I_n$. The result is an $n\times n$ permutation matrix $P$. Equivalently, each row and each column has exactly one $1$, and every other entry is $0$. The row condition chooses one input coordinate for each output; the column condition ensures that every input is used exactly once. These real matrices also act on complex vectors without conjugating their entries.
<!-- bilingual-en:end -->

对正整数 $n$，把[[单位矩阵]] $I_n$ 的行重新排列，得到的 $n\times n$ 矩阵 $P$ 就是置换矩阵。等价地，每行、每列恰有一个 $1$，其余元素全为 $0$。每行一个 $1$ 使每个输出选择一个输入，每列一个 $1$ 则保证每个输入恰好使用一次。这些实矩阵也能作用于复向量，不会对元素取共轭。

<!-- bilingual-en:start -->
## A swap hides the difference between two directions
<!-- bilingual-en:end -->
## 最小例子

$$S=\begin{pmatrix}0&1&0\\1&0&0\\0&0&1\end{pmatrix}.$$

<!-- bilingual-en:start -->
$S$ swaps the first two rows in $SA$ and the first two columns in $AS$, whenever the dimensions allow the products. Two applications restore the original order, so $S^2=I_3$ and $S^{-1}=S$. This useful example is special: an arbitrary permutation need not undo itself.
<!-- bilingual-en:end -->

尺寸允许时，$SA$ 交换 $A$ 的前两行，$AS$ 交换前两列。同样交换两次就恢复，所以 $S^2=I_3$、$S^{-1}=S$。这个例子很有用，但也很特殊：任意置换未必能通过再做自身一次来撤销。

<!-- bilingual-en:start -->
Consider instead the three-cycle
<!-- bilingual-en:end -->

改看一个三循环：

$$P=\begin{pmatrix}0&1&0\\0&0&1\\1&0&0\end{pmatrix},\qquad
P\begin{pmatrix}x_1\\x_2\\x_3\end{pmatrix}
=\begin{pmatrix}x_2\\x_3\\x_1\end{pmatrix}.$$

<!-- bilingual-en:start -->
For an explicit matrix $A$, [[矩阵乘法|matrix multiplication]] gives
<!-- bilingual-en:end -->

对具体矩阵 $A$，按[[矩阵乘法]]得到

$$A=\begin{pmatrix}1&2&3\\4&5&6\\7&8&9\end{pmatrix},\qquad
PA=\begin{pmatrix}4&5&6\\7&8&9\\1&2&3\end{pmatrix},\qquad
AP=\begin{pmatrix}3&1&2\\6&4&5\\9&7&8\end{pmatrix}.$$

<!-- bilingual-en:start -->
$PA$ takes old rows in the order $2,3,1$. But $AP$ takes old columns in the order $3,1,2$: its first column uses the $1$ in row 3 of $P$. Thus “permutes rows or columns” does not mean that the same displayed index list applies on both sides. Here $P^2=P^T\ne P$ and $P^3=I_3$, where $T$ means [[矩阵转置|transpose]]. The [[循环置换的周期|cycle length]] describes when repeated applications return.
<!-- bilingual-en:end -->

$PA$ 按 $2,3,1$ 取原行；$AP$ 却按 $3,1,2$ 取原列，因为它第一列使用的是 $P$ 第三行的那个 $1$。“重排行或列”不表示两侧都照搬同一张编号清单。这里 $P^2=P^T\ne P$、$P^3=I_3$，其中 $T$ 表示[[矩阵转置|转置]]；[[循环置换的周期]]说明重复作用何时返回。

<!-- bilingual-en:start -->
## Read the index convention explicitly
<!-- bilingual-en:end -->
*明确怎样读取编号*

<!-- bilingual-en:start -->
Let $\pi$ be a rearrangement of $1,\ldots,n$, and define $p_{i,\pi(i)}=1$. In words, output position $i$ copies input position $\pi(i)$. The inverse rearrangement $\pi^{-1}$ sends each input label back to the output position that selected it. The entrywise rules are
<!-- bilingual-en:end -->

设 $\pi$ 是 $1,\ldots,n$ 的一个重排，约定 $p_{i,\pi(i)}=1$。也就是说，输出位置 $i$ 从输入位置 $\pi(i)$ 复制内容。逆重排 $\pi^{-1}$ 把输入编号送回选择它的输出位置。逐元素规则为

$$(Px)_i=x_{\pi(i)},\qquad
(PA)_{ij}=A_{\pi(i),j},\qquad
(AP)_{ij}=A_{i,\pi^{-1}(j)}.$$

<!-- bilingual-en:start -->
For the last identity, $p_{kj}$ is nonzero exactly when $\pi(k)=j$, that is, $k=\pi^{-1}(j)$. This derives the direction instead of relying on an ambiguous phrase such as “move according to $\pi$.” Left multiplication only requires $A$ to have $n$ rows; right multiplication only requires it to have $n$ columns. $A$ need not be square.
<!-- bilingual-en:end -->

最后一式中，$p_{kj}$ 非零恰好要求 $\pi(k)=j$，即 $k=\pi^{-1}(j)$。这样能直接推导方向，不必依赖“按 $\pi$ 移动”之类可能有歧义的说法。左乘只要求 $A$ 有 $n$ 行，右乘只要求它有 $n$ 列，$A$ 本身不必为方阵。

<!-- bilingual-en:start -->
## Transpose reverses the rearrangement
<!-- bilingual-en:end -->
*转置撤销重排*

<!-- bilingual-en:start -->
Each column of $P$ is a different coordinate unit vector: one entry is $1$, the rest are zero. The ordinary dot product of two such columns is $1$ when they are the same column and $0$ otherwise. Hence $P^TP=I_n$; the corresponding row argument gives $PP^T=I_n$. Therefore
<!-- bilingual-en:end -->

$P$ 的每列是不同的坐标单位向量，即一个位置为 $1$、其余为零。两列作普通点积，同一列得到 $1$，不同列得到 $0$，故 $P^TP=I_n$；对行作相同计算得到 $PP^T=I_n$。因此

$$P^{-1}=P^T.$$

<!-- bilingual-en:start -->
Every permutation matrix is consequently an [[正交矩阵|orthogonal matrix]]. It preserves [[欧氏范数|Euclidean lengths]] because it only reorders squared coordinate magnitudes; over the complex numbers it is also [[Unitary 矩阵|unitary]], since its real entries make conjugate transpose equal to ordinary transpose. The converse is false: an orthogonal matrix may mix coordinates or change signs, while a permutation matrix has only zeros and ones.
<!-- bilingual-en:end -->

所以置换矩阵都是[[正交矩阵]]。它只重排坐标模平方，因而保持[[欧氏范数|欧氏长度]]；因为元素都是实数，共轭转置等于普通转置，所以在复数域上也是[[Unitary 矩阵|酉矩阵]]。反过来不成立：正交矩阵可以混合坐标或改变符号，置换矩阵则只有零和一。

<!-- bilingual-en:start -->
## Track which object was reordered
<!-- bilingual-en:end -->
## 边界

<!-- bilingual-en:start -->
If $P_1$ acts first on rows and $P_2$ second, their combined record is $P_2P_1$. It is again a permutation matrix, but need not be one row exchange. A single swap is an [[初等矩阵|elementary matrix]]; a three-cycle requires more than one swap. Reversing the complete order uses the transpose of the complete product.
<!-- bilingual-en:end -->

若先作行置换 $P_1$、再作 $P_2$，总记录为 $P_2P_1$。它仍是置换矩阵，但不一定只是交换两行。单次换行是[[初等矩阵]]，三循环则需要多次交换；撤销累计排列要用整个乘积的转置。

<!-- bilingual-en:start -->
For equations $Ax=b$, a row reordering gives $PAx=Pb$, including the right-hand side. A column reordering changes the unknown order: solving $(AQ)z=b$ requires [[列置换后的解向量|recovering $x=Qz$]]. In [[消元与LU分解|pivoted LU]], our convention is $PA=LU$, with $P$ acting on the original rows. A source writing $A=\widetilde P LU$ uses $\widetilde P=P^{-1}$; these may be different matrices, as the three-cycle shows.
<!-- bilingual-en:end -->

对方程 $Ax=b$，重排行得到 $PAx=Pb$，右端也要同样重排。重排列则改变未知量次序，解完 $(AQ)z=b$ 后须[[列置换后的解向量|恢复 $x=Qz$]]。在[[消元与LU分解|选主元 LU]]中，本卡约定 $PA=LU$，$P$ 作用于原行；若来源写成 $A=\widetilde P LU$，则 $\widetilde P=P^{-1}$，三循环说明这两个矩阵可能不同。

> [!question]- Does the same permutation undo itself? · 原置换一定能撤销自身吗？
> <!-- bilingual-en:start -->
> Only when $P^2=I$. A single swap does; the displayed three-cycle does not. Its inverse is $P^T=P^2$.
> <!-- bilingual-en:end -->
>
> 只有 $P^2=I$ 时才可以。单次交换满足，所示三循环不满足；后者的逆是 $P^T=P^2$。
