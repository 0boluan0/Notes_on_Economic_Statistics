# 加法平滑方法与加法误差模型是不同选择
<!-- bilingual-en:start -->
*An additive smoothing method and an additive error model are separate choices*
<!-- bilingual-en:end -->

> [!summary] 原子区别
> 平滑“方法”决定 level、trend、seasonal 如何组成点预测位置 $\mu_t$；误差形式决定随机创新怎样围绕 $\mu_t$ 进入观测。两者不能用一个“加法/乘法”标签代替。
> <!-- bilingual-en:start -->
> The smoothing method determines how states form the point-forecast location. The error type determines how innovations enter around that location. These are separate modelling choices.
> <!-- bilingual-en:end -->

假设一个加法季节方法给出
$$
\mu_t=\ell_{t-1}+b_{t-1}+s_{t-m}.
$$
配 additive error 时，观测方程是
$$
y_t=\mu_t+\varepsilon_t;
$$
配 multiplicative error 时，则是
$$
y_t=\mu_t(1+\varepsilon_t).
$$
若初始状态与平滑参数对齐，两种误差模型可以生成相同的点预测位置；但在 $\operatorname{Var}(\varepsilon_t)=\sigma^2$ 的共同创新尺度下，additive error 给出 $\operatorname{Var}(y_t\mid\mathcal F_{t-1})=\sigma^2$，multiplicative error 则给出 $\mu_t^2\sigma^2$。因此 likelihood、innovation residual 与预测区间不同。

反过来，multiplicative seasonality 是 $\mu_t$ 内部的系统成分，例如 $(\ell_{t-1}+b_{t-1})s_{t-m}$；它不等于 multiplicative error。于是 ETS$(A,A,M)$ 是 additive error 配 multiplicative seasonality，而 ETS$(M,A,A)$ 是 multiplicative error 配 additive seasonality，含义完全不同。

乘法误差要求尺度 $\mu_t$ 可作分母，自动 ETS 通常只在严格正值数据上考虑它。零值、负值或接近零的条件中心会造成未定义、符号或数值稳定性问题。即便数据为正，也应检查相对误差方差是否合理，不能因为“销量随规模变大”就同时机械选择乘法季节与乘法误差。
<!-- bilingual-en:start -->
With the same state path, additive and multiplicative error models may share point forecasts but differ in likelihoods and forecast distributions. Multiplicative seasonality belongs inside the conditional location; multiplicative error scales the innovation around that location. Strict positivity is a practical boundary for multiplicative-error ETS models.
<!-- bilingual-en:end -->

> [!question]- 自检
> 两个模型的点预测完全相同，是否足以断定它们是同一个 ETS 模型？
>
> **答案：** 不足。误差形式可能不同；它们可有相同条件中心，却给出不同 innovation residual、likelihood 和预测区间。

## 来源与核验

- [Hyndman & Athanasopoulos, FPP3 §8.5](https://otexts.com/fpp3/ets.html)：核对同一方法的 additive/multiplicative error 模型可产生相同点预测但不同区间。
- [Hyndman et al. (2002), pp. 2–7](https://www.monash.edu/business/ebs/research/publications/ebs/a_state_space_framework_for_automatic_forecasting_using_exponential_smoothing_methods.pdf)：核对方法中的乘法成分与乘法误差的分离、likelihood 差异和零值边界。
