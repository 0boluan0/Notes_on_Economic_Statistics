# 梯度为零时，方程 $\nabla f(a)^Tv=0$ 不能决定水平集的切空间
<!-- bilingual-en:start -->
*When the gradient is zero, the equation $\nabla f(a)^Tv=0$ cannot determine the tangent space of a level set*
<!-- bilingual-en:end -->

> [!summary] 失效边界
> 对水平集 $L_c=\{x:f(x)=c\}$，每条经过 $a$ 的可微水平集曲线都满足
> $$
> \nabla f(a)^Tv=0.
> $$
> 但若 $\nabla f(a)=0$，这个方程对所有 $v$ 都成立，只留下必要条件 $0=0$。它没有告诉我们水平集在 $a$ 附近究竟是光滑曲面、交叉的分支、尖点，还是孤立点。
> <!-- bilingual-en:start -->
> Every differentiable curve in the level set $L_c=\{x:f(x)=c\}$ has a tangent vector satisfying $\nabla f(a)^Tv=0$. If $\nabla f(a)=0$, however, this equation holds for every $v$ and reduces to the uninformative necessary condition $0=0$. It does not reveal whether the nearby level set is a smooth surface, crossing branches, a cusp, or an isolated point.
> <!-- bilingual-en:end -->

## 最小反例：方程给出全空间，水平集却只有一点
<!-- bilingual-en:start -->
*Minimal counterexample: the equation gives the whole space, but the level set is one point*
<!-- bilingual-en:end -->

令
$$
f(x,y)=x^2+y^2,
\qquad L_0=\{(0,0)\}.
$$
原点的梯度为零，因此 $\nabla f(0,0)^Tv=0$ 允许每个 $v\in\mathbb R^2$。但 $L_0$ 是一个零维集合；把整个 $\mathbb R^2$ 称为它的切空间显然与局部几何不符。
<!-- bilingual-en:start -->
For $f(x,y)=x^2+y^2$, the zero level set is only the origin. The gradient there is zero, so the first-order equation accepts every $v\in\mathbb R^2$. Yet the level set is zero-dimensional; calling all of $\mathbb R^2$ its tangent space would contradict the local geometry.
<!-- bilingual-en:end -->

另一个函数 $f(x,y)=x^2-y^2$ 在原点也有零梯度，但其零水平集是两条相交直线 $y=\pm x$。这里甚至不存在一张唯一的光滑一维曲线来提供单一切线。两个例子的一阶方程完全相同，局部几何却不同。
<!-- bilingual-en:start -->
The function $f(x,y)=x^2-y^2$ also has zero gradient at the origin, but its zero level set consists of the two crossing lines $y=\pm x$. There is no single smooth one-dimensional branch supplying one tangent line. The two examples have the same first-order equation and different local geometries.
<!-- bilingual-en:end -->

## 正确的使用方式
<!-- bilingual-en:start -->
*How to use the tangent-space formula correctly*
<!-- bilingual-en:end -->

当 $\nabla f(a)\ne0$ 时，[[梯度与水平集]] 配合 [[隐函数定理]] 才能把
$$
\ker Df(a)=\{v:\nabla f(a)^Tv=0\}
$$
确认为水平集的切空间。梯度为零时，不能反过来把这个核当成答案；必须查看更高阶项或直接分析局部解集。
<!-- bilingual-en:start -->
When $\nabla f(a)\ne0$, [[梯度与水平集|the regular-level-set result]] together with the [[隐函数定理|implicit function theorem]] identifies $\ker Df(a)=\{v:\nabla f(a)^Tv=0\}$ as the tangent space. When the gradient vanishes, that kernel is not automatically the answer; higher-order terms or a direct analysis of the local solution set is required.
<!-- bilingual-en:end -->

> [!question]- 回忆提示
> 为什么 $\nabla f(a)=0$ 时不能仅凭 $\nabla f(a)^Tv=0$ 宣布切空间是 $\mathbb R^n$？
> <!-- bilingual-en:start -->
> Why can we not declare the tangent space to be $\mathbb R^n$ merely because $\nabla f(a)^Tv=0$ holds when $\nabla f(a)=0$?
> <!-- bilingual-en:end -->
>
> **答案：** 此时方程没有筛掉任何方向，只是失去了信息；不同的奇异水平集可以产生同一个零梯度，却具有完全不同的局部几何。
> <!-- bilingual-en:start -->
> **Answer:** The equation eliminates no direction and has simply lost information. Different singular level sets can have the same zero gradient while possessing entirely different local geometries.
> <!-- bilingual-en:end -->
