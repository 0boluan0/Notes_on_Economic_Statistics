# Rank from singular values
<!-- bilingual-en:end -->

*奇异值与秩*

<!-- bilingual-en:start -->
The [[矩阵秩|rank]] of a matrix counts how many independent output directions it can produce. A [[奇异值|singular value]] measures the stretch of a special unit input direction. A positive stretch keeps a direction alive; a zero stretch erases it. Counting positive stretches, including repetitions, gives the rank.
<!-- bilingual-en:end -->

矩阵的[[矩阵秩|秩]]计数它能产生多少个独立输出方向；[[奇异值]]衡量一个特殊单位输入方向的伸缩量。正伸缩保留一个方向，零伸缩消去它。把正奇异值按出现次数计数，就得到秩。

> [!example] Four inputs, two surviving directions / 四个输入，两个保留方向
> <!-- bilingual-en:start -->
> Consider
>
> $$A=\begin{pmatrix}3&0&0&0\\0&2&0&0\\0&0&0&0\end{pmatrix},\qquad
> A(x_1,x_2,x_3,x_4)^T=(3x_1,2x_2,0)^T.$$
>
> Changing $x_1$ and $x_2$ independently changes the first two output coordinates; changing $x_3$ or $x_4$ does nothing. The outputs fill a plane, so the rank is 2. The three singular values are $3,2,0$: exactly two are positive. Here $T$ is [[矩阵转置|transpose]], used to arrange coordinates in a column.
> <!-- bilingual-en:end -->
>
> 上面的矩阵把四个输入坐标送到三个输出坐标。改变 $x_1,x_2$ 可独立改变前两个输出，改变 $x_3,x_4$ 则没有作用。全部输出填满一个平面，所以秩为2；三个奇异值是 $3,2,0$，正值恰有两个。$T$ 是把坐标排成列的[[矩阵转置|转置]]。

## The exact counting rule
<!-- bilingual-en:end -->

*精确计数规则*

<!-- bilingual-en:start -->
Let $A$ be a real or complex $m\times n$ matrix, with $m,n\ge1$. It takes $n$ input coordinates to $m$ output coordinates. Use the matrix convention listing $p=\min(m,n)$ singular values in decreasing order, $\sigma_1\ge\cdots\ge\sigma_p\ge0$. Then
<!-- bilingual-en:end -->

设 $A$ 为实或复 $m\times n$ 矩阵，$m,n\ge1$，把 $n$ 个输入坐标映到 $m$ 个输出坐标。采用矩阵口径，按降序列出 $p=\min(m,n)$ 个奇异值 $\sigma_1\ge\cdots\ge\sigma_p\ge0$。则

$$\operatorname{rank}(A)=\#\{i:\sigma_i>0\}.$$

<!-- bilingual-en:start -->
The symbol $\#$ means the number of indices satisfying the condition. Repeated values count separately: $7,7,0$ gives rank 2, despite there being only one distinct positive number. The list $7,2,0,0$ likewise gives rank 2. The zero matrix has no positive singular values and has rank zero.
<!-- bilingual-en:end -->

$\#$ 表示满足条件的下标个数，重复值要分别计数：$7,7,0$ 对应秩2，尽管不同的正数只有一种；$7,2,0,0$ 也对应秩2。零矩阵没有正奇异值，秩为零。

## Why stretches count output dimensions
<!-- bilingual-en:end -->

*为什么伸缩量能读出输出维数*

<!-- bilingual-en:start -->
A complete [[奇异值分解|SVD]] writes $A=U\Sigma V^*$. The $n\times n$ matrix $V$ and $m\times m$ matrix $U$ choose perpendicular unit coordinate directions on the input and output sides. The star means conjugate transpose, reducing to ordinary transpose for real entries. The rectangular $m\times n$ matrix $\Sigma$ has the singular values on its diagonal and zeros elsewhere.

The coordinate changes $V^*$ and $U$ are invertible, so they cannot create or remove an independent direction. In $\Sigma$, each positive diagonal entry produces a separate coordinate direction and each zero produces no output. Its column space therefore has as many independent directions as positive entries. This proves the rule for $A$ as well.
<!-- bilingual-en:end -->

完整[[奇异值分解]]写成 $A=U\Sigma V^*$。$n\times n$ 的 $V$ 和 $m\times m$ 的 $U$ 分别选取输入侧、输出侧的相互垂直单位坐标方向。星号表示共轭转置，实数时就是普通转置；$m\times n$ 的矩形对角矩阵 $\Sigma$ 把奇异值放在对角线上，其他元素为零。

$V^*$ 与 $U$ 都是可逆坐标变换，不能增加或抹去独立方向。在 $\Sigma$ 中，每个正对角元产生一个独立坐标方向，零对角元不产生输出，因此列空间维数恰为正对角元个数，也就证明了 $A$ 的计数规则。

<!-- bilingual-en:start -->
More concretely, call the columns of $V$ and $U$ $v_i$ and $u_i$. Positive directions satisfy $Av_i=\sigma_i u_i$. These $u_i$ are perpendicular and independent, and every output is a combination of them. This identifies the output space itself; the full arrangement is explained in [[SVD与四个基本子空间|the four subspaces from an SVD]].
<!-- bilingual-en:end -->

具体地，把 $V,U$ 的列分别记为 $v_i,u_i$，正方向满足 $Av_i=\sigma_i u_i$。这些 $u_i$ 相互垂直、线性无关，每个输出都由它们线性组合而成。这指出实际输出空间；全部方向的安排见[[SVD与四个基本子空间]]。

> [!warning] Count the correct kind of zero / 分清在数哪一种零
> <!-- bilingual-en:start -->
> In the $3\times4$ example, the singular-value list contains one zero but two input directions are erased. In general, rank $r$ gives input nullity $n-r$ and left nullity $m-r$, by [[秩零度定理|rank–nullity]]. The diagonal list has only $\min(m,n)-r$ zeros; rectangular dimensions can supply additional unmatched input or output directions.
> <!-- bilingual-en:end -->
>
> 开头的 $3\times4$ 例子，奇异值列表中只有一个零，却有两个被消去的输入方向。一般地，秩为 $r$ 时，由[[秩零度定理]]可知输入零空间维数为 $n-r$，左零空间维数为 $m-r$；对角列表只有 $\min(m,n)-r$ 个零，矩形尺寸可能另外带来未配对方向。

<!-- bilingual-en:start -->
This is an exact algebraic statement: a tiny positive value still contributes one. Treating it as zero computationally is a separate [[数值秩|numerical-rank decision]], requiring scale, tolerance and a rule. Counting exact [[主元与自由变量|elimination pivots]] and counting positive singular values describe the same rank; numerical implementations may use different thresholds.
<!-- bilingual-en:end -->

这是精确代数恒等式，极小正值仍使精确秩增加1。计算中把它当成零，是需要尺度、容差与规则的[[数值秩]]决定。精确消元的[[主元与自由变量|主元数]]与正奇异值个数描述同一个秩，数值实现却可能采用不同阈值。

> [!question]- An $8\times5$ check / 尺寸检查
> <!-- bilingual-en:start -->
> If an $8\times5$ matrix has three positive singular values, what are its rank and input nullity? **Answer:** Rank 3 and input nullity $5-3=2$. Its left nullity is instead $8-3=5$.
> <!-- bilingual-en:end -->
>
> 一个 $8\times5$ 矩阵只有三个正奇异值，秩与输入零空间维数是多少？**答案：** 秩3，输入零空间维数 $5-3=2$；左零空间维数为 $8-3=5$。
