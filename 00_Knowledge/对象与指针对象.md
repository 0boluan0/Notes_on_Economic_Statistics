# 对象占据存储而指针对象保存的是指针值
<!-- bilingual-en:start -->
*An object occupies storage, while a pointer object stores a pointer value*
<!-- bilingual-en:end -->

> [!summary] 三个层次
> **对象（object）**是执行环境中一块能够表示值的数据存储；对象在自己的生命周期内拥有地址。**指针值（pointer value）**可以指向某个对象、函数或数组末尾后一位，也可以是空指针。**指针对象（pointer object）**则是一个自身也占据存储、其内容恰好为指针值的对象。三者不能压成“指针就是一串地址数字”。
> <!-- bilingual-en:start -->
> An object is a region of data storage that can represent a value. A pointer value may designate an object, a function, or one-past an array, or it may be null. A pointer object is itself an object whose stored value is a pointer value.
> <!-- bilingual-en:end -->

```c
int n = 50;
int *p = &n;
```

这里有两个对象：`n` 保存整数值 `50`，`p` 保存一个指针值。表达式 `&n` 产生指向 `n` 的指针值，并用它初始化 `p`；随后表达式 `p` 读取的是这份指针值。`p` 自己也有地址 `&p`，其类型是 `int **`，即“指向 `int *` 对象的指针”。
<!-- bilingual-en:start -->
There are two objects here: `n` stores the integer value `50`, while `p` stores a pointer value. `&n` produces the pointer value used to initialise `p`; `&p` is the address of the pointer object itself and has type `int **`.
<!-- bilingual-en:end -->

对象在生命周期内“有地址”，不表示每个对象名都可以作为一元 `&` 的操作数：位域不可取地址，以 `register` 存储类声明的对象也不能使用 `&`。所以后文的取地址规则还会明确要求“可取地址”。
<!-- bilingual-en:start -->
An object having an address during its lifetime does not make every object designator a valid operand of unary `&`: a bit-field is not addressable, and neither is an object declared with the `register` storage class. The address-of rule therefore states its addressability precondition explicitly.
<!-- bilingual-en:end -->

把指针画成带箭头的十六进制数是有用的入门模型，却不是语言保证。不同指针类型的表示和大小不必都相同，指针也不必能无损装进普通整数类型；因此不能把“本机常见为 8 字节”写成 C 的普遍事实。可靠推理应问“这个值被允许指向什么、对象是否仍存活”，而不是猜测某个物理内存编号。
<!-- bilingual-en:start -->
Drawing a pointer as a hexadecimal address is a useful introductory model, not a portable language guarantee. Pointer representations and sizes need not all be identical, and an ordinary integer type need not hold every pointer without loss. Reason from what the value may designate and whether that object is alive.
<!-- bilingual-en:end -->

> [!question]- 最小自检
> 在 `int *p = &n;` 中，`n`、`p`、`&n` 分别是什么？
>
> **答案：** `n` 是 `int` 对象，`p` 是指针对象，`&n` 是指向 `n` 的指针值；该值被存入 `p`。
