# 辅助空间是算法运行中同时存活的额外工作存储的峰值

<!-- bilingual-en:start -->
*Auxiliary space is the peak amount of simultaneously live extra working storage*
<!-- bilingual-en:end -->

辅助空间是算法在输入存储之外所需工作存储的峰值，而不是执行期间累计分配过多少存储。报告时须声明单位是机器字、字节还是位，并说明是否计入输出存储；本卡的例子排除原始输入，也不产生大型输出。

<!-- bilingual-en:start -->
Auxiliary space is the peak working storage needed beyond the input, not the cumulative amount allocated during execution. State whether units are words, bytes or bits, and whether output storage is included. The examples here exclude the original input and produce no large output.
<!-- bilingual-en:end -->

在确定的存储口径下，可写为 $S_{\mathrm{aux}}(x)=\max_t M_{\mathrm{live}}(x,t)$：只计时刻 $t$ 仍需保留的额外存储。连续重复分配并释放同一个大小为 $n$ 的缓冲区，若任一时刻只有一个缓冲区存活，峰值是 $\Theta(n)$，不能把所有分配量相加当作空间复杂度；这里假定释放的空间可被复用。

<!-- bilingual-en:start -->
Under a fixed convention, write $S_{\mathrm{aux}}(x)=\max_t M_{\mathrm{live}}(x,t)$, counting extra storage still needed at time $t$. Repeatedly allocating and releasing an $n$-sized buffer has peak $\Theta(n)$ space if only one buffer is live at a time and released memory is reusable. Summing all allocations would measure a different quantity.
<!-- bilingual-en:end -->

递归必须算尚未返回的调用帧及其保留的数据。若每帧额外占用统一的 $O(1)$、且没有其他增长存储，则深度为 $d$ 给出 $O(d)$ 辅助空间上界；这是充分条件，具体分析复用[[递归调用树成本]]。切片会分配新序列，不能只数几个索引变量；见[[切片二分成本]]。原地交换排序可以只用常数额外空间，普通合并排序则需要线性临时缓冲区。

<!-- bilingual-en:start -->
Recursion must include active frames and the data they retain. Uniformly $O(1)$ additional storage per frame, with no other growing workspace, is sufficient for depth $d$ to give an $O(d)$ auxiliary-space bound; see [[递归调用树成本|recursion-tree costs]]. Slices create new sequences, so counting only index variables misses storage; see [[切片二分成本|slicing binary-search costs]]. In-place swap-based sorting can use constant extra space, whereas ordinary merge sort needs a linear temporary buffer.
<!-- bilingual-en:end -->
