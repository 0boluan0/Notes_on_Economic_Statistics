# Counting batches within an epoch
<!-- bilingual-en:end -->

*训练轮次与小批量*

<!-- bilingual-en:start -->
For a fixed finite dataset sampled without replacement, an epoch is one pass over the designated training samples. Batch size $B$ sets how many samples are grouped at once. The number of samples, the number of batches and the number of completed epochs have different units.
<!-- bilingual-en:end -->

对固定、无放回遍历的有限训练集，一个训练轮次（epoch）是把指定样本用于训练一遍。批大小（batch size）$B$ 规定一次装几条样本。样本数、批次数和完成的轮数各自有不同的单位。

<!-- bilingual-en:start -->
## The last batch
<!-- bilingual-en:end -->

*最后一批怎样影响计数*

<!-- bilingual-en:start -->
For $M$ samples, a positive batch size $B$ and a loader that keeps its final partial batch, the number of batches is $\lceil M/B\rceil$. If it drops the partial batch, the loader yields $\lfloor M/B\rfloor$ full batches. In the latter case a loader pass omits the remainder. For $M=185$ and $B=2$, keeping the remainder yields 92 pairs plus one single-sample batch.
<!-- bilingual-en:end -->

设有 $M$ 条样本、批大小 $B>0$。保留最后不足一批的样本时，一遍共有 $\lceil M/B\rceil$ 批。丢弃末批余数时，加载器给出 $\lfloor M/B\rfloor$ 个满批，该次遍历会略过剩余样本。185 条按每批 2 条并保留余数时，得到 92 个满批和 1 个单样本批。

<!-- bilingual-en:start -->
In Raschka’s simple training loop the optimizer is stepped once per training batch. A data-loading loop that merely reads batches counts reads. Parameter updates depend on the actual training code. Window construction fixes the underlying sample count first, as shown in [[00_Knowledge/下一词元滑窗取样|full-window sampling]].
<!-- bilingual-en:end -->

作者的基础训练循环每处理一批，就由优化器（optimizer）执行一次参数更新。只遍历加载器检查数据时，计数表示读取的批数。更新次数要从实际训练循环判断。样本总数先由[[00_Knowledge/下一词元滑窗取样|窗口取样规则]]产生。
