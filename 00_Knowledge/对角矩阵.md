# Diagonal matrix
<!-- bilingual-en:end -->
*对角矩阵*

<!-- bilingual-en:start -->
A **diagonal matrix** has zeros everywhere away from its main diagonal. In the usual square-matrix setting, that diagonal runs from the top-left entry to the bottom-right entry. Only those diagonal positions can contain nonzero values. Multiplying a column vector by such a matrix treats each coordinate separately, without mixing it with the others.
<!-- bilingual-en:end -->

**对角矩阵**在主对角线以外的位置全部为零。通常先讨论方阵，它的主对角线从左上角延伸到右下角，只有这些位置可以非零。用这种矩阵乘一个列向量时，每个坐标单独变化，不会与其他坐标混在一起。

> [!example] Scale, reverse and erase coordinates · 缩放、反向与消去坐标
> <!-- bilingual-en:start -->
> In this matrix, the diagonal values are $2,-1,0$. Apply the [[矩阵乘法|row-by-column multiplication rule]] to the input $(3,4,5)^T$:
> <!-- bilingual-en:end -->
>
> 下面矩阵的对角值为 $2,-1,0$。对输入 $(3,4,5)^T$ 使用[[矩阵乘法|行乘列的计算规则]]：
>
> $$
> D=\begin{pmatrix}2&0&0\\0&-1&0\\0&0&0\end{pmatrix},
> \qquad
> D\begin{pmatrix}3\\4\\5\end{pmatrix}
> =\begin{pmatrix}6\\-4\\0\end{pmatrix}.
> $$
>
> <!-- bilingual-en:start -->
> The first coordinate doubles, the second changes sign, and the third becomes zero. The third diagonal value being zero is allowed: “diagonal” describes where nonzero entries may be, not a requirement that all diagonal entries be nonzero.
> <!-- bilingual-en:end -->
>
> 第一个坐标翻倍，第二个坐标变号，第三个坐标变为零。第三个对角元取零完全合法：“对角”描述的是非零元素允许出现的位置，并不要求每个对角元都非零。

<!-- bilingual-en:start -->
## Write just the diagonal values
<!-- bilingual-en:end -->
*只列出对角元的记号*

<!-- bilingual-en:start -->
For a positive integer $n$, let $D=(d_{ij})$ be a real or complex $n\times n$ matrix. Here $i$ is the row number and $j$ the column number. The diagonal positions have $i=j$. The definition is therefore
<!-- bilingual-en:end -->

设 $n$ 为正整数，$D=(d_{ij})$ 是实数或复数的 $n\times n$ 矩阵，$i$ 为行号，$j$ 为列号。对角位置满足 $i=j$，因此定义可以写成

$$D\text{ is diagonal}\iff d_{ij}=0\quad\text{for every }i\ne j.$$

<!-- bilingual-en:start -->
We abbreviate this by $D=\operatorname{diag}(d_1,\ldots,d_n)$, where $d_i=d_{ii}$. The single-index symbols list the diagonal values in order; all other entries are understood to be zero. For any input column $x$ with coordinates $x_1,\ldots,x_n$,
<!-- bilingual-en:end -->

通常简记为 $D=\operatorname{diag}(d_1,\ldots,d_n)$，其中 $d_i=d_{ii}$。单下标依次列出各个对角值，其余位置默认全为零。对任意坐标为 $x_1,\ldots,x_n$ 的输入列向量 $x$，

$$
\operatorname{diag}(d_1,\ldots,d_n)
\begin{pmatrix}x_1\\\vdots\\x_n\end{pmatrix}
=\begin{pmatrix}d_1x_1\\\vdots\\d_nx_n\end{pmatrix}.
$$

<!-- bilingual-en:start -->
This follows because row $i$ has only one possibly nonzero entry, in column $i$. There is no contribution from any $x_j$ with $j\ne i$. The identity matrix $I_n=\operatorname{diag}(1,\ldots,1)$ leaves every coordinate unchanged. The zero matrix is also diagonal, and every $1\times1$ matrix is diagonal.
<!-- bilingual-en:end -->

原因是第 $i$ 行只有第 $i$ 列可能非零，所以第 $i$ 个输出不会收到任何 $j\ne i$ 的 $x_j$ 的贡献。单位矩阵 $I_n=\operatorname{diag}(1,\ldots,1)$ 使每个坐标保持原值。零矩阵同样是对角矩阵，而每个一阶矩阵都是对角矩阵。

## Keep the shape separate from extra properties
<!-- bilingual-en:end -->
*把形状与额外性质分开*

<!-- bilingual-en:start -->
A square diagonal matrix is both upper and lower [[三角矩阵|triangular]], because both off-diagonal regions are zero. If its entries are real, it is also [[实对称矩阵|symmetric]]: reflection across the diagonal exchanges zeros with zeros. The converse is not true; for example, $\begin{pmatrix}1&2\\2&3\end{pmatrix}$ is symmetric but has nonzero off-diagonal entries.
<!-- bilingual-en:end -->

对角方阵同时是上[[三角矩阵]]和下三角矩阵，因为主对角线的两侧都为零。如果元素为实数，它还[[实对称矩阵|对称]]：沿对角线镜像时，非对角位置只是零与零互换。反过来却不成立，例如 $\begin{pmatrix}1&2\\2&3\end{pmatrix}$ 对称，但非对角位置有非零元素。

> [!warning] A zero diagonal value can lose information · 零对角元可能丢掉信息
> <!-- bilingual-en:start -->
> The example $D=\operatorname{diag}(2,-1,0)$ sends both $(0,0,1)^T$ and $(0,0,0)^T$ to the zero vector. No operation can recover which of these two inputs was supplied from that output alone, so $D$ has no [[逆矩阵|inverse]]. Being diagonal also imposes no positivity condition: the value $-1$ in this example is just as valid as $2$.
> <!-- bilingual-en:end -->
>
> 上例 $D=\operatorname{diag}(2,-1,0)$ 把 $(0,0,1)^T$ 和 $(0,0,0)^T$ 都变成零向量。仅凭这个输出，不可能恢复原来到底是哪一个输入，因此 $D$ 没有[[逆矩阵]]。对角的定义也不要求对角元为正：上例中的 $-1$ 与 $2$ 同样合法。

<!-- bilingual-en:start -->
The shape refers to a matrix in the coordinates currently being used. [[对角化|Diagonalization]] asks whether a [[线性映射|linear transformation]] can be represented by a diagonal matrix after choosing a suitable [[基|basis]], that is, suitable coordinate directions. Changing coordinates and checking whether the present matrix is already diagonal are different questions; diagonalization does not mean simply deleting off-diagonal entries.
<!-- bilingual-en:end -->

这里的形状是相对于当前使用的坐标而言的。[[对角化]]问的是：能否为一个[[线性映射|线性变换]]选取合适的[[基]]，也就是合适的坐标方向，让它在这些坐标中的矩阵成为对角矩阵。“换一组坐标后能否成为对角形状”与“当前矩阵是否已经是对角形状”是不同问题；对角化不等于直接删掉非对角元。

## The rectangular convention in singular value decomposition
<!-- bilingual-en:end -->
*奇异值分解中的矩形用法*

<!-- bilingual-en:start -->
In [[奇异值分解|singular value decomposition]], the term also extends to an $m\times n$ matrix with $m\ne n$. The same position rule remains: entries with $i\ne j$ are zero, and only positions $(1,1),\ldots,(\min(m,n),\min(m,n))$ may be nonzero. For example,
<!-- bilingual-en:end -->

在[[奇异值分解]]中，这个名称也扩展用于 $m\ne n$ 的 $m\times n$ 矩阵。位置规则仍然一样：$i\ne j$ 的元素全部为零，只有 $(1,1),\ldots,(\min(m,n),\min(m,n))$ 可以非零。例如

$$\begin{pmatrix}2&0&0\\0&1&0\end{pmatrix}$$

<!-- bilingual-en:start -->
is a $2\times3$ rectangular diagonal matrix. Its input has three coordinates and its output has two. This extended convention must retain the dimensions; it does not make the matrix square. Singular value decomposition places further restrictions on its particular diagonal factor, such as nonnegative entries; those belong to that decomposition, not to the general zero-pattern definition.
<!-- bilingual-en:end -->

就是一个 $2\times3$ 的矩形对角矩阵。它的输入有三个坐标，输出有两个坐标。使用这个扩展约定时仍须保留尺寸，不能把它当成方阵。奇异值分解还会对它自己的对角因子加上非负等条件；这些条件属于该分解，不属于一般的零元素位置定义。
