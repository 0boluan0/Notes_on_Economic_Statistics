# Upper contour sets
<!-- bilingual-en:end -->

*上轮廓集*

<!-- bilingual-en:start -->
An **upper contour set** collects every allowed input that reaches a chosen minimum output. If a function measures a score, benefit or production level, fixing a threshold asks which choices meet that standard. It collects the choices themselves, including those that meet the standard exactly; it does not collect the scores.
<!-- bilingual-en:end -->

**上轮廓集**收集所有达到指定最低输出的允许输入。若函数表示分数、收益或产量，固定门槛就是问哪些选择能达标。集合里装的是这些选择，包括恰好达标的选择，而不是分数本身。

> [!example] Test the output before choosing a side · 先算输出，再判断在哪一侧
> <!-- bilingual-en:start -->
> For $f(u,v)=u+v$ on $\mathbb R^2$ and threshold $2$, $(1,1)$ belongs because its output is $2$; $(3,0)$ belongs because its output is $3$; $(0,0)$ does not belong. Even $(-1,4)$ belongs. A negative input coordinate does not prevent the output from reaching the threshold.
> <!-- bilingual-en:end -->
>
> 对 $\mathbb R^2$ 上的 $f(u,v)=u+v$，门槛取 $2$。$(1,1)$ 的输出为 $2$，属于集合；$(3,0)$ 的输出为 $3$，也属于；$(0,0)$ 不属于。甚至 $(-1,4)$ 也属于：输入坐标有负数，不妨碍输出达标。

## The weak threshold inequality
<!-- bilingual-en:end -->

*包含等号的门槛不等式*

<!-- bilingual-en:start -->
Let $f:U\to\mathbb R$, where $U\subseteq\mathbb R^n$ contains the allowed inputs and the positive integer $n$ counts their coordinates. Fix a real threshold $k$. The notation $C_k^+$ names a set; the superscript $+$ labels the direction of the output comparison and is not an arithmetic operation. No continuity, differentiability or convexity is assumed in this definition.
<!-- bilingual-en:end -->

设 $f:U\to\mathbb R$，其中 $U\subseteq\mathbb R^n$ 是允许输入的集合，正整数 $n$ 是坐标个数。固定实数门槛 $k$。$C_k^+$ 是集合的名称，上标 $+$ 标记输出比较的方向，不是算术运算。定义本身不要求连续、可微或凸性。

<!-- bilingual-en:start -->
The upper contour set is $C_k^+=\{x\in U:f(x)\ge k\}$, also called a superlevel set. Read the braces as “all allowed inputs satisfying the displayed inequality.” The equality case is included.
<!-- bilingual-en:end -->

对 $f:U\to\mathbb R$，门槛 $k$ 的上轮廓集是 $C_k^+=\{x\in U:f(x)\ge k\}$，也称 superlevel set。集合包含等号处；“上”比较输出，不是要求输入坐标非负。

<!-- bilingual-en:start -->
An input $x$ is a member of this set. A graph point is instead the pair $(x,f(x))$, which contains an extra output coordinate; [[水平集|level sets]] explain that distinction in detail. Replacing $\ge$ by $>$ produces the strict upper contour set, a different set whenever the function attains $k$.
<!-- bilingual-en:end -->

这个集合的成员是输入 $x$。函数图像上的点则是 $(x,f(x))$，多带一个输出坐标；[[水平集]]中详细区分了这两者。把 $\ge$ 改成 $>$ 得到严格上轮廓集；只要函数确实取到 $k$，两种集合就不同。

<!-- bilingual-en:start -->
## The domain determines the region
<!-- bilingual-en:end -->

*定义域决定达标区域*

<!-- bilingual-en:start -->
In the sum example the domain is the whole plane. For the product example below, “positive quadrant” specifically means $U=(0,\infty)^2$: both coordinates are strictly positive. We retain that restriction when solving the inequality.
<!-- bilingual-en:end -->

和函数例子的定义域取整个平面。下面乘积例子的“正象限”明确指 $U=(0,\infty)^2$，两个坐标都严格为正；解不等式时必须保留这个限制。

<!-- bilingual-en:start -->
An upper contour or superlevel set includes inputs at or above the threshold, including equality. “Upper” refers to output comparisons, not positive coordinates. The sum and product examples yield a half-plane and a region above a hyperbola. [[拟凹函数|Quasiconcavity]] requires convexity of all such sets.
<!-- bilingual-en:end -->

$f(x,y)=x+y$ 的 $C_2^+$ 是半平面 $x+y\ge2$。在正象限，$f=xy$ 的 $C_1^+$ 是 $y\ge1/x$。[[拟凹函数]]要求每个这样的集合凸，[[水平集]]则只保留等号处。

<!-- bilingual-en:start -->
For the product, $uv\ge1$ becomes $v\ge1/u$ because $u>0$; division therefore preserves the inequality direction. The inputs $(1,1)$ and $(2,1)$ qualify, while $(1/2,1)$ does not. At any threshold $k\le0$, every input in this positive domain qualifies, since $uv>0$. On the whole plane the threshold-one region would also include the negative-quadrant branch; division by a negative $u$ reverses the comparison. The domain is part of the answer.
<!-- bilingual-en:end -->

乘积例子中，因为 $u>0$，$uv\ge1$ 才能保持不等号方向化为 $v\ge1/u$。$(1,1)$ 和 $(2,1)$ 达标，$(1/2,1)$ 不达标。若门槛 $k\le0$，正象限里的每个输入都达标，因为 $uv>0$。换成整个平面，门槛 $1$ 的区域还包含负象限分支；除以负的 $u$ 时不等号要反向。定义域是答案的一部分。

<!-- bilingual-en:start -->
Nor does “upper” mean the visually upper part of a drawing. For $g(u,v)=-u-v$ and threshold $2$, the qualifying inequality is $u+v\le-2$. The correct side comes from the output test, not from the direction in which the page is held.
<!-- bilingual-en:end -->

“上”也不是图纸上方的意思。对 $g(u,v)=-u-v$，门槛取 $2$，达标条件变成 $u+v\le-2$。应选哪一侧由输出检验决定，而不是由纸面的上下方向决定。

<!-- bilingual-en:start -->
## Raising the threshold removes choices
<!-- bilingual-en:end -->

*提高门槛只会减少选择*

<!-- bilingual-en:start -->
If $k_1<k_2$, then $C_{k_2}^+\subseteq C_{k_1}^+$. Indeed, any member of the left set satisfies $f(x)\ge k_2>k_1$, so it belongs to the right set. The inclusion can be equality: if no output lies in the interval $[k_1,k_2)$, no choice is removed. For a constant function $f\equiv c$, the upper set is $U$ when $k\le c$ and is empty when $k>c$. If the domain is empty, every upper contour set is empty.
<!-- bilingual-en:end -->

若 $k_1<k_2$，则 $C_{k_2}^+\subseteq C_{k_1}^+$。因为左边的每个成员满足 $f(x)\ge k_2>k_1$，自然也属于右边。两集合可以相等：若没有输出落在区间 $[k_1,k_2)$ 中，就不会删去选择。常数函数 $f\equiv c$ 在 $k\le c$ 时给出整个 $U$，在 $k>c$ 时给出空集；定义域为空时，所有上轮廓集都为空。

<!-- bilingual-en:start -->
For a fixed function, domain and threshold, both this set and the [[下轮廓集|lower contour set]] include equality. They are therefore not generally complements: a point with $f(x)=k$ belongs to both. The complement of $C_k^+$ within $U$ uses the strict test $f(x)<k$.
<!-- bilingual-en:end -->

固定函数、定义域与门槛，本集合和[[下轮廓集]]都包含等号，因此一般不是互补的：满足 $f(x)=k$ 的点同时属于两者。$C_k^+$ 在 $U$ 内的补集应使用严格条件 $f(x)<k$。

<!-- bilingual-en:start -->
A [[凸集|convex set]] contains the whole segment between any two of its members. Having this property at every upper threshold, together with a convex domain, is the definition of [[拟凹函数|quasiconcavity]]. It is an additional property of the function, not part of what “upper contour set” means. For example, $f(u)=u^2$ on $\mathbb R$ has $C_1^+=(-\infty,-1]\cup[1,\infty)$: both $-1$ and $1$ qualify, but their midpoint $0$ does not.
<!-- bilingual-en:end -->

[[凸集]]要求集合中任意两点之间的整条线段仍在集合里。在凸定义域上，每个上轮廓集都具有这个性质，才是[[拟凹函数|拟凹性]]；它是函数的额外性质，不属于“上轮廓集”这个词的定义。例如 $\mathbb R$ 上的 $f(u)=u^2$ 给出 $C_1^+=(-\infty,-1]\cup[1,\infty)$；$-1$ 与 $1$ 都达标，但中点 $0$ 不达标。
