# Stochastic process
<!-- bilingual-en:end -->
*随机过程*

<!-- bilingual-en:start -->
A **stochastic process** is a model of uncertain values at several positions, usually several times, together with how those values vary jointly. Recording a queue length every minute produces a sequence of observations. Before observing it, the model must describe both what the queue might be at each minute and how the different minutes belong to the same unfolding experiment.
<!-- bilingual-en:end -->

**随机过程**描述多个位置上的不确定取值，以及这些取值怎样共同变化；这些位置通常是不同时刻。每分钟记录一次排队人数，会得到一串观测。在观测之前，模型既要描述每分钟可能有多少人，也要描述不同分钟的取值怎样属于同一次展开的实验。

<!-- bilingual-en:start -->
A [[随机变量|random variable]] assigns a value to each possible outcome of an experiment. For a process, write $X_t$ for the random variable at position $t$. The [[概率空间|probability space]] $(\Omega,\mathcal F,P)$ supplies the possible complete outcomes $\omega\in\Omega$, the events whose probabilities are defined, and their probabilities. **All the $X_t$ use this same space.** One outcome can encode an entire sequence of coin tosses or arrivals; it need not mean one elementary toss.
<!-- bilingual-en:end -->

[[随机变量]]给实验的每个可能结果赋予一个数值或状态。对于过程，写 $X_t$ 表示位置 $t$ 处的随机变量。[[概率空间]] $(\Omega,\mathcal F,P)$ 给出可能的完整结果 $\omega\in\Omega$、可以谈论概率的事件以及它们的概率。**所有 $X_t$ 共用这个空间。** 一个结果可以编码整串抛硬币或到达记录，不必只是一枚硬币的一次投掷。

> [!example] One random choice, three observations · 一次随机选择，三个观测
> <!-- bilingual-en:start -->
> Choose $\omega=-1$ or $1$, each with probability $1/2$, and define $X_t(\omega)=t+\omega$ for $t\in\{0,1,2\}$. If the choice is $-1$, the observed sequence is $(-1,0,1)$; if it is $1$, the sequence is $(1,2,3)$. These are the only two possibilities. At time $1$, for example, $X_1$ is $0$ or $2$, each with probability $1/2$.
> <!-- bilingual-en:end -->
>
> 以各 $1/2$ 的概率选择 $\omega=-1$ 或 $1$，然后对 $t\in\{0,1,2\}$ 定义 $X_t(\omega)=t+\omega$。若选到 $-1$，整串观测为 $(-1,0,1)$；若选到 $1$，则为 $(1,2,3)$，只有这两种可能。例如时点 $1$ 的随机变量 $X_1$，以各 $1/2$ 的概率取 $0$ 或 $2$。
>
> <!-- bilingual-en:start -->
> Choosing a fresh independent sign at each time would give eight possible sequences. It would keep the same one-time distributions but produce a different process model. Sharing one probability space does not forbid independence; it makes the joint relationship part of the model.
> <!-- bilingual-en:end -->
>
> 若改成每个时点重新独立选择一个符号，就会有八种可能的序列。各时点单独的分布没有变，过程模型却变了。共用一个概率空间并不排除独立，而是要求把联合关系纳入模型。

## Reading the notation
<!-- bilingual-en:end -->
*怎样读定义中的符号*

<!-- bilingual-en:start -->
Let $T$ be the **index set** and $S$ the **state space**, the collection of possible values. A process is the family
<!-- bilingual-en:end -->

令 $T$ 为**指标集**，$S$ 为**状态空间**，即可能取值的集合。过程就是这族随机变量：

$$X=(X_t)_{t\in T},\qquad X_t:\Omega\longrightarrow S.$$

<!-- bilingual-en:start -->
If $T=\{0,1,2,\ldots\}$, observations are indexed by discrete steps. If $T=[0,\infty)$, the model has a value at every nonnegative time. A spatial position can also be an index: time is common, not mandatory. The state space could be $\mathbb R$ for temperature or $\{0,1,2,\ldots\}$ for queue length.
<!-- bilingual-en:end -->

若 $T=\{0,1,2,\ldots\}$，观测按离散步数编号；若 $T=[0,\infty)$，模型在每个非负时刻都有取值。空间位置也可以充当指标：时间很常见，但并非必须。温度的状态空间可以是 $\mathbb R$，排队人数的状态空间则可以是 $\{0,1,2,\ldots\}$。

<!-- bilingual-en:start -->
For probabilities to be meaningful, each $X_t$ is measurable: for every allowed state event $A$, the outcome set $\{\omega:X_t(\omega)\in A\}$ must belong to $\mathcal F$. More formally, the state events form a [[σ-代数|sigma-algebra]] $\mathcal S$, and each $X_t:(\Omega,\mathcal F)\to(S,\mathcal S)$ is a measurable map. This requirement concerns each fixed index; path continuity or differentiability is an additional property, not part of the basic definition.
<!-- bilingual-en:end -->

要让概率有意义，每个 $X_t$ 都必须可测：对允许讨论的状态事件 $A$，结果集合 $\{\omega:X_t(\omega)\in A\}$ 必须属于 $\mathcal F$。更正式地，状态事件构成一个[[σ-代数]] $\mathcal S$，每个 $X_t:(\Omega,\mathcal F)\to(S,\mathcal S)$ 都是可测映射。这个要求针对每个固定指标；路径连续或可导是附加性质，不属于基本定义。

<!-- bilingual-en:start -->
There are two useful ways to inspect the same model. Fix $t$ and vary $\omega$: you see the random variable at that time. Fix $\omega$ and vary $t$: you see one [[样本路径|sample path]], the sequence or curve produced by that outcome. To describe probabilities involving several times together, use [[有限维分布|finite-dimensional distributions]]. Naming the separate [[边际分布|marginal distributions]] at each time leaves those joint probabilities unspecified, as the sign example shows.
<!-- bilingual-en:end -->

同一个模型有两种有用的读法。固定 $t$、改变 $\omega$，看到的是该时点的随机变量；固定 $\omega$、改变 $t$，看到的是一条[[样本路径]]，即该结果产生的序列或曲线。要描述几个时点共同发生的概率，需要[[有限维分布]]。仅指定每个时点的[[边际分布]]，仍没有指定这些联合概率，上面的符号例子正说明这一点。
