# 全正确性由部分正确性与终止性共同构成
<!-- bilingual-en:start -->
*Total correctness combines partial correctness with termination*
<!-- bilingual-en:end -->

> [!summary] 原子关系
> 部分正确性只保证“如果过程产生最终结果，那么该结果满足规格”；它允许过程永远运行。终止性保证过程一定到达最终状态。只有两者同时成立，才能得到“过程一定结束，而且结束时结果正确”的全正确性结论。
> <!-- bilingual-en:start -->
> Partial correctness guarantees only that if a process produces a final result, that result satisfies the specification; the process may still run forever. Termination guarantees that the process reaches a final state. Together they yield total correctness: the process finishes, and its result is correct.
> <!-- bilingual-en:end -->

快速幂程序可用不变量证明：若它在 $z=0$ 停止，则寄存器 $y=a^b$，这是部分正确性。还要另证某个度量随每步严格下降并最终迫使程序停止，才能断言它总会返回正确值。
<!-- bilingual-en:start -->
For fast exponentiation, an invariant can prove that if the program stops at $z=0$, then register $y=a^b$; this is partial correctness. A separate argument that a measure strictly decreases and forces termination is needed before concluding that the program always returns the correct value.
<!-- bilingual-en:end -->

## 边界
<!-- bilingual-en:start -->
*Boundary*
<!-- bilingual-en:end -->

- “若停止则正确”不是“必定停止”；循环不变式通常只承担前一项。
- 终止本身也不保证答案正确；一个程序可以很快停下并返回错误结果。
<!-- bilingual-en:start -->

**1.** “Correct if it terminates” does not mean “must terminate”; a loop invariant usually establishes only the former.<br>
**2.** Termination alone does not guarantee correctness; a program may halt quickly with a wrong result.<br>
<!-- bilingual-en:end -->

> [!question]- 回忆与应用
> 程序 $A$ 总会停止，但你没有证明输出满足规格；程序 $B$ 若停止则输出正确，但可能死循环。哪一个已经全正确？
>
> **答案：** 都没有。$A$ 缺部分正确性，$B$ 缺终止性；全正确性要求两个独立义务都完成。
> <!-- bilingual-en:start -->
> Program $A$ always terminates, but its output has not been proved to satisfy the specification. Program $B$ is correct whenever it terminates, but it may loop forever. Which is totally correct?
>
> **Answer:** Neither. $A$ lacks partial correctness and $B$ lacks termination; total correctness requires both obligations.
> <!-- bilingual-en:end -->
