# 语言模型输出头把隐藏状态映射为词表 logits，并归一化为 token 条件概率

<!-- bilingual-en:start -->
*A language-model output head maps hidden states to vocabulary logits and normalizes them into conditional token probabilities.*
<!-- bilingual-en:end -->

语言模型输出头是把网络隐藏表示转换为 token 预测分布的输出接口。本卡采用标准的线性词表头：先把每个位置的隐藏向量映射成词表中各 token 的 logits，再沿词表轴做 [[Softmax]]，得到该位置在已有条件下的 token 概率。这个定义具体描述线性投影加 softmax 的实现。

<!-- bilingual-en:start -->
A language-model output head is the output interface that converts network representations into token-prediction distributions. This note specifies the standard linear vocabulary head: it maps each position's hidden vector to a logit for every vocabulary token, then applies [[Softmax|softmax]] over the vocabulary axis to obtain conditional token probabilities. The implementation defined here is a linear projection followed by softmax.
<!-- bilingual-en:end -->

## 从表示宽度映到词表大小

<!-- bilingual-en:start -->
*From representation width to vocabulary size.*
<!-- bilingual-en:end -->

令 $H\in\mathbb R^{n\times d_{\mathrm{model}}}$ 为最终隐藏状态，$\mathcal V$ 为词表，$W_U\in\mathbb R^{d_{\mathrm{model}}\times|\mathcal V|}$ 为输出投影。采用不带偏置的写法：

<!-- bilingual-en:start -->
Let $H\in\mathbb R^{n\times d_{\mathrm{model}}}$ be the final hidden states, $\mathcal V$ the vocabulary, and $W_U\in\mathbb R^{d_{\mathrm{model}}\times|\mathcal V|}$ the output projection. In the bias-free form,
<!-- bilingual-en:end -->

$$
L=HW_U\in\mathbb R^{n\times|\mathcal V|},\qquad
p_i(v\mid C_i)=\frac{\exp(L_{iv})}{\sum_{u\in\mathcal V}\exp(L_{iu})}.
$$

$C_i$ 表示产生第 $i$ 行隐藏状态时已经可见的上下文。输出矩阵 $L$ 每行有 $|\mathcal V|$ 个分数，求和索引遍历词表；所有位置使用同一个 $W_U$。在原始 [[Transformer解码器]] 中，$C_i$ 含源端序列和允许读取的目标前缀；在 decoder-only next-token 模型中，条件来自历史 token，其正确实现见 [[Transformer自回归约束]]。

<!-- bilingual-en:start -->
The context $C_i$ is the information visible when hidden-state row $i$ is formed. Every row of $L$ contains $|\mathcal V|$ scores, the sum ranges over vocabulary tokens, and all positions use the same $W_U$. In the original [[Transformer解码器|Transformer decoder]], $C_i$ includes the source sequence and the permitted target prefix. For a decoder-only next-token model it comes from token history; [[Transformer自回归约束|Transformer autoregressive constraints]] describes the required implementation.
<!-- bilingual-en:end -->

## 三个候选 token 的例子

<!-- bilingual-en:start -->
*An example with three candidate tokens.*
<!-- bilingual-en:end -->

假设某位置只有三个词表候选，输出 logits 为 $[\log 2,0,0]$。指数化得到 $[2,1,1]$，所以输出分布为

<!-- bilingual-en:start -->
Suppose a toy vocabulary has three candidates and one position has logits $[\log 2,0,0]$. Exponentiation gives $[2,1,1]$, so the output distribution is
<!-- bilingual-en:end -->

$$
p_i=\left[\frac12,\frac14,\frac14\right].
$$

这一步结束时，模型已经为每个候选提供概率。若把这样的分布用于 decoder-only 预训练，[[自回归目标]] 再选择真实 next token 的概率形成负对数似然；从分布中如何选出实际生成的 token 是后续生成过程的工作。

<!-- bilingual-en:start -->
At this point the model has assigned a probability to each candidate. For decoder-only pretraining, the [[自回归目标|autoregressive objective]] selects the observed next token's probability to form its negative log-likelihood. Choosing an actual generated token from the distribution belongs to the subsequent generation procedure.
<!-- bilingual-en:end -->
