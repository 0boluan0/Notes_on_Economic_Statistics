# 渐近界必须用同一组常数控制所有足够大的输入
<!-- bilingual-en:start -->
*An asymptotic bound must use one set of constants for all sufficiently large inputs*
<!-- bilingual-en:end -->

证明 $f=O(g)$ 时，必须先选定与输入 $n$ 无关的 $C,N$，再证明每个 $n\ge N$ 都有 $f(n)\le Cg(n)$。**对每个 $n$ 各自找到一个 $C_n$ 不是渐近上界**；它把 [[大O记号]] 的量词顺序换掉了。
<!-- bilingual-en:start -->
To prove $f=O(g)$, choose $C,N$ independently of the input $n$, then prove $f(n)\le Cg(n)$ for every $n\ge N$. **Finding a separate $C_n$ for each input is not an asymptotic upper bound**: it changes the quantifier order in [[大O记号|big O notation]].
<!-- bilingual-en:end -->

$$
\underbrace{\exists C>0\;\exists N\;\forall n\ge N}_{\text{one common bound}}
\qquad\ne\qquad
\underbrace{\forall n\;\exists C_n>0}_{\text{a different bound per input}}.
$$

错误归纳“$2^n=O(1)$”：从 $2^n\le C$ 推到 $2^{n+1}\le2C$，每走一步都把常数加倍，不能给整个无穷尾段一个固定上界。事实上，对任何固定 $C$，总能选 $n>\log_2C$ 使 $2^n>C$。
<!-- bilingual-en:start -->
In the false induction “$2^n=O(1)$”, moving from $2^n\le C$ to $2^{n+1}\le2C$ doubles the constant at every step. This never produces a fixed bound for the entire infinite tail. For every fixed $C$, choosing $n>\log_2C$ gives $2^n>C$.
<!-- bilingual-en:end -->

同一问题出现在增长项数的求和中。对每个固定的 $i$，常数函数 $i$ 是 $O(1)$；但隐藏常数依赖 $i$，不能直接把 $\sum_{i=1}^n i$ 写成 $n\,O(1)=O(n)$。实际总和是 $n(n+1)/2=\Theta(n^2)$。若能证明所有 $1\le i\le n$ 的项都被同一个常数 $C$ 控制，就可由逐项相加推出总和不超过 $Cn$；这是充分方法，不是总和为 $O(n)$ 的必要条件。
<!-- bilingual-en:start -->
The same issue occurs when summing a growing number of terms. For each fixed $i$, the constant function $i$ is $O(1)$, but the hidden constant depends on $i$. Therefore one cannot conclude $\sum_{i=1}^n i=n\,O(1)=O(n)$. The actual sum is $n(n+1)/2=\Theta(n^2)$. One common constant $C$ controlling every term with $1\le i\le n$ suffices to give a bound of $Cn$ by summation; this is not a necessary condition for an $O(n)$ total.
<!-- bilingual-en:end -->

常数可以依赖题目已经固定的参数，例如固定多项式的系数与次数；若这些参数也随输入增长，就必须重新说明界是否对它们一致。
<!-- bilingual-en:start -->
Constants may depend on parameters already fixed in the problem, such as the coefficients and degree of a fixed polynomial. If those parameters also grow with the input, their uniformity must be stated and proved separately.
<!-- bilingual-en:end -->
