# 满足加总相干性不能保证预测在任何层级上准确
<!-- bilingual-en:start -->
*Satisfying aggregation coherence does not guarantee forecast accuracy at any level*
<!-- bilingual-en:end -->

> [!summary] 原子边界
> 相干性只回答“这些数字能否同时满足既定加总等式”；准确性回答“它们离未来实现有多远”。把任意底层预测通过 $S$ 上卷都能得到相干向量，即使每个底层预测都含有同方向的大偏差。协调不能从没有信号的 base forecasts 中创造信息。
> <!-- bilingual-en:start -->
> Coherence asks whether forecasts jointly satisfy the aggregation equations; accuracy asks how close they are to future outcomes. Any bottom-level vector can be aggregated into a coherent forecast even when every component is badly biased. Reconciliation cannot create signal absent from the base forecasts.
> <!-- bilingual-en:end -->

反过来，一组不相干的 base forecasts 中可能有某个节点在某一次实现上恰好完全准确，协调仍会移动它。以真实正定 $W_h$ 做 oracle [[MinT协调|MinT]] 时，这不否定 $V_h\preceq W_h$：每个节点的总体误差方差不升，但某一次误差可以变坏。实际系统还会估计或近似 $W_h$，也可能存在偏差、额外约束和不同损失；这些条件下更不能把相干性本身当成准确性保证。
<!-- bilingual-en:start -->
Conversely, one node of an incoherent base vector may happen to be exactly right on a particular realisation and still move during reconciliation. Oracle MinT with the true positive-definite $W_h$ nevertheless gives $V_h\preceq W_h$, so every node's population error variance is no larger even though a realised error may worsen. Estimated or approximate covariance, bias, additional constraints, and other losses make empirical validation still more essential.
<!-- bilingual-en:end -->

验收仍应按业务需要的层级与 horizon 报告 base 和 reconciled forecasts 的同一外样本损失，并检查偏差、区间或分布校准。oracle 结论是条件总体量，不是当前有限样本实现的成绩单；若估计后的 pipeline 在外样本上总量改善而关键地区恶化，应如实呈现，并检查是估计误差、偏差、损失错位还是额外约束造成的。
<!-- bilingual-en:start -->
Acceptance still compares base and reconciled forecasts on the same out-of-sample cases by decision-relevant level and horizon, including bias and distributional calibration where applicable. An oracle population result is not a scorecard for one estimated finite-sample pipeline. If aggregate gains coincide with deterioration at a critical lower level, report it and diagnose covariance estimation, bias, loss mismatch, or added constraints.
<!-- bilingual-en:end -->

> [!question]- 自检
> 一套预测在公司、地区、产品各层都精确相加。还能有什么问题？
>
> **答案：** 所有节点仍可能共同高估；某次实现中本来准确的节点也可能被移动；估计型协调还可能在外样本上恶化某层级。必须用未来实现逐层、逐 horizon 评价。只有满足无偏、真实正定 $W_h$ 等 oracle 条件时，才有逐节点总体方差不升的保证。

## 来源与核验

- [Hyndman & Athanasopoulos, FPP3 §11.3](https://otexts.com/fpp3/reconciliation.html)：核对 coherence 与协调目标，以及各层级包含不同可预测信息的理由。
- Wickramasuriya, Athanasopoulos & Hyndman（2019），[MinT 论文](https://robjhyndman.com/papers/mint.pdf)：核对 oracle MinT 的逐节点总体方差保证，以及该保证不同于单次实现和估计型 pipeline 的表现。
