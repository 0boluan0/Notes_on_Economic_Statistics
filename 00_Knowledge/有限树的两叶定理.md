# 每棵至少两个顶点的有限 tree 都有两个 degree-1 leaves
<!-- bilingual-en:start -->
*Every finite tree with at least two vertices has two degree-one leaves*
<!-- bilingual-en:end -->

> [!summary] 原子定理
> 若有限 tree $T$ 至少有两个顶点，则它至少有两个 degree-$1$ 顶点。这一命题不依赖 leaf 是否把 isolated vertex 算进去：在非平凡 tree 中，degree 不超过 $1$ 的顶点本来就只能是 degree $1$。
> <!-- bilingual-en:start -->
> Every finite tree with at least two vertices has at least two vertices of degree one. This claim is independent of whether a convention counts isolated vertices as leaves: in a nontrivial tree, a vertex of degree at most one must in fact have degree one.
> <!-- bilingual-en:end -->

取一条最长 simple path $v_0,\ldots,v_k$。端点 $v_0$ 至少邻接 $v_1$。若它还有邻点 $w\ne v_1$，则 $w$ 若不在 path 上会把 path 延长；若在 path 上，则边 $v_0w$ 与 path 的一段组成 cycle。两者都矛盾，所以 $\deg(v_0)=1$；另一端同理。
<!-- bilingual-en:start -->
Choose a longest simple path $v_0,\ldots,v_k$. Endpoint $v_0$ is adjacent to $v_1$. Any additional neighbor outside the path would extend it, while an additional neighbor on the path would create a cycle. Hence $\deg(v_0)=1$, and the same argument applies to the other endpoint.
<!-- bilingual-en:end -->

有限性和顶点数边界都不能省。单点 tree 的唯一顶点 degree 为 $0$：MIT 6.042J 的 2015 Session 21 reading 把 leaf 定义为 degree $1$，所以它不算 leaf；2018 主教材把 forest 中 degree 至多 $1$ 的顶点都称为 leaf，所以它算一片 leaf。无论采用哪种约定，单点 tree 都不能满足“至少两个 degree-$1$ 顶点”。双向无限 path 则是 connected acyclic graph，但每个顶点 degree 都是 $2$。
<!-- bilingual-en:start -->
Neither finiteness nor the size boundary may be omitted. The sole vertex of a one-vertex tree has degree zero. MIT 6.042J's 2015 Session 21 reading defines a leaf to have degree one, so it is not a leaf there; the 2018 textbook calls every forest vertex of degree at most one a leaf, so it is one leaf there. Under either convention, the singleton does not have two degree-one vertices. A bi-infinite path is connected and acyclic but every vertex has degree two.
<!-- bilingual-en:end -->

> [!question]- 自检
> 为什么最长 path 的端点不能再连接到 path 中一个非相邻顶点？
>
> **答案：**该新边与端点到该顶点之间的 path 段会组成 cycle，违反 tree 的 acyclic 条件。
