# After a column permutation AQ the original solution coordinates are x equals Qz
<!-- bilingual-en:end -->
*列置换为 AQ 后必须用 x 等于 Qz 恢复原解坐标*

<!-- bilingual-en:start -->
Let $A\in\mathbb R^{m\times n}$ and let $Q$ be an $n\times n$ [[置换矩阵|permutation matrix]]. A solution $z$ of the reordered system $(AQ)z=b$ corresponds to an original solution $x=Qz$:
<!-- bilingual-en:end -->

设 $A\in\mathbb R^{m\times n}$，$Q$ 为 $n\times n$ [[置换矩阵]]。重排后的方程 $(AQ)z=b$ 的解 $z$，对应原方程的解 $x=Qz$：

$$
(AQ)z=b\iff A(Qz)=b,\qquad z=Q^{-1}x.
$$

<!-- bilingual-en:start -->
This follows from associativity and the invertibility of $Q$. For a homogeneous system, if $\widetilde N$ is a [[零空间矩阵|nullspace matrix]] for $AQ$, then $Q\widetilde N$ is one for $A$. The entries must be returned to their original variable labels.
<!-- bilingual-en:end -->

这来自乘法结合律与 $Q$ 的可逆性。对齐次系统，若 $\widetilde N$ 是 $AQ$ 的[[零空间矩阵]]，则 $Q\widetilde N$ 是 $A$ 的零空间矩阵；分量必须回到原来的变量标签下。

<!-- bilingual-en:start -->
For example, swapping columns 2 and 3 changes the coordinate order to $z=(x_1,x_3,x_2,x_4)^T$. A vector $z=(-2,0,1,0)^T$ therefore corresponds to $x=(-2,1,0,0)^T$. Restoring this order swaps rows 2 and 3 of a matrix whose columns are solution vectors.
<!-- bilingual-en:end -->

例如交换第 2、3 列后，坐标顺序为 $z=(x_1,x_3,x_2,x_4)^T$。若 $z=(-2,0,1,0)^T$，原坐标便是 $x=(-2,1,0,0)^T$。对把多个解并排组成的矩阵，恢复该顺序意味着交换第 2、3 行。
