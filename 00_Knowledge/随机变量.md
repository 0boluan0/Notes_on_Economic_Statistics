# 随机变量是把每个样本结果映射成数值的可测函数
<!-- bilingual-en:start -->
*A random variable is a measurable function that maps sample outcomes to numbers*
<!-- bilingual-en:end -->

> [!summary] 它是什么
> 在概率空间 $(\Omega,\mathcal F,P)$ 上，实随机变量是可测函数
> $$X:(\Omega,\mathcal F)\to(\mathbb R,\mathcal B(\mathbb R)).$$
> 它给每个结果 $\omega$ 指定一个数 $X(\omega)$。映射本身是确定的；不确定的是哪一个 $\omega$ 会发生。
> <!-- bilingual-en:start -->
> A real random variable is a measurable function from $(\Omega,\mathcal F)$ to $(\mathbb R,\mathcal B(\mathbb R))$. The map is deterministic; uncertainty concerns which outcome occurs.
> <!-- bilingual-en:end -->

“可测”保证每个数值问题都能拉回原样本空间成为事件。对任意 Borel 集 $A\subseteq\mathbb R$，
$$
\{X\in A\}=\{\omega:X(\omega)\in A\}\in\mathcal F,
$$
所以 $P(X\in A)$ 才有定义。在有限或可数样本空间且 $\mathcal F=2^\Omega$ 时，每个数值函数都自动可测；一般空间不能省略这项条件。

<!-- bilingual-en:start -->
Measurability makes every numerical question an event in the original sample space. For each Borel set $A$, the preimage $\{\omega:X(\omega)\in A\}$ must belong to $\mathcal F$, so its probability is defined. On a finite or countable full-power-set space this is automatic; in general it is not.
<!-- bilingual-en:end -->

一次试验可产生多个随机变量。掷两枚骰子的结果 $(i,j)$ 可以映射成和 $i+j$、最大值 $\max(i,j)$ 或某个收益。它们共享 outcome，却回答不同的数值问题。

> [!question]- 自检
> 为什么“随机变量”这个名字容易误导？
>
> **答案：** 因为 $X$ 是确定函数；随机的是输入 outcome，进而使观察到的 $X(\omega)$ 不确定。
