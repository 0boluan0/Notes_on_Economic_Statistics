# 原函数公式不能跨越奇点而不先拆分积分区间
<!-- bilingual-en:start -->
*An antiderivative formula cannot be applied across a singularity without first splitting the integration interval*
<!-- bilingual-en:end -->

> [!summary] 原子诊断
> 微积分基本定理的端点公式要求原函数适用于整个普通区间；若被积函数在内部点无定义或无界，就不能跨过该点直接写 $F(b)-F(a)$。先找出所有奇点、拆成单侧截断积分，再在每一段合法区间上使用原函数。
> <!-- bilingual-en:start -->
>
> &nbsp;
> The Fundamental Theorem of Calculus applies an antiderivative on a proper interval. If the integrand is undefined or unbounded at an interior point, one cannot jump across that point and write $F(b)-F(a)$. Locate every singularity, split into one-sided truncated integrals, and use the antiderivative only on each valid interval.
> <!-- bilingual-en:end -->

经典错误是
$$\int_{-1}^{1}\frac{dx}{x^2}
\overset{\text{错误}}=
\left[-\frac1x\right]_{-1}^{1}=-2.$$
被积函数在定义域内非负，所谓“面积”却算成负数，已经发出结构性警报。真正的问题是 $0$ 把区间切断；两侧分别像 $\int_0^1x^{-2}dx$ 一样发散，所以总积分发散。
<!-- bilingual-en:start -->
The classic error is $\int_{-1}^{1}x^{-2}dx\overset{\text{wrong}}=[-1/x]_{-1}^{1}=-2$. The integrand is nonnegative on its domain, yet the alleged area is negative—a structural warning. The point zero breaks the interval. Each side diverges like $\int_0^1x^{-2}dx$, so the whole improper integral diverges.
<!-- bilingual-en:end -->

## 一套先于计算的检查

1. 求 integrand 的定义域，标出端点和内部所有奇点。
2. 在每个坏点拆区间，给每段写自己的单侧极限参数。
3. 只在不跨坏点的有限区间上套原函数。
4. 每段都得到有限极限后，才把这些有限数相加。

符号检查也很有用：非负 integrand 不可能给出负的普通积分。但符号矛盾只能提醒错误，不能替代上述定义检查。
<!-- bilingual-en:start -->
1. Find the integrand's domain and mark every endpoint and interior singularity.
2. Split at each problematic point and give every component its own one-sided limit parameter.
3. Apply an antiderivative only on finite intervals that do not cross a problematic point.
4. Add the components only after every one has a finite limit.

A sign check is useful: a nonnegative integrand cannot have a negative ordinary integral. The contradiction flags an error but does not replace the definition check.
<!-- bilingual-en:end -->

> [!question]- 自检
> 一个原函数公式在奇点左右都分别成立，为什么仍不能直接跨奇点相减端点值？
>
> **答案：** 左右属于不同的合法区间；基本定理没有跨过函数失效点的前提。必须先验证两个单侧截断极限。
