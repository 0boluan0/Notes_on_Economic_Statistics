# Level sets
<!-- bilingual-en:end -->

*水平集*

<!-- bilingual-en:start -->
A **level set** answers a precise question: which allowed inputs give exactly one chosen output? Imagine a height function on a map. Fix a height, then collect all ground locations having that height. Those locations form a set in the input space. The height is the test used to select them; it is not itself a member of the set.
<!-- bilingual-en:end -->

**水平集**回答一个明确问题：哪些允许的输入恰好给出某个指定输出？可以想象地图上的高度函数：先固定一个高度，再收集所有达到该高度的地面位置。这些位置组成输入空间中的集合；高度是筛选条件，不是集合里的元素。

> [!example] One output, several inputs · 一个输出，多个输入
> <!-- bilingual-en:start -->
> For $f(u,v)=u+v$ on the whole plane, the inputs $(-1,3)$, $(0,2)$ and $(1,1)$ all give output $2$. The input $(1,2)$ gives $3$, so it is excluded from the level set at $2$. Solving $u+v=2$ gives every member: $(u,2-u)$ for any real $u$.
> <!-- bilingual-en:end -->
>
> 在整个平面上取 $f(u,v)=u+v$。输入 $(-1,3)$、$(0,2)$、$(1,1)$ 的输出都为 $2$；$(1,2)$ 的输出为 $3$，所以不属于水平 $2$ 的集合。解方程 $u+v=2$，全部成员就是任意实数 $u$ 对应的 $(u,2-u)$。

<!-- bilingual-en:start -->
## Fix the function, domain and output
<!-- bilingual-en:end -->

*先固定函数、定义域与输出*

<!-- bilingual-en:start -->
Write $f:U\to\mathbb R$: $U\subseteq\mathbb R^n$ is the domain, the set of allowed inputs, and $f$ assigns one real output to each input. Here $n$ is a positive integer counting input coordinates. Fix a real number $k$, called the level. The notation $\{x\in U:f(x)=k\}$ means “all inputs $x$ in $U$ satisfying this equality”; $x$ can be a vector. We denote this set by $C_k$.
<!-- bilingual-en:end -->

记 $f:U\to\mathbb R$：定义域 $U\subseteq\mathbb R^n$ 是允许输入的集合，$f$ 给每个输入分配一个实数输出。正整数 $n$ 是输入坐标的个数。固定实数 $k$，称为水平。记号 $\{x\in U:f(x)=k\}$ 表示“所有属于 $U$ 且满足这个等式的输入 $x$”；$x$ 可以是向量。用 $C_k$ 表示这个集合。

<!-- bilingual-en:start -->
For $f:U\to\mathbb R$, the level set is $C_k=\{x\in U:f(x)=k\}$. It contains inputs, whereas the function graph consists of input-output pairs $\{(x,f(x)):x\in U\}$.
<!-- bilingual-en:end -->

对 $f:U\to\mathbb R$，水平集为 $C_k=\{x\in U:f(x)=k\}$。这是输入空间中的集合，不是函数图像 $\{(x,f(x))\}$。

<!-- bilingual-en:start -->
For the sum example, $(1,1)$ is a member of $C_2\subseteq\mathbb R^2$; $(1,1,2)$ is the corresponding point on the graph in $\mathbb R^3$. Cutting the graph at output height $2$ gives graph points $(u,2-u,2)$. Dropping their last coordinate produces the level set. This explains why a contour drawn on a two-dimensional map and a curve drawn on a three-dimensional surface represent related but different objects.
<!-- bilingual-en:end -->

在和函数的例子中，$(1,1)$ 是 $C_2\subseteq\mathbb R^2$ 的成员，而 $(1,1,2)$ 是三维图像上对应的点。用输出高度 $2$ 切图像，得到 $(u,2-u,2)$；去掉最后一个坐标才得到水平集。因此二维地图上的等高线与三维曲面上的截线相互对应，但属于不同的空间。

<!-- bilingual-en:start -->
The domain remains part of the definition. If the same formula is restricted to $U=\{(u,v):u\ge0,\ v\ge0\}$, the level set at $2$ is only the segment from $(0,2)$ to $(2,0)$, not the whole line. No continuity, derivative or [[凸集|convexity]] assumption is needed to form a level set; convexity would be an additional requirement about segments between inputs.
<!-- bilingual-en:end -->

定义域始终是定义的一部分。若将同一个公式限制在 $U=\{(u,v):u\ge0,\ v\ge0\}$，水平 $2$ 的集合就只有 $(0,2)$ 与 $(2,0)$ 之间的线段，而非整条直线。形成水平集不要求连续、可导或[[凸集|凸性]]；凸性是关于输入之间线段的另一项要求。

## A level need not trace a curve
<!-- bilingual-en:end -->

*水平集不一定是一条曲线*

<!-- bilingual-en:start -->
In the following two-variable examples first take the domain to be the whole plane. They show several possible shapes without changing the definition.
<!-- bilingual-en:end -->

下面的二维例子先取整个平面为定义域；同一个定义能够产生不同形状。

<!-- bilingual-en:start -->
A level set collects inputs with exactly the specified output. It is distinct from the function graph. The examples give a line, a point, an empty set, or a whole domain, so a level set need not be a smooth curve or precisely the boundary of an [[上轮廓集|upper contour set]].
<!-- bilingual-en:end -->

$f(x,y)=x+y$ 的 $C_2$ 是直线 $x+y=2$；$f(x,y)=x^2+y^2$ 的 $C_0$ 是一点，负水平为空；常数函数相应水平可为整个域。水平集未必是光滑曲线，也未必只等于[[上轮廓集]]的边界。

<!-- bilingual-en:start -->
For $q(u,v)=u^2+v^2$, the equation $q=0$ forces both squares to be zero, so $C_0=\{(0,0)\}$. A negative level has no solution because a sum of squares is nonnegative; its level set is $\varnothing$, the empty set. A positive level $k$ gives a circle of radius $\sqrt{k}$. If instead $f$ is constant with value $5$ on a domain $U$, then $C_5=U$ and $C_k=\varnothing$ for every $k\ne5$. When $U=\varnothing$, every level set is empty.
<!-- bilingual-en:end -->

对 $q(u,v)=u^2+v^2$，等式 $q=0$ 强制两个平方都为零，因此 $C_0=\{(0,0)\}$。平方和非负，负水平没有解，对应水平集就是空集 $\varnothing$。正水平 $k$ 给出半径 $\sqrt{k}$ 的圆周。若 $f$ 在定义域 $U$ 上恒为 $5$，则 $C_5=U$，而所有 $k\ne5$ 都给出空集；若 $U=\varnothing$，每个水平集都是空集。

> [!warning] Equality is not a boundary test · 等号不是边界判据
> <!-- bilingual-en:start -->
> The [[集合边界|boundary]] of a set consists of positions whose every neighbourhood meets both the set and its complement. If $f\equiv5$ on $\mathbb R^2$, its level set at $5$ is the whole plane. Its upper contour set at $5$ is also the whole plane, whose boundary in $\mathbb R^2$ is empty: there is no point outside it for a neighbourhood to meet. Thus an equation $f(x)=k$ does not automatically describe the boundary of the corresponding threshold region.
> <!-- bilingual-en:end -->
>
> [[集合边界|边界]]收集每个邻域都同时碰到集合及其补集的位置。若 $f$ 在 $\mathbb R^2$ 上恒为 $5$，水平 $5$ 的水平集是整个平面，上轮廓集也是整个平面；但整个平面在 $\mathbb R^2$ 中的边界为空，因为没有外部点可供邻域接触。因此方程 $f(x)=k$ 并不自动给出对应门槛区域的边界。

<!-- bilingual-en:start -->
The [[上轮廓集|upper contour set]] keeps outputs at least $k$; the [[下轮廓集|lower contour set]] keeps outputs at most $k$. For the same function, domain and threshold, their intersection is exactly $C_k$: being both at least and at most $k$ means equality. The two inequalities therefore include every level-set input.
<!-- bilingual-en:end -->

[[上轮廓集]]保留输出至少为 $k$ 的输入，[[下轮廓集]]保留输出至多为 $k$ 的输入。固定同一个函数、定义域与门槛，两者的交集恰好是 $C_k$：同时不小于又不大于 $k$ 就是等于 $k$，所以两个不等式集合都包含水平集。
