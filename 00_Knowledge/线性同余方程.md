# 线性同余方程是在指定模数下约束未知整数的一次同余关系
<!-- bilingual-en:start -->
*A linear congruence is a first-degree congruence relation constraining an unknown integer modulo a specified modulus*
<!-- bilingual-en:end -->

**线性同余方程**是形如 $ax\equiv b\pmod n$ 的方程，其中整数 $a,b$ 和整数模数 $n>1$ 已给定，整数 $x$ 未知。它要求 $n\mid(ax-b)$，也就是寻找乘以 $a$ 后与 $b$ 有相同模 $n$ 余数的整数；这里也允许 $a=0$ 的退化形式。
<!-- bilingual-en:start -->
A **linear congruence** is an equation of the form $ax\equiv b\pmod n$, where integers $a,b$ and an integer modulus $n>1$ are given, and the integer $x$ is unknown. It requires $n\mid(ax-b)$: multiplying $x$ by $a$ must give the same remainder modulo $n$ as $b$. The degenerate form with $a=0$ is also allowed here.
<!-- bilingual-en:end -->

一个**整数解**是代入后使同余成立的具体整数。一个**模 $n$ 解类**则把相差 $n$ 的整数倍的解视为同一类：若 $x$ 是解，则 $a(x+kn)-b=(ax-b)+akn$，所以 $x+kn$ 对任何 $k\in\mathbb Z$ 也是解。说“一个解类”不等于“只有一个整数解”。
<!-- bilingual-en:start -->
An **integer solution** is a particular integer that makes the congruence true when substituted. A **solution class modulo $n$** groups solutions differing by an integer multiple of $n$: if $x$ is a solution, then $a(x+kn)-b=(ax-b)+akn$, so $x+kn$ is also a solution for every $k\in\mathbb Z$. One solution class does not mean a single integer solution.
<!-- bilingual-en:end -->

例如在 $3x\equiv1\pmod7$ 中，$a=3,b=1,n=7$ 已知。代入 $x=5$ 得 $3\cdot5-1=14$，被 7 整除，因此 5 是整数解；12 与 5 属于同一个模 7 解类。判定是否有解、求出全部解类的方法见 [[线性同余求解]]。
<!-- bilingual-en:start -->
For example, in $3x\equiv1\pmod7$, the given data are $a=3,b=1,n=7$. Substituting $x=5$ gives $3\cdot5-1=14$, which is divisible by seven, so five is an integer solution. Twelve and five belong to the same solution class modulo seven. See [[线性同余求解|solving a linear congruence]] for solvability and the complete set of solution classes.
<!-- bilingual-en:end -->
