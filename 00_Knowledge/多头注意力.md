# 多头注意力是在多个可学习投影子空间并行读取后拼接并投影的注意力层

<!-- bilingual-en:start -->
*Multi-head attention performs parallel reads in learned projection subspaces, then concatenates and projects their outputs*
<!-- bilingual-en:end -->

多头注意力使用多组可学习的 Q/K/V 投影，在各自子空间中并行执行注意力读取，再沿通道拼接每个头的输出并做一次线性投影。一个 head 对应一套投影与一次读取；同一来源因此可以形成多种表示下的匹配与汇总。

<!-- bilingual-en:start -->
Multi-head attention uses several learned Q/K/V projection sets to perform parallel attention reads in their respective subspaces. It concatenates the head outputs along the channel dimension and applies a final linear projection. Each head consists of a projection set and an attention read, allowing a shared source to be matched and aggregated through different representations.
<!-- bilingual-en:end -->

## 每个头怎样计算与合并

<!-- bilingual-en:start -->
*Computing and combining heads*
<!-- bilingual-en:end -->

为了区分投影前来源与投影后的 Q/K/V，记来源为 $H_Q,H_K,H_V$。$H_Q$ 有 $n_q$ 行查询位置，$H_K,H_V$ 的 $n_k$ 行按相同顺序对应候选位置；这里沿用原始 Transformer 的共同输入宽度 $d_{\mathrm{model}}$，每个头的 key/value 宽度分别为 $d_k,d_v$。对第 $r$ 个头：

<!-- bilingual-en:start -->
To distinguish source representations from projected Q/K/V, denote the sources by $H_Q,H_K,H_V$. $H_Q$ has $n_q$ query rows; the $n_k$ rows of $H_K,H_V$ correspond to the same candidates in the same order. This formulation follows the original Transformer's shared input width $d_{\mathrm{model}}$, with per-head key and value widths $d_k,d_v$. Head $r$ is computed as follows:
<!-- bilingual-en:end -->

$$
\mathrm{head}_r=
\operatorname{Attention}(H_QW_r^Q,H_KW_r^K,H_VW_r^V),
\qquad r=1,\ldots,h,
$$

$$
W_r^Q,W_r^K\in\mathbb R^{d_{\mathrm{model}}\times d_k},
\qquad W_r^V\in\mathbb R^{d_{\mathrm{model}}\times d_v}.
$$

这里的 Attention 是[[缩放点积注意力]]。每个头形成自己的 $n_q\times n_k$ 权重矩阵，并分别沿 key 轴归一化；输出都是 $n_q\times d_v$。然后

<!-- bilingual-en:start -->
Here Attention means [[缩放点积注意力|scaled dot-product attention]]. Each head forms its own $n_q\times n_k$ weight matrix and normalizes separately along the key axis, producing an $n_q\times d_v$ output. The outputs are then combined:
<!-- bilingual-en:end -->

$$
O=\operatorname{Concat}(\mathrm{head}_1,\ldots,\mathrm{head}_h)W^O,
\qquad
W^O\in\mathbb R^{h d_v\times d_{\mathrm{model}}},
\qquad
O\in\mathbb R^{n_q\times d_{\mathrm{model}}}.
$$

拼接保留每个头输出的通道，$W^O$ 再学习如何混合这些通道。这个操作并不是把各头的 attention 权重矩阵先求平均。

<!-- bilingual-en:start -->
Concatenation retains each head's output channels, and $W^O$ learns how to mix them. The operation does not first average the heads' attention-weight matrices.
<!-- bilingual-en:end -->

## 两个头的形状例子

<!-- bilingual-en:start -->
*A two-head shape example*
<!-- bilingual-en:end -->

设 $d_{\mathrm{model}}=4$、$h=2$、$d_k=d_v=2$。每个头将来源投影到 2 维，每次读取输出 $n_q\times2$；两个结果拼接成 $n_q\times4$，再乘 $4\times4$ 的 $W^O$，输出仍为 $n_q\times4$。若某个 query 的两个头分别读出 $(1,2)$ 与 $(3,4)$，拼接行是 $(1,2,3,4)$；只有在这个小例另取 $W^O=I_4$ 时，最终行才恰好保持这些数值。

<!-- bilingual-en:start -->
Let $d_{\mathrm{model}}=4$, $h=2$, and $d_k=d_v=2$. Each head projects its sources to width two and produces an $n_q\times2$ readout. Concatenation gives $n_q\times4$, and multiplication by a $4\times4$ matrix $W^O$ keeps the output shape $n_q\times4$. If one query's heads return $(1,2)$ and $(3,4)$, their concatenation is $(1,2,3,4)$. The final row preserves those values only if this example additionally takes $W^O=I_4$.
<!-- bilingual-en:end -->

原论文采用 $d_k=d_v=d_{\mathrm{model}}/h$，让增加头数时单头宽度相应缩小；多头的一般定义并不要求这个比例。不同投影允许各头学习不同读取方式，但不能仅据结构断言每个头必有一种固定语言职能或必然互不冗余。

<!-- bilingual-en:start -->
The original paper uses $d_k=d_v=d_{\mathrm{model}}/h$, reducing per-head width as the head count increases. The general definition of multi-head attention does not require this ratio. Different projections allow different reads, without guaranteeing a fixed linguistic role for every head or an absence of redundancy.
<!-- bilingual-en:end -->

## 多头与表示来源的关系

<!-- bilingual-en:start -->
*Heads and representation sources*
<!-- bilingual-en:end -->

在[[自注意力]]中，可取 $H_Q=H_K=H_V=X$；在[[交叉注意力]]中，query 来源与 key/value 来源分开。两种来源组织都能使用多头，因此“多头”回答如何并行组合读取，“self/cross”回答从哪里读取。

<!-- bilingual-en:start -->
For [[自注意力|self-attention]], one can take $H_Q=H_K=H_V=X$. For [[交叉注意力|cross-attention]], the query source differs from the key/value source. Both source arrangements can use multiple heads: head structure specifies how reads are combined in parallel, while self/cross specifies their sources.
<!-- bilingual-en:end -->
