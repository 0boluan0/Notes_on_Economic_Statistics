# export将变量标记给后续子命令但不回写父进程或永久保存
<!-- bilingual-en:start -->
*Export marks variables for subsequent child commands; it neither updates a parent process nor saves configuration permanently.*
<!-- bilingual-en:end -->

在 Bash 中，`export name` 给变量加上导出属性；随后启动的外部命令收到它当时的值。普通赋值不自动导出一个原本未导出的新变量；但已经导出的变量再赋值，后续子命令会收到新值。`export -n name` 去掉导出属性，并不删除 shell 中的变量。
<!-- bilingual-en:start -->
In Bash, `export name` marks a variable for export, and subsequently launched external commands receive its value at that time. Assigning a previously unexported new variable does not automatically export it; reassignment of an already exported variable updates what later children receive. `export -n name` removes the export attribute without deleting the shell variable.
<!-- bilingual-en:end -->

```bash
lesson_value=alpha
export lesson_value
bash -c 'printf "%s\n" "$lesson_value"'
```

这个子 Bash 输出 `alpha`。它即使把自己的 `lesson_value` 改成 `beta`，也不会回写父 shell。要让新的独立 shell 自动获得配置，应明确[[Bash启动文件选择]]；`export` 本身不保存到磁盘。
<!-- bilingual-en:start -->
The child Bash prints `alpha`. Changing its own `lesson_value` to `beta` would not update the parent. Configuration for a future independent shell requires deliberate [[Bash启动文件选择|startup-file selection]]; `export` itself writes no persistent configuration.
<!-- bilingual-en:end -->

对外部命令可用 `lesson_value=beta command` 只设置该次调用的环境。不要把这一简便规则不加条件地推广到 shell 函数、特殊内建命令或所有 shell 模式。
<!-- bilingual-en:start -->
For an external command, `lesson_value=beta command` supplies a value for that invocation only. Do not extend this shorthand rule unconditionally to shell functions, special builtins, or every shell mode.
<!-- bilingual-en:end -->

## 来源与核验

[GNU Bash Manual §3.7.4](https://www.gnu.org/software/bash/manual/html_node/Environment.html) 与本机 `bash(1)` ENVIRONMENT 段：支持继承和赋值前缀；导出属性及 `export -n` 另逐项核对本机 `help export`。
<!-- bilingual-en:start -->
[GNU Bash Manual §3.7.4](https://www.gnu.org/software/bash/manual/html_node/Environment.html) and installed `bash(1)` ENVIRONMENT support inheritance and assignment prefixes. Installed `help export` separately establishes the export attribute and `export -n`.
<!-- bilingual-en:end -->
