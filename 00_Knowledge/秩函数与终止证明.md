# Ranking functions for termination
<!-- bilingual-en:end -->
*秩函数与终止证明*

<!-- bilingual-en:start -->
A process can keep obeying its rules without ever finishing. A **ranking function** proves that this cannot happen by assigning each state a measure of remaining progress. Every allowed step must move strictly down in an order that cannot descend forever. The measure is a mathematical tool; it need not be a variable stored by the program or the exact number of steps remaining.
<!-- bilingual-en:end -->
一个过程可以一直遵守规则，却永远不结束。**秩函数**给每个状态赋一个衡量剩余进展的量，用来排除这种可能：每条允许的步骤都必须沿某种不能无限下降的次序严格下降。这个量是证明工具，不一定是程序实际保存的变量，也不一定恰好等于剩余步数。

> [!example] A countdown · 倒计数
> <!-- bilingual-en:start -->
> Let the state be a nonnegative integer $k$. Start at $3$, and allow $k\to k-1$ exactly when $k>0$. The execution is $3\to2\to1\to0$. Taking $v(k)=k$ gives a nonnegative integer that drops by one on each of the three transitions. At $0$, no step is allowed. If we added a self-loop $1\to1$, the same measure would no longer prove termination: that loop could be repeated forever.
> <!-- bilingual-en:end -->
>
> 以非负整数 $k$ 为状态，从 $3$ 开始，只在 $k>0$ 时允许 $k\to k-1$。执行为 $3\to2\to1\to0$。取 $v(k)=k$，每次转移都让这个非负整数减少一，共三次转移。到 $0$ 后没有合法步骤。若另加自环 $1\to1$，同一个度量就不能证明终止，因为该自环可以无限重复。

<!-- bilingual-en:start -->
## What must decrease, and where?
<!-- bilingual-en:end -->
*什么必须下降，在哪些状态上下降？*

<!-- bilingual-en:start -->
In the [[状态机与可达性|state-machine model]], $q\to r$ means one allowed transition. A state is reachable if a finite legal execution gets there from the designated start $s_0$. A terminal state has no outgoing transition. Here termination means that no infinite legal execution starts at $s_0$: a run that keeps taking a step whenever one is available must eventually reach a terminal state. A finite prefix stopped early by an observer is not itself evidence of termination.
<!-- bilingual-en:end -->
在[[状态机与可达性|状态机模型]]中，$q\to r$ 表示一条允许转移。从指定起点 $s_0$ 出发，经过有限次合法转移能够到达的状态叫可达状态；没有出边的状态叫终止状态。这里“终止”指不存在从 $s_0$ 开始的无限合法执行：只要还有步骤就继续走的执行，最终必须到达终止状态。观察者提前截断的有限前缀，本身并不是终止的证据。

<!-- bilingual-en:start -->
Choose a function $v$ assigning a value to each relevant state. For the most common proof, verify both obligations:

- Every reachable state has $v(q)\in\mathbb N=\{0,1,2,\ldots\}$.
- For **every** allowed transition out of a reachable state, $v(r)<v(q)$.

The second condition includes every possible branch, not just a preferred route. One can prove these conditions on all states, or on a region already known to contain every reachable state. Restricting to such a region must be justified, for example by an [[不变量原理|invariant proof]].
<!-- bilingual-en:end -->
选取函数 $v$，给相关状态赋值。最常用的证明需要核对两项：

- 每个可达状态都满足 $v(q)\in\mathbb N=\{0,1,2,\ldots\}$。
- 从可达状态出发的**每一条**允许转移都满足 $v(r)<v(q)$。

第二项包括所有可能分支，不只是偏好走的一条路线。可以在全部状态上证明这些条件，也可以在已知包含全部可达状态的区域内证明；后一种限制必须有依据，例如先用[[不变量原理|不变量证明]]确定这个区域。

<!-- bilingual-en:start -->
Write $q_0=s_0$ for the start of an execution $q_0,q_1,\ldots,q_k$. Strict decrease between integer values gives a decrease of at least one per transition. Repeatedly applying this fact yields
<!-- bilingual-en:end -->
将执行 $q_0,q_1,\ldots,q_k$ 的起点记为 $q_0=s_0$。整数值的严格下降意味着每次至少减少一。逐步应用便得到

$$0\le v(q_k)\le v(s_0)-k,\qquad k\le v(s_0).$$

<!-- bilingual-en:start -->
Thus the run cannot make more than $v(s_0)$ transitions. This is a bound on the number of modelled steps, not automatically on seconds or machine instructions. The underlying fact is the [[良序原理适用域|well-ordering principle for nonnegative integers]]: a nonempty set of such values has a least element, so a strictly smaller visited value cannot follow the least one.
<!-- bilingual-en:end -->
所以执行不可能超过 $v(s_0)$ 次转移。这个上界数的是模型中的步骤，不自动等于秒数或机器指令数。背后的依据是[[良序原理适用域|非负整数的良序原理]]：这样的非空值集合有最小元，而最小的已访问值后面不可能再出现一个更小的已访问值。

<!-- bilingual-en:start -->
## Why a well-ordered range also works
<!-- bilingual-en:end -->
*为什么也能使用一般良序值域？*

<!-- bilingual-en:start -->
A **well-ordered set** is an ordered set in which every nonempty subset has a least element. Nonnegative integers with their usual order are one example. Suppose $v$ takes values in such a set and strictly decreases on every relevant transition. If an infinite execution existed, collect all its rank values and choose the least one, say the value at step $j$. Step $j+1$ would have a strictly smaller value in the same set, a contradiction. This proves termination without requiring an integer-valued measure.
<!-- bilingual-en:end -->
**良序集**是每个非空子集都有最小元的有序集合；按通常大小排序的非负整数就是一个例子。若 $v$ 的取值属于这样的集合，并且每条相关转移都使它严格下降，那么假设存在无限执行，收集这条执行的全部秩值，选出其中最小的一个，设它出现在第 $j$ 步。第 $j+1$ 步就会在同一集合中给出更小值，产生矛盾。这个证明不要求度量必须是整数。

<!-- bilingual-en:start -->
The essential condition is the absence of an infinite descending chain. More generally, one can use a **well-founded strict order** with this property; a numerical or total order is not essential. The rank must descend in the specified order at every step. Unlike the nonnegative-integer case, a general ordered value does not by itself give the numerical bound “at most $v(s_0)$ steps.” MIT calls any state-dependent value a *derived variable*; it becomes a termination certificate only after the range and strict-descent conditions have been proved.
<!-- bilingual-en:end -->
关键条件是不存在无限下降链。更一般地，可以使用具有这一性质的**良基严格序**，不一定是数值序或全序；但必须按所指定的次序逐步下降。与非负整数情形不同，一般有序值并不自动给出“至多 $v(s_0)$ 步”这样的数值上界。MIT 把依赖状态的量统称为 *derived variable*；只有证明了值域与严格下降条件，它才成为终止证书。

## The exponent register in fast exponentiation
<!-- bilingual-en:end -->
*快速幂的指数寄存器*

<!-- bilingual-en:start -->
In fast exponentiation, the nonnegative-integer register $z$ is at least halved after every nonterminal transition and remains in $\mathbb N$. More precisely, when $z>0$, one complete iteration replaces it by $\lfloor z/2\rfloor$, the integer quotient from [[带余除法|division by two]]. The brackets mean rounding down, so
<!-- bilingual-en:end -->
快速幂中，非负整数寄存器 $z$ 在每次未终止转移后至少减半并保持在 $\mathbb N$ 中。更精确地，当 $z>0$ 时，一次完整迭代将它变成 $\lfloor z/2\rfloor$，即[[带余除法|除以二所得的整数商]]；括号表示向下取整，因此

$$0\le\lfloor z/2\rfloor<z.$$

<!-- bilingual-en:start -->
For $z=13$, the ranks are $13,6,3,1,0$: four iterations, within the coarser bound of thirteen. If $z=0$ initially, there are no iterations. Every positive $z$ has a next step, and $z=0$ has none, so the terminal condition in this model is exactly $z=0$. The other registers need not decrease. Showing that the returned register contains the required power is the separate [[不变量与部分正确性|partial-correctness argument]].
<!-- bilingual-en:end -->
若 $z=13$，秩值依次为 $13,6,3,1,0$，实际四次迭代，也符合较粗的十三步上界。若初始 $z=0$，一次也不迭代。每个正 $z$ 都有后继，$z=0$ 则没有，所以此模型的终止条件恰为 $z=0$。其他寄存器无须下降；返回寄存器是否真的装着目标幂值，要由单独的[[不变量与部分正确性|部分正确性论证]]说明。

## Boundaries
<!-- bilingual-en:end -->
## 边界

<!-- bilingual-en:start -->
Weak decrease is insufficient: a self-loop may keep $v$ constant forever. Strict decrease with a real lower bound is also insufficient: $1,1/2,1/3,\ldots$ is an infinite decreasing sequence of positive reals. Its values never reach zero, and the set of those values has no least element. For integers, a fixed lower bound can be shifted to obtain a nonnegative measure; for arbitrary real values, the same conclusion does not follow.
<!-- bilingual-en:end -->
弱下降不够：自环可能让 $v$ 永远不变。实数度量严格下降且有下界也不够：$1,1/2,1/3,\ldots$ 是无限下降的正实数序列，它从未到达零，其值集合也没有最小元。整数度量若有固定下界，可以平移为非负度量；任意实数值则没有同样的结论。

<!-- bilingual-en:start -->
Finding no suitable rank yet does not prove nontermination. Nor must a terminal state's rank equal zero: a machine may stop earlier. If one modelled transition stands for an entire loop body or subroutine, that internal computation must itself finish; descent checked only after completed iterations would miss an infinite execution inside a body. Finally, stopping does not establish the required output: [[全正确性构成|total correctness]] also needs a proof that every permitted final result is correct.
<!-- bilingual-en:end -->
暂时找不到合适的秩，并不能证明过程不终止；终止状态的秩也不必为零，机器可能更早停止。若模型的一条转移代表整段循环体或子程序，就必须另外确认这段内部计算本身会完成：只在完成迭代后检查下降，会漏掉循环体内部的无限执行。最后，结束不等于答案正确；[[全正确性构成|全正确性]]还要求证明每个允许的最终结果都正确。

> [!question]- Is weak decrease enough? · 回忆与应用
> <!-- bilingual-en:start -->
> A loop has a nonnegative integer measure satisfying $v_{\text{next}}\le v_{\text{current}}$ on every step. Does this prove termination? **No:** the loop may preserve the same value forever. Strict decrease on every continuing transition, or another argument excluding infinite execution, is still needed.
> <!-- bilingual-en:end -->
>
> 某循环每步都满足整数度量 $v_{\text{next}}\le v_{\text{current}}$，且 $v\ge0$。这足以证明终止吗？**不足：**循环可能一直保持同一个 $v$；仍需逐个继续转移的严格下降，或其他排除无限执行的论证。
