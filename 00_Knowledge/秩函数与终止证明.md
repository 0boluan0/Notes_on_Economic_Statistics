# 严格下降到良序集的秩函数证明终止而弱下降不够
<!-- bilingual-en:start -->
*A ranking function into a well-ordered set proves termination; weak decrease is insufficient*
<!-- bilingual-en:end -->

> [!summary] 原子程序
> 给每个状态赋值 $v(q)$。若 $v$ 的取值落在良序集中，并且每个合法转移 $q\to r$ 都满足 $v(r)<v(q)$，那么不可能存在无限执行，因此过程终止。这个值在教材中叫 derived variable；用于终止证明时常叫秩函数或变体函数。
> <!-- bilingual-en:start -->
> Assign each state a value $v(q)$. If the values lie in a well-ordered set and every legal transition $q\to r$ satisfies $v(r)<v(q)$, then no infinite execution exists and the process terminates. The text calls such an assignment a derived variable; in termination proofs it is often called a ranking or variant function.
> <!-- bilingual-en:end -->

快速幂中，非负整数寄存器 $z$ 在每次未终止转移后至少减半并保持在 $\mathbb N$ 中。于是 $z$ 严格下降，不可能无限下降，最终必须到达停止条件。
<!-- bilingual-en:start -->
In fast exponentiation, the nonnegative-integer register $z$ is at least halved after every nonterminal transition and remains in $\mathbb N$. Thus $z$ strictly decreases, cannot decrease forever, and must eventually reach the stopping condition.
<!-- bilingual-en:end -->

## 边界
<!-- bilingual-en:start -->
*Boundary*
<!-- bilingual-en:end -->

- 只证明 $v(r)\le v(q)$ 不够；无限执行可以让 $v$ 永远保持常数。
- “有下界”不自动等于“良序”。实数序列 $1,1/2,1/3,\ldots$ 严格下降且有下界，却可无限延续；必须核验值域本身排除无限严格下降。
<!-- bilingual-en:start -->

**1.** Showing only $v(r)\le v(q)$ is insufficient; an infinite execution may keep $v$ constant forever.<br>
**2.** Being bounded below is not the same as being well ordered. The real sequence $1,1/2,1/3,\ldots$ is strictly decreasing and bounded below but infinite, so the codomain must itself rule out infinite strict descent.<br>
<!-- bilingual-en:end -->

> [!question]- 回忆与应用
> 某循环每步都满足整数度量 $v_{\text{next}}\le v_{\text{current}}$，且 $v\ge0$。这足以证明终止吗？
>
> **答案：** 不足。循环可能一直保持同一个 $v$。需要证明每个未终止转移都让一个取值于良序集的度量严格下降，或提供其他能排除无限执行的论证。
> <!-- bilingual-en:start -->
> A loop has a nonnegative integer measure satisfying $v_{\text{next}}\le v_{\text{current}}$ on every step. Does this prove termination?
>
> **Answer:** No. The loop may preserve the same value forever. One needs strict decrease on every nonterminal transition into a well-ordered codomain, or some other argument excluding infinite execution.
> <!-- bilingual-en:end -->
