# 凸函数的图像不高于任意两点间的弦而凹函数的图像不低于弦
<!-- bilingual-en:start -->
*A convex function lies below every chord and a concave function lies above every chord*
<!-- bilingual-en:end -->

> [!summary] 它是什么
> 在区间 $I$ 上，若
> $$
> f((1-t)x+ty)\le(1-t)f(x)+tf(y)
> $$
> 对 $x,y\in I$、$0\le t\le1$ 成立，则 $f$ 为凸函数，图像位于弦下方，也常称“凹向上”；反向不等式定义凹函数或“凹向下”。术语可能不同，弦不等式不会含糊。
> <!-- bilingual-en:start -->
> A function is convex on an interval when its graph lies below every chord, equivalently when $f((1-t)x+ty)\le(1-t)f(x)+tf(y)$. Reversing the inequality defines concavity. Descriptive terms such as “concave up” vary by convention, so the chord inequality fixes the meaning.
> <!-- bilingual-en:end -->

例如 $f(x)=x^2$，弦高度与函数值之差恰好为
$$
(1-t)x^2+ty^2-\big((1-t)x+ty\big)^2=t(1-t)(x-y)^2\ge0.
$$
这就直接验证了凸性，无须求导。对仿射函数 $ax+b$，差值恒为零，所以它既凸又凹。“凸”和“凹”在这里都允许等号。
<!-- bilingual-en:start -->
For the square function, the chord excess is exactly $t(1-t)(x-y)^2\ge0$, proving convexity without differentiation. For an affine function, that excess is always zero, so it is both convex and concave. Both definitions allow equality.
<!-- bilingual-en:end -->

同一个弦不等式也定义多元函数的凸性，只需让 $x,y$ 是凸定义域中的向量；凸定义域保证连接两点的线段都在域内。单变量课程中的区间正是它的一维情形。这一定义不要求可导，导数存在时才使用 [[导数判凹凸]]。优化问题中，如何由凹性得到全局结论见 [[凸优化全局性]]。
<!-- bilingual-en:start -->
The same chord inequality defines multivariable convexity when $x,y$ are vectors in a convex domain, which keeps their connecting segment feasible. An interval is its one-dimensional instance. Differentiability is unnecessary for the definition; when derivatives exist, use the [[导数判凹凸|derivative criterion]]. The [[凸优化全局性|global optimality theorem]] explains how concavity applies to optimization.
<!-- bilingual-en:end -->

> [!question]- 自检
> 为什么仿射函数既凸又凹？
>
> **答案：** 它在任意两点之间都与弦重合，定义中的两种不等式均以等号成立。
> <!-- bilingual-en:start -->
> **Check:** Why is an affine function both convex and concave?
>
> **Answer:** Its graph coincides with the chord between any two points, so both defining inequalities hold with equality.
> <!-- bilingual-en:end -->
