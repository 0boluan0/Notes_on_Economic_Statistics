# 用同一变量先构造簇再做普通组间检验会忽略分组的选择事件，描述性比较不能冒充确认性推断
<!-- bilingual-en:start -->
*Using the same variables first to construct clusters and then to run ordinary between-group tests ignores the selection event that created the groups; descriptive comparisons cannot masquerade as confirmatory inference*
<!-- bilingual-en:end -->

> [!summary] 原子推断边界
> 若簇标签 $C(X)$ 正是算法为拉开 $X$ 中的对象而生成，再把这些标签当作预先给定组别，对 $X$ 做普通 t test、ANOVA 或逐变量检验，就重复使用了同一数据。经典参考分布没有条件于“这些组是怎样被挑出来的”，naive p 值通常过小。
> <!-- bilingual-en:start -->
> If cluster labels $C(X)$ were constructed by an algorithm to separate observations in $X$, treating those labels as pre-specified groups and applying ordinary t tests, ANOVA, or feature-wise tests to $X$ uses the data twice. Classical reference distributions do not condition on how the groups were selected, and naive p-values are generally anti-conservative.
> <!-- bilingual-en:end -->

## 问题不是只做了很多检验，而是零假设也由数据产生

普通两组检验假定组别在当前检验之外已经给定。聚类后，比较哪两组、哪些均值以及分组成员本身都由 $X$ 决定。即使只检验一个变量，选择事件仍然存在；仅用 Bonferroni 修正变量数量，不能校正“先找最分离的组，再检验其分离”的过程。

因此应区分三种输出：

- **描述性画像：** 报告簇中心、变量均值和分布，明确这些差异部分由算法目标造成，不附普通确认性 p 值。
- **外部验证：** 在未参与构簇、且问题事先规定的外部结果上检查关联，或在真正独立的总体中复现整个结构。它回答的是新的验证问题，仍需考虑 assignment 和估计不确定性。
- **selective inference：** 在明确模型条件下，对聚类选择事件进行条件化或校正。它不是普通 ANOVA 加一个多重比较修正。

简单拆成 training/test 也未必自动修复：若又使用 test 对象的同一 $X$ 来形成或选择要检验的 test groups，再对这些 $X$ 做普通检验，数据驱动假设仍然存在。设计必须真正分开结构发现、分配规则和确认性结果。

> [!question]- 自检
> 用十个基因表达变量做 K-means 后，研究者对同一十个变量逐一做普通 ANOVA，并对十个 p 值作 Bonferroni。这样是否已经解决选择偏差？
>
> **答案：** 没有。Bonferroni 只处理十次检验的多重性，没有处理簇标签本身就是用这十个变量、以制造组间分离为目标构造出来的这一选择过程。可作描述性画像；确认性结论需独立问题或专门的 selective-inference 方法。

## 来源与核验

- Chen & Witten (2023), [*Selective Inference for K-means Clustering*](https://www.jmlr.org/papers/volume24/22-0371/22-0371.pdf)：核对 K-means 后普通均值差检验反保守及有限样本 selective p-value 的条件。
- Gao, Bien & Witten (2022), [*Selective Inference for Hierarchical Clustering*](https://doi.org/10.1080/01621459.2022.2116331)：核对层次聚类后分组由同一数据产生时的选择事件。
- [[选择后推断]]：复用数据先选择问题、再按固定问题参考分布推断会失真的一般边界；本卡拥有聚类标签这一专门情形。
