# is 比较对象身份而双等号比较值是否相等
<!-- bilingual-en:start -->
*`is` compares object identity, while `==` compares value equality*
<!-- bilingual-en:end -->

> [!summary] 原子区别
> `a is b` 询问两个操作数是否指向同一个对象；`a == b` 调用相等比较，询问两个对象的值是否按其类型规则相等。值相等不要求身份相同；身份相同通常会比较相等，但这不是逻辑保证：NaN 值可以与自身比较不等，自定义 `__eq__` 也能改变结果。
> <!-- bilingual-en:start -->
> `a is b` asks whether both operands designate the same object. `a == b` invokes equality comparison under the objects' type rules. Equal values need not share identity, and shared identity does not logically guarantee equality: a NaN value can compare unequal to itself, while a custom `__eq__` can define another result.
> <!-- bilingual-en:end -->

```python
a = [1, 2]
b = [1, 2]
c = a

a == b   # True: equal contents
a is b   # False: distinct list objects
a is c   # True: the same list object
```

身份比较不能被类型自定义，因此检查单例 `None` 应写 `x is None`。普通数字、字符串与容器内容比较应使用 `==`；解释器可能复用某些不可变对象是实现细节，不能把偶然的 `is` 结果当成值比较规则。

自定义类型可以实现 `__eq__`，所以 `==` 可能返回非布尔对象或抛出异常，再由使用场景做真值判断；核心区别仍是值语义与对象身份，不是“严格比较”和“宽松比较”。

> [!question]- 回忆与应用
> 为什么两个内容相同的列表可能 `==` 为真而 `is` 为假？
>
> **答案：** 列表相等比较内容；两个列表可以分别创建、身份不同，却保存相同元素。
