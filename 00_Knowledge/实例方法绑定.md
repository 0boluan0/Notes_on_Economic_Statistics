# 从实例读取类中普通函数会得到把该实例预绑定为首个参数的方法
<!-- bilingual-en:start -->
*Reading an ordinary class function through an instance produces a method with that instance pre-bound as the first argument*
<!-- bilingual-en:end -->

> [!summary] 原子绑定规则
> 类体中的普通 `def` 把函数对象存为类属性。经实例读取该属性时，函数的描述器协议返回一个 bound method，其中 `__self__` 是该实例、`__func__` 是原函数；之后调用方法时，实例会自动成为函数的第一个实参。`self` 只是首个形参的惯用名称，不是关键字。
> <!-- bilingual-en:start -->
> An ordinary `def` in a class body stores a function object as a class attribute. Reading that attribute through an instance invokes the function's descriptor protocol and returns a bound method whose `__self__` is the instance and whose `__func__` is the original function. Calling the method then supplies the instance automatically as the function's first argument. `self` is only the conventional parameter name, not a keyword.
> <!-- bilingual-en:end -->

```python
class Counter:
    def add(self, amount):
        self.total += amount

c = Counter()
c.total = 0

c.add(3)                 # bound call
Counter.add(c, 4)        # equivalent explicit function call
c.add.__self__ is c      # True
c.total                  # 7
```

绑定发生在属性读取时，而不是把函数代码复制进每个实例。保存 `saved = c.add` 会保存这个已绑定的方法；之后调用 `saved(...)` 仍把原来的 `c` 作为首个实参。

> [!question]- 回忆与应用
> 为什么 `c.add(3)` 只显式给一个参数，而 `Counter.add(c, 3)` 要给两个？
>
> **答案：** `c.add` 已把 `c` 绑定为首个实参；从类读取 `Counter.add` 得到的函数没有这个预绑定。
