# Basel Framework 是国际最低标准而不是自动生效的本地法律
*The Basel Framework is an international minimum standard, not self-executing domestic law*

> [!summary] 适用口径
> 巴塞尔委员会为国际活跃银行制定共同的最低审慎标准，但委员会本身不是超国家立法机关。银行真正受约束的规则来自适用法域把标准写入法律、监管规则或监督决定后的版本。

因此，“Basel 要求 8%”只能回答国际基线，不能自动回答某家银行今天是否合法。实际判断至少要锁定银行所属法域、监管合并范围、机构类别、报告日期、过渡安排、本地附加缓冲和监督加成。本地规则可以晚于、严于或在允许的国家裁量范围内不同于 Basel 文本。

例：同属一个跨国银行集团的母行与境外子行，可能分别面对集团合并层面和所在国单体层面的要求。即使两地都宣称实施 Basel III，生效日期、披露表格和附加资本也未必相同。英国 PRA 在 2026 年发布的 PS1/26 就把主要 Basel 3.1 最终规则定于 2027-01-01 生效，而 FRTB 内部模型法定于 2028-01-01 生效；这不是 Basel 文本自动变成英国法，而是本地实施选择的一个有日期例子。

## 边界

- “国际最低标准”不等于可忽略；成员法域承诺实施，并通过监管一致性评估计划（RCAP）接受监测。
- Basel 的适用范围以国际活跃银行为核心；本地是否扩展到其他机构由该法域决定。
- 本卡不列某一国家的最终合规数字；任何具体判断必须查当日有效的本地规则。

> [!question]- 自检
> 一家银行达到 Basel 整合框架的最低资本率，能否据此断言它满足英国或美国的全部资本要求？
>
> **答案：** 不能。还要核对适用法域、本地实施版本、机构分类、缓冲、监督加成和生效日期。

## 来源与核验

- [Basel Committee, RCAP implementation monitoring](https://www.bis.org/bcbs/implementation/rcap_reports.htm)：核对各法域实施状态并不相同。
- [UK PRA, PS1/26 — Implementation of the Basel 3.1 final rules](https://www.bankofengland.co.uk/prudential-regulation/publication/2026/january/implementation-of-the-basel-3-1-final-rules-policy-statement.)：核对英国主要规则与 FRTB 内部模型法的分阶段本地生效日。
- 口径核验日：2026-08-29；具体合规仍须回到当时有效的本地法律与监管规则。
