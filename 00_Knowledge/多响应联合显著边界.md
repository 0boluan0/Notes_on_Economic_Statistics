# 多响应联合显著不推出每个响应都显著
<!-- bilingual-en:start -->
*Joint multivariate significance does not imply significance for every response*
<!-- bilingual-en:end -->

> [!summary] 原子边界
> 拒绝 $H_0:CBA=D$ 只说明这组预先指定的联合限制与数据不相容：至少一个被检验的系数—响应组合偏离零假设。它不推出 $CBA-D$ 的每个坐标都显著，也不推出每个原始响应都变化。
> <!-- bilingual-en:start -->
> Rejecting $CBA=D$ shows that the specified collection of contrasts is not jointly compatible with the null. It does not establish that every coordinate or every original response is individually significant.
> <!-- bilingual-en:end -->

联合检验会利用响应间协方差，因此它和逐响应检验回答不同问题。总体拒绝后，可用预先指定对比、同时区间或有错误率控制的后续分析定位方向；把未经控制的一串单变量 $p$ 值当作总体检验，或者把总体检验当作每一列的检验，方向都错。

定位还要回到可解释尺度。报告预设组间/系数对比的估计、同时或多重性调整后的区间、原单位图形与实际量级，才能回答“差多少、在哪些响应上”。Wilks、Pillai 等是总体检验准则，不是自动具有统一实质含义的效应量。

Pillai、Wilks、Hotelling–Lawley 与 Roy 可以针对同一个 $H_0$、同一对假设/误差 SSCP 计算，但它们的定义与参考分布属于独立的统计量层，见 [[MANOVA四种统计量]] 与 [[MANOVA检验校准]]。无论选哪一种，总体检验都不会因此变成逐响应定位工具；更不能在看完四个 $p$ 值后才挑最显著的一种。

至于能否把这些响应差异解释成干预效应，是另一条独立问题；见 [[多响应因果边界]]。

> [!question]- 自检
> Pillai 检验拒绝“处理对三个响应全部无效”后，能否直接写“三个响应都显著变化”？
>
> **答案：** 不能；它可能由一个响应或某个响应线性组合驱动，还需定位性对比和多重性控制。

## 来源与核验

- [R `summary.manova` documentation](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/summary.manova.html)：核对多元统计量与逐响应 ANOVA 表是不同输出。
- [Penn State STAT 505, Lesson 8](https://online.stat.psu.edu/stat505/Lesson08)：核对总体 MANOVA 检验之后需要用预先规定对比或同时区间定位响应方向。
- [statsmodels, Multivariate Linear Model](https://www.statsmodels.org/stable/examples/notebooks/generated/multivariate_ls.html)：核对默认多元检验问每一模型项是否对任何 dependent variable 有联合效应。
- [[多响应因果边界]] 与 [[回归联合显著边界]]：分别承接因果识别问题，以及单响应回归中“联合显著不等于每个系数显著”的对应区别。

- R and statsmodels distinguish multivariate tests from univariate follow-ups; the dedicated MANOVA-statistic atoms own the separate statistic and calibration definitions.
