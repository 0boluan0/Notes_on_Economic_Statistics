# 有限无向图可二着色当且仅当它不含奇环
<!-- bilingual-en:start -->
*A finite simple undirected graph is two-colorable if and only if it contains no odd cycle*
<!-- bilingual-en:end -->

> [!summary] 原子定理
> 对 finite simple undirected graph $G$，下列命题等价：
>
> 1. $V$ 可以分成 $L\mathbin{\dot\cup}R$，且每条边都跨越两侧，即 $G$ bipartite；
> 2. $G$ 存在使用至多两种颜色的 proper vertex coloring；
> 3. $G$ 不含 odd cycle。
>
> <!-- bilingual-en:start -->
> For a finite simple undirected graph $G$, the following are equivalent: $G$ is bipartite; $G$ admits a proper coloring with at most two colors; and $G$ contains no odd cycle.
> <!-- bilingual-en:end -->

从 bipartition 到 two-coloring 很直接：给 $L$ 与 $R$ 不同颜色。反方向也直接：把两个 color classes 当作左右两侧；properness 保证没有边留在同一侧。这里允许一侧为空，因而无边图和 null graph 也都是 bipartite。
<!-- bilingual-en:start -->
A bipartition immediately gives a two-coloring by assigning one color to each side. Conversely, the two color classes form a bipartition because properness leaves no edge within either class. An empty side is allowed, so edgeless graphs and the null graph are also bipartite.
<!-- bilingual-en:end -->

若图已经二着色，沿任意 cycle 每经过一条边都必须换色。走偶数条边才可能回到起点原来的颜色，所以 odd cycle 不可能存在。
<!-- bilingual-en:start -->
In any proper two-coloring, the color must alternate across every edge of a cycle. Returning to the starting color therefore requires an even number of edges, so an odd cycle cannot occur.
<!-- bilingual-en:end -->

困难的方向是“没有 odd cycle 就可以二着色”。对每个 connected component 选一个 root，把 parent tree 中深度为偶数和奇数的顶点分到两侧；BFS 时这个深度恰好也是无权最短距离，DFS 时则只能解读为搜索树深度。若某条边 $uv$ 的两端落在同一侧，root 到 $u$ 与 $v$ 的树路径去掉共同前缀，再加上 $uv$，便形成一条奇数长度 cycle，与假设矛盾。因此所有边都跨越两侧。
<!-- bilingual-en:start -->
For the harder direction, choose a root in every connected component and split vertices by even or odd parent-tree depth. With BFS this depth is also the unweighted shortest-path distance; with DFS it is only search-tree depth. If some edge $uv$ joined vertices on the same side, remove the common prefix from the two root paths and add $uv$; the result would be an odd cycle, a contradiction. Hence every edge crosses the partition.
<!-- bilingual-en:end -->

“可二着色”表示至多使用两色。若非空图没有任何边，它当然 bipartite，但实际只需一种颜色；只有图至少含一条边时，bipartite 才进一步推出 $\chi(G)=2$。
<!-- bilingual-en:start -->
Two-colorable means colorable with at most two colors. A nonempty edgeless graph is bipartite but needs only one color. Exact equality $\chi(G)=2$ additionally requires at least one edge.
<!-- bilingual-en:end -->

这个定理解决的是“能否分成左右两侧”。一旦左右角色已经确定，[[二分图配对关系|matching]] 才继续追问应从跨侧的允许边中选择哪些配对；二着色本身不做分配。
<!-- bilingual-en:start -->
The theorem recognizes whether two sides exist. Once those roles are fixed, [[二分图配对关系|matching]] asks which permitted cross-edges should be selected. Two-coloring itself makes no assignments.
<!-- bilingual-en:end -->

> [!question]- 回忆与辨别
> 一张图没有 triangle，是否已经足以断定它可二着色？
>
> **答案：**不够。它仍可能含 $C_5,C_7$ 等更长 odd cycles。必须排除所有奇环，或直接运行二着色搜索。
