# Communicating classes
<!-- bilingual-en:end -->
*马氏链的可达、互通与沟通类*

<!-- bilingual-en:start -->
A **communicating class** groups states between which travel is possible in both directions. Imagine a system moving among four locations: locations 1 and 2 can send it back and forth, and locations 3 and 4 can do the same. If it can move from the first pair to the second but never back, these are two different classes. The classification asks which routes are possible, not which routes are likely or fast.
<!-- bilingual-en:end -->

**沟通类**把能够双向往返的状态归在一起。设系统在四个地点之间移动：1、2 可以来回走，3、4 也可以来回走。如果能从第一组进入第二组，却永远无法返回，那么这是两个不同的类。分类关注路线是否可能，不是路线有多大概率、需要多快走完。

<!-- bilingual-en:start -->
Use a [[离散时间Markov链|discrete-time Markov chain]] with a nonempty finite or countably infinite state set $S$. Assume [[DTMC时间齐次转移核|time homogeneity]]: the same transition rule applies at every step. In the [[Markov矩阵左右约定|row convention]], $p_{ij}$ is the one-step probability from state $i$ to state $j$, and the entries of each row sum to one. Draw a directed arrow $i\to j$ for each positive one-step probability when drawing the transition graph; in the accessibility notation below, the same arrow also allows a route of several steps.
<!-- bilingual-en:end -->

考虑非空、有限或可数无限状态集 $S$ 上的[[离散时间Markov链]]，并假设[[DTMC时间齐次转移核|时间齐次]]：每一步使用同一条转移规则。采用[[Markov矩阵左右约定|行约定]]，$p_{ij}$ 是从状态 $i$ 一步到达 $j$ 的概率，每行概率之和为一。画转移图时，为每个正的一步概率画有向箭头；下面的“可达”记号也用箭头，但允许沿多步路线到达。

<!-- bilingual-en:start -->
## From a route to a class
<!-- bilingual-en:end -->
*先看路线，再划分类*

<!-- bilingual-en:start -->
Write $p_{ij}^{(n)}$ for the probability of being at $j$ after exactly $n$ steps when started at $i$. The [[DTMC转移复合|transition-composition rule]] gives $p_{ij}^{(n)}=(P^n)_{ij}$ for a finite transition matrix $P$. State $j$ is **accessible** from $i$ if $p_{ij}^{(n)}>0$ for at least one integer $n\ge0$. We write $i\to j$. A positive finite route has probability equal to the product of its positive transition probabilities, so it establishes accessibility. Conversely, a positive $n$-step probability requires at least one such route in this countable-state setting.
<!-- bilingual-en:end -->

记 $p_{ij}^{(n)}$ 为从 $i$ 出发、恰好 $n$ 步后位于 $j$ 的概率。由[[DTMC转移复合]]，有限转移矩阵 $P$ 满足 $p_{ij}^{(n)}=(P^n)_{ij}$。如果至少存在一个整数 $n\ge0$ 使该概率为正，就称 $j$ 从 $i$ **可达**，记作 $i\to j$。一条有限路线的概率是沿途转移概率的乘积；各项都正，就给出了可达性。反过来，在可数状态范围内，正的 $n$ 步转移概率也要求至少一条这样的正概率路线。

> [!example] Two groups and a one-way exit · 两组状态与单向出口
> <!-- bilingual-en:start -->
> Order the states as $1,2,3,4$ and use
> <!-- bilingual-en:end -->
>
> 按 $1,2,3,4$ 排列状态，取
>
> $$P=\begin{pmatrix}0&1&0&0\\1/2&0&1/2&0\\0&0&0&1\\0&0&1&0\end{pmatrix}.$$
>
> <!-- bilingual-en:start -->
> The route $1\to2\to3\to4$ has probability $1\times(1/2)\times1=1/2$, so 4 is accessible from 1. But 4 cannot reach 1: once in $\{3,4\}$, the chain only alternates there. States 1 and 2 reach each other, as do states 3 and 4. The communicating classes are therefore $\{1,2\}$ and $\{3,4\}$.
> <!-- bilingual-en:end -->
>
> 路线 $1\to2\to3\to4$ 的概率是 $1\times(1/2)\times1=1/2$，所以 4 从 1 可达。但 4 无法到达 1：进入 $\{3,4\}$ 后只能在其中交替。1 与 2 互相可达，3 与 4 也互相可达，因此沟通类恰为 $\{1,2\}$ 与 $\{3,4\}$。

<!-- bilingual-en:start -->
Two states **communicate**, written $i\leftrightarrow j$, when both $i\to j$ and $j\to i$. The class containing $i$ is

$$[i]=\{j\in S:i\leftrightarrow j\}.$$

This is a **maximal** group: it includes every state communicating with $i$, not an arbitrarily chosen subset of them. For example, $\{1\}$ is not a class in the four-state model, because state 2 must be included too.
<!-- bilingual-en:end -->

如果 $i\to j$ 和 $j\to i$ 都成立，就称两状态**互通**，记作 $i\leftrightarrow j$。包含 $i$ 的类是 $[i]=\{j\in S:i\leftrightarrow j\}$。这里要求**最大**：所有与 $i$ 互通的状态都要纳入，不能任意挑一部分。在四状态例中，$\{1\}$ 不是沟通类，因为还必须纳入状态 2。

<!-- bilingual-en:start -->
## Why the classes partition the state set
<!-- bilingual-en:end -->
*为什么每个状态恰好归入一个类*

<!-- bilingual-en:start -->
We allow a zero-step route: $p_{ii}^{(0)}=1$ and $p_{ij}^{(0)}=0$ for $i\ne j$. Thus every state communicates with itself even if it can never return after leaving. Communication is symmetric by definition. It is also transitive, because routes can be joined. If $p_{ij}^{(m)}>0$ and $p_{jk}^{(n)}>0$, then

$$p_{ik}^{(m+n)}\ge p_{ij}^{(m)}p_{jk}^{(n)}>0.$$

Joining the reverse routes as well shows that $i\leftrightarrow j$ and $j\leftrightarrow k$ imply $i\leftrightarrow k$. These three properties mean that communication is an equivalence relation: its classes are disjoint and cover $S$.
<!-- bilingual-en:end -->

本卡允许零步路线：$p_{ii}^{(0)}=1$，不同状态之间则 $p_{ij}^{(0)}=0$。所以每个状态都与自身互通，即使离开后永远不能返回。互通按定义具有对称性，也具有传递性，因为两条路线能够接起来。若 $p_{ij}^{(m)}>0$、$p_{jk}^{(n)}>0$，上式表明 $i$ 可以先到 $j$ 再到 $k$；把反向路线也接起来，就得到 $i\leftrightarrow j$、$j\leftrightarrow k$ 蕴含 $i\leftrightarrow k$。这三个性质说明互通是等价关系：各类互不重叠，合起来覆盖 $S$。

<!-- bilingual-en:start -->
For the one-way chain $1\to2\to3$, with 3 staying at itself forever, the classes are $\{1\},\{2\},\{3\}$. Being connected by arrows is not enough for mutual communication. In particular, zero-step self-communication does not assert a positive-time return. Some texts define accessibility using positive steps and then explicitly add self-communication; that convention gives the same classes.
<!-- bilingual-en:end -->

对单向链 $1\to2\to3$，其中 3 永远留在自身，沟通类是 $\{1\},\{2\},\{3\}$。被箭头连起来不足以证明互通。尤其要注意，零步的自我互通没有断言正时间后能够返回。有些教材把可达限定为正步数，再额外规定状态与自身互通；这样得到的类划分相同。

<!-- bilingual-en:start -->
## Routes within a class stay within it
<!-- bilingual-en:end -->
*同类之间的路线为什么不能绕到类外再回来*

<!-- bilingual-en:start -->
Suppose a positive route from $i$ to $j$ passes through $z$, with $i,j$ in the same class. Then $i\to z\to j$ and $j\to i$, so $z\to i$ and $i\to z$. Therefore $z$ belongs to that class too. A route between class members cannot genuinely leave the class and then return. A class may still have an exit leading somewhere from which return is impossible; a class without any exit is a [[闭沟通类|closed communicating class]]. If the entire state set is one class, the chain is [[不可约链|irreducible]]. These graph definitions apply to finite and countably infinite state sets; conclusions about [[常返与暂态|eventual return with probability one]] require further reasoning.
<!-- bilingual-en:end -->

设一条从 $i$ 到 $j$ 的正概率路线经过 $z$，而 $i,j$ 属于同一类。那么 $i\to z\to j$ 且 $j\to i$，于是 $z\to i$、$i\to z$，说明 $z$ 也属于该类。因此，同类成员之间的路线不可能真正离开类以后又回来。一个类仍可能有出口，但出口通向的是无法返回的地方；没有任何出口的类才叫[[闭沟通类]]。如果整个状态集就是一个类，链便[[不可约链|不可约]]。这些图结构定义适用于有限和可数无限状态集；关于[[常返与暂态|是否以概率一最终返回]]的结论，还需要额外论证。
