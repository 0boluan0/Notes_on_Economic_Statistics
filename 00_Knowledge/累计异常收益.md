# 累计异常收益是事件窗内逐期异常收益的总和
<!-- bilingual-en:start -->
*Cumulative abnormal return is the sum of period-by-period abnormal returns over an event window*
<!-- bilingual-en:end -->

> [!summary] 原子定义
> 对证券 $i$ 和预先指定的事件窗 $[\tau_1,\tau_2]$，累计异常收益定义为
> $$CAR_i(\tau_1,\tau_2)=\sum_{t=\tau_1}^{\tau_2}AR_{it}.$$
> 它把同一证券在事件时间上的 [[异常收益]] 聚合为一个窗口反应量。
> <!-- bilingual-en:start -->
> For security $i$ and a prespecified event window $[\tau_1,\tau_2]$, cumulative abnormal return is $CAR_i(\tau_1,\tau_2)=\sum_{t=\tau_1}^{\tau_2}AR_{it}$. It aggregates the same security's [[异常收益|abnormal returns]] through event time into one window-reaction measure.
> <!-- bilingual-en:end -->

若某股票在事件日 $-1,0,+1$ 的 AR 分别为 1%、$-0.5$% 和 0.8%，则 $CAR_i(-1,+1)=1.3\%$。窗口起点和终点属于定义的一部分；换一个窗口就得到另一个被估计的目标量，不能看完结果再挑最显著的区间。
<!-- bilingual-en:start -->
If a stock's AR on event days $-1,0,+1$ is 1%, $-0.5$%, and 0.8%, then $CAR_i(-1,+1)=1.3\%$. The window endpoints are part of the estimand. A different window defines a different quantity, so the most significant interval cannot be selected after observing the results.
<!-- bilingual-en:end -->

跨时间求和与跨证券平均不是同一件事。$CAR_i$ 先对单个证券沿时间求和；累计平均异常收益（CAAR）再在证券之间聚合。CAR 的不确定性也不能总靠逐日方差机械相加：事件窗内序列协方差、正常收益参数估计误差，以及多证券研究中的横截面协方差都可能需要保留。
<!-- bilingual-en:start -->
Time aggregation and cross-security averaging are different operations. $CAR_i$ first sums one security through time; average CAR or CAAR then aggregates across securities. CAR uncertainty cannot always be obtained by mechanically adding daily variances: serial covariance within the window, normal-return parameter-estimation error, and cross-security covariance in multi-security studies may all matter.
<!-- bilingual-en:end -->

CAR 仍然是正常收益模型相对量，也只描述所选窗口中的价格反应。是否能把它归因于目标事件，还要检查预期、泄漏、事件时点和并发消息，见 [[事件研究因果边界]]。
<!-- bilingual-en:start -->
CAR remains relative to the normal-return model and describes only the price reaction in the selected window. Attributing it to the target event additionally requires checking anticipation, leakage, event timing, and concurrent news; see [[事件研究因果边界|the causal boundary]].
<!-- bilingual-en:end -->

> [!question]- 自检
> 三日窗口的 AR 依次为 2%、$-1$%、0.5%，但研究者只报告第一天的 2%。这是否等于三日 CAR？
>
> **答案：** 不等于。三日 CAR 是 $2\%-1\%+0.5\%=1.5\%$；只报告第一天改变了事件窗与被估计的量。
