# Python 表达式求值产生带类型的结果
<!-- bilingual-en:start -->
*Python expression evaluation yields a typed result*
<!-- bilingual-en:end -->

> [!summary] 原子执行模型
> Python 在当前环境中求值一个表达式，得到一个结果对象；该对象具有值和类型，类型决定它支持哪些操作。复杂表达式会把子表达式的结果继续交给外层运算，最终收束为一个结果。这个结果可能是既有对象，不保证每次求值都新建对象；求值也可能抛出异常而没有正常结果。
> <!-- bilingual-en:start -->
> Python evaluates an expression in the current environment to obtain a result object. That object has a value and a type, and its type determines which operations it supports. A compound expression feeds subexpression results into enclosing operations until one result remains. The result may be an existing object rather than a newly allocated one, and evaluation may raise an exception instead of completing normally.
> <!-- bilingual-en:end -->

```python
2 + 3 * 4       # value 14, type int
len("cat")      # value 3, type int
1 / 0           # raises ZeroDivisionError; no normal value is produced
```

## 表达式不等于输出

交互式 shell 会显示非 `None` 的表达式结果；脚本中的普通表达式语句通常只求值并丢弃结果。若表达式调用了有副作用的函数，副作用仍可能发生，但“屏幕上出现结果”必须由交互环境或显式输出语句解释，不能由表达式概念本身推出。
<!-- bilingual-en:start -->
An interactive shell displays a non-`None` expression result, whereas a plain expression statement in a script normally evaluates and discards that result. A called function may still have side effects, but visible output comes from the interactive environment or an explicit output operation, not from the definition of an expression itself.
<!-- bilingual-en:end -->

> [!question]- 回忆与应用
> 为什么 `type(2 + 3.0)` 是 `float`，但仅把这一行写进脚本不保证屏幕会显示 `5.0`？
>
> **答案：** 运算得到的结果对象是浮点数；脚本会求值表达式，却不会像交互式 shell 那样自动显示普通表达式结果。
