# 浮点基本运算会把精确结果舍入到目标格式

<!-- bilingual-en:start -->
*Floating-point basic operations round the exact result to the destination format*
<!-- bilingual-en:end -->

> [!summary] 原子模型
> 对目标格式中的浮点输入 $x,y$，IEEE 754 基本运算可理解为：先形成实数意义下的精确结果 $x\circ y$，再按当前舍入方向映射到目标格式，写作 $\operatorname{fl}(x\circ y)$。默认的 round-to-nearest, ties-to-even 会选最近值，恰好居中时选末位为偶数的候选。
>
> <!-- bilingual-en:start -->
> For floating-point inputs $x,y$ in a destination format, an IEEE 754 basic operation can be modeled as forming the exact real result $x\circ y$ and then rounding it into that format, written $\operatorname{fl}(x\circ y)$. The default round-to-nearest, ties-to-even mode chooses the nearest value and, on an exact tie, the candidate with an even least significant digit.
> <!-- bilingual-en:end -->

这与输入表示误差不同：`0.1` 在进入运算前可能已经是 $1/10$ 的近似值；之后每一个不能精确落在格式内的加、减、乘、除或平方根又可能引入新的舍入。某次运算如果结果本来就可表示，则该步可以没有新舍入误差。
<!-- bilingual-en:start -->
This differs from input representation error: `0.1` may already approximate $1/10$ before arithmetic begins, and each later addition, subtraction, multiplication, division, or square root whose exact result is not representable may introduce another rounding. If an operation's exact result is representable, that step need not add error.
<!-- bilingual-en:end -->

令 $u$ 表示当前格式与舍入模式下的 unit roundoff（单位舍入误差），常用相对误差模型为

$$
\operatorname{fl}(x\circ y)=(x\circ y)(1+\delta),\qquad |\delta|\le u
$$

只在结果处于正常有限范围且满足相应假设时使用；接近下溢、发生溢出、结果为零或特殊值时，必须单独分析，不能机械套用相对误差界。
<!-- bilingual-en:start -->
Let $u$ denote the unit roundoff for the current format and rounding mode. The familiar relative-error model applies under its assumptions, notably for normal finite results. Near underflow, at overflow, at zero, or for special values, separate analysis is required rather than mechanically applying the bound.
<!-- bilingual-en:end -->

> [!question]- 回忆与应用
> 两个输入浮点数都能精确表示，是否保证它们的乘积也能精确表示？
>
> **答案：** 不保证。精确乘积仍可能落在相邻可表示点之间，或超出目标格式范围，因此需要舍入或产生范围异常。
