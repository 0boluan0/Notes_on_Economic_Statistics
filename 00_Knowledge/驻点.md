# 驻点是可微函数一阶导数等于零的点

<!-- bilingual-en:start -->
*A stationary point is a domain point of a differentiable function at which the first derivative is zero*
<!-- bilingual-en:end -->

若 $f$ 在点 $a$ 可微且 $Df(a)=0$，称 $a$ 为驻点（stationary point）；采用列梯度时就是 $\nabla f(a)=0$。当最优性结论需要拓扑内部时，另要求 $a\in\operatorname{int}U$。

SOFP 在光滑语境把这类点称为 critical points；其他微积分材料的[[临界点]]还可包含不可导点。[[无约束一阶条件]]说明可微的内部局部极值必驻定，但驻点不保证极值：$f(x)=x^3$ 在零点驻定却仍穿过该点持续上升。

<!-- bilingual-en:start -->
Stationarity means a zero derivative at a point where the function is differentiable. The point must belong to the domain; when topological interior is needed, that assumption is stated explicitly. SOFP uses “critical point” in this smooth sense, while other texts use [[临界点|critical point]] more broadly. [[无约束一阶条件|Interior first-order necessity]] does not make stationarity sufficient for an extremum.
<!-- bilingual-en:end -->
