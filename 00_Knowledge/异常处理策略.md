# 传播、重试、跳过或返回默认值必须由失败情形的契约决定

<!-- bilingual-en:start -->
*The failure contract determines whether to propagate, retry, skip, or return a default*
<!-- bilingual-en:end -->

异常发生后，先确定失败属于哪一层的责任以及调用者被承诺什么，再选择响应：本层不能履行承诺时传播异常；有明确恢复步骤时重试；只有契约允许忽略该项或采用替代值时，才跳过或返回默认值。捕获只是获得选择响应的机会，不自动意味着结果仍然正确。

<!-- bilingual-en:start -->
First determine which layer owns the failure and what the caller was promised. Propagate when this layer cannot meet that promise; retry when there is a defined recovery step; skip an item or return a default only when the contract permits it. Catching an exception offers a choice of response, not an automatic guarantee of a correct result.
<!-- bilingual-en:end -->

以“空成绩列表的平均值”为最小对照：直接除以长度会抛 `ZeroDivisionError`；只打印提醒而走到函数末尾会返回 `None`；返回 `0.0` 则明确采用一个替代政策。后两者都不是数学上的空集平均值。若契约规定空记录按零分计，`0.0` 可以正确；若它承诺实际平均成绩，该替代就可能掩盖缺失数据。

<!-- bilingual-en:start -->
For an empty grade list, division by its length raises `ZeroDivisionError`; merely printing a warning and reaching the function's end returns `None`; returning `0.0` adopts an explicit replacement policy. Neither latter result is the mathematical mean of an empty set. Zero can be correct under a contract that assigns zero to an empty record, but can conceal missing data if the promise is an actual mean grade.
<!-- bilingual-en:end -->

因此，“没有抛异常”不是成功判据，“返回默认值”也不必然是静默失败。检查返回值、状态与副作用是否符合契约；[[返回值与打印|打印信息不能替代返回结果]]。重试还必须重新执行所需操作，并考虑此前副作用，不能把捕获本身当作重试。

<!-- bilingual-en:start -->
Therefore, “no exception” is not a success criterion, and “returned a default” is not inherently silent failure. Check the return value, state, and side effects against the contract; [[返回值与打印|printing cannot substitute for returning a result]]. Retrying must explicitly repeat the required operation and account for earlier effects; catching alone does not retry it.
<!-- bilingual-en:end -->
