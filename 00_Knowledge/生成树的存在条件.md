# 有限无向图存在 spanning tree 当且仅当它 connected
<!-- bilingual-en:start -->
*A finite undirected graph has a spanning tree exactly when it is connected*
<!-- bilingual-en:end -->

> [!summary] 原子定理
> spanning subgraph 保留原图的全部顶点，只删去部分边；若该子图是 tree，就叫 spanning tree。有限无向图 $G$ 存在 spanning tree，当且仅当 $G$ connected。
> <!-- bilingual-en:start -->
> A spanning subgraph keeps every vertex of the original graph and may delete edges. A spanning subgraph that is a tree is a spanning tree. A finite undirected graph has a spanning tree exactly when it is connected.
> <!-- bilingual-en:end -->

若 $G$ 有 spanning tree $T$，则 $T$ 中连接任意两点的 path 也是 $G$ 的 path，所以 $G$ connected。反向，从 finite connected $G$ 开始，只要还有 cycle，就删去 cycle 上任意一边；该边两端仍能沿 cycle 其余部分绕行，故连通性不变。边数每次严格减少，过程最终停在 connected、acyclic 的 spanning subgraph，也就是 spanning tree。
<!-- bilingual-en:start -->
If $G$ contains a spanning tree $T$, every path in $T$ is also a path in $G$, so $G$ is connected. Conversely, repeatedly delete an edge from a cycle of a finite connected graph. The rest of that cycle still connects its endpoints, so connectivity is preserved. Since the edge count decreases, the process ends at a connected, acyclic spanning subgraph.
<!-- bilingual-en:end -->

在无向图中，BFS/DFS parent edges 会在 root 所在 connected component 上给出一种 spanning tree；若原图 connected，它才覆盖全体顶点。search tree 仍依赖 root 与邻接顺序，“覆盖该 component”只证明 spanning，不包含 minimum-total-weight 语义。
<!-- bilingual-en:start -->
In an undirected graph, BFS or DFS parent edges give a spanning tree of the root's connected component; they span all vertices only when the original graph is connected. The search tree depends on the root and adjacency order, and spanning a component carries no minimum-total-weight guarantee.
<!-- bilingual-en:end -->

> [!question]- 自检
> disconnected graph 能否通过只删边得到 spanning tree？
>
> **答案：**不能。删边不会在不同 components 之间创造 path；若要连通必须加边，而 spanning subgraph 不允许这样做。
