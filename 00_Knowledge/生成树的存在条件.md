# When a spanning tree exists
<!-- bilingual-en:end -->
*生成树的存在条件*

<!-- bilingual-en:start -->
A **[[生成树|spanning tree]]** keeps every vertex of a network while retaining just enough edges to connect them without a cycle. It answers a practical question: can redundant connections be removed without leaving any vertex behind? The answer is yes exactly when the original finite, nonempty undirected graph is connected.
<!-- bilingual-en:end -->
**[[生成树]]**保留网络中的每个顶点，只留下足以连接它们、又不形成环的边。它回答一个具体问题：能否删去多余连接，同时不丢下任何顶点？对有限、非空的无向图，答案恰好取决于原图是否连通。

<!-- bilingual-en:start -->
## Keep all vertices, select some edges
<!-- bilingual-en:end -->
*顶点全部保留，边可以选择*

<!-- bilingual-en:start -->
Write $G=(V,E)$ for a finite [[图类型的建模边界|undirected graph]], with vertex set $V\ne\varnothing$ and edge set $E$. A **spanning subgraph** is $T=(V,F)$ with $F\subseteq E$: it has the same vertices but may omit original edges. It is a spanning tree when it is an [[无向树|undirected tree]], meaning connected and acyclic. The selected edges need not include every original edge between retained vertices.
<!-- bilingual-en:end -->
设 $G=(V,E)$ 是有限[[图类型的建模边界|无向图]]，顶点集 $V\ne\varnothing$，边集为 $E$。**生成子图**写成 $T=(V,F)$，其中 $F\subseteq E$：顶点与原图相同，边则可以少选。若它还是[[无向树]]，即连通且无环，就称为生成树。保留了两个顶点，并不要求同时保留原图中连接它们的所有边。

> [!example] Remove a redundant edge · 删去一条多余的边
> <!-- bilingual-en:start -->
> Take $V=\{a,b,c,d\}$ and edges $ab,bc,ca,cd$, where $ab$ abbreviates the undirected edge $\{a,b\}$. The first three edges form a triangle. Removing $ca$ leaves the spanning tree $a-b-c-d$. Keeping only $a-b-c$ would omit $d$, so it would not span the original graph. Removing $cd$ instead would isolate $d$ and destroy connectedness.
> <!-- bilingual-en:end -->
>
> 取 $V=\{a,b,c,d\}$，边为 $ab,bc,ca,cd$，这里 $ab$ 简写无向边 $\{a,b\}$。前三条边形成三角形。删去 $ca$，就留下生成树 $a-b-c-d$。若只保留 $a-b-c$，会遗漏 $d$，不是原图的生成树；若改删 $cd$，则会孤立 $d$，破坏连通性。

<!-- bilingual-en:start -->
## Connectedness is exactly the condition
<!-- bilingual-en:end -->
*连通性正是充要条件*

> [!important] Spanning-tree existence · 生成树存在定理
> <!-- bilingual-en:start -->
> A finite nonempty undirected graph has a spanning tree **if and only if** it is [[无向图连通分量|connected]]: every pair of vertices can be joined by a path.
> <!-- bilingual-en:end -->
>
> 有限非空无向图存在生成树，**当且仅当**它[[无向图连通分量|连通]]，即任意两个顶点之间都有路径。

<!-- bilingual-en:start -->
**From a spanning tree to connectedness.** If $T=(V,F)$ is a spanning tree, any two vertices have a path in $T$. Since $F\subseteq E$, that same path is available in $G$. Thus $G$ is connected.
<!-- bilingual-en:end -->
**由生成树推出连通。** 若 $T=(V,F)$ 是生成树，任意两点在 $T$ 中都有路径。因为 $F\subseteq E$，同一路径也存在于 $G$，所以原图连通。

<!-- bilingual-en:start -->
**From connectedness to a spanning tree.** Start with the whole connected graph. If it contains a [[游走路径与环|cycle]], remove one edge of that cycle. The endpoints of the removed edge still have the rest of the cycle as a route between them. Any old route using that edge can take this detour instead; if repetitions occur, [[游走去环得到路径|deleting repeated portions of the walk]] gives a path with the same endpoints. Hence the deletion preserves connectedness and removes no vertices.
<!-- bilingual-en:end -->
**由连通构造生成树。** 从整张连通图开始。如果它含有[[游走路径与环|环]]，就删去环上的一条边。被删边的两个端点仍能沿环的其余部分连通；原先使用这条边的路线，可以改走这段绕行。若出现重复，[[游走去环得到路径|删去游走中的重复段]]，仍得到连接相同端点的路径。因此，删除保持连通性，也没有删去顶点。

<!-- bilingual-en:start -->
Repeat while a cycle remains. Every step decreases the finite number of edges by one, so the procedure terminates. Its result is connected, acyclic and still has all vertices: it is a spanning tree. In particular, the [[Forest 的边数公式|tree edge-count formula]] gives exactly $|V|-1$ retained edges. The proof does not assume that every graph with that many edges is connected.
<!-- bilingual-en:end -->
只要还有环就重复删除。每一步都使有限的边数减少一，因此过程必定终止。终点仍连通、不再含环，又保留全部顶点，正是一棵生成树。由[[Forest 的边数公式|树的边数公式]]，最终恰好保留 $|V|-1$ 条边；证明没有偷用“只要有这么多条边就连通”。

<!-- bilingual-en:start -->
The example starts with four vertices and four edges; one deletion leaves three edges. Different cycle-edge choices can produce different spanning trees. The theorem guarantees existence, not a unique choice.
<!-- bilingual-en:end -->
上例最初有四个顶点、四条边，删除一次后剩三条边。选择不同的环边删除，可能得到不同生成树。这个定理保证存在，并不保证选法唯一。

## Components and small boundary cases
<!-- bilingual-en:end -->
*连通分量与最小情形*

<!-- bilingual-en:start -->
Deleting edges can never create a path between different original [[无向图连通分量|components]]. A disconnected graph therefore has no spanning tree on all its vertices. Applying the theorem inside each component instead produces a [[森林|spanning forest with one tree per original component]]. Isolated vertices remain as one-vertex trees.
<!-- bilingual-en:end -->
删边不可能在原本不同的[[无向图连通分量|分量]]之间创造路径，因此不连通图没有覆盖全部顶点的一棵生成树。可以在每个分量内部应用定理，得到[[森林|每个原分量各有一棵树的生成森林]]；孤立顶点作为单点树保留。

<!-- bilingual-en:start -->
A single vertex needs no edges and is its own spanning tree. The empty vertex set is excluded here because the adopted tree definition requires a vertex. If the model permits loops or distinct parallel edges, use the cycle convention in [[无向树|the tree definition]]: a loop is a one-cycle and two parallel edges form a two-cycle. A loop may be deleted without changing reachability; one of two parallel edges can be removed while the other connects its endpoints. The same finite deletion proof therefore applies.
<!-- bilingual-en:end -->
单个顶点不需要边，本身就是自己的生成树。本卡排除空顶点集，因为采用的树定义要求至少一个顶点。若模型允许自环或可区分的平行边，则使用[[无向树|树定义中的环约定]]：自环是一环，两条平行边构成二环。删去自环不改变可达性；删去两条平行边之一，另一条仍连接相同端点。因此，同一个有限删边证明依然适用。

<!-- bilingual-en:start -->
A complete BFS or DFS from one root also supplies a [[搜索标记与父森林|parent tree]] for its reachable component. In this undirected setting it spans the whole graph exactly when the graph is connected. With several components, [[全图搜索与强连通边界|restarting full search]] gives a forest. Neither construction alone minimizes edge weights; that is the additional objective in the [[最小生成树的定义与唯一性|minimum spanning tree]] problem.
<!-- bilingual-en:end -->
从一个根完整执行 BFS 或 DFS，也能为它可达的分量提供[[搜索标记与父森林|父树]]。在这里的无向图中，它恰在原图连通时覆盖全图；多个分量则需要[[全图搜索与强连通边界|重启全图搜索]]，得到森林。这些构造本身没有最小化边权；那是[[最小生成树的定义与唯一性|最小生成树]]问题额外提出的目标。
