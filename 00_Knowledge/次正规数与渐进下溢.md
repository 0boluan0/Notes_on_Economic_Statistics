# 次正规数用渐进下溢填补最小正规数与零之间的空隙

<!-- bilingual-en:start -->
*Subnormal numbers provide gradual underflow between the smallest normal value and zero*
<!-- bilingual-en:end -->

> [!summary] 原子机制
> 正规数要求有效数有固定的非零前导位；若一直保持这个要求，最小正规数与 0 之间会留下巨大相对空隙。IEEE 754 次正规数（subnormal，早期也称 denormal）在最小指数处放松前导位要求，用固定的最小绝对间距继续逼近 0，这叫渐进下溢。
>
> <!-- bilingual-en:start -->
> Normal numbers require a fixed nonzero leading significand digit. Keeping that rule all the way down would leave a large relative gap between the smallest normal value and zero. IEEE 754 subnormal numbers (formerly also called denormals) relax the leading-digit rule at the minimum exponent and continue toward zero with the smallest fixed absolute spacing. This is gradual underflow.
> <!-- bilingual-en:end -->

渐进下溢保留了许多本来会被 flush-to-zero 的微小非零结果，并支持重要性质：在同一格式的有限数中，若 $x\ne y$，则精确舍入的 $x-y$ 不会仅因跨过正规边界而突然变成 0。它让误差随尺度更平滑，而不是在最小正规数处断崖式变化。
<!-- bilingual-en:start -->
Gradual underflow preserves many tiny nonzero results that flush-to-zero would discard. It supports the useful property that, for finite values in the same format, distinct $x$ and $y$ do not suddenly produce zero for $x-y$ merely because the normal boundary was crossed. Error behavior changes smoothly rather than falling off a cliff at the smallest normal value.
<!-- bilingual-en:end -->

代价是次正规数的有效位逐渐减少：绝对间距保持不变，但相对误差界随值接近 0 而恶化。某些硬件或性能模式会采用 flush-to-zero 或 denormals-are-zero；需要严格下溢语义时必须确认运行环境没有启用这类非渐进模式。
<!-- bilingual-en:start -->
The cost is gradually reduced significand precision: absolute spacing stays fixed, while relative error bounds worsen toward zero. Some hardware or performance modes use flush-to-zero or denormals-are-zero. Code that relies on gradual-underflow semantics must confirm that such modes are not enabled.
<!-- bilingual-en:end -->

> [!question]- 回忆与应用
> 次正规数为什么改善近零行为，却不能维持与正规数相同的相对精度？
>
> **答案：** 它用固定最小绝对步长填补到零的空隙；值越小，同一绝对步长占它的比例越大，因此相对精度下降。
