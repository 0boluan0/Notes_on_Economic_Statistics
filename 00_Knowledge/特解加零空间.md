# A particular solution plus the null space
<!-- bilingual-en:end -->
*一个特解加上零空间*

<!-- bilingual-en:start -->
Once one input produces the required output, every other solution is obtained by adding an input change that the matrix cannot detect. The first input gives a starting point; the [[零空间|null space]] gives all allowable changes. A **particular solution** means any one exact solution chosen as that starting point, not necessarily a unique or preferred answer.
<!-- bilingual-en:end -->

只要已有一个输入产生所需输出，其他全部解都能通过加上矩阵检测不到的输入变化得到。第一个输入提供起点，[[零空间]]提供全部允许的变化。**特解**就是任选的一个精确解，不意味着它唯一，也不意味着它比其他解更好。

<!-- bilingual-en:start -->
Consider the real system
<!-- bilingual-en:end -->

考虑实数域上的方程组

$$A=\begin{pmatrix}1&2&0\\0&0&1\end{pmatrix},\qquad
b=\begin{pmatrix}3\\4\end{pmatrix},\qquad
Ax=b.$$

<!-- bilingual-en:start -->
It asks for $x_1+2x_2=3$ and $x_3=4$. Taking $x_2=0$ gives one solution $x_p=(3,0,4)^T$. Here $p$ stands for “particular,” and $T$ denotes [[矩阵转置|transpose]]. The zero-output equation $Az=0$ instead gives $z_1+2z_2=0$ and $z_3=0$, so
<!-- bilingual-en:end -->

它要求 $x_1+2x_2=3$、$x_3=4$。取 $x_2=0$，得到一个解 $x_p=(3,0,4)^T$；下标 $p$ 代表 particular，上标 $T$ 表示[[矩阵转置|转置]]。零输出方程 $Az=0$ 则要求 $z_1+2z_2=0$、$z_3=0$，因此

$$N(A)=\left\{t\begin{pmatrix}-2\\1\\0\end{pmatrix}:t\in\mathbb R\right\}.$$

<!-- bilingual-en:start -->
Adding every such change gives
<!-- bilingual-en:end -->

把每种这样的变化都加到起点上，得到

$$x=x_p+t\begin{pmatrix}-2\\1\\0\end{pmatrix}
=\begin{pmatrix}3-2t\\t\\4\end{pmatrix},\qquad t\in\mathbb R.$$

<!-- bilingual-en:start -->
Every value of $t$ still satisfies both equations. Conversely, any solution must have $x_2=t$, forcing $x_1=3-2t$ and $x_3=4$, so the formula misses nothing. It describes an entire line in the three-dimensional input space.
<!-- bilingual-en:end -->

每个 $t$ 都仍然满足两个方程。反过来，任何解都可以把 $x_2$ 记成 $t$，随后只能有 $x_1=3-2t$、$x_3=4$，所以公式没有遗漏。它描述的是三维输入空间中的一整条直线。

> [!important] Translate the whole null space · 平移整个零空间
> <!-- bilingual-en:start -->
> Let $A\in\mathbb F^{m\times n}$, where $m,n$ are positive integers and $\mathbb F$ is a scalar field, and let $b\in\mathbb F^m$. Suppose the system is [[方程组解分类|consistent]], meaning at least one solution exists, and choose $x_p$ with $Ax_p=b$. Then
> <!-- bilingual-en:end -->
>
> 设 $A\in\mathbb F^{m\times n}$，其中 $m,n$ 为正整数，$\mathbb F$ 为标量域，$b\in\mathbb F^m$。假设系统[[方程组解分类|相容]]，即至少有一个解，并选取满足 $Ax_p=b$ 的 $x_p$，则
>
> $$\boxed{\{x:Ax=b\}=x_p+N(A)
> =\{x_p+z:z\in N(A)\}.}$$
>
> <!-- bilingual-en:start -->
> The plus sign between a vector and a set means “add this vector to every member of the set.” The matrix need not be square or invertible.
> <!-- bilingual-en:end -->
>
> 向量与集合之间的加号表示“把这个向量加到集合的每一个元素上”。矩阵不必是方阵，也不必可逆。

<!-- bilingual-en:start -->
## Why the description is exact
<!-- bilingual-en:end -->
*为什么恰好得到全部解*

<!-- bilingual-en:start -->
There are two inclusions to prove. First, every proposed input is a solution: if $z\in N(A)$, [[线性映射|linearity]] gives
<!-- bilingual-en:end -->

需要证明两个方向。首先，列出的每个输入都是解：若 $z\in N(A)$，由[[线性映射|线性性]]得到

$$A(x_p+z)=Ax_p+Az=b+0=b.$$

<!-- bilingual-en:start -->
Second, every actual solution is listed. If $Ax=b$, subtract the chosen solution:
<!-- bilingual-en:end -->

其次，每个真正的解都已列出。若 $Ax=b$，减去选定的特解：

$$A(x-x_p)=Ax-Ax_p=b-b=0.$$

<!-- bilingual-en:start -->
Thus $z=x-x_p$ lies in $N(A)$ and $x=x_p+z$. This proves both “no false solutions” and “no missing solutions.” It also proves that the difference between any two solutions lies in the null space. The same argument works for any linear map $T:V\to W$ over a common scalar field: a nonempty set of inputs with fixed output $w$ is $v_p+\ker T$, where $\ker T=\{v:Tv=0\}$ is the map’s null space.
<!-- bilingual-en:end -->

因此 $z=x-x_p$ 属于 $N(A)$，且 $x=x_p+z$。这同时证明“没有加入假解”和“没有漏掉真解”，也证明任意两个解之差都在零空间。相同论证适用于同一标量域上的任意线性映射 $T:V\to W$：若输出 $w$ 有原像，则全部原像为 $v_p+\ker T$，其中 $\ker T=\{v:Tv=0\}$ 就是映射的零空间。

<!-- bilingual-en:start -->
If $z_1,\ldots,z_d$ form a [[基|basis]] of $N(A)$, each null-space vector is a unique linear combination of them. The full solution can therefore be written
<!-- bilingual-en:end -->

若 $z_1,\ldots,z_d$ 是 $N(A)$ 的一组[[基]]，每个零空间向量都唯一写成它们的线性组合，因此完整解可以写成

$$x=x_p+t_1z_1+\cdots+t_dz_d,\qquad t_1,\ldots,t_d\in\mathbb F.$$

<!-- bilingual-en:start -->
Here $d$ is the [[零度|nullity]], the number of independent null-space directions. All $d$ coefficients must be allowed to vary to cover every solution. When $d=0$, the sum is empty and $x_p$ is the only solution. Finding merely some zero-output directions is insufficient unless they span the whole null space; [[RREF读取零空间基|reading a null-space basis from RREF]] supplies a systematic construction.
<!-- bilingual-en:end -->

这里 $d$ 是[[零度]]，即独立零空间方向的数量。要覆盖全部解，必须让这 $d$ 个系数都能变化。$d=0$ 时求和为空，只有 $x_p$ 这个解。只找到若干零输出方向还不够，除非它们张成整个零空间；[[RREF读取零空间基]]给出系统的构造方法。

## Geometry and the choice of starting point
<!-- bilingual-en:end -->
## 几何与边界

<!-- bilingual-en:start -->
The set $x_p+N(A)$ is an **affine translate**: a subspace shifted by a fixed vector. For $b=0$, the solution set is $N(A)$ itself and we may choose $x_p=0$. For $b\ne0$, a consistent solution set excludes the origin, because $A0=0\ne b$, so it is not a [[子空间|subspace]]. In the real example, the solution line has constant third coordinate $4$, while the parallel null-space line has third coordinate $0$.
<!-- bilingual-en:end -->

集合 $x_p+N(A)$ 是**仿射平移**，即把子空间整体移动一个固定向量。$b=0$ 时解集就是 $N(A)$，可取 $x_p=0$；$b\ne0$ 时，相容解集不包含原点，因为 $A0=0\ne b$，所以不是[[子空间]]。在实数例子中，解直线的第三坐标恒为 $4$，与之平行的零空间直线第三坐标则恒为 $0$。

<!-- bilingual-en:start -->
A different particular solution changes the starting point but not the set. If $x_q$ is also a solution, then $x_q-x_p\in N(A)$, and adding this null-space vector simply reparametrizes all null-space changes. In the example, $x_q=(1,1,4)^T=x_p+(-2,1,0)^T$. The description $x_q+s(-2,1,0)^T$ is the same line, with $t=s+1$.
<!-- bilingual-en:end -->

换一个特解，只改变起点，不改变集合。若 $x_q$ 也是解，则 $x_q-x_p\in N(A)$；多加上这个零空间向量，只是重新标记全部零空间变化。例中 $x_q=(1,1,4)^T=x_p+(-2,1,0)^T$，所以 $x_q+s(-2,1,0)^T$ 描述同一直线，两种参数满足 $t=s+1$。

> [!warning] The starting point has a fixed coefficient · 起点的系数不能任意变
> <!-- bilingual-en:start -->
> For a nonzero target, this is not the linear span of $x_p$ and $N(A)$. If $Ax_p=b$ and $Az=0$, then $A(\alpha x_p+z)=\alpha b$. For $b\ne0$, staying in the original solution set requires $\alpha=1$. The null-space part may vary freely, but scaling the starting point generally changes the target.
> <!-- bilingual-en:end -->
>
> 目标非零时，这不是 $x_p$ 与 $N(A)$ 的线性张成。若 $Ax_p=b$、$Az=0$，则 $A(\alpha x_p+z)=\alpha b$。当 $b\ne0$ 时，要仍解原方程，就必须有 $\alpha=1$。零空间部分可以自由变化，但缩放起点通常会改变目标。

<!-- bilingual-en:start -->
If the system is inconsistent, no $x_p$ exists and this description cannot start. If a candidate only approximately fits $b$, adding a null-space vector leaves its residual unchanged; it does not turn that candidate into an exact solution. Selecting a [[最小范数最小二乘解|minimum-norm least-squares solution]] is a separate task.
<!-- bilingual-en:end -->

若系统不相容，就没有 $x_p$，这个描述也无从开始。若某个候选输入只是近似拟合 $b$，加上零空间向量只会保持残差不变，不能把它变成精确解。选取[[最小范数最小二乘解]]属于另一项任务。
