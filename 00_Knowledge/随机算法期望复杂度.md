# 随机算法期望复杂度是在固定输入上对算法内部随机选择取成本期望

<!-- bilingual-en:start -->
*Randomized expected complexity averages over internal random choices on a fixed input*
<!-- bilingual-en:end -->

随机算法期望复杂度固定输入 $x$，把算法运行中的随机选择记为 $R$，对成本 $T(x,R)$ 取 $\mathbb E_R[T(x,R)]$。输入可以由对手选定；结论不要求输入本身随机。

<!-- bilingual-en:start -->
Randomized expected complexity fixes an input $x$ and averages $T(x,R)$ over the algorithm's internal random choices $R$. The input may be adversarial; it need not be randomly generated.
<!-- bilingual-en:end -->

若要按规模给出“最坏输入上的期望成本”，最大值存在时定义

<!-- bilingual-en:start -->
To report the expected cost on the worst input of each size, define, when the maximum exists,
<!-- bilingual-en:end -->

$$
T_{\mathrm{worst\text{-}exp}}(n)
=\max_{x\in I_n}\mathbb E_R[T(x,R)].
$$

这里先固定输入取期望，再比较输入。它不是 $\max_{x,R}T(x,R)$，也不是对输入分布求[[平均情况复杂度]]。期望上界允许某些随机运行很慢；它自身不承诺每次都快，也不自动给出同阶的高概率界。

<!-- bilingual-en:start -->
The expectation is taken before comparing inputs. This differs from $\max_{x,R}T(x,R)$ and from [[平均情况复杂度|averaging over an input distribution]]. An expected bound permits some slow random runs; it is neither a per-run guarantee nor automatically a high-probability bound of the same order.
<!-- bilingual-en:end -->

例如，每次在当前子问题内均匀随机选择 pivot 的快速排序，在固定的一组互异键上，比较次数的期望为 $O(n\log n)$；输入无需随机排列。这里的随机对象是各次 pivot 选择。该例用于识别期望的对象，实际实现仍须按[[算法成本模型]]计算选择 pivot、分区及其他操作。

<!-- bilingual-en:start -->
For example, quicksort choosing a uniform-random pivot in each current subproblem has expected $O(n\log n)$ comparisons on a fixed set of distinct keys without assuming random input order. The random objects are its pivot choices. An implementation must still account for pivot selection, partitioning and other work in its [[算法成本模型|cost model]].
<!-- bilingual-en:end -->
