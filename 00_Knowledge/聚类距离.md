# 聚类距离或相异度是对两个对象有多不相似的数值表达，它先于算法定义什么算接近
<!-- bilingual-en:start -->
*A clustering distance or dissimilarity numerically represents how unlike two objects are and defines what counts as close before the algorithm begins*
<!-- bilingual-en:end -->

> [!summary] 原子定义
> 给定两个已表示的对象 $x$ 和 $y$，聚类距离或相异度 $d(x,y)$ 用一个数值表示它们有多不相似，数值越小通常表示越接近。Euclidean 距离重视绝对坐标差，correlation dissimilarity 重视轮廓，Jaccard 距离重视共同出现而忽略共同缺席；所以“什么算接近”必须由数据类型与分析目的决定。
> <!-- bilingual-en:start -->
> For represented objects $x$ and $y$, a clustering distance or dissimilarity $d(x,y)$ gives a numerical account of how unlike they are, with smaller values usually meaning closer objects. Euclidean distance emphasises absolute coordinate differences, correlation dissimilarity profile shape, and Jaccard distance shared presences, so the choice must follow the data type and purpose.
> <!-- bilingual-en:end -->

## 常见度量回答不同问题

| 度量 | 主要在问什么 | 关键边界 |
|---|---|---|
| Euclidean $\lVert x-y\rVert_2$ | 两个连续向量在绝对坐标上相差多远 | 对 [[聚类尺度|尺度]] 和异常坐标敏感；是 K-means 与 Ward 平方和解释的几何基础 |
| Manhattan $\sum_j|x_j-y_j|$ | 各坐标绝对差累计多大 | 仍依赖尺度和坐标轴；不能直接塞进以均值和平方距离定义的 K-means |
| correlation dissimilarity $1-r(x,y)$ | 两个向量的相对起伏形状是否相似 | 会忽略整体平移和正比例缩放；常量向量的相关系数未定义，且该 dissimilarity 不必满足所有 metric 条件 |
| Jaccard distance $1-\frac{|A\cap B|}{|A\cup B|}$ | 两个二元对象共享了多少“出现” | 共同为 0 不计相似；当并集为空时需要预先规定处理方式 |

[[马氏距离]]还可按 covariance 方向重标几何，但它需要可靠的 covariance 估计；[[样本协方差秩边界|高维或精确共线]]会使样本尺度矩阵奇异，改用伪逆后在全空间中得到的只是[[奇异尺度马氏伪距离|伪度量]]。污染数据还会让估计本身不稳定。

## 距离还要与算法目标匹配

选定 $d$ 还没有完成方法定义：簇间 linkage 或优化目标决定算法怎样使用它。尤其 Ward 与 K-means 的平方和解释不能随任意 dissimilarity 一起原样保留；这个独立适用边界见 [[距离须匹配聚类算法]]。

> [!question]- 自检
> 两位用户对十种商品的购买曲线形状几乎相同，但一位在每种商品上都买得多十倍。Euclidean 与 correlation dissimilarity 会怎样看待这对用户？
>
> **答案：** Euclidean 会把绝对购买量差视为很大距离；correlation dissimilarity 会把相同的相对起伏视为高度相似。哪种判断合理取决于目标是区分消费规模还是消费偏好轮廓。
