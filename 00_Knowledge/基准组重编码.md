# 在保持同一完整类别模型时，更换基准组只重参数化系数，不改变拟合值、残差和可识别对比
<!-- bilingual-en:start -->
*For the same complete categorical model, changing the reference group reparameterizes coefficients without changing fitted values, residuals, or estimable contrasts*
<!-- bilingual-en:end -->

> [!summary] 不变的是模型，变化的是坐标
> 基准组决定系数从哪个组水平开始表达。只要新旧编码张成同一个设计列空间，更换基准组就是对系数作可逆线性变换：每个观测的拟合值和残差不变，任意可识别组间对比也不变；改变的是截距、单个系数及它们各自代表的零假设。
> <!-- bilingual-en:start -->
> The reference group determines the origin from which coefficients express category levels. If the old and new codings span the same design column space, changing the reference is an invertible coefficient transformation. Fitted values, residuals, and every estimable group contrast remain unchanged, while the intercept, individual coefficients, and their associated null hypotheses change.
> <!-- bilingual-en:end -->

以三组均值 $\mu_A,\mu_B,\mu_C$ 为例。以 A 为基准时，系数可写成
$$
(\beta_0,\beta_B,\beta_C)
=(\mu_A,\mu_B-\mu_A,\mu_C-\mu_A).
$$
改以 B 为基准，则变成
$$
(\tilde\beta_0,\tilde\beta_A,\tilde\beta_C)
=(\mu_B,\mu_A-\mu_B,\mu_C-\mu_B).
$$
两套系数不同，但重建出的三个 $\mu$ 完全相同。
<!-- bilingual-en:start -->
For group means $\mu_A,\mu_B,\mu_C$, A-reference coefficients are $(\mu_A,\mu_B-\mu_A,\mu_C-\mu_A)$, whereas B-reference coefficients are $(\mu_B,\mu_A-\mu_B,\mu_C-\mu_B)$. The coefficient vectors differ, but both reconstruct exactly the same three group means.
<!-- bilingual-en:end -->

有交互项时，这个边界更重要。换基准后，某个“主效应”系数的 $p$ 值可以变化，因为它现在检验另一基准层内的简单效应；这不是数据或整体模型改变，而是问题改变。若关心 B 与 C 的差、某一取值处的组差或整组因子，应直接构造相同的[[线性组合推断|目标对比]]，而不是把某个编码下的一行系数当成永恒对象。
<!-- bilingual-en:start -->
The distinction matters even more with interactions. A main-effect coefficient can acquire a different p-value after releveling because it now tests a simple effect within another reference level. The data and overall model did not change; the question did. For a B-versus-C difference, a group difference at a chosen value, or a factor-wide test, construct the same target contrast directly rather than treating one coding-dependent coefficient row as permanent.
<!-- bilingual-en:end -->

> [!question]- 自检
> 把学历基准从“高中”改成“本科”后，本科系数消失、截距变化。模型预测是否因此变了？
>
> **答案：** 没有。只要保留同一完整类别模型，各组预测和可识别差异不变；变化的是用哪组水平作坐标原点。

- Stata's factor-variable documentation verifies releveling within the same factor model. Its official interaction FAQ shows that coefficient-level tests change because their hypotheses change. The linked source-checked linear-combination atom supplies invariant contrast inference.
