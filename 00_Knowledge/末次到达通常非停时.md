# Last visit times and future information
<!-- bilingual-en:end -->

*末次到达与未来信息*

<!-- bilingual-en:start -->
A first visit can be recognized when it occurs. A **last visit before a deadline** is usually a retrospective choice: seeing a visit now does not tell us whether another visit will occur later. The distinction concerns the information needed to identify the selected time, not whether that time is numerically finite.
<!-- bilingual-en:end -->

首次到达可以在发生时认出来；**截止期限前的末次到达**通常是一种事后挑选：现在看到一次到达，还不能判断以后是否会再来一次。区别在于辨认所选时刻需要什么信息，而不在于这个时刻的数值是否有限。

<!-- bilingual-en:start -->
A [[停时定义|stopping time]] $L$ for a [[滤过定义|filtration]] $(\mathcal F_n)$ must satisfy $\{L\le n\}\in\mathcal F_n$ at every $n\ge0$. The question is “has the selected time already occurred?”, not “can I compute it after the entire experiment?”. The following four possible histories make the difference explicit.
<!-- bilingual-en:end -->

相对于[[滤过定义|滤过]] $(\mathcal F_n)$ 的[[停时定义|停时]] $L$，必须对每个 $n\ge0$ 满足 $\{L\le n\}\in\mathcal F_n$。要问的是“所选时刻是否已经发生”，而不是“等整场试验结束后能否把它算出来”。下面的四条可能历史把区别展示出来。

<!-- bilingual-en:start -->
## A two-period counterexample
<!-- bilingual-en:end -->

## 一个两期反例

<!-- bilingual-en:start -->
Let $\xi_1,\xi_2$ be [[相互独立|independent]] fair $0/1$ observations, so each pair has probability $1/4$. The [[自然滤过|natural filtration]] reveals them in order:
$$\mathcal F_0=\{\varnothing,\Omega\},\qquad
\mathcal F_1=\sigma(\xi_1),\qquad
\mathcal F_2=\sigma(\xi_1,\xi_2).$$
Here $\sigma(\cdots)$ is the event collection generated by the listed observations. For the fixed horizon two, define the last occurrence of $1$ by
$$L=\max\bigl(\{n\in\{1,2\}:\xi_n=1\}\cup\{0\}\bigr).$$
The added $0$ specifies a value when neither observation is $1$; it is a no-visit convention, not a claim that a visit occurred at zero.
<!-- bilingual-en:end -->

令 $\xi_1,\xi_2$ 是[[相互独立]]的公平 $0/1$ 观察，每一对结果的概率都是 $1/4$。[[自然滤过]]按顺序揭示两次结果，上式的 $\sigma(\cdots)$ 表示由所列观察生成的事件族。固定截止在第二期，按第二式定义最后一次出现 $1$ 的时刻。添入 $0$ 是为了在两期都不出现 $1$ 时仍有规定值，并不是说零时刻发生过访问。

> [!example] All four histories · 四条完整历史
> <!-- bilingual-en:start -->
> | $(\xi_1,\xi_2)$ | $L$ | Is $L\le1$? |
> |---|---:|---|
> | $(0,0)$ | $0$ | Yes |
> | $(0,1)$ | $2$ | No |
> | $(1,0)$ | $1$ | Yes |
> | $(1,1)$ | $2$ | No |
>
> At time one, $(1,0)$ and $(1,1)$ look identical: both have shown $\xi_1=1$. Yet the selected time has already occurred in the first history and has not in the second. No decision using only the first observation can tell them apart.
> <!-- bilingual-en:end -->
>
> 表中列出全部四条历史。时刻一，$(1,0)$ 与 $(1,1)$ 看起来完全一样，都只显示了 $\xi_1=1$；但第一条的末次时刻已经发生，第二条却还没有。只用第一次观察，不可能区分这两种判断。

<!-- bilingual-en:start -->
In event notation,
$$\{L\le1\}=\{\xi_2=0\}=\{(0,0),(1,0)\}.$$
But $\mathcal F_1$ contains only unions of the two observed-history groups $\{(0,0),(0,1)\}$ and $\{(1,0),(1,1)\}$. The displayed event splits both groups, so it is not in $\mathcal F_1$. Thus $L$ is not a stopping time. The pair with $\xi_1=1$ already proves the failure, so the conclusion is not caused merely by the no-visit convention.
<!-- bilingual-en:end -->

用事件记号写出 $\{L\le1\}=\{\xi_2=0\}$。但 $\mathcal F_1$ 只能由“第一次为零”和“第一次为一”这两个历史组取并，不能把每个组内部拆开。所示事件把两组都拆开，所以不属于 $\mathcal F_1$，$L$ 不是停时。仅比较第一次为一的两条历史就已经足够，因此问题并非只是由未访问时取零的约定造成。

<!-- bilingual-en:start -->
Here $0\le L\le2$ and $E[L]=(0+2+1+2)/4=5/4$. It is bounded and has finite mean, but still fails the information requirement. At the final deadline, $\{L\le2\}=\Omega$ is certainly known; passing that single final-time check cannot replace checking every earlier time. In contrast, the [[离散首次到达停时|first occurrence]] is a stopping time because “some hit has occurred by now” only examines the observed past.
<!-- bilingual-en:end -->

这里 $0\le L\le2$，而且 $E[L]=(0+2+1+2)/4=5/4$。它有界、期望有限，却仍不满足信息要求。到了最终期限，当然知道 $\{L\le2\}=\Omega$；通过这个末期检查，不能代替此前每个时刻的检查。相比之下，[[离散首次到达停时|首次出现]]是停时，因为“截至现在已经出现过”只需要观察已发生的历史。

<!-- bilingual-en:start -->
## Why “generally” matters
<!-- bilingual-en:end -->

## “通常”为什么必要

<!-- bilingual-en:start -->
This is not a theorem that every rule named “last” must fail. If the model guarantees $\xi_2=1$, the last occurrence before the fixed horizon is the deterministic time $L=2$, which is a stopping time. If both tosses are revealed at time zero, the original random $L$ also becomes a stopping time for that larger filtration: every event $\{L\le n\}$ is then already known. Changing the information changes the claim.
<!-- bilingual-en:end -->

这并不是说名字里带“最后”的规则全都不合格。如果模型保证 $\xi_2=1$，截止两期前的末次出现就是确定时刻 $L=2$，当然是停时。如果两次结果在零时刻就全部揭晓，原来的随机 $L$ 对那个更大的滤过也成为停时，因为每个 $\{L\le n\}$ 都已经可知。信息改变，结论也会改变。

<!-- bilingual-en:start -->
The finite horizon matters: “last visit by $N$” and “last visit over all future times” are different random quantities. For the latter, a last finite visit may not exist at all. Always specify the target, observation horizon, convention for no visit and reference filtration, then test the events $\{L\le n\}$. A retrospective time can still be useful for describing a completed path; it simply cannot be inserted into a theorem requiring a stopping time without further verification.
<!-- bilingual-en:end -->

有限期限也很重要：“截至 $N$ 的最后一次访问”与“整个未来中的最后一次访问”是不同的随机量，后一种甚至可能不存在有限的最后一次。因此，应先说明目标、观察期限、从未访问时的约定及参照滤过，再检验 $\{L\le n\}$。事后时刻仍可用于描述已完成路径，只是不能未经核验就代入要求停时的定理。
