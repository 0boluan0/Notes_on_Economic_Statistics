# 精确稠密注意力的二次计算量不要求把完整注意力矩阵存入显存
<!-- bilingual-en:start -->
*Exact dense attention's quadratic computation does not require storing the full attention matrix in device memory*
<!-- bilingual-en:end -->

[[稠密注意力二次成本|成对运算量随序列长度平方增长]]，不等于必须在显存中保存一个完整的 $n\times n$ 注意力矩阵。运算量问“计算了多少”，存储量问“哪些中间结果需要同时保留”；改变执行方式可以保留精确注意力结果，同时减少中间存储。

<!-- bilingual-en:start -->
[[稠密注意力二次成本|Quadratic pairwise computation]] does not require a complete $n\times n$ attention matrix to be stored in device memory. Computation counts the operations performed; memory counts the intermediates that must coexist. A different execution strategy can preserve exact attention while reducing intermediate storage.
<!-- bilingual-en:end -->

朴素执行 [[缩放点积注意力]] 时，通常先生成完整分数矩阵 $S$，再生成完整权重矩阵 $A$。只要把其中任意一个完整矩阵显式保存，每头就需要 $O(n^2)$ 个元素。

<!-- bilingual-en:start -->
A straightforward implementation of [[缩放点积注意力|scaled dot-product attention]] forms the complete score matrix $S$ and then the complete weight matrix $A$. Explicitly storing either full matrix requires $O(n^2)$ elements per head.
<!-- bilingual-en:end -->

FlashAttention 提供一个精确计算的反例：它分块读取 Q/K/V，并维护每行 softmax 所需的统计量和累计输出，避免把完整 $S/A$ 写入高带宽显存。其原论文 Theorem 1 在 $Q,K,V\in\mathbb R^{n\times d}$ 的设置下给出

$$
\text{FLOPs}=O(n^2d),
\qquad
\text{输入输出之外的额外存储}=O(n).
$$

<!-- bilingual-en:start -->
FlashAttention is a counterexample to the claimed memory necessity: it processes Q/K/V in blocks and maintains row-wise softmax statistics and accumulated outputs without writing full $S/A$ matrices to high-bandwidth device memory. The original paper's Theorem 1 gives the displayed computation and additional-memory bounds for $Q,K,V\in\mathbb R^{n\times d}$.
<!-- bilingual-en:end -->

这里的 $O(n)$ 是论文算法的**附加存储口径**；Q/K/V 和输出本身仍占 $O(nd)$，模型参数、其他层的激活与片上工作空间也需按各自口径统计。“精确”指计算同一个注意力算子，不承诺不同浮点运算顺序逐 bit 一致。

<!-- bilingual-en:start -->
The $O(n)$ bound uses the paper's **additional-storage convention**. Q/K/V and the output still occupy $O(nd)$; model parameters, other activations, and on-chip workspace require their own accounting. “Exact” means computing the same attention operator, not guaranteeing bitwise equality across floating-point operation orders.
<!-- bilingual-en:end -->

例如 $n=4$ 时有 16 个 query–key 配对；算法可以分块处理这些配对，而不让全部 16 个权重同时常驻显存。因此读到“显存随长度线性增长”时，仍需另查它是否减少了配对计算、改变了算子，以及统计的显存包含哪些对象。

<!-- bilingual-en:start -->
At $n=4$ there are 16 query–key pairs, but an algorithm can process them in blocks without keeping all 16 weights resident in device memory at once. A claim of linear memory therefore leaves separate questions: whether pairwise computation is reduced, whether the operator changes, and which objects the memory measurement includes.
<!-- bilingual-en:end -->
