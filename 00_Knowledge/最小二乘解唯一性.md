# Uniqueness of a least-squares solution
<!-- bilingual-en:end -->

*最小二乘解唯一性*

<!-- bilingual-en:start -->
A least-squares fit chooses both an output and coefficients that produce it. **Coefficient uniqueness** asks whether only one coefficient vector produces the best fit. These are different objects: if the output is $x_1+x_2$, then coefficients $(2,0)$ and $(1,1)$ both produce $2$. There is no way to distinguish those coefficients by looking at this output alone.
<!-- bilingual-en:end -->

最小二乘拟合既选出一个输出，也选择产生它的系数。**系数解唯一性**问的是：是否只有一组系数能产生最佳拟合？两者是不同对象：若输出为 $x_1+x_2$，系数 $(2,0)$ 与 $(1,1)$ 都产生 $2$，只看这个输出无法区分它们。

<!-- bilingual-en:start -->
## Several coefficient lists can give one fit
<!-- bilingual-en:end -->
## 最小例子

<!-- bilingual-en:start -->
Let $A=[1\ 1]$ and let the target be the scalar $b=2$. The [[线性最小二乘|least-squares objective]] is $(x_1+x_2-2)^2$. It reaches its smallest possible value, zero, whenever $x_1+x_2=2$. Thus $(2,0)^T$, $(1,1)^T$ and $(0,2)^T$ are all minimizers. The fitted output is always $2$, although the coefficient vectors differ.
<!-- bilingual-en:end -->

令 $A=[1\ 1]$，目标是标量 $b=2$。[[线性最小二乘]]目标为 $(x_1+x_2-2)^2$；只要 $x_1+x_2=2$，就达到可能的最小值零。因此 $(2,0)^T$、$(1,1)^T$ 和 $(0,2)^T$ 都是最优解。拟合输出始终是 $2$，但系数向量不同。

<!-- bilingual-en:start -->
Increasing $x_1$ by $t$ and decreasing $x_2$ by the same $t$ leaves the output unchanged. The direction $(1,-1)^T$ lies in the [[零空间|nullspace]] $N(A)=\{z:Az=0\}$: it is a coefficient change that the matrix sends to zero. This is the source of non-uniqueness.
<!-- bilingual-en:end -->

把 $x_1$ 增加 $t$、同时把 $x_2$ 减少 $t$，输出不会变。方向 $(1,-1)^T$ 属于[[零空间]] $N(A)=\{z:Az=0\}$：它是一种被矩阵映成零的系数变化。这就是不唯一的来源。

> [!important] The exact criterion · 精确判据
> <!-- bilingual-en:start -->
> Let $A\in\mathbb R^{m\times n}$ with positive integers $m,n$, and fix any $b\in\mathbb R^m$. The unconstrained problem $\min_x\|Ax-b\|_2^2$ has exactly one coefficient solution if and only if
> <!-- bilingual-en:end -->
>
> 设 $A\in\mathbb R^{m\times n}$，$m,n$ 为正整数，并固定任意 $b\in\mathbb R^m$。无约束问题 $\min_x\|Ax-b\|_2^2$ 恰有一个系数解，当且仅当
>
> $$
> N(A)=\{0\}
> \quad\Longleftrightarrow\quad
> \operatorname{rank}(A)=n.
> $$
>
> <!-- bilingual-en:start -->
> [[矩阵秩|Full column rank]] means that all $n$ columns are [[线性无关|linearly independent]]: only the all-zero coefficient list can cancel them. The criterion depends on $A$, not on which $b$ is chosen. If it holds, every target has a unique coefficient minimizer. If it fails, every target has infinitely many coefficient minimizers. In both cases the fitted vector and residual are unique.
> <!-- bilingual-en:end -->
>
> [[矩阵秩|满列秩]]表示全部 $n$ 列[[线性无关]]，只有全零系数才能抵消它们。这个判据取决于 $A$，而不是选了哪个 $b$。条件成立时，每个目标都只有一个系数最优解；条件不成立时，每个目标都有无穷多个系数最优解。两种情况下，拟合向量与残差都唯一。

<!-- bilingual-en:start -->
## Why the nullspace settles the question
<!-- bilingual-en:end -->
## 为什么秩决定系数而不决定拟合值

<!-- bilingual-en:start -->
Finite-dimensional least squares always has a minimizer; choose one and call it $\hat x$. The [[最佳逼近与正交残差|nearest-point theorem]] gives a unique fitted vector $p=A\hat x$. Any other minimizer $y$ must produce the same $p$, so $A(y-\hat x)=0$. Conversely, adding any $z\in N(A)$ leaves both the output and its error unchanged. Hence the complete solution set is
<!-- bilingual-en:end -->

有限维最小二乘总有最优解，选一个记为 $\hat x$。[[最佳逼近与正交残差|最近点定理]]给出唯一拟合向量 $p=A\hat x$。任意另一个最优解 $y$ 必须产生同一个 $p$，所以 $A(y-\hat x)=0$。反过来，加上任意 $z\in N(A)$，输出及其误差都不变。因此完整解集为

$$
\hat x+N(A)=\{\hat x+z:z\in N(A)\}.
$$

<!-- bilingual-en:start -->
When $N(A)=\{0\}$, only $\hat x$ remains. When the nullspace contains a nonzero $z$, every $\hat x+t z$, for real $t$, is another minimizer, giving infinitely many. In the opening example the solution set is $(1,1)^T+t(1,-1)^T$.
<!-- bilingual-en:end -->

若 $N(A)=\{0\}$，只剩 $\hat x$。若零空间含非零 $z$，则对每个实数 $t$，$\hat x+t z$ 都是最优解，因此有无穷多个。开头例子的解集就是 $(1,1)^T+t(1,-1)^T$。

<!-- bilingual-en:start -->
The [[最小二乘正规方程|normal equations]] give an equivalent matrix test. Their [[Gram矩阵正定判据|Gram matrix]] $G=A^TA$ satisfies $z^TGz=\|Az\|_2^2$. It is [[正定矩阵|positive definite]]—strictly positive on every nonzero $z$—exactly when no such $z$ is lost by $A$. It is then invertible, and the unique solution is
<!-- bilingual-en:end -->

[[最小二乘正规方程]]给出等价的矩阵判别。它的 [[Gram矩阵正定判据|Gram 矩阵]] $G=A^TA$ 满足 $z^TGz=\|Az\|_2^2$。恰好当 $A$ 不会抹去任何非零 $z$ 时，$G$ [[正定矩阵|正定]]，即在每个非零 $z$ 上二次型都严格为正。此时它可逆，唯一解为

$$\hat x=(A^TA)^{-1}A^Tb.$$

<!-- bilingual-en:start -->
If $A$ has dependent columns, the inverse in this formula does not exist. The least-squares problem still has minimizers; only this inverse formula fails. Over $\mathbb C$, use conjugate transpose $A^*$ and squared magnitudes. The same argument gives $\hat x=(A^*A)^{-1}A^*b$ under full column rank and the same nullspace description otherwise.
<!-- bilingual-en:end -->

若 $A$ 的列相关，这个公式中的逆不存在，但最小二乘仍有最优解，只是逆矩阵公式不能用了。复数情形使用共轭转置 $A^*$ 和模的平方；同一论证在满列秩时给出 $\hat x=(A^*A)^{-1}A^*b$，否则仍用相同的零空间形式描述解集。

<!-- bilingual-en:start -->
## Enough equations, and an extra selection rule
<!-- bilingual-en:end -->

*方程数量与额外选择规则*

<!-- bilingual-en:start -->
Having at least as many rows as columns, $m\ge n$, is necessary for full column rank but not sufficient: the square matrix $\begin{bmatrix}1&1\\1&1\end{bmatrix}$ still has duplicate columns. If $m<n$, unrestricted coefficients cannot be unique. At the opposite extreme, if $A=0$, every coefficient vector gives the same fit $0$ and residual $b$. These facts do not depend on whether the original equations happen to fit exactly.
<!-- bilingual-en:end -->

行数不少于列数，即 $m\ge n$，是满列秩的必要条件，但并不充分：方阵 $\begin{bmatrix}1&1\\1&1\end{bmatrix}$ 仍有重复列。若 $m<n$，无约束系数不可能唯一。另一个极端是 $A=0$：每个系数向量都给出拟合值 $0$ 和残差 $b$。这些结论不取决于原方程是否恰好能够精确拟合。

<!-- bilingual-en:start -->
A program may return one vector even when many minimize the residual. It may impose the additional rule of selecting the [[最小范数最小二乘解|least-squares solution with smallest coefficient norm]]. In the opening example,
<!-- bilingual-en:end -->

即使有多个系数都能最小化残差，程序仍可能只返回一个向量。它可能另加了“在最优解中选[[最小范数最小二乘解|系数范数最小者]]”的规则。在开头例子中，

$$\|(1+t,1-t)^T\|_2^2=(1+t)^2+(1-t)^2=2+2t^2,$$

<!-- bilingual-en:start -->
so this extra rule selects $(1,1)^T$. It does not make the original unqualified least-squares solution set a singleton. Likewise, uniqueness in exact arithmetic does not certify insensitivity to small changes; [[条件性与算法稳定性|conditioning]] is a separate issue. The regression version of the rank condition is [[满列秩与OLS唯一性|full column rank and OLS uniqueness]].
<!-- bilingual-en:end -->

所以额外规则选出 $(1,1)^T$，但原来没有附加规则的最小二乘解集并未变成单点。同样，精确算术中的唯一性不保证对微小变化不敏感，[[条件性与算法稳定性|条件性]]是另一件事。回归语境下的秩条件见[[满列秩与OLS唯一性]]。
