# 状态周期是所有可能返回时长的最大公约数
<!-- bilingual-en:start -->
*The period of a state is the greatest common divisor of all possible return lengths*
<!-- bilingual-en:end -->

> [!summary] 看所有回路长度
> 当正步回返集合非空时，状态 $i$ 的周期为
> $$d(i)=\gcd\{n\ge1:p_{ii}^{(n)}>0\}.$$
> 若不存在任何正步回返，这里约定周期未定义。对有回返的状态，$d(i)=1$ 称非周期；同一沟通类中的状态周期相同，因此不可约链可谈一个共同周期。
> <!-- bilingual-en:start -->
> When the set of positive return times is nonempty, the period is its greatest common divisor. Under the convention used here, the period is left undefined if no positive-time return is possible. Communicating states that admit returns have the same period, so an irreducible chain has a common period.
> <!-- bilingual-en:end -->

$p_{ii}>0$ 是非周期的方便充分条件，但不是必要条件；只要存在若干可能回返长度的最大公约数为 1 即可。只检查 $P^2$ 的一个元素也不是一般判据：例如回返长度可能为 3 与 4，周期仍为 1。

周期与非周期的常用类级结论默认讨论会回返的状态；不能把空集合的最大公约数静默当作 1。

> [!question]- 自检
> 已知某状态的所有可能回返时长都是偶数，而且 4 步和 6 步都可以返回。若这些回返时长的最大公约数为 2，周期是多少？若又发现 5 步也能返回呢？
>
> **答案：** 前者周期为 2；加入 5 步回返后，最大公约数变为 1，状态非周期。
