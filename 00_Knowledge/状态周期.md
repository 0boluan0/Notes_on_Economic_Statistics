# Period of a Markov state
<!-- bilingual-en:end -->
*状态周期：所有可能正回返步数的共同节拍*

<!-- bilingual-en:start -->
A state's **period** describes a restriction on the step numbers at which a Markov chain can return to that state. Imagine a chain forced to alternate between two states: $0\to1\to0\to1\to\cdots$. Starting at $0$, returns are possible at $2,4,6,\ldots$ steps, but never at an odd step. Its period is two. The question concerns which return lengths have positive probability, not how long one particular simulated visit lasted.
<!-- bilingual-en:end -->

一个状态的**周期**描述 Markov 链能在第几步返回该状态所受的限制。想象链被迫在两个状态间交替：$0\to1\to0\to1\to\cdots$。从 $0$ 出发，只能在 $2,4,6,\ldots$ 步返回，奇数步不能返回，所以周期为二。这里问的是哪些回返步数具有正概率，不是某次模拟实际上隔了多久才返回。

<!-- bilingual-en:start -->
Use a [[DTMC时间齐次转移核|time-homogeneous]] chain on a finite or countable state set. The [[DTMC转移复合|multistep probability]] $p_{ii}^{(n)}$ is the chance of being back at $i$ after $n$ steps when we start at $i$. A return need not be the [[n步转移非首达|first return]]: earlier visits are allowed.
<!-- bilingual-en:end -->

考虑有限或可数状态上的[[DTMC时间齐次转移核|时间齐次链]]。[[DTMC转移复合|多步转移概率]] $p_{ii}^{(n)}$ 是从 $i$ 出发，$n$ 步后又在 $i$ 的概率。这里的回返不要求是[[n步转移非首达|第一次返回]]，中间可以早已访问过。

> [!abstract] Positive return lengths and their gcd · 正回返步数及最大公约数
> <!-- bilingual-en:start -->
> Form the set $\mathcal R_i=\{n\ge1:p_{ii}^{(n)}>0\}$. If it is nonempty, define
> <!-- bilingual-en:end -->
>
> 先收集 $\mathcal R_i=\{n\ge1:p_{ii}^{(n)}>0\}$。若该集合非空，定义
>
> $$d(i)=\gcd\mathcal R_i.$$
>
> <!-- bilingual-en:start -->
> Here [[最大公因数|gcd]] means the greatest positive integer dividing **every** member of the set. This extends the same common-divisor idea from two integers to all possible return lengths. A state is **aperiodic** if $d(i)=1$, and periodic if $d(i)\ge2$. Zero steps are excluded: merely starting at $i$ is not a positive-time return.
> <!-- bilingual-en:end -->
>
> 这里的[[最大公因数|最大公约数]]指能整除集合中**每一个**步数的最大正整数，是把两个整数的共同因子概念用于全部可能回返步数。$d(i)=1$ 称为**非周期**，$d(i)\ge2$ 则为周期状态。零步不加入集合：一开始就在 $i$，不算正时刻回返。

<!-- bilingual-en:start -->
The set may be infinite, but its gcd is well-defined when it contains a positive integer: every common divisor must divide that integer, which has only finitely many positive divisors. The period need not equal the shortest return time. Nor does “period $d$” promise a return at time $d$; it says every possible return length is a multiple of $d$ and no larger integer divides them all.
<!-- bilingual-en:end -->

集合可以无穷，但只要含有一个正整数，最大公约数就有定义：所有公因子都必须整除那个整数，而它的正因子只有有限个。周期不一定等于最短回返步数。“周期为 $d$”也不保证第 $d$ 步就能返回；它说的是每个可能步数都是 $d$ 的倍数，而且不存在更大的共同正因子。

## Aperiodic without any self-loop
<!-- bilingual-en:end -->
*没有自环，也可以非周期*

<!-- bilingual-en:start -->
Consider states $0,1,2,3$. Move from $0$ to $1$, then from $1$ to $2$, with certainty. From $2$, move to $0$ or $3$ with probability $1/2$ each; from $3$, move to $0$ with certainty. Its row matrix is
<!-- bilingual-en:end -->

考虑状态 $0,1,2,3$：从 $0$ 必到 $1$，从 $1$ 必到 $2$；从 $2$ 以各 $1/2$ 的概率到 $0$ 或 $3$；从 $3$ 必到 $0$。行随机矩阵是

$$P=\begin{pmatrix}
0&1&0&0\\
0&0&1&0\\
1/2&0&0&1/2\\
1&0&0&0
\end{pmatrix}.$$

<!-- bilingual-en:start -->
Starting at $0$, the paths $0\to1\to2\to0$ and $0\to1\to2\to3\to0$ return in three and four steps, each with probability $1/2$. Any divisor of all return lengths must therefore divide both $3$ and $4$, so it can only be $1$. Hence $d(0)=1$, even though one-step and two-step returns are impossible and the matrix has no positive diagonal entry.
<!-- bilingual-en:end -->

从 $0$ 出发，路径 $0\to1\to2\to0$ 与 $0\to1\to2\to3\to0$ 分别用三步、四步返回，各有 $1/2$ 的概率。全部回返步数的公因子必定同时整除 $3$ 与 $4$，所以只能是 $1$。因此 $d(0)=1$，尽管一步、两步都不能返回，整个矩阵也没有正的对角元。

<!-- bilingual-en:start -->
A **self-loop** means $p_{ii}>0$, a positive chance to stay at $i$ for one step. It is a convenient sufficient condition for aperiodicity because $1\in\mathcal R_i$. The example shows it is not necessary. Finding two coprime positive return lengths already proves period one; finding two lengths with gcd greater than one does not settle the period unless other lengths have been ruled out.
<!-- bilingual-en:end -->

**自环**指 $p_{ii}>0$，也就是一步后仍停在 $i$ 有正概率。它是非周期性的方便充分条件，因为此时 $1\in\mathcal R_i$；上例说明它不是必要条件。找到两个互素的正回返步数就足以证明周期为一；若找到的两个步数的最大公约数大于一，还必须排除其他步数，才能确定周期。

## Empty return sets and communicating classes
<!-- bilingual-en:end -->
*不能返回的状态，以及沟通类*

<!-- bilingual-en:start -->
This course leaves the period **undefined** when $\mathcal R_i$ is empty. For instance, let state $0$ move to state $1$ with certainty and let $1$ be [[吸收状态|absorbing]], meaning it is never left. State $0$ has no positive-time return and no period under this convention; state $1$ has period one. Other texts may assign an empty-set value by convention, so check that convention before comparing statements. An empty set is not silently treated as period one here.
<!-- bilingual-en:end -->

本课程在 $\mathcal R_i$ 为空时，把周期记作**未定义**。例如，状态 $0$ 一步必到状态 $1$，而 $1$ 是进入后不再离开的[[吸收状态]]。状态 $0$ 没有正时刻回返，按这里的约定没有周期；状态 $1$ 的周期为一。有的教材另给空集合指定约定值，比较结论前要检查口径；这里不会把空集合静默当作周期一。

<!-- bilingual-en:start -->
States [[马氏链沟通类|communicate]] when each can reach the other along a positive-probability route. Distinct communicating states necessarily have positive return routes and [[沟通状态周期相同|have the same period]]. Thus an [[不可约链|irreducible chain]], whose states all communicate, has a common period. This is a class property, not a claim that every visit returns with probability one or that the class is [[闭沟通类|closed]] to exits. In a finite nonempty closed communicating class, returns are possible at every state, so the empty-return exception does not arise.
<!-- bilingual-en:end -->

若两个状态之间有双向的正概率路线，就称它们[[马氏链沟通类|互通]]。不同的互通状态必定存在正回返路线，而且[[沟通状态周期相同|周期相同]]。因此，所有状态互通的[[不可约链]]可以谈一个共同周期。这是类的性质，并没有声称每次都以概率一返回，也没有声称该类是没有出口的[[闭沟通类]]。在有限非空闭沟通类内，每个状态都有可能返回，因此不会遇到空回返集合的例外。

<!-- bilingual-en:start -->
Aperiodicity describes possible return timings. Convergence of distributions is a separate question: the usual [[有限链逐步收敛|finite-chain convergence theorem]] also assumes irreducibility, while general finite matrices use the [[Markov矩阵幂收敛判据|matrix-power criterion]]. Reading one or two entries of $P^2$ is not a substitute for the return-set or convergence conditions.
<!-- bilingual-en:end -->

非周期性描述的是可能返回的时间。分布是否收敛是另一问题：常用的[[有限链逐步收敛|有限链收敛定理]]还要求不可约，一般有限矩阵则使用[[Markov矩阵幂收敛判据]]。只检查 $P^2$ 的一两个元素，不能代替回返集合或收敛条件。

> [!question]- Check the missing information · 检查还缺什么
> <!-- bilingual-en:start -->
> If every possible return length is even and both $4$ and $6$ are possible, the period is $2$. If a five-step return is then found, the earlier “every length is even” claim was false and the actual period is $1$, since $\gcd(4,6,5)=1$.
> <!-- bilingual-en:end -->
>
> 若已证明所有可能回返步数都为偶数，且 $4$ 步、$6$ 步都可返回，周期就是 $2$。若随后发现还能五步返回，说明原先“全部为偶数”的判断不成立；实际周期为 $1$，因为 $\gcd(4,6,5)=1$。
