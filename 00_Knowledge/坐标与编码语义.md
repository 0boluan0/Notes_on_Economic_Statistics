# 坐标尺度、显示范围、基线与视觉通道会在数据不变时改变读者感知，因此必须显式标注并避免只靠颜色传义
<!-- bilingual-en:start -->
*Scale, range, baseline, and visual channels can change perception without changing data, so label them and never rely on colour alone*
<!-- bilingual-en:end -->

> [!summary] 图展示的是经过变换和编码的数据
> 读者看见的距离、斜率、面积和对比度由坐标变换、显示范围、基线及视觉通道共同决定。数据没有改变，不代表视觉命题没有改变；轴、单位、变换、截断和图例必须显式，类别区分还要有形状、线型或直接标签等非颜色线索。
> <!-- bilingual-en:start -->
> Perceived distance, slope, area, and contrast are jointly determined by coordinate transformation, display range, baseline, and visual channels. Unchanged data do not imply an unchanged visual claim. Axes, units, transformations, truncation, and legends must be explicit, and categorical distinctions need non-colour cues such as shape, line style, or direct labels.
> <!-- bilingual-en:end -->

## 尺度改变几何意义

在线性纵轴上，两值 $y_1,y_2$ 的视觉距离与差值

$$
\Delta=y_2-y_1
$$

成正比；在对数纵轴上，视觉距离与

$$
\log y_2-\log y_1=\log(y_2/y_1)
$$

成正比。因此线性轴突出绝对变化，对数轴突出倍数变化。对数轴要求正值。换底只会把对数坐标乘以正常数，重新缩放后相对几何不变；图必须明确这是对数轴并尽量以原始数据单位标刻度。只有直接展示数值化的 log 值，或刻度设计与特定底数绑定时，才需要另行注明底数。
<!-- bilingual-en:start -->
On a linear vertical axis, visual separation is proportional to the absolute difference $y_2-y_1$. On a logarithmic axis it is proportional to the log ratio $\log(y_2/y_1)$. Linear scales therefore foreground absolute change, while log scales foreground multiplicative change. A log scale requires positive values. Changing base multiplies all log coordinates by a positive constant, so relative geometry is unchanged after rescaling. The chart must identify the axis as logarithmic and should normally label ticks in the original data units; name the base separately only when displaying numerical log values or using base-specific ticks.
<!-- bilingual-en:end -->

例如序列 $10,20,40,80$ 在线性轴上的相邻差为 $10,20,40$，斜率不断变大；在以 2 为底的对数轴上，位置是 $\log_2 y$，相邻距离都为 1，显示恒定翻倍。两张图都可以正确，但回答的视觉问题不同。
<!-- bilingual-en:start -->
For $10,20,40,80$, successive absolute differences are $10,20,40$, so a linear plot steepens. On a base-2 log scale, successive positions differ by one and reveal constant doubling. Both displays can be correct, but they foreground different questions.
<!-- bilingual-en:end -->

## 显示范围与基线

若纵轴显示范围为 $[a,b]$，数据差 $d$ 大约占绘图区高度的比例是 $d/(b-a)$。缩窄范围会放大同一差异的视觉占比，扩大范围则会压缩它。对依赖长度表示大小的条形图，截断零基线会把条长比

$$
\frac{y_2}{y_1}
$$

改造成可见长度比

$$
\frac{y_2-a}{y_1-a},
$$

可能严重夸大相对大小。折线图主要编码位置与变化，未必总要从零开始，但必须显示完整刻度并避免把截断后的微小差异解释成巨大水平差异。
<!-- bilingual-en:start -->
If the displayed vertical range is $[a,b]$, a data difference $d$ occupies roughly $d/(b-a)$ of the plotting height. Narrowing the range magnifies the same difference visually. For bars, which encode magnitude by length, truncating the zero baseline changes the length ratio from $y_2/y_1$ to $(y_2-a)/(y_1-a)$ and can greatly exaggerate relative magnitude. Lines primarily encode position and change and need not always start at zero, but ticks and truncation must be visible and interpretation must remain proportional to the question.
<!-- bilingual-en:end -->

## 视觉通道必须有可读语义

位置通常支持精确比较；长度、角度、面积和颜色明度的可比较性不同。选择通道时还要区分：

- **类别：**用离散颜色、形状、线型或直接标签；颜色不应是唯一线索。
- **有序或定量值：**使用有序位置、长度或单调变化的明度；无序彩虹色可能因感知不均匀的明度变化制造虚假边界或掩盖真实顺序。
- **多序列：**图例名称必须对应变量，且在线条密集时优先直接标注或同时改变线型。
- **可访问性：**即使颜色视觉正常，灰度打印、投影、色觉差异或低对比度也可能让类别消失。

WCAG 的原则是：颜色不能作为传递信息、提示动作或区分元素的唯一视觉方式。最小修复通常不是新增一套复杂设计系统，而是给颜色再配一个可靠通道，例如实线/虚线、圆/三角 marker、文字标签或纹理。
<!-- bilingual-en:start -->
Position generally supports precise comparison, while length, angle, area, and luminance have different perceptual precision. Categorical values need discrete colours plus shape, line style, or direct labels. Ordered values need ordered positions, lengths, or monotone luminance; an unordered rainbow map can create false boundaries or hide real order through perceptually uneven luminance. Legends must identify variables, and dense multi-series displays benefit from direct labels or redundant line styles. WCAG requires that colour not be the only visual means of conveying information, prompting action, or distinguishing an element. The minimal remedy is a second dependable channel such as solid versus dashed lines, distinct markers, text labels, or patterns.
<!-- bilingual-en:end -->

> [!question]- 可核验自检
> 两个部门的完成率是 82% 和 84%。图表把纵轴设为 80%–85%，使用等长红线和绿线区分部门，但没有说明截断，也没有图例文字。数据是否错误？图是否合格？
>
> **答案：**数据值未必错误，但图的表达不合格。窄范围使 2 个百分点占据 40% 的绘图区高度，容易夸大差异；颜色还是唯一类别线索。应清楚显示轴范围和单位，按任务选择是否需要零基线，并给两个部门直接标签或同时使用不同线型/marker。
> <!-- bilingual-en:start -->
> The values need not be wrong, but the display is inadequate. The narrow range makes a two-percentage-point difference occupy 40% of the plotting height and can exaggerate it, while colour is the sole category cue. Show the range and units clearly, choose the baseline according to the task, and add direct labels or redundant line styles or markers.
> <!-- bilingual-en:end -->
