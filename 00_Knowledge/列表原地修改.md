# 列表的元素赋值与变异方法会修改同一对象而不是改绑名称
<!-- bilingual-en:start -->
*List item assignment and mutating methods change the same object rather than rebinding a name*
<!-- bilingual-en:end -->

> [!summary] 原子操作
> **a[i] = x**、切片赋值、**append**、**extend**、**insert**、**remove**、**clear**、**sort** 与 **reverse** 都作用于原列表。所有指向该列表的名称都会观察到变化。相反，**sorted(a)** 和 **a + b** 产生列表结果，是否让原名称指向它取决于后续赋值。

~~~python
a = [3, 1]
b = a
a.sort()
assert b == [1, 3]

c = a + [4]
assert c is not a
assert a == [1, 3]
~~~

多数没有独立结果要返回的原地方法返回 **None**，正是为了避免把“修改原对象”和“产生新值”混在一条表达式中。**pop** 是例外，因为它同时移除并返回一个具体元素。

切片赋值还可以改变列表长度：

~~~python
a[1:2] = [8, 9, 10]
~~~

遍历期间修改结构没有一种跨类型统一的结果。列表可能跳过或重复访问元素，字典的大小变化通常会报错；安全策略见 [[for与range]]，不要把某一种现象写成 Python 的普遍规则。

> [!question]- 自检
> 为什么函数名若叫 **sort_items**，仍应在文档中说明它是否原地排序？
>
> **答案：** 名称不能唯一确定副作用契约。调用者需要知道原列表会不会变化、返回值是什么，才能正确管理共享状态。
