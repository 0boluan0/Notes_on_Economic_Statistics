# Cost model
<!-- bilingual-en:end -->

*算法成本模型*

<!-- bilingual-en:start -->
A **cost model** is the rule for charging work to a computation. Before comparing two programs, decide whether you count comparisons, copied references, bit operations, or another resource. Two statements that each occupy one line of code can receive very different charges.
<!-- bilingual-en:end -->

**算法成本模型**是给计算工作计费的规则。比较程序之前，要先决定数比较次数、复制的引用数、位操作，还是别的资源。两条各占一行的代码，可能应收完全不同的成本。

<!-- bilingual-en:start -->
A cost model specifies the resource being measured, the primitive operations, and the cost charged to each. “One step” and “constant time” become meaningful only after the model and [[输入规模|input size]] are fixed. One source-code line may perform several operations or one operation whose cost grows with the input.
<!-- bilingual-en:end -->

算法成本模型规定分析中计量什么资源、把什么当作基本操作，以及每项操作收取多少成本。只有模型与[[输入规模]]明确后，“执行一步”或“常数时间”才有确定含义；一行程序可以包含多个操作或一次随输入增长的操作。

> [!example] One line can mean one access or many copies · 一行可以只访问一次，也可以复制许多项
> <!-- bilingual-en:start -->
> Let `L` contain eight entries. Under a random-access list model, `L[4]` reads one position. The slice `L[4:]` creates a new list containing four references. A slice of $k$ entries performs copying work proportional to $k$, written $\Theta(k)$ using [[大Θ记号|Theta notation]], in the stated model, even though the expression occupies one line. The stored objects need not themselves be copied recursively. See [[切片二分成本|slicing binary-search costs]] for the effect across several rounds.
> <!-- bilingual-en:end -->
>
> 设 `L` 有八个元素。在列表随机访问模型下，`L[4]` 读取一个位置；`L[4:]` 则创建一个含有四个引用的新列表。按所述模型，切出 $k$ 项的引用复制工作量与 $k$ 同阶，用[[大Θ记号]]写成 $\Theta(k)$，即使表达式只有一行，也不能当作只访问一个位置。引用指向的对象本身不必被递归复制；多轮累计的影响见[[切片二分成本]]。

<!-- bilingual-en:start -->
For example, a word-RAM with word length $w$ may charge $O(1)$ for its specified arithmetic, comparisons and memory accesses on a constant number of words. Addressing $n$ locations normally requires $w\ge\lceil\log_2 n\rceil$. This does not make multiplication of arbitrarily large integers a single constant-cost step. Python integers can grow in representation length; a bit-cost analysis must include that length and the corresponding arithmetic costs.
<!-- bilingual-en:end -->

例如，字长为 $w$ 的 word-RAM 模型可把模型规定的、作用于常数个机器字的算术、比较与内存访问计为 $O(1)$；寻址 $n$ 个位置通常要求 $w\ge\lceil\log_2 n\rceil$。这不意味着任意长整数乘法也只花一步。Python 整数的表示长度会增长；若按位操作计费，就必须把长度及相应算术成本纳入分析。

<!-- bilingual-en:start -->
The notation $O(1)$ means a bound independent of the declared input size under this model; see [[大O记号|Big-O notation]]. A machine word is a fixed-width block of bits within the chosen model. A constant number of words is different from an integer whose number of words keeps growing. The model must state which operations it permits at unit cost; choosing a model does not prove that every Python object fits its assumptions. Once the charges are fixed, [[循环成本求和|sum the work that actually executes]].
<!-- bilingual-en:end -->

在这个模型下，$O(1)$ 表示成本上界不随所声明的输入规模增长，参见[[大O记号]]。机器字是在选定模型中具有规定宽度的一块二进制位。“常数个机器字”与“占用机器字数量不断增长的整数”不同。模型要说明哪些操作按单位成本计费；选了一个模型，不等于证明每个 Python 对象都满足它。计费规则确定后，再按[[循环成本求和]]汇总真正执行的工作。

<!-- bilingual-en:start -->
Likewise, syntax alone does not make indexing, slicing, membership tests and resizing unit-cost operations. Copying a slice of $k$ fixed-size references takes $\Theta(k)$ copying work. List membership requires counting the examined elements and the cost of each equality test. Dynamic containers also require distinguishing a single operation's worst-case cost from [[摊还复杂度|amortized complexity]].
<!-- bilingual-en:end -->

同样，列表索引、切片、成员测试与扩容不能凭语法都记为一步。若切片复制 $k$ 个固定大小引用，其复制工作为 $\Theta(k)$；一次列表成员测试要计算实际检查了多少元素及每次相等比较的成本。动态容器还要区分单次操作的最坏成本与[[摊还复杂度]]。
