# Closure of a set
<!-- bilingual-en:end -->

*集合闭包*

<!-- bilingual-en:start -->
The **closure** of a set contains its existing points and every further point that cannot be separated from the set by a small open neighbourhood. On the real line, consider $A=(0,1)$. The point $0$ is missing from $A$, but every open interval around $0$ contains some positive number below $1$. The same is true at $1$. Adding these endpoints gives the closure $[0,1]$.
<!-- bilingual-en:end -->

一个集合的**闭包**包含原有点，还包含那些无法用小的开邻域与原集合隔开的点。先看实线上的 $A=(0,1)$：$0$ 虽然不在 $A$ 里，但每个包含 $0$ 的小开区间都含有小于 $1$ 的正数；$1$ 也有同样的性质。把两端补上，就得到闭包 $[0,1]$。

<!-- bilingual-en:start -->
Here “small neighbourhood” has a precise meaning. A [[拓扑|topology]] specifies the [[开集|open sets]] of an ambient space $X$. An **open neighbourhood of $x$** is simply an open set $U$ containing $x$. In a [[度量空间|metric space]], whose distance is $d$, it is enough to test open balls $B_r(x)=\{y\in X:d(x,y)<r\}$ for every radius $r>0$. Every open neighbourhood contains such a ball.
<!-- bilingual-en:end -->

这里“小邻域”有准确含义。[[拓扑]]规定环境空间 $X$ 中哪些集合是[[开集]]。$x$ 的**开邻域**就是一个包含 $x$ 的开集 $U$。在距离为 $d$ 的[[度量空间]]中，只需检查所有半径 $r>0$ 的开球 $B_r(x)=\{y\in X:d(x,y)<r\}$，因为每个开邻域都包含这样一个球。

> [!abstract] The neighbourhood test · 邻域判据
> <!-- bilingual-en:start -->
> For $A\subseteq X$, write its closure as $\operatorname{cl}_X A$, or $\overline A$ when the space is clear. Then
> $$x\in\operatorname{cl}_X A\quad\Longleftrightarrow\quad U\cap A\ne\varnothing\text{ for every open }U\ni x.$$
> The symbol $U\cap A\ne\varnothing$ says that the neighbourhood and the set have at least one point in common. The point of intersection may be $x$ itself; it need not be a different point.
> <!-- bilingual-en:end -->
>
> 对 $A\subseteq X$，将闭包写为 $\operatorname{cl}_X A$；环境清楚时也写 $\overline A$。上式要求每个包含 $x$ 的开集都与 $A$ 有交点。交点可以就是 $x$ 本身，不要求另找一个不同的点。

<!-- bilingual-en:start -->
Thus every point already in $A$ is in its closure. For example, the singleton $\{2\}$ is closed in the usual real line and its closure is still $\{2\}$. Closure does not require infinitely many nearby points. A point outside the closure, such as $2$ for $A=(0,1)$, has an open neighbourhood missing $A$ altogether, for example $(3/2,5/2)$.
<!-- bilingual-en:end -->

因此原本属于 $A$ 的点都在闭包内。例如通常实线中的单点集 $\{2\}$ 是闭集，其闭包仍为 $\{2\}$。属于闭包不要求附近存在无穷多个点。相反，对于 $A=(0,1)$，闭包外的点 $2$ 有完全避开 $A$ 的开邻域，例如 $(3/2,5/2)$。

## The smallest closed set containing the original set
<!-- bilingual-en:end -->

*包含原集合的最小闭集*

<!-- bilingual-en:start -->
The same object can be built from [[闭集|closed sets]], meaning sets with open complements. Intersect every closed set that contains $A$:
$$\operatorname{cl}_X A=\bigcap_{\substack{F\text{ closed in }X\\A\subseteq F}}F.$$
There is always at least one candidate, namely $X$. [[闭集运算|Arbitrary intersections of closed sets are closed]], and every candidate contains $A$. Their intersection is therefore closed and contains $A$. It lies inside every closed superset, which is exactly what “smallest” means here; this is inclusion, not a comparison of cardinalities.
<!-- bilingual-en:end -->

也可以从[[闭集]]构造同一个对象；闭集的意思是补集为开集。把所有包含 $A$ 的闭集取交，就得到上式。候选集合至少有整个 $X$；[[闭集运算|任意个闭集的交仍闭]]，每个候选又都包含 $A$，所以交集闭且包含 $A$。它还包含于每个闭超集，这正是“最小”的含义：比较包含关系，不是比较元素数量。

<!-- bilingual-en:start -->
To see why the two descriptions agree, first suppose an open neighbourhood $U$ of $x$ misses $A$. Then $X\setminus U$ is a closed superset of $A$ that excludes $x$, so $x$ cannot belong to the intersection. Conversely, if $x$ is absent from that intersection, some closed superset $F$ excludes it; the open neighbourhood $X\setminus F$ then misses $A$. Both tests therefore reject exactly the same points.
<!-- bilingual-en:end -->

两种描述为何一致？若 $x$ 的某个开邻域 $U$ 完全避开 $A$，则 $X\setminus U$ 是包含 $A$ 却不含 $x$ 的闭集，所以 $x$ 不在所有候选的交中。反过来，若 $x$ 不在交中，就有某个闭超集 $F$ 排除了它；于是开邻域 $X\setminus F$ 避开 $A$。两种判据排除的点完全相同。

<!-- bilingual-en:start -->
In particular, $A$ is closed exactly when $A=\operatorname{cl}_X A$. Taking closure a second time adds nothing, because the first closure is already closed. The empty set has empty closure, and the whole space has closure $X$.
<!-- bilingual-en:end -->

特别地，$A$ 是闭集，当且仅当 $A=\operatorname{cl}_X A$。第一次闭包已经闭，因此再取一次不会增加点。空集的闭包为空集，整个空间的闭包就是 $X$。

> [!example] Closure can fill much more than endpoints · 闭包可能补上远不止端点
> <!-- bilingual-en:start -->
> Let $\mathbb Q$ be the rational numbers, the numbers expressible as fractions of integers. Every nonempty open interval in $\mathbb R$ contains a rational: a sufficiently fine grid with spacing $1/n$ places an integer multiple of $1/n$ inside it. Hence every real number passes the neighbourhood test, and $\operatorname{cl}_{\mathbb R}\mathbb Q=\mathbb R$. An endpoint-only picture would miss this example.
> <!-- bilingual-en:end -->
>
> 令 $\mathbb Q$ 表示有理数，即可写成整数分数的数。实线中每个非空开区间都含有有理数：把间距 $1/n$ 的网格取得足够细，就有某个 $1/n$ 的整数倍落入区间。因此每个实数都通过邻域检验，$\operatorname{cl}_{\mathbb R}\mathbb Q=\mathbb R$；只想象“补端点”就无法解释这个例子。

## Keep the ambient space visible
<!-- bilingual-en:end -->

*不要省略环境空间*

<!-- bilingual-en:start -->
Closure adds only points that belong to the ambient space. For $A=(0,1)$ inside $Y=(0,2)$ with its [[子空间拓扑|subspace topology]], the closure is $(0,1]$, because $0$ is not even a point of $Y$. In the ambient real line it is $[0,1]$. In a metric space, [[闭包的序列判别|convergent sequences from the set also detect closure]]; that is a useful additional criterion, not an unrestricted replacement for the neighbourhood definition in every topological space.
<!-- bilingual-en:end -->

闭包只能加入环境空间中已有的点。把 $A=(0,1)$ 放在带[[子空间拓扑]]的 $Y=(0,2)$ 中，其闭包是 $(0,1]$，因为 $0$ 根本不是 $Y$ 中的点；放在实线中则为 $[0,1]$。度量空间内还可用[[闭包的序列判别|集合内的收敛序列探测闭包]]，但不能在所有拓扑空间中无条件地用它替代邻域定义。
