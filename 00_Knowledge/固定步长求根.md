# 固定步长求根在有界区间按固定间隔枚举网格点并以残差容差验收候选
<!-- bilingual-en:start -->
*Fixed-step root search enumerates equally spaced grid points on a bounded interval and accepts candidates by a residual tolerance*
<!-- bilingual-en:end -->

> [!summary] 它是什么
> 固定步长求根先给定搜索区间 $[a,b]$、步长 $h>0$ 和残差容差 $\tau>0$，再从 $a$ 开始按间隔 $h$ 生成有限网格，并依次检查 $|f(x)|\le\tau$。第一个通过检查的网格点就是一个可接受候选；若网格耗尽仍无候选通过，算法必须返回明确的“未命中”状态。
>
> <!-- bilingual-en:start -->
> Fixed-step root search specifies an interval $[a,b]$, a step $h>0$, and a residual tolerance $\tau>0$, generates a finite grid from $a$ at spacing $h$, and checks $|f(x)|\le\tau$ point by point. The first grid point that passes is an acceptable candidate; if the grid is exhausted without one, the algorithm must return an explicit no-hit status.
> <!-- bilingual-en:end -->

## 搜索对象是有限网格

按“从 $a$ 起步且不越过 $b$”的约定，候选集合是

$$
G_h
=
\left\{
a+jh:
j=0,1,\ldots,
\left\lfloor\frac{b-a}{h}\right\rfloor
\right\}.
$$

对每个 $x\in G_h$ 计算 [[求根残差|残差]] $|f(x)|$。若它不超过 $\tau$，算法返回 $x$；否则继续到下一个网格点。这个输出说明候选代回方程后的缺口不超过 $\tau$，并不自动说明它离真根多近；把残差换成位置误差需要 [[残差控制根误差|额外条件]]。

<!-- bilingual-en:start -->
With the convention that the scan starts at $a$ and never steps beyond $b$, its candidate set is $G_h=\{a+jh:0\le j\le\lfloor(b-a)/h\rfloor\}$. At each grid point it evaluates the [[求根残差|residual]] $|f(x)|$ and returns the first value no larger than $\tau$. This certifies a small equation defect, not automatically a small distance to a true root; [[残差控制根误差|additional conditions]] are required for that conversion.
<!-- bilingual-en:end -->

一个最小例子是求 $x^2-2=0$，取 $[a,b]=[0,2]$、$h=0.1$、$\tau=0.05$。扫描到 $x=1.4$ 时，

$$
|1.4^2-2|=0.04\le0.05,
$$

所以返回 $1.4$ 及“满足残差容差”的状态。它不是精确根；本方法返回的是按既定规则验收的网格候选。

<!-- bilingual-en:start -->
For a minimal example, solve $x^2-2=0$ on $[0,2]$ with $h=0.1$ and $\tau=0.05$. At $x=1.4$, the residual is $|1.4^2-2|=0.04\le0.05$, so the method returns $1.4$ with a residual-tolerance success status. It is not the exact root; it is the grid candidate accepted by the stated rule.
<!-- bilingual-en:end -->

## 步长同时控制网格密度和成本

候选数量为

$$
N_h
=
\left\lfloor\frac{b-a}{h}\right\rfloor+1.
$$

若每个候选只需要一次函数求值和一次残差比较，最坏情形需要 $N_h$ 次函数求值，成本为 $O(N_h)$。在区间固定时把 $h$ 大致减半，候选数和最坏求值成本大致翻倍。步长决定在哪里看，容差决定看到什么时算成功；两者不是同一个参数。

<!-- bilingual-en:start -->
The grid contains $N_h=\lfloor(b-a)/h\rfloor+1$ candidates. If each candidate requires one function evaluation and one residual comparison, the worst case costs $N_h$ evaluations, or $O(N_h)$ work. On a fixed interval, roughly halving $h$ roughly doubles both grid density and worst-case cost. The step determines where the algorithm looks; the tolerance determines what counts as acceptance.
<!-- bilingual-en:end -->

若 $f$ 本身昂贵，函数求值会主导成本。若用浮点数反复执行 `x += h`，累计舍入还可能让实际候选偏离理想的 $a+jh$。实现时宜按索引构造候选，或至少用明确的区间边界和求值上限控制循环，而不是等待浮点值精确等于 $b$。

## 输入、成功状态和失败出口共同构成规格

一次可复现的固定步长搜索至少要说明：

- 搜索范围 $[a,b]$，以及为何目标根值得在此处寻找；
- 正步长 $h$ 与残差容差 $\tau$；
- 返回第一个可接受点，还是收集全部可接受网格点；
- 网格耗尽、达到求值上限、越出函数定义域或出现 NaN/overflow 时返回什么状态。

<!-- bilingual-en:start -->
A reproducible fixed-step search specifies the interval and why the target root is sought there, the positive step and residual tolerance, whether it returns the first acceptable point or all acceptable grid points, and explicit statuses for grid exhaustion, an evaluation cap, domain escape, or non-finite values.
<!-- bilingual-en:end -->

“网格耗尽”只说明这些网格点没有通过验收，不能直接解释成“区间内没有根”。这种独立失效边界及其反例属于 [[固定步长漏根]]；统一的成功证据、工作上限和异常出口见 [[数值迭代停止条件]]。若函数连续且已经找到端点异号区间，[[二分求根]] 可以改用每轮都保留根存在证书的括区间不变量。

<!-- bilingual-en:start -->
Grid exhaustion means only that none of the inspected grid points passed the acceptance rule; it does not establish that the interval contains no root. The independent failure boundary and counterexample belong to [[固定步长漏根|fixed-step grid miss]], while [[数值迭代停止条件|numerical stopping criteria]] owns the general success evidence, work limits, and exceptional exits. For a continuous function with a sign-changing bracket, [[二分求根|bisection root-finding]] can instead maintain a root-existence certificate at every iteration.
<!-- bilingual-en:end -->

> [!question]- 自检
> 在固定区间 $[a,b]$ 上把 $h$ 减半但保持 $\tau$ 不变，算法的候选与验收规则分别怎样变化？
>
> **答案：** 网格大致加密一倍，最坏函数求值次数也大致翻倍；每个候选仍由同一个条件 $|f(x)|\le\tau$ 验收。网格更密提高命中机会，但是否一定命中仍需额外条件，不能只由“减半”推出。
>
> <!-- bilingual-en:start -->
> On a fixed interval, what changes when $h$ is halved while $\tau$ is unchanged?
>
> **Answer:** The grid becomes roughly twice as dense and the worst-case number of evaluations roughly doubles, while every candidate is still tested by $|f(x)|\le\tau$. Denser sampling improves the chance of a hit, but a guaranteed hit still requires additional assumptions.
> <!-- bilingual-en:end -->
