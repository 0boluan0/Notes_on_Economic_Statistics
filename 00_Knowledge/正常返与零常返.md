# 正常返要求有限平均返回时间而零常返只在无限状态边界出现
<!-- bilingual-en:start -->
*Positive recurrence requires a finite mean return time; null recurrence is a countably infinite-state boundary phenomenon*
<!-- bilingual-en:end -->

> [!summary] 常返再分两类
> 对常返状态 $i$，若 $E_i\tau_i^+<\infty$，称**正常返**（positive recurrent）；若 $E_i\tau_i^+=\infty$，称**零常返**（null recurrent）。同一沟通类中的状态类型一致。
> <!-- bilingual-en:start -->
> A recurrent state is positive recurrent when its expected return time is finite and null recurrent when that expectation is infinite. States in one communicating class share the same type.
> <!-- bilingual-en:end -->

有限不可约链中所有状态都正常返，所以零常返只会在无限状态空间出现。整数 $\mathbb Z$ 上的对称随机游走以概率一返回原点，却有无限平均返回时间，是零常返的典型反例；不能把“必回来”误写成“平均很快回来”。

> [!question]- 自检
> $\Pr_i(\tau_i^+<\infty)=1$ 是否足以推出 $E_i\tau_i^+<\infty$？
>
> **答案：** 不足。零常返状态会以概率一返回，但平均返回时间无限。
