# 贷款创造存款与银行仍需稳定融资并不矛盾
*Banks can create deposits through lending and still need stable funding*

> [!summary] 边界
> “贷款创造存款”解释贷款发放瞬间的会计分录；“银行需要融资”解释新存款可能外流后，银行如何持续持有贷款资产并满足结算与到期付款。两句话处在不同时间点，没有矛盾。

贷款发放时，新增存款本身就是银行的一笔负债融资。但借款人通常很快花掉它，始发银行可能失去存款和准备金，只留下期限较长的贷款资产。它于是要留住或吸收客户存款、发行批发债务、借同业资金、出售资产，或在条件允许时向央行融资。

## 例子

甲银行发放十年期按揭 100，购房款流入乙银行。跨行结算后，甲的借款人存款负债减少 100、准备金流出 100，却保留十年期贷款资产。若甲用隔夜同业借款补充结算资产，短期内账能平，但面临续作和利率风险；若吸收一年期定期存款或发行长期债务，融资更稳定但成本可能更高。

全体系同时扩贷时，各行既失去自己创造的存款，也可能收到别行贷款带来的存款，因此净融资缺口不会简单等于贷款额。但每家银行仍要管理实际付款流、期限错配和集中撤资风险。

> [!question]- 自检
> 银行既能在放贷时创造存款，为什么还会竞相吸收存款？
>
> **答案：** 新存款可能随客户付款流向别行；吸收稳定负债能替换流失的结算资金，并降低期限与再融资风险。
