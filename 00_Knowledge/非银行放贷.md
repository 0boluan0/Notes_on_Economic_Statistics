# 非银行放贷通常转移既有银行存款而不以同一分录创造银行存款
*Non-bank lending usually transfers existing bank deposits rather than creating them in the same entry*

> [!summary] 部门边界
> 非银行贷款人向借款人放款时，通常要求自己的银行把存款转给借款人：贷款人的存款减少、借款人的存款增加，商业银行存款总量不变。只有存款类机构能在同一贷款分录中以自己的新存款负债支付。

## 例子

基金向企业贷款 100，并从基金在甲银行的账户转到企业在乙银行的账户。基金取得贷款资产，企业承担债务；基金存款 -100、企业存款 +100，合并银行体系存款不变。若甲银行先向基金提供一笔新贷款，银行那一段会创造存款；基金再转贷只是后续信用链，不能把两步都归为“影子银行凭空创造银行存款”。

非银行可以发行 MMF 份额、电子货币、回购或其他近似货币的负债，也可以进行期限与流动性转换。这些工具的货币统计身份不能只凭名称判断：欧元区把统计上的 MMF 纳入 MFI 发行部门，其份额进入 M3；符合条件的电子货币机构也可列入 MFI，其预付电子货币余额按隔夜存款统计。美国 M2 纳入零售 MMF 份额但扣除其中的 IRA/Keogh 退休账户余额，并排除机构 MMF。即使被某一广义货币口径纳入，这些负债也不因此变成商业银行存款，其保障、赎回与结算结构仍需分开。“非银不能用同一分录创造银行存款”不等于“非银不创造信用或流动性风险”。

> [!question]- 自检
> 贷款公司把自己账户中的 50 转给客户，为什么客户存款增加却没有形成 50 的银行存款净增量？
>
> **答案：** 贷款公司的存款同时减少 50；银行只是把既有负债换了持有人。
