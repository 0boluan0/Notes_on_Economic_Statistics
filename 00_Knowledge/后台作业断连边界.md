# 后台运行不保证断开终端后存活而nohup与disown只处理特定挂断路径
<!-- bilingual-en:start -->
*Background execution does not guarantee survival after terminal disconnection; nohup and disown address specific hangup paths.*
<!-- bilingual-en:end -->

`&` 只安排异步／后台执行，不自动隔离终端、保存工作或保证父会话结束后继续运行。Bash 收到 `SIGHUP` 退出时，交互 shell 会向作业转发挂断信号；正常退出时的行为还受登录方式、`huponexit` 等条件影响，不能概括为“关窗口后台程序一律死亡”。
<!-- bilingual-en:start -->
`&` requests asynchronous or background execution; it does not isolate terminal I/O, save work, or guarantee survival after the parent session ends. An interactive Bash exiting on `SIGHUP` forwards hangups to jobs. Behavior on ordinary exit also depends on login mode and options such as `huponexit`, so closing a window does not imply one unconditional outcome for every background program.
<!-- bilingual-en:end -->

`nohup command` 让新命令继承忽略 `SIGHUP` 的处置，并按工具规则处理终端输出；它自身不等于添加 `&`。Bash 的 `disown` 移除作业表条目，`disown -h` 标记不由该 shell 转发 `SIGHUP`；它们不自动改接已经打开的终端输入输出。
<!-- bilingual-en:start -->
`nohup command` gives the new command an ignored `SIGHUP` disposition and handles terminal output according to its rules; it is not itself an added `&`. Bash `disown` removes a job-table entry, while `disown -h` prevents that shell from forwarding `SIGHUP` to the marked job. Neither automatically reconnects existing terminal input and output.
<!-- bilingual-en:end -->

程序可以改变继承的信号处置，其他信号、管理员策略、资源耗尽或主机重启也能结束任务。需要可重新连接的交互工作区时考虑[[终端复用]]，但仍应分别验证任务完成与[[tmux会话保持边界|会话保持条件]]。
<!-- bilingual-en:start -->
A program may change its inherited signal disposition, and other signals, administrative policies, resource exhaustion, or a host reboot can still end it. For a reconnectable interactive workspace consider [[终端复用|terminal multiplexing]], while separately checking task completion and [[tmux会话保持边界|session-survival conditions]].
<!-- bilingual-en:end -->

## 来源与核验

[GNU Bash Manual §3.7.6, Signals](https://www.gnu.org/software/bash/manual/html_node/Signals.html) 与本机 `bash(1)` SIGNALS、`help disown`：核对转发、`huponexit`、移除作业和 `-h` 的区别。
<!-- bilingual-en:start -->
[GNU Bash Manual §3.7.6: Signals](https://www.gnu.org/software/bash/manual/html_node/Signals.html), installed `bash(1)`, and `help disown` support forwarding, `huponexit`, job removal, and `-h`.
<!-- bilingual-en:end -->

[OpenBSD nohup(1)](https://man.openbsd.org/nohup.1)：支持忽略 HUP 后执行及终端输出重定向；这不构成所有故障下的持久运行保证。
<!-- bilingual-en:start -->
[OpenBSD nohup(1)](https://man.openbsd.org/nohup.1) supports execution with ignored HUP and terminal-output redirection, not durability under every failure.
<!-- bilingual-en:end -->
