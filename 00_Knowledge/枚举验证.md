# 枚举验证系统生成候选并用同一谓词逐一检验
<!-- bilingual-en:start -->
*Exhaustive enumeration systematically generates candidates and tests each one with the same predicate*
<!-- bilingual-en:end -->

> [!summary] 它是什么
> 枚举验证先明确一个有限候选集合 $C$ 和判断规则 $P$，再系统生成其中每个候选，并对每个候选运行同一个谓词。若只求任意一个解，就返回第一个满足 $P(c)$ 的候选；若全部候选都不满足，就报告“这个候选集合内没有解”。
> <!-- bilingual-en:start -->
> Exhaustive enumeration first specifies a finite candidate set $C$ and a validity predicate $P$, then generates every candidate systematically and applies the same predicate to each one. If any solution is enough, it returns the first $c$ satisfying $P(c)$; if every candidate fails, it reports that no solution exists inside this candidate set.
> <!-- bilingual-en:end -->

## 完备性需要候选空间、生成器和检验规则同时成立

设候选集合为

$$
C=\{c_1,c_2,\ldots,c_N\},
$$

目标是找一个满足 $P(c)=\mathrm{true}$ 的候选。基本算法是：

```text
for c in C:
    if P(c):
        return c
return not_found
```

“完备”依赖三个条件：$C$ 覆盖题目允许的全部候选；循环确实能在有限时间内访问每个 $c\in C$；$P$ 对每个候选的判断正确。若只要求找到任意一个解，遇到第一个通过者即可返回；若要列出全部解，就必须继续到候选耗尽。

<!-- bilingual-en:start -->
Let $C=\{c_1,\ldots,c_N\}$ be the candidate set and let $P(c)$ test whether a candidate is valid. Completeness requires three things at once: $C$ covers every eligible candidate, the generator visits every element of $C$ in finite time, and $P$ is correct. Returning at the first success finds one solution; listing every solution requires continuing until the set is exhausted.
<!-- bilingual-en:end -->

最坏情形下，找到最后一个解或证明“没有候选通过”都需要 $N$ 次检验。若生成一个候选和检验它的成本分别至多为 $T_G$ 与 $T_P$，总成本为

$$
O\!\left(N(T_G+T_P)\right).
$$

因此 exhaustive enumeration 的优点是覆盖保证，不是效率保证。缩小候选空间、避免重复生成或从约束推出部分变量，会减少成本，但不能以漏掉合法候选为代价。

<!-- bilingual-en:start -->
In the worst case, finding the last solution or establishing that none exists takes $N$ tests. If generation and testing cost at most $T_G$ and $T_P$ per candidate, the total cost is $O(N(T_G+T_P))$. Exhaustive enumeration guarantees coverage, not speed; pruning is valid only when it cannot remove a feasible solution.
<!-- bilingual-en:end -->

连续区间上的 [[固定步长求根]] 只是把问题改成有限网格枚举；它不能由本卡的有限集合结论推到整个实数区间。即使区间内有根，网格仍可能完全错过残差接受区域，见 [[固定步长漏根]]。

<!-- bilingual-en:start -->
A [[固定步长求根|fixed-step root search]] over a continuous interval merely replaces the problem by enumeration on a finite grid; this card's finite-set conclusion does not extend to the whole real interval. Even when the interval contains a root, the grid can miss the entire residual-acceptance region; see [[固定步长漏根|fixed-step grid miss]].
<!-- bilingual-en:end -->

> [!question]- 自检
> 程序系统检查了集合 $C'$ 的每个元素，且都不满足 $P$。要据此断言原问题无解，还必须确认什么？
>
> **答案：** 必须确认 $C'$ 覆盖原问题允许的全部候选，而且谓词 $P$ 的判断正确；若漏掉合法候选，穷尽 $C'$ 只能证明 $C'$ 内无解。
>
> <!-- bilingual-en:start -->
> A program checks every element of $C'$ and none satisfies $P$. What else is required before declaring the original problem unsolvable?
>
> **Answer:** $C'$ must cover every candidate allowed by the original problem, and $P$ must be correct. If eligible candidates were omitted, exhausting $C'$ proves only that no solution lies inside $C'$.
> <!-- bilingual-en:end -->
