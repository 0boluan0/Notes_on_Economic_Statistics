# 固定位宽下扩大量化范围会增大等级间距并改变舍入与截断的权衡

<!-- bilingual-en:start -->
*At a fixed bit width, a wider quantization range increases level spacing and changes the rounding-clipping tradeoff*
<!-- bilingual-en:end -->

对[[数值量化|均匀量化]]，固定位宽就固定了可用等级数。扩大范围能容纳更极端的数值，却会拉大相邻等级的距离；缩小范围能把等级放得更密，却可能把范围外的数值截到端点。因此，选择量化范围是在舍入误差与截断误差之间作权衡。

<!-- bilingual-en:start -->
For [[数值量化|uniform quantization]], fixing the bit width fixes the number of available levels. A wider range accommodates more extreme values but increases the distance between adjacent levels. A narrower range places levels closer together but may clip values outside it. Range selection therefore trades rounding error against clipping error.
<!-- bilingual-en:end -->

## 哪种误差有半个步长的界

<!-- bilingual-en:start -->
*Which error is bounded by half a step*
<!-- bilingual-en:end -->

设 $b$ 位均匀量化使用全部 $2^b$ 个等级，最小与最大等级为 $r_{\min}$、$r_{\max}$，相邻间距为 $s$。端点之间有 $2^b-1$ 段，所以

<!-- bilingual-en:start -->
Let a $b$-bit uniform quantizer use all $2^b$ levels, from $r_{\min}$ to $r_{\max}$, with spacing $s$. There are $2^b-1$ gaps between the endpoints, so
<!-- bilingual-en:end -->

$$
s=\frac{r_{\max}-r_{\min}}{2^b-1}.
$$

对于位于范围内的输入 $x$，取最近等级时，最远只需移动半个间距，故 $|\widehat x-x|\le s/2$。对于范围外的输入，结果被截到最近端点；例如 $x>r_{\max}$ 时误差是 $x-r_{\max}$，没有同一个 $s/2$ 上界。

<!-- bilingual-en:start -->
For an input $x$ inside the range, a nearest level is at most half a gap away, giving $|\widehat x-x|\le s/2$. An input outside the range is clipped to an endpoint. For example, when $x>r_{\max}$ the error is $x-r_{\max}$, which need not satisfy that bound.
<!-- bilingual-en:end -->

## 改变范围时，谁受益、谁受损

<!-- bilingual-en:start -->
*Which values benefit from a range change*
<!-- bilingual-en:end -->

使用 2-bit 无符号码，zero-point 为 0，比较两个候选 scale。输入为 $(0.2,1.4,3)$：

<!-- bilingual-en:start -->
Use two-bit unsigned codes with zero-point zero, and compare two candidate scales for inputs $(0.2,1.4,3)$:
<!-- bilingual-en:end -->

$$
\begin{array}{c|c|c|c}
s&\text{levels}&\widehat x&|\widehat x-x|\\\hline
1&\{0,1,2,3\}&(0,1,3)&(0.2,0.4,0)\\
0.5&\{0,0.5,1,1.5\}&(0,1.5,1.5)&(0.2,0.1,1.5)
\end{array}
$$

缩小范围让 $1.4$ 的绝对误差从 $0.4$ 降到 $0.1$，但把 $3$ 截成 $1.5$。这个例子没有一种对所有输入都更好的范围；更不能仅据其中一个数的误差断言模型任务质量。

<!-- bilingual-en:start -->
Narrowing the range reduces the absolute error for $1.4$ from $0.4$ to $0.1$, but clips $3$ to $1.5$. Neither range improves every input in this example, and the error of one value cannot establish model-level task quality.
<!-- bilingual-en:end -->

若少数 outlier 决定了整个张量的最大范围，普通值就可能只剩很粗的等级。[[量化粒度|让不同组使用不同参数]]可以改变这个局部权衡；最终仍须检查[[量化输出误差|数值误差怎样作用于实际输入和输出]]。

<!-- bilingual-en:start -->
If a few outliers determine the range of an entire tensor, ordinary values may receive very coarse levels. [[量化粒度|Using separate parameters for different groups]] changes this local tradeoff, while [[量化输出误差|the effect of numerical error on actual inputs and outputs]] still needs examination.
<!-- bilingual-en:end -->
