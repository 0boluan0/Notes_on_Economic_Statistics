# Fixed-rank matrix sets
<!-- bilingual-en:end -->
*固定秩矩阵集合*

<!-- bilingual-en:start -->
A fixed-rank set groups matrices of one size by the number of independent columns they have. This is a restriction on [[矩阵秩|rank]], not a guarantee of [[子空间|subspace]] structure: addition can create or cancel independent directions.
<!-- bilingual-en:end -->

固定秩集合按独立列的数量，挑出同一尺寸的某些矩阵。这是对[[矩阵秩]]的限制，本身不保证[[子空间]]结构，因为相加可能增加或抵消独立方向。

<!-- bilingual-en:start -->
Take two $2\times2$ matrices, each with only one nonzero column:
<!-- bilingual-en:end -->

取两个 $2\times2$ 矩阵，每个只有一个非零列：

$$
\begin{pmatrix}1&0\\0&0\end{pmatrix}
+\begin{pmatrix}0&0\\0&1\end{pmatrix}
=I_2.
$$

<!-- bilingual-en:start -->
Both summands have rank $1$, while the sum has rank $2$. Thus even the set of $2\times2$ matrices of rank **at most** $1$ is not a subspace. In the lecture's $5\times17$ setting, append twelve zero columns to $\operatorname{diag}(1,1,1,1,0)$ and $\operatorname{diag}(0,1,1,1,1)$. Both have rank $4$; their sum has rank $5$.
<!-- bilingual-en:end -->

两个加数的秩都为 $1$，和的秩为 $2$。因此即使允许秩**至多**为 $1$，全部这样的 $2\times2$ 矩阵仍不是子空间。课堂的 $5\times17$ 情形可在 $\operatorname{diag}(1,1,1,1,0)$ 和 $\operatorname{diag}(0,1,1,1,1)$ 后各补十二列零；两者秩都为 $4$，和的秩却为 $5$。

<!-- bilingual-en:start -->
For a positive integer $r\le\min(m,n)$, the set $\{A\in\mathbb R^{m\times n}:\operatorname{rank}A=r\}$ is not a subspace: it omits the zero matrix. Adjoining zero fixes that one failure, but does not in general fix addition.
<!-- bilingual-en:end -->

若 $0<r\le\min(m,n)$，集合 $\{A\in\mathbb R^{m\times n}:\operatorname{rank}A=r\}$ 不是子空间，因为没有零矩阵。补入零矩阵只修复这一处问题，一般仍不能保证加法封闭。

> [!warning] Check the boundary of the set · 检查集合的边界
> <!-- bilingual-en:start -->
> The boundary matters: rank zero gives the zero subspace. A rank-at-most bound at least $\min(m,n)$ permits the whole matrix space. When $\min(m,n)=1$, adjoining zero to the rank-one set also gives the whole space. Always check the exact set and its closure rather than treating every rank constraint as the same condition.
> <!-- bilingual-en:end -->
>
> 边界需要区分：秩为零得到零子空间；“秩至多为某数”的上限若达到 $\min(m,n)$，便允许全部矩阵。当 $\min(m,n)=1$ 时，给秩一集合补入零也会得到全空间。应检查具体集合及其封闭性，而不能把所有秩限制混为一谈。
