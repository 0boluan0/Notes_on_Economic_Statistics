# 普通赋值不会复制对象而多个名称可以共享同一可变对象
<!-- bilingual-en:start -->
*Ordinary assignment does not copy an object, so several names can share one mutable object*
<!-- bilingual-en:end -->

> [!summary] 原子关系
> **b = a** 把 **b** 绑定到 **a** 当前所指的对象，并不复制那个对象。若对象可变，通过任一别名做原地修改，其他别名都会看到结果；若某个名称随后被重新绑定，则只改变该名称与对象的关系。

~~~python
a = [1, 2]
b = a

b.append(3)
assert a == [1, 2, 3]
assert a is b

b = []              # 只把 b 改绑到另一个列表
assert a == [1, 2, 3]
~~~

最可靠的理解方式是画对象图：名称是指向对象的箭头，而不是装着值的盒子。**is** 判断两条箭头是否落在同一对象；**==** 判断对象的值是否相等。两个不同列表可以 **==**，却不 **is**。

## 函数调用也不会自动复制实参

调用函数时，实参对象会绑定给新调用帧中的形参。函数若修改该对象，调用者可以观察到；函数若只把形参改绑到新对象，调用者的名称不受影响。

~~~python
def add_tag(items):
    items.append("new")     # 修改共享对象

def replace(items):
    items = ["new"]         # 只改绑局部名称

records = []
add_tag(records)
assert records == ["new"]
replace(records)
assert records == ["new"]
~~~

别名并非只存在于可变对象之间；两个名称也可以指向同一个不可变对象。区别在于不可变对象不能被原地改写，因此这种共享通常不会产生“从另一处突然变化”的可见副作用。

函数是否保留引用、修改实参或返回独立结果，属于 [[函数契约]]。当共享不是有意设计的一部分时，再按 [[复制层级边界]] 选择只断开外层还是递归处理对象图。

> [!question]- 自检
> 为什么 **b = a[:]** 与 **b = a** 对列表有不同后果？
>
> **答案：** **b = a** 让两个名称指向同一列表；列表切片会创建新的外层列表，所以 **b = a[:]** 断开外层身份，但其中嵌套对象仍可能共享。
