# Intermediate value theorem
<!-- bilingual-en:end -->

*介值定理*

<!-- bilingual-en:start -->
The function $f(x)=x^2$ has output $1$ at input $1$ and output $4$ at input $2$. Can it pass from the first output to the second without ever taking the value $2$? The intermediate value theorem says that a continuous real function cannot skip this intermediate height. Some input $c$ between $1$ and $2$ must satisfy $c^2=2$, even before we know how to calculate $c$.
<!-- bilingual-en:end -->

函数 $f(x)=x^2$ 在输入 $1$ 时输出 $1$，在输入 $2$ 时输出 $4$。它能否从前一个输出走到后一个输出，却从未取到 $2$？介值定理说明，连续实函数不能跳过这个中间高度。即使尚不知道怎样计算，也能确定 $1$ 与 $2$ 之间有输入 $c$ 满足 $c^2=2$。

<!-- bilingual-en:start -->
Here “intermediate” describes an **output value**, not the midpoint of the input interval. In this example the input midpoint is $3/2$, whose output is $9/4$, not $2$.
<!-- bilingual-en:end -->

这里的“中间”指的是**输出值**，不是输入区间的中点。本例输入中点为 $3/2$，对应输出是 $9/4$，并不是 $2$。

<!-- bilingual-en:start -->
## State the interval and the target value
<!-- bilingual-en:end -->

*明确输入区间与目标输出*

<!-- bilingual-en:start -->
Let $a<b$ be real numbers, and let $f:[a,b]\to\mathbb R$ assign a finite real output to every input in the closed interval. Assume that $f$ is [[一点连续|continuous at every point]] of this interval: nearby allowed inputs give nearby outputs. At $a$ only inputs from the right are relevant, and at $b$ only inputs from the left are relevant; continuity is relative to the stated domain.
<!-- bilingual-en:end -->

设 $a<b$ 为实数，$f:[a,b]\to\mathbb R$ 给闭区间中的每个输入指定一个有限实数输出。假设 $f$ 在区间的[[一点连续|每一点都连续]]：相近的允许输入给出相近的输出。在 $a$ 处只考虑右侧输入，在 $b$ 处只考虑左侧输入；连续性是相对于所给定义域而言的。

> [!important] Every intermediate output is attained · 每个中间输出都能取到
> <!-- bilingual-en:start -->
> For each real number $y$ satisfying
> $$\min\{f(a),f(b)\}\le y\le\max\{f(a),f(b)\},$$
> there is at least one $c\in[a,b]$ such that $f(c)=y$. The symbols $\min$ and $\max$ select the smaller and larger endpoint outputs, so the statement covers either order of those outputs. If $y$ lies strictly between them, a solution lies in the open interval $(a,b)$.
> <!-- bilingual-en:end -->
>
> 对每个满足上述不等式的实数 $y$，至少存在一个 $c\in[a,b]$ 使 $f(c)=y$。$\min$ 和 $\max$ 分别选出较小、较大的端点输出，因此不要求 $f(a)<f(b)$。若 $y$ 严格位于两个端点输出之间，就有解位于开区间 $(a,b)$ 内。

<!-- bilingual-en:start -->
If $y$ equals an endpoint output, that endpoint already supplies a solution. If $f(a)=f(b)$, the statement only guarantees this common output; it does not say that the function is constant. The degenerate interval $[a,a]$ is a separate trivial case with its single input and output.
<!-- bilingual-en:end -->

若 $y$ 等于某个端点输出，该端点本身就给出一个解。若 $f(a)=f(b)$，本陈述只保证这个共同输出能取到，并不说明函数为常值。退化区间 $[a,a]$ 只有一个输入及其输出，是单独的平凡情形。

<!-- bilingual-en:start -->
## Why continuity matters
<!-- bilingual-en:end -->

## 为什么连续性是关键

<!-- bilingual-en:start -->
A proof can make “cannot skip a height” precise using [[连通性|connectedness]], which means that a set cannot be separated into two disjoint nonempty relatively open pieces. The usual real interval $[a,b]$ is connected by the [[实线连通集是区间|interval characterization of connected subsets of the real line]]. By [[连续像保持连通|preservation of connectedness under continuous maps]], the image
<!-- bilingual-en:end -->

可以用[[连通性]]把“不能跳过一个高度”变成证明：连通意味着，不能把集合分成两个不交、非空的相对开部分。由[[实线连通集是区间|实线连通集的区间刻画]]，通常实区间 $[a,b]$ 连通。再由[[连续像保持连通]]，像集

$$f([a,b])=\{f(x):x\in[a,b]\}$$

<!-- bilingual-en:start -->
is connected. This is the set of outputs actually attained. A nonempty connected subset of the real line is an interval, so it contains every real number between any two of its points. Both $f(a)$ and $f(b)$ belong to the image; therefore the chosen $y$ also belongs to the image. By the definition of the image, some input $c\in[a,b]$ satisfies $f(c)=y$. If $y$ differs from both endpoint outputs, neither endpoint can be that input, so $c\in(a,b)$.
<!-- bilingual-en:end -->

也连通。这个集合由实际取到的输出组成。实线的非空连通子集是区间，因此包含其中任意两点之间的全部实数。$f(a),f(b)$ 都在像集中，所以所选的 $y$ 也在像集中。按像集的定义，就有输入 $c\in[a,b]$ 满足 $f(c)=y$。若 $y$ 与两个端点输出都不同，端点就不可能是这个输入，因此 $c\in(a,b)$。

> [!example] A jump can omit zero · 跳跃可以漏掉零
> <!-- bilingual-en:start -->
> On $[-1,1]$, define $h(x)=-1$ for $x<0$ and $h(x)=1$ for $x\ge0$. Its endpoint outputs straddle zero, but its only outputs are $-1$ and $1$. It has no zero. At input $0$ it is discontinuous, so it does not satisfy the theorem's assumptions.
> <!-- bilingual-en:end -->
>
> 在 $[-1,1]$ 上，定义 $x<0$ 时 $h(x)=-1$，$x\ge0$ 时 $h(x)=1$。端点输出跨过了零，但函数只取 $-1,1$，根本没有零点。它在输入 $0$ 处不连续，所以不满足定理的假设。

<!-- bilingual-en:start -->
Closed endpoints make the displayed endpoint statement meaningful; closedness is not required for the intermediate-value property on an arbitrary interval. If $f$ is continuous on an open or unbounded interval, choose any two inputs $a<b$ inside it. Their whole segment $[a,b]$ is still in the domain, and the theorem applies to the restriction to that segment.
<!-- bilingual-en:end -->

包含端点使上述端点版本有意义，但一般区间的介值性质并不要求区间闭。若 $f$ 在开区间或无界区间上连续，可在其中任选两个输入 $a<b$；整段 $[a,b]$ 仍在定义域内，对这一段上的限制函数即可使用定理。

## Use the theorem to prove that a root exists
<!-- bilingual-en:end -->

## 用于证明有根

<!-- bilingual-en:start -->
A **root** of a function $g$ is an input $c$ with $g(c)=0$. For a continuous $g$ on $[a,b]$, opposite endpoint signs place $0$ strictly between the outputs and give a root in $(a,b)$. If an endpoint output is already zero, that endpoint is a root. More generally, solving $f(c)=y$ is the same as finding a root of $g(x)=f(x)-y$.
<!-- bilingual-en:end -->

函数 $g$ 的**根**是满足 $g(c)=0$ 的输入 $c$。若 $g$ 在 $[a,b]$ 上连续，端点异号就使 $0$ 严格位于两个输出之间，因而在 $(a,b)$ 内有根。若端点输出已经为零，该端点本身就是根。更一般地，求解 $f(c)=y$ 等同于给 $g(x)=f(x)-y$ 求根。

<!-- bilingual-en:start -->
For the opening example, $g(x)=x^2-2$ has $g(1)=-1$ and $g(2)=2$. Its continuity on $[1,2]$ can be checked directly: for any $x,z\in[1,2]$,
<!-- bilingual-en:end -->

在开头的例子中，$g(x)=x^2-2$ 满足 $g(1)=-1$、$g(2)=2$。它在 $[1,2]$ 上的连续性可以直接检查：对任意 $x,z\in[1,2]$，

$$|g(x)-g(z)|=|x-z|\,|x+z|\le4|x-z|.$$

<!-- bilingual-en:start -->
Thus input distance less than $\varepsilon/4$ makes output distance less than any prescribed $\varepsilon>0$. The theorem gives at least one root in $(1,2)$. Whether that root is unique and how to approximate it are separate questions, explained in [[介值定理只保证存在性|the scope of the intermediate value theorem]].
<!-- bilingual-en:end -->

因此，只要输入距离小于 $\varepsilon/4$，输出距离就小于任意给定的 $\varepsilon>0$。定理保证 $(1,2)$ 中至少有一个根。这个根是否唯一、怎样近似计算，是另外的问题，见[[介值定理只保证存在性|介值定理的结论范围]]。
