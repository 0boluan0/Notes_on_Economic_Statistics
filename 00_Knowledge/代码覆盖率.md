# 代码覆盖率是在指定代码范围和度量下测试实际执行的结构占全部计入结构的比例
<!-- bilingual-en:start -->
*Code coverage measures the proportion of counted code structures exercised by tests, under a specified scope and metric.*
<!-- bilingual-en:end -->

必须说明分子、分母在数什么：语句覆盖记录可执行语句是否执行；分支覆盖记录控制流分支是否经过。文件范围与排除规则会改变分母，因此两个没有相同口径的百分比不能直接比较。
<!-- bilingual-en:start -->
State what is counted: statement coverage records executed statements, while branch coverage records exercised control-flow alternatives. File selection and exclusions change the denominator, so percentages with different scopes or metrics are not directly comparable.
<!-- bilingual-en:end -->

例如，下列函数只用 `flag=True` 运行，就能执行函数体里的所有可执行语句，但没有走过条件为假时直接到达 `return` 的分支。
<!-- bilingual-en:start -->
Calling this function only with `flag=True` executes every executable statement in its body, but never takes the false branch directly to `return`.
<!-- bilingual-en:end -->

```python
def adjusted(flag):
    value = 0
    if flag:
        value = 1
    return value
```

覆盖率记录“执行过哪里”，并不记录“检查结果有多严格”。完整路径覆盖还要区分循环次数和递归深度，通常不能由有限用例穷尽；更高覆盖的正确性边界见[[覆盖率不能证明正确]]。
<!-- bilingual-en:start -->
Coverage records where execution went, not how thoroughly results were checked. Complete path coverage also distinguishes loop counts and recursion depths and is generally not finitely exhaustible. See [[覆盖率不能证明正确|why coverage does not prove correctness]].
<!-- bilingual-en:end -->
