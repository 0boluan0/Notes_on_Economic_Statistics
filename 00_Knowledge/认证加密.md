# 认证加密在一个构造中同时保护明文机密性与消息认证性
<!-- bilingual-en:start -->
*Authenticated encryption protects plaintext confidentiality and message authenticity in one construction*
<!-- bilingual-en:end -->

> [!summary] 它是什么
> 认证加密（AE）在一个经过分析的构造中同时提供明文机密性和消息完整性／数据来源认证。带关联数据的认证加密（AEAD）还允许一部分数据保持可见，同时把它纳入认证保护。
> <!-- bilingual-en:start -->
> Authenticated encryption supplies plaintext confidentiality and message integrity/data-origin authentication together in one analysed construction. Authenticated encryption with associated data also lets some data remain visible while covering it with authentication.
> <!-- bilingual-en:end -->

AEAD 加密通常接收密钥、明文、nonce 和关联数据（AAD），输出密文与 tag。解密接收相同上下文并返回明文或失败。AAD 适合放版本号、路由信息或序号等“必须可见但不能被静默篡改”的字段；它不被加密，但改动会让认证失败。
<!-- bilingual-en:start -->
AEAD encryption normally takes a key, plaintext, nonce, and associated data and outputs ciphertext and a tag. Decryption takes the matching context and returns plaintext or failure. Associated data is suitable for version, routing, or sequence fields that must remain visible but cannot be silently altered. It is not encrypted, but changing it causes authentication to fail.
<!-- bilingual-en:end -->

最小例子是传输一个带版本号的请求：请求正文作为明文被加密，版本号作为 AAD 保持可路由；接收方只有在正文、版本号、nonce 与 tag 整体匹配时才得到明文。这里的“认证”仍只相对于持有对称密钥的一方，不自动标识自然人，也不自动提供防重放。
<!-- bilingual-en:start -->
A minimal example is a request carrying a version number. The body is encrypted as plaintext while the version remains routable as associated data. The receiver obtains plaintext only when the body, version, nonce, and tag match as a whole. This authentication is still relative to holders of the symmetric key; it does not automatically identify a human or provide replay resistance.
<!-- bilingual-en:end -->

> [!question]- 自检
> 为什么 AEAD 的 AAD 可以保持明文，却仍能防止攻击者静默修改它？
>
> **答案：** AAD 不进入加密输出，但参与 tag 计算；接收方用相同 AAD 验证，任何未经授权的改动都会导致认证失败。

## 来源与核验

- [RFC 5116, Sections 2 and 3, *An Interface and Algorithms for Authenticated Encryption*](https://datatracker.ietf.org/doc/html/rfc5116)：核对 AEAD 的明文、nonce、AAD 接口，以及认证解密输出明文或 `FAIL`。
- [NIST SP 800-38D, *Galois/Counter Mode and GMAC*](https://csrc.nist.gov/pubs/sp/800/38/d/final)：以 GCM 核对 AEAD 同时保护明文机密性、明文与 AAD 的认证性，并让 AAD 保持可见。
