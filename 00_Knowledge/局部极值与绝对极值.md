# Local and absolute extrema
<!-- bilingual-en:end -->

*局部极值与绝对极值*

<!-- bilingual-en:start -->
A hill can be higher than everything nearby without being the highest place in the whole region. **Local** and **absolute** extrema make precisely this distinction for function outputs: local comparisons stay near one input, while absolute, or global, comparisons range over the whole allowed domain. Neither word requires derivatives.
<!-- bilingual-en:end -->

一座小山可以比附近所有地方高，却不是整个区域最高的地方。函数的**局部极值**与**绝对极值**正是在区分这种比较范围：局部只与一个输入附近的值比较，绝对（或全局）则与整个合法定义域比较。两种定义都不要求导数。

<!-- bilingual-en:start -->
For example, take $f(x)=3x-x^3$ on $\mathbb R$. At $c=1$ its value is $2$. For a small displacement $h$:
<!-- bilingual-en:end -->

例如在 $\mathbb R$ 上取 $f(x)=3x-x^3$。在 $c=1$ 处，函数值为 $2$。对一个小位移 $h$，有

$$f(1+h)-f(1)=-h^2(3+h).$$

<!-- bilingual-en:start -->
If $0<|h|<1$, the right side is negative: every nearby distinct input gives a smaller output. Thus $1$ is a local maximum point. It is not an absolute maximum point, because the allowed input $-3$ gives $f(-3)=18>2$.
<!-- bilingual-en:end -->

当 $0<|h|<1$，右边为负，因此每个附近的不同输入都产生更小的输出，$1$ 是局部最大点。但它不是绝对最大点，因为另一个合法输入 $-3$ 满足 $f(-3)=18>2$。

<!-- bilingual-en:start -->
## The definition keeps the comparison set visible
<!-- bilingual-en:end -->

*定义的关键是与哪些输入比较*

<!-- bilingual-en:start -->
Let $f:D\to\mathbb R$, where $D\subseteq\mathbb R$ is a nonempty set of allowed inputs, and let $c\in D$. A radius $\delta>0$ specifies which inputs are nearby: $|x-c|<\delta$ means distance less than $\delta$. A neighbourhood **relative to $D$** includes only those nearby points that also lie in $D$; this is the local viewpoint of the [[子空间拓扑|subspace topology]].
<!-- bilingual-en:end -->

设 $f:D\to\mathbb R$，其中非空集合 $D\subseteq\mathbb R$ 是允许输入的集合，且 $c\in D$。正半径 $\delta>0$ 指定“附近”的范围：$|x-c|<\delta$ 表示距离小于 $\delta$。**相对于 $D$** 的邻域只包括这些附近点中仍属于 $D$ 的点，这就是[[子空间拓扑]]的局部视角。

> [!important] Local versus global · 局部与全局
> <!-- bilingual-en:start -->
> The input $c$ is a **local maximum point** if some $\delta>0$ makes $f(x)\le f(c)$ for every $x\in D$ with $|x-c|<\delta$. It is an **absolute maximum point** if $f(x)\le f(c)$ for every $x\in D$. Reversing the inequality defines local and absolute minimum points. “Extremum” means either a maximum or a minimum.
> <!-- bilingual-en:end -->
>
> 若存在某个 $\delta>0$，使每个满足 $x\in D$ 且 $|x-c|<\delta$ 的输入都有 $f(x)\le f(c)$，则 $c$ 是**局部最大点**。若每个 $x\in D$ 都有 $f(x)\le f(c)$，则 $c$ 是**绝对最大点**。把不等号反向，就得到局部、绝对最小点的定义。“极值”统称最大或最小。

<!-- bilingual-en:start -->
Every absolute maximum is local under this relative-domain definition, because an inequality true on the entire domain is true on each smaller neighbourhood. The opening cubic shows that a local maximum need not be absolute. A local radius can depend on the point; no single radius is required for all extrema.
<!-- bilingual-en:end -->

按这种相对定义域的定义，每个绝对最大点也都是局部最大点，因为在全域成立的不等式，在更小的邻域上仍成立。开头的三次函数说明局部最大点未必是绝对最大点。局部半径可以随点改变，不要求所有极值点共用一个半径。

<!-- bilingual-en:start -->
For several inputs at once, take $D\subseteq\mathbb R^n$, where the positive integer $n$ is the number of coordinates. Replace $|x-c|$ by the [[欧氏范数|Euclidean distance]] $\|x-c\|_2$, the straight-line distance between the input vectors. The same definitions apply, and one radius must work for **every** nearby feasible direction. For example, $f(x_1,x_2)=x_1^2+x_2^2$ has a strict absolute minimum at $(0,0)$ on $\mathbb R^2$ because every other input gives a positive value.
<!-- bilingual-en:end -->

若同时有多个输入坐标，就取 $D\subseteq\mathbb R^n$，正整数 $n$ 表示坐标数量。把 $|x-c|$ 换成[[欧氏范数|欧氏距离]] $\|x-c\|_2$，即两个输入向量之间的直线距离，其余定义相同；同一个半径必须同时控制**每个**附近的可行方向。例如，$\mathbb R^2$ 上的 $f(x_1,x_2)=x_1^2+x_2^2$ 在 $(0,0)$ 取得严格绝对最小值，因为其余每个输入都产生正值。

<!-- bilingual-en:start -->
## A value is not its location
<!-- bilingual-en:end -->

*函数值、输入位置与图像点不同*

<!-- bilingual-en:start -->
The extremal **value** is the output $f(c)$; its **location** is the input $c$; the graph point is $(c,f(c))$. In the opening example these are $2$, $1$ and $(1,2)$. A set of several inputs may attain the same extremal value. Thus “the maximum value is $x=2$” mixes two kinds of object: $x=2$ would describe a maximizing input, while the value would be $f(2)$.
<!-- bilingual-en:end -->

极**值**是输出 $f(c)$，取得它的**位置**是输入 $c$，图像点则是 $(c,f(c))$。开头的例子中，它们依次是 $2$、$1$、$(1,2)$。同一个极值也可能在多个输入处取得。因此，“最大值是 $x=2$”混淆了对象：$x=2$ 描述的是可能取得最大值的输入，最大值应是 $f(2)$。

<!-- bilingual-en:start -->
## Strictness rules out ties in the stated comparison region
<!-- bilingual-en:end -->

*严格性排除相应范围内的并列*

<!-- bilingual-en:start -->
The preceding definitions are **non-strict**: equality at another input is allowed. A **strict local maximum** requires $f(x)<f(c)$ for all nearby allowed $x\ne c$, using one suitable radius. A **strict absolute maximum** requires that inequality for every $x\in D\setminus\{c\}$. For minima, use $>$. Excluding $c$ is essential because $f(c)<f(c)$ is impossible.
<!-- bilingual-en:end -->

前面的定义都是**非严格**的，允许其他输入取得相同值。**严格局部最大点**要求在某个合适半径内，每个合法且不同于 $c$ 的输入都满足 $f(x)<f(c)$；**严格绝对最大点**则要求每个 $x\in D\setminus\{c\}$ 都满足这一不等式。最小点把不等号改为 $>$。必须排除 $c$ 自己，因为 $f(c)<f(c)$ 不可能成立。

<!-- bilingual-en:start -->
For $g(x)=(x^2-1)^2$ on $\mathbb R$, all outputs are nonnegative and $g(-1)=g(1)=0$. There are two absolute minimum points. Each is a strict local minimum: take a radius smaller than $1$, so the other zero is outside the neighbourhood, and every remaining nearby point has positive value. Neither is a strict absolute minimum, since the other point ties it. By contrast, a constant function on $\mathbb R$ has both a non-strict maximum and minimum at every point, but no strict local extrema.
<!-- bilingual-en:end -->

对 $\mathbb R$ 上的 $g(x)=(x^2-1)^2$，全部输出非负，且 $g(-1)=g(1)=0$，所以有两个绝对最小点。它们分别又是严格局部最小点：选小于 $1$ 的半径，另一个零点就在邻域外，其余附近点的函数值都为正。但两者都不是严格绝对最小点，因为另一个点与它并列。相比之下，$\mathbb R$ 上的常值函数在每一点都同时取得非严格最大和最小，却没有严格局部极值。

<!-- bilingual-en:start -->
## The domain determines which neighbours are allowed
<!-- bilingual-en:end -->

*端点也可以是相对定义域的局部极值*

<!-- bilingual-en:start -->
For $f(x)=x$ on $D=[0,1]$, zero is a strict absolute minimum and one is a strict absolute maximum. They are also strict local extrema relative to $D$: near zero there are no allowed negative inputs, and near one there are no allowed inputs larger than one. If the same formula is instead defined on all of $\mathbb R$, neither zero nor one is a local extremum. The formula alone does not determine the comparison.
<!-- bilingual-en:end -->

对 $D=[0,1]$ 上的 $f(x)=x$，零点是严格绝对最小点，一点是严格绝对最大点。它们也是相对于 $D$ 的严格局部极值点：零附近没有合法负输入，一附近没有大于一的合法输入。若同一公式改为定义在整个 $\mathbb R$ 上，零和一都不是局部极值点。因此，只看公式不能确定比较结果。

> [!note] A stated convention matters · 需要明确约定
> <!-- bilingual-en:start -->
> Some elementary texts reserve “local extremum” for interior points. Here the comparison is relative to the whole domain, including its endpoints; [[临界点|critical points]] are separately defined using interior points in $\mathbb R$. At an isolated domain point, a small enough neighbourhood contains no other allowed input, so both strict local inequalities hold vacuously. These facts are about the comparison set, not about derivative tests.
> <!-- bilingual-en:end -->
>
> 有些初等教材把“局部极值”限定在内点。本卡则相对于整个定义域比较，包括端点；[[临界点]]另按实数线中的内点来定义。如果某个定义域中的点是孤立的，足够小的邻域不含其他合法输入，那么两个严格局部不等式都会空泛地成立。这些现象由比较集合决定，并不是导数检验的结论。

<!-- bilingual-en:start -->
## Attainment is a separate question
<!-- bilingual-en:end -->

*存在性与分类分别回答不同问题*

<!-- bilingual-en:start -->
An extremal value must actually be produced by an allowed input. For $f(x)=x$ on $(0,1)$, the [[上确界|supremum]] is $1$, meaning the least upper bound on the outputs. There is no maximum: for each allowed $x$, the allowed input $(x+1)/2$ gives a strictly larger value. Calling $1$ an “unattained maximum” would obscure the difference.
<!-- bilingual-en:end -->

极值必须由某个合法输入真正产生。对 $(0,1)$ 上的 $f(x)=x$，输出集合的[[上确界]]为 $1$，即最小上界，但函数没有最大值：任给合法的 $x$，另一个合法输入 $(x+1)/2$ 都产生更大的值。把 $1$ 称为“未取得的最大值”会模糊这一区别。

<!-- bilingual-en:start -->
The [[极值定理|extreme value theorem]] guarantees attained absolute maxima and minima for a [[连续性|continuous]] real-valued function on a nonempty [[紧致性|compact]] domain. It does not require differentiability or identify the maximizing inputs. Derivative conditions and the [[闭区间极值法|closed-interval method]] address candidates and their comparison under their own hypotheses. Neither finding a zero derivative nor failing an existence theorem settles every extremum question.
<!-- bilingual-en:end -->

[[极值定理]]保证：非空[[紧致性|紧致]]定义域上的[[连续性|连续]]实值函数会取得绝对最大值和最小值。它不要求可导，也不指出取得极值的输入在哪里。导数条件与[[闭区间极值法]]在各自假设下处理候选及其比较。找到零导数，或者无法使用某个存在性定理，都不能直接解决所有极值问题。
