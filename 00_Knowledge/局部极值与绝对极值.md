# 局部极值只比较邻域而绝对极值比较整个可行域
<!-- bilingual-en:start -->
*A local extremum compares a neighborhood whereas an absolute extremum compares the entire feasible domain*
<!-- bilingual-en:end -->

> [!summary] 原子区分
> 若存在 $c$ 的一个定义域内邻域，使邻域内 $f(x)\le f(c)$，则 $c$ 是局部最大点；若该不等式对整个可行域成立，则它是绝对最大点。把不等号反向得到局部与绝对最小。点 $c$、极值 $f(c)$ 与取得该值的位置集合是不同对象。
> <!-- bilingual-en:start -->
> A local maximum compares $f(c)$ only with values in a domain neighborhood of $c$; an absolute maximum compares it with every feasible value. Reversing the inequalities defines minima. The point $c$, the extremal value $f(c)$, and the set of points attaining that value are distinct objects.
> <!-- bilingual-en:end -->

局部最大不必是最高峰，绝对最大也不必唯一。函数可以在多个点取得同一个最大值；严格极值才要求附近其他点的函数值严格更小或更大。端点可以是相对定义域的局部极值，也常是绝对极值，却没有双侧可行方向。
<!-- bilingual-en:start -->
A local maximum need not be the highest peak, and an absolute maximum need not be attained uniquely. Strict extrema require strict comparison with nearby distinct points. An endpoint may be locally extremal relative to the domain and may also be absolute, even though it has no two-sided feasible neighborhood.
<!-- bilingual-en:end -->

存在性与分类也要分开。[[极值定理]] 在非空紧集上为连续函数保证绝对最大、最小确实取得；导数检验只分类已有候选，不能替代取得性条件。开区间 $(0,1)$ 上的 $f(x)=x$ 有上确界 $1$，却没有最大点。
<!-- bilingual-en:start -->
Existence and classification are separate. The extreme value theorem guarantees attainment for a continuous function on a nonempty compact set, whereas derivative tests only classify candidates. On the open interval $(0,1)$, $f(x)=x$ has supremum one but no maximum point.
<!-- bilingual-en:end -->

> [!question]- 自检
> “最大值是 $x=2$”为什么类型错了？
>
> **答案：** $x=2$ 是最大点；最大值是函数输出 $f(2)$。
> <!-- bilingual-en:start -->
> **Check:** Why does “the maximum value is $x=2$” confuse two kinds of object?
>
> **Answer:** The input $x=2$ is a maximizer; the maximum value is the output $f(2)$.
> <!-- bilingual-en:end -->
