# 量化粒度规定哪些元素共享同一组量化参数

<!-- bilingual-en:start -->
*Quantization granularity specifies which elements share one set of quantization parameters*
<!-- bilingual-en:end -->

量化粒度是把张量划分为若干共享量化参数的集合的规则。在[[数值量化|均匀仿射量化]]中，这主要决定哪些元素共用 scale 和 zero-point。它回答“参数覆盖哪些元素”，位宽则回答“每个元素使用多少个码位”。

<!-- bilingual-en:start -->
Quantization granularity partitions a tensor into sets that share quantization parameters. For [[数值量化|uniform affine quantization]], it chiefly determines which elements share a scale and zero-point. Granularity specifies the elements covered by each parameter set; bit width specifies the code bits per element.
<!-- bilingual-en:end -->

## 必须说明共享参数的轴

<!-- bilingual-en:start -->
*The sharing axis must be specified*
<!-- bilingual-en:end -->

per-tensor 为整个张量共用一套参数；per-channel 为每个指定通道分别使用一套；per-token 常为每个 token 的激活行分别使用一套；per-group 为明确分出的每一组使用一套。通道可能指输入轴或输出轴，组也可能沿不同轴划分，因此“group size 128”必须连同张量对象、分组轴和组大小一起解释。

<!-- bilingual-en:start -->
Per-tensor quantization shares one parameter set across a tensor; per-channel uses one set for each specified channel; per-token commonly uses one set for each activation row; and per-group uses one set for each defined group. A channel can refer to an input or output axis, and groups can follow different axes. “Group size 128” therefore requires the tensor, grouping axis, and group size to be stated together.
<!-- bilingual-en:end -->

## 四个权重的一组与两组

<!-- bilingual-en:start -->
*One group versus two groups for four weights*
<!-- bilingual-en:end -->

取四个非负权重 $(0.08,0.2,0.8,2)$，固定使用 2-bit 无符号码和 $z=0$。先让整个向量共用 $s=2/3$，最近舍入得到

<!-- bilingual-en:start -->
Take nonnegative weights $(0.08,0.2,0.8,2)$ and fix two-bit unsigned codes with $z=0$. First share $s=2/3$ across the vector. Nearest rounding gives
<!-- bilingual-en:end -->

$$
q=(0,0,1,3),\qquad
\widehat w=(0,0,2/3,2).
$$

现在按相邻两个元素分组。第一组最大值为 $0.2$，取 $s_1=0.2/3=1/15$；第二组最大值为 $2$，取 $s_2=2/3$。两组分别编码为 $(1,3)$ 与 $(1,3)$，但解码时使用不同 scale：

<!-- bilingual-en:start -->
Now group adjacent pairs. The first group has maximum $0.2$, giving $s_1=0.2/3=1/15$; the second has maximum $2$, giving $s_2=2/3$. Both groups encode as $(1,3)$, but decode with different scales:
<!-- bilingual-en:end -->

$$
\widehat w=(1/15,0.2,2/3,2)
\approx(0.0667,0.2,0.6667,2).
$$

第一个小权重不再被舍入成 0，第二个被准确表示；同时，scale 从一个增加到两个。这个例子隔离了“固定码宽、改变参数共享范围”的效果，并未测量真实模型质量。

<!-- bilingual-en:start -->
The first small weight no longer rounds to zero, and the second is represented exactly. The number of scales also increases from one to two. This example isolates a change in parameter sharing at fixed code width, without measuring model quality.
<!-- bilingual-en:end -->

更细粒度可以缓解不同幅值共用范围的问题，但增加参数存储和处理要求。某种分组能否被高效 kernel 执行，属于[[量化加速条件]]；不能仅按分组更细就推断推理更快。

<!-- bilingual-en:start -->
Finer granularity can ease range sharing across different magnitudes, but adds parameter storage and processing requirements. Whether a grouping has an efficient kernel is part of [[量化加速条件|the conditions for quantization speedup]]. Finer groups alone do not imply faster inference.
<!-- bilingual-en:end -->

## 来源与核验

<!-- bilingual-en:start -->
*Sources and verification*
<!-- bilingual-en:end -->

- [Xiao et al. (2022), *SmoothQuant*](https://arxiv.org/html/2211.10438v1)，§2、Figure 2：支持 per-tensor/per-token/per-channel 的参数共享定义，以及分组轴影响矩阵 kernel 的实现。四权重例子是独立构造计算。
  <!-- bilingual-en:start -->
  Section 2 and Figure 2 define parameter sharing by tensor, token, and channel, and explain how the axis affects matrix-kernel implementation. The four-weight example is independently constructed and calculated.
  <!-- bilingual-en:end -->
- [Liu et al. (2024), *KIVI*](https://arxiv.org/html/2402.02750v2)，§3.1–3.3：提供沿不同轴量化 K/V 的具体实例，支持必须声明对象和分组轴；其特定轴选择不作为所有模型的通则。
  <!-- bilingual-en:start -->
  Sections 3.1–3.3 provide concrete K/V quantization along different axes, supporting the need to state the target and grouping axis. The paper's specific axis choices are not imposed on all models.
  <!-- bilingual-en:end -->
