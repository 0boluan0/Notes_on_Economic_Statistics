# 标准流是约定用于输入、常规输出和诊断输出的三个通道

Unix 命令通常通过标准输入 stdin、标准输出 stdout 与标准错误 stderr 接收输入、输出常规结果和输出诊断信息。在 Bash 重定向语法中，它们对应文件描述符 0、1、2。通道可以连接终端、文件或管道；不是每个程序都使用全部三个，也不能仅凭通道名称判断消息内容。
<!-- bilingual-en:start -->
Unix commands conventionally use standard input, standard output, and standard error for input, ordinary results, and diagnostics. Bash redirection syntax associates them with file descriptors 0, 1, and 2. They can connect to terminals, files, or pipes. Programs need not use all three, and a channel's name alone does not determine the meaning of its contents.
<!-- bilingual-en:end -->

```bash
printf '%s\n' result
printf '%s\n' diagnostic >&2
```

若 stdout 与 stderr 都连接同一个终端，两行都会出现在屏幕上，但它们仍是不同通道。只重定向 stdout 不会同时重定向 stderr；要组合两者须显式改变连接。
<!-- bilingual-en:start -->
If both standard output and standard error connect to the same terminal, both lines appear on screen while remaining distinct channels. Redirecting standard output alone does not redirect standard error; combining them requires an explicit connection change.
<!-- bilingual-en:end -->

标准输入也是字节流，不等于[[Shell简单命令|命令的参数列表]]。程序可以只读参数、只读 stdin、两者都读，或都不读。[[命令退出状态]]则是与这些输出内容分开的数值结果。
<!-- bilingual-en:start -->
Standard input is a byte stream, not the command's [[Shell简单命令|argument list]]. A program can read arguments, standard input, both, or neither. Its [[命令退出状态|exit status]] is a separate numerical result rather than the contents of these streams.
<!-- bilingual-en:end -->

- GNU Bash 3.2 本机 `bash(1)`，`REDIRECTION`、`Pipelines` 与 `EXIT STATUS`；[官方重定向章节](https://www.gnu.org/software/bash/manual/html_node/Redirections.html)：支持描述符 0、1、2、独立连接与状态的区别。
- [Missing Semester 2020：The Shell](https://missing.csail.mit.edu/2020/course-shell/)，Connecting programs；[Shell Tools](https://missing.csail.mit.edu/2020/shell-tools/)，stdout、stderr 与 return code 段：支持课程中的流接口。
<!-- bilingual-en:start -->
The local Bash manual supports descriptor numbers, independently redirected channels, and numerical status. The course introduces stream composition and distinguishes standard output, standard error, and return codes.
