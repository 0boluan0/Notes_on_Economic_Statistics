# State augmentation
<!-- bilingual-en:end -->
*状态扩充*

<!-- bilingual-en:start -->
**State augmentation** means putting information that still affects the next step into the current state. If tomorrow depends on both today and yesterday, calling only today's observation “the state” leaves out useful information. Calling the ordered pair “the state” lets a one-step transition carry that memory forward. The observations and their probabilities have not changed; their description has.
<!-- bilingual-en:end -->

**状态扩充**就是把仍会影响下一步的信息纳入当前状态。如果明天同时依赖今天和昨天，只把今天的观测叫作“状态”就漏掉了信息；把有序二元组叫作“状态”，一次转移就能把这份记忆带下去。没有改变观测本身及其概率规律，改变的是描述方式。

<!-- bilingual-en:start -->
The goal is a [[Markov充分状态|sufficient state]], which retains the historical information needed for prediction. The [[Markov性|Markov property]] then says that earlier augmented states add nothing to the next-state forecast once the current augmented state is known. Adding arbitrary variables is not a proof: the proposed state must contain the actual predictive information and must update using information it retains.
<!-- bilingual-en:end -->

目标是得到[[Markov充分状态|充分状态]]，保留历史中预测所需的信息。此时 [[Markov性]]意味着：知道当前扩充状态后，较早的扩充状态不再改变下一状态的预测。随便多加几个变量并不构成证明；新状态必须包含真正相关的信息，而且能利用已保留的信息继续更新。

> [!example] Remember two binary observations · 记住两个二元观测
> <!-- bilingual-en:start -->
> Let each observation $Z_n$ be $0$ or $1$. Suppose the chance that $Z_{n+1}=1$ depends only on the current value $a=Z_n$ and the previous value $b=Z_{n-1}$, with the following rule at every step. Take all four initial pairs $(Z_1,Z_0)$ to have probability $1/4$.
> <!-- bilingual-en:end -->
>
> 每个观测 $Z_n$ 取 $0$ 或 $1$。假设 $Z_{n+1}=1$ 的概率只依赖当前值 $a=Z_n$ 和前一个值 $b=Z_{n-1}$，每一步都用下面的规则；最初四个二元组 $(Z_1,Z_0)$ 各以 $1/4$ 的概率出现。
>
> | Current pair · 当前二元组 $(a,b)$ | $\Pr(Z_{n+1}=1\mid a,b)$ |
> |---|---:|
> | $(0,0)$ | $0.1$ |
> | $(0,1)$ | $0.7$ |
> | $(1,0)$ | $0.4$ |
> | $(1,1)$ | $0.9$ |
>
> <!-- bilingual-en:start -->
> Knowing only that today's value is $0$ does not distinguish probabilities $0.1$ and $0.7$. At the initial pair, forgetting yesterday averages them to $0.4$; recovering yesterday changes the forecast. Thus the original one-coordinate description is not first-order Markov. Set $X_n=(Z_n,Z_{n-1})$, with the **newest value first**. From $(0,1)$ the new value is $1$ with probability $0.7$, giving the next pair $(1,0)$; otherwise it is $0$, giving $(0,0)$ with probability $0.3$.
> <!-- bilingual-en:end -->
>
> 只知道今天为 $0$，无法区分 $0.1$ 和 $0.7$ 两种概率。在最初二元组中，忘记昨天会把它们平均成 $0.4$；再告诉你昨天的值，预测又会改变，因此原来只记一个坐标的表示并非一阶 Markov。令 $X_n=(Z_n,Z_{n-1})$，按**最新值在前**排列。从 $(0,1)$ 出发，以 $0.7$ 的概率得到新值 $1$，下一二元组是 $(1,0)$；否则以 $0.3$ 的概率得到 $0$，下一组是 $(0,0)$。

<!-- bilingual-en:start -->
Order the augmented states as $(0,0),(0,1),(1,0),(1,1)$. The [[Markov矩阵左右约定|row-stochastic convention]] puts the current state in the row and the next state in the column, so the transition matrix is
<!-- bilingual-en:end -->

把扩充状态按 $(0,0),(0,1),(1,0),(1,1)$ 排列。采用[[Markov矩阵左右约定|行随机约定]]，行表示当前状态、列表示下一状态，得到

$$P=\begin{pmatrix}
0.9&0&0.1&0\\
0.3&0&0.7&0\\
0&0.6&0&0.4\\
0&0.1&0&0.9
\end{pmatrix}.$$

<!-- bilingual-en:start -->
Each row sums to one. The zeros enforce the shift: the second coordinate of the next pair must equal the first coordinate of the current pair. For example, from $(0,1)$ a one-step move to $(1,1)$ is impossible. Earlier pairs cannot change either the new observation's law or the copied coordinate, so the pair process is Markov.
<!-- bilingual-en:end -->

每行之和为一。零元素表达了移位约束：下一组的第二坐标必须等于当前组的第一坐标。例如，$(0,1)$ 不可能一步变成 $(1,1)$。更早的二元组既不能改变新观测的条件律，也不能改变复制的坐标，所以二元组过程具有 Markov 性。

## A finite-memory construction and why it works
<!-- bilingual-en:end -->
*有限记忆的一般构造与理由*

<!-- bilingual-en:start -->
Let $Z_n$ take values in a finite or countable set, and let $k\ge1$ be an integer. Assume that for every $n\ge k-1$ the [[条件分布|conditional law]] of the next observation given its full history depends only on the most recent $k$ observations. Write that law as $q_n(z\mid a_1,\ldots,a_k)$, where $z$ is the new value and $a_1,\ldots,a_k$ list the recent values newest first:
<!-- bilingual-en:end -->

设 $Z_n$ 取值于有限或可数集合，整数 $k\ge1$。假设对每个 $n\ge k-1$，下一观测在完整历史下的[[条件分布|条件律]]只依赖最近 $k$ 个观测。用 $q_n(z\mid a_1,\ldots,a_k)$ 表示这份概率，其中 $z$ 是新值，$a_1,\ldots,a_k$ 按从新到旧排列：

$$\Pr(Z_{n+1}=z\mid Z_0,\ldots,Z_n)
=q_n(z\mid Z_n,Z_{n-1},\ldots,Z_{n-k+1}).$$

<!-- bilingual-en:start -->
This equality is required on histories of positive probability. Define the augmented state and its update by
<!-- bilingual-en:end -->

等式要求在正概率历史上成立。定义扩充状态及其更新：

$$X_n=(Z_n,Z_{n-1},\ldots,Z_{n-k+1}),$$
$$X_{n+1}=(Z_{n+1},Z_n,\ldots,Z_{n-k+2}).$$

<!-- bilingual-en:start -->
Given $X_n=(a_1,\ldots,a_k)$, draw $z$ according to $q_n$ and move to $(z,a_1,\ldots,a_{k-1})$. All other next tuples have probability zero. The old coordinates are already known, and the only new coordinate has a law determined by $X_n$ and $n$. This directly proves the first-order Markov condition. For $k=1$ there are no copied older coordinates: this is the original one-coordinate process.
<!-- bilingual-en:end -->

给定 $X_n=(a_1,\ldots,a_k)$，按 $q_n$ 抽取 $z$，然后移到 $(z,a_1,\ldots,a_{k-1})$；其他下一元组的概率都是零。旧坐标已经确定，唯一的新坐标也只按 $X_n$ 和 $n$ 决定分布，这就直接证明一阶 Markov 条件。$k=1$ 时没有需要复制的更旧坐标，得到的就是原来只用一个坐标的过程。

<!-- bilingual-en:start -->
The first augmented state is $X_{k-1}=(Z_{k-1},\ldots,Z_0)$. Specify its joint distribution as part of the model; the first $k$ observations need not be independent. Reindexing this initial tuple as step zero changes only the clock label.
<!-- bilingual-en:end -->

第一个扩充状态是 $X_{k-1}=(Z_{k-1},\ldots,Z_0)$。模型需要指定它的联合分布，不能擅自认为最初 $k$ 个观测相互独立。把这个初始元组重新编号为第零步，只是改变时间标签。

> [!warning] First-order, homogeneous and finite are separate properties · 一阶、齐次、有限是不同性质
> <!-- bilingual-en:start -->
> If the rule $q_n$ can be chosen independent of $n$ on the model's state space, the augmented chain has a [[DTMC时间齐次转移核|time-homogeneous kernel]]. If the specified rule still changes with $n$, the tuple construction keeps that time dependence. Appending the clock as another coordinate, $(n,X_n)$, can encode this rule as a homogeneous transition on a larger state space: read $n$, use $q_n$, then increment the clock. An unbounded clock creates infinitely many states even when each $X_n$ has only finitely many possibilities.
> <!-- bilingual-en:end -->
>
> 若在模型状态空间上可以把规则 $q_n$ 选为不随 $n$ 改变，扩充链就有[[DTMC时间齐次转移核]]。若指定规则仍随 $n$ 变化，组成元组并不会消除它。把时钟也纳入状态，写成 $(n,X_n)$，可以在更大的空间上把这套规则编码为齐次转移：先读出 $n$、使用 $q_n$，再把时钟加一。但无上限的时钟会产生无穷多个状态，即使每个 $X_n$ 只有有限种可能。

<!-- bilingual-en:start -->
With $r$ possible original values, the length-$k$ tuple has at most $r^k$ candidate states; some may be unreachable. A binary process requiring the latest three observations uses $(Z_n,Z_{n-1},Z_{n-2})$ and at most $2^3=8$ states. This can increase storage, transition parameters and data requirements, even though the shift forces many matrix entries to zero. Nor does every dependence mechanism have a fixed finite memory: unobserved regimes, unbounded durations or genuinely infinite memory require a separate sufficiency argument. A longer window is not automatically enough.
<!-- bilingual-en:end -->

原观测有 $r$ 种取值时，长度为 $k$ 的元组至多有 $r^k$ 个候选状态，其中一些可能不可达。需要最近三期的二元过程可用 $(Z_n,Z_{n-1},Z_{n-2})$，至多有 $2^3=8$ 个状态。这可能增加存储、转移参数和数据需求，尽管移位约束会使很多矩阵条目为零。也不是每种依赖都具有固定的有限记忆：未观测制度、无上限持续时间或真正的无限记忆，都需要另外论证充分性；窗口更长并不自动意味着足够。
