# 正整数反复向下取整减半直到零需要对数级迭代次数

<!-- bilingual-en:start -->
*Repeated floor-halving of a positive integer reaches zero in logarithmically many iterations*
<!-- bilingual-en:end -->

从整数 $m_0=n\ge1$ 开始，只要 $m_t>0$ 就执行一次 $m_{t+1}=\lfloor m_t/2\rfloor$，总迭代次数恰为 $\lfloor\log_2 n\rfloor+1$。若 $n=0$ 则执行零次。该结论数的是迭代次数，不是无条件的运行时间。

<!-- bilingual-en:start -->
Starting from integer $m_0=n\ge1$, repeatedly apply $m_{t+1}=\lfloor m_t/2\rfloor$ while $m_t>0$. The exact iteration count is $\lfloor\log_2 n\rfloor+1$; it is zero for $n=0$. This counts iterations, not unconditional running time.
<!-- bilingual-en:end -->

因为 $m_t=\lfloor n/2^t\rfloor$，第一次变为零等价于 $2^t>n$，所以最小整数 $t$ 就是上述表达式，渐近为 $\Theta(\log(n+1))$。例如 $n=8$ 时状态是 $8,4,2,1,0$，执行四次更新。若终止条件改为 $m\le1$，精确次数也会改变，不能原样套用。

<!-- bilingual-en:start -->
Since $m_t=\lfloor n/2^t\rfloor$, reaching zero first means finding the least integer $t$ with $2^t>n$. This gives the expression above and asymptotic count $\Theta(\log(n+1))$. For $n=8$, the states are $8,4,2,1,0$, requiring four updates. Stopping at $m\le1$ changes the exact count.
<!-- bilingual-en:end -->

若每轮总工作为统一的 $\Theta(1)$，则可直接由对数轮数推出对数时间；这是一个充分的成本条件。[[二分查找]]在常数时间随机访问与比较模型下使用这个机制；若每轮复制当前区间，必须改用[[循环成本求和]]或[[分治成本模型]]，具体见[[切片二分成本]]。

<!-- bilingual-en:start -->
Uniformly $\Theta(1)$ work per iteration is sufficient to infer logarithmic time directly from logarithmically many iterations. [[二分查找|Binary search]] uses this mechanism under constant-time random access and comparison. Copying the current interval on each round requires [[循环成本求和|summing loop costs]] or a [[分治成本模型|divide-and-conquer cost model]]; see [[切片二分成本|slicing binary-search costs]].
<!-- bilingual-en:end -->
