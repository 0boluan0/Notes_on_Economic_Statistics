# 生成同一开集族的度量给出同一拓扑但不保留距离大小
<!-- bilingual-en:start -->
*Metrics that generate the same open sets define the same topology but need not preserve numerical distances*
<!-- bilingual-en:end -->

> [!summary] 原子命题
> 同一集合 $X$ 上的两个度量 $d_1,d_2$ 若生成完全相同的开集族，就称它们诱导同一拓扑。此时开闭性、收敛、连续性、紧致性与连通性相同；具体距离、直径、Lipschitz 常数等数值几何量却未必相同。
> <!-- bilingual-en:start -->
> Two metrics induce the same topology when they generate exactly the same open sets. Topological properties then agree, while metric magnitudes need not.
> <!-- bilingual-en:end -->

例如在任意度量空间中令
$$
\rho(x,y)=\min\{1,d(x,y)\}.
$$
$\rho$ 仍是度量；其中三角不等式可由 $\min\{1,a+b\}\leq\min\{1,a\}+\min\{1,b\}$ 核对。半径小于 1 时，$d$ 与 $\rho$ 的开球相同，所以二者生成同一开集族；但若 $d$ 无界，$\rho$ 的所有距离都不超过 1。于是“拓扑相同”绝不等于“距离相同”或“存在统一比例缩放”。

应用时先问结论依赖哪一层结构：只谈极限、连续或开集，通常只需拓扑；谈收敛速度、误差界或 Lipschitz 性，则仍需具体度量。

> [!question]- 自检
> 把 $d$ 换成 $\min\{1,d\}$ 后，为什么远处的距离信息变了而收敛序列不变？
>
> **答案：** 收敛只检查任意小半径的邻域；半径小于 1 时两种度量完全一致。截断只压平较大的距离。
