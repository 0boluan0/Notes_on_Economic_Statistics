# break、continue 与 return 跳转到不同控制流边界
<!-- bilingual-en:start -->
*`break`, `continue`, and `return` transfer control to different boundaries*
<!-- bilingual-en:end -->

> [!summary] 原子边界
> `break` 结束最近一层包围它的 `for` 或 `while`；`continue` 跳过本轮余下语句，进入最近一层循环的下一轮；`return` 结束当前函数调用，并把给定表达式结果或省略时的 `None` 交还调用者。它们不是强弱不同的“停止”命令，而是目的地不同的控制转移。
> <!-- bilingual-en:start -->
> `break` terminates the nearest enclosing `for` or `while`; `continue` skips the rest of the current iteration and begins the next cycle of the nearest loop; `return` ends the current function call and gives its caller the expression result, or `None` when no expression is supplied. They are not stronger and weaker versions of one stop command; they have different destinations.
> <!-- bilingual-en:end -->

```python
def first_even(values):
    for value in values:
        if value < 0:
            continue          # next item
        if value % 2 == 0:
            return value      # leave the function
    return None
```

在嵌套循环中，`break` 与 `continue` 只针对最近一层循环，不会自动退出所有外层循环。循环的 `else` 在 `while` 条件变假或 `for` iterator 正常耗尽时执行；`break` 会明确跳过它，`return` 与未处理异常也会因离开当前流程而不进入它。`return` 离开整个当前函数，而不是仅离开循环。若控制转移穿过 `try/finally`，`finally` 会先执行；其中新抛出的异常或新的 `return`、`break`、`continue` 还可能替换原先待完成的转移，因此不能把原目的地视为无条件保证。
<!-- bilingual-en:start -->
In nested loops, `break` and `continue` target only the nearest loop; they do not automatically leave every outer loop. A loop's `else` suite runs when a `while` condition becomes false or a `for` iterator is normally exhausted. `break` explicitly skips it, while `return` and an unhandled exception also leave the current flow before it can run. `return` leaves the entire current function rather than merely its loop. If a transfer crosses `try/finally`, the `finally` suite runs first; a newly raised exception or a new `return`, `break`, or `continue` there can replace the pending transfer, so the original destination is not unconditional.
<!-- bilingual-en:end -->

> [!question]- 回忆与应用
> 函数里的双层循环执行内层 `break` 后，函数和外层循环都结束了吗？
>
> **答案：** 没有。它只结束最近的内层循环；要离开函数需执行 `return` 或用其他显式结构传递结果。
