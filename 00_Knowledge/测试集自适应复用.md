# 测试集自适应复用是反复依据同一测试集结果选择模型或流程，使该测试集参与开发决策的过程
<!-- bilingual-en:start -->
*Adaptive test-set reuse repeatedly uses results from the same test set to select a model or procedure, making that test set part of development*
<!-- bilingual-en:end -->

> [!summary] 它是什么
> 测试集本来应在所有拟合与选择完成后提供独立检验。若分析者查看同一 test set 的分数或错误，再据此改变变量、预处理、超参数、模型版本、prompt 或工具，测试集就反复参与方案选择；最终分数混入了对这批测试观测的适配。
>
> <!-- bilingual-en:start -->
> A test set is meant to provide an independent check after fitting and selection are complete. If its scores or errors then change variables, preprocessing, hyperparameters, model versions, prompts, or tools, that test set repeatedly participates in selecting the design. The final score includes adaptation to those observations.
> <!-- bilingual-en:end -->

## 它怎样发生
<!-- bilingual-en:start -->
*How it arises*
<!-- bilingual-en:end -->

设同一 holdout $H$ 上试了 $K$ 个方案，并选择

$$
k^*=\arg\max_{k\le K} S_k(H).
$$

即使每个 $S_k(H)$ 都带有有限样本噪声，选择最大值也会偏向偶然有利的方案；之后若继续查看错误并迭代，方案还会逐步学习 $H$ 的特殊结构。未参与选择的新数据上的表现通常低于这个被选择后的最大分数。
<!-- bilingual-en:start -->
Suppose $K$ designs are tried on one holdout $H$ and $k^*=\arg\max_{k\le K}S_k(H)$ is selected. Even when each score contains only finite-sample noise, selecting the maximum favors a lucky design. Continued error inspection lets the design adapt further to peculiarities of $H$. Performance on fresh data will generally be lower than the selected maximum.
<!-- bilingual-en:end -->

## 它不是训练数据污染
<!-- bilingual-en:start -->
*It is not training-data contamination*
<!-- bilingual-en:end -->

[[训练评测污染]]要求评测内容进入模型训练数据；测试集自适应复用只要求测试反馈进入开发决策。两者可以同时发生，也可以各自单独发生。即使模型参数从未接触 test 文本，反复用 test 选择 prompt 或工具仍会削弱分数的独立性。
<!-- bilingual-en:start -->
[[训练评测污染]] requires evaluation content to enter model-training data. Adaptive reuse requires only that test feedback enter development decisions. They can co-occur or arise separately. Even if model parameters never see test text, repeated prompt or tool selection on that test weakens score independence.
<!-- bilingual-en:end -->

Dwork et al. 研究一般的 adaptive holdout reuse；Cawley 与 Talbot 则说明模型选择准则本身也会被过拟合。回归变量筛选、机器学习调参，以及 prompt、工具和模型版本选择，都是“根据 holdout 结果决定下一次尝试”的具体形式。
<!-- bilingual-en:start -->
Dwork et al. study adaptive holdout reuse in general, while Cawley and Talbot show that a model-selection criterion can itself be overfitted. Regression-variable search, machine-learning tuning, and the selection of prompts, tools, or model versions are all concrete forms of choosing the next attempt from holdout feedback.
<!-- bilingual-en:end -->

> [!example] 最小例子
> 团队在同一 200 道 test set 上试 100 个 prompts，报告最高分。题目从未进入模型训练数据，因此没有内容污染；但 test 已经成为 prompt 开发集，最高分不再是独立验收结果。
>
> <!-- bilingual-en:start -->
> A team tries 100 prompts on the same 200-item test set and reports the best score. The items never entered model training, so there is no content contamination; nevertheless, the test set has become a prompt-development set and the maximum is no longer an independent validation result.
> <!-- bilingual-en:end -->

> [!question]- 自检
> 怎样恢复独立验收？
>
> **答案：** 把开发与最终验收分开：记录尝试，使用未参与选择的 final holdout、嵌套评测、刷新题集或时间后移数据；不要在看到最终集结果后继续调参并仍称它为 test。

## 来源与核验
<!-- bilingual-en:start -->
*Sources and verification*
<!-- bilingual-en:end -->

- [Dwork et al. (2015), *Generalization in Adaptive Data Analysis and Holdout Reuse*](https://arxiv.org/abs/1506.02629)：形式化并实验展示依据同一 holdout 结果反复选择会对 holdout 过拟合。
- [Cawley and Talbot (2010), *On Over-fitting in Model Selection and Subsequent Selection Bias in Performance Evaluation*](https://jmlr.csail.mit.edu/papers/volume11/cawley10a/cawley10a.pdf)：核验有限验证准则也会被模型选择过程过拟合，最终评价必须把选择视为拟合流程的一部分。
- [Grattafiori et al. (2024), *The Llama 3 Herd of Models*](https://arxiv.org/abs/2407.21783)：核对这一通用原则在提示、评测配置和污染报告中的 LLM 专门应用。
