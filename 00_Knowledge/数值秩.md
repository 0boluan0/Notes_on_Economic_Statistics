# Numerical rank
<!-- bilingual-en:end -->

*数值秩*

<!-- bilingual-en:start -->
A matrix can distinguish two input directions exactly, while one of them produces an output too small to distinguish reliably at the working precision. **Numerical rank** counts the directions treated as nonzero under a stated tolerance and decision rule. It describes a working resolution, not just the exact entries of a matrix.
<!-- bilingual-en:end -->

一个矩阵在精确数学中可能区分两个输入方向，但其中一个产生的输出非常微弱，在当前精度下难以可靠地分辨。**数值秩**是在声明容差和判定规则后，被当作非零的方向个数。它描述采用的分辨尺度，不只由矩阵的精确元素决定。

> [!example] Two exact directions, one weak response / 两个精确方向，一个微弱响应
> <!-- bilingual-en:start -->
> The [[对角矩阵|diagonal matrix]] $A=\operatorname{diag}(1,10^{-8})$ sends $(x_1,x_2)^T$ to $(x_1,10^{-8}x_2)^T$. Both directions survive, so its exact [[矩阵秩|rank]] is 2. If the rule treats stretches at or below $10^{-6}$ as zero, only the first direction survives that rule and the numerical rank is 1. With threshold $10^{-10}$ it is 2. No matrix entry changed; the resolution changed. Here $T$ is [[矩阵转置|transpose]], used to write a column vector.
> <!-- bilingual-en:end -->
>
> [[对角矩阵]] $A=\operatorname{diag}(1,10^{-8})$ 把 $(x_1,x_2)^T$ 送到 $(x_1,10^{-8}x_2)^T$。两个方向都没有被完全消去，所以精确[[矩阵秩]]为2。若把不超过 $10^{-6}$ 的伸缩量当作零，只有第一方向被保留，数值秩为1；改用 $10^{-10}$，数值秩就是2。矩阵没有改变，改变的是分辨尺度。$T$ 是[[矩阵转置|转置]]，这里用来写列向量。

<!-- bilingual-en:start -->
The [[奇异值分解|singular value decomposition]] separates a matrix into perpendicular input directions and their matching output directions. Its nonnegative [[奇异值|singular values]] are the stretch amounts. For an $m\times n$ real or complex matrix, with $m,n\ge1$, list them as $\sigma_1\ge\cdots\ge\sigma_p\ge0$, where $p=\min(m,n)$. Under the singular-value-threshold convention, an absolute tolerance $\tau\ge0$ defines
<!-- bilingual-en:end -->

[[奇异值分解]]把矩阵分成相互垂直的输入方向及其配对输出方向，非负的[[奇异值]]就是各方向的伸缩量。对 $m\times n$ 实或复矩阵，$m,n\ge1$，将奇异值列为 $\sigma_1\ge\cdots\ge\sigma_p\ge0$，其中 $p=\min(m,n)$。采用奇异值阈值口径，给定绝对容差 $\tau\ge0$，定义

$$\operatorname{rank}_\tau(A)=\#\{i:\sigma_i>\tau\}.$$

<!-- bilingual-en:start -->
The symbol $\#$ means “number of indices.” Equality with the threshold is classified as zero here. At $\tau=0$ this reduces to [[奇异值与秩|algebraic rank]], which counts all positive singular values. For the zero matrix the count is zero at every nonnegative threshold. Another endpoint convention must be stated if used.
<!-- bilingual-en:end -->

$\#$ 表示“满足条件的下标个数”。这里恰好等于阈值也判为零。取 $\tau=0$ 就得到[[奇异值与秩|代数秩]]，即全部正奇异值的个数；零矩阵在任意非负阈值下计数均为零。若采用不同的等号处理规则，需要明说。

<!-- bilingual-en:start -->
## Absolute and relative tolerances
<!-- bilingual-en:end -->

## 绝对阈值与相对阈值

<!-- bilingual-en:start -->
An absolute tolerance uses the same units as the singular values. A relative tolerance uses a dimensionless number $\rho\ge0$ and sets $\tau=\rho\sigma_1$. Multiplying the whole matrix by a nonzero scalar multiplies every singular value by that scalar's absolute value. A fixed relative rule therefore preserves the count under overall rescaling; a fixed absolute threshold need not. For $A=0$, use $\tau=0$ and the same strict comparison, without dividing by $\sigma_1$.
<!-- bilingual-en:end -->

绝对阈值与奇异值使用相同的单位。相对口径采用无量纲数 $\rho\ge0$，设置 $\tau=\rho\sigma_1$。整个矩阵乘非零标量后，全部奇异值都乘该标量的绝对值，因此固定的相对规则在整体缩放下保持计数；固定绝对阈值则未必如此。若 $A=0$，直接使用 $\tau=0$ 和同一严格比较，不需要除以 $\sigma_1$。

<!-- bilingual-en:start -->
Changing individual columns' units is not an overall rescaling and can change even a relative count. For example, replacing the second input unit in the opening problem by a factor of $10^8$ changes the displayed matrix to $I_2$, the [[单位矩阵|identity]]. A numerical rank report therefore needs the matrix's scaling, the tolerance, and the algorithm. Machine rounding, measurement error and acceptable downstream error are different considerations; a software default does not choose all three for you.
<!-- bilingual-en:end -->

分别改变某些列的单位并非整体缩放，即使使用相对阈值，计数也可能改变。例如把开头问题的第二个输入单位换成原来的 $10^8$ 倍，显示的矩阵就变为[[单位矩阵]] $I_2$。所以数值秩报告需要包含矩阵缩放、容差与算法。机器舍入、测量误差和下游可接受误差是不同考虑，软件默认值不会自动替你决定三者。

<!-- bilingual-en:start -->
## The algorithm is part of the reported rule
<!-- bilingual-en:end -->

## SVD 阈值与 CPQR 估计不是同一判定

<!-- bilingual-en:start -->
For the usual parameter range $0<\mathrm{RCOND}<1$, LAPACK's SVD-based `DGELSD` counts singular values strictly above $\mathrm{RCOND}\,\sigma_1$. A value equal to the cutoff is discarded. A negative `RCOND` requests a machine-precision default. Do not interpret every other input value by blindly substituting it into the mathematical definition: the current `DLALSD` backend also uses machine precision when `RCOND` is zero or at least one. Thus setting the software parameter to zero is not a reliable way to request exact algebraic rank.
<!-- bilingual-en:end -->

在通常参数范围 $0<\mathrm{RCOND}<1$ 内，LAPACK 的 SVD 求解器 `DGELSD` 计数严格大于 $\mathrm{RCOND}\,\sigma_1$ 的奇异值，等于截断值时舍去。负 `RCOND` 请求机器精度默认值。其他输入值不能一律直接代入数学定义：当前 `DLALSD` 后端在 `RCOND` 为零或至少为1时，也会采用机器精度。因此，把软件参数设为零，并不能可靠地要求它报告精确代数秩。

<!-- bilingual-en:start -->
The [[CPQR秩揭示边界|column-pivoted QR]] route uses different evidence. `DGELSY` examines a leading triangular block and estimates its conditioning: roughly, whether solving with that block would amplify relative errors too much. `RCOND` controls which block is accepted; its size is the reported rank. This is not the direct singular-value count, and the two solvers need not agree on every matrix. A successful factorization also does not establish that its rank decision is suitable for the data's uncertainty.
<!-- bilingual-en:end -->

[[CPQR秩揭示边界|列主元 QR]] 路线使用另一种证据。`DGELSY` 检查领先三角块并估计其条件性，直观上是在判断用这个块求解会不会过度放大相对误差。`RCOND` 控制接受哪个块，块的阶数便是报告的秩。它并非直接数奇异值，两种求解器不保证对每个矩阵给出相同结果；成功完成分解，也不证明判秩规则适合数据的不确定程度。

> [!important] A rank decision changes what is recovered / 判秩决定恢复哪些方向
> <!-- bilingual-en:start -->
> [[截断SVD反演|Truncated SVD inversion]] actually removes the selected small directions from the inverse model. [[岭的SVD滤波公式|Ridge filtering]] instead continuously shrinks their contribution. Neither a small singular value nor a numerical-rank label alone proves that a direction contains only noise. State the rule and its purpose before interpreting the recovered coefficients.
> <!-- bilingual-en:end -->
>
> [[截断SVD反演]]会实际从反演模型中移除选定的小方向；[[岭的SVD滤波公式|岭滤波]]则连续收缩其贡献。仅凭小奇异值或“数值秩”的标签，都不能证明某方向只含噪声。解释恢复的系数前，应先说明规则及目的。
