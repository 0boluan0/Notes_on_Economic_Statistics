# 簇数选择是在候选分辨率之间，结合内部准则、稳定性、外部证据和用途选择保留哪个分区的过程
<!-- bilingual-en:start -->
*Choosing the number of clusters is the process of selecting which partition resolution to retain by combining internal criteria, stability, external evidence, and purpose*
<!-- bilingual-en:end -->

> [!summary] 原子定义
> 簇数选择先在同一分析流程下产生若干候选分区，再比较每个分区的内部几何、重复性、外部含义和实际用途，最后决定保留哪一个粒度。这是模型选择过程，不是从单个分数中读出一个答案。
> <!-- bilingual-en:start -->
> Cluster-count selection first generates candidate partitions under one analysis pipeline, then compares their internal geometry, repeatability, external meaning, and practical use before retaining a resolution. It is a model-selection process rather than reading an answer from one score.
> <!-- bilingual-en:end -->

## 先生成可比的候选分区

对层次聚类，候选分区来自同一棵树的不同 [[树状图切割|切割]]；对 K-means，则对不同 $K$ 分别求解同一 [[K-means目标]]。比较期间应锁定观察单位、变量、尺度、距离、算法和数据范围；否则“换 $K$”会与其他改动混在一起。

K-means 的每个候选 $K$ 还要使用足够的 [[K-means多启动]]，以免把某个 $K$ 的差初值当成这个分辨率本身的问题。

## 再说每项证据回答什么

- elbow 比较 WCSS 继续下降的边际幅度；
- [[轮廓系数]]比较指定距离下的簇内紧密与簇间分离；
- gap statistic 把观测到的离散度与某个无簇参照分布比较；
- 重采样稳定性检查换一批样本后分区是否可重现；
- 领域或决策证据检查这个粒度是否能被命名、复现和使用。

这些证据不需要给出同一结论。簇数为何不存在无条件的自动真值，单独见 [[簇数不是自动真值]]。

> [!question]- 自检
> 对 $K=2,3,4$ 各得到一个 K-means 分区。为什么不能在 $K=2$ 用原始变量、$K=3$ 用标准化变量、$K=4$ 又删掉一列，然后把三个 silhouette 直接比较？
>
> **答案：** 因为三次运行同时改了尺度和表示，silhouette 差异不再只是簇数差异。要比较 $K$，必须先锁定其他流程决定。

## 来源与核验

- Tibshirani, Walther & Hastie (2001), [*Estimating the Number of Clusters in a Data Set via the Gap Statistic*](https://doi.org/10.1111/1467-9868.00293)：核对参照分布、gap 统计量和候选 $K$ 选择框架。
- [scikit-learn, selecting $K$ with silhouette analysis](https://scikit-learn.org/stable/auto_examples/cluster/plot_kmeans_silhouette_analysis.html)：核对用轮廓图和平均 silhouette 比较候选 $K$ 的实例。
- [Penn State STAT 505, Lesson 14](https://online.stat.psu.edu/stat505/Lesson14)：核对层次树切割和 K-means 的簇数需要由分析者结合领域目的选择。
