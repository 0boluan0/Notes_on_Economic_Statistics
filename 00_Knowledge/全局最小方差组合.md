# 全局最小方差组合在给定可行权重中取得最小收益方差而不预设目标收益
<!-- bilingual-en:start -->
*A global minimum-variance portfolio minimizes return variance over the allowed weights without imposing a target expected return.*
<!-- bilingual-en:end -->

设资产收益具有有限二阶矩，权重可行域为 $\mathcal W$。**全局最小方差组合**（GMV）是下述问题的任意一个最优解；“全局”指与 $\mathcal W$ 中所有权重比较，不是只在某一指定收益水平上比较：
<!-- bilingual-en:start -->
For asset returns with finite second moments and allowed weights $\mathcal W$, a global minimum-variance portfolio is any optimizer of the following problem. “Global” compares all weights in $\mathcal W$, rather than only those at one prescribed expected return:
<!-- bilingual-en:end -->

$$
w_G\in\operatorname*{arg\,min}_{w\in\mathcal W}w^T\Sigma w.
$$

当 $\mathcal W$ 只由预算、权重上下限等不依赖 $\mu$ 的约束决定时，GMV 权重只需协方差输入；求出权重后，仍要用 $\mu_G=w_G^T\mu$ 才知道它的期望收益。若可行域本身含收益要求，便不能再声称整个问题与均值无关。
<!-- bilingual-en:start -->
When $\mathcal W$ contains only constraints independent of $\mu$, such as the budget and weight bounds, GMV weights depend only on covariance inputs. Their expected return still requires $\mu_G=w_G^T\mu$. If feasibility itself includes a return requirement, the problem is no longer independent of means.
<!-- bilingual-en:end -->

例如 $\Sigma=\begin{bmatrix}0.04&0.015\\0.015&0.09\end{bmatrix}$，只要求权重和为 1。[[全局最小方差解]]给出 $w_G=(0.75,0.25)^T$，方差为 $0.03375$。再代入 $\mu=(0.08,0.12)^T$，得到 $\mu_G=0.09$；这个 $9\%$ 是结果，不是事先指定的目标。
<!-- bilingual-en:start -->
For the stated covariance matrix and only a unit-sum constraint, the [[全局最小方差解|GMV solution]] is $w_G=(0.75,0.25)^T$ with variance $0.03375$. Using $\mu=(0.08,0.12)^T$ then gives $\mu_G=0.09$. The $9\%$ mean is an output, not a prescribed target.
<!-- bilingual-en:end -->

定义本身不保证最优解存在或唯一。经典正定模型中的存在与唯一性由[[全局最小方差解]]保证；有多个最小方差组合时，还可能有同方差但收益更高者，所以不能把每一个 GMV 权重无条件称为[[均值方差有效前沿|有效组合]]。
<!-- bilingual-en:start -->
The definition alone guarantees neither existence nor uniqueness. The [[全局最小方差解|positive-definite GMV result]] supplies both in the classical model. If several portfolios attain the minimum variance, one may have a higher mean than another, so not every GMV allocation is unconditionally [[均值方差有效前沿|mean-variance efficient]].
<!-- bilingual-en:end -->
