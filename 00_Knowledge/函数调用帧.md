# 普通用户函数每次调用都会建立新局部 frame 并把实参对象绑定到形参
<!-- bilingual-en:start -->
*Each call to an ordinary user-defined function creates a new local frame and binds argument objects to parameters*
<!-- bilingual-en:end -->

> [!summary] 原子调用模型
> 调用前，Python 先求值 callable 与全部实参表达式；随后按位置、关键字和默认值规则填充形参。普通用户函数每次成功调用都有独立的局部 frame，形参只是该 frame 中新建的名称绑定。缺少必需实参、重复填充同一形参或出现不接受的额外实参会产生 `TypeError`，而不是让函数体自行猜测。
> <!-- bilingual-en:start -->
> Before a call, Python evaluates the callable and all argument expressions, then fills parameters using positional, keyword, and default rules. Every successful call to an ordinary user-defined function has an independent local frame whose parameters are fresh name bindings. Missing, duplicate, or unsupported arguments raise `TypeError` instead of being resolved by the body.
> <!-- bilingual-en:end -->

```python
def append_one(items):
    items.append(1)

values = []
append_one(values)
```

新 frame 隔离的是形参和局部名称，不会复制传入对象。上例中 `items` 与 `values` 是不同 frame 里的名称，却引用同一个列表，所以原地修改对调用者可见；若函数只把 `items` 改绑到另一个列表，`values` 的绑定不会随之改变。递归只是同一规则反复应用，每层调用仍有自己的 frame。

> [!question]- 自检
> 两次调用同一个函数时，为什么两个形参同名却不会互相覆盖；这是否意味着可变实参被复制？
>
> **答案：** 每次调用建立独立局部 frame，所以名称绑定分开；对象不会因此自动复制，不同 frame 仍可能引用同一可变对象。
