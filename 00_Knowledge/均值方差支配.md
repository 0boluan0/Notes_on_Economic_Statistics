# 期望收益不低且方差不高并至少一项严格改善构成均值方差支配
<!-- bilingual-en:start -->
*Mean-variance dominance means no lower expected return and no higher variance, with at least one strict improvement.*
<!-- bilingual-en:end -->

对同一期间、同一收益口径且二阶矩有限的两个可行组合 $a,b$，若
<!-- bilingual-en:start -->
For two feasible portfolios $a,b$ over the same horizon and return convention, with finite second moments, portfolio $a$ mean-variance dominates $b$ when
<!-- bilingual-en:end -->

$$
\mu_a\ge\mu_b,\qquad \sigma_a^2\le\sigma_b^2,
\qquad (\mu_a,\sigma_a^2)\ne(\mu_b,\sigma_b^2),
$$

就称 $a$ **均值方差支配** $b$。比较标准差得到相同关系，因为平方根在非负数上严格递增。两项完全相同不是严格支配，即使两个配置的权重不同。
<!-- bilingual-en:start -->
Using standard deviations gives the same relation because the square root is strictly increasing on nonnegative numbers. Equal means and variances do not constitute strict dominance, even when portfolio weights differ.
<!-- bilingual-en:end -->

例如期望收益 $10\%$、标准差 $20\%$ 的组合，支配期望收益 $8\%$、标准差同为 $20\%$ 的组合。但 $10\%/20\%$ 与 $9\%/18\%$ 各有一项较好，仅凭这条关系无法排序。
<!-- bilingual-en:start -->
A portfolio with expected return $10\%$ and standard deviation $20\%$ dominates one with expected return $8\%$ and the same standard deviation. In contrast, $10\%/20\%$ and $9\%/18\%$ each improve on a different dimension, so this relation alone cannot rank them.
<!-- bilingual-en:end -->

它是[[均值方差准则|均值—方差评价]]中的比较关系，不是“每种状态收益都较高”，也不自动等于对所有递增效用函数的偏好。是否能用均值和方差完整代表投资者的选择，需要另查[[均值方差偏好边界]]。
<!-- bilingual-en:start -->
This is a comparison within the [[均值方差准则|mean-variance criterion]], not higher returns in every state or a preference shared by every increasing utility function. Whether two moments fully represent an investor's choices is governed by the [[均值方差偏好边界|preference boundary of mean-variance analysis]].
<!-- bilingual-en:end -->

## 来源与核验
<!-- bilingual-en:start -->
*Sources and verification*
<!-- bilingual-en:end -->

- [Zivot, *Portfolio Theory with Matrix Algebra*, PDF pp.10–11](https://faculty.washington.edu/ezivot/econ424/portfolioTheoryMatrix.pdf#page=10)：支持在可行组合间比较期望收益与风险的效率准则；本卡把“不差且至少一项严格更好”写成明确关系，不把它等同一般效用排序。
- [[均值方差偏好边界]]：承接均值—方差比较与真实偏好之间需要的附加条件。例中的严格与不可比较关系逐项代入定义核验。
<!-- bilingual-en:start -->
- Zivot, PDF pp.10–11, supports efficiency comparisons using expected return and risk. This note formalizes weak improvement in both dimensions with at least one strict improvement, without identifying it with unrestricted utility rankings.
- [[均值方差偏好边界|The preference-boundary atom]] handles the additional assumptions needed for preference claims. Both examples are checked directly against the inequalities.
