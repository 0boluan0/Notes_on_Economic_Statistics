# 完整依赖边让增量构建与并行构建都保持正确
<!-- bilingual-en:start -->
*Complete dependency edges preserve correctness in both incremental and parallel builds*
<!-- bilingual-en:end -->

> [!summary] 原子不变量
> 每个目标必须声明会影响其结果的真实输入，以及必须在它之前完成的真实生产者。这样，同一张图既能决定哪些目标因输入变化而失效，也能决定哪些互不依赖的配方可以安全并行。
> <!-- bilingual-en:start -->
> Every target must declare the real inputs that affect its result and the real producers that must finish first. The same graph can then decide which targets are invalidated by a change and which independent recipes may safely run in parallel.
> <!-- bilingual-en:end -->

漏边会产生两类表面不同、根因相同的错误：增量构建可能沿用陈旧产物；`make -j` 又可能让消费者抢在生产者之前运行。把并行关闭可以暂时遮住第二种症状，却不会补回第一种缺失的因果关系。
<!-- bilingual-en:start -->
A missing edge creates two superficially different failures with the same cause: an incremental build may reuse a stale artifact, and `make -j` may run a consumer before its producer. Disabling parallelism can hide the second symptom, but it does not restore the missing causal relationship behind the first.
<!-- bilingual-en:end -->

## 顺序依赖的特殊边界

GNU Make 的普通先决条件同时约束执行顺序和过期判断；order-only prerequisite（写在 `|` 右侧）只约束顺序。例如输出目录必须先存在，但目录时间戳变化不应令其中每个对象文件重建。若一个生成文件的内容真正影响目标，它就不是 order-only 的候选。
<!-- bilingual-en:start -->
In GNU Make, a normal prerequisite constrains both execution order and freshness. An order-only prerequisite, written to the right of `|`, constrains order only. An output directory may need to exist first without its timestamp invalidating every object inside it. A generated file whose contents affect a target is therefore not a candidate for order-only treatment.
<!-- bilingual-en:end -->

> [!question]- 自检
> 编译器读取自动生成的 `version.h`，但 Makefile 没把它列为先决条件。串行构建偶尔成功，能否说明依赖图正确？
>
> **答案：** 不能。成功可能只是偶然执行顺序；增量或并行运行仍会暴露漏边。

<!-- bilingual-en:start -->
- [GNU Make Manual: Types of Prerequisites](https://www.gnu.org/software/make/manual/html_node/Prerequisite-Types.html) was checked for the dual versus order-only semantics of prerequisites.

The missing-edge consequences in the text follow from this invariant together with normal-prerequisite semantics.
