# Graph incidence matrix
<!-- bilingual-en:end -->
*图的关联矩阵*

<!-- bilingual-en:start -->
A **graph incidence matrix** turns values attached to nodes into differences across edges. Think of assigning a height or voltage to each node. An edge compares the value at one endpoint with the value at the other. One matrix multiplication performs every comparison at once.
<!-- bilingual-en:end -->

**图的关联矩阵**把节点上的数值变成各条边两端的差值。可以把每个节点的数想成高度或电势：一条边比较两端的数，一个矩阵乘法则同时完成全部比较。

<!-- bilingual-en:start -->
## A three-node path
<!-- bilingual-en:end -->
*先看三个节点的路径*

<!-- bilingual-en:start -->
Join nodes $1,2,3$ by two edges. Choose the reference arrows $1\to2$ and $2\to3$. For node values $x_1,x_2,x_3$, the required differences are $x_2-x_1$ and $x_3-x_2$. The [[矩阵乘法|row-by-column multiplication rule]] gives exactly these differences:
<!-- bilingual-en:end -->

用两条边连接节点 $1,2,3$，选参考箭头 $1\to2$、$2\to3$。节点值为 $x_1,x_2,x_3$ 时，要计算的差是 $x_2-x_1$、$x_3-x_2$。按[[矩阵乘法|行乘列规则]]，它们恰好写成

$$A=\begin{pmatrix}-1&1&0\\0&-1&1\end{pmatrix},\qquad
Ax=\begin{pmatrix}x_2-x_1\\x_3-x_2\end{pmatrix}.$$

<!-- bilingual-en:start -->
For $x=(3,1,0)^T$, the output is $(-2,-1)^T$. The superscript $T$ denotes [[矩阵转置|transpose]], turning the listed row into a column. Each negative result says that the value decreases along that edge's arrow. Adding $10$ to every node gives $(13,11,10)^T$ and leaves both differences unchanged. Differences record relative values, so they cannot recover the common offset.
<!-- bilingual-en:end -->

取 $x=(3,1,0)^T$，输出就是 $(-2,-1)^T$；上标 $T$ 表示[[矩阵转置|转置]]，把所列的一行变成一列。负值表示沿该边箭头行进时数值下降。给所有节点同时加 $10$，得到 $(13,11,10)^T$，两个差值仍然不变。差值记录相对关系，不能恢复共同加上的常数。

<!-- bilingual-en:start -->
## One row per edge
<!-- bilingual-en:end -->
*每条边对应一行*

<!-- bilingual-en:start -->
Use a finite [[图类型的建模边界|undirected graph]] with $n\ge1$ nodes and $m\ge0$ edges. Initially exclude self-loops; distinct parallel edges are allowed. Number the nodes and edges, and choose an arbitrary reference arrow for each edge. The real **signed incidence matrix** $A\in\mathbb R^{m\times n}$ has edges as rows and nodes as columns. For edge $e:i\to j$, its row contains
<!-- bilingual-en:end -->

考虑有限[[图类型的建模边界|无向图]]，有 $n\ge1$ 个节点、$m\ge0$ 条边；先排除自环，允许可区分的平行边。给节点和边编号，并为每条边任取参考箭头。实**带符号关联矩阵** $A\in\mathbb R^{m\times n}$ 以边为行、节点为列。边 $e:i\to j$ 对应的行满足

$$A_{ei}=-1,\qquad A_{ej}=1,\qquad A_{ek}=0\quad(k\notin\{i,j\}).$$

<!-- bilingual-en:start -->
For a node-potential column $x\in\mathbb R^n$, “potential” here simply means the assigned scalar value. Then $(Ax)_e=x_j-x_i$ is **head minus tail**. The map takes $n$ node coordinates to $m$ edge coordinates. If $m=0$, there are no rows or edge differences; every node assignment produces the empty output. Some texts instead put nodes in rows, so their incidence matrix is this matrix's transpose. Check the dimensions before applying a formula.
<!-- bilingual-en:end -->

对节点势列向量 $x\in\mathbb R^n$，“势”在这里就是赋给节点的标量值。于是 $(Ax)_e=x_j-x_i$ 表示**终点减起点**。映射把 $n$ 个节点坐标变为 $m$ 个边坐标。若 $m=0$，就没有行，也没有边差值；任何节点赋值都产生空输出。有些教材反过来以节点为行，其关联矩阵就是这里的转置，因此使用公式前应先核对尺寸。

<!-- bilingual-en:start -->
The arrows fix signs; they do not turn the underlying undirected graph into a model that permits movement only one way. Nor do they require physical current to follow the arrow. Reversing an arrow negates the corresponding row of $A$ and the coordinate of the same difference or signed flow. Connectivity is unchanged.
<!-- bilingual-en:end -->

箭头规定正负号，并没有把原无向图变成只能单向行进的模型，也不要求实际电流顺着箭头流动。反转箭头时，$A$ 的对应行以及描述同一差值或带符号流量的坐标都要反号；连通性不变。

## The four subspaces in a graph
<!-- bilingual-en:end -->
## 四个子空间的图意义

<!-- bilingual-en:start -->
Write $N(A)=\{x:Ax=0\}$ for the [[零空间|nullspace]], and $C(A)=\{Ax:x\in\mathbb R^n\}$ for the [[列空间|column space]], the attainable outputs. A [[无向图连通分量|connected component]] is a maximal group of nodes joined by paths; an isolated node counts as one component. Let $c$ be the component count.
<!-- bilingual-en:end -->

用 $N(A)=\{x:Ax=0\}$ 表示[[零空间]]，用 $C(A)=\{Ax:x\in\mathbb R^n\}$ 表示[[列空间]]，即所有可达输出。[[无向图连通分量|连通分量]]是由路径相连的最大节点组，孤立节点也单独算一个分量。令分量数为 $c$。

<!-- bilingual-en:start -->
**Zero differences.** If $Ax=0$, every edge has equal values at its endpoints. Following a path propagates equality, so $x$ is constant separately on each component. Conversely, such an assignment makes every edge difference zero. There is one independent constant per component. Thus [[秩零度定理|rank–nullity]] gives
<!-- bilingual-en:end -->

**零差值。** 若 $Ax=0$，每条边两端的值相等；沿路径逐边传递，就得到 $x$ 在每个分量上分别为常数。反过来，这样的赋值显然使所有边差值为零。每个分量有一个独立常数，因此由[[秩零度定理]]，

$$\dim N(A)=c,\qquad \operatorname{rank}A=n-c.$$

<!-- bilingual-en:start -->
Here rank is the dimension of the attainable output space. When the graph is connected, $N(A)$ consists of all multiples of $\mathbf1=(1,\ldots,1)^T$ and the rank is $n-1$. The identity $A\mathbf1=0$ also follows by adding each row's $-1$ and $+1$. With no edges, $c=n$, the nullspace is all of $\mathbb R^n$ and the rank is zero.
<!-- bilingual-en:end -->

这里的秩是可达输出空间的维数。图连通时，$N(A)$ 就是 $\mathbf1=(1,\ldots,1)^T$ 的全部倍数，秩为 $n-1$；逐行把 $-1$ 与 $+1$ 相加，也直接得到 $A\mathbf1=0$。无边时 $c=n$，零空间为整个 $\mathbb R^n$，秩为零。

<!-- bilingual-en:start -->
**Attainable edge differences.** $C(A)\subseteq\mathbb R^m$ contains precisely the edge values that arise from some node potentials. Around a cycle their signed sum is zero, because successive node terms cancel. The [[关联矩阵与生成森林|spanning-forest interpretation]] explains how to select independent edge comparisons.
<!-- bilingual-en:end -->

**可产生的边差值。** $C(A)\subseteq\mathbb R^m$ 恰好收集能够由某组节点势产生的边值。沿环把它们按行进方向带符号相加，和为零，因为相邻节点项逐个抵消。[[关联矩阵与生成森林|生成森林的解释]]进一步说明怎样挑出独立的边比较。

<!-- bilingual-en:start -->
**Conserved flows.** For a signed edge-flow column $y\in\mathbb R^m$, positive in the reference directions, $(A^Ty)_i$ is inflow minus outflow at node $i$. Thus $N(A^T)$ contains flows balanced at every node, the real [[回路空间与守恒流|cycle space]]. Its dimension is $m-(n-c)=m-n+c$, by rank–nullity for $A^T$ and [[行秩等于列秩|equality of transpose ranks]]. The linked cycle-space card constructs a basis of independent circulations.
<!-- bilingual-en:end -->

**守恒流。** 对带符号的边流量列 $y\in\mathbb R^m$，以参考方向为正，则 $(A^Ty)_i$ 是节点 $i$ 的流入减流出。因此，$N(A^T)$ 包含每个节点都平衡的流量，构成实[[回路空间与守恒流|回路空间]]。对 $A^T$ 使用秩零度定理，并利用[[行秩等于列秩|转置不改变秩]]，得到维数 $m-(n-c)=m-n+c$；所链卡片构造了独立环流的基。

<!-- bilingual-en:start -->
**Attainable node balances.** $C(A^T)\subseteq\mathbb R^n$ consists exactly of node vectors whose entries sum to zero on each component. Necessity follows because each internal edge contributes one positive and one negative entry. Sufficiency follows from the [[基本子空间正交补|complete complement identity]] $C(A^T)=N(A)^\perp$: being perpendicular to each component's constant vector means precisely that its entries sum to zero there. These are net inflows from edges; an external injection that balances them has the opposite sign.
<!-- bilingual-en:end -->

**可产生的节点平衡量。** $C(A^T)\subseteq\mathbb R^n$ 恰好是每个分量内坐标和都为零的节点向量。必要性来自每条内部边贡献一正一负；充分性来自[[基本子空间正交补|完整正交补关系]] $C(A^T)=N(A)^\perp$：与各分量的常数向量垂直，恰好要求该分量内坐标和为零。这些量表示边带来的净流入；要与之平衡的外部注入则取相反符号。

## Incidence versus adjacency
<!-- bilingual-en:end -->
## 与 adjacency matrix 不同

<!-- bilingual-en:start -->
The incidence matrix has size $m\times n$ and records which endpoints belong to each edge. An [[邻接表与邻接矩阵|adjacency matrix]] has size $n\times n$ and records adjacency between node pairs; its entries may indicate existence, edge counts or weights according to the chosen model. With edge-count entries, powers count walks. It does not directly perform the edge-difference map above.
<!-- bilingual-en:end -->

关联矩阵尺寸为 $m\times n$，记录每条边的两个端点；[[邻接表与邻接矩阵|邻接矩阵]]尺寸为 $n\times n$，记录节点对的邻接关系。依模型不同，其元素可以表示是否相邻、边数或权重；使用边数编码时，矩阵幂计数游走。它并不直接完成上面的边差值映射。

<!-- bilingual-en:start -->
Parallel edges occupy separate rows; equal reference directions give equal rows. If self-loops are admitted, use the signed-incidence convention: departure and arrival occur in the same column and cancel, giving a zero row. Such a loop produces no potential difference but adds one independent edge coordinate to $N(A^T)$, since conservation places no constraint on that coordinate. This is a statement about the graph's linear constraints, not a claim that a passive resistor sustains current at zero voltage difference.
<!-- bilingual-en:end -->

平行边各占一行；参考方向相同时，两行相同。若允许自环，则采用带符号关联约定：出发与到达发生在同一列，正负贡献抵消，得到零行。自环不产生势差，却给 $N(A^T)$ 增加一个独立的边坐标，因为守恒式不约束这个坐标。这描述的是图的线性约束，并不是说无源电阻能在零电压差下维持电流。

> [!question]- Why does reversing an arrow preserve $A^TA$? · 为什么反转箭头不改变 $A^TA$？
> <!-- bilingual-en:start -->
> Put $-1$ in the reversed edge's position of a [[对角矩阵|diagonal sign matrix]] $D$ and $+1$ elsewhere. The new incidence matrix is $DA$. Since $D^TD=I$, $(DA)^T(DA)=A^TA$. When edges have nonnegative weights, the corresponding orientation-independent operator is the [[加权图 Laplacian|weighted graph Laplacian]] $A^TCA$.
> <!-- bilingual-en:end -->
>
> 在[[对角矩阵|对角符号矩阵]] $D$ 中，把反转边对应的对角元取为 $-1$，其余取 $+1$，新关联矩阵就是 $DA$。因为 $D^TD=I$，所以 $(DA)^T(DA)=A^TA$。边有非负权重时，对应的方向无关算子是[[加权图 Laplacian|加权图拉普拉斯矩阵]] $A^TCA$。
