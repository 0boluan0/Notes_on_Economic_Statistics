# 图的关联矩阵把节点势映成有向边上的势差
<!-- bilingual-en:start -->
*A graph incidence matrix maps vertex potentials to oriented edge differences*
<!-- bilingual-en:end -->

> [!summary] 原子模型
> 给一张有 $n$ 个 vertices、$m$ 条 edges 的有限无向无自环图，任意选定每条边的参考方向。其 incidence matrix $A\in\mathbb R^{m\times n}$ 每行对应一条边：若第 $e$ 条边定向为 $i\to j$，就令
> $$
> A_{e i}=-1,\qquad A_{e j}=+1,
> $$
> 其余 entries 为 $0$。对节点势 $x\in\mathbb R^n$，$(Ax)_e=x_j-x_i$ 是沿参考方向的 edge potential difference。
> <!-- bilingual-en:start -->
> For a finite loopless undirected graph with $n$ vertices and $m$ edges, choose an arbitrary reference orientation for every edge. Its incidence matrix $A\in\mathbb R^{m\times n}$ has one row per edge. If edge $e$ is oriented $i\to j$, set
> $$
> A_{e i}=-1,\qquad A_{e j}=+1,
> $$
> with zeros elsewhere. For vertex potentials $x\in\mathbb R^n$, $(Ax)_e=x_j-x_i$ is the edge potential difference in the reference direction.
> <!-- bilingual-en:end -->

参考方向只是符号选择，不是说物理流一定沿箭头。反转 edge $e$ 会把 $A$ 的第 $e$ 行乘 $-1$，同时把该边的 signed difference 或 flow 坐标反号；只要所有符号约定一致，underlying graph、连通性与可观测物理关系都不变。
<!-- bilingual-en:start -->
The reference orientation is a sign convention, not a claim that physical flow must follow the arrow. Reversing edge $e$ multiplies row $e$ of $A$ by $-1$ and reverses the signed coordinate of its difference or flow. With consistent conventions, the underlying graph, connectivity, and physical relationships are unchanged.
<!-- bilingual-en:end -->

平行边可以各占一行，因而这个定义也能处理无自环 multigraph。self-loop 的两个端点却是同一顶点；在常见的 signed-incidence 约定下，$-1$ 与 $+1$ 会在同一列相消，该行为零。此时 self-loop 不传递节点势差，却在 $N(A^T)$ 中增加一个独立环流方向；若使用别的 loop 约定，必须明说。
<!-- bilingual-en:start -->
Parallel edges may occupy separate rows, so the definition also handles loopless multigraphs. A self-loop has the same vertex at both ends. Under the usual signed-incidence convention, its $-1$ and $+1$ cancel in one column, leaving a zero row. The loop then transmits no vertex-potential difference but contributes one independent circulation direction to $N(A^T)$. Any different loop convention must be stated explicitly.
<!-- bilingual-en:end -->

## 四个子空间的图意义
<!-- bilingual-en:start -->
*Graph meaning of the four subspaces*
<!-- bilingual-en:end -->

设图有 $c$ 个 connected components：

- $Ax=0$ 当且仅当 $x$ 在每个 component 上分别为常数，所以 $\dim N(A)=c$。
- 因此 $\operatorname{rank}(A)=n-c$。
- $N(A^T)$ 是在每个 vertex 满足净流量为零的 edge flows；其自由度为 $m-n+c$，可由独立 circulations 生成。
- $C(A^T)$ 是由 edge quantities 汇总到 vertices 的净注入向量；它在每个 component 上的分量和为 $0$。
<!-- bilingual-en:start -->
If the graph has $c$ connected components:

**1.** $Ax=0$ exactly when $x$ is constant separately on each component, so $\dim N(A)=c$.<br>
**2.** Therefore $\operatorname{rank}(A)=n-c$.<br>
**3.** $N(A^T)$ consists of edge flows with zero net flow at every vertex. It has dimension $m-n+c$ and is generated by independent circulations.<br>
**4.** $C(A^T)$ consists of net-injection vectors accumulated from edge quantities; their entries sum to zero on each component.<br>
<!-- bilingual-en:end -->

连通情形的核结论不需要消元：$Ax=0$ 使每条 edge 两端势相同；沿任意 path 逐边传递，就得到所有 vertices 势相同。反向 $A\mathbf1=0$，因为每行的 $-1$ 与 $+1$ 相消。于是 connected graph 有 $N(A)=\operatorname{span}\{\mathbf1\}$ 与 rank $n-1$。
<!-- bilingual-en:start -->
The connected-case nullspace needs no elimination. Equation $Ax=0$ makes the endpoints of every edge equal. Propagating equality along paths makes every vertex potential equal. Conversely, $A\mathbf1=0$ because the $-1$ and $+1$ in each row cancel. Thus a connected graph has $N(A)=\operatorname{span}\{\mathbf1\}$ and rank $n-1$.
<!-- bilingual-en:end -->

## 与 adjacency matrix 不同
<!-- bilingual-en:start -->
*Difference from an adjacency matrix*
<!-- bilingual-en:end -->

incidence matrix 的 shape 是 $m\times n$，rows 是 edges、columns 是 vertices；adjacency matrix 是 $n\times n$，rows 与 columns 都是 vertices。前者直接编码“edge 连接哪两个 vertex”并把节点量变成边差，后者直接编码“哪一对 vertex 相邻”并用幂计数 walks。
<!-- bilingual-en:start -->
An incidence matrix is $m\times n$, with edges as rows and vertices as columns. An adjacency matrix is $n\times n$, with vertices on both axes. The first records edge–endpoint incidence and maps vertex values to edge differences; the second records vertex adjacency and uses powers to count walks.
<!-- bilingual-en:end -->

> [!question]- 回忆与应用
> 反转一条 edge 的参考方向，为什么 $A^TA$ 不变？
>
> **答案：**反转相当于左乘一个只有该对角元为 $-1$ 的 diagonal sign matrix $D$。新矩阵为 $DA$，而 $D^TD=I$，所以 $(DA)^T(DA)=A^TA$。
> <!-- bilingual-en:start -->
> Why does reversing the reference orientation of one edge leave $A^TA$ unchanged?
>
> **Answer:** Reversal left-multiplies $A$ by a diagonal sign matrix $D$ whose corresponding entry is $-1$. Since $D^TD=I$, $(DA)^T(DA)=A^TA$.
> <!-- bilingual-en:end -->
