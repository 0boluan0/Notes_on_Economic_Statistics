# 适合模拟的伪随机数生成器不因此适合密码或安全用途
<!-- bilingual-en:start -->
*A pseudorandom number generator suitable for simulation is not thereby suitable for cryptographic or security use*
<!-- bilingual-en:end -->

> [!summary] 统计上像随机，不等于对攻击者不可预测
> 模拟用 PRNG 关心周期、均匀性、相关结构和可复现性等统计与计算性质；安全用途还要求攻击者无法从已见输出、部分状态或种子空间预测后续值。
> <!-- bilingual-en:start -->
> Simulation PRNGs are judged by statistical and computational properties such as period, equidistribution, dependence, and reproducibility. Security use additionally requires resistance to prediction from observed outputs, partial state, or a searchable seed space.
> <!-- bilingual-en:end -->

一个确定性生成器可以通过大量统计测试，却仍可能在状态被推断后完全暴露后续输出。因此，用固定 seed 生成可重放的实验路径是合理的；用同一机制生成重置令牌、会话密钥或长期秘密则需要另外的密码学保证。
<!-- bilingual-en:start -->
A deterministic generator can pass extensive statistical tests and still expose all future outputs once its state is inferred. Reproducible experiment paths and password-reset tokens therefore have different randomness requirements.
<!-- bilingual-en:end -->

在 Python 中，普通 `random` 模块的核心生成器是确定性的 Mersenne Twister，官方明确不建议将它用于安全目的。重置令牌、密码与密钥应调用 `secrets` 或等价的操作系统密码学随机源，而不是仅仅更换一个 seed。
<!-- bilingual-en:start -->
Python's ordinary `random` module uses the deterministic Mersenne Twister and explicitly excludes security use. Tokens, passwords, and keys should use `secrets` or an equivalent operating-system cryptographic source rather than merely a different seed.
<!-- bilingual-en:end -->

> [!question]- 可核验自检
> 某个 PRNG 周期极长且通过常用统计测试。这是否已证明它可用于生成密码重置令牌？
>
> **答案：** 没有。这些证据没有验证状态恢复、下一输出预测或种子猜测等对手模型下的安全性。
> <!-- bilingual-en:start -->
> No. Those tests do not establish resistance to state recovery, next-output prediction, or seed search.
> <!-- bilingual-en:end -->

## 来源与核验

- Python Software Foundation, [`random` — Generate pseudo-random numbers](https://docs.python.org/3/library/random.html)：核对 Mersenne Twister 的确定性、非密码用途警告及 `SystemRandom` 入口。
- Python Software Foundation, [`secrets` — Generate secure random numbers for managing secrets](https://docs.python.org/3/library/secrets.html)：核对密码、身份验证、安全令牌等用途应使用操作系统提供的高质量随机源。
- NIST, [*SP 800-90A Rev. 1: Recommendation for Random Number Generation Using Deterministic Random Bit Generators*](https://doi.org/10.6028/NIST.SP.800-90Ar1)：核对密码学 DRBG 的安全强度、状态妥协与预测抵抗等对手模型要求；这些不能由一般模拟统计测试替代。
