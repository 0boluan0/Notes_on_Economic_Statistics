# 博弈类型是玩家的私人信息状态，收益参数是影响收益的物理状态；二者只在简化表述中才可合并
<!-- bilingual-en:start -->
*A game-theoretic type is a player's private-information state, whereas a payoff parameter is a physical state affecting payoffs; the two coincide only in simplified formulations*
<!-- bilingual-en:end -->

> [!summary] 核心区别
> $\theta\in\Theta$ 表示决定收益环境的物理参数，$t_i\in T_i$ 表示玩家 $i$ 观察到的私人信息状态。类型通过[[事中信念]] $p_i(\theta,t_{-i}\mid t_i)$ 提供关于物理参数和他人类型的信息，但不必等于其中任何一个物理参数。
> <!-- bilingual-en:start -->
> The payoff parameter $\theta\in\Theta$ describes the physical payoff environment, while $t_i\in T_i$ describes player $i$'s observed private-information state. Through the [[事中信念|interim belief]] $p_i(\theta,t_{-i}\mid t_i)$, a type provides information about physical parameters and other players' types without being identical to any particular physical parameter.
> <!-- bilingual-en:end -->

## 两个对象承担不同角色
<!-- bilingual-en:start -->
*The Two Objects Play Different Roles*
<!-- bilingual-en:end -->

收益函数可写为

$$
u_i:\Theta\times A\to\mathbb R,
$$

其中 $\theta$ 决定给定行动组合时的收益。类型 $t_i$ 则决定玩家知道什么、据此怎样对 $(\theta,t_{-i})$ 形成条件判断。两名玩家可以面对同一个 $\theta$，却因收到不同信息而具有不同类型。
<!-- bilingual-en:start -->
The payoff function $u_i:\Theta\times A\to\mathbb R$ uses $\theta$ to determine payoffs for a given action profile. A type $t_i$ instead determines what the player knows and therefore how the player assesses $(\theta,t_{-i})$. Two players may face the same $\theta$ while having different types because they received different information.
<!-- bilingual-en:end -->

## 何时可以合并记号
<!-- bilingual-en:start -->
*When the Notation Can Be Collapsed*
<!-- bilingual-en:end -->

在某些有限模型中，教材直接写 $u_i(t,a)$，让类型剖面同时索引收益状态。这是一种等价或方便的特殊表示。采用它时，必须确认当前问题不需要单独保留“物理状态是什么”与“玩家观察到什么”这两层信息。
<!-- bilingual-en:start -->
Some finite models write $u_i(t,a)$ and let the type profile index payoff states directly. This can be an equivalent or convenient special representation, but it is appropriate only when the problem does not require the physical state and the players' information about that state to remain separate.
<!-- bilingual-en:end -->
