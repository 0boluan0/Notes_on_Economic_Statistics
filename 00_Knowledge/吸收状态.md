# Absorbing states
<!-- bilingual-en:end -->
*吸收状态*

<!-- bilingual-en:start -->
An **absorbing state** is a state that the model never leaves once it has entered it. For example, if an order marked “completed” can never be reopened, completed is absorbing. A machine that is merely likely to remain idle is different: any positive chance of restarting prevents idle from being absorbing.
<!-- bilingual-en:end -->

**吸收状态**是模型一旦进入，就以概率一不再离开的状态。例如，若订单标成“已完成”以后绝不会重新打开，那么“已完成”就是吸收状态。机器只是很可能继续闲置，则是另一回事：只要还有正概率重新启动，“闲置”就不是吸收状态。

<!-- bilingual-en:start -->
Use a [[DTMC时间齐次转移核|time-homogeneous Markov transition rule]] on a finite or countable state set $S$: the same rule applies at every step. In the [[Markov矩阵左右约定|row convention]], $p_{ij}$ is the probability of moving from current state $i$ to next state $j$. All entries are nonnegative and each row sums to one.
<!-- bilingual-en:end -->

考虑有限或可数状态集 $S$ 上的[[DTMC时间齐次转移核|时间齐次 Markov 转移规则]]，即每一步使用同一规则。采用[[Markov矩阵左右约定|行约定]]，$p_{ij}$ 表示从当前状态 $i$ 下一步到状态 $j$ 的概率；所有条目非负，每行之和为一。

> [!important] All outgoing probability stays at the same state · 全部向外的概率仍留在自身
> <!-- bilingual-en:start -->
> State $a$ is absorbing precisely when $p_{aa}=1$. The row-sum condition then forces every other entry in row $a$ to be zero:
> <!-- bilingual-en:end -->
>
> 状态 $a$ 是吸收状态，当且仅当 $p_{aa}=1$。行和条件随即迫使这一行的其他条目全部为零：
>
> $$p_{aa}=1\quad\Longleftrightarrow\quad p_{aj}=0\text{ for every }j\ne a.$$
>
> <!-- bilingual-en:start -->
> Thus an absorbing state has no positive-probability exit. In a column-stochastic convention, inspect the outgoing column instead; the diagonal condition is still one.
> <!-- bilingual-en:end -->
>
> 因而，吸收状态没有任何正概率出口。若采用列随机约定，应检查表示去向的那一列；对角条目仍然必须为一。

## Why one step determines all future steps
<!-- bilingual-en:end -->
*为什么一步条件能决定此后的所有步骤*

<!-- bilingual-en:start -->
Starting at $a$, the next state is $a$ with probability one. The same transition rule applies again, so the state remains $a$ at every fixed later step. Since there are only countably many steps, the event of ever departing is a countable union of zero-probability events and has probability zero. The same reasoning applies after an entry from another state. “Never leaves” here describes a probability-one property of the model.
<!-- bilingual-en:end -->

从 $a$ 开始，下一步以概率一仍在 $a$；再次使用同一规则，就得到每个固定的较晚步数都以概率一在 $a$。由于步骤只有可数多个，“曾经离开”是这些零概率事件的可数并，概率仍为零。从其他状态进入后，也适用同样的论证。这里的“不会离开”是模型中的概率一性质。

<!-- bilingual-en:start -->
This is exactly a **singleton [[闭沟通类|closed communicating class]]**: the one-element set $\{a\}$ has no exit. A larger closed class can still have internal motion. For instance, two states that alternate forever form a closed pair, but neither individual state is absorbing.
<!-- bilingual-en:end -->

这恰好是一个**单点[[闭沟通类]]**：只含 $a$ 的集合 $\{a\}$ 没有出口。更大的闭类仍可在内部运动。例如，永远交替的两个状态组成闭类，但其中任何单个状态都不是吸收状态。

> [!example] The incoming probability does not define absorption · 是否吸收不由进入概率决定
> <!-- bilingual-en:start -->
> With states ordered as $1,2$, let
> <!-- bilingual-en:end -->
>
> 按 $1,2$ 排列状态，令
>
> $$P=\begin{pmatrix}1&0\\q&1-q\end{pmatrix},\qquad 0\le q\le1.$$
>
> <!-- bilingual-en:start -->
> State 1 is absorbing for every value of $q$: its own row is always $(1,0)$. If $q=0$, state 2 is also absorbing and can never reach 1. If $q=1/4$, state 2 can move to 1, but has probability $3/4$ of staying at 2 for the next step, so 2 is not absorbing. If $q=1$, it reaches 1 immediately. Changing the chance of entering 1 does not change whether 1 retains the chain after entry.
> <!-- bilingual-en:end -->
>
> 无论 $q$ 取什么值，状态 1 都吸收，因为它自己那一行始终为 $(1,0)$。若 $q=0$，状态 2 也吸收，并且永远无法到达 1。若 $q=1/4$，2 可以转到 1，但下一步仍有 $3/4$ 的概率留在 2，因此 2 不是吸收状态。若 $q=1$，2 一步就进入 1。进入 1 的机会怎样变化，并不改变进入后是否会被它留住。

<!-- bilingual-en:start -->
A self-transition probability such as $0.9$ is not close enough to satisfy the definition. With $q=0.1$ in this example, starting at 2 and remaining there for the first $n$ transitions has probability $0.9^n$, which tends to zero. One absorbing state also says nothing about whether every other state can reach an absorbing state; that whole-chain requirement belongs to [[吸收链|absorbing chains]].
<!-- bilingual-en:end -->

例如 $0.9$ 的自环概率仍不满足定义。在上例取 $q=0.1$，从 2 出发、前 $n$ 次转移一直留在 2 的概率为 $0.9^n$，反而趋于零。存在一个吸收状态，也没有说明所有其他状态都能到达某个吸收状态；后一项全链要求属于[[吸收链]]的定义。

<!-- bilingual-en:start -->
The fixed-rule assumption matters. If transition probabilities change with time, a one-step value $p_n(a,a)=1$ at one particular time only guarantees retention for that step. Permanent absorption requires the corresponding retention rule at every future step when the state can be occupied.
<!-- bilingual-en:end -->

规则固定这一前提也很重要。若转移概率随时间改变，某一时点恰有 $p_n(a,a)=1$，只保证那一步留下；永久吸收要求在此后可能占据该状态的每一步，都满足相应的留存规则。

## Sources and verification
<!-- bilingual-en:end -->
## 来源与核验

<!-- bilingual-en:start -->
- [Grinstead and Snell, Introduction to Probability, Definition 11.1, PDF p.424 / printed p.416](https://math.dartmouth.edu/~prob/prob/prob.pdf#page=424): the diagonal-one definition and its distinction from the whole-chain condition. The parameterized two-state example and repeated-retention probabilities are checked directly.
- [Weber, Cambridge Markov Chains, §2.5, PDF p.12 / printed p.8](https://www.statslab.cam.ac.uk/~rrw1/markov/M.pdf#page=12): an absorbing state is a singleton closed class. The permanent-retention argument applies the fixed rule repeatedly; the time-dependent qualification explains why one isolated one-step condition is insufficient.
<!-- bilingual-en:end -->

- Grinstead–Snell 定义11.1（PDF424／印刷416页）：核对对角元为一的定义，并与全链条件区分；两状态参数例及连续留存概率直接计算。
- Weber §2.5（PDF12／印刷8页）：核对吸收状态就是单点闭类。永久留存由固定规则逐步推出；非齐次限定解释为什么孤立的一步条件不足。
