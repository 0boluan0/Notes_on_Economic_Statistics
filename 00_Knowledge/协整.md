# 协整是同阶整合变量存在降低整合阶数的非零线性组合
<!-- bilingual-en:start -->
*Cointegration means that equally integrated variables admit a nonzero linear combination of lower integration order*
<!-- bilingual-en:end -->

> [!summary] 它是什么
> 对向量 $x_t=(x_{1t},\ldots,x_{nt})'$，若各分量都是 $I(d)$，却存在非零向量 $\beta$ 使 $\beta'x_t\sim I(d-b)$、其中 $b>0$，就称这些分量协整，记作 $x_t\sim CI(d,b)$。最常见的 $CI(1,1)$ 指各水平序列都是 $I(1)$，但某个线性组合已经是 $I(0)$。

“每个变量都是 $I(1)$”只完成了定义的第一半。第二半是找到一个真正降低整合阶数的组合；若任意非零线性组合仍是 $I(1)$，这些变量就不协整。反过来，一个向量中混有 $I(0)$ 和 $I(1)$ 分量时，也不能不加说明地套用这个同阶定义：平稳变量可以在明确规格中作为协变量、确定性部分或协整关系中的平稳分量，但必须说清它的角色。只有数据本身确实呈现更高阶整合时，才需要 $I(2)$ 或多协整的专门框架；“混合 $I(0)/I(1)$”本身不会推出它们。

定义说的是随机趋势能否被某个组合抵消，不要求单个序列本身围绕常数波动，也不要求样本相关系数很高。

> [!question]- 自检
> $x_t$ 与 $y_t$ 都是 $I(2)$，而 $y_t-2x_t$ 是 $I(1)$。能否称它们为 $CI(2,1)$？
>
> **答案：** 可以；组合把整合阶数从 2 降到 1。若要得到常见的平稳均衡误差，还需进一步降到 $I(0)$。
