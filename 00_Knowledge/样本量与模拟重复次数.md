# 样本量 n 改变每次估计使用的数据量，重复次数 R 改变抽样分布模拟的精度

<!-- bilingual-en:start -->
*Sample size n changes the data used per estimate; repetitions R change simulation precision*
<!-- bilingual-en:end -->

> [!summary] 核心
> 在重复抽样模拟中，每次抽 $n$ 个观察、计算一个估计值，重复 $R$ 次便得到 $R$ 个估计值。改变 $n$ 可改变估计程序的抽样分布；固定 $n$ 增加 $R$ 主要改善对同一分布的模拟近似。
>
> <!-- bilingual-en:start -->
> Each repetition draws n observations and produces one estimate; R repetitions produce R estimates. Changing n can change the statistic’s sampling distribution. At fixed n, increasing R improves the simulation approximation to that same distribution.
> <!-- bilingual-en:end -->
^core

对独立正态样本均值，$\operatorname{Var}(\bar X_n)=\sigma^2/n$。固定 $n=10$，把 $R$ 从 100 增至 10000 不会把单次均值的方差从 $\sigma^2/10$ 变成 $\sigma^2/10000$。若把模拟结果再平均，就另定义了一个 [[Monte Carlo估计|Monte Carlo 统计量]]，必须明确新的目标与数据量。对只用 $X_1$ 的规则，增加 $n$ 也不会缩小方差。

<!-- bilingual-en:start -->
For the iid sample mean, variance is $\sigma^2/n$. More simulation runs at fixed n do not reduce that single-estimate variance. Averaging the simulated outputs defines a different [[Monte Carlo估计|Monte Carlo statistic]]. A rule that always uses only the first observation need not improve when n grows.
<!-- bilingual-en:end -->
