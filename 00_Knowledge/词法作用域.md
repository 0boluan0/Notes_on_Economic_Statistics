# 嵌套函数的自由名称沿定义处的外层函数作用域解析而不是沿调用处解析
<!-- bilingual-en:start -->
*A nested function resolves free names through enclosing function scopes at its definition site rather than through its call site*
<!-- bilingual-en:end -->

> [!summary] 原子名称解析
> 函数体使用但未在该函数块内绑定的名称是自由名称。对嵌套在函数中的函数，调用时的局部 frame 会延伸它定义时的环境；查找从当前局部作用域开始，再沿定义处的最近外层函数作用域向外，最后到模块全局与 builtins。调用者自己的局部变量不会因为“谁调用了函数”而插入这条链。
> <!-- bilingual-en:start -->
> A name used but not bound in a function block is free there. When a function nested inside another function is called, its local frame extends the environment in which it was defined: lookup proceeds through the nearest enclosing function scopes, then the module globals and builtins. The caller's local variables do not enter this chain merely because that caller invoked the function.
> <!-- bilingual-en:end -->

```python
def outer(scale):
    def apply(value):
        return scale * value
    return apply
```

这里 `scale` 在 `apply` 中是自由名称，解析到定义 `apply` 时的 `outer` 调用环境。规则描述的是名称可见性，不意味着定义时就把自由变量的当前值复制进函数；自由名称通常到调用时才读取其绑定，这也解释了闭包的 late-binding 边界。

> [!question]- 自检
> 某调用者自己的局部变量也叫 `scale`，为什么它不会改变上例返回函数使用的倍率？
>
> **答案：** Python 使用词法作用域；返回函数沿其定义处的外层环境找 `scale`，不沿动态调用链找调用者局部变量。
