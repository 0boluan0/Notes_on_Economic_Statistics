# Material implication
<!-- bilingual-en:end -->
*蕴含的真值条件*

<!-- bilingual-en:start -->
An “if–then” condition singles out a situation that must not happen: the stated condition holds, but its required consequence fails. For example, a rule might require a fan to run whenever an overheating sensor is active. The fan running while the sensor is inactive does not violate that rule; the rule did not say that overheating was the only reason to run the fan.
<!-- bilingual-en:end -->
“如果……那么……”这种条件指出一种不能出现的情形：所说的条件成立，要求的结果却不成立。例如，规则可能要求过热传感器触发时风扇必须运转。传感器没触发而风扇运转，并不违反这条规则，因为规则没说过热是开启风扇的唯一理由。

<!-- bilingual-en:start -->
Here we use ordinary two-valued classical logic. Let $P$ and $Q$ be [[命题与谓词|propositions]], statements with definite true or false values in a specified context. The **material implication** $P\Rightarrow Q$, read “if $P$, then $Q$,” is a new proposition. $P$ is its **antecedent**, the if-part; $Q$ is its **consequent**, the then-part. The word “material” specifies that the compound's truth value depends only on these two input truth values.
<!-- bilingual-en:end -->
这里使用通常的二值经典逻辑。$P,Q$ 是[[命题与谓词|命题]]，即在指定语境中具有确定真假的陈述。**材料蕴含** $P\Rightarrow Q$ 读作“如果 $P$，那么 $Q$”，它本身也是一个命题。$P$ 是**前件**，即“如果”的部分；$Q$ 是**后件**，即“那么”的部分。“材料”这一限定表示：复合命题的真假只由这两个输入真值决定。

> [!important] The one failing combination · 唯一失败的组合
> <!-- bilingual-en:start -->
> $P\Rightarrow Q$ promises that whenever $P$ holds, $Q$ holds as well. Its only false case is a true $P$ with a false $Q$; equivalently,
> $$P\Rightarrow Q\equiv\neg P\lor Q.$$
> <!-- bilingual-en:end -->
>
> $P\Rightarrow Q$ 承诺：每当 $P$ 成立，$Q$ 也成立。它唯一为假的情形是 $P$ 真而 $Q$ 假；等价地，
> $$P\Rightarrow Q\equiv\neg P\lor Q.$$

<!-- bilingual-en:start -->
The symbol $\neg$ means “not,” $\lor$ means inclusive “or” (at least one is true, possibly both), and $\equiv$ says the two expressions agree under every truth assignment. A [[真值表等价检验|truth table]] lists all four combinations. Here T means true and F means false.

| $P$ | $Q$ | $P\Rightarrow Q$ | $\neg P\lor Q$ |
|---|---|---|---|
| T | T | T | T |
| T | F | F | F |
| F | T | T | T |
| F | F | T | T |
<!-- bilingual-en:end -->
$\neg$ 表示“非”，$\lor$ 表示可兼有的“或”（至少一项为真，也可以两项都真），$\equiv$ 表示两个表达式在每种真值赋值下都相同。上面的[[真值表等价检验|真值表]]列出了四种组合，T 表示真，F 表示假。后两列逐行一致，因此得到框中的等价式。

<!-- bilingual-en:start -->
## Read the four rows in one example
<!-- bilingual-en:end -->
*用同一个例子读懂四行*

<!-- bilingual-en:start -->
Suppose a specification says, “if the sensor reports overheating $P$, the fan must be on $Q$.” The rule is violated only when the system overheats without the fan. When there is no overheating, this conditional rule imposes no requirement on whether the fan is on or off.
<!-- bilingual-en:end -->
若规定“传感器处于过热状态 $P$ 时，风扇必须开启 $Q$”，系统只在过热却不开风扇时违反规定。没有过热时，这条条件规则没有要求风扇开或关，因此不构成反例。

<!-- bilingual-en:start -->
Fix one observed system state, with the sensor reading and fan state taken at that same checkpoint. The first row meets the demand, and the second violates it. In each of the last two rows the demand is inactive, so this particular condition is satisfied. This does not certify every other safety condition or every future system state. If the intended specification involves a delayed response, that time requirement must be included in the propositions; the arrow alone adds no delay or causal mechanism.
<!-- bilingual-en:end -->
先固定一个被观察的系统状态，把传感器读数与风扇状态放在同一检查点。第一行满足要求，第二行违反要求；后两行没有触发这项要求，所以当前这条条件成立。这不代表其余安全条件或所有未来状态也已核验。如果规格要求延迟一段时间后响应，就要把时间要求写进命题中；箭头本身不会自动添加延迟或因果机制。

<!-- bilingual-en:start -->
## A true conditional is not evidence for either part
<!-- bilingual-en:end -->
*条件句为真，不等于两端都已证真*

<!-- bilingual-en:start -->
Knowing only that $P\Rightarrow Q$ is true leaves three rows possible. It does not establish $P$, and it does not establish $Q$: the F,F row is still possible. If both the conditional and $P$ are known true, however, only the T,T row remains, so $Q$ follows. That is a [[数学证明的有效推理|truth-preserving inference]] with two premises, rather than a conclusion extracted from the arrow alone.

A true $Q$ also makes the conditional true regardless of $P$. For example, “if $2+2=5$, then $3=3$” is a true material implication, but the false antecedent has not become a useful explanation or evidence for the true consequent. Conversely, **not knowing** whether $P$ is true is not the same as knowing it is false; uncertainty does not select either of the last two rows.
<!-- bilingual-en:end -->
只知道 $P\Rightarrow Q$ 为真，仍有三行可能：既不能据此断言 $P$，也不能断言 $Q$，因为 F,F 那一行仍未排除。如果同时知道条件句为真、$P$ 也为真，才只剩 T,T 行，因而能推出 $Q$。这是使用两个前提的[[数学证明的有效推理|保真推理]]，不是只凭箭头得到结论。

后件 $Q$ 为真时，无论 $P$ 如何，条件句都为真。例如“若 $2+2=5$，则 $3=3$”是一个真的材料蕴含，但错误的前件并没有变成真后件的有效解释或证据。反过来，**不知道** $P$ 是否为真，并不等于知道它为假；不知道真值，不能直接选真值表后两行。

<!-- bilingual-en:start -->
## One instance and a universal claim
<!-- bilingual-en:end -->
*一个实例与一条普遍规律*

<!-- bilingual-en:start -->
When $P(n)$ and $Q(n)$ are predicates about an integer $n$, each particular $n$ gives one conditional. A claim about every integer is the stronger statement $\forall n\in\mathbb Z\,(P(n)\Rightarrow Q(n))$. A [[全称命题与反例|counterexample]] must be one integer in that domain with $P(n)$ true and $Q(n)$ false. A successful instance, especially one with a false antecedent, does not prove the universal claim.

For “divisible by $4$ implies even,” a general argument is available: if $n=4k$ for an integer $k$, then $n=2(2k)$, so $n$ is even. This covers negative integers and zero as well. If no object in a stated domain satisfies the antecedent, the universal conditional is vacuously true and supplies no existence claim; a universal statement over the empty domain is likewise true by convention.
<!-- bilingual-en:end -->
当 $P(n),Q(n)$ 是关于整数 $n$ 的谓词时，每个具体 $n$ 都给出一个条件句；要断言所有整数都如此，写的是更强的 $\forall n\in\mathbb Z\,(P(n)\Rightarrow Q(n))$。一个[[全称命题与反例|反例]]必须是论域内满足 $P(n)$、却不满足 $Q(n)$ 的整数。某个成功实例，特别是前件为假的实例，不能证明全称命题。

对于“被 $4$ 整除就为偶数”，可以给出一般论证：若对某整数 $k$ 有 $n=4k$，则 $n=2(2k)$，所以 $n$ 为偶数。这同时覆盖负整数与零。如果声明的论域中没有对象满足前件，全称条件句就空真，但不提供任何存在结论；按通常约定，空论域上的全称命题同样为真。

## Boundaries
<!-- bilingual-en:end -->
## 边界

<!-- bilingual-en:start -->
- An implication with a false antecedent is vacuously true. This neither proves that the antecedent can occur nor establishes the consequent independently.
- Ordinary language such as “causes” and “because” often asserts causation, whereas material implication specifies only a truth-functional relation. They are not interchangeable.
<!-- bilingual-en:end -->
- 前件为假时蕴含为真，称为 vacuous truth；这不证明前件能发生，也不证明后件独立成立。
- 自然语言中的“导致”“因为”常含因果关系，而形式蕴含只规定真值关系；二者不能机械等同。

> [!question]- Find the forbidden row · 回忆与应用
> <!-- bilingual-en:start -->
> What form must a counterexample to “if an integer $n$ is divisible by $4$, then it is even” take?
>
> **Answer:** It must be an integer divisible by $4$ but not even: a true antecedent and false consequent. No such integer exists.
> <!-- bilingual-en:end -->
>
> 要否定“若整数 $n$ 被 $4$ 整除，则 $n$ 为偶数”，反例必须具有什么形状？
>
> **答案：** 必须找到一个被 $4$ 整除但不是偶数的整数，即前件真、后件假；事实上不存在这样的整数。
