# 在有限期多阶段可观察行动博弈中，策略组合为子博弈完美均衡当且仅当不存在有利的单次偏离
<!-- bilingual-en:start -->
*In a finite-horizon multistage game with observed actions, a strategy profile is subgame perfect if and only if it admits no profitable one-shot deviation*
<!-- bilingual-en:end -->

**单次偏离**让某名玩家只在一个决策点改变行动，随后又回到候选策略。单次偏离原理说，在它适用的博弈中，不必穷举所有跨时期的复杂改写：只要每个历史后的这种局部偏离都无利可图，候选策略就是[[子博弈完美均衡|SPE]]。
<!-- bilingual-en:start -->
A **one-shot deviation** changes one decision by one player and then returns to the candidate strategy. Where the principle applies, one need not enumerate every complicated multi-period deviation: the candidate is an [[子博弈完美均衡|SPE]] exactly when no such local deviation is profitable after any history.
<!-- bilingual-en:end -->

## 为什么有限期可以缩减
<!-- bilingual-en:start -->
*Why the Reduction Works in a Finite Horizon*
<!-- bilingual-en:end -->

若存在一份有利的复杂偏离，有限期保证它有最后一个与原策略不同的决策点。从这个最后偏离点开始，把更早的改动固定住，最后这一次改动本身就必须带来收益改善；否则删掉它不会使偏离变差。于是“存在复杂有利偏离”会推出“存在单次有利偏离”。反向显然成立，因为单次偏离本来就是完整偏离的一种。
<!-- bilingual-en:start -->
If a profitable compound deviation exists in a finite horizon, it has a last decision at which it differs from the candidate strategy. Holding earlier changes fixed, that final change must itself improve payoff; otherwise removing it would not make the deviation worse. A profitable compound deviation therefore implies a profitable one-shot deviation. The reverse implication is immediate because a one-shot deviation is itself a feasible deviation.
<!-- bilingual-en:end -->

## 实际检查
<!-- bilingual-en:start -->
*How to Apply the Test*
<!-- bilingual-en:end -->

对每名玩家、每个可能历史：

1. 假设该历史已经发生；
2. 固定其他玩家的续局策略；
3. 让该玩家只在当前决策点改选一次，之后恢复原策略；
4. 比较这次改变造成的续局期望收益。

<!-- bilingual-en:start -->
**1.** Treat the history as having occurred.<br>
**2.** Hold the other players' continuation strategies fixed.<br>
**3.** Change the player's choice only at the current decision and return to the original strategy thereafter.<br>
**4.** Compare the resulting continuation expected payoff.
<!-- bilingual-en:end -->

这里必须检查所有历史，包括均衡路径外历史；只检验实际路径上的节点，不能推出 SPE。
<!-- bilingual-en:start -->
Every history, including off-path histories, must be checked. Testing only the realized equilibrium path does not establish SPE.
<!-- bilingual-en:end -->

## 无限期与信息结构边界
<!-- bilingual-en:start -->
*Infinite-Horizon and Information-Structure Boundaries*
<!-- bilingual-en:end -->

无限期版本还需要 **continuous at infinity**：两条路径若在足够长的初始段完全相同，它们的收益差应趋近于零。有界每期收益配合几何贴现通常满足这一条件。若远期事件仍能造成不衰减的当前收益差，最后偏离点论证就可能失败。

本卡采用的是多阶段且行动可观察的版本。若行动不能被后续玩家观察、博弈含一般非单点信息集，或策略使用相关随机化，必须查验适用于该信息结构的具体定理；不能把“只查一次偏离”当成所有动态博弈的通用口诀。
<!-- bilingual-en:start -->
An infinite-horizon version additionally requires **continuity at infinity**: when two paths share an increasingly long initial segment, their payoff difference must vanish. Bounded per-period payoffs with geometric discounting commonly satisfy this condition. If remote events retain a non-vanishing effect on current payoff, the last-deviation argument can fail.

This card states the multistage version with observed actions. When actions are not observed by later players, the game has general non-singleton information sets, or strategies use correlated randomization, the theorem appropriate to that information structure must be checked separately. “Test only one deviation” is not a universal rule for every dynamic game.
<!-- bilingual-en:end -->
