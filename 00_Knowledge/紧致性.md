# 紧致集的每个开覆盖都含有有限子覆盖
<!-- bilingual-en:start -->
*A compact set is one for which every open cover has a finite subcover*
<!-- bilingual-en:end -->

> [!summary] 原子定义
> 设 $K$ 是拓扑空间 $X$ 的子集。一族开集 $\{U_i\}_{i\in I}$ 若满足
> $$K\subseteq\bigcup_{i\in I}U_i,$$
> 就称为 $K$ 的一个开覆盖。若每个开覆盖都能选出有限多个 $U_{i_1},\ldots,U_{i_m}$ 仍然覆盖 $K$，就称 $K$ 紧致。
> <!-- bilingual-en:start -->
> A set is compact when every open cover admits a finite subcover.
> <!-- bilingual-en:end -->

紧致性表达一种全局有限性：不论覆盖由多少个局部开集组成，总能删到只剩有限多个。它不表示集合本身只有有限个点；例如闭区间 $[0,1]$ 有无穷多个点，却是紧致集。

开区间 $(0,1)$ 不紧致。令 $U_n=(1/n,1)$，$n\ge 2$，则 $\{U_n\}$ 覆盖 $(0,1)$；任取有限多个，只需保留其中下标最大的 $N$，它们的并仍是 $(1/N,1)$，遗漏靠近 0 的点。

不要把“闭且有界”当作定义。开覆盖定义适用于一般拓扑空间；在度量空间中可以使用 [[紧致性的序列判别]]；在有限维欧氏空间中才有 [[Heine–Borel 定理的边界|闭且有界的 Heine–Borel 判别]]。

> [!question]- 自检
> 为什么“集合有无穷多个点”不能说明它不紧致？
>
> **答案：** 紧致性限制的是每个开覆盖能否缩成有限子覆盖，而不是集合含有多少个点；$[0,1]$ 就是无限但紧致的集合。
