# Truth-table equivalence testing
<!-- bilingual-en:end -->

真值表等价检验

<!-- bilingual-en:start -->
Two formulas can look different yet return the same truth value whenever their inputs agree. A truth table checks this by listing every possible combination of true and false inputs, evaluating both formulas on each row, and comparing the two output columns. Agreement on every row proves logical equivalence; one disagreeing row disproves it.

Here $P$ and $Q$ are variables standing for [[命题与谓词|propositions]]. Each is assigned either true ($T$) or false ($F$). A **truth assignment** fixes one value for each distinct variable. Every occurrence of the same variable must receive that same value within the row. This is classical, two-valued propositional logic.
<!-- bilingual-en:end -->

两个公式的外形可能不同，却在输入真值相同时总给出相同输出。真值表把所有真、假输入组合逐行列出，在每一行分别算出两个公式的值，再比较输出列。所有行都一致就证明逻辑等价；只要一行不同就能否定等价。

这里用 $P,Q$ 等变量代表[[命题与谓词|命题]]，每个取真（$T$）或假（$F$）。一次**真值赋值**给每个不同变量固定一个值；同一行内，同一变量的所有出现都必须取这个值。本文使用经典二值命题逻辑。

<!-- bilingual-en:start -->
## Build the complete table

Start with the union of the variables appearing in either formula. If there are $n$ distinct variables, each has two choices, so the number of rows is $2\cdot2\cdots2=2^n$. Repeating $P$ inside a formula does not create a second independent input. For $P,Q$, the four rows are $(T,T),(T,F),(F,T),(F,F)$.

The connectives give the calculation rules: $\neg P$ reverses the truth value of $P$; $P\land Q$ is true exactly when both are true; $P\lor Q$ is inclusive “or,” true when at least one is true. The [[蕴含真值条件|implication]] $P\Rightarrow Q$ is false only for $(T,F)$, and $P\Leftrightarrow Q$ is true exactly when the two inputs agree. Evaluate inner subformulas before the outer connective, just as brackets determine the order of an arithmetic calculation.
<!-- bilingual-en:end -->

列出完整真值表

先收集两个公式中出现的所有不同变量。若共有 $n$ 个，每个都有两种选择，因此共有 $2\cdot2\cdots2=2^n$ 行。一个公式重复出现 $P$，并不会增加一个独立输入。对 $P,Q$，四行是 $(T,T),(T,F),(F,T),(F,F)$。

连接词给出计算规则：$\neg P$ 把 $P$ 的真假反转；$P\land Q$ 当且仅当两者都真时为真；$P\lor Q$ 是包含“两者都真”的“或”，至少一个真便为真。[[蕴含真值条件|蕴含]] $P\Rightarrow Q$ 仅在 $(T,F)$ 时为假，而 $P\Leftrightarrow Q$ 当且仅当两个输入一致时为真。先算内部子公式，再算外层连接词，作用类似算术式中的括号。

> [!important] Compare all assignments / 比较全部赋值
> <!-- bilingual-en:start -->
> Propositional logic temporarily ignores the internal content of atomic propositions and studies how $\neg,\land,\lor,\Rightarrow,\Leftrightarrow$ determine output truth values from their inputs. A complete truth table for $n$ propositional variables has $2^n$ rows, and two formulas are logically equivalent only when they agree on every assignment.
> <!-- bilingual-en:end -->
>
> 命题逻辑暂不分析原子命题内部，只研究 $\neg,\land,\lor,\Rightarrow,\Leftrightarrow$ 怎样按输入真值产生输出真值。含 $n$ 个命题变量的完整真值表有 $2^n$ 行；两个公式只有在每一种赋值下真值相同才逻辑等价。

<!-- bilingual-en:start -->
## Work through one comparison

Compare $P\lor(\neg P\land Q)$ with $P\lor Q$. The intermediate columns below make each calculation visible. Read $T$ as true and $F$ as false.
<!-- bilingual-en:end -->

逐行完成一次比较

比较 $P\lor(\neg P\land Q)$ 与 $P\lor Q$。下表列出中间结果，让每一步计算都可追踪；$T$ 表示真，$F$ 表示假。

| $P$ | $Q$ | $\neg P$ | $\neg P\land Q$ | $P\lor(\neg P\land Q)$ | $P\lor Q$ |
|---|---|---|---|---|---|
| $T$ | $T$ | $F$ | $F$ | $T$ | $T$ |
| $T$ | $F$ | $F$ | $F$ | $T$ | $T$ |
| $F$ | $T$ | $T$ | $T$ | $T$ | $T$ |
| $F$ | $F$ | $T$ | $F$ | $F$ | $F$ |

<!-- bilingual-en:start -->
For instance, on the third row $P$ is false and $Q$ is true. Therefore $\neg P$ is true, $\neg P\land Q$ is true, and the left formula is $F\lor T=T$. The right formula is also $F\lor T=T$. The last two columns agree on all four rows, including the row on which both outputs are false, so the formulas are logically equivalent.

This is exhaustive verification, not a sample of situations. Every assignment must be one of the listed rows, and each row has been evaluated by the connective definitions. We can also say that the biconditional between the two formulas is true on every row.
<!-- bilingual-en:end -->

例如，第三行的 $P$ 假、$Q$ 真，所以 $\neg P$ 真，$\neg P\land Q$ 真，左侧公式得到 $F\lor T=T$；右侧也得到 $F\lor T=T$。最后两列在全部四行都一致，包括两个输出都假的最后一行，因此两式逻辑等价。

这穷尽了全部赋值，并非抽样检验：每种赋值必属于表中某一行，而每行都已按连接词定义计算。等价地，连接这两个公式的双条件在每一行都为真。

<!-- bilingual-en:start -->
For example, $P\Rightarrow Q$ and $\neg P\lor Q$ agree on all four assignments to $(P,Q)$ and are therefore equivalent. Finding one assignment on which both are true is insufficient; equivalence requires the absence of any disagreeing row.

For this second example, both output columns, in the row order above, are $T,F,T,T$. In contrast, $P\land Q$ and $P\lor Q$ agree when both inputs are true but disagree at $(T,F)$. That single row is already a counterexample to their equivalence.
<!-- bilingual-en:end -->

例如，$P\Rightarrow Q$ 与 $\neg P\lor Q$ 在四种 $(P,Q)$ 赋值下逐行相同，所以二者等价。只找一个让它们都为真的例子不够；等价要求不存在任何一行分歧。

第二个例子中，按上表行序，两输出列都是 $T,F,T,T$。相反，$P\land Q$ 与 $P\lor Q$ 虽在两个输入都真时一致，却在 $(T,F)$ 时不同。这一行就足以成为两式不等价的反例。

<!-- bilingual-en:start -->
## Boundary
<!-- bilingual-en:end -->

## 边界

<!-- bilingual-en:start -->
Truth tables work directly for finitely many propositional variables, but their $2^n$ growth may make algebraic equivalences or other proofs preferable for larger formulas.

Logical equivalence is not causation, linguistic similarity, or identical real-world meaning. It asserts agreement under every truth assignment.

An extra assumption changes the question. If we assume $P$ is true, then $P\lor Q$ and $P$ agree on all allowed rows. They are nevertheless not unconditionally equivalent, because they disagree when $P$ is false and $Q$ is true. State explicitly whether the comparison uses all assignments or only assignments satisfying additional hypotheses.

Nor does a table with two propositional variables enumerate the values of two integer variables. A quantified sentence such as “every integer has property $R$” may serve as one propositional input, but establishing its truth requires reasoning about its domain. The [[全称证明与存在见证|universal-proof and witness methods]] address that separate task. If formulas have no variables and truth constants are allowed, there is one empty assignment, consistent with $2^0=1$.
<!-- bilingual-en:end -->

真值表适合有限个命题变量；行数按 $2^n$ 增长，变量多时可能需要等价变形或其他证明。

逻辑等价不是因果、语义相似或现实含义相同；它只断言所有真值赋值下输出一致。

附加假设会改变问题。若假设 $P$ 为真，则 $P\lor Q$ 与 $P$ 在所有允许的行中都一致；但它们并非无条件等价，因为 $P$ 假、$Q$ 真时两者不同。应明确比较的是所有赋值，还是只比较满足额外假设的赋值。

两个命题变量的真值表，也不是对两个整数变量的所有取值进行枚举。“每个整数都满足性质 $R$”可以作为一个命题输入，但判断这个输入是真是假仍需针对其论域作证明；[[全称证明与存在见证]]处理的是后一任务。若允许含真值常量而不含变量的公式，则只有一种空赋值，与 $2^0=1$ 一致。

> [!question]- Recall and apply / 回忆与应用
> <!-- bilingual-en:start -->
> Two formulas in three propositional variables agree on seven truth-table rows. May we declare them equivalent?
>
> **Answer:** No. There are $2^3=8$ assignments, and the unchecked row may distinguish the formulas.
>
> For a concrete example, $P\land Q\land R$ and $P\land\neg P$ agree on all seven assignments other than $(T,T,T)$; on that remaining assignment the first is true and the second false.
> <!-- bilingual-en:end -->
>
> 两个含三个命题变量的公式在七行真值上一致，能否宣布等价？
>
> **答案：** 不能。完整真值表有 $2^3=8$ 行；还未检查的一行可能使二者分歧。
>
> 具体地，$P\land Q\land R$ 与 $P\land\neg P$ 在除 $(T,T,T)$ 以外的七种赋值下都一致；剩余这一行，前者真而后者假。
