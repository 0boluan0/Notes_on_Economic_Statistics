# Choosing a grid step from a derivative bound
<!-- bilingual-en:end -->

*用导数界选择网格步长*

<!-- bilingual-en:start -->
A bound on the [[导数|derivative]] limits how quickly function values can change between sampled inputs. If a search interval contains a root, this can tell us how small a fixed step should be so that at least one sampled point has a sufficiently small [[求根残差|residual]]. It is a quantitative way to prevent [[固定步长漏根|grid miss]], provided the stated derivative bound applies throughout the interval.
<!-- bilingual-en:end -->

[[导数]]的界限制了函数值在两个采样输入之间能变化多快。如果搜索区间内有根，就可以据此选择足够小的固定步长，保证至少一个采样点的 [[求根残差|残差]] 足够小。这是防止 [[固定步长漏根]] 的一种定量办法，前提是所用的导数界在整个区间内有效。

<!-- bilingual-en:start -->
Use the exact [[固定步长求根|fixed-step grid]] $G_h=\{a+jh:j=0,1,\ldots,\lfloor(b-a)/h\rfloor\}$ with finite $a<b$ and $h>0$. A candidate is acceptable when $|f(x)|\le\tau$ for a prescribed $\tau>0$; write $A_\tau=\{x\in[a,b]:|f(x)|\le\tau\}$ for all acceptable inputs. The left endpoint is included, while the right endpoint may be omitted by the floor truncation.
<!-- bilingual-en:end -->

使用精确的 [[固定步长求根|固定步长网格]] $G_h=\{a+jh:j=0,1,\ldots,\lfloor(b-a)/h\rfloor\}$，其中端点有限、$a<b$、$h>0$。给定 $\tau>0$，以 $|f(x)|\le\tau$ 验收候选，并记 $A_\tau=\{x\in[a,b]:|f(x)|\le\tau\}$ 为所有合格输入。网格包含左端点，而右端点可能因下取整截断而没有被采样。

> [!important] A sufficient step choice · 一个充分步长选择
> <!-- bilingual-en:start -->
> Suppose $f$ is continuous on $[a,b]$, differentiable on $(a,b)$, and has at least one root in $[a,b]$. If $|f'(x)|\le L$ for every $x\in(a,b)$, with finite $L>0$, choose $0<h\le\tau/L$. The grid then contains an acceptable input. A bound at just one point is insufficient for this conclusion.
> <!-- bilingual-en:end -->
>
> 设 $f$ 在 $[a,b]$ 上连续、在 $(a,b)$ 上可导，并且在 $[a,b]$ 内至少有一个根。如果每个 $x\in(a,b)$ 都满足 $|f'(x)|\le L$，其中 $0<L<\infty$，就可以选择 $0<h\le\tau/L$；此时网格中必有合格输入。只知道某一个点的导数界，不足以推出这个结论。

<!-- bilingual-en:start -->
## Use the grid point just to the left of a root
<!-- bilingual-en:end -->

## 取根左侧紧邻的网格点

<!-- bilingual-en:start -->
Let $r\in[a,b]$ be a root and define $q=a+h\lfloor(r-a)/h\rfloor$. The integer index is between zero and $\lfloor(b-a)/h\rfloor$, so $q\in G_h$. Rounding down gives $0\le r-q<h$: even if the root is the unsampled right endpoint, this grid point lies less than one full step away. If $q=r$, its residual is already zero; otherwise apply the function-difference bound between $q$ and $r$.
<!-- bilingual-en:end -->

取一个根 $r\in[a,b]$，定义 $q=a+h\lfloor(r-a)/h\rfloor$。这个整数下标位于 0 与 $\lfloor(b-a)/h\rfloor$ 之间，所以 $q\in G_h$；向下取整给出 $0\le r-q<h$。即使根就在没有被采样的右端点，该网格点与它的距离也小于一个完整步长。若 $q=r$，残差已经是零；否则在 $q$ 与 $r$ 之间应用函数差的界。

<!-- bilingual-en:start -->
For example, let $a<b$, assume $f$ is continuous on $[a,b]$, differentiable on $(a,b)$, has a root $r$ there including the endpoints, and satisfies $|f'(x)|\le L$ throughout $(a,b)$ for some finite $L\ge0$. The [[导数界控制函数差|derivative bound on function differences]] gives $|f(q)-f(r)|\le L|q-r|$. Using the same left grid point proves:
<!-- bilingual-en:end -->

例如令 $a<b$，假设 $f$ 在 $[a,b]$ 上连续、在 $(a,b)$ 上可导，在此闭区间内有根 $r$（允许端点），而且整个 $(a,b)$ 上都有 $|f'(x)|\le L$，其中 $L\ge0$ 是有限常数。[[导数界控制函数差]] 给出 $|f(q)-f(r)|\le L|q-r|$；使用同一个左侧网格点便得到：

$$
|f(q)|=|f(q)-f(r)|\le L|q-r|\le Lh.
\qquad
Lh\le\tau\ \Longrightarrow\ G_h\cap A_\tau\ne\varnothing.
$$

<!-- bilingual-en:start -->
This is a sufficient condition, not a necessary one. For $x^2-2$ on $[0,2]$, $|f'(x)|=2x\le4$, so $h=0.00025$ guarantees a hit at $\tau=0.001$ in exact arithmetic; the full grid has 8001 points. A larger step may still succeed by landing favourably. When $L=0$, the function is constant on the interval and the assumed root makes every grid point a root.
<!-- bilingual-en:end -->

这是充分条件，不是必要条件。对 $[0,2]$ 上的 $x^2-2$，有 $|f'(x)|=2x\le4$，所以在精确算术中取 $h=0.00025$ 就能保证命中 $\tau=0.001$ 的接受区域，完整网格有 8001 个点。更大的步长也可能因为刻度位置合适而成功。若 $L=0$，函数在区间上恒定，而已有根的假设使每个网格点都是根。

> [!warning] The right-hand tail matters · 右端剩余一段不能忽略
> <!-- bilingual-en:start -->
> For the floor-truncated grid, the nearest grid point need not be within $h/2$. On $[0,1]$ with $h=0.6$, the grid is only $\{0,0.6\}$; the root of $f(x)=x-1$ is $0.4$ away from its nearest grid point, exceeding $h/2=0.3$. With $L=1$ and $\tau=0.35$, the tempting condition $Lh/2\le\tau$ holds but the scan misses. A sufficient setup for a half-spacing bound is a grid covering both endpoints with every gap at most $h$, for example by explicitly adding $b$. For the grid defined here, the left-point argument using $h$ is valid.
> <!-- bilingual-en:end -->
>
> 对取整截断的网格，最近网格点未必在 $h/2$ 以内。在 $[0,1]$ 上取 $h=0.6$，网格只有 $\{0,0.6\}$；$f(x)=x-1$ 的根离最近网格点仍有 $0.4$，超过 $h/2=0.3$。取 $L=1$、$\tau=0.35$ 时，看似合理的 $Lh/2\le\tau$ 成立，扫描却仍未命中。保证半步长界的一种充分网格规格是：覆盖两个端点且相邻间隔都不超过 $h$，例如明确补上 $b$；本卡定义的网格可使用前述以 $h$ 为界的左侧点论证。

## Interpreting a computed scan
<!-- bilingual-en:end -->

## 解释程序报告的扫描结果

<!-- bilingual-en:start -->
To report a computed search as completed successfully or exhausted without a hit, the actual evaluation and stopping behaviour also matter:
<!-- bilingual-en:end -->

若要把计算搜索报告为正常成功结束，或完整耗尽后未命中，还要检查实际的求值与停止行为：

<!-- bilingual-en:start -->
These conclusions require a completed, valid scan. Early budget exhaustion or an undefined evaluation leaves candidates unresolved, as in [[枚举验证|exhaustive verification]]. The $Lh$ guarantee is about exact points and exact function values: rounded grid generation and computed residual error must be controlled before a floating-point run inherits it. Even a valid residual hit does not by itself bound the distance to a root; that separate inference needs [[残差控制根误差|conditions converting residual into root error]].
<!-- bilingual-en:end -->

这些结论要求扫描完整且判定有效。提前耗尽预算或求值无定义，都会留下未决候选，和 [[枚举验证]] 的情况一样。$Lh$ 保证讨论的是精确点与精确函数值；实际浮点程序必须控制网格生成误差和残差求值误差，才能继承这个保证。即使残差命中本身有效，也不会自动给出离根的距离界；那是另一个需要 [[残差控制根误差|额外转换条件]] 的推断。

<!-- bilingual-en:start -->
For $L>0$, the inequality $Lh\le\tau$ is equivalent to the step choice $h\le\tau/L$. The root need not be known numerically; what is needed is its existence in the interval and a valid global derivative upper bound. A small residual at an isolated probe does not establish that bound. If only continuity at a root is known, [[连续函数网格命中|eventual grid coverage]] supplies an existence guarantee without this explicit step size.
<!-- bilingual-en:end -->

当 $L>0$ 时，$Lh\le\tau$ 等价于步长条件 $h\le\tau/L$。不必预先知道根的具体数值，需要的是根在区间内存在，以及有效的全区间导数上界。某一个采样点的残差很小，并不能证明这个上界；若只知道根处连续，[[连续函数网格命中]]仍给出最终覆盖的存在性保证，但没有这里这个明确的步长数值。
