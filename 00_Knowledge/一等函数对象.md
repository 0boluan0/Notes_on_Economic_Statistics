# Python 函数是一等对象因而可以被绑定存储传入和返回
<!-- bilingual-en:start -->
*Python functions are first-class objects and can therefore be bound, stored, passed, and returned*
<!-- bilingual-en:end -->

> [!summary] 原子对象模型
> Python 中函数对象可以像其他对象一样绑定给名称、放入数据结构、作为实参传递，或作为返回值交出。表达式 `f` 只读取名称当前绑定的对象；`f()` 则进一步尝试调用该对象并得到调用结果。把应传入的函数写成 `f()`，会提前执行函数并传入它的返回值，而不是传入行为本身。
> <!-- bilingual-en:start -->
> A Python function object can be bound to names, stored in data structures, passed as an argument, or returned as a result. The expression `f` retrieves the object currently bound to that name, while `f()` additionally calls it and produces the call result. Writing `f()` when a function is expected invokes it too early and passes its result rather than the behavior itself.
> <!-- bilingual-en:end -->

```python
def is_even(x):
    return x % 2 == 0

predicate = is_even
checks = [is_even]
```

“一等函数”不表示只有 `function` 类型能被调用；类、绑定方法以及实现 `__call__` 的实例也可能是 callable。本原子只说明 Python 函数对象拥有常见值操作能力，不保证任意两个函数有兼容签名、相同副作用或可互换契约。

> [!question]- 自检
> `apply(is_even, 10)` 与 `apply(is_even(10), 10)` 的第一个实参分别是什么？
>
> **答案：** 前者是函数对象；后者先调用 `is_even(10)`，传入其布尔返回值。
