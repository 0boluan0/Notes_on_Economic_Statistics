# Choosing indicators for a count
<!-- bilingual-en:end -->
*计数指标的索引策略*

<!-- bilingual-en:start -->
Before calculating an expected count, decide exactly what one unit of the count represents. A person, a matching pair of people, and an occupied birthday date are different units. **Choosing the indicator index** means choosing a list of candidates so that each contribution to the desired count is recorded exactly once.
<!-- bilingual-en:end -->

计算一个计数的期望之前，先确定“一个”到底指什么。一个人、一对生日相同的人、一个有人生日的日期，是三种不同的单位。**选择指标索引**，就是列出一组候选，使目标计数中的每份贡献都恰好被记录一次。

<!-- bilingual-en:start -->
An [[事件指示变量|indicator]] records one if its candidate qualifies and zero otherwise. The [[随机计数的指标和|indicator-sum method]] then adds these records. Its crucial modelling requirement is equality on each outcome, not merely a plausible-looking expected value.
<!-- bilingual-en:end -->

[[事件指示变量|指示变量]]在候选符合要求时记一，否则记零；[[随机计数的指标和|指标求和法]]再把这些记录相加。建模时最关键的要求，是每个结果上的计数都一致，而不是最后算出的期望看起来合理。

> [!example] Counting matching birthday pairs · 数生日相同的人对
> <!-- bilingual-en:start -->
> Suppose four people all have the same birthday. There are six matching pairs: each person can be paired with the other three, and each pair has then been listed twice. One indicator per person who shares a birthday would instead give four; one per occupied birthday date would give one. To count pairs, a candidate must be a pair.
> <!-- bilingual-en:end -->
>
> 假设四个人生日完全相同。他们形成六对生日相同的人：每人可与另外三人配对，但这样每对会被列两次。若给“有同生日伙伴的人”每人一个指标，和会是四；若给有生日的日期每个一个指标，和会是一。要数人对，候选就必须是人对。

<!-- bilingual-en:start -->
Number $n$ people from $1$ to $n$, and let $M_{ij}$ indicate that persons $i,j$ have matching birthdays. Use only $i<j$, so each unordered pair has one representative. If $X$ is the number of matching pairs, then
<!-- bilingual-en:end -->

给 $n$ 个人编号 $1$ 到 $n$，用 $M_{ij}$ 记录第 $i,j$ 人的生日是否相同。只取 $i<j$，让每个无序人对只有一种代表。若 $X$ 是生日相同的人对数，则

$$X=\sum_{1\le i<j\le n}M_{ij}.$$

<!-- bilingual-en:start -->
Using both $(i,j)$ and $(j,i)$ would count each pair twice. The number of candidates is the [[组合数|combination count]] $\binom n2$, not $n$ or $n(n-1)$. The indexing identity itself does not assume any birthday probabilities or independence.
<!-- bilingual-en:end -->

如果同时使用 $(i,j)$ 和 $(j,i)$，每对就会被数两次。候选数是[[组合数]] $\binom n2$，不是 $n$，也不是 $n(n-1)$。这个索引恒等式本身还没有假设生日概率或独立性。

<!-- bilingual-en:start -->
## Match the candidates to the contributions
<!-- bilingual-en:end -->
*让候选与贡献单位对应*

<!-- bilingual-en:start -->
For a general finite count, let $J$ be the candidate index set, let $A_j$ mean “candidate $j$ qualifies”, and let $\omega$ be a complete outcome. A valid construction satisfies
<!-- bilingual-en:end -->

对一般有限计数，用 $J$ 表示候选索引集，$A_j$ 表示“候选 $j$ 符合条件”，$\omega$ 表示一个完整结果。正确构造应满足

$$X(\omega)=\sum_{j\in J}I_{A_j}(\omega).$$

<!-- bilingual-en:start -->
Check this by tracing each real contribution to exactly one term of the sum. For correctly returned hats, a person is the contribution unit, so use one indicator per person. For occupied boxes, use one per box. For triangles in a graph, use one per unordered set of three distinct vertices, indicating that all three required edges are present. Each triangle has six vertex orderings, so indexing by those orderings would give six contributions for one triangle.
<!-- bilingual-en:end -->

检查时，把每份真实贡献对应到和式中的唯一一项。数拿回自己帽子的人，以人为单位，每人一个指标；数非空箱子，以箱子为单位；数图中的三角形，以三个不同顶点组成的无序集合为单位，记录所需三条边是否齐全。每个三角形都有六种顶点排列，若按排列编号，就会把一个三角形贡献六次。

<!-- bilingual-en:start -->
## One count can have more than one valid description
<!-- bilingual-en:end -->
*同一个计数可以有多个正确表示*

<!-- bilingual-en:start -->
Imagine balls arriving one at a time and remaining in boxes. Let $O$ be the final number of occupied boxes. One representation puts an indicator $J_b$ on each box $b$, equal to one when that box is nonempty. Another puts an indicator $K_i$ on each arrival $i$, equal to one when that ball enters a previously empty box. Every finally occupied box has exactly one first arrival, so both representations count the same thing:
<!-- bilingual-en:end -->

设球依次进入箱子并留在其中，$O$ 是最后的非空箱数。一种表示给每个箱子 $b$ 一个指标 $J_b$，箱子非空就记一；另一种给每次到达 $i$ 一个指标 $K_i$，当这个球进入此前空着的箱子时记一。每个最终非空的箱子都恰好有一次首次到达，所以两种表示数的是同一个量：

$$O=\sum_bJ_b=\sum_iK_i.$$

<!-- bilingual-en:start -->
For arrivals into boxes $A,A,B,A$, the final box records for $A,B,C$ are $(1,1,0)$ and the arrival records are $(1,0,1,0)$. Both sums are two. The indicators differ, but their totals agree for every arrival sequence under this model.
<!-- bilingual-en:end -->

例如，球依次进入 $A,A,B,A$，最终三个箱子 $A,B,C$ 的记录是 $(1,1,0)$，四次到达的记录是 $(1,0,1,0)$，两种和都为二。在这个模型中，每条到达序列都满足相同的总数对应，虽然逐项的指标不同。

<!-- bilingual-en:start -->
After verifying the identity, choose the representation whose probabilities are easier to calculate. For a mean, [[期望线性性|linearity]] needs only each candidate's probability. For a variance, the [[指示变量协方差|joint probabilities of pairs of candidates]] matter too. Easy notation alone is not evidence that a representation is correct.
<!-- bilingual-en:end -->

验证恒等式之后，再选概率更容易计算的表示。求均值时，[[期望线性性]]只需要各候选自己的概率；求方差时，还要考虑[[指示变量协方差|候选两两同时发生的概率]]是否容易求。符号写起来方便，不能替代计数正确性的检查。

> [!note] Use symmetry after choosing the count · 确定计数以后再用对称性
> <!-- bilingual-en:start -->
> If there are $m$ candidates and each has the same probability $p$ of qualifying, then $E[X]=mp$, without independence. For birthday pairs under independent uniform birthdays on $d$ dates, each pair matches with probability $1/d$, giving $E[X]=\binom n2/d$. If candidate probabilities differ, keep their individual probabilities in the sum; do not substitute an unjustified “typical” probability.
> <!-- bilingual-en:end -->
>
> 若有 $m$ 个候选，每个符合要求的概率都相同为 $p$，就有 $E[X]=mp$，不需要指标独立。生日独立且均匀分布在 $d$ 个日期时，每对匹配概率为 $1/d$，因此 $E[X]=\binom n2/d$。若候选概率不同，就保留逐项概率之和，不要随意换成一个“典型概率”。
