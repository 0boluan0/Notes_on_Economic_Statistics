# 问题条件性与算法稳定性是不同的误差来源

<!-- bilingual-en:start -->
*Problem conditioning and algorithmic stability are distinct sources of numerical error*
<!-- bilingual-en:end -->

> [!summary] 原子区分
> **条件性（conditioning）**描述数学问题本身对输入微小扰动有多敏感；**算法稳定性（algorithmic stability）**描述实现是否把舍入误差控制成“好像在一个邻近输入上精确求解”。前者属于问题，后者属于算法。准确结果通常同时需要问题不过度病态、算法足够稳定。
>
> <!-- bilingual-en:start -->
> **Conditioning** describes how sensitive the mathematical problem is to small input perturbations. **Algorithmic stability** describes whether an implementation controls rounding error so that its output resembles an exact solution for nearby input. Conditioning belongs to the problem; stability belongs to the algorithm. Accurate results generally require both a reasonably conditioned problem and a sufficiently stable algorithm.
> <!-- bilingual-en:end -->

一个稳定算法也可能在病态问题上产生较大前向误差，因为任何微小输入或舍入扰动都会被问题放大；一个良态问题也可能被不稳定公式算坏，例如用会发生灾难性消去的代数形式。把精度提高或重复运行得到同样结果，都不能单独区分这两种来源。
<!-- bilingual-en:start -->
A stable algorithm can still have large forward error on an ill-conditioned problem because the problem amplifies tiny input or rounding perturbations. A well-conditioned problem can be spoiled by an unstable formula, such as one with catastrophic cancellation. Higher precision or reproducible reruns alone do not distinguish these sources.
<!-- bilingual-en:end -->

验证应至少分三层：检查输入与单位；用残差或后向误差问“结果是否精确解决了邻近问题”；再结合条件数或敏感性把后向误差解释为前向误差。解析特例、区间界或更高精度计算可以作为外部基准，但“结果看起来稳定”不是正确性证书。
<!-- bilingual-en:start -->
Validation should separate at least three layers: inspect inputs and units; use residual or backward error to ask whether the output exactly solves a nearby problem; then use a condition number or sensitivity analysis to translate backward error into forward error. Analytic special cases, interval bounds, or higher-precision computation can serve as external references, but a result that merely looks stable is not a correctness certificate.
<!-- bilingual-en:end -->

> [!question]- 回忆与应用
> 同一个算法把输入最后一位改动后，答案改变很多。这一现象是否直接证明算法不稳定？
>
> **答案：** 不直接证明。变化可能来自问题本身病态；要比较精确问题的敏感性与算法额外引入的误差。
