# Problem conditioning and algorithmic stability
<!-- bilingual-en:end -->

*条件性与算法稳定性*

<!-- bilingual-en:start -->
A calculation can miss its intended answer for two different reasons. The data may not determine that answer accurately: tiny input changes can produce large changes even in exact mathematics. Or the chosen computational route may introduce avoidable rounding damage. **Conditioning** describes the first sensitivity; **algorithmic stability** describes the second aspect, relative to the problem being solved. A condition number does not itself create an error—it measures possible amplification.
<!-- bilingual-en:end -->

一次计算偏离预期答案，可能有两种不同原因。数据本身未必足够准确地确定答案：即使用精确数学，输入的微小变化也可能引起结果大变。计算路线还可能带来可以避免的舍入损伤。**条件性**描述前一种敏感性，**算法稳定性**则相对于所求问题，描述后一方面。条件数本身不会制造误差，它衡量可能的放大。

> [!example] A nearby problem can have a different answer · 邻近问题也可能答案不同
> <!-- bilingual-en:start -->
> Keep $A=\operatorname{diag}(1,10^{-8})$ fixed, meaning two independent coordinate scales, and solve $Ax=b$ for $b=(1,0)^T$. The answer is $x=(1,0)^T$. If $b$ changes to $\widetilde b=(1,10^{-8})^T$, its relative Euclidean change is only $10^{-8}$, but the exact answer becomes $\widetilde x=(1,1)^T$: relative solution change $1$. An algorithm returning this latter vector for the original input would exactly solve a very nearby right-hand side, yet its output would be far from the original answer.
> <!-- bilingual-en:end -->
>
> 固定 $A=\operatorname{diag}(1,10^{-8})$，即两个坐标各自按这两个量缩放。对 $b=(1,0)^T$，方程 $Ax=b$ 的解是 $x=(1,0)^T$。若输入变成 $\widetilde b=(1,10^{-8})^T$，欧氏相对变化只有 $10^{-8}$，精确答案却成为 $\widetilde x=(1,1)^T$，解的相对变化为 $1$。若算法面对原输入返回后一个向量，它确实精确解了一个很邻近的右端问题，却仍远离原答案。

<!-- bilingual-en:start -->
## Forward error looks at the answer; backward error looks at the input
<!-- bilingual-en:end -->

*前向误差与后向误差*

<!-- bilingual-en:start -->
Write the exact problem as $y=f(d)$, where $d$ is the input data and $\widehat y$ is the computed output. The [[欧氏范数|Euclidean norm]] $\|\cdot\|$ measures vector length here; other problems may use another stated norm. The **forward error** compares $\widehat y$ with $f(d)$. The **backward error** asks how little we would need to change the input to make $\widehat y$ an exact answer. For nonzero reference scales, the corresponding relative quantities are
<!-- bilingual-en:end -->

把精确问题写成 $y=f(d)$，$d$ 是输入数据，$\widehat y$ 是计算结果。这里用[[欧氏范数]] $\|\cdot\|$ 衡量向量长度；别的问题也可以采用另行说明的范数。**前向误差**比较 $\widehat y$ 与 $f(d)$；**后向误差**则问：至少要把输入改变多少，才能使 $\widehat y$ 成为精确答案？参考尺度非零时，相应的相对量为

$$
\text{forward error}=\frac{\|\widehat y-f(d)\|}{\|f(d)\|},\qquad
\text{backward error}=\inf_{\widetilde d:\ f(\widetilde d)=\widehat y}
\frac{\|\widetilde d-d\|}{\|d\|}.
$$

<!-- bilingual-en:start -->
The infimum means the smallest achievable perturbation size, or its limiting value. The perturbed input must remain in the stated problem class. If no such input exists, exact backward error is infinite. If a denominator is zero, use a meaningful [[绝对误差与相对误差|absolute error or another declared scale]]. A small backward error for one computed result is evidence about that result, not a proof that the algorithm behaves well on all inputs.
<!-- bilingual-en:end -->

下确界表示可以达到的最小扰动大小，或其极限值；扰动后的输入还必须留在规定的问题类别中。若不存在这样的输入，精确后向误差为无穷。分母为零时，应使用有意义的[[绝对误差与相对误差|绝对误差或另行声明的尺度]]。一次结果后向误差很小，只是这次结果的证据，不是算法对所有输入都表现良好的证明。

<!-- bilingual-en:start -->
**Backward stability** is a stronger, algorithm-wide guarantee: in a specified domain and error model, outputs exactly solve inputs whose relative changes are bounded by a modest constant times the rounding scale $u$. Here $u$ measures the precision of [[浮点舍入|floating-point rounding]]; constants are independent of the particular input but may depend on problem dimensions, and usual analyses exclude overflow and problematic underflow. Normwise smallness does not promise the same relative accuracy in every tiny coordinate. Backward stability is one important meaning of numerical stability, not the definition of every use of that word.
<!-- bilingual-en:end -->

**后向稳定性**是针对算法的一种更强保证：在指定定义域及误差模型下，结果精确求解的邻近输入，其相对变化受“适度常数乘舍入尺度 $u$”控制。$u$ 描述[[浮点舍入]]的精度；常数不依赖具体输入，但可以依赖问题维数；通常分析还排除溢出及有问题的下溢。按范数衡量很小，并不保证每个很小坐标都有同等相对精度。后向稳定是数值稳定性的一个重要含义，但不能替代这个词的所有用法。

## Why conditioning connects the two errors
<!-- bilingual-en:end -->

*条件性如何连接两种误差*

<!-- bilingual-en:start -->
For a fixed invertible square matrix $A$, let $x=A^{-1}b$ with $b\ne0$. A candidate $\widehat x$ has residual $r=b-A\widehat x$. It exactly solves the nearby system $A\widehat x=b-r$. Thus, when only $b$ may vary, its relative backward error is exactly $\|r\|_2/\|b\|_2$. Also $\widehat x-x=-A^{-1}r$, giving
<!-- bilingual-en:end -->

固定可逆方阵 $A$，令 $x=A^{-1}b$，其中 $b\ne0$。候选 $\widehat x$ 的残差为 $r=b-A\widehat x$，它精确求解邻近方程 $A\widehat x=b-r$。所以只允许 $b$ 改变时，相对后向误差恰好为 $\|r\|_2/\|b\|_2$。再由 $\widehat x-x=-A^{-1}r$ 得到

$$
\frac{\|\widehat x-x\|_2}{\|x\|_2}
\le\kappa_2(A)\frac{\|r\|_2}{\|b\|_2},
\qquad \kappa_2(A)=\|A\|_2\|A^{-1}\|_2.
$$

<!-- bilingual-en:start -->
The [[谱范数|matrix norm]] is the largest length amplification. A large $\kappa_2(A)$ permits a small backward error to coexist with a large forward error, as in the opening example; it does not say that every error direction is amplified maximally. This bound fixes $A$ and concerns an invertible system. For general [[线性最小二乘|least squares]], the fitting residual can be nonzero even for an exact optimizer; its size alone is not numerical backward error. Perturbing both the matrix and the right-hand side also changes the sensitivity calculation.
<!-- bilingual-en:end -->

[[谱范数|矩阵范数]]是最大的长度放大倍数。较大的 $\kappa_2(A)$ 允许小后向误差与大前向误差同时出现，开头例子便如此；并不表示每个误差方向都会被最大程度放大。这个界固定 $A$，针对可逆方程。一般[[线性最小二乘]]即使精确达到最优，拟合残差也可能非零，不能仅把它的大小当成数值后向误差。同时扰动矩阵和右端，也需要重新分析敏感性。

> [!example] A sensitive formula for a well-conditioned task · 良态任务也能被公式算坏
> <!-- bilingual-en:start -->
> Consider $g(t)=\sqrt{1+t}-1$ for $t\ge0$, and evaluate it at a small positive $t$. Algebra gives the identical expression
>
> $$g(t)=\frac{t}{\sqrt{1+t}+1}.$$
>
> At $t=10^{-16}$, ordinary binary64 evaluation of the first expression can return zero because $1+t$ rounds to $1$. The second gives approximately $5\times10^{-17}$. The task itself is relatively well-conditioned there: its relative local sensitivity is $t g'(t)/g(t)=(\sqrt{1+t}+1)/(2\sqrt{1+t})$, near $1$; $g'$ denotes the [[导数|derivative]]. The first route loses the small result through [[灾难性消去|cancellation of rounded quantities]]. Its zero answer corresponds to $t=0$, a $100\%$ relative input change, not a tiny backward perturbation.
> <!-- bilingual-en:end -->
>
> 考虑定义在 $t\ge0$ 上的 $g(t)=\sqrt{1+t}-1$，并在一个很小的正数 $t$ 处求值。有理化给出完全相同的公式 $t/(\sqrt{1+t}+1)$。当 $t=10^{-16}$ 时，通常的 binary64 直接计算第一式可能返回零，因为 $1+t$ 舍入成 $1$；第二式则约为 $5\times10^{-17}$。问题本身在此相对良态：局部相对敏感性 $t g'(t)/g(t)=(\sqrt{1+t}+1)/(2\sqrt{1+t})$ 接近 $1$，其中 $g'$ 是[[导数]]。第一条路线因[[灾难性消去|已舍入量相减]]而丢失小结果。其零答案对应 $t=0$，相对输入变化为 $100\%$，并非微小后向扰动。

<!-- bilingual-en:start -->
In practice, first state which inputs may vary, their units, and the error scale. Then assess the computed residual or an appropriate backward error, and use the problem's sensitivity to interpret it. Analytic checks, reliable higher-precision calculations and error bounds provide independent evidence. Repeating a deterministic calculation or printing more digits does not. If a one-digit input change causes a large output change, compare it with exact-problem sensitivity before blaming the algorithm.
<!-- bilingual-en:end -->

实际检查时，先说明哪些输入可以改变、它们的单位及误差尺度；再评估残差或适当的后向误差，并用问题的敏感性解释它。解析特例、可靠的高精度计算及误差界可以提供独立证据，重复确定性计算或多打印小数位则不能。输入末位改变导致输出大变时，应先与精确问题的敏感性比较，再判断是否算法失稳。
