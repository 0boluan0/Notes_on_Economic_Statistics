# 要修改调用者的指针对象必须返回新指针或传入二级指针
<!-- bilingual-en:start -->
*To change a caller's pointer object, return a new pointer or pass a pointer to that pointer*
<!-- bilingual-en:end -->

> [!summary] 多一级间接访问
> 普通 `T *p` 形参只是调用者指针值的副本，给 `p` 重新赋值不会改变调用者的指针对象。要改那个指针对象，可以让函数返回新的 `T *` 再由调用者赋值；也可以把指针对象的地址传入，使形参类型成为 `T **`，再通过 `*slot` 写调用者的 `T *`。
> <!-- bilingual-en:start -->
> An ordinary `T *p` parameter is only a copy of the caller's pointer value, so assigning to `p` cannot change the caller's pointer object. Return a new `T *` for the caller to assign, or pass the pointer object's address as `T **` and write it through `*slot`.
> <!-- bilingual-en:end -->

```c
#include <stddef.h>

void redirect(int **slot, int *target) {
    if (slot != NULL) {
        *slot = target;
    }
}

void example(void) {
    int x = 1;
    int y = 2;
    int *p = &x;
    redirect(&p, &y);  // p 现在指向 y
}
```

调用时复制给 `slot` 的值是 `&p`。因此 `slot` 指向调用者的指针对象 `p`，`*slot` 正是那个 `int *` 对象；`*slot = target` 才会改动它。`target` 自己仍按值复制，函数没有神秘的“引用传递模式”。
<!-- bilingual-en:start -->
The value copied into `slot` is `&p`, so `slot` designates the caller's pointer object and `*slot` is that `int *` object. Assigning through `*slot` changes it. `target` is still passed by value; no separate pass-by-reference mode appears.
<!-- bilingual-en:end -->

二级指针也不自动代表二维数组。`T **` 描述“指向 `T *` 对象的指针”；真正连续的二维数组 `T a[R][C]` 转换后是指向一整行的 `T (*)[C]`，类型、布局和算术都不同。若 `T **` 被用作分配型输出参数，接口还必须写清：`slot` 能否为空、失败时是否保持 `*slot` 不变、成功后谁拥有新对象、传入槽位已有资源时会不会泄漏。
<!-- bilingual-en:start -->
A double pointer does not automatically represent a two-dimensional array. `T **` points to a `T *` object, whereas a contiguous `T a[R][C]` converts to `T (*)[C]`. An allocating output parameter must additionally specify nullability, failure atomicity, ownership transfer, and what happens if the output slot already owns a resource.
<!-- bilingual-en:end -->

> [!question]- 最小自检
> 为什么函数内 `p = NULL` 改不了调用者的 `int *p`，而接收 `int **slot` 后 `*slot = NULL` 可以？
>
> **答案：** 前者只给指针形参副本赋值；后者通过 `slot` 找到并写入调用者的指针对象。
