# Two matrices are equal exactly when their solution sets agree for every identical right-hand side
<!-- bilingual-en:end -->
*两个同型矩阵相等，当且仅当对每个相同的右端，它们的完整解集都相同*

<!-- bilingual-en:start -->
Let $A,C\in\mathbb R^{m\times n}$. If each fixed $b\in\mathbb R^m$ gives exactly the same set of inputs solving $Ax=b$ and $Cx=b$, then $A=C$. The converse is immediate. Both **every $b$** and **the same $b$** are essential.
<!-- bilingual-en:end -->

设 $A,C\in\mathbb R^{m\times n}$。如果对每个固定的 $b\in\mathbb R^m$，满足 $Ax=b$ 与 $Cx=b$ 的输入集合完全相同，则 $A=C$；反向显然成立。条件中的**每个 $b$**与**相同的 $b$**缺一不可。

$$
\bigl[\forall b\in\mathbb R^m,\ 
\{x:Ax=b\}=\{x:Cx=b\}\bigr]
\quad\Longleftrightarrow\quad A=C.
$$

<!-- bilingual-en:start -->
## Proof
<!-- bilingual-en:end -->
*证明*

<!-- bilingual-en:start -->
Choose any $v\in\mathbb R^n$ and set $b=Av$. Then $v$ solves $Ax=b$, so it also solves $Cx=b$. Thus $Cv=Av$ for every $v$. Taking $v$ to be each coordinate vector shows that corresponding columns agree, hence $A=C$. No invertibility or full-rank assumption is required.
<!-- bilingual-en:end -->

任取 $v\in\mathbb R^n$，令 $b=Av$。此时 $v$ 是 $Ax=b$ 的解，所以也必须是 $Cx=b$ 的解。因此对每个 $v$ 都有 $Cv=Av$。依次取各坐标单位向量，就得到两矩阵对应的列相同，从而 $A=C$。不要求可逆，也不要求满秩。

<!-- bilingual-en:start -->
## Boundary
<!-- bilingual-en:end -->
*适用边界*

<!-- bilingual-en:start -->
Equal nullspaces only test $b=0$ and do not determine the matrix: $I$ and $2I$ have the same nullspace. For any nonzero $b$, however, $Ix=b$ has solution $b$, while $2Ix=b$ has solution $b/2$.
<!-- bilingual-en:end -->

零空间相同只检查了 $b=0$，不能确定矩阵：$I$ 与 $2I$ 的零空间相同。但对任意非零 $b$，$Ix=b$ 的解为 $b$，$2Ix=b$ 的解为 $b/2$。

<!-- bilingual-en:start -->
[[行操作的解集不变性|Reversible row operations preserve solutions]] by changing **both** sides: $Ax=b\iff EAx=Eb$. This does not say that $Ax=b$ and $EAx=b$ agree for every unchanged $b$.
<!-- bilingual-en:end -->

[[行操作的解集不变性|可逆行操作保持解集]]时，改变的是**两侧**：$Ax=b\iff EAx=Eb$。这不意味着把 $b$ 保持不变后，$Ax=b$ 与 $EAx=b$ 对每个 $b$ 仍有相同解集。
