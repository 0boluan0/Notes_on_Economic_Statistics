# 位置编码是把序列位置或位置差引入 token 表示或注意力计算的机制
<!-- bilingual-en:start -->
*Positional encoding introduces sequence positions or position differences into token representations or attention computation*
<!-- bilingual-en:end -->

**位置编码**（positional encoding）是向模型显式提供序列位置关系的机制：它把 token 的绝对位置，或两个位置之间的相对位移，写入 token 表示或注意力计算。[[Token嵌入]] 区分 token 身份；位置编码使同一个 token 出现在不同位置时，计算可以有所区别。

<!-- bilingual-en:start -->
**Positional encoding** explicitly supplies sequence-position information to a model by incorporating absolute positions or relative offsets into token representations or attention computation. [[Token嵌入|Token embeddings]] distinguish token identities; positional encoding lets computation distinguish occurrences of the same token at different positions.
<!-- bilingual-en:end -->

例如序列中两次出现“很”，二者查到的 token 嵌入可以相同。若输入采用 $z_p=e(\text{token}_p)+p_p$，它们会加上不同槽位的位置向量；模型因此能读取“同一个词、不同的位置”这两层信息。

<!-- bilingual-en:start -->
If a sequence contains two occurrences of “very,” both may retrieve the same token embedding. With an additive representation $z_p=e(\text{token}_p)+p_p$, they receive position vectors from different slots. The representation therefore carries both shared token identity and positional context.
<!-- bilingual-en:end -->

位置编码不限定为“加一个向量”：[[正弦位置编码]] 和 [[可学习位置嵌入]] 可以加到输入表示；[[RoPE]] 则旋转已投影的 query 和 key，让点积包含相对位置项。也有方法直接给注意力分数加入位置偏置。它们都向计算提供位置关系，但注入位置和参数化方式不同。

<!-- bilingual-en:start -->
Positional encoding is not limited to adding a vector. [[正弦位置编码|Sinusoidal encodings]] and [[可学习位置嵌入|learned positional embeddings]] can be added to input representations. [[RoPE|RoPE]] instead rotates projected queries and keys so their dot product contains a relative-position term. Other methods add positional biases directly to attention scores. These methods differ in where and how they introduce position information.
<!-- bilingual-en:end -->

[[自注意力置换等变性|纯内容、无顺序约束的自注意力具有置换等变性]]，这说明为何要考虑位置机制。[[因果注意力掩码]] 则规定哪些位置允许互读，也会引入顺序结构；因此“没有显式位置向量”本身不足以判断整个模型是否利用顺序。

<!-- bilingual-en:start -->
[[自注意力置换等变性|Content-only self-attention without ordering constraints is permutation equivariant]], which motivates positional mechanisms. A [[因果注意力掩码|causal attention mask]] specifies which positions may read one another and also introduces order. The absence of explicit position vectors alone therefore does not establish whether a whole model uses sequence order.
<!-- bilingual-en:end -->

## 来源与核验
<!-- bilingual-en:start -->
*Sources and verification*
<!-- bilingual-en:end -->

- [Vaswani et al. (2017), *Attention Is All You Need*](https://arxiv.org/html/1706.03762v7#S3.SS5)，§3.5：支持通过位置编码加入绝对或相对位置信息，以及原始 Transformer 中与输入嵌入相加的方案。
- [Su et al., *RoFormer*, v5](https://arxiv.org/html/2104.09864v5)，§2.2–2.3、§3.2：支持绝对位置向量、分数中的相对位置项和投影后旋转等不同注入方式。

<!-- bilingual-en:start -->
- Vaswani et al., §3.5, motivates positional information and uses additive input encodings.
- Su et al., §2.2–2.3 and §3.2, presents absolute position vectors, relative terms in attention scores, and rotation after projection as distinct ways to introduce position information.
<!-- bilingual-en:end -->
