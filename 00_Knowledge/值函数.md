# 值函数把每个参数对应的优化问题映射为该问题能达到或逼近的最优目标值
<!-- bilingual-en:start -->
*A value function maps each parameter to the optimal objective value that the corresponding problem attains or approaches*
<!-- bilingual-en:end -->

> [!summary] 它是什么
> 对参数 $\theta$ 下的最大化问题
> $$
> \sup_{x\in X(\theta)} f(x,\theta),
> $$
> 值函数定义为
> $$
> v(\theta)=\sup_{x\in X(\theta)} f(x,\theta).
> $$
> 它只记录“在当前参数下，目标最好能有多好”；哪些选择实现这个值，由 [[最优解对应]] 另行记录。
>
> <!-- bilingual-en:start -->
> For the parameterised maximisation problem $\sup_{x\in X(\theta)}f(x,\theta)$, the value function is $v(\theta)=\sup_{x\in X(\theta)}f(x,\theta)$. It records how good the objective can be at each parameter. [[最优解对应|The solution correspondence]] separately records which choices attain that value.
> <!-- bilingual-en:end -->

## 为什么定义用 supremum
<!-- bilingual-en:start -->
*Why the definition uses a supremum*
<!-- bilingual-en:end -->

最优值可能被无限逼近，却没有被任何可行选择取到。例如在开区间 $(0,1)$ 上最大化 $f(x)=x$ 时，
$$
v=\sup_{0<x<1}x=1,
$$
但不存在最大点。只有在另行证明最优值被取得后，才能把 $\sup$ 改写为 $\max$。连续目标加非空紧可行集是一条常用的取得性路线，见 [[极值定理]]。

<!-- bilingual-en:start -->
The optimal value may be approached without being attained. Maximising $x$ over $(0,1)$ gives the finite supremum one but no maximizer. Only after attainment has been proved may $\sup$ be replaced by $\max$. Continuity on a nonempty compact feasible set is one standard route; see [[极值定理|the extreme-value theorem]].
<!-- bilingual-en:end -->

在扩展实数约定下，最大化问题的可行集为空时，其值常记为 $-\infty$；目标在可行集上无上界时，记为 $+\infty$。因此要把“不可行”、“无界”、“有限但不取得”和“取得最优”分开。

<!-- bilingual-en:start -->
Under extended-real conventions, an infeasible maximisation problem is often assigned value $-\infty$, while an unbounded-above problem has value $+\infty$. Infeasibility, unboundedness, a finite but unattained supremum, and an attained optimum are four different states.
<!-- bilingual-en:end -->

## 值不记录“怎么做到”
<!-- bilingual-en:start -->
*The value does not record how it is achieved*
<!-- bilingual-en:end -->

同一个最优值可以由一个、多个甚至无限多个选择实现。因而 $v(\theta)$ 可以很平滑，而某条最优选择路径却发生跳跃。[[隐函数比较静态]] 研究选择分支怎样变；[[包络定理]] 和 [[Danskin定理]] 研究值怎样变。这些问题的研究对象不同。

<!-- bilingual-en:start -->
One optimal value may be attained by one, several, or infinitely many choices. The value can therefore be smooth even when a selected optimizer path jumps. Implicit comparative statics studies a choice branch; envelope results study the value.
<!-- bilingual-en:end -->

利润函数和间接效用函数是最大值函数；成本函数和支出函数是最小值函数。最小化时把 $\sup$ 换成 $\inf$，定义的核心不变。

<!-- bilingual-en:start -->
Profit and indirect-utility functions are maximum-value functions; cost and expenditure functions are minimum-value functions. For minimisation, replace the supremum with an infimum.
<!-- bilingual-en:end -->

> [!question]- 自检
> 若 $v(\theta)$ 是有限数，能否据此断言该参数下存在最优选择？
>
> <!-- bilingual-en:start -->
> If $v(\theta)$ is finite, can one conclude that an optimal choice exists at that parameter?
> <!-- bilingual-en:end -->
>
> **答案：** 不能。有限上确界仍可能不被取得；还需要独立的取得性证明。
>
> <!-- bilingual-en:start -->
> **Answer:** No. A finite supremum may be unattained; a separate attainment argument is still required.
> <!-- bilingual-en:end -->
