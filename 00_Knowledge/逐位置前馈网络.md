# 逐位置前馈网络在每个 token 位置独立施加共享参数的非线性通道变换

<!-- bilingual-en:start -->
*A position-wise feed-forward network independently applies a shared nonlinear channel transformation at every token position.*
<!-- bilingual-en:end -->

逐位置前馈网络（position-wise FFN）是分别作用于序列中每个 token 表示的前馈网络：同一层的所有位置使用同一组参数，每个位置只把自己的输入向量交给该网络。在原始 [[Transformer]] 中，这个映射由两次仿射变换和夹在中间的 ReLU 组成，输入与输出宽度均为 $d_{\mathrm{model}}$。

<!-- bilingual-en:start -->
A position-wise feed-forward network operates separately on each token representation. All positions in the same layer use the same parameters, and each position supplies only its own input vector to the network. In the original [[Transformer|Transformer architecture]], the mapping consists of two affine transformations with a ReLU between them; both its input and output have width $d_{\mathrm{model}}$.
<!-- bilingual-en:end -->

## 同一映射作用于每一行

<!-- bilingual-en:start -->
*The same mapping acts on every row.*
<!-- bilingual-en:end -->

令 $X\in\mathbb R^{n\times d_{\mathrm{model}}}$ 按行排列 token。对其中任意一行 $x_i$，原始 FFN 计算

<!-- bilingual-en:start -->
Let $X\in\mathbb R^{n\times d_{\mathrm{model}}}$ contain one token per row. For any row $x_i$, the original FFN computes
<!-- bilingual-en:end -->

$$
\operatorname{FFN}(x_i)
=\operatorname{ReLU}(x_iW_1+b_1)W_2+b_2,
$$

$$
W_1\in\mathbb R^{d_{\mathrm{model}}\times d_{\mathrm{ff}}},\qquad
W_2\in\mathbb R^{d_{\mathrm{ff}}\times d_{\mathrm{model}}}.
$$

$b_1$、$b_2$ 分别是宽度为 $d_{\mathrm{ff}}$、$d_{\mathrm{model}}$ 的行向量。第一步把通道映射到内部宽度，ReLU 逐元素保留正值并把负值置零，第二步映回原宽度，以便接入 [[残差连接]]。跨位置共享参数意味着所有 $i$ 都用这同一对 $W_1,W_2$；不同层则有各自的参数。

<!-- bilingual-en:start -->
The row-vector biases $b_1$ and $b_2$ have widths $d_{\mathrm{ff}}$ and $d_{\mathrm{model}}$. The first transformation maps the channels into the internal width, ReLU retains positive entries and zeros negative entries, and the second transformation returns to the original width for a [[残差连接|residual connection]]. Parameter sharing across positions means that every $i$ uses this same pair of matrices; different layers have their own parameters.
<!-- bilingual-en:end -->

## 两个位置的最小算例

<!-- bilingual-en:start -->
*A minimal example with two positions.*
<!-- bilingual-en:end -->

为方便手算，取 $d_{\mathrm{model}}=d_{\mathrm{ff}}=2$、$W_1=I$、$W_2=\operatorname{diag}(2,1)$，偏置为零：

<!-- bilingual-en:start -->
For a small arithmetic example, set $d_{\mathrm{model}}=d_{\mathrm{ff}}=2$, $W_1=I$, $W_2=\operatorname{diag}(2,1)$, and both biases to zero:
<!-- bilingual-en:end -->

$$
X=\begin{bmatrix}1&-1\\2&3\end{bmatrix}
\quad\longrightarrow\quad
\operatorname{ReLU}(X)=\begin{bmatrix}1&0\\2&3\end{bmatrix}
\quad\longrightarrow\quad
\operatorname{FFN}(X)=\begin{bmatrix}2&0\\4&3\end{bmatrix}.
$$

两行走的是同一套运算；计算第一行没有读取第二行。上下文可以已经由前面的 [[自注意力]] 写进第一行，FFN 随后处理这个包含上下文的向量。因此“逐位置”描述的是此子层的运算方式，并不意味着输入表示没有上下文。

<!-- bilingual-en:start -->
Both rows undergo the same computation, and the first row's calculation does not read the second row. Earlier [[自注意力|self-attention]] may already have written contextual information into the first row, which the FFN then transforms. “Position-wise” describes this sublayer's operation; its input representation may already contain context.
<!-- bilingual-en:end -->
