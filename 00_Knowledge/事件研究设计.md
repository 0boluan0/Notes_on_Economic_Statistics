# 金融事件研究须预先定义事件样本估计窗与事件窗
<!-- bilingual-en:start -->
*A financial event study must prespecify the event, sample, estimation window, and event window*
<!-- bilingual-en:end -->

> [!summary] 原子设计
> 一个可复核的金融事件研究先冻结：事件是什么、事件日怎样确定、哪些证券进入样本、正常收益在哪个估计窗估计、价格反应在哪个事件窗累计，以及原假设和聚合方式。看完回报再改日期、样本或窗口会把结果选择混入检验。
> <!-- bilingual-en:start -->
> A reproducible financial event study first fixes the event definition, event-date rule, sample-inclusion criteria, estimation window for normal returns, event window for price reactions, null hypothesis, and aggregation method. Changing dates, samples, or windows after observing returns mixes outcome selection into the test.
> <!-- bilingual-en:end -->

估计窗通常位于事件窗之前，且不包含事件期，以免目标事件污染正常收益参数。事件窗可覆盖公告日及次日来容纳收盘后公告，也可加入公告前时期观察提前反应；但每增加一天都会引入更多普通波动和并发消息，因此窗口不是越长越完整。
<!-- bilingual-en:start -->
The estimation window usually precedes and excludes the event window so that the event does not contaminate normal-return parameters. The event window may include the announcement day and the next day for after-close releases, and may include pre-event days to inspect early reactions. Every added day also admits more ordinary volatility and concurrent news, so a longer window is not automatically more complete.
<!-- bilingual-en:end -->

样本规则应同时报告数据可得性限制、行业或规模限制、事件在日历时间的分布和退出原因。缺失价格、并购后退市或只保留“干净事件”都可能改变目标总体；排除规则必须在看到 [[异常收益|AR]]/[[累计异常收益|CAR]] 前定义并做敏感性检查。
<!-- bilingual-en:start -->
Sample rules should report data-availability, industry or size restrictions, the calendar distribution of events, and reasons for exclusion. Missing prices, post-merger delisting, or retaining only “clean events” can change the target population. Exclusion rules should be set before viewing AR/CAR and subjected to sensitivity analysis.
<!-- bilingual-en:end -->

> [!question]- 自检
> 研究者试了十种事件窗后只报告显著的一种，主要问题是什么？
>
> **答案：** 窗口选择已经使用结果信息，名义显著性不再对应一次预先定义的检验；应报告搜索范围、校正多重比较，并用冻结窗口复核。
