# 平均情况复杂度是在指定输入分布下对资源成本取期望

<!-- bilingual-en:start -->
*Average-case complexity averages resource costs over a specified input distribution*
<!-- bilingual-en:end -->

平均情况复杂度是在规模为 $n$ 的合法输入上指定概率分布 $D_n$，再对成本取[[期望]]。对确定性算法，随机性来自输入选择，而不是程序内部；离散输入下，期望存在时为

<!-- bilingual-en:start -->
Average-case complexity specifies a distribution $D_n$ over valid inputs of size $n$ and takes the [[期望|expectation]] of their costs. For a deterministic algorithm, randomness comes from input selection, not from the program. For discrete inputs, when the expectation exists:
<!-- bilingual-en:end -->

$$
T_{\mathrm{avg},D}(n)
=\mathbb E_{X\sim D_n}[T(X)]
=\sum_{x\in I_n}D_n(x)T(x).
$$

“平均”必须回答按什么分布平均。例如，长度为 $n\ge1$ 的列表中元素互异，目标保证存在且等概率位于每一个位置；找到即停的线性搜索比较次数才有

<!-- bilingual-en:start -->
An average must identify its distribution. For example, suppose a list has $n\ge1$ distinct elements, and the target is guaranteed to occur at a uniformly selected position. An early-return linear search then has expected comparison count
<!-- bilingual-en:end -->

$$
\frac1n\sum_{j=1}^{n}j=\frac{n+1}{2}.
$$

若目标以概率 $q$ 存在，且给定存在时仍均匀分布，则期望比较次数为 $q(n+1)/2+(1-q)n$。若总命中第一项则是 $1$。所以“平均检查半个列表”有分布条件，不是线性搜索自身无条件的性质。

<!-- bilingual-en:start -->
If the target is present with probability $q$ and is conditionally uniform when present, the expected count becomes $q(n+1)/2+(1-q)n$. If every query matches the first item, it is $1$. Thus “half the list on average” depends on a distribution; it is not an unconditional property of linear search.
<!-- bilingual-en:end -->

对固定输入取程序内部随机选择的期望，属于[[随机算法期望复杂度]]；跨任意操作序列分摊总成本，属于[[摊还复杂度]]。这三种平均化对象不能混用。

<!-- bilingual-en:start -->
Expectation over internal random choices on a fixed input belongs to [[随机算法期望复杂度|randomized expected complexity]]. Spreading total cost over arbitrary operation sequences belongs to [[摊还复杂度|amortized complexity]]. These three objects of averaging are distinct.
<!-- bilingual-en:end -->
