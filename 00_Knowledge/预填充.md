# 预填充是处理已知提示并产生首个输出 token 分布的推理阶段

<!-- bilingual-en:start -->
*Prefill processes the known prompt and produces the distribution for the first output token*
<!-- bilingual-en:end -->

**预填充**（prefill）是自回归语言模型处理已有提示的阶段：模型计算提示位置的表示与逐层注意力状态，并由最后提示位置的[[语言模型输出头]]给出首个新 token 的分布。选择该分布中的一个 token 后，首次输出已经产生；接下来才是[[增量解码]]。

<!-- bilingual-en:start -->
**Prefill** processes an autoregressive language model's existing prompt. It computes representations and layer-wise attention state for prompt positions, then uses the final prompt position's [[语言模型输出头|language-model output head]] to produce a distribution for the first new token. Selecting a token from that distribution produces the first output; [[增量解码|incremental decoding]] follows.
<!-- bilingual-en:end -->

## 从三个输入位置到第一个输出

<!-- bilingual-en:start -->
*From three input positions to the first output*
<!-- bilingual-en:end -->

考虑一个 decoder-only causal LM，提示为三个已编码的 token $x_1,x_2,x_3$。模型按[[因果注意力掩码]]计算各位置表示；最后一个位置可以读取全部提示，所以它的输出分布是

<!-- bilingual-en:start -->
Consider a decoder-only causal LM with three encoded prompt tokens $x_1,x_2,x_3$. A [[因果注意力掩码|causal attention mask]] controls each position's visibility. The final position can read the entire prompt, so its output distribution is
<!-- bilingual-en:end -->

$$
p_\theta(y_1\mid x_1,x_2,x_3).
$$

按生成规则选择 $y_1$ 后，[[KV cache]] 已包含三个提示位置的键和值。此时 $y_1$ 刚被选出，还没有作为新输入经过模型，因此通常还没有它的 KV；处理 $y_1$ 才能继续预测 $y_2$。

<!-- bilingual-en:start -->
After the generation rule selects $y_1$, the [[KV cache|KV cache]] contains keys and values for the three prompt positions. The newly selected $y_1$ has not yet passed through the model as an input, so its KV state has ordinarily not been computed. Processing $y_1$ is what predicts $y_2$.
<!-- bilingual-en:end -->

## 已知输入提供并行机会

<!-- bilingual-en:start -->
*Known inputs provide parallelism*
<!-- bilingual-en:end -->

所有提示 token 在预填充开始前已知，所以同一层可一起处理多个位置；因果掩码限制读取方向，不要求把这些已知输入逐个送完。层与层之间仍有依赖，而未来生成的 token 尚未知，不能按同一理由直接并行生成整段回答。

<!-- bilingual-en:start -->
All prompt tokens are known before prefill begins, allowing multiple positions to be processed together within a layer. Causal masking restricts visibility without requiring known inputs to be submitted one at a time. Layers still depend on earlier layers, and unknown future tokens cannot be generated in parallel by the same argument.
<!-- bilingual-en:end -->

预填充定义的是阶段，不规定它必须是一次 kernel 或一个不间断执行片段：[[分块预填充]]可以拆分提示，[[KV复用条件|合法的前缀复用]]可以省去已经计算过的部分。阶段的计算时间也不等于包含排队和传输的[[首Token延迟]]。以上三 token 示例是假设没有前缀缓存命中的基本路径。

<!-- bilingual-en:start -->
Prefill names a phase, not a requirement for one kernel or uninterrupted execution. [[分块预填充|Chunked prefill]] can split the prompt, and [[KV复用条件|valid prefix reuse]] can avoid work already performed. Its computation time also differs from [[首Token延迟|time to first token]], which may include queueing and transmission. The three-token example assumes no prefix-cache hit.
<!-- bilingual-en:end -->
