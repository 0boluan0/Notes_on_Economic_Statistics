# 期望吸收时间向量等于基本矩阵乘以全一向量
<!-- bilingual-en:start -->
*The expected time-to-absorption vector is the fundamental matrix times the all-ones vector*
<!-- bilingual-en:end -->

> [!summary] $t=N\mathbf1$
> 对有限吸收链，令 $\tau$ 是首次进入任一吸收状态的时间，$t_i=E_i\tau$；若 $N$ 是吸收链基本矩阵，$\mathbf1$ 是维数等于暂态状态数的全一列向量，则
> $$t=N\mathbf1.$$
> <!-- bilingual-en:start -->
> For a finite absorbing chain, let $\tau$ be the first entrance time into any absorbing state and set $t_i=E_i\tau$. If $N$ is the fundamental matrix and $\mathbf1$ is the all-ones column vector over the transient states, then $t=N\mathbf1$.
> <!-- bilingual-en:end -->

第 $i$ 行的 $N_{ij}$ 是吸收前访问暂态状态 $j$ 的期望次数。对所有暂态 $j$ 求和，正好数出时刻 $0,1,\ldots,\tau-1$ 的暂态访问总数，也就是吸收时间 $\tau$ 的步数。
<!-- bilingual-en:start -->
The entry $N_{ij}$ is the expected number of visits to transient state $j$ before absorption. Summing row $i$ therefore counts the expected total number of transient-state visits at times $0,1,\ldots,\tau-1$, which is exactly $E_i\tau$.
<!-- bilingual-en:end -->

这个公式依赖非吸收状态确实暂态，从而 $N=(I-Q)^{-1}$ 存在。对一般 Markov 链，即使目标几乎必然可达，期望命中时间仍可能无穷；此时应回到 [[期望命中时间方程]] 并单独检查 [[必达不推有限期望|均值有限性]]，不能直接套用有限矩阵逆。
<!-- bilingual-en:start -->
The formula requires all nonabsorbing states to be transient, so that $N=(I-Q)^{-1}$ exists. In a general Markov chain, almost-sure hitting can still coexist with an infinite mean hitting time; then one must use the first-step equations and check finiteness separately rather than forcing a finite matrix inverse.
<!-- bilingual-en:end -->

若只有一个暂态状态且每步以概率 $q<1$ 留下、以概率 $1-q$ 吸收，则
$$N=(1-q)^{-1},\qquad t=(1-q)^{-1},$$
与几何等待时间的均值一致。
<!-- bilingual-en:start -->
With one transient state, the absorption time is geometric with success probability $1-q$, so the matrix formula reproduces its mean $(1-q)^{-1}$.
<!-- bilingual-en:end -->

> [!question]- 自检
> 为什么公式使用 $N\mathbf1$，而不是只读取 $N$ 的对角线？
> <!-- bilingual-en:start -->
> Why does the formula use $N\mathbf1$ rather than only the diagonal of $N$?
> <!-- bilingual-en:end -->
>
> **答案：** 吸收前经过的所有暂态状态都贡献时间；必须把一行中对每个暂态状态的期望访问次数全部相加。
> <!-- bilingual-en:start -->
> **Answer:** Time accumulates in every transient state visited before absorption, so all expected visit counts in the row must be added.
> <!-- bilingual-en:end -->
