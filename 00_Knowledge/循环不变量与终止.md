# 循环的完全正确性由不变量与终止度量共同证明
<!-- bilingual-en:start -->
*Loop total correctness combines an invariant with a decreasing termination measure*
<!-- bilingual-en:end -->

> [!summary] 原子方法
> 循环不变量是在选定的循环头检查点成立的命题，包括第一次测试之前以及每次完成循环体、回到该检查点之后。证明循环完成目标通常分三步：初始化使不变量第一次成立；每条会回到循环头的迭代路径都保持它；退出条件与不变量共同推出后置条件。若还要证明终止，则需给出取值于良基集合的度量，例如一个非负整数，并证明每条重复路径都使它严格减少。
> <!-- bilingual-en:start -->
>
> &nbsp;
> A loop invariant is a proposition that holds at a chosen loop-head checkpoint, including before the first test and after each completed body returns to that point. A usual correctness argument has three parts: initialisation establishes the invariant; every iteration path that returns to the loop head preserves it; and the exit condition together with the invariant implies the postcondition. To prove termination as well, give a measure in a well-founded set—for example, a nonnegative integer—and show that every repeating path decreases it strictly.
> <!-- bilingual-en:end -->

```c
long total = 0;
size_t i = 0;
while (i < n) {
    total += values[i];
    i++;
}
```

进入每次迭代前，可以陈述：`0 <= i <= n`，且 `total` 等于 `values[0]` 到 `values[i-1]` 的和。初始化时 `i=0`，空前缀的和为 0；循环体把第 `i` 项纳入并把 `i` 增加 1，命题仍成立；退出时 `i=n`，于是 `total` 覆盖整个数组。终止度量可取 `n-i`，它是非负整数且每次减少 1。
<!-- bilingual-en:start -->
Before each iteration, state that `0 <= i <= n` and that `total` is the sum of `values[0]` through `values[i-1]`. At initialisation `i=0`, and the empty prefix sums to zero. The body includes item `i` and increments `i`, preserving the claim. On exit `i=n`, so `total` covers the complete array. A termination measure is `n-i`: a nonnegative integer that decreases by one each iteration.
<!-- bilingual-en:end -->

## 不变量不是代码的逐句复述

“`i` 每次加一”描述程序动作，不说明已经完成的部分为何正确。好的不变量连接**已处理前缀**、**累积结果**和**尚未处理区间**，足以在退出时推出目标。它也能直接暴露越界：若循环条件写成 `i <= n`，访问 `values[n]` 时就无法维持合法索引范围。
<!-- bilingual-en:start -->
“`i` increases each time” describes an action but does not explain why completed work is correct. A useful invariant connects the processed prefix, the accumulated result, and the unprocessed region strongly enough to imply the goal at exit. It also exposes bounds errors directly: with `i <= n`, an access to `values[n]` cannot preserve the valid-index claim.
<!-- bilingual-en:end -->

上例的论证还依赖前置条件：`values` 必须提供至少 `n` 个可读元素，而且所有前缀和都必须能由 `long` 表示。若加法先发生有符号溢出，数学上的部分和不变量并不能让 C 执行重新获得定义。循环不变量与终止度量是程序员的证明方法，不是 C 语法自动检查的保证；只要求部分正确性或有意永久运行的循环，也不应伪造一个终止证明。
<!-- bilingual-en:start -->
The example also relies on preconditions: `values` must provide at least `n` readable elements, and every prefix sum must be representable by `long`. If addition first incurs signed overflow, the mathematical sum invariant cannot make the C execution defined again. Invariants and termination measures are proof obligations for the programmer, not guarantees enforced by C syntax. A proof of partial correctness, or a deliberately nonterminating loop, should not pretend to establish termination.
<!-- bilingual-en:end -->

> [!question]- 自检
> 一个循环一直保持正确的部分和，但 `i` 在某条分支上不增加。它已经正确了吗？
>
> **答案：** 只证明了部分正确性；若终止度量不在每条可重复路径上推进，循环可能永不结束。
