# 残差连接把捷径传来的输入与可学习变换的输出逐元素相加

<!-- bilingual-en:start -->
*A residual connection adds the input carried by a shortcut to the output of a learned transformation, element by element.*
<!-- bilingual-en:end -->

残差连接是在网络中同时保留捷径支路和可学习变换支路，并把两条支路的输出逐元素相加的连接方式。最常见的恒等捷径直接传递输入 $x$，因此输出为 $y=x+F(x)$；这里 $F$ 是需要学习的残差变换，两项必须具有相同形状。

<!-- bilingual-en:start -->
A residual connection maintains both a shortcut path and a learned transformation path, then adds their outputs element by element. In the common identity-shortcut form, the shortcut passes $x$ directly, giving $y=x+F(x)$. The learned function $F$ is the residual transformation, and the two terms must have the same shape.
<!-- bilingual-en:end -->

## 为什么叫残差

<!-- bilingual-en:start -->
*Why the learned branch is called a residual.*
<!-- bilingual-en:end -->

如果希望整个模块实现映射 $H(x)$，恒等捷径已提供 $x$，可学习支路便承担两者之间的差：

<!-- bilingual-en:start -->
If the whole module is intended to implement a mapping $H(x)$, the identity shortcut already supplies $x$, leaving the learned branch to represent the difference:
<!-- bilingual-en:end -->

$$
F(x)=H(x)-x,
\qquad H(x)=x+F(x).
$$

例如 $x=[1,2]$、$F(x)=[0.5,-1]$，相加后 $y=[1.5,1]$。当 $F(x)=0$ 时，这个相加模块的输出就是 $x$。捷径形状不匹配时，可以先用投影 $P(x)$ 对齐，再计算 $P(x)+F(x)$；原始 Transformer 用固定的 $d_{\mathrm{model}}$ 宽度让子层采用恒等捷径。

<!-- bilingual-en:start -->
For example, $x=[1,2]$ and $F(x)=[0.5,-1]$ give $y=[1.5,1]$. When $F(x)=0$, this addition module returns $x$. If the shortcut has a different shape, a projection $P(x)$ can align it before computing $P(x)+F(x)$. The original Transformer keeps the width at $d_{\mathrm{model}}$ so its sublayers can use identity shortcuts.
<!-- bilingual-en:end -->

## 在 Transformer 中怎样使用

<!-- bilingual-en:start -->
*Use in a Transformer.*
<!-- bilingual-en:end -->

[[多头注意力]] 的最终投影和 [[逐位置前馈网络]] 的第二个映射都输出 $d_{\mathrm{model}}$ 维表示，使其能与子层输入相加。相加之后的后续运算由具体架构决定；[[Transformer后归一化]] 把原始 Transformer 的完整顺序写成 $\operatorname{LayerNorm}(x+F(x))$，其中外层归一化仍会处理相加结果。

<!-- bilingual-en:start -->
The final projection of [[多头注意力|multi-head attention]] and the second mapping of a [[逐位置前馈网络|position-wise feed-forward network]] both produce $d_{\mathrm{model}}$-dimensional representations, allowing addition to the sublayer input. Subsequent operations depend on the architecture. [[Transformer后归一化|Original Transformer post-normalization]] specifies the complete sequence as $\operatorname{LayerNorm}(x+F(x))$, where the outer normalization still transforms the sum.
<!-- bilingual-en:end -->
