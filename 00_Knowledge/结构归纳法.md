# Structural induction
<!-- bilingual-en:end -->
*结构归纳法*

<!-- bilingual-en:start -->
Structural induction proves a claim about objects by following the rules that build them. A string is built by adding a character to a shorter string; an arithmetic expression is built by combining smaller expressions. Instead of listing every possible object, we prove the claim for the starting objects and show that each permitted construction preserves it. Every object with a finite construction then inherits the claim.
<!-- bilingual-en:end -->
结构归纳沿着对象的生成规则证明性质。字符串可以由较短字符串加上一个字符得到，算术表达式可以由较小表达式组合得到。我们不逐个罗列所有对象，而是先证明起始对象具有性质，再证明每一种允许的构造都保持性质。这样，每个能经过有限构造得到的对象就都继承了这个性质。

<!-- bilingual-en:start -->
## Start with the generation rules
<!-- bilingual-en:end -->
*先明确对象怎样生成*

<!-- bilingual-en:start -->
A recursive specification names **base objects**, which need no earlier objects of the same type, and **constructors**, which form an object from already available ones. Here the domain consists of exactly the objects obtainable by finitely many applications of these rules. This last restriction matters: the rules are not permission to add arbitrary extra objects or infinite structures.
<!-- bilingual-en:end -->
递归说明先列出**基础对象**：它们不需要同类的更早对象；再列出**构造器**：它们把已有对象组合成一个对象。这里的论域恰好包含通过有限次应用这些规则得到的对象。最后这项限制很重要：不能在规则之外随意加入额外对象或无限结构。

<!-- bilingual-en:start -->
For example, fix the alphabet $A=\{a,b\}$, a set of allowed characters. The empty string $\varepsilon$ has no characters. The constructor $\langle c,r\rangle$ puts character $c\in A$ in front of string $r$. Thus $\langle b,\varepsilon\rangle$ is `b`, and $\langle a,\langle b,\varepsilon\rangle\rangle$ is `ab`. The letter $c$ is a parameter chosen from $A$; the string $r$ is the recursive input. Every finite string over $A$ is obtained this way, while an endless stream `aaaa…` is not obtained in finitely many steps.
<!-- bilingual-en:end -->
例如固定字母表 $A=\{a,b\}$，即允许使用的字符集合。空串 $\varepsilon$ 不含字符；构造器 $\langle c,r\rangle$ 把字符 $c\in A$ 放在字符串 $r$ 的前面。所以 $\langle b,\varepsilon\rangle$ 是 `b`，而 $\langle a,\langle b,\varepsilon\rangle\rangle$ 是 `ab`。字符 $c$ 是从 $A$ 中任取的参数，字符串 $r$ 才是递归输入。$A$ 上每个有限字符串都可如此生成，无尽的字符流 `aaaa…` 则不能经过有限步生成。

<!-- bilingual-en:start -->
Write $P(r)$ for the property we want to prove about object $r$. It is a [[命题与谓词|predicate]]: after substituting a particular object, it becomes a statement that is true or false. The proof must follow the specified bases and constructors, with all their allowed parameters.
<!-- bilingual-en:end -->
用 $P(r)$ 表示要证明对象 $r$ 具有的性质。它是一个[[命题与谓词|谓词]]：代入具体对象后，就成为一个有真假的陈述。证明须对应已经规定的基础对象与构造器，并覆盖它们允许的全部参数。

> [!important] Follow every construction case · 对应每种构造情形
> <!-- bilingual-en:start -->
> When objects are generated by a recursive definition, structural induction follows those generation rules. Verify every base object in the definition; then, for every constructor, assume the property for its recursive inputs and prove it for the newly constructed object. This covers every object obtainable by finitely many constructor applications.
> <!-- bilingual-en:end -->
>
> 当对象由递归定义生成时，结构归纳沿生成规则证明性质：先验证定义列出的每一种基础对象；再对每个构造器，假设性质对构造器输入的递归子对象成立，并推出性质对新对象成立。这样才覆盖由有限次构造得到的全部对象。

<!-- bilingual-en:start -->
For a constructor $C$ with recursive inputs $r_1,\ldots,r_k$, where $k\ge1$, the obligation is the following implication. A rule with no recursive inputs is included among the base cases.
<!-- bilingual-en:end -->
若构造器 $C$ 的递归输入为 $r_1,\ldots,r_k$，其中 $k\ge1$，证明义务就是下面的蕴含；没有递归输入的规则归入基例。

$$P(r_1)\land\cdots\land P(r_k)\ \Longrightarrow\ P(C(r_1,\ldots,r_k)).$$

<!-- bilingual-en:start -->
Here $\land$ means “and”; the implication must hold for every permitted choice of inputs and parameters. The hypotheses concern the input objects, not the result being proved. They are available assumptions: a particular argument need not actually use every one if fewer suffice. A base case may itself be a family, such as a numeral for every nonnegative integer; checking only the numerals $0$ and $1$ would not cover that whole family.
<!-- bilingual-en:end -->
这里 $\land$ 表示“并且”；这个蕴含必须对每组允许的输入与参数成立。归纳假设针对输入对象，不是把正在证明的构造结果当作已知。这些假设是**可用**的条件：某个具体论证若只需其中部分，并不必机械地使用全部。基例也可能是一整族，例如每个非负整数对应的数码；只检查数码 $0$ 和 $1$，不能覆盖整族。

## A complete proof for strings
<!-- bilingual-en:end -->
*把字符串例子证明完整*

<!-- bilingual-en:start -->
Suppose strings are recursively defined by taking the empty string as a string and constructing $\langle a,r\rangle$ from a character $a$ and a string $r$. To prove $P$ for all strings, establish $P(\varepsilon)$ and derive $P(\langle a,r\rangle)$ from $P(r)$ for an arbitrary character $a$.
<!-- bilingual-en:end -->
若字符串递归定义为：空串是字符串；字符 $a$ 与字符串 $r$ 可构造 $\langle a,r\rangle$。要证明性质 $P$ 对所有字符串成立，就要证明 $P(\varepsilon)$，并从 $P(r)$ 推出 $P(\langle a,r\rangle)$，其中 $a$ 是任意字符。

<!-- bilingual-en:start -->
To see an actual property propagate, let $|s|$ be the number of characters in $s$, and let $s\cdot t$ mean concatenation: write $s$ followed by $t$. For instance, `ab` followed by `b` gives `abb`, with length $2+1=3$. The recursive definitions are
<!-- bilingual-en:end -->
为了看清具体性质怎样传递，记 $|s|$ 为 $s$ 的字符个数，$s\cdot t$ 为拼接：先写 $s$，再写 $t$。例如 `ab` 后面接 `b` 得到 `abb`，长度为 $2+1=3$。递归定义为

$$
\begin{aligned}
|\varepsilon|&=0,& |\langle a,r\rangle|&=1+|r|,\\
\varepsilon\cdot t&=t,& \langle a,r\rangle\cdot t&=\langle a,r\cdot t\rangle.
\end{aligned}
$$

<!-- bilingual-en:start -->
We prove that $|s\cdot t|=|s|+|t|$ for all finite strings $s,t$. Induct on the construction of $s$, with the predicate $P(s)$ meaning “for every string $t$, the displayed equality holds.” In the base case, $|\varepsilon\cdot t|=|t|=0+|t|=|\varepsilon|+|t|$ for every $t$. For the constructor case, assume $P(r)$ and take any character $a$ and any string $t$. Then
<!-- bilingual-en:end -->
要证所有有限字符串 $s,t$ 都满足 $|s\cdot t|=|s|+|t|$。沿 $s$ 的构造归纳，让谓词 $P(s)$ 表示“对每个字符串 $t$，上述等式成立”。基例中，对每个 $t$ 都有 $|\varepsilon\cdot t|=|t|=0+|t|=|\varepsilon|+|t|$。构造步假设 $P(r)$，任取字符 $a$ 和字符串 $t$，则

$$
\begin{aligned}
|\langle a,r\rangle\cdot t|
&=|\langle a,r\cdot t\rangle|\\
&=1+|r\cdot t|\\
&=1+(|r|+|t|)\\
&=|\langle a,r\rangle|+|t|.
\end{aligned}
$$

<!-- bilingual-en:start -->
The third line uses the induction hypothesis for $r$, which applies to this arbitrary $t$. All the other lines use the definitions or ordinary addition. Thus $P(r)$ implies $P(\langle a,r\rangle)$ for every character. The base and the only constructor have both been covered, so the equality holds for all $s,t$. The empty string is included; there is no need to exclude a zero length.
<!-- bilingual-en:end -->
第三行使用关于 $r$ 的归纳假设，它适用于当前任取的 $t$；其余各行使用定义或通常的加法。于是对每个字符，都从 $P(r)$ 推出了 $P(\langle a,r\rangle)$。基例与唯一的构造器均已覆盖，因此等式对所有 $s,t$ 成立。空串也包括在内，不需要排除长度为零的情况。

## When a constructor has two inputs
<!-- bilingual-en:end -->
*构造器有两个输入时*

<!-- bilingual-en:start -->
Consider a different family $R$ of bracket strings. Its base is $\varepsilon$. From $s,t\in R$, form $[s]t$, meaning a left bracket, the string $s$, a right bracket, then $t$. Only finite constructions belong to $R$. The same rule can produce `[]`, `[[]]` and `[][]` by choosing different inputs.

Let $L(w)$ and $D(w)$ count the left and right brackets in $w$. We prove $L(w)=D(w)$ for every $w\in R$. The empty string has both counts zero. For arbitrary inputs $s,t$, assume $L(s)=D(s)$ and $L(t)=D(t)$. Counting the new pair and the two old strings gives
<!-- bilingual-en:end -->
再看另一族括号串 $R$。基例为 $\varepsilon$；从 $s,t\in R$ 构造 $[s]t$，即依次写左括号、$s$、右括号、$t$。只有有限次构造所得的串属于 $R$。选择不同输入，同一规则可以生成 `[]`、`[[]]` 与 `[][]`。

用 $L(w)$ 和 $D(w)$ 分别计数串 $w$ 的左、右括号。要证每个 $w\in R$ 都满足 $L(w)=D(w)$。空串的两种计数都是零；对任取的输入 $s,t$，假设 $L(s)=D(s)$ 与 $L(t)=D(t)$。数出新增的一对括号及两个旧串，得到

$$
L([s]t)=1+L(s)+L(t)=1+D(s)+D(t)=D([s]t).
$$

<!-- bilingual-en:start -->
Both input hypotheses do real work in this calculation. Proving the case $[s]$ alone, which fixes $t=\varepsilon$, would leave the general second input untreated. Also, the conclusion is only a necessary property of members of $R$: `][` has equal counts but cannot be generated by these rules, since every nonempty generated string begins with `[`. Proving an invariant of the construction does not automatically characterize the entire generated set.
<!-- bilingual-en:end -->
这次计算确实使用了两个输入的假设。若只证明 $[s]$，等于固定 $t=\varepsilon$，仍未处理一般的第二个输入。另外，结论只给出了 $R$ 中成员的必要性质：`][` 的两种括号个数相同，却不能由这些规则生成，因为每个非空生成串都以 `[` 开头。证明构造保持某性质，并不会自动给出生成集合的充要刻画。

## Why finite construction is enough
<!-- bilingual-en:end -->
*有限构造为什么保证覆盖*

<!-- bilingual-en:start -->
Take any object in the stated domain and one finite record of its construction. View that record as a tree: base objects are leaves, and each constructor sits above the records of its recursive inputs. Give a base record height $0$ and a constructor record height one plus the greatest height of its inputs. Each constructor has finitely many recursive inputs here, so every finite record has a nonnegative integer height.

Apply [[普通数学归纳法|ordinary induction]] to the statement “every record of height at most $h$ produces an object satisfying $P$.” At height $0$, the base obligations give $P$. For height at most $h+1$, an object is either a base or comes from inputs whose records have height at most $h$. The induction hypothesis gives $P$ for those inputs, and the relevant constructor implication gives $P$ for the output. Every finite record has some height, so the proof reaches every object in the domain.
<!-- bilingual-en:end -->
任取论域中的对象，并取出它的一份有限构造记录。把记录看成一棵树：基础对象是叶子，每个构造器位于其递归输入的构造记录上方。基础记录的高度为 $0$；构造器记录的高度为输入记录的最大高度再加一。这里每个构造器只有有限个递归输入，所以每份有限记录都有非负整数高度。

对“高度至多为 $h$ 的每份记录，生成的对象都满足 $P$”应用[[普通数学归纳法]]。高度为 $0$ 时，基例证明给出 $P$。考虑高度至多为 $h+1$ 的记录：对象或者本来就是基础对象，或者由高度至多为 $h$ 的输入记录构造而成。归纳假设给出输入的 $P$，再由对应构造器的蕴含得到输出的 $P$。每份有限记录总有某个高度，因此覆盖论域中的每个对象。

<!-- bilingual-en:start -->
Conversely, the nonnegative integers themselves have base $0$ and constructor $n\mapsto n+1$. Structural induction for exactly those rules is ordinary induction. With strings or expressions, following the immediate pieces usually makes the needed hypotheses clearer than assigning a separate numerical size. If an object has several construction records, choose any finite one for this argument; uniqueness is not required for a property already well-defined on the object. Defining a function by different constructions is a separate issue: its proposed values must agree.
<!-- bilingual-en:end -->
反过来，非负整数本身就有基例 $0$ 与构造器 $n\mapsto n+1$；对应这两条规则的结构归纳就是普通归纳。对字符串或表达式，沿直接组成部件展开，通常比另定一个数值大小更清楚地显示需要哪些假设。若一个对象有多份构造记录，论证中任取一份有限记录即可；对已经在对象上定义好的性质，并不要求构造唯一。若要按不同构造来定义一个函数，则是另一项义务：所得函数值必须一致。

## Boundaries
<!-- bilingual-en:end -->
## 边界

<!-- bilingual-en:start -->
- If a constructor has several recursive inputs, the induction hypotheses must cover each of them; proving only one branch is insufficient.
- If the proof uses a “construction” absent from the recursive definition, one must first show that it is generated by the original constructors; otherwise exhaustive coverage has not been established.
<!-- bilingual-en:end -->
- 构造器有多个递归输入时，归纳假设要覆盖每个递归输入；不能只证明其中一个分支。
- 若证明步骤使用了一个未出现在递归定义中的“构造方式”，还需证明它可由原构造器得到；否则覆盖性没有建立。

<!-- bilingual-en:start -->
Here “cover each input” means that the full constructor case is justified for arbitrary permitted inputs, not that every hypothesis must appear syntactically in the calculation. Likewise, deriving an extra operation from the original constructors only makes that operation legitimate; if a proof uses it instead of the original constructors, one must also show that the chosen base and operations reach every object in the claimed domain.

The finite-generation clause cannot be dropped. The set of all finite **and** infinite binary strings contains the empty string and is closed under prefixing a bit. Yet “the string is finite” is true at the base and preserved when prefixing a finite string, while it fails on the extra infinite strings. Closure under the rules alone is therefore insufficient. [[结构递归|Structural recursion]] uses the construction cases to compute results; structural induction uses them to prove claims. Neither name by itself justifies applying the finite proof to cyclic object graphs or infinite constructions.
<!-- bilingual-en:end -->
这里“覆盖每个输入”要求对任意允许输入都证明完整的构造情形，并不要求每条假设都在计算中实际出现。同样，由原构造器导出一种额外操作，只能说明该操作合法；如果证明改用它代替原构造器，还必须说明所选基例与操作能够到达所声明论域中的每个对象。

有限生成这项约定不能删去。例如，“全部有限或无限二进制串”包含空串，而且在前面加一个二进制位后仍留在该集合中。但“字符串有限”在空串上成立，给有限串加一个字符也保持有限，却不适用于额外加入的无限串。因此，仅有规则下的封闭性仍不够。[[结构递归]]用构造情形计算结果，结构归纳用它们证明性质；不能只凭这两个名称，就把有限构造的证明直接套到带环对象图或无限构造上。

> [!question]- Check every constructor · 回忆与应用
> <!-- bilingual-en:start -->
> Arithmetic expressions are recursively generated from nonnegative numerals, a variable, sums $[e+f]$, products $[e*f]$, and unary negatives $-[e]$. Is a structural-induction proof complete if it handles only numerals, the variable, and sums?
>
> **Answer:** No. It must also handle the product and unary-negative constructors. The product branch needs hypotheses for both $e$ and $f$, while the negative branch needs the hypothesis for $e$.
> <!-- bilingual-en:end -->
>
> 算术表达式由非负整数、变量、加法 $[e+f]$、乘法 $[e*f]$ 与一元负号 $-[e]$ 递归生成。一个结构归纳证明只处理非负整数、变量和加法，是否完整？
>
> **答案：** 不完整。还必须处理乘法和一元负号两个构造器；乘法分支要对 $e,f$ 都使用归纳假设，负号分支要对 $e$ 使用归纳假设。

<!-- bilingual-en:start -->
The two product hypotheses and the one negative hypothesis are the available assumptions in the respective cases, as clarified above; a simple particular property might be proved without using all of them. In any case, omitting a constructor's output entirely leaves a gap. A single general argument may cover several cases, but its scope must include every one of them.
<!-- bilingual-en:end -->
乘法的两条假设与负号的一条假设，是各自情形可用的条件，含义如上所述；某个简单的具体性质，可能无需实际使用全部假设也能证明。但完全不处理某种构造器的输出，就留下了缺口。一个统一论证可以同时覆盖多种情形，只是必须明确确实覆盖了它们。
