# Spanning trees
<!-- bilingual-en:end -->
*生成树*

<!-- bilingual-en:start -->
A **spanning tree** keeps every vertex of a given network and selects original edges that connect those vertices without forming a cycle. “Spanning” says that no vertex is left behind; “tree” says that the selected network is connected and acyclic. The definition concerns a choice of connections, not a choice of which vertices to keep.
<!-- bilingual-en:end -->
**生成树**保留给定网络的每个顶点，并从原有边中选出一些，使这些顶点连通而不形成环。“生成”表示不遗漏顶点，“树”表示所选网络连通且无环。这个定义是在选择连接方式，而不是挑选要保留哪些顶点。

> [!example] Four vertices, three selected connections · 四个顶点，三条选中连接
> <!-- bilingual-en:start -->
> Let the vertices be $a,b,c,d$ and the edges be $ab,bc,ca,cd$, where $ab$ denotes an undirected edge joining $a$ and $b$. The first three edges form a triangle, and $cd$ attaches $d$. Selecting $ab,bc,cd$ gives the path $a-b-c-d$, a spanning tree. Keeping only the vertices $a,b,c$ and edges $ab,bc$ gives a tree, but it does not span the original graph because $d$ is absent. Keeping all four original edges spans all vertices but retains the triangle, so it is not a tree.
> <!-- bilingual-en:end -->
>
> 顶点为 $a,b,c,d$，边为 $ab,bc,ca,cd$，其中 $ab$ 表示连接 $a,b$ 的无向边。前三条边构成三角形，$cd$ 把 $d$ 接上。选择 $ab,bc,cd$，得到路径 $a-b-c-d$，它就是生成树。若只保留顶点 $a,b,c$ 与边 $ab,bc$，虽然也是树，却因遗漏 $d$ 而不是原图的生成树。若保留原来的四条边，虽然覆盖全部顶点，却保留了三角形，因此不是树。

## Retain the vertex set, choose the edge set
<!-- bilingual-en:end -->
*顶点集不变，边集可以选择*

<!-- bilingual-en:start -->
Write $G=(V,E)$ for a finite [[图类型的建模边界|undirected graph]] with nonempty vertex set $V$ and edge set $E$. A **spanning subgraph** has the form $T=(V,F)$, where $F\subseteq E$: its vertices are exactly those of $G$, and every selected edge already belongs to $G$. It need not retain all the edges between those vertices. Requiring all such edges would simply recover $G$ itself.
<!-- bilingual-en:end -->
设 $G=(V,E)$ 是有限[[图类型的建模边界|无向图]]，$V$ 为非空顶点集，$E$ 为边集。**生成子图**写成 $T=(V,F)$，其中 $F\subseteq E$：顶点恰好是 $G$ 的全部顶点，每条选中边也必须是 $G$ 原有的边。它不必保留这些顶点之间的全部原边；若要求全部保留，就只是原图 $G$ 本身。

> [!definition] Spanning tree · 生成树
> <!-- bilingual-en:start -->
> A **spanning tree of $G$** is a spanning subgraph $T=(V,F)$ that is an [[无向树|undirected tree]]: it is connected and contains no cycle. Authors sometimes call the edge set $F$ itself a spanning tree, with the fixed vertex set $V$ understood.
> <!-- bilingual-en:end -->
>
> $G$ 的**生成树**是同时构成[[无向树]]的生成子图 $T=(V,F)$，即它连通且不含环。有时直接把边集 $F$ 称作生成树，此时顶点集 $V$ 已由语境固定。

<!-- bilingual-en:start -->
Connectedness means that every pair of retained vertices can be joined by a [[游走路径与环|path]] using selected edges. Acyclicity excludes a positive-length closed route with distinct edges and with no repeated vertex except its starting/ending vertex. If the graph model permits distinguishable parallel edges, their identities remain part of the choice: either of two parallel edges can connect the same two vertices, but selecting both creates a two-edge cycle. A self-loop is a one-edge cycle and cannot be selected in a tree.
<!-- bilingual-en:end -->
连通表示任意两个保留的顶点，都能沿选中边组成的[[游走路径与环|路径]]连接。无环排除了正长度、边不重复、除首尾外顶点也不重复的闭合路线。若图模型允许可区分的平行边，选边时仍要区分它们的身份：两条平行边任选一条，都能连接相同的两个顶点，但同时选择两条就构成二环。自环是一环，也不能被选入树。

<!-- bilingual-en:start -->
## Recognize the object without adding an optimization objective
<!-- bilingual-en:end -->
*识别生成树，不额外加入最优化目标*

<!-- bilingual-en:start -->
A spanning tree on $n=|V|$ vertices has $n-1$ edges by the [[Forest 的边数公式|forest edge-count formula]], applied to its single connected component. That count is a consequence, not a replacement for the definition. A triangle together with an isolated fourth vertex has three edges and four vertices, but is disconnected and contains a cycle. Counting alone would misclassify it.
<!-- bilingual-en:end -->
含 $n=|V|$ 个顶点的生成树，由[[Forest 的边数公式|森林边数公式]]在一个连通分量的情形下可知，恰有 $n-1$ 条边。这个数量是定义推出的结论，不能单独代替定义。一个三角形再加一个孤立的第四顶点，也有四个顶点、三条边，却既不连通又含环；只数边会误判。

<!-- bilingual-en:start -->
The [[生成树的存在条件|spanning-tree existence theorem]] states that a finite nonempty undirected graph has a spanning tree exactly when it is connected. If the original graph is disconnected, selecting original edges cannot connect its separate components. One may instead select a [[森林|spanning forest]], meaning one spanning tree in each original connected component, with every original vertex retained.
<!-- bilingual-en:end -->
[[生成树的存在条件|生成树存在定理]]说明，有限非空无向图恰在连通时存在生成树。如果原图不连通，只选择原有边不可能把不同原分量连接起来。这时可以选择[[森林|生成森林]]：在每个原连通分量内各选一棵生成树，仍保留原图全部顶点。

<!-- bilingual-en:start -->
A one-vertex graph has the empty selected edge set as its spanning tree, even if the host graph also has loops. The graph with no vertices has no spanning tree under the adopted nonempty-tree convention. No root, edge weights, or preferred drawing is required. Once finite real edge weights are supplied, asking for the smallest **total** selected weight is the additional [[最小生成树的定义与唯一性|minimum spanning tree]] problem. Different spanning trees can have different totals, or can tie.
<!-- bilingual-en:end -->
单顶点图以空的选中边集构成生成树，即使原图另有自环也一样。按本卡采用的非空树约定，没有顶点的空图没有生成树。定义不要求根、边权或某种画法。给边赋予有限实权之后，要求选中边的**总权重**最小，才是额外的[[最小生成树的定义与唯一性|最小生成树]]问题；不同生成树的总权重可能不同，也可能并列。

<!-- bilingual-en:start -->
The word “undirected” is essential here. A directed graph has additional questions about which arrows can be followed from a chosen root. Those directional reachability requirements are not imposed by this definition; see the [[Tree 与 DAG 的区别|distinction between trees and directed acyclic graphs]] before moving between the models.
<!-- bilingual-en:end -->
这里的“无向”很重要。有向图还要讨论从指定根出发能沿哪些箭头到达其他顶点；这些带方向的可达性条件不属于本定义。在两种模型之间转换时，应先区分[[Tree 与 DAG 的区别|树与有向无环图]]。
