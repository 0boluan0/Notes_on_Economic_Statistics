# Recognizing a finite tree
<!-- bilingual-en:end -->

*有限树的等价刻画*

<!-- bilingual-en:start -->
A tree connects its vertices without keeping a redundant route around a cycle. You can recognize this structure in several ways: check for a unique route between each pair, check what happens when an edge is removed, or check what happens when a missing edge is added. These tests describe the same structure, but each asks a different operational question.
<!-- bilingual-en:end -->

树把顶点连在一起，却不保留绕环而行的冗余路线。可以从不同角度识别它：任意两点间的路线是否唯一，删去一条边会怎样，或者补上一条缺失边会怎样。这些检验描述同一种结构，却回答不同的操作问题。

<!-- bilingual-en:start -->
Work with a finite [[图类型的建模边界|simple undirected graph]] $G=(V,E)$ with **at least one vertex**. Simple means that there are no self-loops or parallel edges. A [[游走路径与环|path]] does not repeat vertices; a cycle returns to its starting vertex without other vertex or edge repetition. The graph is [[无向图连通分量|connected]] if every two vertices can be joined by a path. By definition, an [[无向树|undirected tree]] is nonempty, connected and acyclic.
<!-- bilingual-en:end -->

考虑有限[[图类型的建模边界|简单无向图]] $G=(V,E)$，并明确要求**至少有一个顶点**。简单图没有自环或平行边。[[游走路径与环|路径]]不重复顶点；环返回起点，除此之外不重复顶点或边。任意两顶点间都有路径时，图是[[无向图连通分量|连通的]]。按定义，[[无向树]]非空、连通且无环。

> [!important] Four equivalent tests · 四种等价检验
> <!-- bilingual-en:start -->
> Under these assumptions, each of the following conditions says that $G$ is a tree:
>
> - **Connected and acyclic.**
> - **Unique paths:** every two distinct vertices have exactly one path between them.
> - **Edge-minimal connected:** $G$ is connected, and deleting any edge disconnects it.
> - **Edge-maximal acyclic:** $G$ is acyclic, and adding any missing edge between distinct vertices creates a cycle.
> <!-- bilingual-en:end -->
>
> 在上述前提下，以下每一项都等价于“$G$ 是树”：
>
> - **连通且无环。**
> - **路径唯一：**任意两个不同顶点之间恰有一条路径。
> - **删边意义下的极小连通：**图连通，而且删去任意一条边都会使它不连通。
> - **加边意义下的极大无环：**图无环，而且在两个不同顶点间加入任意一条原本缺失的边，都会产生环。

<!-- bilingual-en:start -->
For a vertex paired with itself, the only path is its length-zero path, so including equal endpoints does not change the unique-path statement. The nonempty assumption keeps the empty graph from satisfying some of the tests vacuously while being excluded by the tree definition. A one-vertex graph with no edges is a tree: there is no edge to delete and no allowable missing simple edge to add.
<!-- bilingual-en:end -->

若两端取同一顶点，唯一的路径就是零长度路径，因此把相同端点也包括进来不会改变“路径唯一”的说法。非空前提避免空图在某些条件上因无对象可检而自动成立，却又被树定义排除。单顶点无边图是树：它没有边可删，也没有可补的简单边。

## Why uniqueness combines connection and no cycles
<!-- bilingual-en:end -->

*为什么路径唯一同时表达连通与无环*

<!-- bilingual-en:start -->
In a tree, connectedness gives at least one path between two vertices. Suppose there were two different paths. Follow their common initial segment to the point where they separate; then follow one path until it first returns to the other. Such a return exists because both paths end at the same vertex. The two segments between separation and return have no interior vertex in common, so together they form a cycle. This contradicts acyclicity. Thus the path is unique.
<!-- bilingual-en:end -->

树的连通性先保证两点之间至少有一条路径。若存在两条不同路径，就沿共同的开头走到分叉处，再沿其中一条走到首次重新碰到另一条路径的位置。两条路径终点相同，所以必然会重会。分叉到重会之间的两段没有共同的内部顶点，合起来构成环，与无环性矛盾。因此路径唯一。

<!-- bilingual-en:start -->
Conversely, unique paths give connectedness. If a cycle existed, the endpoints of any one of its edges could be joined either by that edge or by the rest of the cycle. These would be two different paths. Hence the graph is acyclic as well, and is a tree.
<!-- bilingual-en:end -->

反过来，路径唯一首先保证存在路径，因而保证连通。若有环，环上任意一条边的两个端点既可经该边连接，也可沿环的其余部分连接，得到两条不同路径。因此图也无环，故是树。

<!-- bilingual-en:start -->
## Removing an edge tests whether there is a detour
<!-- bilingual-en:end -->

*删边检验是否存在绕行路线*

<!-- bilingual-en:start -->
An edge is a **bridge**, or cut edge, if deleting it increases the number of connected components. In a connected graph this means that deletion disconnects the graph. In a tree, the unique path between the endpoints of an edge is the edge itself. Removing it therefore separates its endpoints: every tree edge is a bridge.
<!-- bilingual-en:end -->

若删去一条边会增加连通分量数，就称它为**桥边**或**割边**。对连通图，这等价于删边后不再连通。在树中，一条边的两端之间的唯一路径就是该边本身；删去它便使两端失去连接。因此树的每条边都是桥边。

<!-- bilingual-en:start -->
Conversely, assume the graph is connected and every edge is a bridge. An edge on a cycle could be removed without disconnecting its endpoints, because the rest of the cycle provides a detour. Any route that used the removed edge can take that detour instead; [[游走去环得到路径|removing repeated portions of the resulting walk]] gives a path if needed. Thus an edge on a cycle is not a bridge. The assumption rules out every cycle, proving that the graph is a tree. This also answers why a connected graph whose every edge is a bridge cannot contain a cycle.
<!-- bilingual-en:end -->

反过来，设图连通且每条边都是桥边。若某条边处在环上，删去后仍能沿环的其余部分绕行，连接它的两端。原来用到该边的任何路线都可以改走绕路；需要时再[[游走去环得到路径|删去游走中的重复部分]]得到路径。因此环上的边不是桥边。前提便排除了全部环，图必为树。这也解释了为什么“连通且每条边都是桥边”不可能与含环同时成立。

<!-- bilingual-en:start -->
## Adding an edge tests whether connection is already complete
<!-- bilingual-en:end -->

*加边检验连通是否已经充分*

<!-- bilingual-en:start -->
In a tree, two nonadjacent vertices already have a unique path between them. Adding the missing edge closes that path into a cycle. Conversely, suppose the graph is acyclic and every missing edge would create a cycle. If it were disconnected, choose vertices in two different components. Adding an edge between them cannot create a cycle: a cycle using the new edge would require a pre-existing path between those components. This contradicts the assumption. The graph must therefore be connected, and hence a tree.
<!-- bilingual-en:end -->

树中两个不相邻顶点之间已经有唯一路径；补上缺失边，就把该路径闭合成环。反过来，设图无环，而且加入任意缺失边都会成环。若图不连通，就从两个不同分量各取一个顶点。把它们连起来不可能成环：一个使用新边的环还需要原来就有一条跨越这两个分量的路径。这与前提矛盾。因此图必连通，也就是树。

> [!example] A path on three vertices · 三顶点路径
> <!-- bilingual-en:start -->
> In $a-b-c$, the only path from $a$ to $c$ is $a,b,c$. Removing either edge disconnects the graph. The only missing simple edge is $\{a,c\}$, and adding it creates a triangle. Thus the same small graph satisfies all four tests. The triangle itself is connected but fails the other tests: it has two routes between its vertices, its edges can be removed without disconnecting it, and it is already cyclic.
> <!-- bilingual-en:end -->
>
> 在 $a-b-c$ 中，从 $a$ 到 $c$ 的唯一路径是 $a,b,c$；删去哪条边都会断开。唯一缺失的简单边是 $\{a,c\}$，加入后成为三角形。因此同一张小图满足四种检验。三角形本身虽连通，却不满足其他条件：两点间有不同路线，删去一条边仍连通，而且它本来就有环。

<!-- bilingual-en:start -->
“Minimal” and “maximal” here concern deleting or adding edges while keeping the vertex set fixed. The last test allows **every** missing simple edge on that vertex set. A maximal forest chosen only from the edges of a disconnected host graph need not be a tree: the host may offer no edge between its components. That relative notion is explained in [[森林|spanning forests]]. The numerical $n-1$ test needs an additional connectedness or acyclicity assumption, as shown by the separate [[Forest 的边数公式|forest edge-count theorem]].
<!-- bilingual-en:end -->

这里的“极小”和“极大”针对固定顶点集上的删边、加边操作。最后一项允许加入该顶点集上**任何**缺失的简单边。若只准从某张不连通原图已有的边中选择，选出的极大森林未必是树，因为原图可能根本没有跨分量的边；这种相对概念见[[森林|生成森林]]。数值上的 $n-1$ 判据还需另配连通或无环条件，具体见 [[Forest 的边数公式|森林边数定理]]。
