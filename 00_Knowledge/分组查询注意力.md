# 分组查询注意力让每组查询头共享一组键和值

<!-- bilingual-en:start -->
*Grouped-query attention lets each group of query heads share one set of keys and values*
<!-- bilingual-en:end -->

分组查询注意力（grouped-query attention，GQA）把 query 头分成若干组，每组内的 query 头共享一个 key 头和一个 value 头。它把“发起多少次独立读取”和“准备多少组 K/V”分开：query 头仍分别计算注意力，K/V 则按组提供。

<!-- bilingual-en:start -->
Grouped-query attention (GQA) divides query heads into groups, with one key head and one value head shared within each group. It separates the number of independent attention reads from the number of K/V sets: queries compute attention separately, while K/V is supplied by group.
<!-- bilingual-en:end -->

## 用分组映射写出计算

<!-- bilingual-en:start -->
*Expressing attention through a group mapping*
<!-- bilingual-en:end -->

设有 $H_q$ 个 query 头和 $G$ 组 K/V，$g(h)\in\{1,\ldots,G\}$ 表示第 $h$ 个 query 头所在组。沿用[[多头注意力]]中投影后的张量形状，每个 query 头宽度为 $d_k$，每组 key/value 宽度为 $d_k,d_v$，则

<!-- bilingual-en:start -->
Let there be $H_q$ query heads and $G$ K/V groups, with $g(h)\in\{1,\ldots,G\}$ identifying the group of query head $h$. Using the projected tensor shapes from [[多头注意力|multi-head attention]], each query has width $d_k$ and each group has key/value widths $d_k,d_v$:
<!-- bilingual-en:end -->

$$
\mathrm{head}_h=
\operatorname{Attention}(Q_h,K_{g(h)},V_{g(h)}),
\qquad h=1,\ldots,H_q.
$$

Attention 按[[缩放点积注意力]]计算，各头输出仍拼接并作输出投影。常见等分配置要求 $G$ 整除 $H_q$，每组包含 $H_q/G$ 个 query 头。增加或减少 $G$，不等于改变 $H_q$ 或单头宽度。

<!-- bilingual-en:start -->
Attention uses [[缩放点积注意力|scaled dot-product attention]], with the head outputs concatenated and projected. A common equal-sized grouping requires $G$ to divide $H_q$, giving $H_q/G$ query heads per group. Changing $G$ does not itself change $H_q$ or the per-head width.
<!-- bilingual-en:end -->

## 四个查询头的三个配置

<!-- bilingual-en:start -->
*Three configurations with four query heads*
<!-- bilingual-en:end -->

固定 $H_q=4$，下面用组编号直接表示每个 query 读取哪一组 K/V。

<!-- bilingual-en:start -->
Fix $H_q=4$. The group numbers below identify the K/V set read by each query.
<!-- bilingual-en:end -->

| 配置 | query 1 | query 2 | query 3 | query 4 | K/V 组数 |
|---|---:|---:|---:|---:|---:|
| 标准 MHA | 1 | 2 | 3 | 4 | 4 |
| GQA，$G=2$ | 1 | 1 | 2 | 2 | 2 |
| MQA | 1 | 1 | 1 | 1 | 1 |

<!-- bilingual-en:start -->
The columns list query heads 1–4 and the final K/V group count. Standard MHA assigns a separate group to every query; GQA with $G=2$ shares within pairs; MQA shares one group across all four queries.
<!-- bilingual-en:end -->

因此，GQA-$1$ 就是[[多查询注意力|MQA]]；当 $G=H_q$ 且每组只有一个 query 头时，它回到标准 MHA。日常强调 GQA 与两端的区别时，通常指 $1<G<H_q$。表中始终有四个 query 头，不能把中间配置解释为“只剩两个注意力读出”。

<!-- bilingual-en:start -->
Thus GQA-$1$ is [[多查询注意力|MQA]], while $G=H_q$ with one query per group recovers standard MHA. When GQA is contrasted with those endpoints, it usually means $1<G<H_q$. Every row still contains four query heads; the middle configuration does not reduce attention to two readouts.
<!-- bilingual-en:end -->

GQA 的分组是模型结构的一部分。[[KV共享非等价改写|从已有 MHA 合并投影一般改变模型函数]]，分组数量的质量与速度折中需在具体模型和实现上检验。

<!-- bilingual-en:start -->
Grouping is part of the model architecture. [[KV共享非等价改写|Pooling projections from an existing MHA model generally changes its function]], so the quality and speed tradeoff must be evaluated for the particular model and implementation.
<!-- bilingual-en:end -->
