# A single cyclic permutation has a period equal to its cycle length
<!-- bilingual-en:end -->
*单个循环置换的周期等于该循环的长度*

<!-- bilingual-en:start -->
Let a [[置换矩阵|permutation matrix]] $P$ move $r\ge2$ positions in one cycle and fix every other position. For a positive integer $k$, $P^k=I$ exactly when $r$ divides $k$.
<!-- bilingual-en:end -->

设[[置换矩阵]] $P$ 将 $r\ge2$ 个位置组成一个循环，其余位置保持不动。对正整数 $k$，$P^k=I$ 当且仅当 $r$ 整除 $k$。

<!-- bilingual-en:start -->
After $k$ applications, each position has advanced by $k$ steps around the cycle. All positions return precisely after a whole number of turns. Fixed positions add no further requirement.
<!-- bilingual-en:end -->

作用 $k$ 次后，每个循环位置前进 $k$ 步；恰好走完整数圈才全部恢复。固定的位置不增加限制。

$$\nP=\begin{pmatrix}0&0&1\\1&0&0\\0&1&0\end{pmatrix},\qquad P^3=I_3,\quad P^4=P\ne I_3.\n$$

<!-- bilingual-en:start -->
Embedding this $P$ as $\operatorname{diag}(P,1)$ gives a $4\times4$ permutation whose period is still three. Matrix size alone does not determine the period. The stated criterion concerns one nontrivial cycle; for several cycles each cycle must return.
<!-- bilingual-en:end -->

将此 $P$ 嵌入 $\operatorname{diag}(P,1)$，得到的四阶置换仍以三为周期。矩阵阶数本身不决定周期。上面的判据针对单个非平凡循环；若含多个循环，各循环都须恢复。
