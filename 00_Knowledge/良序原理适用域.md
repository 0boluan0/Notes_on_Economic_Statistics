# 良序原理只保证非空非负整数集合存在最小元
<!-- bilingual-en:start -->
*The Well Ordering Principle guarantees a least element only for a nonempty set of nonnegative integers*
<!-- bilingual-en:end -->

> [!summary] 原子原理
> 良序原理说：每个非空的非负整数集合都有最小元素。应用时必须逐项确认三个条件——集合非空、元素都是非负整数、所需的是最小元——然后才能选取“最小的坏对象”或“最早失败的位置”。
> <!-- bilingual-en:start -->
> The Well Ordering Principle states that every nonempty set of nonnegative integers has a least element. Before invoking it, check all three conditions: the set is nonempty, its elements are nonnegative integers, and the argument needs a least element. Only then may one choose a “smallest bad object” or “first failure.”
> <!-- bilingual-en:end -->

例如，若某个关于非负整数的命题存在反例，就可以把所有反例的下标组成集合 $C\subseteq\mathbb N$。在 $C\ne\varnothing$ 的反设下，良序原理给出最小反例 $c$。
<!-- bilingual-en:start -->
For example, if a proposition about nonnegative integers has a counterexample, collect all counterexample indices in $C\subseteq\mathbb N$. Under the supposition $C\ne\varnothing$, the Well Ordering Principle supplies a least counterexample $c$.
<!-- bilingual-en:end -->

## 边界
<!-- bilingual-en:start -->
*Boundary*
<!-- bilingual-en:end -->

- 非空是必要条件；空集没有最小元。
- 不能把结论原样套到任意实数子集。例如 $\{1/n:n\ge1\}$ 非空且有下界，却没有最小元素。
<!-- bilingual-en:start -->

**1.** Nonemptiness is necessary; the empty set has no least element.<br>
**2.** The conclusion cannot be transferred unchanged to arbitrary subsets of the reals. For example, $\{1/n:n\ge1\}$ is nonempty and bounded below but has no least element.<br>
<!-- bilingual-en:end -->

> [!question]- 回忆与应用
> 集合 $\{5,7,9,\ldots\}$ 能否直接应用良序原理？集合 $\{-1,-2,-3,\ldots\}$ 呢？
>
> **答案：** 前者可以：它非空且由非负整数构成，最小元是 $5$。后者不满足非负整数条件，而且没有最小元。
> <!-- bilingual-en:start -->
> Can the Well Ordering Principle be applied directly to $\{5,7,9,\ldots\}$? What about $\{-1,-2,-3,\ldots\}$?
>
> **Answer:** Yes for the first set: it is nonempty, consists of nonnegative integers, and has least element $5$. The second set is outside the stated domain and has no least element.
> <!-- bilingual-en:end -->
