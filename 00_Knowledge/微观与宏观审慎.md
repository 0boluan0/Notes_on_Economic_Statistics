# 单家机构稳健不推出体系稳定且宏观审慎关注共同敞口互联与火售外部性
<!-- bilingual-en:start -->
*Sound individual institutions do not guarantee system stability; macroprudential policy addresses common exposures, interconnections, and fire-sale externalities*
<!-- bilingual-en:end -->

> [!summary] 原子系统边界
> 微观审慎主要检查单家机构能否承受自身风险；宏观审慎检查很多机构同时持有同类资产、依赖同类短期融资、彼此互联并在压力中同步出售时产生的系统外部性。每家单独看似合规，合并后仍可能脆弱。
> <!-- bilingual-en:start -->
> Microprudential analysis mainly asks whether each institution can withstand its own risks. Macroprudential analysis asks how common asset exposures, shared short-term funding, interconnections, and simultaneous sales create system-wide externalities. Every firm can appear compliant in isolation while the combined system remains fragile.
> <!-- bilingual-en:end -->

例：十家银行各自持有可出售资产缓冲，单家测试都假设可以按当前价格出售；若十家同时遇到流出并卖同一资产，价格下跌会使所有缓冲缩水。个体最优的“先卖”可能形成集体不稳定，因此需要系统压力测试、逆周期缓冲或针对互联与流动性错配的工具。共同敞口只是脆弱性，不是危机的充分条件：冲击大小、杠杆、融资期限、缓冲、网络结构、市场替代性和政策反应共同决定是否真正失稳。

## 易错边界

- 宏观审慎不等于“监管更严”这一句口号；它针对跨机构反馈和时间维度的顺周期性。
- 相关性、共同资产或互联本身不必然造成系统危机；必须再识别冲击、放大机制与缓冲是否同时成立。
- 系统稳定也不意味着任何单家机构都不得失败；关键是关键服务和损失传播可被控制。
- 最后贷款人是危机工具之一，不能替代事前的系统性风险约束。

> [!question]- 自检
> 为什么每家银行都持有同一种“高流动性”资产，反而可能形成系统风险？
>
> **答案：** 同时出售会压低共同资产价格，使所有机构的缓冲和资本一起恶化，产生单家决策未计入的外部性。
