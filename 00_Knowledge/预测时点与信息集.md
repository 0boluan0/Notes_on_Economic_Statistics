# 预测起点、期限与信息集共同限定可执行的历史预测
<!-- bilingual-en:start -->
*Forecast origin, horizon, and information set jointly define an executable historical forecast*
<!-- bilingual-en:end -->

> [!summary] 原子信息边界
> 在 forecast origin $t$ 生成对 target time $t+h$ 的 $h$ 步预测时，只能使用该起点真实可得的信息集 $\mathcal F_t$。历史回测必须重放当时的发布时间、数据版本、预处理与未来 predictor 假设；用后来修订的数据或事后实现的 predictor 会把 ex-post 分析伪装成 ex-ante 预测。
> <!-- bilingual-en:start -->
> An $h$-step forecast formed at origin $t$ for target time $t+h$ may use only the information set genuinely available at that origin. Historical evaluation must replay release lags, data vintages, preprocessing, and assumptions about future predictors.
> <!-- bilingual-en:end -->

origin、target time 与 horizon 是三个不同字段。同一个 target time 可以由多个 origin 预测，对应不同 horizon；同一个 origin 也可产生一条多期限路径。若只记录“预测 2027 年 GDP”，却不记录预测是在何时形成的，就无法判断模型当时知道什么，也无法公平比较不同预测。

宏观数据尤其要保留 vintage。今天下载的历史 GDP 常包含后来修订，未必等于当时决策者看到的版本。缺失值填补、异常处理、变换、特征选择与调参也都只能在每个训练窗口内拟合；先看完整历史再回填，会让未来信息进入过去。

未来 predictor 要分三类：日历或已正式排定的活动可以在 origin 时已知；天气、价格或收入等未知路径需要另行预测；人为给定的路径只能产生明确标注的 conditional/scenario forecast。使用后来实现的 predictor 可以研究模型在该路径下的行为，但不能称为当时可执行的 genuine forecast。

> [!question]- 自检
> 用 2028 年下载的最终修订 GDP 数据，回测一个声称在 2025 年发布的预测，最大问题是什么？
>
> **答案：** 训练和输入包含了 2025 年当时不存在的数据 vintage；这没有重建原 forecast origin 的信息集。

## 来源与核验

- [Hyndman & Athanasopoulos, FPP3 §5.10](https://otexts.com/fpp3/tscv.html)：核对每个 rolling origin 只能使用此前观测。
- [FPP3 §7.6](https://otexts.com/fpp3/forecasting-regression.html) 与 [§10.3](https://otexts.com/fpp3/forecasting.html)：核对 ex-ante/ex-post、未知未来 predictor 与条件预测区间。
- Croushore & Stark, [Does Data Vintage Matter for Forecasting?](https://www.philadelphiafed.org/the-economy/macroeconomics/does-data-vintage-matter-for-forecasting)：核对实时宏观数据 vintage 与修订可改变预测结果。
