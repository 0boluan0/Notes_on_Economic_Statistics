# 社会福利函数以明确的社会评价规则将个人效用组合映射为福利排序指标
<!-- bilingual-en:start -->
*A social welfare function maps individual utility profiles to an index representing an explicit social evaluation*
<!-- bilingual-en:end -->

社会福利函数在本卡指 Bergson–Samuelson 型函数 $W(u_1,\ldots,u_n)$：它以每个人的效用为输入，用一个实数指标表示所采用的社会评价。$W(u)>W(v)$ 表示按该规则社会更偏好效用组合 $u$；这项排序包含价值判断，不是个人效用数据自动给出的事实结论。
<!-- bilingual-en:start -->
Here a social welfare function means a Bergson–Samuelson function $W(u_1,\ldots,u_n)$. It takes individual utilities as inputs and represents the chosen social evaluation by a real-valued index. The inequality $W(u)>W(v)$ means that this rule socially prefers profile $u$. The ranking incorporates value judgements; it is not determined automatically by individual utility data.
<!-- bilingual-en:end -->

一般函数并不限于线性加权和。例如，给定可解释的效用刻度，可采用非负权重的加权和 $W(u)=\sum_i\omega_i u_i$、$\omega_i\ge0$，也可采用只按最低效用评价的 $W(u)=\min_i u_i$。二者都是具体规则，不是“社会福利函数”一词本身的唯一含义。谁被纳入、怎样看待分配以及需要怎样的跨人效用比较，必须说明。
<!-- bilingual-en:start -->
The general function need not be a linear weighted sum. Given interpretable utility scales, examples include $W(u)=\sum_i\omega_i u_i$ with $\omega_i\ge0$, and $W(u)=\min_i u_i$, which evaluates a profile by its lowest utility. These are particular rules, not alternative definitions of the general concept. State whose welfare counts, how distribution is evaluated, and what interpersonal utility comparisons the rule requires.
<!-- bilingual-en:end -->

效用刻度与评价公式须配套指定；只保留个人偏好排序的改标，不保证原封不动的加总公式保持社会排序，见[[社会福利的效用尺度]]。
<!-- bilingual-en:start -->
Specify utility scales together with the evaluation formula. A rescaling that preserves personal preferences need not preserve the social ranking from an unchanged sum; see [[社会福利的效用尺度|utility scales in social welfare]].
<!-- bilingual-en:end -->

函数也不自动保证尊重所有 [[Pareto改进与有效|Pareto 改进]]。若要求每次“无人受损、至少一人获益”都使 $W$ 严格上升，就需要相应的严格递增要求；$\min_i u_i$ 对不改变最低效用的改善可能无差异。选用哪种要求属于规则设定。
<!-- bilingual-en:start -->
A welfare function does not automatically rank every [[Pareto改进与有效|Pareto improvement]] strictly higher. That requirement needs the corresponding strict monotonicity condition. The function $\min_i u_i$ can remain unchanged when an improvement leaves the lowest utility unchanged. Which requirement to impose is part of specifying the rule.
<!-- bilingual-en:end -->

两人时，$W(u_1,u_2)=\bar W$ 的等值线称为社会无差异曲线；它表示评价相同，而[[效用可能集]]表示可行性。把二者合起来寻找可行方案中的最高评价，才形成社会福利最大化问题。光滑内点的斜率条件见[[社会福利最优的切点条件]]。
<!-- bilingual-en:start -->
With two people, the level set $W(u_1,u_2)=\bar W$ is an isowelfare curve: it represents equal social evaluation, whereas the [[效用可能集|utility possibility set]] represents feasibility. Maximising welfare combines these two objects to find the highest-valued feasible profile. See [[社会福利最优的切点条件|the tangency condition for a welfare optimum]] for the smooth interior case.
<!-- bilingual-en:end -->
