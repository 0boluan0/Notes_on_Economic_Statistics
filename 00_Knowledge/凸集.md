# 凸集包含其中任意两点之间的整条线段

<!-- bilingual-en:start -->
*A convex set contains the entire segment between each pair of its points*
<!-- bilingual-en:end -->

集合 $U\subseteq\mathbb R^n$ 凸，是指对任意 $x,y\in U$ 和 $t\in[0,1]$ 都有 $tx+(1-t)y\in U$。两个权重非负且和为一；$t=0,1$ 是端点，$t=1/2$ 是中点。

半空间 $c^Tx\le b$ 凸，因为混合点仍满足同一线性不等式。圆盘凸，圆周不凸：相对两点的中点离开圆周。空集也凸。凸性只谈输入集合；[[凹凸性]]另外比较函数在混合输入处的输出。

<!-- bilingual-en:start -->
A convex set contains every convex combination of each pair of its points. Half-spaces satisfy this by linearity. A disk is convex but its circumference is not; the empty set is convex as well. This is a property of input sets, distinct from the output comparisons defining [[凹凸性|function curvature]].
<!-- bilingual-en:end -->
