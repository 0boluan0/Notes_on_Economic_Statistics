# Counting by bijection
<!-- bilingual-en:end -->

*双射计数*

<!-- bilingual-en:start -->
A selection of two numbers from $\{1,2,3\}$ can be recorded as a three-bit string: write $1$ in a selected position and $0$ elsewhere. The complete correspondence is
<!-- bilingual-en:end -->

从 $\{1,2,3\}$ 中选两个数，可以用三位二进制串记录：被选中的位置写 $1$，其余写 $0$。全部对应关系是

$$
\{1,2\}\longleftrightarrow110,\qquad
\{1,3\}\longleftrightarrow101,\qquad
\{2,3\}\longleftrightarrow011.
$$

<!-- bilingual-en:start -->
You can recover the selection by reading the positions containing $1$. Thus each selection matches exactly one string, and each string with exactly two ones matches exactly one selection. The two collections have the same number of objects. **Counting by bijection** uses such a reversible pairing to transfer a count from one collection to another.
<!-- bilingual-en:end -->

反过来，只要读出哪些位置是 $1$，就能恢复选择。因此每个选择恰好配一个串，每个恰有两个 $1$ 的串也恰好配一个选择，两类对象一样多。**双射计数**就是用这种可逆配对，把一类对象的数量转移给另一类。

<!-- bilingual-en:start -->
Let $A$ and $B$ be finite sets of [[计数对象|counting objects]]. A function $f:A\to B$ assigns exactly one target $f(a)$ in $B$ to each source object $a$ in $A$. It is a **bijection** if every target object is assigned to by exactly one source object. With $|A|$ and $|B|$ denoting the two counts,
<!-- bilingual-en:end -->

令 $A,B$ 是两个有限的[[计数对象]]集合。函数 $f:A\to B$ 给每个源对象 $a\in A$ 指定唯一的目标对象 $f(a)\in B$。如果每个目标对象也恰好来自一个源对象，这个函数就是**双射**。用 $|A|,|B|$ 表示两个集合的大小，就有

$$
|A|=|B|.
$$

<!-- bilingual-en:start -->
The objects need not look alike. A subset and a bit string have different forms, but the encoding preserves exactly enough information to recover either from the other. Once one collection is easy to count, its count solves the other problem too.
<!-- bilingual-en:end -->

对象不必长得相似。子集和二进制串的外形不同，但编码保留的信息足以相互恢复。只要其中一类容易数，另一类的数量就随之确定。

## Checking both directions
<!-- bilingual-en:end -->

## 怎样证明没有重计或漏计

<!-- bilingual-en:start -->
An **injective** map sends distinct source objects to distinct targets, so it does not merge two objects. A **surjective** map reaches every target, so it leaves no target out. A bijection has both properties. In the opening example, recording all the selected positions prevents merging, and reading the ones in any allowed string produces a valid two-element subset, proving coverage.

One convenient proof is to write a decoder $g:B\to A$. Check both identities: $g(f(a))=a$ for every $a\in A$, and $f(g(b))=b$ for every $b\in B$. The first says “encoding then decoding restores every source”; the second says “decoding then encoding restores every target.” The order of these operations matters.
<!-- bilingual-en:end -->

**单射**把不同源对象送到不同目标，排除把两个对象混成一个；**满射**能到达每个目标，排除遗漏。双射同时具备这两条。开头的例子记录了全部被选位置，因此不会混淆不同选择；对任意允许的串读出所有 $1$ 的位置，又能得到一个合法二元子集，因此覆盖了全部目标。

一种直接的证明方式是写出解码函数 $g:B\to A$，然后检查：对所有 $a\in A$，$g(f(a))=a$；对所有 $b\in B$，$f(g(b))=b$。前者表示“编码再解码，恢复每个源对象”，后者表示“解码再编码，恢复每个目标对象”。操作顺序不能混淆。

> [!warning] Specify the target set exactly · 目标集合必须说准确
> <!-- bilingual-en:start -->
> If the target in the opening example were **all** three-bit strings, the map would miss $000$, $111$ and the strings with one $1$; it would not be surjective. If we encoded a subset only by its size, the three different two-element subsets would all become $2$; that map would not be injective. A plausible encoding is not enough without these checks.
> <!-- bilingual-en:end -->
>
> 如果开头的目标集合改成**全部**三位二进制串，映射就到不了 $000$、$111$ 以及只有一个 $1$ 的串，因此不是满射。如果只记录子集的大小，三个不同的二元子集都会变成数字 $2$，因此不是单射。编码看起来合理，还不够保证双射。

<!-- bilingual-en:start -->
For nonnegative integers $n$ and $k$ with $0\le k\le n$, the same encoding pairs $k$-element subsets of $\{1,\ldots,n\}$ with length-$n$ bit strings containing exactly $k$ ones. Their common count is the [[组合数|binomial coefficient]] $\binom nk$. At $k=0$, the empty subset corresponds to the all-zero string; when $n=0$ as well, it corresponds to the empty string. Each collection then has one object.

A counting bijection need only pair objects reversibly. A [[图同构的定义与不变量|graph isomorphism]] also pairs vertices but must preserve adjacency. Equal counts alone do not establish that extra structure.
<!-- bilingual-en:end -->

对满足 $0\le k\le n$ 的非负整数 $n,k$，同样的编码把 $\{1,\ldots,n\}$ 的 $k$ 元子集与“长度为 $n$、恰有 $k$ 个 $1$ 的串”配成双射，数量都是[[组合数]] $\binom nk$。$k=0$ 时，空子集对应全零串；若 $n=0$，则对应空串，两边都各有一个对象。

计数双射只要求可逆配对。[[图同构的定义与不变量|图同构]]虽然也配对顶点，却额外要求保持邻接关系；数量相同本身不能证明这种结构也相同。
