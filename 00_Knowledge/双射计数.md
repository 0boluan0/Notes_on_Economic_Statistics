# 双射把一个有限集合的计数无损转移到另一个集合
<!-- bilingual-en:start -->
*A bijection transfers a finite count without loss from one set to another*
<!-- bilingual-en:end -->

> [!summary] 原子方法
> 若 \(f:A\to B\) 对每个 \(b\in B\) 都给出唯一的 \(a\in A\)，则 \(f\) 是双射，有限集合满足 \(|A|=|B|\)。计数证明的核心不是“看起来很像”，而是说明映射可逆。

例如，把 \(\{1,\ldots,n\}\) 的一个 \(k\) 元子集映射为长度 \(n\)、恰有 \(k\) 个 1 的二进制串：第 \(i\) 位为 1 当且仅当 \(i\) 在子集中。由二进制串也能唯一恢复子集，所以这是双射，两类对象都由 \(\binom nk\) 计数。

## 怎样证明没有重计或漏计

- **单射：** 两个不同源对象不会映到同一目标；
- **满射：** 每个目标对象都能由某个源对象得到；
- 或者直接写出逆映射，并验证两个复合都是恒等映射。

图同构也是一种双射，但还要求保持邻接结构；一般计数双射只要求保留“一个对象对应一个对象”，不能把两者混成同一概念。

> [!question]- 自检
> 为什么双射是一种“不用逐个枚举”的计数证明？
>
> **答案：** 它把每个目标对象与已知集合中的唯一对象配对。可逆性同时排除重复和遗漏，所以已知集合的大小直接转移过来。
