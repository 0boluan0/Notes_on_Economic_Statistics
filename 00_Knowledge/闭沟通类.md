# 闭沟通类是从类内任何状态都无法到达类外的沟通类
<!-- bilingual-en:start -->
*A closed communicating class is a class from which no state outside the class is accessible*
<!-- bilingual-en:end -->

> [!summary] 它是什么
> 沟通类 $C$ 称为 **闭沟通类**，若从类内任一状态出发都不能到达类外：
> $$
> i\in C,\ i\to j\quad\Longrightarrow\quad j\in C.
> $$
> 对一步转移，这等价于每个 $i\in C$ 都满足
> $$
> \sum_{j\in C}p_{ij}=1.
> $$
> 一旦链进入闭类，就会永远留在其中。
> <!-- bilingual-en:start -->
> A communicating class is closed when every transition starting in the class remains inside it, equivalently when no outside state is accessible from the class.
> <!-- bilingual-en:end -->

吸收状态 $a$ 满足 $p_{aa}=1$，所以单点集合 $\{a\}$ 是最小的闭沟通类；但闭类不必只有一个状态。若两个状态只在彼此之间来回转移，它们共同组成一个二状态闭类。

> [!question]- 自检
> 某沟通类内部的状态彼此可达，但其中一个状态以正概率跳到类外。这个沟通类闭吗？
>
> **答案：** 不闭。只要存在一条正概率出口，进入该类后就仍可能离开。
