# 使用sort排序文本必须确定比较键、数值规则与并列处理

<!-- bilingual-en:start -->
*Sorting text with sort requires explicit comparison keys, numeric rules, and tie handling*
<!-- bilingual-en:end -->

`sort` 默认按当前 locale 的排序规则比较整行文本，而不是自动理解字段的业务类型。若要按某个字段排序，应显式指定键：`-k2,2` 只取第二字段，`-k2` 则从第二字段一直取到行尾。字段分界和字段内容必须符合已知输入格式。

<!-- bilingual-en:start -->
`sort` normally compares complete text lines using the current locale's collation rules; it does not infer the business type of each field. Specify a key when sorting by a field: `-k2,2` ends at the second field, while `-k2` extends from that field through the end of the line. Field boundaries and contents must follow a known input format.
<!-- bilingual-en:end -->

```bash
printf '%s\n' 2 10 | LC_ALL=C sort
printf '%s\n' 2 10 | LC_ALL=C sort -n
printf '%s\n' 'b 2' 'a 2' | LC_ALL=C sort -k2,2n
```

第一条输出 `10`、`2`，第二条输出 `2`、`10`。`-n` 比较开头的数值部分，不是对整条记录执行数值合法性检查；科学计数法也不能直接套用普通 `-n` 的契约。需先验证数值字段，再选择工具支持的数值比较模式。

<!-- bilingual-en:start -->
The first command outputs `10`, then `2`; the second outputs `2`, then `10`. `-n` compares an initial numeric portion rather than validating the entire record as a number. Scientific notation is also outside ordinary `-n` semantics. Validate numeric fields and select a supported comparison mode accordingly.
<!-- bilingual-en:end -->

第三条的第二字段相等，但默认最终会再比较整行，得到 `a 2`、`b 2`，所以不能假定[[稳定排序|相等键保持输入次序]]。需要可重复的排名时，应写明主键方向和次键，例如先按频数降序、再按文本值升序；需要稳定性则另查所用实现的稳定排序选项。`sort -u` 还会按比较规则删除相等项，职责已超出只排序并保留全部项目的[[排序正确性标准]]。

<!-- bilingual-en:start -->
In the third command, the second fields tie, but the default final whole-line comparison produces `a 2`, then `b 2`. Thus [[稳定排序|preservation of input order among equal keys]] cannot be assumed. Specify primary direction and secondary keys for reproducible rankings, such as descending frequency followed by ascending text. If stability is required, check the implementation's stable-sort option. `sort -u` additionally removes items equal under its comparison rules, going beyond [[排序正确性标准|sorting while preserving every input item]].
<!-- bilingual-en:end -->
