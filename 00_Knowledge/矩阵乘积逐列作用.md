# Reading a matrix product by columns
<!-- bilingual-en:end -->
*矩阵乘积的逐列读法*

<!-- bilingual-en:start -->
A matrix can act on several input vectors by placing those vectors side by side. If the columns of $B$ are those inputs, then the columns of $AB$ are the corresponding outputs of $A$. Each column is processed separately, using the same rule. The familiar [[Ax的列组合解释|column-combination reading of $Ax$]] explains each output: its input entries are coefficients for combining the columns of $A$.
<!-- bilingual-en:end -->

把几个输入向量并排放成一张矩阵，就可以让同一个矩阵规则处理它们。如果 $B$ 的各列是这些输入，那么 $AB$ 的各列就是 $A$ 产生的对应输出。各列分别计算，使用同一个规则。熟悉的 [[Ax的列组合解释|$Ax$ 列组合读法]]解释每个输出：输入的各分量，就是组合 $A$ 各列所用的系数。

<!-- bilingual-en:start -->
## Three inputs, one matrix rule
<!-- bilingual-en:end -->
*三个输入，同一个矩阵规则*

<!-- bilingual-en:start -->
Take a $3\times2$ matrix $A$ and a $2\times3$ matrix $B$:
<!-- bilingual-en:end -->

取一个 $3\times2$ 矩阵 $A$ 和一个 $2\times3$ 矩阵 $B$：

$$A=\begin{pmatrix}2&-1\\1&0\\0&1\end{pmatrix},\qquad
B=\begin{pmatrix}1&2&0\\3&1&4\end{pmatrix}.$$

<!-- bilingual-en:start -->
The two columns of $A$ are $a_1=(2,1,0)^T$ and $a_2=(-1,0,1)^T$; $T$ means [[矩阵转置|transpose]], turning a written row into a column. The three columns of $B$ are the two-entry input vectors $b_1=(1,3)^T$, $b_2=(2,1)^T$, $b_3=(0,4)^T$. Apply $A$ to each:
<!-- bilingual-en:end -->

$A$ 的两列是 $a_1=(2,1,0)^T$、$a_2=(-1,0,1)^T$；$T$ 表示[[矩阵转置|转置]]，把横写的行变成列。$B$ 的三列分别是含两个分量的输入向量 $b_1=(1,3)^T$、$b_2=(2,1)^T$、$b_3=(0,4)^T$。对它们分别应用 $A$：

$$\begin{aligned}
Ab_1&=a_1+3a_2=(-1,1,3)^T,\\
Ab_2&=2a_1+a_2=(3,2,1)^T,\\
Ab_3&=4a_2=(-4,0,4)^T.
\end{aligned}
\qquad AB=\begin{pmatrix}-1&3&-4\\1&2&0\\3&1&4\end{pmatrix}.$$

<!-- bilingual-en:start -->
There are three output columns because we supplied three inputs. Each output has three entries because $A$ has three rows. Input dimension, output dimension and number of inputs are separate counts; the matrices need not be square.
<!-- bilingual-en:end -->

输入共有三列，所以结果有三列；$A$ 有三行，所以每个输出含三个分量。输入维数、输出维数与输入的个数，是三个不同的计数；矩阵不必是方阵。

## The identity and its entrywise proof
<!-- bilingual-en:end -->
*恒等式及逐元素证明*

<!-- bilingual-en:start -->
Let $A\in\mathbb F^{m\times n}$ and $B=[b_1\ \cdots\ b_p]\in\mathbb F^{n\times p}$, where $m,n,p$ are positive integers and $\mathbb F=\mathbb R$ or $\mathbb C$. The vector $b_j$ is the $j$th column of $B$. Write $a_k$ for column $k$ of $A$, and $b_{kj}$ for entry $k$ of $b_j$. Then
<!-- bilingual-en:end -->

设 $A\in\mathbb F^{m\times n}$、$B=[b_1\ \cdots\ b_p]\in\mathbb F^{n\times p}$，其中 $m,n,p$ 为正整数，$\mathbb F=\mathbb R$ 或 $\mathbb C$。向量 $b_j$ 是 $B$ 的第 $j$ 列；把 $A$ 的第 $k$ 列记作 $a_k$，$b_j$ 的第 $k$ 个分量记作 $b_{kj}$。于是

> [!important] Apply the same matrix to each column · 对每列应用同一矩阵
> $$\boxed{AB=[Ab_1\ \cdots\ Ab_p],\qquad
> (AB)_{:j}=Ab_j=\sum_{k=1}^{n}b_{kj}a_k.}$$
>
> <!-- bilingual-en:start -->
> The colon in $(AB)_{:j}$ means take all rows of column $j$. The coefficients come from column $j$ of $B$; the vectors being combined are columns of $A$.
> <!-- bilingual-en:end -->
>
> $(AB)_{:j}$ 中的冒号表示取第 $j$ 列的所有行。组合系数来自 $B$ 的第 $j$ 列，被组合的向量则是 $A$ 的各列。

<!-- bilingual-en:start -->
To check this from [[矩阵乘法|matrix multiplication]], fix a row $i$. Entry $i$ of $Ab_j$ is $\sum_{k=1}^n a_{ik}b_{kj}$, where $a_{ik}$ is entry $(i,k)$ of $A$. The same sum defines entry $(i,j)$ of $AB$. It agrees for all $i$, so the columns agree. Expanding $Ab_j$ by the column-combination identity gives the final sum. Complex entries use ordinary multiplication, with no conjugation.
<!-- bilingual-en:end -->

从[[矩阵乘法]]定义检查，固定一行 $i$。$Ab_j$ 的第 $i$ 个分量为 $\sum_{k=1}^n a_{ik}b_{kj}$，其中 $a_{ik}$ 是 $A$ 的第 $(i,k)$ 个元素；同一个和定义了 $AB$ 的第 $(i,j)$ 个元素。对所有 $i$ 相同，所以整列相同。再按列组合恒等式展开 $Ab_j$，就得到最后的求和式。复数元素使用普通乘法，不取共轭。

## Which outputs can occur?
<!-- bilingual-en:end -->
*哪些输出可以出现？*

<!-- bilingual-en:start -->
The [[列空间|column space]] $C(A)$ contains all combinations of columns of $A$. Each output column $Ab_j$ belongs to it, and any combination of these output columns also stays in it. Consequently,
<!-- bilingual-en:end -->

[[列空间]] $C(A)$ 包含 $A$ 各列的全部组合。每条输出列 $Ab_j$ 都属于它，而把这些输出列再作组合，也仍留在其中。因此

$$\boxed{C(AB)\subseteq C(A).}$$

<!-- bilingual-en:start -->
Both are subsets of the same output space $\mathbb F^m$. More precisely, if $x\in\mathbb F^p$ varies, then $(AB)x=A(Bx)$, so
<!-- bilingual-en:end -->

二者都是同一输出空间 $\mathbb F^m$ 的子集。更准确地，让 $x\in\mathbb F^p$ 变化，有 $(AB)x=A(Bx)$，所以

$$C(AB)=\{Ay:y\in C(B)\}=A(C(B)).$$

<!-- bilingual-en:start -->
Here $A(C(B))$ means apply $A$ to every vector in $C(B)$. Only intermediate vectors attainable through $B$ are supplied to $A$. This restriction can shrink the result: if $A$ is the $2\times2$ [[单位矩阵|identity matrix]] and $B=(1,0)^T$, then $C(A)=\mathbb F^2$ but $C(AB)$ is only the first-coordinate line. Thus containment need not be equality; zero or dependent input columns are allowed.
<!-- bilingual-en:end -->

$A(C(B))$ 表示把 $A$ 应用于 $C(B)$ 中的每个向量。只有经 $B$ 可达的中间向量才会被交给 $A$；这个限制可能缩小结果：若 $A$ 为 $2\times2$ [[单位矩阵]]、$B=(1,0)^T$，则 $C(A)=\mathbb F^2$，而 $C(AB)$ 只是第一坐标轴。因此包含不必是相等；输入列也允许为零或相互相关。

<!-- bilingual-en:start -->
The [[矩阵乘积逐行作用|rowwise reading]] gives a different containment, $\operatorname{Row}(AB)\subseteq\operatorname{Row}(B)$. Output columns come from columns of $A$, while output rows come from rows of $B$. Their dimensions give the [[矩阵乘积秩上界|rank bound for a product]].
<!-- bilingual-en:end -->

[[矩阵乘积逐行作用|逐行读法]]给出另一条包含关系 $\operatorname{Row}(AB)\subseteq\operatorname{Row}(B)$。结果的列来自 $A$ 的列，结果的行来自 $B$ 的行。比较这些空间的维数，就得到[[矩阵乘积秩上界]]。

## Matrix actions and abstract composition
<!-- bilingual-en:end -->
*矩阵作用与抽象映射复合*

<!-- bilingual-en:start -->
For coordinate columns, the order is always $x\mapsto Bx\mapsto A(Bx)$: the rightmost matrix acts first. If the arrays represent abstract [[线性映射|linear maps]], dimension matching alone does not verify that their coordinates mean the same thing. The output basis used for $B$ and the input basis expected by $A$ must be checked. When they are the same ordered basis, $AB$ represents the composite; otherwise the full coordinate path inserts the appropriate conversion matrix between them. See [[复合映射的表示矩阵|the matrix of a composition]].
<!-- bilingual-en:end -->

对坐标列，顺序总是 $x\mapsto Bx\mapsto A(Bx)$：最右边的矩阵先作用。若这些数组表示抽象[[线性映射]]，尺寸匹配本身还不能确认两套坐标意义一致，需要核对 $B$ 使用的输出基与 $A$ 接收的输入基。中间使用同一有序基时，$AB$ 表示复合；否则完整坐标路径会在两者之间插入相应的转换矩阵，见[[复合映射的表示矩阵]]。

<!-- bilingual-en:start -->
The [[表示矩阵的列|column rule for a representing matrix]] says each input basis vector's image supplies one coordinate column. Applying the second map to these images explains the same columnwise rule. It does not require the columns themselves to form a basis, nor does an accidental equality of products prove that two coordinate systems coincide.
<!-- bilingual-en:end -->

[[表示矩阵的列|表示矩阵的列规则]]说，每个输入基向量的像提供一列坐标。再把第二个映射应用于这些像，就解释了同一逐列规则。它不要求各列本身是一组基，乘积的偶然相等也不能证明两套坐标系一致。
