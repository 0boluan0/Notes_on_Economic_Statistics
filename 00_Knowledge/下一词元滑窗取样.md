# Sliding windows for next-token prediction
<!-- bilingual-en:end -->

*下一词元滑窗取样*

<!-- bilingual-en:start -->
A full training sample pairs $T$ consecutive input IDs with the IDs immediately following them at each position. Given a source sequence $u$ of length $N$ and a start $i$, use the two half-open slices below. The final input needs one further token as its label, so the source chunk spans $T+1$ positions.
<!-- bilingual-en:end -->

一条完整训练样本包含连续 $T$ 个输入编号，以及各个输入位置后面的真实编号作为目标。设全文序列为 $u$，含 $N$ 个词元，起点为 $i$，用下面两个左闭右开的切片。最后一个输入还需要后面一个词元作标签，因此一组样本共用到 $T+1$ 个原文位置。

$$x=u[i:i+T],\qquad y=u[i+1:i+T+1].$$

<!-- bilingual-en:start -->
## Valid starts
<!-- bilingual-en:end -->

*窗口起点的合法范围*

<!-- bilingual-en:start -->
The last target index is $i+T$. It must be at most $N-1$, so $0\le i<N-T$. For positive stride $s$, the starts are `range(0, N-T, s)`. Under the full-window policy, a sequence with $N\le T$ supplies zero complete samples. Exactly $T+1$ source tokens supply one sample. Each target refers to a prefix of its own sample, subject to [[00_Knowledge/Transformer自回归约束|causal visibility]].
<!-- bilingual-en:end -->

最后一个目标的索引为 $i+T$，最多取到 $N-1$，故合法起点满足 $0\le i<N-T$。步长 $s>0$ 时依次取 `range(0, N-T, s)`。在只取完整窗口的规则下，$N\le T$ 时无法组成一条，$N=T+1$ 时恰有一条。每个目标对应自己样本中的可见前缀，见[[00_Knowledge/Transformer自回归约束]]。

<!-- bilingual-en:start -->
Changing stride alters which starts are sampled and how many positions adjacent input windows share. The one-position label offset follows from the next-token task itself. A larger stride may leave a usable start unvisited. The sampling rule therefore determines which source positions contribute and with what repetition.
<!-- bilingual-en:end -->

改变步长决定哪些起点被取到、相邻输入有多少重叠。标签相对输入错开一格由下一词元任务本身决定。较大的步长还可能跨过原本合法的起点，因此同一篇文字里哪些位置出现、出现多少次，取决于取样设置。
