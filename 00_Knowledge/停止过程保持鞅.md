# Stopped martingales
<!-- bilingual-en:end -->

*停止过程保持鞅*

<!-- bilingual-en:start -->
Stopping a process means freezing its recorded value after a rule tells us to stop. The clock can keep running: at time $n$, we report the original value if the rule has not yet stopped, and the value at stopping otherwise. For a discrete-time [[鞅定义|martingale]], this frozen process is still a martingale, provided the stopping rule uses only information already available.
<!-- bilingual-en:end -->

停止一个过程，是在规则要求停止后冻结它的记录值。时钟仍可继续走：到时刻 $n$，若尚未停止就报告原过程的当前值，否则报告停止时的值。对离散时间[[鞅定义|鞅]]，只要停止规则仅使用已经获得的信息，冻结后的过程仍然是鞅。

<!-- bilingual-en:start -->
A martingale $M_n$ relative to a [[滤过定义|filtration]] $\mathcal F_n$ is observable at time $n$, is [[期望|integrable]] ($E|M_n|<\infty$), and satisfies $E[M_n\mid\mathcal F_{n-1}]=M_{n-1}$ for $n\ge1$. A [[停时定义|stopping time]] $T$ may take any nonnegative integer value, or $\infty$ if stopping never occurs. Write $n\wedge T=\min(n,T)$ and define the stopped process by $M_n^T=M_{n\wedge T}$.
<!-- bilingual-en:end -->

相对于[[滤过定义|滤过]] $\mathcal F_n$ 的鞅 $M_n$，在时刻 $n$ 可以观测，[[期望|可积]]（$E|M_n|<\infty$），并且对 $n\ge1$ 满足 $E[M_n\mid\mathcal F_{n-1}]=M_{n-1}$。[[停时定义|停时]] $T$ 可以取任意非负整数；永不停止时取 $\infty$。记 $n\wedge T=\min(n,T)$，停止过程定义为 $M_n^T=M_{n\wedge T}$。

> [!example] A fair coin game with a stopping rule · 有停止规则的公平硬币游戏
> <!-- bilingual-en:start -->
> Start at $M_0=0$ and add $+1$ for a head, $-1$ for a tail, using independent fair tosses. Stop after the first toss if it is a head; otherwise stop after the second. At time $2$, the equally likely paths HH, HT, TH, TT have stopped values $1,1,0,-2$, respectively. Their mean is $0$. After a first head, the frozen value stays $1$; after a first tail, the next two possibilities $0,-2$ average to the current value $-1$.
> <!-- bilingual-en:end -->
>
> 从 $M_0=0$ 开始，独立公平抛掷中正面加 $1$、反面减 $1$。第一次为正面就停止，否则第二次后停止。到时刻 $2$，四条等可能路径 HH、HT、TH、TT 的停止值依次为 $1,1,0,-2$，平均仍是 $0$。第一次为正面时，冻结值一直为 $1$；第一次为反面时，下一步的两种停止值 $0,-2$ 的平均是当时的值 $-1$。

<!-- bilingual-en:start -->
The theorem applies to every finite deterministic $n$: $(M_n^T,\mathcal F_n)_{n\ge0}$ is a martingale and $E[M_{n\wedge T}]=E[M_0]$. It does not require $T$ to be bounded or $E[T]$ to be finite. If $T=0$, the process is constantly $M_0$; if $T=\infty$, it is the original process. In neither case do we need to define a value $M_\infty$ to evaluate $M_{n\wedge T}$ at finite $n$.
<!-- bilingual-en:end -->

定理适用于每个有限的确定时刻 $n$：$(M_n^T,\mathcal F_n)_{n\ge0}$ 是鞅，且 $E[M_{n\wedge T}]=E[M_0]$。这里不要求 $T$ 有界，也不要求 $E[T]$ 有限。$T=0$ 时过程恒为 $M_0$；$T=\infty$ 时仍是原过程。在有限 $n$ 处计算 $M_{n\wedge T}$，不需要先定义 $M_\infty$。

## Keep only the increments taken before stopping
<!-- bilingual-en:end -->

## 证明骨架

<!-- bilingual-en:start -->
Let $\Delta M_k=M_k-M_{k-1}$ be the $k$th [[鞅差序列|martingale difference]]. Let $\mathbf1_A$ denote the [[事件指示变量|indicator]] of event $A$, equal to $1$ on $A$ and $0$ elsewhere. On each individual path,
<!-- bilingual-en:end -->

令 $\Delta M_k=M_k-M_{k-1}$ 为第 $k$ 个[[鞅差序列|鞅差]]。$\mathbf1_A$ 是事件 $A$ 的[[事件指示变量|指示变量]]，事件发生时为 $1$，否则为 $0$。逐条路径都有

$$
M_{n\wedge T}=M_0+\sum_{k=1}^{n}\mathbf1_{\{T\ge k\}}\Delta M_k.
$$

<!-- bilingual-en:start -->
We include the increment at the stopping step itself. Thus the condition is $T\ge k$, not $T>k$: if $T=k$, the process still moves from $M_{k-1}$ to $M_k$ before freezing. Because $T$ is integer-valued, $\{T\ge k\}=\{T>k-1\}\in\mathcal F_{k-1}$. The decision to include step $k$ is therefore [[离散可预测过程|predictable]], known one step in advance.
<!-- bilingual-en:end -->

停止的那一步增量也要保留，所以条件是 $T\ge k$，而不是 $T>k$：若 $T=k$，过程先从 $M_{k-1}$ 走到 $M_k$，然后才冻结。由于 $T$ 取整数值，$\{T\ge k\}=\{T>k-1\}\in\mathcal F_{k-1}$，因此是否保留第 $k$ 步是[[离散可预测过程|可预测的]]，提前一期就已知道。

<!-- bilingual-en:start -->
The finite sum is [[适应过程|adapted]]: every term up to $n$ is measurable using $\mathcal F_n$. It is integrable because each indicator is bounded and each difference is integrable; alternatively, $|M_{n\wedge T}|\le\sum_{j=0}^{n}|M_j|$. Finally, a bounded coefficient known at time $n-1$ can be [[条件期望取出已知量|taken outside conditional expectation]], giving
<!-- bilingual-en:end -->

这个有限和是[[适应过程|适应的]]，因为到 $n$ 为止的每一项都可由 $\mathcal F_n$ 判断。它也可积，因为指示变量有界，而各个鞅差可积；也可直接用 $|M_{n\wedge T}|\le\sum_{j=0}^{n}|M_j|$。最后，时刻 $n-1$ 已知的有界系数可以[[条件期望取出已知量|提出条件期望]]，于是

$$
\begin{aligned}
E[M_n^T-M_{n-1}^T\mid\mathcal F_{n-1}]
&=\mathbf1_{\{T\ge n\}}E[\Delta M_n\mid\mathcal F_{n-1}]\\
&=0.
\end{aligned}
$$

<!-- bilingual-en:start -->
These are precisely the martingale conditions. Equivalently, this is the [[鞅差部分和|partial-sum construction from martingale differences]], with the predictable indicators choosing which increments remain. Taking expectations repeatedly yields $E[M_n^T]=E[M_0]$.
<!-- bilingual-en:end -->

这恰好验证了鞅的全部条件。等价地，这是[[鞅差部分和|由鞅差部分和构造鞅]]，其中可预测指示变量决定保留哪些增量。逐步取期望便得 $E[M_n^T]=E[M_0]$。

> [!warning] A finite clock time is not a random terminal value · 有限时刻与随机终值不同
> <!-- bilingual-en:start -->
> Every finite $n$ is covered, even for an unbounded $T$. Passing to $M_T$ as $n\to\infty$ is a further step: $M_T$ may fail to be integrable, and even an integrable terminal value need not preserve the initial expectation. Check [[可选停止条件|optional-stopping conditions]] before making that passage. The proof here is discrete: it uses a finite sum and one-step predictability. A continuous-time stopped-martingale theorem needs its own path-regularity and filtration hypotheses; replacing $n$ by $t$ does not supply a proof.
> <!-- bilingual-en:end -->
>
> 每个有限 $n$ 都在定理范围内，即使 $T$ 无界。令 $n\to\infty$ 得到 $M_T$ 是另外一步：$M_T$ 可能不可积，即使可积也未必保持初始期望。应先核验[[可选停止条件]]。这里的证明属于离散时间，使用有限求和和提前一期的可预测性；连续时间版本还需核对相应的路径正则性与滤过条件，不能仅把 $n$ 改成 $t$ 就视为证明。
