# Continuity at a point
<!-- bilingual-en:end -->
*一点连续*

<!-- bilingual-en:start -->
A function is **continuous at a point** if keeping the input sufficiently close to that point keeps the output as close as we wish to its value there. For $f(x)=2x$ at input $3$, the point value is $f(3)=6$. To keep the output error below $0.1$, it is enough to keep the input distance below $0.05$, because $|2x-6|=2|x-3|$.
<!-- bilingual-en:end -->

函数在**一点连续**，表示：只要把输入限制在这个点附近足够小的范围，就能让输出任意接近这个点的函数值。例如 $f(x)=2x$ 在输入 $3$ 处的点值是 $f(3)=6$。要让输出误差小于 $0.1$，只需让输入距离小于 $0.05$，因为 $|2x-6|=2|x-3|$。

<!-- bilingual-en:start -->
The centre of the output comparison is the **actual point value** $f(a)$. A [[函数极限|function limit]] instead tests nearby inputs against a proposed number $L$ while omitting $a$ itself. Continuity connects nearby behaviour to the value already assigned at $a$.
<!-- bilingual-en:end -->

这里比较输出时，以**实际点值** $f(a)$ 为中心。[[函数极限]]则把附近输入的输出与候选数 $L$ 比较，排除 $a$ 本身。连续性把附近的行为与已经赋给 $a$ 的点值连接起来。

> [!important] Local input control · 局部输入控制
> <!-- bilingual-en:start -->
> Let $D\subseteq\mathbb R$ be the set of allowed inputs, let $f:D\to\mathbb R$, and choose $a\in D$. The function is continuous at $a$ if **for every** output tolerance $\varepsilon>0$, **there is** an input radius $\delta>0$ such that every $x\in D$ satisfies
> <!-- bilingual-en:end -->
>
> 设 $D\subseteq\mathbb R$ 是合法输入的集合，$f:D\to\mathbb R$，并选取 $a\in D$。若**对于每个**输出容差 $\varepsilon>0$，**都存在**输入半径 $\delta>0$，使每个 $x\in D$ 满足下式，就称 $f$ 在 $a$ 连续：
>
> $$|x-a|<\delta\quad\Longrightarrow\quad |f(x)-f(a)|<\varepsilon.$$
>
> <!-- bilingual-en:start -->
> Absolute value measures distance. First specify the required output accuracy; then choose one input radius that works for all allowed inputs inside it. The radius may depend on $a$ and $\varepsilon$, but not on an input chosen afterwards. Unlike a punctured limit, this test permits $x=a$; that input gives output error zero.
> <!-- bilingual-en:end -->
>
> 绝对值衡量距离。先规定输出精度，再选取一个对范围内所有合法输入都有效的半径。半径可以依赖 $a$ 与 $\varepsilon$，但不能随之后挑出的输入临时改变。与去心极限不同，这个检验允许 $x=a$；此时输出误差为零。

<!-- bilingual-en:start -->
For the opening linear example, any requested $\varepsilon>0$ is handled by $\delta=\varepsilon/2$. This proves continuity at $3$ for arbitrary accuracy, rather than only for the tolerance $0.1$. The requirement $a\in D$ is essential: a function with no assigned value at $a$ has no $f(a)$ to compare against.
<!-- bilingual-en:end -->

在开头的线性例子中，对任何 $\varepsilon>0$ 都可以取 $\delta=\varepsilon/2$。这就证明了 $3$ 处对任意精度的连续性，而不只是容差 $0.1$ 的情况。$a\in D$ 很重要：如果函数在 $a$ 没有赋值，就没有可供比较的 $f(a)$。

## The three checks at an interior point
<!-- bilingual-en:end -->
## 内点处的三项检查

<!-- bilingual-en:start -->
At an interior point, some interval around $a$ lies in the domain, so nearby inputs come from both sides. Continuity then amounts to three checks: the point value is defined, the finite two-sided limit exists, and that limit equals the point value. The [[双侧极限判定|two-sided criterion]] establishes the middle check by comparing left and right limits.
<!-- bilingual-en:end -->

在定义域内点处，$a$ 周围的某个区间全部属于定义域，因此输入可以从两侧趋近。此时连续性等价于三项检查：点值有定义、有限双侧极限存在、极限等于点值。中间一项可以用[[双侧极限判定]]比较左右极限。

$$f(a)\text{ is defined},\qquad
\lim_{x\to a}f(x)=L\in\mathbb R,\qquad L=f(a).$$

<!-- bilingual-en:start -->
More generally, whenever $a\in D$ is a **cluster point**—there are other domain inputs arbitrarily close to it—the same reasoning gives the domain-relative equivalence
<!-- bilingual-en:end -->

更一般地，只要 $a\in D$ 是一个**聚点**，也就是存在任意靠近它的其他定义域输入，就有相对于定义域的等价关系：

$$f\text{ is continuous at }a
\quad\Longleftrightarrow\quad
\lim_{\substack{x\to a\\x\in D}}f(x)=f(a).$$

<!-- bilingual-en:start -->
Indeed, continuity gives the limit estimate when we omit $a$. Conversely, the limit gives the estimate for $x\ne a$, and $x=a$ adds only the automatically valid inequality $0<\varepsilon$. An existing point value alone does not create a nearby limit, and an existing limit does not automatically match the point value.
<!-- bilingual-en:end -->

这是因为：从连续性的保证中删去 $a$，便得到极限的误差保证；反过来，极限保证处理 $x\ne a$，加上 $x=a$ 只多出自动成立的 $0<\varepsilon$。有点值不等于附近一定有极限；有极限也不等于它已经与点值相等。

## A hole and two possible fillings
<!-- bilingual-en:end -->
## 最小例子

<!-- bilingual-en:start -->
Consider the rule
<!-- bilingual-en:end -->

考虑函数规则

$$f(x)=\frac{x^2-1}{x-1},\qquad D=\mathbb R\setminus\{1\}.$$

<!-- bilingual-en:start -->
For $x\ne1$, factoring $x^2-1=(x-1)(x+1)$ gives $f(x)=x+1$, so its limit at $1$ is $2$. The original function is not defined at $1$: continuity there is not a point property available to that original map. Define an extended function $g$ on all real inputs by keeping these nearby values and choosing $g(1)$.
<!-- bilingual-en:end -->

当 $x\ne1$ 时，由 $x^2-1=(x-1)(x+1)$ 可约去 $x-1$，得到 $f(x)=x+1$，所以在 $1$ 处的极限为 $2$。原函数在 $1$ 没有定义，因此原映射在这个点上谈不上具有连续性。可以另定义一个扩展函数 $g$，保留这些附近取值，并补上 $g(1)$。

> [!example] The limit stays fixed; continuity depends on the filling · 极限不变，连续性取决于补值
> <!-- bilingual-en:start -->
> If $g(1)=2$, then $g(x)=x+1$ everywhere, and $|g(x)-g(1)|=|x-1|$ proves continuity. If $g(1)=100$, the limit remains $2$ by [[点值不决定极限|invariance under changing one point]], but continuity fails. For $0<|x-1|<1$, the nearby output lies between $1$ and $3$, at distance greater than $97$ from $100$; no input radius can guarantee even output tolerance $1$.
> <!-- bilingual-en:end -->
>
> 若 $g(1)=2$，则处处有 $g(x)=x+1$，由 $|g(x)-g(1)|=|x-1|$ 可得连续性。若 $g(1)=100$，依据[[点值不决定极限]]，极限仍为 $2$，但连续性失败。当 $0<|x-1|<1$ 时，附近输出介于 $1$ 和 $3$ 之间，与 $100$ 的距离大于 $97$；无论输入半径多小，都不能保证输出容差 $1$。

## Approach endpoints through the domain
<!-- bilingual-en:end -->
## 端点要沿定义域趋近

<!-- bilingual-en:start -->
For $f(x)=\sqrt{x}$ on $D=[0,\infty)$, the endpoint $0$ belongs to the domain, and $f(0)=0$. Given $\varepsilon>0$, choose $\delta=\varepsilon^2$. An allowed input with $|x|<\delta$ satisfies $0\le x<\varepsilon^2$, hence $|\sqrt{x}-0|<\varepsilon$. This proves continuity at $0$ using only inputs from the right. There is no need to invent negative inputs outside the domain.
<!-- bilingual-en:end -->

对于 $D=[0,\infty)$ 上的 $f(x)=\sqrt{x}$，端点 $0$ 属于定义域，且 $f(0)=0$。给定 $\varepsilon>0$，取 $\delta=\varepsilon^2$。若合法输入满足 $|x|<\delta$，就有 $0\le x<\varepsilon^2$，进而 $|\sqrt{x}-0|<\varepsilon$。这就只用右侧输入证明了 $0$ 处连续，不需要虚构定义域之外的负输入。

<!-- bilingual-en:start -->
## Continuity at an isolated domain point
<!-- bilingual-en:end -->
## 孤立点自动连续

<!-- bilingual-en:start -->
A domain point is **isolated** if a sufficiently small interval around it contains no other domain point. For example, take $D=\{0\}\cup[1,2]$ and any real-valued function on $D$. At $a=0$, choose $\delta=1/2$. The only allowed input within that radius is $x=0$, so $|f(x)-f(0)|=0<\varepsilon$ for every $\varepsilon>0$, regardless of the function's values on $[1,2]$.
<!-- bilingual-en:end -->

若某个定义域点周围足够小的区间内没有其他定义域点，就称它是**孤立点**。例如，取 $D=\{0\}\cup[1,2]$，并在 $D$ 上定义任意实值函数。在 $a=0$ 处取 $\delta=1/2$，半径内唯一的合法输入就是 $x=0$，所以对每个 $\varepsilon>0$，都有 $|f(x)-f(0)|=0<\varepsilon$，不管函数在 $[1,2]$ 上如何取值。

<!-- bilingual-en:start -->
Thus every real-valued function is continuous at each isolated point of its domain. This does not assign a unique punctured limit there: the [[函数极限|limit definition used here]] requires a cluster point. It is the direct continuity definition that covers the isolated case.
<!-- bilingual-en:end -->

因此，任意实值函数在其定义域的每个孤立点都连续。这不意味着那里有一个唯一的去心极限，因为这里的[[函数极限]]定义要求聚点；覆盖孤立点情形的是连续性的直接定义。

<!-- bilingual-en:start -->
Being continuous at one point says nothing by itself about other points. Being continuous as a map on the whole domain means satisfying the local condition at every domain point; [[连续性|the general definition of a continuous map]] expresses this with neighbourhoods and open preimages. This card uses real inputs and outputs with their usual distances.
<!-- bilingual-en:end -->

在一个点连续，本身不说明其他点的情况。在整个定义域上作为连续映射，要求每个定义域点都满足局部条件；一般的[[连续性]]用邻域与开集原像表达这一点。本卡使用实数输入、实数输出及其通常距离。
