# 误差函数是从零到自变量的高斯核积分乘以归一化常数
<!-- bilingual-en:start -->
*The error function is the normalized integral of the Gaussian kernel from zero to its argument*
<!-- bilingual-en:end -->

对实数 $x$，误差函数定义为
$$
\operatorname{erf}(x)=\frac{2}{\sqrt\pi}\int_0^x e^{-t^2}\,dt.
$$
它把高斯形状 $e^{-t^2}$ 的累积面积写成一个命名函数，满足 $\operatorname{erf}(0)=0$。归一化常数来自 [[高斯积分|$\int_0^{\infty}e^{-t^2}dt=\sqrt\pi/2$]]，因此 $\lim_{x\to\infty}\operatorname{erf}(x)=1$。
<!-- bilingual-en:start -->
For real $x$, the error function is defined by the displayed integral and has value zero at the origin. The [[高斯积分|Gaussian integral]] supplies the normalization, so its limit as $x\to\infty$ is one.
<!-- bilingual-en:end -->

由于被积函数为偶函数，$\operatorname{erf}(-x)=-\operatorname{erf}(x)$；由 [[积分求导定理]]，$\operatorname{erf}'(x)=2e^{-x^2}/\sqrt\pi>0$。这些性质直接帮助读懂函数图形，而数值计算可使用 [[误差函数幂级数]]。
<!-- bilingual-en:start -->
The even integrand makes the error function odd. The [[积分求导定理|fundamental theorem for accumulation integrals]] gives $\operatorname{erf}'(x)=2e^{-x^2}/\sqrt\pi>0$, so it increases everywhere. The [[误差函数幂级数|power-series expansion]] provides one way to calculate it.
<!-- bilingual-en:end -->
