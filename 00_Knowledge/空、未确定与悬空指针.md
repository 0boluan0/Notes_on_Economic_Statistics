# 空指针、未确定指针与悬空指针是三种不同状态
<!-- bilingual-en:start -->
*Null, indeterminate, and dangling pointers are three different states*
<!-- bilingual-en:end -->

> [!summary] 状态区别
> **空指针（null pointer）**是保证不等于任何对象或函数地址的有效指针值，可用于比较和表示“目前不指向对象”，但不能解引用。**未确定指针（indeterminate pointer）**尚无可安全依赖的值，常见于未初始化的自动对象。**悬空指针（dangling pointer）**是工程上对“曾指向对象、但对象生命周期已经结束”的称呼；按 N1570，所指对象寿命结束时，相关指针值会变成未确定值。
> <!-- bilingual-en:start -->
> A null pointer is a valid pointer value guaranteed not to equal any object or function pointer and may represent “no object,” but it cannot be dereferenced. An indeterminate pointer has no safely usable value, often because an automatic object was never initialised. A dangling pointer is the engineering name for a pointer whose former target's lifetime has ended; under N1570, that pointer value becomes indeterminate at that point.
> <!-- bilingual-en:end -->

```c
#include <stddef.h>

void pointer_states(void) {
    int *none = NULL;  // 已知为空，可比较
    int *unknown;      // 块内自动对象未初始化，值未确定
    (void) sizeof unknown;  // 只使用类型，不读取 unknown 的值

    if (none == NULL) {
        /* 正常的空指针判断 */
    }
    /* unknown 在赋成确定值前不能被读取 */
}

void expired_pointer_example(void) {
    int *old;
    {
        int local = 7;
        old = &local;
    }
    /* local 寿命已结束；old 从这里起不能再读取、比较或返回 */
    (void) sizeof old;  // sizeof 不求值，因此没有读取 old
}
```

`NULL` 是头文件提供的空指针常量宏，不是“一块特殊内存”，也不能据此假定所有空指针都用全零比特表示。`none == NULL` 是正常判断，`free(NULL)` 也被规定为什么都不做；但 `*none` 没有对象可访问。`unknown` 在赋成确定值之前连读取、比较或传给期待有效值的代码都不应发生，不能先用 `unknown == NULL` 猜它是否“碰巧为空”。
<!-- bilingual-en:start -->
`NULL` is a macro for a null pointer constant, not a special memory block, and does not imply an all-bits-zero representation. Comparing `none` with `NULL` is valid and `free(NULL)` is a no-op, while `*none` is invalid. An indeterminate pointer must not first be read or compared in an attempt to discover whether it happens to be null.
<!-- bilingual-en:end -->

悬空和 one-past 也不同：只要数组仍存活，one-past 指针是允许形成的边界值，只是不能解引用；悬空指针的目标寿命已经结束，不能继续用于访问。`free(p); p = NULL;` 能防止之后误用这个变量 `p`，却不会改变任何仍保存旧值的别名，因此不能单靠“释放后置空”证明系统中没有 use-after-free（释放后使用）。
<!-- bilingual-en:start -->
Dangling and one-past are also distinct. A one-past pointer remains a permitted boundary value while its array is alive, though it is not dereferenceable. A dangling pointer's target lifetime has ended. Assigning `NULL` to one pointer after `free` does not update aliases that retained the old value.
<!-- bilingual-en:end -->

> [!question]- 最小自检
> 为什么未初始化的 `int *p` 不能通过 `if (p != NULL)` 变得安全？
>
> **答案：** 判断条件本身就要读取 `p` 的未确定值；空指针是一个已知有效状态，未确定不是“尚未检查的空指针”。
