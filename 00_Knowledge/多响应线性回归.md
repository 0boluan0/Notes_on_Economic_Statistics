# 多响应线性回归是用同一设计矩阵同时建模多个响应条件均值的线性模型
<!-- bilingual-en:start -->
*Multivariate linear regression uses one design matrix to model the conditional means of several responses jointly*
<!-- bilingual-en:end -->

> [!summary] 它是什么
> **多响应线性回归**把同一个观测单位的多个响应排成一行，并用同一行预测变量同时建模这些响应的条件均值。它的矩阵形式是
> $$Y_{n\times q}=X_{n\times k}B_{k\times q}+U_{n\times q}.$$
> $Y$ 的第 $i$ 行是第 $i$ 个观测的 $q$ 维响应；$X$ 的第 $i$ 行是同一观测的 $k$ 个已编码回归项；$B$ 的第 $j$ 列给第 $j$ 个响应的系数；$U$ 保存未被条件均值 $XB$ 解释的误差。
> <!-- bilingual-en:start -->
> In $Y_{n\times q}=X_{n\times k}B_{k\times q}+U_{n\times q}$, rows index observational units, columns of $Y$ index responses, columns of $X$ index encoded regressors, and columns of $B$ contain response-specific coefficient vectors.
> <!-- bilingual-en:end -->

维度检查给出 $(n\times k)(k\times q)=n\times q$。若模型含截距，它是 $X$ 的一列，已经计入 $k$；因此经典残差自由度是 $n-r$，其中 $r=\operatorname{rank}(X)$，满列秩时才简化为 $n-k$。

模型陈述还需要条件均值边界，例如 $E(U\mid X)=0$。仅把数据排成矩阵不会自动赋予 $B$ 因果意义，也不会保证线性条件均值正确。若不同响应使用不同样本、不同预测变量或不同函数形式，就不再是这一张共享 $X$ 的简单矩阵模型。

> [!question]- 自检
> $X$ 是 $120\times5$、$Y$ 是 $120\times3$ 时，$B$ 和 $U$ 分别是什么维度？
>
> **答案：** $B$ 是 $5\times3$，$U$ 是 $120\times3$。
