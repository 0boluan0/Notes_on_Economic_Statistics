# 条件更新在同一条语句中用当前行版本决定是否写入

<!-- bilingual-en:start -->
*Under PostgreSQL Read Committed, a conditional update rechecks the current row version*
<!-- bilingual-en:end -->

> [!summary] 原子定义
> 在 PostgreSQL Read Committed 下，把局部不变量的条件写进同一条 `UPDATE ... WHERE ...`，数据库会在等待并发写者后对当前行版本重查条件；再用 affected-row count 或 `RETURNING` 区分成功与条件不成立。这样可关闭“先查、后写”的语句间窗口。
>
> <!-- bilingual-en:start -->
> Under PostgreSQL Read Committed, put a local invariant in the same `UPDATE ... WHERE ...`; after waiting for a concurrent writer, PostgreSQL rechecks the condition against the current row version. Use the affected-row count or `RETURNING` to distinguish success from a failed condition. This closes the statement gap between checking and writing.
> <!-- bilingual-en:end -->

## 自然解释

库存扣减可写成：

```sql
UPDATE products
SET stock = stock - 1
WHERE product_id = 42
  AND stock > 0
RETURNING stock;
```

在 PostgreSQL Read Committed 下，若目标行被另一事务先更新，本语句等待后会在新版本上重查 `stock > 0`。返回一行表示扣减成功；零行表示不存在该商品或库存条件不成立，应用要按业务再区分。

<!-- bilingual-en:start -->
Under PostgreSQL Read Committed, if another transaction updates the target row first, this statement waits and then rechecks `stock > 0` on the new row version. One returned row means the decrement succeeded; zero rows means either the product was absent or the stock condition failed, which the application may need to distinguish.
<!-- bilingual-en:end -->

> [!warning] 边界
> 单语句 conditional update 适合由该行当前值决定的局部规则。涉及多行汇总、区间不存在性或外部系统时，一条行更新未必足够，需要 constraint、锁或 Serializable 等更强边界。
>
> <!-- bilingual-en:start -->
> A one-statement conditional update suits a local rule determined by the current row. Multi-row aggregates, absence over a range, or external systems may require a constraint, locks, or Serializable isolation instead.
> <!-- bilingual-en:end -->

> [!question]- 回忆与应用
> 为什么执行后必须检查受影响行数，而不能只看 SQL 没报错？
>
> **答案：** 条件不成立时合法结果就是更新零行；不检查会把“没有扣减”误当成成功。

## 来源与核验

- PostgreSQL 18, [*Read Committed Isolation Level*](https://www.postgresql.org/docs/current/transaction-iso.html#XACT-READ-COMMITTED)：说明并发更新等待后在新行版本上重查 `WHERE`。
- PostgreSQL 18, [`UPDATE`](https://www.postgresql.org/docs/current/sql-update.html)：定义条件更新、command tag 计数与 `RETURNING`。
