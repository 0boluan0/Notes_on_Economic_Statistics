# The invariant principle
<!-- bilingual-en:end -->

不变量原理

<!-- bilingual-en:start -->
An **invariant proof** shows that a process cannot leave a region described by a property: it starts inside that region, and every allowed step keeps it inside. The property may say “the balance is nonnegative” or “the coordinate sum is even.” The numerical state can change; what stays true is the statement about that state.
<!-- bilingual-en:end -->

**不变量证明**说明过程不会离开由某个性质描述的区域：起点在区域内，每一步允许的转移也留在区域内。性质可以是“余额非负”或“坐标和为偶数”。数值状态可以改变，保持的是关于状态的陈述为真。

<!-- bilingual-en:start -->
We use the [[状态机与可达性|state-machine model]]: $S$ is the set of states, $s_0$ the start, and $q\to r$ an allowed step. A **predicate** $P$ is a statement that has a truth value once a state is supplied: $P(q)$ is either true or false. For example, with integer-coordinate states $q=(x,y)$, the predicate “$x+y$ is even” is true at $(1,1)$ and false at $(1,0)$. The [[命题与谓词|proposition–predicate distinction]] explains this use of an input-dependent statement.
<!-- bilingual-en:end -->

使用[[状态机与可达性|状态机模型]]：$S$ 是状态集合，$s_0$ 是起点，$q\to r$ 是允许的一步。**谓词** $P$ 是在给定状态后具有确定真值的陈述，$P(q)$ 因而有真值。例如，对整数坐标状态 $q=(x,y)$，谓词“$x+y$ 为偶数”在 $(1,1)$ 为真，在 $(1,0)$ 为假。[[命题与谓词|命题与谓词的区别]]解释了这种依赖输入的陈述。

## Initialization and preservation
<!-- bilingual-en:end -->

初始化与保持性

<!-- bilingual-en:start -->
> [!theorem] The invariant principle
> For a predicate $P$ on states, first prove that $P$ holds at the start state. Then prove for every allowed transition $q\to r$ that $P(q)\Rightarrow P(r)$. Induction on execution length then shows that $P$ holds at every reachable state. These obligations are initialization and preservation.
<!-- bilingual-en:end -->

> [!theorem] 不变量原理
> 对状态谓词 $P$，先证明 $P$ 在起始状态成立；再对任意允许转移 $q\to r$ 证明 $P(q)\Rightarrow P(r)$。于是按执行长度归纳，$P$ 对每个可达状态成立。这两项分别叫初始化与保持性。

<!-- bilingual-en:start -->
There are two distinct obligations:

- **Initialization:** $P(s_0)$ is true.
- **Preservation:** for every allowed pair $q\to r$, if $P(q)$ is true, then $P(r)$ is true.

A transition whose starting state fails $P$ does not violate this implication. The claim is that no transition can lead **from a $P$-state to a non-$P$-state**. MIT calls preservation alone a *preserved invariant*; other texts use “invariant” for a property true on all reachable states. Here we keep the proof obligation and its conclusion distinct. Checking all $P$-states avoids assuming in advance which states are reachable.
<!-- bilingual-en:end -->

两个义务彼此不同：

- **初始化：** $P(s_0)$ 为真。
- **保持性：** 对每条允许转移 $q\to r$，若 $P(q)$ 为真，则 $P(r)$ 也为真。

一条从不满足 $P$ 的状态出发的转移，不会违反这个蕴含式。要求是没有转移会**从满足 $P$ 的状态走到不满足 $P$ 的状态**。MIT 将单独的保持性称为 *preserved invariant*；其他教材也用“不变量”指所有可达状态都满足的性质。这里区分证明义务与得到的结论。对所有满足 $P$ 的状态检查保持性，避免事先假定哪些状态可达。

<!-- bilingual-en:start -->
## Why it covers every execution
<!-- bilingual-en:end -->

为什么覆盖所有执行

<!-- bilingual-en:start -->
The proof uses [[普通数学归纳法|ordinary induction]] on the number of transitions. Let $Q(k)$ mean: every state reachable in exactly $k$ transitions satisfies $P$.

At $k=0$, the only endpoint is $s_0$, so initialization proves $Q(0)$. Now assume $Q(k)$, and choose any legal execution of $k+1$ transitions. Its penultimate state $q$ is reachable in $k$ transitions and hence satisfies $P(q)$. The last step $q\to r$ preserves $P$, giving $P(r)$. This proves $Q(k+1)$ for every such execution, not just for one chosen route.

Every reachable state is the endpoint of some finite execution prefix, so the induction proves the conclusion. It also covers every position of an infinite execution: each position has a finite index. No assumption that the state set is finite or that the process terminates is needed.
<!-- bilingual-en:end -->

证明对转移次数使用[[普通数学归纳法]]。令 $Q(k)$ 表示：每个恰好经过 $k$ 次转移可达的状态都满足 $P$。

当 $k=0$ 时，唯一终点是 $s_0$，初始化便证明了 $Q(0)$。现在假设 $Q(k)$，任取一条有 $k+1$ 次转移的合法执行。其倒数第二个状态 $q$ 在 $k$ 步可达，因此满足 $P(q)$。最后一步 $q\to r$ 保持 $P$，所以得到 $P(r)$。这证明了所有此类执行的 $Q(k+1)$，而不是只证明某一条选定路线。

每个可达状态都是某个有限执行前缀的终点，所以归纳得到结论。这也覆盖无限执行的每个位置，因为每个位置都有有限下标。不需要假定状态集合有限，也不需要假定过程会终止。

## A robot that cannot reach an odd sum
<!-- bilingual-en:end -->

机器人与偶数坐标和

<!-- bilingual-en:start -->
If every robot move changes the coordinate sum by $0$ or $\pm2$, and the start-state sum is $0$, then “the coordinate sum is even” is initialized and preserved. Hence every state with an odd coordinate sum is unreachable.
<!-- bilingual-en:end -->

若机器人每步都让坐标和改变 $0$ 或 $\pm2$，而初态坐标和为 $0$，则“坐标和为偶数”在起点成立并被每一步保持。因此坐标和为奇数的状态都不可达。

<!-- bilingual-en:start -->
Make the moves explicit: from $(x,y)\in\mathbb Z^2$, the robot may move to $(x+1,y+1)$, $(x+1,y-1)$, $(x-1,y+1)$, or $(x-1,y-1)$. Their changes to $x+y$ are respectively $2,0,0,-2$. The start $(0,0)$ has even sum, and each of the four move types preserves evenness. Therefore $(1,0)$ is unreachable. We checked the four **rule types**, so the argument applies at every state; inspecting four particular journeys would not establish this universal claim.
<!-- bilingual-en:end -->

把动作写清楚：从 $(x,y)\in\mathbb Z^2$ 可以走到 $(x+1,y+1)$、$(x+1,y-1)$、$(x-1,y+1)$ 或 $(x-1,y-1)$。它们使 $x+y$ 分别变化 $2,0,0,-2$。起点 $(0,0)$ 的坐标和为偶数，四类动作都保持偶性，因此 $(1,0)$ 不可达。这里检查的是四类**转移规则**，所以适用于每个状态；只查看四条具体旅程并不能证明这个全称结论。

## Boundaries
<!-- bilingual-en:end -->

## 边界

<!-- bilingual-en:start -->

&nbsp;
**1.** Checking $P$ only at the start is insufficient. Preservation must cover every allowed transition, including every branch of a nondeterministic system.<br>
**2.** A preserved predicate that is false initially does not yield a property of all reachable states. Conversely, observing the property on several sample executions does not replace a general preservation proof.<br>
<!-- bilingual-en:end -->

- 只在起点检查 $P$ 不够；必须覆盖每一种允许转移，包括非确定系统中的所有分支。
- 一个保持性谓词若在起点为假，不能借不变量原理推出可达状态满足它；反过来，偶然在若干样例执行中成立也不能替代一般保持性证明。

<!-- bilingual-en:start -->
Satisfying the invariant is generally only a **necessary** condition for reachability. In a different machine with states the nonnegative integers, start $0$, and sole rule $q\to q+2$, “$q$ is an integer” is initialized and preserved. State $1$ satisfies that property but is unreachable. Nor does an invariant prove termination: this same machine runs forever while preserving integrality. To obtain an answer-correctness statement, a suitable invariant must be combined with the exit condition to imply the required result; that is the separate [[不变量与部分正确性|partial-correctness step]].
<!-- bilingual-en:end -->

满足不变量通常只是可达的**必要条件**。换一个机器：状态为非负整数，起点为 $0$，唯一规则为 $q\to q+2$。“$q$ 为整数”在起点成立并被保持，但状态 $1$ 虽满足它，仍不可达。不变量也不证明终止：同一机器会永远运行，同时保持整数性质。要得到“输出答案正确”，还必须让合适的不变量与退出条件共同推出要求的结果；这是单独的[[不变量与部分正确性|部分正确性步骤]]。

<!-- bilingual-en:start -->
> [!question]- Check every rule
> You proved $P$ at the start state and checked that three of four transition rules preserve it. May you conclude that all reachable states satisfy $P$?
>
> **Answer:** No. The unchecked fourth rule may carry a reachable $P$-state to a state violating $P$. Preservation must cover every allowed transition.
<!-- bilingual-en:end -->

> [!question]- 回忆与应用
> 你已证明 $P$ 在初态成立，也验证了四条转移规则中的三条都保持 $P$。能否宣布 $P$ 对所有可达状态成立？
>
> **答案：** 不能。未检查的第四条规则可能把满足 $P$ 的可达状态带到不满足 $P$ 的状态；保持性必须覆盖全部允许转移。
