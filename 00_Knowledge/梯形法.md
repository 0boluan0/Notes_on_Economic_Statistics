# The trapezoidal rule
<!-- bilingual-en:end -->

*梯形法*

<!-- bilingual-en:start -->
Suppose we know a real-valued function's values at several points and want the total accumulated between them. The **trapezoidal rule** joins neighbouring graph points with straight segments and integrates that broken line. It replaces the unknown shape between two samples with a simple shape whose integral we can calculate. The target is the [[定积分|definite integral]], which keeps negative contributions as well as positive ones.
<!-- bilingual-en:end -->

如果知道一个实值函数在几个点的取值，怎样估计这些点之间累积的总量？**梯形法**把相邻的图像点用直线段连接起来，再对这条折线积分。它用容易计算的形状，替代两个采样点之间尚未掌握的曲线形状。目标是[[定积分]]，因此既保留正贡献，也保留负贡献。

<!-- bilingual-en:start -->
## Start with one strip
<!-- bilingual-en:end -->

*先看一小条*

<!-- bilingual-en:start -->
On a finite interval $[u,v]$ with $u<v$, let $h=v-u$ be its width. The straight line through the two sampled heights is
$$\ell(x)=f(u)+\frac{f(v)-f(u)}h(x-u).$$
Here $\ell$ names the replacement line: it starts at $f(u)$ and changes at a constant rate until reaching $f(v)$. Integrating this affine expression gives
$$\int_u^v\ell(x)\,dx
=hf(u)+\frac{h}{2}[f(v)-f(u)]
=\frac h2[f(u)+f(v)].$$
Thus the contribution is **width times average endpoint height**. For nonnegative heights this is the area of a trapezoid. The algebra also works when a height is negative or the line crosses zero; in that case it is a signed contribution.
<!-- bilingual-en:end -->

在有限区间 $[u,v]$ 上，设 $u<v$，宽度为 $h=v-u$。上式中的 $\ell$ 是替代曲线的直线：从高度 $f(u)$ 出发，以固定变化率到达 $f(v)$。对这个一次表达式积分，得到**宽度乘两端高度的平均数**。两端高度非负时，这是梯形面积；如果高度为负，或者直线穿过零点，公式仍成立，只是结果表示带符号的贡献。

<!-- bilingual-en:start -->
If the original function already has the form $f(x)=mx+c$ with constant slope $m$ and intercept $c$, the replacement line is the function itself, so the rule is exact. For a curved graph it is generally only an approximation; matching the endpoints does not determine everything between them.
<!-- bilingual-en:end -->

如果原函数本来就是斜率 $m$、截距 $c$ 固定的 $f(x)=mx+c$，替代直线就是函数本身，因此梯形法给出精确值。对一般曲线，它通常只是近似；知道两端高度并不能确定中间的全部形状。

<!-- bilingual-en:start -->
## Assemble a common grid
<!-- bilingual-en:end -->

*把各段放到同一个网格上*

<!-- bilingual-en:start -->
Let $a<b$ be finite real endpoints and let $N\ge1$ be an integer counting **subintervals**, not sample points. Set
$$h=\frac{b-a}{N},\qquad x_i=a+ih\quad(i=0,1,\ldots,N).$$
The points $x_0=a,\ldots,x_N=b$ divide the interval into $N$ equal strips, so there are $N+1$ distinct endpoint locations. Adding their contributions defines the composite trapezoidal value $T_N$:
<!-- bilingual-en:end -->

设有限实端点满足 $a<b$，正整数 $N$ 计算的是**小区间数**，不是采样点数。令 $h=(b-a)/N$、$x_i=a+ih$，其中 $i=0,1,\ldots,N$。这些端点从 $x_0=a$ 到 $x_N=b$，共形成 $N$ 个等宽小区间，需要 $N+1$ 个不同位置的端点函数值。把每段贡献相加，定义复合梯形值 $T_N$：

$$\boxed{T_N=\sum_{i=1}^{N}\frac h2[f(x_{i-1})+f(x_i)]
=\frac h2\left[f(x_0)+2\sum_{i=1}^{N-1}f(x_i)+f(x_N)\right].}$$

<!-- bilingual-en:start -->
Every interior height appears twice, once in each neighbouring strip. The outer heights appear only once. This explains the weights $1,2,\ldots,2,1$, rather than leaving them as a formula to memorize. When $N=1$, the interior sum is empty and equals zero.
<!-- bilingual-en:end -->

每个内部端点的高度出现两次，分别属于相邻的左右两段；最外侧两个高度只出现一次。这就是权重 $1,2,\ldots,2,1$ 的来源，不必把它当作孤立公式死记。$N=1$ 时没有内部端点，中间的空和按零处理。

<!-- bilingual-en:start -->
The [[左右端点矩形法|left- and right-endpoint rectangle rules]] use one endpoint height throughout each strip. On this same grid they give
$$L_N=h\sum_{i=1}^Nf(x_{i-1}),\qquad R_N=h\sum_{i=1}^Nf(x_i),\qquad T_N=\frac{L_N+R_N}{2}.$$
The last equality is exact algebra, not an error estimate. Using different grids for the two rectangle sums would not give this identity for the stated $T_N$.
<!-- bilingual-en:end -->

[[左右端点矩形法]]分别用每段左端、右端的高度代表整段。在同一网格上，它们给出上式中的 $L_N,R_N$，而 $T_N$ 恰好是二者的平均。这是精确的代数恒等式，不是误差估计；如果左右和用了不同网格，就不能这样得到当前网格的 $T_N$。

> [!example] Two strips for a reciprocal · 倒数函数的两段近似
> <!-- bilingual-en:start -->
> For $\int_1^2(1/x)\,dx$, choose $N=2$. Then $h=1/2$ and the sample locations are $1,3/2,2$, with heights $1,2/3,1/2$. Hence
> $$T_2=\frac14\left(1+2\cdot\frac23+\frac12\right)=\frac{17}{24}\approx0.708333.$$
> Here the exact integral happens to be $\ln2\approx0.693147$, so this approximation is about $0.015186$ too large. The rule itself did not need an antiderivative to produce its answer.
> <!-- bilingual-en:end -->
>
> 对 $\int_1^2(1/x)\,dx$ 取 $N=2$，段宽为 $1/2$，三个采样位置是 $1,3/2,2$，对应高度为 $1,2/3,1/2$。代入得到 $T_2=17/24\approx0.708333$。这个例子恰好知道真值 $\ln2\approx0.693147$，所以近似值高出约 $0.015186$；梯形法本身并不需要先求原函数才能给出答案。

## Refinement and what it promises
<!-- bilingual-en:end -->

*细分网格能保证什么*

<!-- bilingual-en:start -->
If $f$ is continuous on $[a,b]$, [[连续函数可积|its Riemann integral exists]], and both endpoint [[黎曼和|Riemann sums]] $L_N,R_N$ approach it as $N\to\infty$. Their average therefore approaches the same integral. More generally, this reasoning works for every Riemann-integrable $f$. Computing one finite $T_N$ only requires the displayed sample values to exist; an accuracy guarantee requires further information about the function between them.
<!-- bilingual-en:end -->

若 $f$ 在 $[a,b]$ 上连续，由[[连续函数可积]]可知其黎曼积分存在；左右端点[[黎曼和]]都在 $N\to\infty$ 时趋于它，二者的平均也就趋于同一个积分。更一般地，这个论证适用于每个黎曼可积的 $f$。算出某个有限的 $T_N$，只要求相应采样值存在；要保证精度，还须知道采样点之间函数的行为。

<!-- bilingual-en:start -->
The [[梯形积分误差界|trapezoidal error bound]] supplies a quantitative guarantee from a bound on the second derivative throughout the interval. Continuity alone does not supply that derivative bound or a particular $N$ for a chosen accuracy. For unequal widths, retain the strip-by-strip formula $\sum_i (x_i-x_{i-1})[f(x_{i-1})+f(x_i)]/2$; the single common factor $h$ is no longer available. For reversed limits, compute in increasing order and negate the result; a zero-length interval has integral zero.
<!-- bilingual-en:end -->

[[梯形积分误差界]]利用全区间上的二阶导数界给出定量保证；仅有连续性，并不能提供这个导数界，也不能直接给出达到某个精度所需的 $N$。段宽不等时，保留逐段公式 $\sum_i(x_i-x_{i-1})[f(x_{i-1})+f(x_i)]/2$，不能再提出统一的 $h$。上下限反向时，先按递增方向计算再取负；零长度区间的积分为零。

> [!tip] Check the constant function · 用常数函数检查权重
> <!-- bilingual-en:start -->
> For $f(x)=1$, the weights add to $1+2(N-1)+1=2N$. Multiplying by $h/2$ gives $Nh=b-a$, exactly the integral. A formula failing this check has incorrect weights or scale.
> <!-- bilingual-en:end -->
>
> 令 $f(x)=1$，权重之和为 $1+2(N-1)+1=2N$，再乘 $h/2$ 得到 $Nh=b-a$，恰好就是积分值。若某个公式连这个检查都过不了，权重或外侧系数就有错误。
