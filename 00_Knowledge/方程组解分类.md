# How many solutions does Ax = b have?
<!-- bilingual-en:end -->
*方程组的解如何分类？*

<!-- bilingual-en:start -->
Solving a linear system asks for inputs that produce a specified output. There are two questions to answer in order: **can the matrix produce this target at all, and if so, can different inputs produce it?** The [[列空间|column space]] answers the first; the [[零空间|null space]] answers the second. Keeping these questions separate prevents “at most one” from being mistaken for “exactly one.”
<!-- bilingual-en:end -->

解线性方程组，就是寻找能产生指定输出的输入。要依次回答两个问题：**矩阵能否产生这个目标；如果能，不同输入能否产生同一目标？** [[列空间]]回答第一个，[[零空间]]回答第二个。分清二者，才能避免把“至多一个”误当成“恰好一个”。

<!-- bilingual-en:start -->
Start with the real matrix
<!-- bilingual-en:end -->

先看实矩阵

$$A=\begin{pmatrix}1&1\\0&0\end{pmatrix},\qquad
Ax=\begin{pmatrix}x_1+x_2\\0\end{pmatrix}.$$

<!-- bilingual-en:start -->
The target $b=(3,0)^T$ is reachable: $(3,0)^T$ and $(2,1)^T$ both work. In fact $(3-t,t)^T$ works for every real $t$. But $b=(3,1)^T$ is unreachable, because the second output is always zero. Thus one fixed matrix can give either no solutions or many, depending on the target. The superscript $T$ is [[矩阵转置|transpose]], used to write a list as a column.
<!-- bilingual-en:end -->

目标 $b=(3,0)^T$ 能达到：$(3,0)^T$、$(2,1)^T$ 都是解；实际上，每个实数 $t$ 都给出一个解 $(3-t,t)^T$。但 $b=(3,1)^T$ 到不了，因为第二个输出始终是零。同一个矩阵，可以随目标不同而无解或多解。上标 $T$ 表示[[矩阵转置|转置]]，用于把列表写成列。

## First existence, then uniqueness
<!-- bilingual-en:end -->
*先判断存在，再判断唯一*

<!-- bilingual-en:start -->
Let $A\in\mathbb F^{m\times n}$, with positive integers $m,n$, and let the target $b\in\mathbb F^m$. The scalar field $\mathbb F$ specifies the allowed numbers, commonly $\mathbb R$ or $\mathbb C$; inputs belong to $\mathbb F^n$. The column space $C(A)=\{Ax:x\in\mathbb F^n\}$ contains all reachable targets. The null space $N(A)=\{z:Az=0\}$ contains input changes that leave the output unchanged. A system is **consistent** if it has at least one solution.
<!-- bilingual-en:end -->

设 $A\in\mathbb F^{m\times n}$，其中 $m,n$ 为正整数，目标 $b\in\mathbb F^m$。标量域 $\mathbb F$ 指定允许使用的数，通常是 $\mathbb R$ 或 $\mathbb C$；输入属于 $\mathbb F^n$。列空间 $C(A)=\{Ax:x\in\mathbb F^n\}$ 收集全部可达目标；零空间 $N(A)=\{z:Az=0\}$ 收集不改变输出的输入变化。方程组**相容**，就是至少有一个解。

> [!important] The three cases · 三种情形
> <!-- bilingual-en:start -->
> | Is the target reachable? | Can a nonzero input change disappear? | Number of solutions |
> |---|---|---|
> | $b\notin C(A)$ | Either possibility | None |
> | $b\in C(A)$ | $N(A)=\{0\}$ | Exactly one |
> | $b\in C(A)$ | $N(A)\ne\{0\}$ | More than one; infinitely many over $\mathbb R$ or $\mathbb C$ |
> <!-- bilingual-en:end -->
>
> | 目标是否可达？ | 非零输入变化能否被消去？ | 解数 |
> |---|---|---|
> | $b\notin C(A)$ | 两种都可能 | 无解 |
> | $b\in C(A)$ | $N(A)=\{0\}$ | 恰有一个 |
> | $b\in C(A)$ | $N(A)\ne\{0\}$ | 多个；在 $\mathbb R$ 或 $\mathbb C$ 上无穷多个 |

<!-- bilingual-en:start -->
The existence test is the definition of $C(A)$. For uniqueness, if $x_1,x_2$ solve the same equation, then $A(x_1-x_2)=b-b=0$. A trivial null space therefore forces $x_1=x_2$. Conversely, if one solution $x_p$ exists and a nonzero $z$ satisfies $Az=0$, both $x_p$ and $x_p+z$ solve the equation. The complete family is [[特解加零空间|one particular solution plus the null space]].
<!-- bilingual-en:end -->

存在性判据就是 $C(A)$ 的定义。对唯一性，若 $x_1,x_2$ 解同一方程，则 $A(x_1-x_2)=b-b=0$；零空间只有零向量，就迫使 $x_1=x_2$。反过来，若已有一个解 $x_p$，又有非零 $z$ 满足 $Az=0$，那么 $x_p$、$x_p+z$ 都是解。完整的一族见[[特解加零空间]]。

## What rank says about every target
<!-- bilingual-en:end -->
*秩怎样描述所有目标的情况*

<!-- bilingual-en:start -->
The [[矩阵秩|rank]] $r=\dim C(A)$ counts independent output directions. The [[秩零度定理|rank–nullity theorem]] gives $\dim N(A)=n-r$. These dimensions translate the two tests into reusable rules.
<!-- bilingual-en:end -->

[[矩阵秩|秩]] $r=\dim C(A)$ 计数独立的输出方向；[[秩零度定理]]给出 $\dim N(A)=n-r$。这些维数把前面的两个判据变成可重复使用的规则。

<!-- bilingual-en:start -->
**Full column rank**, $r=n$, makes $N(A)=\{0\}$. Every target has at most one solution, but some targets may be unreachable. For example, $A=(1,0)^T$ maps a scalar $x$ to $(x,0)^T$. The target $(3,0)^T$ has the unique solution $x=3$, while $(3,1)^T$ has none. This is the recovery property behind a [[左逆与满列秩|left inverse]].
<!-- bilingual-en:end -->

**满列秩** $r=n$ 使 $N(A)=\{0\}$：每个目标至多有一个解，但有些目标可能到不了。例如 $A=(1,0)^T$ 把标量 $x$ 映成 $(x,0)^T$；目标 $(3,0)^T$ 唯一解为 $x=3$，$(3,1)^T$ 则无解。这是[[左逆与满列秩|左逆]]背后的输入恢复性质。

<!-- bilingual-en:start -->
**Full row rank**, $r=m$, makes $C(A)=\mathbb F^m$, so every target has at least one solution. If $n>m$, the nullity is $n-m>0$ and every target has multiple solutions. For instance, $A=(1\ \ 0)$ sends $(x_1,x_2)^T$ to $x_1$: for any scalar target $b$, all $(b,t)^T$ are solutions. This reachability property corresponds to a [[右逆与满行秩|right inverse]].
<!-- bilingual-en:end -->

**满行秩** $r=m$ 使 $C(A)=\mathbb F^m$，所以每个目标至少有一个解。若 $n>m$，零度为 $n-m>0$，每个目标都有多解。例如 $A=(1\ \ 0)$ 把 $(x_1,x_2)^T$ 送到 $x_1$；对任何标量目标 $b$，所有 $(b,t)^T$ 都是解。这种可达性对应[[右逆与满行秩|右逆]]。

<!-- bilingual-en:start -->
Every target has exactly one solution precisely when both properties hold, which requires $r=m=n$: an [[逆矩阵|invertible]] square matrix. Being square alone is insufficient, as the opening example shows. Having more equations or more unknowns does not by itself determine the answer for a specified $b$; the actual rank and target membership still matter.
<!-- bilingual-en:end -->

每个目标都恰有一个解，当且仅当这两种性质同时成立，即 $r=m=n$：矩阵是[[逆矩阵|可逆]]方阵。仅仅是方阵不够，开头的例子已经说明这一点。方程更多或未知数更多，本身不能决定给定 $b$ 的解数；仍须检查实际秩和目标是否属于列空间。

> [!warning] Multiple need not mean infinitely many · 多解未必无穷
> <!-- bilingual-en:start -->
> If $x_p$ is a solution and $z\ne0$ lies in $N(A)$, distinct scalars $t$ give distinct solutions $x_p+tz$. An infinite field therefore gives infinitely many. Over a finite field with $q$ elements, a consistent system has exactly $q^d$ solutions, where $d=\dim N(A)$: choose $d$ basis coefficients freely. For example, over $\mathbb F_2=\{0,1\}$ with addition modulo $2$, $x_1+x_2=1$ has just $(1,0)$ and $(0,1)$. It has a nontrivial null space without infinitely many solutions.
> <!-- bilingual-en:end -->
>
> 若 $x_p$ 是一个解，且非零 $z\in N(A)$，不同标量 $t$ 给出不同解 $x_p+tz$，所以无限域上有无穷多解。若有限域含 $q$ 个元素，相容系统恰有 $q^d$ 个解，其中 $d=\dim N(A)$：一组零空间基的 $d$ 个系数可自由选择。例如在按模 $2$ 加法计算的 $\mathbb F_2=\{0,1\}$ 上，$x_1+x_2=1$ 只有 $(1,0)$、$(0,1)$ 两个解；零空间非平凡，却没有无穷多个解。
