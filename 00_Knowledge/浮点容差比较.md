# 容差比较必须同时说明相对尺度与近零绝对边界

<!-- bilingual-en:start -->
*Tolerance comparison must specify relative scale and an absolute near-zero boundary*
<!-- bilingual-en:end -->

> [!summary] 原子决策规则
> Python 的 `math.isclose(a, b, rel_tol=r, abs_tol=s)` 在
> $$|a-b|\le\max\{r\max(|a|,|b|),s\}$$
> 时返回 `True`。`rel_tol` 让允许差异随数值尺度变化；`abs_tol` 给接近零时的最小绝对边界。两者都应由问题的单位、误差预算和失败代价决定，而不是因为“浮点不精确”随手选一个小数。
>
> <!-- bilingual-en:start -->
> Python's `math.isclose(a, b, rel_tol=r, abs_tol=s)` returns `True` when
> $|a-b|\le\max\{r\max(|a|,|b|),s\}$. `rel_tol` scales the allowed difference with magnitude; `abs_tol` supplies a minimum absolute boundary near zero. Both must come from domain units, an error budget, and the cost of failure—not from an arbitrary small constant chosen merely because floats are inexact.
> <!-- bilingual-en:end -->

若比较 `x` 与 0 且只使用小于 1 的相对容差，条件退化为 $|x|\le r|x|$，任何非零 `x` 都不会通过；因此近零比较需要有意义的 `abs_tol`。但把 `abs_tol` 设得过大又会吞掉本应显著的差异，所以 Python 默认把它设为 0，而不猜测通用尺度。
<!-- bilingual-en:start -->
When comparing nonzero `x` with zero using only a relative tolerance below 1, the test reduces to $|x|\le r|x|$ and always fails. A meaningful `abs_tol` is therefore needed near zero. But an overly large absolute tolerance hides important differences, which is why Python defaults it to zero rather than guessing a universal scale.
<!-- bilingual-en:end -->

`math.isclose` 不是自动正确性证明。它不替代误差传播分析、单位测试规格或 ULP 级验证；NaN 与任何值都不 close，正负无穷只与自身 close。对于已知参考值的单向误差预算，还可能需要直接按参考值定义不对称区间，而不是使用对称 `isclose`。
<!-- bilingual-en:start -->
`math.isclose` is not an automatic proof of correctness. It does not replace error-propagation analysis, a unit-test specification, or ULP-level validation. NaN is close to nothing, while each infinity is close only to itself. A one-sided budget against a known reference may require an explicitly asymmetric interval rather than symmetric `isclose`.
<!-- bilingual-en:end -->

> [!question]- 回忆与应用
> 为什么 `math.isclose(x, 0.0)` 的默认参数通常不能判定一个非零量“足够接近零”？
>
> **答案：** 默认 `abs_tol=0.0`；只靠小于 1 的相对容差，非零 `x` 无法满足与零的相对比较，必须给出领域相关的绝对容差。
