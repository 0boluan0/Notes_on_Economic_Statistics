# Statistic
<!-- bilingual-en:end -->

*统计量*

<!-- bilingual-en:start -->
A **statistic** is a specified rule that turns observed data into a value. For the three observations $2,5,8$, the rule “take the average” gives $5$, and “take the largest” gives $8$. Both use the data we have. The rule must not require an unknown population quantity as an extra input.
<!-- bilingual-en:end -->

**统计量**是一条把观察数据转换成数值或其他结果的明确规则。给定三个观察 $2,5,8$，“取平均”得到 $5$，“取最大值”得到 $8$，两者都只使用已经拿到的数据。计算规则不能额外要求输入一个尚未知晓的总体量。

^core

<!-- bilingual-en:start -->
## The rule and its observed value
<!-- bilingual-en:end -->

*计算规则与本次结果*

<!-- bilingual-en:start -->
Write a [[总体与样本|sample]] before observation as $X_1,\ldots,X_n$, where $n$ is its size. If $g$ is the calculation rule, the statistic is
$$T_n=g(X_1,\ldots,X_n).$$
After seeing values $x_1,\ldots,x_n$, the realized value is $t_n=g(x_1,\ldots,x_n)$. Uppercase notation emphasizes the random object before observation; lowercase emphasizes the result after the data are fixed. The same rule can yield different results for different samples.
<!-- bilingual-en:end -->

观察前，把[[总体与样本|样本]]写成 $X_1,\ldots,X_n$，$n$ 是样本量，$g$ 是计算规则，则统计量为 $T_n=g(X_1,\ldots,X_n)$。看到具体数值 $x_1,\ldots,x_n$ 后，结果为 $t_n=g(x_1,\ldots,x_n)$。大写强调观察前的随机对象，小写强调数据固定后的实现值；同一个规则遇到不同样本，可以得到不同结果。

<!-- bilingual-en:start -->
Formally, $g$ must be **measurable**, so statements such as “$T_n$ is at most $5$” correspond to events to which the probability model can assign probabilities. This is the same requirement that makes a [[随机变量|random variable]] a valid probability object. For the real-valued sample here, sums, averages and maxima satisfy it. The definition of a statistic does not itself require iid observations or a normal distribution.
<!-- bilingual-en:end -->

严格地说，$g$ 必须**可测**，使“$T_n$ 不超过 $5$”之类的说法对应概率模型能够赋予概率的事件。这与[[随机变量]]成为合法概率对象的要求相同。对这里的实数样本，求和、平均、最大值都满足要求。统计量的定义本身不要求观测 iid，也不要求正态分布。

> [!example] Compute from the same three observations · 对同一份数据计算
> <!-- bilingual-en:start -->
> For $(x_1,x_2,x_3)=(2,5,8)$,
> $$\bar x_3=\frac{2+5+8}{3}=5,\qquad \max_i x_i=8.$$
> The constant rule $g(x_1,x_2,x_3)=7$ is also a statistic: it always returns $7$, even though it discards the data. A statistic can also return several numbers, such as $(\bar x_3,\max_i x_i)=(5,8)$. Thus neither usefulness nor reduction to one scalar is part of the general definition.
> <!-- bilingual-en:end -->
>
> 给定 $(2,5,8)$，平均数为 $5$，最大值为 $8$。恒等于 $7$ 的规则也是统计量，因为无论数据怎样都能算出 $7$，尽管它把数据完全丢掉。统计量还可以返回多个数，比如“平均数与最大值”这对结果 $(5,8)$。因此，是否有用、是否只输出一个标量，都不是一般定义的要求。

## Unknown parameters are different from known reference values
<!-- bilingual-en:end -->

*未知参数与已指定的参考值不同*

<!-- bilingual-en:start -->
Suppose the [[期望|population mean]] $\mu=E[X]$ exists but is unknown. The expression $\bar X_n-\mu$ describes an estimation error, but it is **not a statistic** in this model: data alone do not tell us which unknown $\mu$ to subtract. Its usefulness in a theoretical proof does not make its realized value observable.
<!-- bilingual-en:end -->

假设[[期望|总体均值]] $\mu=E[X]$ 存在却未知。$\bar X_n-\mu$ 描述估计误差，但在这个模型里**不是统计量**：只有数据，还不知道该减去哪个未知 $\mu$。它可以在理论证明中有用，却不因此变成能够直接观察和计算的结果。

<!-- bilingual-en:start -->
If a [[零假设与备择假设|null hypothesis]] specifies the known reference value $\mu_0=4$, the rule $T_n=\bar X_n-4$ is a statistic. For $(2,5,8)$ it equals $1$. Using a proposed reference value does not establish that the true mean equals it; it merely defines a computable comparison. The same distinction applies to any fixed known constant.
<!-- bilingual-en:end -->

若[[零假设与备择假设|零假设]]指定已知参考值 $\mu_0=4$，则 $T_n=\bar X_n-4$ 是统计量；对 $(2,5,8)$，结果为 $1$。使用一个假设参考值，并没有证明真实均值就等于它，只是规定了一个可计算的比较。其他固定已知常数也是同一道理。

<!-- bilingual-en:start -->
The rule can be known even when its **distribution** is unknown. For example, if $X_1,\ldots,X_n$ are iid with finite mean $\mu$, $E[\bar X_n]=\mu$, so the distribution of the sample mean can depend on the unknown population mean. The rule $g(x)=n^{-1}\sum_i x_i$ still uses no unknown parameter. This difference between a computable rule and its [[抽样分布|sampling distribution]] is central to statistical inference.
<!-- bilingual-en:end -->

计算规则已知，其**分布**仍可以未知。例如，若 $X_1,\ldots,X_n$ iid 且均值 $\mu$ 有限，则 $E[\bar X_n]=\mu$，样本均值的分布可以依赖未知总体均值；但 $g(x)=n^{-1}\sum_i x_i$ 的计算仍不需要未知参数。可计算规则与其[[抽样分布]]的区别，是统计推断的关键。

## When a statistic becomes an estimator
<!-- bilingual-en:end -->

*何时把统计量用作估计量*

<!-- bilingual-en:start -->
A statistic becomes an **estimator** when we use it as a rule for estimating a specified target. Calling the average an estimator of the population mean adds a purpose to the rule; the observed average is its **estimate**. The [[估计对象三分|estimand, estimator and estimate]] are therefore separate objects. A statistic may instead summarize data or help test a hypothesis. No name guarantees that it is accurate, unbiased, consistent or informative for the chosen target.
<!-- bilingual-en:end -->

当用一条统计量规则估计某个明确目标时，它就承担**估计量**的角色。把平均数用作总体均值的估计量，是给规则指定用途；实际算出的平均数则是**估计值**。[[估计对象三分|估计目标、估计量、估计值]]是不同对象。统计量也可以只是描述数据，或者用于检验假设；名称本身不保证它准确、无偏、一致，或对所选目标有信息。
