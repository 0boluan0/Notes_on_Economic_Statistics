# Forests
<!-- bilingual-en:end -->
*森林*

<!-- bilingual-en:start -->
A **forest** is an undirected graph with no cycles. It may form a single connected piece or several separate pieces: a forest can consist of one tree, several trees, isolated vertices, or nothing at all under the empty-graph convention below. The essential condition is the absence of cycles, not a requirement to be disconnected.
<!-- bilingual-en:end -->
**森林**是不含环的无向图。它可以连成一体，也可以分成互不相连的部分：可以是一棵树、若干棵树、一些孤立顶点，或按下文约定取空图。核心条件是没有环，并不是“必须不连通”。

<!-- bilingual-en:start -->
For example, take five vertices $a,b,c,d,e$ and only two edges, one joining $a$ to $b$ and one joining $c$ to $d$. There is no cycle, so this is a forest. Its three [[无向图连通分量|connected components]] are the two one-edge pieces and the isolated vertex $e$. A component is a whole group of vertices reachable from one another, together with their edges; the isolated vertex counts as a component too.
<!-- bilingual-en:end -->
例如，取五个顶点 $a,b,c,d,e$，只放两条边，分别连接 $a$ 与 $b$、$c$ 与 $d$。图中没有环，所以它是森林。三个[[无向图连通分量|连通分量]]分别是两块单边结构，以及孤立顶点 $e$。一个分量包含一整组互相可达的顶点及其内部的边；孤立顶点也算一个分量。

<!-- bilingual-en:start -->
## One condition, with no connectivity requirement
<!-- bilingual-en:end -->
*只要求无环，不要求连通*

<!-- bilingual-en:start -->
We work with finite undirected graphs $F=(V,E)$: $V$ denotes vertices and $E$ denotes edges. A [[游走路径与环|cycle]] is a positive-length closed route that repeats no edge and repeats no vertex except its first/last vertex. “Acyclic” means that no such route exists.
<!-- bilingual-en:end -->
本卡讨论有限无向图 $F=(V,E)$，其中 $V$ 表示顶点集合，$E$ 表示边集合。[[游走路径与环|环]]是正长度的闭合路线，不重复边，除首尾顶点相同外不重复顶点。“无环”就是不存在这样的路线。

> [!definition] Forest / 森林
> <!-- bilingual-en:start -->
> A finite undirected graph is a **forest** exactly when it is acyclic. Equivalently, each of its connected components is an [[无向树|undirected tree]]. We allow $V=E=\varnothing$: the empty forest has no components.
> <!-- bilingual-en:end -->
>
> 有限无向图**无环**时，称为**森林**。等价地，它的每个连通分量都是一棵[[无向树]]。本卡允许 $V=E=\varnothing$：空森林没有连通分量。

<!-- bilingual-en:start -->
The component description follows directly from the definitions. Each component is nonempty and connected. If the full graph has no cycle, no component has one, so each component is a tree. Conversely, a cycle would lie entirely inside one component; if every component is a tree, that cycle is impossible. For the empty forest there are no components to check.
<!-- bilingual-en:end -->
分量说法可直接从定义理解。每个分量都非空且连通；如果全图无环，分量中也没有环，所以每个分量都是树。反过来，一个环必然完全位于某个分量中；如果每个分量都是树，这样的环就不可能存在。空森林没有分量需要检查。

<!-- bilingual-en:start -->
Thus every tree is a forest, and every nonempty connected forest is a tree. An edgeless graph on $n$ vertices is a forest of $n$ isolated one-vertex trees, including $n=0$. The empty forest is not a tree, because the tree definition requires at least one vertex. Some texts define all graphs to have nonempty vertex sets; our explicit empty-forest convention extends that convention without changing any nonempty case.
<!-- bilingual-en:end -->
因此，每棵树都是森林，而非空的连通森林就是树。有 $n$ 个顶点、没有边的图是森林，由 $n$ 棵孤立的单顶点树组成，其中也允许 $n=0$。空森林不是树，因为树的定义要求至少一个顶点。有些教材规定所有图的顶点集合都非空；本卡明确允许空森林，是对此约定的扩展，不改变任何非空情形。

<!-- bilingual-en:start -->
If the [[图类型的建模边界|graph model]] permits self-loops or parallel edges, we count a loop as a one-cycle and two distinct parallel edges as a two-cycle. Neither can occur in a forest. Traversing the same edge out and back is different: it repeats that edge and is not a cycle.
<!-- bilingual-en:end -->
若[[图类型的建模边界|图模型]]允许自环或平行边，本卡把自环计为一环，把两条不同的平行边计为二环。森林不能包含这两种结构。沿同一条边往返则不同：它重复了边，不算环。

<!-- bilingual-en:start -->
## A forest inside another graph
<!-- bilingual-en:end -->
*从另一张图中选出的森林*

<!-- bilingual-en:start -->
Being a forest describes the selected graph itself. Being a **spanning forest of a given graph $G$** also describes how it covers $G$. Here “spanning forest” means retaining all vertices and choosing one spanning tree in each connected component of $G$; each chosen tree connects every vertex of that component. This is the componentwise-spanning, or maximal-forest, convention.
<!-- bilingual-en:end -->
“是森林”描述所选图自身的结构。“是给定图 $G$ 的**生成森林**”还要说明它如何覆盖 $G$。本卡所说的生成森林，指保留全部顶点，并在 $G$ 的每个连通分量内选出一棵覆盖该分量全部顶点的生成树。这是按原图分量生成、也称极大森林的约定。

<!-- bilingual-en:start -->
For the host path $a-b-c$, keeping all three vertices but selecting only the edge $a-b$ gives a forest, yet it fails this spanning-forest condition: $c$ has been separated from vertices that were connected to it in $G$. Adding the available edge $b-c$ connects them without creating a cycle. A maximal forest allows no further edge **from the host graph** to be added while remaining acyclic; merely selecting some edges without cycles does not ensure maximality.
<!-- bilingual-en:end -->
以原图路径 $a-b-c$ 为例：保留三个顶点，却只选边 $a-b$，得到的确实是森林，但不满足这里的生成森林条件，因为 $c$ 被同一原分量中的其他顶点隔开了。加入原图中已有的边 $b-c$，仍然无环，却恢复了连接。极大森林指不能再加入任何一条**原图中的边**而仍保持无环；任意选一些不成环的边，并不自动达到极大。

<!-- bilingual-en:start -->
The separate [[Forest 的边数公式|forest edge-count theorem]] explains why the number of selected edges equals the number of vertices minus the number of components of the forest. When checking a spanning forest, distinguish those selected components from the host graph's components: in a spanning forest they must coincide.
<!-- bilingual-en:end -->
独立的 [[Forest 的边数公式|森林边数定理]]解释了为什么森林的边数等于顶点数减去自身的分量数。检验生成森林时，要分清所选森林的分量与原图的分量：生成森林要求两者一致。

## 来源与核验

- [[01_Math/07-Mathematics for Computer Science/MIT-6-042j-pdf.pdf#page=535|MIT Mathematics for Computer Science, §12.11, Definition 12.11.1, PDF 535–537]]: forests are acyclic undirected graphs, their components are trees, and isolated vertices are included. - [[01_Math/07-Mathematics for Computer Science/MIT-6-042j-pdf.pdf#page=535|MIT Mathematics for Computer Science，§12.11，定义 12.11.1，PDF 535–537]]：支持森林是无环无向图、各分量是树，以及孤立顶点也计入。PDF 510 的定义 12.1.1 要求顶点集合非空；空森林是本卡明确采用的扩展约定。
- [Richard Stanley，Topics in Algebraic Combinatorics，§11.2，PDF 170（印刷页 211）](https://math.mit.edu/~rstan/algcomb/algcomb.pdf#page=170)：支持森林由互不相交的树组成，极大森林在原图每个分量中都是生成树。第 9 章 PDF 135 提供不重复边的环与平行边约定，第 1 章 PDF 7–8 定义自环。
