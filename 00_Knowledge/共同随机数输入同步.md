# 共同随机数只有在两个方案把共享输入解释为同一冲击时才形成有意义的成对比较
<!-- bilingual-en:start -->
*Common random numbers form a meaningful paired comparison only when both alternatives interpret each shared input as the same shock*
<!-- bilingual-en:end -->

> [!summary] 相同 seed 不等于相同场景
> 成对比较要求两个方案中的同一输入维度代表同一时间、同一事件和同一类冲击。若调用顺序已错位，数值上来自同一随机流也不再等于共享同一场景。
> <!-- bilingual-en:start -->
> A paired comparison requires the same input dimension to represent the same time, event, and kind of shock in both alternatives. Once call order is misaligned, values drawn from the same random stream no longer constitute the same scenario.
> <!-- bilingual-en:end -->

假设方案 A 在每个月份先抽需求、再抽交付时间。若方案 B 在库存为零时额外抽一次加急运输，随后 B 的“需求”可能会消费 A 用作“交付时间”的下一个随机数。两者即使从同一 seed 开始，后续也已不是逐场景对比。
<!-- bilingual-en:start -->
Suppose both policies draw monthly demand and delivery time, but policy B makes an extra emergency-shipping draw after a stockout. Subsequent positions in the raw stream can then represent different shocks across policies even though both runs started from the same seed.
<!-- bilingual-en:end -->

稳健的实现方式包括：

- 先生成完整外生场景，再让两个方案读取同一份场景；
- 按冲击类型分配命名子流，使条件分支不会推进其他类型的随机状态；
- 每次复制都从记录的子流起点开始，并验证两个方案的输入标识而不只是数组位置。

<!-- bilingual-en:start -->
Robust implementations pre-generate exogenous scenarios, allocate named streams by shock type, or restart each replication from a recorded substream boundary. Pairing should be checked by semantic input identifiers rather than by raw array position alone.
<!-- bilingual-en:end -->

输入对齐只保证“比的是同一冲击”。它不保证成对输出正相关，所以是否降低差值方差还要另查 [[配对方差缩减的协方差方向]]。
<!-- bilingual-en:start -->
Semantic alignment establishes that the alternatives face the same shocks. It does not guarantee positive output covariance, so variance reduction remains a separate question.
<!-- bilingual-en:end -->

> [!question]- 可核验自检
> 两个方案使用同一 seed，但其中一个方案在条件分支中多抽一次数。为什么不能继续假定后续输入成对？
>
> **答案：** 额外调用改变了随机状态的消耗位置；后续数值可能已代表不同冲击。
> <!-- bilingual-en:start -->
> The extra call shifts state consumption, so later values can represent different shocks across the alternatives.
> <!-- bilingual-en:end -->
