# 同一有限集合的两种完备计数给出相等表达式
<!-- bilingual-en:start -->
*Two complete counts of the same finite set yield equal expressions*
<!-- bilingual-en:end -->

> [!summary] 原子方法
> 双重计数先定义一个有限集合——通常是满足某种关系的配对或关联（incidence）对——再用两种分组方式数它。因为两边数的是同一批对象，两个表达式必然相等。

对有限无向简单图，顶点—边关联集可以写为

\[
I=\{(v,e):v\text{ 是边 }e\text{ 的端点}\}.
\]

按顶点分组得到 \(|I|=\sum_v\deg(v)\)；按边分组时每条边有两个端点，得到 \(|I|=2|E|\)。于是 \(\sum_v\deg(v)=2|E|\)，即 [[无向图握手定理|握手定理]]。

## 与相邻方法的区别

- [[双射计数]]在两个集合之间逐一对应；
- [[除法法则]]使用固定 \(k\)-to-1 表示；
- 双重计数对同一个集合用两种完备分组求和。

“式子里出现两个求和号”本身不等于双重计数；必须先指出两边共同计数的对象。

> [!question]- 自检
> 要证明 \(\sum_{k=0}^{n}k\binom nk=n2^{n-1}\)，可以共同计数什么？
>
> **答案：** 计数“一个子集以及该子集中被标出的一个元素”。按子集大小数得到左边；先选被标元素，再任选其余 \(n-1\) 个元素是否进入子集，得到右边。
