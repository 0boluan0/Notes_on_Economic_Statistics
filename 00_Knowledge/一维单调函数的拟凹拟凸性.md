# Monotone functions and both quasi-properties
<!-- bilingual-en:end -->

*一维单调函数的拟凹拟凸性*

<!-- bilingual-en:start -->
On a real interval, a monotone function moves in one direction as its input increases: it may stay flat, but it does not reverse direction. An intermediate input therefore cannot produce a value outside the range between the two endpoint values. This single observation proves both [[拟凹函数|quasiconcavity]] and [[拟凸函数|quasiconvexity]].
<!-- bilingual-en:end -->

实数区间上的单调函数，随输入增加只沿一个方向变化：允许不变，但不反向。因此，两个输入之间的点不会产生超出两端函数值范围的输出。这个观察同时证明[[拟凹函数|拟凹性]]与[[拟凸函数|拟凸性]]。

<!-- bilingual-en:start -->
Monotonicity on an interval places every intermediate value between the endpoint values, satisfying both segment criteria without continuity or differentiability. The cubic is an example without global convexity or concavity. [[多元单调不推拟凹|Coordinatewise monotonicity in higher dimensions]] does not provide the same ordering along arbitrary segments.
<!-- bilingual-en:end -->

若 $f$ 在区间上非减或非增，则两输入之间任何点的函数值都介于两端值之间，故同时满足[[拟凹性线段判据]]与[[拟凸性线段判据]]。无需连续或可导。

<!-- bilingual-en:start -->
## The order argument
<!-- bilingual-en:end -->

*用实数的先后顺序证明*

<!-- bilingual-en:start -->
Let $I\subseteq\mathbb R$ be an interval: whenever it contains two real numbers, it contains every number between them. Thus it is a one-dimensional [[凸集|convex set]]. Let $f:I\to\mathbb R$. Nondecreasing means $a\le b\Rightarrow f(a)\le f(b)$ for all $a,b\in I$; nonincreasing reverses the output inequality. The theorem assumes either one of these properties on the whole interval.
<!-- bilingual-en:end -->

设 $I\subseteq\mathbb R$ 为区间，即只要包含两个实数，就包含它们之间的所有数；因此它是一维[[凸集]]。设 $f:I\to\mathbb R$。非减指任意 $a,b\in I$ 满足 $a\le b\Rightarrow f(a)\le f(b)$；非增则将输出的不等号反向。本命题要求在整个区间上满足其中一种性质。

<!-- bilingual-en:start -->
Fix any $x,y\in I$ and $t\in[0,1]$, and put $z=tx+(1-t)y$. Let $a=\min\{x,y\}$ and $b=\max\{x,y\}$. Nonnegative weights summing to one give $a\le z\le b$. For a nondecreasing function this gives $f(a)\le f(z)\le f(b)$; for a nonincreasing function it gives $f(a)\ge f(z)\ge f(b)$. In either case,
<!-- bilingual-en:end -->

固定任意 $x,y\in I$、$t\in[0,1]$，令 $z=tx+(1-t)y$，再令 $a=\min\{x,y\}$、$b=\max\{x,y\}$。权重非负且和为一，所以 $a\le z\le b$。若函数非减，得到 $f(a)\le f(z)\le f(b)$；若非增，得到 $f(a)\ge f(z)\ge f(b)$。无论哪种情况，都有

$$\min\{f(x),f(y)\}\le f(tx+(1-t)y)\le\max\{f(x),f(y)\}.$$

<!-- bilingual-en:start -->
The left inequality is the [[拟凹性线段判据|quasiconcave segment criterion]]; the right is the [[拟凸性线段判据|quasiconvex segment criterion]]. Since the pair and weight were arbitrary, both properties hold. This proves the claim on open, closed, half-open and unbounded intervals. On a one-point interval it is immediate; if the empty interval is allowed, all tests are vacuous.
<!-- bilingual-en:end -->

左边是[[拟凹性线段判据]]，右边是[[拟凸性线段判据]]。点对与权重任意，所以两种性质都成立。这个证明适用于开、闭、半开和无界区间；单点区间显然成立，若允许空区间，则所有检验都自动成立。

## Jumps and flat portions do not break the proof
<!-- bilingual-en:end -->

*跳跃与平台都不妨碍证明*

> [!example] A step function · 阶梯函数
> <!-- bilingual-en:start -->
> On $\mathbb R$, define $h(x)=0$ for $x<0$ and $h(x)=1$ for $x\ge0$. It is nondecreasing, although it jumps at zero. For thresholds $0<k\le1$, its upper set is $[0,\infty)$; for $0\le k<1$, its lower set is $(-\infty,0)$. All other upper or lower sets are empty or all of $\mathbb R$. Each is convex, confirming both properties directly.
> <!-- bilingual-en:end -->
>
> 在 $\mathbb R$ 上定义 $h(x)=0$（$x<0$）以及 $h(x)=1$（$x\ge0$）。它非减，但在零点跳跃。当 $0<k\le1$ 时，上轮廓集为 $[0,\infty)$；当 $0\le k<1$ 时，下轮廓集为 $(-\infty,0)$。其余门槛对应的上、下轮廓集为空集或整个 $\mathbb R$，全部凸，直接验证了两种性质。

<!-- bilingual-en:start -->
The proof uses inequalities between ordered inputs, not the [[介值定理|intermediate value theorem]]. It never says that every value between the endpoint outputs must be attained. A jump can skip many such values while staying between the endpoint bounds. Constant functions also qualify.
<!-- bilingual-en:end -->

证明使用输入的先后顺序和不等式，没有使用[[介值定理|中间值定理]]，也没有说两个端点输出之间的每一个值都必须取到。跳跃可以跳过很多输出值，同时仍满足端点上下界。常函数也满足本命题。

## The domain and the shape still matter
<!-- bilingual-en:end -->

*仍需辨认定义域与函数形状*

<!-- bilingual-en:start -->
The cubic $f(x)=x^3$ is increasing: for $a<b$, $b^3-a^3=(b-a)(a^2+ab+b^2)>0$, since $a^2+ab+b^2=(a+b/2)^2+3b^2/4$ vanishes only when both inputs are zero. Nevertheless, it is neither [[凹凸性|convex nor concave]] on all of $\mathbb R$. At $-2,0$ the midpoint value $-1$ exceeds the chord height $-4$, violating convexity; at $0,2$ the midpoint value 1 falls below chord height 4, violating concavity.
<!-- bilingual-en:end -->

三次函数 $f(x)=x^3$ 递增：若 $a<b$，则 $b^3-a^3=(b-a)(a^2+ab+b^2)>0$，因为 $a^2+ab+b^2=(a+b/2)^2+3b^2/4$ 只有在两输入都为零时才为零。然而它在整个 $\mathbb R$ 上既不[[凹凸性|凸也不凹]]：输入 $-2,0$ 的中点值 $-1$ 高于弦高度 $-4$，违反凸性；输入 $0,2$ 的中点值 1 低于弦高度 4，违反凹性。

例如 $x^3$ 在实线上有这两个性质，却不在全实线上凹或凸。区间前提保证混合点仍在定义域；[[多元单调不推拟凹|多维逐坐标单调]]不提供同样的线段排序。

<!-- bilingual-en:start -->
For example, an order-preserving function on the disconnected set $\{-1,1\}$ cannot be called quasiconvex or quasiconcave under the definitions used here: its domain is not convex and the midpoint is unavailable. In several dimensions, a segment can increase one coordinate and decrease another, so [[多元单调不推拟凹|coordinatewise monotonicity]] needs a separate analysis.
<!-- bilingual-en:end -->

例如，定义在不连通集合 $\{-1,1\}$ 上的保序函数，按这里的定义不能直接称为拟凸或拟凹：定义域不凸，中点没有函数值。在多维空间，沿线段可能有的坐标增加、有的减少，所以[[多元单调不推拟凹|逐坐标单调性]]需要另行分析。
