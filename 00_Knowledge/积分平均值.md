# 积分平均值是函数积分除以所平均区间的长度
<!-- bilingual-en:start -->
*The integral average of a function is its integral divided by the length of the averaging interval*
<!-- bilingual-en:end -->

可积函数 $f$ 在非退化区间 $[a,b]$、$a<b$ 上相对于 $x$ 的积分平均值，定义为
<!-- bilingual-en:start -->
For an integrable function $f$ on a nondegenerate interval $[a,b]$, with $a<b$, its integral average with respect to $x$ is defined by
<!-- bilingual-en:end -->

$$
f_{\mathrm{avg}}=\frac1{b-a}\int_a^b f(x)\,dx.
$$

它将累计值除以总长度，单位与 $f$ 相同。等距分割时，$\Delta x=(b-a)/n$，因而 $\frac1n\sum_{i=1}^n f(x_i^*)=\frac1{b-a}\sum_{i=1}^nf(x_i^*)\Delta x$；取极限便得到定义。常数函数 $f=c$ 的平均值仍为 $c$。
<!-- bilingual-en:start -->
Dividing the accumulated value by total length leaves the same units as $f$. For an equal partition, $\Delta x=(b-a)/n$, so the arithmetic mean of sampled values equals the normalised Riemann sum; taking its limit gives the definition. A constant function $f=c$ has average $c$.
<!-- bilingual-en:end -->

平均值对应于保持相同有向积分的常数高度，即 $\int_a^bf=f_{\mathrm{avg}}(b-a)$。定义只要求可积；是否存在某个 $c\in[a,b]$ 使 $f(c)=f_{\mathrm{avg}}$，是需要额外条件的 [[积分中值定理]]。
<!-- bilingual-en:start -->
The average is a constant height preserving the signed integral: $\int_a^bf=f_{\mathrm{avg}}(b-a)$. Integrability suffices for the definition. Whether some $c\in[a,b]$ satisfies $f(c)=f_{\mathrm{avg}}$ is a separate question addressed by the [[积分中值定理|mean value theorem for integrals]] under additional conditions.
<!-- bilingual-en:end -->

必须说明按哪个变量均匀平均。单位上半圆的高度，按水平位置 $x$ 平均为 $\frac12\int_{-1}^1\sqrt{1-x^2}\,dx=\pi/4$；按弧长均匀平均时可用 $0\le\theta\le\pi$、$y=\sin\theta$，得到 $\frac1\pi\int_0^\pi\sin\theta\,d\theta=2/\pi$。两者给不同位置的权重不同。
<!-- bilingual-en:start -->
Specify the variable that receives uniform weight. A unit upper semicircle has average height $\pi/4$ with respect to horizontal position. Uniform averaging by arc length uses $y=\sin\theta$ for $0\le\theta\le\pi$ and gives $2/\pi$. These averages assign different weights to positions.
<!-- bilingual-en:end -->
