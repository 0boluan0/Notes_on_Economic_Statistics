# 奇偶搜索要么给出二着色要么给出一条奇环证书
<!-- bilingual-en:start -->
*Parity search returns either a two-coloring or an odd-cycle certificate*
<!-- bilingual-en:end -->

> [!summary] 原子算法
> 对 finite simple undirected graph 的每个尚未访问 connected component，任选 root 染成 0；用 BFS 或 DFS 扩展时，把未访问邻点染成相反颜色并记录 parent。检查每条边：
>
> - 若所有边两端异色，输出一份 proper 2-coloring；
> - 若发现同色 edge $uv$，用 parent chains 与 $uv$ 还原一条 odd cycle，作为不可能二着色的证书。
>
> <!-- bilingual-en:start -->
> In every unvisited connected component of a finite simple undirected graph, choose a root of color 0. During BFS or DFS, give each undiscovered neighbor the opposite color and record its parent. If every edge has differently colored endpoints, return a proper two-coloring. If an edge $uv$ joins equal colors, its two parent chains together with $uv$ yield an odd-cycle certificate.
> <!-- bilingual-en:end -->

只说“搜索遇到冲突”还不够复查。设 $z$ 是 parent forest 中 root-to-$u$ 与 root-to-$v$ 两条路径的最后公共顶点。删去共同的 root-to-$z$ 前缀后，保留 $z$ 到 $u$、$z$ 到 $v$ 的两段，再加边 $uv$。两段在内部不相交，所以得到 simple cycle。
<!-- bilingual-en:start -->
Saying only that the search found a conflict is not independently checkable. Let $z$ be the last common vertex of the parent paths from the component root to $u$ and $v$. Remove their common root-to-$z$ prefix and retain the two remaining branches plus $uv$. The branches are internally disjoint, so they form a simple cycle.
<!-- bilingual-en:end -->

由于 $u,v$ 同色，它们在搜索树中的深度同奇偶；从 $z$ 到两点的两段总长度为偶数，再加冲突边 $uv$ 的一步，cycle 长度为奇数。这条 cycle 直接解释了为什么任何二着色都会失败，而不是只报告一个布尔值。
<!-- bilingual-en:start -->
Equal colors mean that $u$ and $v$ have depths of the same parity. The two branches from $z$ therefore have even total length; adding the conflict edge makes the cycle odd. This cycle explains why every two-coloring must fail instead of returning only a Boolean answer.
<!-- bilingual-en:end -->

用 adjacency list 时，每个顶点只首次发现一次、每条无向边至多检查两次（每个端点各一次），所以运行时间为 $O(|V|+|E|)$。必须启动所有未访问 components；只从一个 root 搜索会漏掉其他 component 中的 odd cycle。null graph 没有 component 需启动，算法直接返回空着色。
<!-- bilingual-en:start -->
With adjacency lists, each vertex is discovered once and each undirected edge is examined at most twice, once from each endpoint, giving $O(|V|+|E|)$ time. The search must restart from every unvisited component; one root cannot detect an odd cycle in another component. The null graph has no component to start, so the algorithm immediately returns the empty coloring.
<!-- bilingual-en:end -->

> [!question]- 回忆与应用
> 为什么失败时必须保留 parent pointers，而不能只保留冲突边 $uv$？
>
> **答案：**单独一条边不会构成奇环。parent pointers 给出两端回到共同祖先的路径；两条路径与冲突边合起来，才是一份可以逐边核验的 odd-cycle certificate。
