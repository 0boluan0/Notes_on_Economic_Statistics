# Left-covering and perfect matchings
<!-- bilingual-en:end -->

*左侧覆盖与完美匹配*

<!-- bilingual-en:start -->
An assignment can finish every student's task without using every available project. This is the difference between a matching that **covers the left side** and a **perfect matching**: the first serves a designated group; the second leaves no vertex anywhere unmatched. Before searching for a solution, state which group must be served.
<!-- bilingual-en:end -->

一次分配可以让每位学生都有项目，却不必用完所有项目。这就是**覆盖左侧的匹配**与**完美匹配**的区别：前者完成指定一组对象的任务，后者要求整张图没有任何未匹配顶点。开始寻找解之前，先说明必须服务哪一组对象。

> [!example] Two students and three projects · 两名学生与三个项目
> <!-- bilingual-en:start -->
> Let $L=\{a,b\}$ be the students and $R=\{1,2,3\}$ the projects. Suppose the allowed edges are $a1,a2,b2,b3$, where $a1$ means the undirected edge joining $a$ to $1$. The selected set $M=\{a1,b2\}$ gives each student a different project. It covers $L$, while project $3$ remains unmatched. That unused project does not make the student assignment fail, but it makes this matching nonperfect.
> <!-- bilingual-en:end -->
>
> 设学生为 $L=\{a,b\}$，项目为 $R=\{1,2,3\}$，允许边为 $a1,a2,b2,b3$；其中 $a1$ 表示连接 $a$ 与 $1$ 的无向边。选取 $M=\{a1,b2\}$，两名学生各得到不同项目，因此覆盖 $L$；项目 $3$ 仍未匹配。这个空项目不影响完成学生侧任务，却使该匹配不是完美匹配。

<!-- bilingual-en:start -->
## What does a matching cover?
<!-- bilingual-en:end -->

*匹配覆盖了什么？*

<!-- bilingual-en:start -->
Work with a finite simple undirected [[二分图|bipartite graph]] $G=(L\cup R,E)$, with $L\cap R=\varnothing$ and every edge joining the two sides. A [[匹配定义|matching]] is a selected edge set $M\subseteq E$ in which no two edges share an endpoint. A vertex is **covered**, or matched, when it is an endpoint of a selected edge. Thus it is covered exactly once, not merely adjacent to some vertex that has been matched.
<!-- bilingual-en:end -->

考虑有限简单无向[[二分图]] $G=(L\cup R,E)$，其中 $L\cap R=\varnothing$，每条边都连接两侧。[[匹配定义|匹配]]是选中的边集 $M\subseteq E$，任意两条选中边不共享端点。一个顶点若是某条选中边的端点，就称为**被覆盖**或已匹配；它恰好参与一个配对。仅仅邻接某个已经匹配的顶点，不等于自己被覆盖。

<!-- bilingual-en:start -->
A matching covers $L$ if every vertex of $L$ is covered. It is **perfect** if every vertex of $L\cup R$ is covered. Perfectness has the same all-vertices meaning in a general graph, even without a bipartition. Here each selected edge covers one left and one right vertex, so a matching of size $k=|M|$ covers exactly $k$ vertices on each side.
<!-- bilingual-en:end -->

若 $L$ 中每个顶点都被覆盖，就称匹配覆盖 $L$；若 $L\cup R$ 的全部顶点都被覆盖，就称它为**完美匹配**。在没有指定二分划分的一般图中，完美也仍表示覆盖全部顶点。本卡的二分图里，每条选中边各覆盖一个左点和一个右点，因此大小为 $k=|M|$ 的匹配恰好在每侧覆盖 $k$ 个顶点。

<!-- bilingual-en:start -->
## Why left coverage is a one-to-one assignment
<!-- bilingual-en:end -->

*为什么覆盖左侧给出单射？*

<!-- bilingual-en:start -->
If $M$ covers $L$, define $f(\ell)$ to be the right partner of $\ell$. Coverage supplies a partner; the matching rule makes it unique. Different left vertices cannot have the same right partner, because that would reuse a right endpoint. Thus $f:L\to R$ is **injective**, or one-to-one: $f(\ell_1)=f(\ell_2)$ implies $\ell_1=\ell_2$. It also respects the allowed edges: $\{\ell,f(\ell)\}\in E$ for every $\ell\in L$.
<!-- bilingual-en:end -->

若 $M$ 覆盖 $L$，就把 $f(\ell)$ 定义为左点 $\ell$ 的右侧伙伴。覆盖要求保证伙伴存在，匹配规则保证它唯一。不同左点不能有同一个右侧伙伴，否则会重复使用右端点。因此 $f:L\to R$ 是**单射**：$f(\ell_1)=f(\ell_2)$ 必推出 $\ell_1=\ell_2$。它还必须遵守允许边，即每个 $\ell\in L$ 都满足 $\{\ell,f(\ell)\}\in E$。

<!-- bilingual-en:start -->
Conversely, any such edge-respecting injection produces a left-covering matching by selecting all edges $\{\ell,f(\ell)\}$. Distinct left inputs and distinct right outputs prevent repeated endpoints. An arbitrary injection that uses a forbidden pair is not a graph matching. A perfect matching is precisely the case in which this assignment also reaches every right vertex, so it is a bijection between the sides.
<!-- bilingual-en:end -->

反过来，任何遵守允许边的单射都能给出覆盖左侧的匹配：选取所有 $\{\ell,f(\ell)\}$ 即可。左侧输入各不相同，右侧输出也各不相同，因此没有重复端点。任意一个用了禁止配对的单射，并不是图中的匹配。若这份分配还到达每个右点，就是完美匹配，此时它是两侧之间的双射。

<!-- bilingual-en:start -->
## When does covering one side cover both?
<!-- bilingual-en:end -->

*什么时候覆盖一侧就覆盖两侧？*

<!-- bilingual-en:start -->
Every matching has at most $\min(|L|,|R|)$ edges. If it covers $L$, then $|M|=|L|$, so $|L|\le |R|$ is necessary. Exactly $|R|-|L|$ right vertices remain unmatched. In particular,
<!-- bilingual-en:end -->

任何匹配至多有 $\min(|L|,|R|)$ 条边。若它覆盖 $L$，则 $|M|=|L|$，因此必须有 $|L|\le |R|$；右侧恰好留下 $|R|-|L|$ 个未匹配顶点。特别地，

$$M\text{ covers }L\quad\text{and}\quad |L|=|R|
\quad\Longrightarrow\quad M\text{ is perfect}.$$

<!-- bilingual-en:start -->
The reason is finite counting: $|L|$ distinct right partners exhaust the finite right side when the two sizes agree. The first example has sizes $2$ and $3$, so a left-covering matching leaves exactly one right vertex. It already has the largest possible number of edges, although it is not perfect; see [[极大与最大匹配|maximal versus maximum matchings]] for that separate size question.
<!-- bilingual-en:end -->

理由是有限计数：两侧大小相等时，$|L|$ 个不同右侧伙伴已经用完有限的右侧。开头两侧大小为 $2$ 和 $3$，所以覆盖左侧后恰好剩一个右点。这份匹配虽然不完美，却已经有尽可能多的边；这种大小问题另见[[极大与最大匹配]]。

> [!warning] Equal sizes do not supply the edges · 等大不保证有足够的允许边
> <!-- bilingual-en:start -->
> Take $L=\{a,b\}$, $R=\{1,2\}$ and only edges $a1,b1$. The two sides have equal sizes, but both students can use only project $1$. No matching covers $L$, and no perfect matching exists. Equality of the side sizes is necessary for perfectness, not sufficient for its existence. [[Hall 定理|Hall's theorem]] tests existence of left coverage by checking the neighbor supply for every subset of $L$.
> <!-- bilingual-en:end -->
>
> 取 $L=\{a,b\}$、$R=\{1,2\}$，只允许边 $a1,b1$。两侧等大，但两名学生都只能使用项目 $1$，所以没有匹配能覆盖 $L$，也没有完美匹配。两侧等大是完美匹配的必要条件，不是其存在的充分条件。[[Hall 定理]]通过检查 $L$ 的每个子集是否有足够多的邻点，判断覆盖左侧的匹配是否存在。

## Empty sides and the finite-size boundary
<!-- bilingual-en:end -->

*空侧与有限性的边界*

<!-- bilingual-en:start -->
If $L=\varnothing$, the empty matching covers $L$ without making any assignment. It is perfect only if $R$ is also empty. If $L\ne\varnothing$ and $R=\varnothing$, no matching covers $L$. An isolated left vertex likewise prevents left coverage; an isolated right vertex prevents perfectness but need not prevent left coverage.
<!-- bilingual-en:end -->

若 $L=\varnothing$，空匹配无需作任何分配就覆盖 $L$；只有 $R$ 也为空时，它才完美。若 $L\ne\varnothing$ 而 $R=\varnothing$，则不可能覆盖左侧。孤立左点同样阻止覆盖 $L$；孤立右点会阻止完美匹配，却未必阻止覆盖左侧。

<!-- bilingual-en:start -->
Do not drop finiteness from the equal-size implication. For an explicit infinite example, let the two sides be $\{\ell_0,\ell_1,\ldots\}$ and $\{r_0,r_1,\ldots\}$, and select edges $\ell_i r_{i+1}$ for every nonnegative integer $i$. The sides have the same countably infinite size, and all left vertices are covered, but $r_0$ is not. The definitions of coverage and perfectness still apply; the finite counting inference does not.
<!-- bilingual-en:end -->

不能从“等大就覆盖两侧”的推论中删去有限性。一个具体的无限例子是：两侧分别为 $\{\ell_0,\ell_1,\ldots\}$ 与 $\{r_0,r_1,\ldots\}$，对每个非负整数 $i$ 选边 $\ell_i r_{i+1}$。两侧同为可数无限，全部左点都被覆盖，但 $r_0$ 没有。覆盖与完美的定义仍适用，有限计数的推论却不再成立。

<!-- bilingual-en:start -->
Before solving an application, distinguish “cover $L$,” “cover $R$,” “cover all vertices,” and “maximize the number of selected edges.” An unused project may be acceptable; an unserved student may not. The graph alone does not choose this requirement for you.
<!-- bilingual-en:end -->

求解应用前，先区分“覆盖 $L$”“覆盖 $R$”“覆盖全部顶点”与“选边数尽量多”。闲置项目可能可以接受，未分配学生却可能不行；图本身不会替你决定这个要求。
