# Sum rule of counting
<!-- bilingual-en:end -->

*加法法则*

<!-- bilingual-en:start -->
Suppose a shelf contains the three novels $a,b,c$ and the two dictionaries $d,e$. You want to choose **one book**. The complete list of choices is $a,b,c,d,e$, so there are $3+2=5$ choices. Adding works because the two lists cover all the books, and no book appears on both lists.

This is the **sum rule**: split the objects to be counted into separate cases, count each case, and add. First fix the [[计数对象|counting object]]—what one result is and when two descriptions denote the same result. Here a result is a single book, not a pair consisting of one book of each kind.
<!-- bilingual-en:end -->

书架上有三本小说 $a,b,c$ 和两本词典 $d,e$，现在只选**一本书**。全部选择是 $a,b,c,d,e$，所以有 $3+2=5$ 种。能相加，是因为两份名单覆盖了全部书，而且没有一本同时出现在两份名单里。

这就是**加法法则**：把要数的对象分成互不重叠的类别，分别数完后相加。先确定[[计数对象]]——一个结果是什么，哪些描述算同一个结果。这里的结果是一本书，不是“每类各选一本”组成的书对。

<!-- bilingual-en:start -->
Let $A_1,\ldots,A_m$ be finitely many finite sets of objects. The notation $|A_i|$ means the number of objects in case $i$, and $A_1\cup\cdots\cup A_m$ is their union: all objects belonging to at least one case. The cases are **pairwise disjoint** when no object belongs to two different cases.
<!-- bilingual-en:end -->

设 $A_1,\ldots,A_m$ 是有限多个有限对象集合。$|A_i|$ 表示第 $i$ 类的对象数；并集 $A_1\cup\cdots\cup A_m$ 包含至少属于其中一类的所有对象。**两两不交**是说，任何对象都不会同时属于两个不同类别。

> [!important] One appearance per object · 每个对象恰好出现一次
> <!-- bilingual-en:start -->
> For pairwise disjoint cases,
> <!-- bilingual-en:end -->
>
> 对两两不交的类别，
>
> $$
> |A_1\cup\cdots\cup A_m|=\sum_{i=1}^{m}|A_i|.
> $$
>
> <!-- bilingual-en:start -->
> The summation sign means “add all the case counts.” Disjointness prevents duplicates; covering the target set prevents omissions. The cases need not have equal sizes.
> <!-- bilingual-en:end -->
>
> 求和号表示把各类数量相加。不交保证不重复，覆盖目标集合保证不遗漏；各类不需要一样大。

> [!example] Four-bit strings with different endpoints · 首尾不同的四位二进制串
> <!-- bilingual-en:start -->
> A binary string is an ordered list of zeros and ones. For length four, separate the valid strings by their first bit:
>
> - First bit $0$, last bit $1$: $0001,0011,0101,0111$.
> - First bit $1$, last bit $0$: $1000,1010,1100,1110$.
>
> Each string belongs to exactly one list, so the answer is $4+4=8$. Within either case, the two middle positions each allow two choices; the [[乘法法则|product rule]] gives the same count $2^2=4$.
> <!-- bilingual-en:end -->
>
> 二进制串是按顺序写出的零和一。长度为四且首尾不同的串，可以按首位分成两类：
>
> - 首位 $0$、末位 $1$：$0001,0011,0101,0111$。
> - 首位 $1$、末位 $0$：$1000,1010,1100,1110$。
>
> 每个串只属于一份名单，所以共有 $4+4=8$ 个。每类中间的两位各有两种选择，也可以由[[乘法法则]]得到 $2^2=4$。

## When the cases overlap
<!-- bilingual-en:end -->

## 边界

<!-- bilingual-en:start -->
If the mathematics club contains Ana and Ben, while the computing club contains Ben and Cara, adding the two membership counts gives $2+2=4$. There are only three distinct people: Ben was counted twice. To count people who belong to at least one club, either use disjoint categories—“mathematics members” and “computing members who are not mathematics members”—or correct the overlap with [[容斥原理|inclusion–exclusion]].

Empty cases contribute zero. A collection of no cases has an empty union and an empty sum, both with count zero. This card concerns finite counting. The [[互斥事件加法|addition rule for disjoint events]] uses the same disjoint-set structure but adds probabilities; it does not require the outcomes to be equally likely. Turning a count ratio into a probability requires a separate equal-likelihood assumption.
<!-- bilingual-en:end -->

如果数学社有 Ana、Ben，计算机社有 Ben、Cara，两个社团人数相加是 $2+2=4$，但只有三名不同的人，因为 Ben 被算了两次。要数“至少参加一个社团的人”，可以改成“数学社成员”和“参加计算机社但不参加数学社的人”这两个不交类别，或用[[容斥原理]]修正重叠。

空类别贡献零；没有任何类别时，并集为空、求和为空，计数也都是零。本卡讨论有限计数。[[互斥事件加法]]使用相同的不交集合结构，但相加的是概率，并不要求各结果等可能。若要把人数或对象数的比例当作概率，还须另行说明等可能假设。
