# 全图搜索要从未发现顶点重启而一次有向搜索不能直接求强连通分量
<!-- bilingual-en:start -->
*A full traversal restarts at undiscovered vertices; one directed search does not compute SCCs*
<!-- bilingual-en:end -->

> [!summary] 原子程序
> 单源 BFS/DFS 结束后，若仍有未发现顶点，就任选一个作为新根再搜索；重复直到所有顶点都被发现。parent edges 因而形成 forest。这个过程称 full BFS 或 full DFS，它覆盖整张图，但每棵树的语义取决于边是否有方向。
> <!-- bilingual-en:start -->
> After a source BFS or DFS finishes, choose any still-undiscovered vertex as a new root and search again. Repeat until every vertex is discovered. Parent edges therefore form a forest. This full BFS or full DFS covers the entire graph, but the meaning of each tree depends on whether edges are directed.
> <!-- bilingual-en:end -->

在 undirected graph 中，从一个根发现的恰是它的 entire connected component：component 内所有点可达，component 外没有边可跨越。因此 full search 的每棵 tree 正好对应一个 component，tree 数就是 component 数。
<!-- bilingual-en:start -->
In an undirected graph, one root discovers exactly its entire connected component: every vertex in the component is reachable, and no edge crosses to a different component. Each full-search tree therefore corresponds to one component, and the number of trees equals the number of components.
<!-- bilingual-en:end -->

## directed graph 的根序边界
<!-- bilingual-en:start -->
*Root-order boundary in a directed graph*
<!-- bilingual-en:end -->

在 digraph 中，一棵 search tree 只表示“从这个根向外可达”。不同 SCC 之间若有单向边，先选上游根可能一次跨越多个 SCC；先选下游根又可能产生更多 trees。forest 会随 root order 改变，既不等于 weak components，也不等于 SCC partition。
<!-- bilingual-en:start -->
In a digraph, one search tree means only “reachable outward from this root.” A one-way edge between SCCs lets an upstream root cross several SCCs at once, while choosing a downstream root first may create more trees. The forest depends on root order and is neither the weak-component partition nor the SCC partition.
<!-- bilingual-en:end -->

full DFS 的 finishing order 仍是重要中间信息：在 DAG 中，其 reverse finishing order 是 topological order；SCC 算法也会结合 finishing order 与 transpose graph，或使用 low-link 值。但“做一次 full DFS”本身还没有完成 SCC decomposition。
<!-- bilingual-en:start -->
The finishing order of a full DFS is still useful. Its reverse is a topological order in a DAG, and SCC algorithms combine finishing order with the transpose graph or use low-link values. But “run one full DFS” alone is not an SCC decomposition.
<!-- bilingual-en:end -->

> [!question]- 回忆与应用
> digraph 只有边 $a\to b$。full DFS 先选 $a$ 与先选 $b$ 会得到几棵树？SCC 数是否改变？
>
> **答案：**先选 $a$ 时一棵 tree 覆盖 $a,b$；先选 $b$ 时先得到单点 tree，再从 $a$ 得第二棵。SCC 始终是两个单点，说明 directed search forest 的树数不是 SCC 数。
> <!-- bilingual-en:start -->
> A digraph contains only edge $a\to b$. How many full-DFS trees result when choosing $a$ first versus $b$ first? Does the number of SCCs change?
>
> **Answer:** Choosing $a$ first yields one tree containing both vertices. Choosing $b$ first yields a singleton tree and then a second tree rooted at $a$. The SCCs remain the two singleton vertices, so the number of directed search trees is not the number of SCCs.
> <!-- bilingual-en:end -->
