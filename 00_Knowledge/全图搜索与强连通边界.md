# Full graph search and its connectivity limits
<!-- bilingual-en:end -->

*全图搜索与强连通边界*

<!-- bilingual-en:start -->
A search from one starting vertex may leave part of a graph untouched. **Full graph search** continues from a new, still-undiscovered vertex whenever the current search finishes. It keeps the marks and parent records already made. This guarantees coverage of every vertex, but coverage alone does not identify the strongly connected components of a directed graph.
<!-- bilingual-en:end -->

从一个起点出发的搜索可能漏掉图中其他部分。**全图搜索**在当前搜索结束后，继续从一个尚未发现的新顶点出发，并保留已有标记和父记录。这样能够覆盖每个顶点，但“全部都访问过”本身并不能识别有向图的强连通分量。

<!-- bilingual-en:start -->
Consider a finite [[图类型的建模边界|directed or undirected graph]] $G=(V,E)$, where $V$ is its vertex set and $E$ its edge set. Initially every vertex is undiscovered. Within each run, use a complete source search such as [[BFS 分层与无权最短路|BFS]] or [[DFS 可达性与非最短路径|DFS]]: follow outgoing edges in a directed graph, inspect all permitted neighbors, and apply the [[搜索标记与父森林|first-discovery rule]]. A new vertex is marked before its work is scheduled, receives one parent, and is not scheduled again when encountered later. An undirected edge permits both directions.
<!-- bilingual-en:end -->

考虑有限[[图类型的建模边界|有向图或无向图]] $G=(V,E)$，其中 $V$ 为顶点集、$E$ 为边集。起初所有顶点均未发现。每次采用 [[BFS 分层与无权最短路|BFS]] 或 [[DFS 可达性与非最短路径|DFS]] 这样的完整单源搜索：有向图沿出边走，检查全部允许的邻居，并遵守[[搜索标记与父森林|首次发现规则]]。新顶点先标记，再安排其探索，同时只确定一个父顶点；之后再次遇到它，不再重复安排。无向边则允许双向行走。

<!-- bilingual-en:start -->
## Restart without clearing the old marks
<!-- bilingual-en:end -->

*保留旧标记，再选择新根*

<!-- bilingual-en:start -->
Scan a list containing every vertex once. If the current vertex is already marked, skip it. Otherwise, make it a new root with no parent, mark it, and finish its search before continuing the list. This gives full BFS when each run uses a FIFO queue, and full DFS when each run uses standard recursive DFS or stack frames that preserve each suspended neighbor-scan position. Old parent records are not overwritten, and an edge into an already marked region does not start another exploration there.
<!-- bilingual-en:end -->

扫描一份包含每个顶点一次的列表。若当前顶点已有标记，就跳过；否则把它设为无父顶点的新根，标记它，并完成这次搜索，再继续扫描列表。每次使用 FIFO 队列时，得到 full BFS；每次使用标准递归 DFS，或保存暂停邻接扫描位置的栈帧时，得到 full DFS。已有父记录不改写；遇到指向已标记区域的边，也不会在那里重新启动探索。

> [!example] Why clearing marks changes the task · 为什么不能每次清空标记？
> <!-- bilingual-en:start -->
> With only $a\to b$, a fresh search from $a$ finds both vertices. If marks are then cleared and a fresh search starts at $b$, $b$ is visited again. Those separate reachability queries are legitimate, but they are not one full traversal with disjoint discovery trees. Keeping marks is what makes each vertex belong to exactly one tree.
> <!-- bilingual-en:end -->
>
> 只有 $a\to b$ 时，从 $a$ 开始的全新搜索找到两个顶点。若随后清空标记，再从 $b$ 全新搜索，$b$ 就会再次被访问。这些彼此独立的可达性查询是合法的，但不是一次具有不交发现树的全图遍历。正是保留标记，才让每个顶点恰好属于一棵树。

<!-- bilingual-en:start -->
Every new root starts a singleton tree. Each later discovery attaches one new vertex by one parent edge to the current tree, so ignoring arrow directions the combined parent edges form a [[森林|forest]]. A finite root list eventually considers every vertex; a vertex is either already discovered then or becomes a root. Thus every vertex is covered exactly once as a discovery. With [[邻接表图搜索复杂度|adjacency lists and the stated operation-cost assumptions]], the one root scan plus one scan of each adjacency entry gives $O(|V|+|E|)$ total time for nonempty inputs. This does not mean that every input edge becomes a parent edge.
<!-- bilingual-en:end -->

每个新根先形成一棵单点树；之后每次发现都用一条父边把一个新顶点接到当前树上。因此，忽略箭头后，全部父边组成一片[[森林]]。有限的根列表最终会检查每个顶点；检查时它要么已经发现，要么成为新根，所以每个顶点恰好被首次发现一次。满足[[邻接表图搜索复杂度|邻接表及所述操作成本前提]]时，一次根扫描加上每个邻接项的一次扫描，对非空输入给出总时间 $O(|V|+|E|)$。这不表示原图每条边都会成为父边。

<!-- bilingual-en:start -->
## In an undirected graph, the trees span components
<!-- bilingual-en:end -->

*无向图中，搜索树覆盖各个连通分量*

<!-- bilingual-en:start -->
An undirected [[无向图连通分量|connected component]] contains exactly the vertices reachable from any one of its members. The first root selected in that component discovers every vertex of it: if a path led to an undiscovered vertex after the run, its first undiscovered vertex would follow a discovered predecessor whose adjacency entry had already been inspected, a contradiction. The search cannot leave the component, because an edge to an outside vertex would put that vertex in the same component.
<!-- bilingual-en:end -->

无向[[无向图连通分量|连通分量]]恰好收齐从其中任一点可达的顶点。某个分量里第一个被选作根的顶点会发现整个分量：若本次搜索结束后仍有路径通向未发现点，那么路径上第一个未发现点的前驱已经发现，其邻接项也已经检查过，应当发现该点，矛盾。搜索也不会离开这个分量，因为通向外部顶点的一条边就足以使它归入同一个分量。

<!-- bilingual-en:start -->
Consequently, no later root lies in that component. Each search tree spans exactly one component, so the number of trees equals the number of components. The tree need not contain all of the component's edges: a triangle component has three edges, while its search tree uses two. Root and neighbor orders may change the parent tree, but not the component's vertex set. Isolated vertices produce singleton trees; a graph with no vertices produces an empty forest.
<!-- bilingual-en:end -->

因此，之后不再从这个分量选新根。每棵搜索树恰好覆盖一个分量，树数也就等于分量数。树不必包含分量的全部边：三角形分量有三条边，搜索树只用其中两条。根序和邻接顺序可能改变父树，却不会改变分量的顶点集合。孤立顶点得到单点树；没有顶点的图得到空森林。

<!-- bilingual-en:start -->
## Directed trees depend on the order of roots
<!-- bilingual-en:end -->

## directed graph 的根序边界

<!-- bilingual-en:start -->
In a directed graph, a tree's parent paths certify that its root reaches each of its vertices. They do not certify a return path. Moreover, a later run with retained marks need not newly discover **every** vertex reachable from its root. Its tree records only the vertices newly discovered during that run; previously visited vertices keep their earlier tree membership.
<!-- bilingual-en:end -->

有向图中，一棵树的父路径证明其根可以到达树内每个顶点，却不能证明它们能返回根。此外，保留标记后的某次后续搜索，不一定新发现根可达的**全部**顶点。这棵树只记录本次新发现的点；先前访问过的顶点仍属于之前的树。

> [!example] The same graph, two different search forests · 同一张图，两种搜索森林
> <!-- bilingual-en:start -->
> Let $V=\{a,b\}$ and let the only edge be $a\to b$. With root order $a,b$, the first run discovers both vertices and records parent $a$ for $b$; the forest has one tree. With root order $b,a$, the first run discovers only $b$. The second run starts at $a$, sees that $b$ is already marked, and leaves its old record alone. There are now two singleton trees, even though $a$ reaches $b$ in the original graph.
>
> In both orders the graph has the same two singleton [[强连通与弱连通|strong components]] and the same one weak component. Thus the forest's tree partition need not equal either component partition. Sometimes the sets happen to agree; the search rule alone does not guarantee that agreement.
> <!-- bilingual-en:end -->
>
> 令 $V=\{a,b\}$，唯一的边为 $a\to b$。根序为 $a,b$ 时，第一次搜索发现两个点，记录 $b$ 的父顶点为 $a$，森林只有一棵树。根序为 $b,a$ 时，第一次只发现 $b$；第二次从 $a$ 开始，看到 $b$ 已标记，便保留它的旧记录。此时有两棵单点树，尽管原图中 $a$ 可以到达 $b$。
>
> 两种根序下，图都具有相同的两个单点[[强连通与弱连通|强连通分量]]和同一个弱连通分量。因此，搜索树划分不保证等于强分量划分，也不保证等于弱分量划分；有时集合恰好一致，但单凭搜索规则没有这种保证。

<!-- bilingual-en:start -->
Any one search tree stays inside one weak component, since every parent edge is an undirected connection after forgetting its arrow. Yet a weak component may split across several trees, as above. Conversely, an outward tree may cross several SCCs. These are statements about the information recorded by ordinary full search, not failures of its coverage guarantee.
<!-- bilingual-en:end -->

一棵搜索树一定留在某个弱连通分量内，因为每条父边丢掉箭头后都是一条无向连接；但一个弱分量可能像上例那样分散在多棵树中。反过来，一棵向外探索的树又可能跨过多个 SCC。这些边界说明普通全图搜索记录了什么信息，并不否定它访问全部顶点的保证。

## What further information can be useful?
<!-- bilingual-en:end -->

*还可以利用哪些信息？*

<!-- bilingual-en:start -->
A standard full DFS also records when each recursive visit finishes. For a directed acyclic graph, or **DAG**, [[DFS 逆完成序拓扑排序|reversing that finishing order]] orders every edge from earlier to later. The acyclicity and DFS nesting conditions matter; an arbitrary last-in, first-out work list does not automatically supply the same finishing-order theorem. SCC algorithms can use additional structure, such as a carefully chosen order obtained from the reverse graph. Merely collecting the trees from an arbitrary full DFS does not perform that extra computation. The distinction between outward reachability, mutual reachability and direction-forgetting is stated in [[强连通与弱连通|strong and weak connectivity]].
<!-- bilingual-en:end -->

标准 full DFS 还会记录每个递归访问何时完成。在**有向无环图**（DAG）上，[[DFS 逆完成序拓扑排序|反转这个完成顺序]]就能让每条边都从较早顶点指向较晚顶点。无环与 DFS 嵌套条件都重要，任意后进先出工作列表不会自动满足同一个完成序定理。SCC 算法还可以利用附加结构，例如从反图得到的特定处理顺序。仅仅收集任意 full DFS 的树，没有完成这些额外计算。向外可达、互相可达与忽略方向之间的区别，见[[强连通与弱连通]]。
