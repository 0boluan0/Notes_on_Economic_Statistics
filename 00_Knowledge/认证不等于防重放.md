# 消息通过认证仍可能是攻击者重放的旧消息
<!-- bilingual-en:start -->
*An authenticated message can still be an old message replayed by an attacker*
<!-- bilingual-en:end -->

> [!summary] 原子边界
> MAC 或 AEAD 验证成功说明消息与认证数据未被不持钥者改写，却不自动说明消息是新的。攻击者可以原样保存一条曾经有效的消息，并在以后再次发送；旧 tag 仍与旧消息匹配。
> <!-- bilingual-en:start -->
> Successful MAC or AEAD verification shows that the message and authenticated data were not modified by a party without the key, but it does not automatically show that the message is fresh. An attacker can retain a previously valid message and send it again later; the old tag still matches the old message.
> <!-- bilingual-en:end -->

防重放需要协议额外定义可认证的新鲜性标识，例如序号、会话标识、挑战值或受约束的时间窗，并要求接收方维护相应状态。只把序号放进明文却不认证，攻击者仍能改写；只认证序号却不记录已经接受的值，接收方也无法识别重复。
<!-- bilingual-en:start -->
Replay resistance requires the protocol to define an authenticated freshness value such as a sequence number, session identifier, challenge, or bounded time window, and requires the receiver to maintain corresponding state. A sequence number in unauthenticated plaintext can be altered; an authenticated sequence number without a record of accepted values still cannot reveal a duplicate.
<!-- bilingual-en:end -->

发送方 nonce 唯一性与接收方防重放解决的是不同问题。前者防止新加密调用在同一密钥下重复 nonce；后者拒绝已经出现过、整体仍合法的旧消息。一个系统经常同时需要两者。
<!-- bilingual-en:start -->
Sender-side nonce uniqueness and receiver-side replay resistance solve different problems. The first prevents a fresh encryption invocation from reusing a nonce under one key; the second rejects a previously seen old message that remains valid as a whole. A system often needs both.
<!-- bilingual-en:end -->

> [!question]- 自检
> 发送方保证每条新消息都使用不同 nonce，为什么接收方仍可能接受一条被重放的旧消息？
>
> **答案：** 旧消息的 nonce、密文和 tag 仍是一组有效输入。只有接收方验证并记录序号、会话或时间窗状态，才能识别它已经出现过。

## 来源与核验

- [RFC 5116, Sections 1.2 and 2.1](https://datatracker.ietf.org/doc/html/rfc5116)：核对 AEAD 接口明确不负责 anti-replay，并允许把序号等上下文放入 AAD 认证。
- [RFC 4303, Sections 2.2 and 3.4.3, *IP Encapsulating Security Payload*](https://datatracker.ietf.org/doc/html/rfc4303)：以标准协议实例核对防重放需要受完整性保护的序号与接收方滑动窗口，而不是由认证 tag 单独完成。
