# 连续函数在闭区间上至少有一点取到它的积分平均值
<!-- bilingual-en:start -->
*A continuous function on a closed interval attains its integral average at some point*
<!-- bilingual-en:end -->

若 $f$ 在 $[a,b]$ 连续且 $a<b$，则存在 $c\in[a,b]$ 使
$$\int_a^bf(x)dx=f(c)(b-a),\qquad
f(c)=\frac1{b-a}\int_a^bf(x)dx.$$
[[积分平均值]]本身是由积分定义的高度；本定理额外保证这个高度确实在图像上出现。它一般不告诉你 $c$ 在哪里，也不保证唯一。
<!-- bilingual-en:start -->
The integral average is a height defined by an integral. This theorem additionally guarantees that a continuous graph actually attains that height somewhere in the interval. It generally neither locates the point nor makes it unique.
<!-- bilingual-en:end -->

证明先由[[极值定理]]取最小值 $m$、最大值 $M$。积分上下界给出 $m\le f_{\mathrm{avg}}\le M$，[[介值定理]]再保证函数在取得最小与最大值的两点之间取到 $f_{\mathrm{avg}}$。例如 $f(x)=x^2$ 在 $[0,1]$ 平均值为 $1/3$，相应点为 $c=1/\sqrt3$，不是区间中点。
<!-- bilingual-en:start -->
The extreme value theorem provides attained minimum and maximum heights; integral bounds put the average between them, and the intermediate value theorem yields a point attaining it. For the square function on the unit interval, that point is $1/\sqrt3$, not the midpoint.
<!-- bilingual-en:end -->

连续性不能删掉：在 $[0,1/2)$ 取零、在 $[1/2,1]$ 取一的阶梯函数可积、平均值为 $1/2$，却从不取值 $1/2$。它仍然有平均值，只是没有“平均值必被取到”的保证。
<!-- bilingual-en:start -->
A step function taking only zero on the first half and one on the second has average one half but never takes that value. Its average still exists; what fails without continuity is the attainment guarantee.
<!-- bilingual-en:end -->
