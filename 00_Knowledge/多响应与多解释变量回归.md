# 多响应回归与多解释变量回归按响应维数区分
<!-- bilingual-en:start -->
*Multivariate regression and multiple regression are distinguished by the dimension of the response*
<!-- bilingual-en:end -->

> [!summary] 原子区别
> **multiple linear regression** 通常指一个响应 $y$ 配多个解释变量；本组卡中的 **multivariate linear regression** 指每个观测有 $q>1$ 个响应，响应写成矩阵 $Y$。解释变量个数并不能替代这一区分：多响应模型可以只有一个非截距预测变量，单响应模型也可以有很多预测变量。
> <!-- bilingual-en:start -->
> Multiple linear regression ordinarily has one response and several predictors. Multivariate linear regression here has more than one response per observational unit. The number of predictors does not determine which model it is.
> <!-- bilingual-en:end -->

中文“多元线性回归”常被用来指单响应 multiple regression，所以必须先看 $Y$ 是 $n\times1$ 还是 $n\times q$，不能只按标题判断。单响应模型的系数解释、$t/F$ 检验和残差平方和继续使用 [[OLS 线性回归.canvas|OLS 线性回归]]；多个响应的共同协方差和联合假设才进入本组卡。

MANOVA 是多响应线性模型的一类检验用法，不限于“分别做多个 ANOVA”。分类预测变量可编码进 $X$，连续预测变量也可进入同一多响应模型。

> [!question]- 自检
> 三个解释变量预测一个考试分数，是 multivariate regression 吗？
>
> **答案：** 按本组卡的术语不是；它是单响应 multiple regression。只有响应本身是向量时才进入这里的 multivariate regression。
