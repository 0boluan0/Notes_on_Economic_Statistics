# 无向图的路径可达关系把顶点划分为连通分量
<!-- bilingual-en:start -->
*Path reachability partitions the vertices of an undirected graph into connected components*
<!-- bilingual-en:end -->

> [!summary] 原子命题
> 在无向图上定义 $u\sim v$ 当且仅当存在连接 $u$ 与 $v$ 的 path。关系 $\sim$ 是等价关系；它的每个等价类连同类内边组成一个 connected component。图 connected 当且仅当只有一个 component。
> <!-- bilingual-en:start -->
> In an undirected graph, define $u\sim v$ exactly when a path joins $u$ and $v$. This is an equivalence relation. Each equivalence class, together with the edges whose endpoints lie in it, forms a connected component. The graph is connected exactly when it has one component.
> <!-- bilingual-en:end -->

## 为什么真的是等价关系
<!-- bilingual-en:start -->
*Why this is an equivalence relation*
<!-- bilingual-en:end -->

- **自反：**长度 $0$ path 把每个顶点连到自身。
- **对称：**无向 path 可以反向读取。
- **传递：**$u$ 到 $v$ 与 $v$ 到 $w$ 的 paths 拼成 walk；删去重复段即可得到 $u$ 到 $w$ 的 path。
<!-- bilingual-en:start -->

**1. Reflexive:** The length-zero path joins every vertex to itself.<br>
**2. Symmetric:** An undirected path can be read in reverse.<br>
**3. Transitive:** Concatenate a path from $u$ to $v$ with one from $v$ to $w$ and remove repeated detours to obtain a path from $u$ to $w$.<br>
<!-- bilingual-en:end -->

不同 components 之间不可能有边：若 $u$ 与 $v$ 位于不同类却有边 $\{u,v\}$，这条长度 $1$ path 会使二者属于同一类。isolated vertex 自己构成一个 component；因此一个有 $n$ 个顶点、无边的图有 $n$ 个 components。
<!-- bilingual-en:start -->
No edge can run between distinct components. If $u$ and $v$ belonged to different classes but $\{u,v\}$ were an edge, that length-one path would put them in the same class. An isolated vertex forms a component by itself, so an edgeless graph on $n$ vertices has $n$ components.
<!-- bilingual-en:end -->

> [!question]- 回忆与应用
> “每个顶点 degree 都大于 $0$”能否推出图 connected？
>
> **答案：**不能。两条互不相交的边构成四点图，每点 degree 都是 $1$，却有两个 components。positive degree 只排除 isolated vertices，不排除多个非平凡 components。
> <!-- bilingual-en:start -->
> Does positive degree at every vertex imply that the graph is connected?
>
> **Answer:** No. Two disjoint edges give four vertices of degree one but two components. Positive degree excludes isolated vertices, not multiple nontrivial components.
> <!-- bilingual-en:end -->
