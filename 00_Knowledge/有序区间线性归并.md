# 线性归并依赖两个输入区间各自有序

<!-- bilingual-en:start -->
*Linear merging requires both input ranges to be sorted*
<!-- bilingual-en:end -->

> [!summary] 原子不变量
> 合并两个已排序序列时，只需比较各自尚未输出的首项，输出较小者并推进对应指针。每一步后，结果区包含两个输入中已经确定的最小项目且保持有序；两个未消费后缀仍各自有序。
>
> <!-- bilingual-en:start -->
> To merge two sorted sequences, compare only their first unconsumed items, emit the smaller one, and advance that sequence's pointer. After every step, the output contains the smallest items determined so far in sorted order, while both unconsumed suffixes remain individually sorted.
> <!-- bilingual-en:end -->

## 自然解释

若左右长度分别为 $p$ 与 $q$，每个项目恰好输出一次，普通数组实现的时间与数据移动为 $\Theta(p+q)$，并为结果使用 $\Theta(p+q)$ 临时空间。一侧耗尽后，另一侧的剩余后缀可直接追加。

<!-- bilingual-en:start -->
For left and right lengths $p$ and $q$, every item is emitted exactly once, so an ordinary array implementation takes $\Theta(p+q)$ time and movement and uses $\Theta(p+q)$ temporary result space. Once one side is exhausted, the remaining suffix of the other side can be appended directly.
<!-- bilingual-en:end -->

> [!warning] 边界
> 线性归并的前提是两侧已经有序；它不能直接把两个任意乱序区间在线性时间内变成全局有序。稳定性取决于相等键时先取左侧项目。MIT 6.100L 示例代码用 `<`，相等时走右侧，因此对可区分的相等键记录并不稳定；改为左侧优先才可保持原次序。
>
> <!-- bilingual-en:start -->
> Linear merging assumes both sides are already sorted; it cannot turn two arbitrary unsorted ranges into a globally sorted sequence in linear time. Stability requires taking the left item first on equal keys. The MIT 6.100L sample uses `<` and therefore takes the right item on a tie, so it is not stable for distinguishable equal-key records; left-first tie handling restores stability.
> <!-- bilingual-en:end -->

> [!question]- 回忆与应用
> 为什么只比较两个“当前首项”就能选出下一项？
>
> **答案：** 因为每个未消费后缀已排序，各自首项就是该后缀最小值；两者中较小者必是所有剩余项目的全局最小值。
