# 异常收益是实际收益减去正常收益模型给出的预期收益
<!-- bilingual-en:start -->
*Abnormal return is actual return minus the return implied by a normal-return model*
<!-- bilingual-en:end -->

> [!summary] 原子定义
> 对证券 $i$ 和事件时点 $t$，
> $$AR_{it}=R_{it}-\widehat{E}(R_{it}\mid X_t).$$
> 其中 $R_{it}$ 是实际收益，$\widehat{E}(R_{it}\mid X_t)$ 是事先选定并在估计窗拟合的正常收益模型给出的反事实基准。AR 因而是“相对于该模型多出来的当期收益”，不是脱离模型存在的真值。
> <!-- bilingual-en:start -->
> For security $i$ at event time $t$, $AR_{it}=R_{it}-\widehat{E}(R_{it}\mid X_t)$. The second term is the counterfactual benchmark supplied by a prespecified normal-return model fitted in the estimation window. AR is therefore an event-time residual relative to that model, not a model-free truth.
> <!-- bilingual-en:end -->

常数均值模型、市场模型、CAPM 或多因子模型给出的正常收益可能不同，所以同一个实际回报可以对应不同 AR。若公告日股票回报为 4%、市场模型给出的正常收益为 1%，当日 AR 为 3%。
<!-- bilingual-en:start -->
Constant-mean, market, CAPM, and multifactor models can imply different normal returns, so the same realised return can produce different AR estimates. If the stock returns 4% while the market model implies a 1% normal return, the event-day AR is 3%.
<!-- bilingual-en:end -->

这个 3% 只是该模型下的当期实现残差，不等于永久 Alpha，也不自动证明事件创造了 3% 的公司价值。把多个事件日的 AR 跨时间相加得到 [[累计异常收益]]；把多个证券的 AR 做横截面平均则是另一种聚合，不能混称。
<!-- bilingual-en:start -->
This 3% is a realised event-time residual under the stated model, not permanent alpha and not automatic evidence that the event created 3% of firm value. Summing AR through event time gives [[累计异常收益|cumulative abnormal return]]; averaging AR across securities is a different aggregation.
<!-- bilingual-en:end -->

> [!question]- 自检
> 同一公告日用市场模型得到 AR 2%，用多因子模型得到 0.5%，哪一个是“真实事件收益”？
>
> **答案：** 两者都是各自正常收益模型下的估计。应说明模型与估计窗，并检验结论对合理基准是否稳健，不能把 AR 当作无模型真值。
