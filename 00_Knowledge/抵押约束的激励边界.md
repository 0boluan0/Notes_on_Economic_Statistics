# 抵押增加违约代价可以改善激励但不保证更高抵押要求降低总体贷款风险

<!-- bilingual-en:start -->
Collateral can improve incentives by increasing the cost of default, but higher collateral requirements need not reduce overall loan risk.
<!-- bilingual-en:end -->

对同一个借款人，如果某项隐蔽行动提高违约概率，而违约会使他失去有价值、可执行的[[抵押品]]，抵押就可能降低该行动的吸引力。但借款人失去资产的代价与银行处置后的净回收不是同一个量；不能用资产标价直接替代任一方的实际收益变化。

<!-- bilingual-en:start -->
For a given borrower, collateral can make a hidden action less attractive if it raises default probability and default causes the loss of valuable, enforceable [[抵押品|collateral]]. The borrower's loss and the bank's net recovery are different quantities; an asset's quoted value is not automatically either party's payoff change.
<!-- bilingual-en:end -->

例如两项行动的其他收益差暂保持不变，违约概率分别为 0.1 和 0.4；若违约额外损失为 30，较冒险行动多承担的期望抵押损失为 $(0.4-0.1)30=9$。这是固定行动集合与其他合同条件下的局部激励比较，不是完整均衡结论。

<!-- bilingual-en:start -->
Holding other payoff differences fixed, suppose two actions have default probabilities 0.1 and 0.4 and default imposes an additional loss of 30. The riskier action adds expected collateral loss of $(0.4-0.1)30=9$. This is a local incentive comparison with a fixed action set and other contract terms, not an equilibrium conclusion.
<!-- bilingual-en:end -->

提高抵押要求也会改变谁能借、谁愿意借。在 Stiglitz–Weiss 的一个特定财富与风险偏好模型中，对给定借款人的直接收益改善，可以被申请人构成恶化抵消。因此须分别检查行为变化、参与者筛选和实际回收，而不能把“抵押更多”当成无条件的安全排序。

<!-- bilingual-en:start -->
Higher requirements also change who can and wishes to borrow. In a particular wealth-and-risk-preference model of Stiglitz–Weiss, the direct benefit for a given borrower can be offset by deterioration in applicant composition. Behavior, selection, and actual recovery must therefore be examined separately; more collateral is not an unconditional safety ranking.
<!-- bilingual-en:end -->
