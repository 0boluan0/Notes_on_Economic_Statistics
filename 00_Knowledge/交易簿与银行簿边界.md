# 监管交易簿与银行簿边界不等于短炒长持或会计分类的简单二分
*The regulatory trading-book boundary is not a simple short-term-versus-hold-to-maturity or accounting split*

> [!summary] 监管指定的风险归属
> 交易簿通常承载为短期转售、从实际或预期短期价格变动获利、套利或对冲交易簿风险而持有的工具；银行簿承载其余银行业务头寸。但分类还受工具类型、可交易性、估值和明确的纳入、排除与转移规则约束。

会计上的 fair value / amortised cost、管理层口头说的“长期持有”以及监管交易簿不是同一分类系统。某项工具按会计准则以公允价值计量，不必然进入监管交易簿；某些法律实体或工具又可能被监管规则明确要求进入或排除。

边界之所以严格，是为了防止银行在信用风险与市场风险资本方法之间择低。初始指定要有文件、交易策略、估值与风险管理支持；簿间转移受到限制，通常不能仅凭资本更低而转移，且转移带来的资本利益会被监管处理。

例：银行持有一张长期债券用于结构性流动性管理，期限长并不自动证明是银行簿；必须看交易意图、监管推定、指定与管理方式。反过来，交易簿工具也可能持有超过数日。

## 边界

- 银行簿不是“无市场风险”；利率、信用利差和期权风险仍可能存在，只是适用资本与监督框架不同。
- 交易簿不是“所有衍生品”的同义词。
- 最终分类须逐工具核对当前本地实施规则。

> [!question]- 自检
> 为什么“这张债券准备长期持有”不足以决定其监管簿别？
>
> **答案：** 监管分类还取决于规则中的推定、交易意图、工具资格、管理与文件，不能只看期限或一句内部标签。
