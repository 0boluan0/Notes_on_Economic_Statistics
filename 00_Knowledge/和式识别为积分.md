# Recognising a Riemann-sum limit
<!-- bilingual-en:end -->
*和式识别为积分*

<!-- bilingual-en:start -->
A limit of sums can sometimes be evaluated by recognising a [[黎曼和|Riemann sum]]: each term is a sampled height multiplied by a small interval width. The main task is to identify the interval, the sample locations, and the width without losing a scale factor. We then need a reason that the corresponding function is integrable before replacing the limit by an integral.
<!-- bilingual-en:end -->

有些和式极限可以通过识别[[黎曼和]]来计算：每一项都是“采样高度乘以小段宽度”。关键是找准区间、采样位置和段宽，保留全部缩放系数；然后说明对应函数为什么可积，才能把极限改写为积分。

<!-- bilingual-en:start -->
For example, consider $A_n=\frac1n\sum_{i=1}^n(2+3i/n)^2$, where the positive integer $n$ is the number of terms. The sample inputs $2+3i/n$ run across $[2,5]$ in steps of $3/n$. The visible coefficient $1/n$ is therefore only one third of the width for that interval. Keeping that factor is what makes the calculation correct.
<!-- bilingual-en:end -->

例如，考虑 $A_n=\frac1n\sum_{i=1}^n(2+3i/n)^2$，正整数 $n$ 是项数。采样输入 $2+3i/n$ 在 $[2,5]$ 中以 $3/n$ 为步长排列。所以，眼前的系数 $1/n$ 只是这个区间段宽的三分之一。保留这层系数，计算才会正确。

<!-- bilingual-en:start -->
## Match the grid to a fixed function
<!-- bilingual-en:end -->
*把网格与一个固定函数对应起来*

<!-- bilingual-en:start -->
Choose fixed finite endpoints $a<b$ and a fixed real-valued function $f$ on $[a,b]$. Dividing into $n$ equal pieces gives the width $\Delta x=(b-a)/n$ and the right endpoints $x_i=a+i\Delta x$ for $i=1,\ldots,n$. In particular, $x_1$ is the first piece's right endpoint and $x_n=b$. The corresponding sum is
<!-- bilingual-en:end -->

选定不随 $n$ 改变的有限端点 $a<b$，以及定义在 $[a,b]$ 上的固定实值函数 $f$。等分为 $n$ 段，段宽就是 $\Delta x=(b-a)/n$，右端点为 $x_i=a+i\Delta x$（$i=1,\ldots,n$）。其中，$x_1$ 是第一段的右端点，$x_n=b$。对应的和为

$$S_n=\sum_{i=1}^n f\!\left(a+i\frac{b-a}{n}\right)\frac{b-a}{n}.$$

> [!important] Integrability licenses the limit · 可积性保证这一步极限转换
> <!-- bilingual-en:start -->
> If $f$ is Riemann integrable on $[a,b]$, then
> <!-- bilingual-en:end -->
>
> 若 $f$ 在 $[a,b]$ 上黎曼可积，则
>
> $$\lim_{n\to\infty}S_n=\int_a^b f(x)\,dx.$$
>
> <!-- bilingual-en:start -->
> The mesh is $(b-a)/n\to0$, so this is one permitted sequence in the [[定积分|definition of the integral]]. [[连续函数可积|Continuity throughout the finite closed interval]] is a sufficient condition that often makes the check immediate. Left endpoints, midpoints, or any one tag inside each piece also work under the same integrability assumption.
> <!-- bilingual-en:end -->
>
> 网格大小为 $(b-a)/n\to0$，所以这是一列符合[[定积分]]定义的分割。[[连续函数可积|在整个有限闭区间上连续]]是常用充分条件，往往能直接完成检查。在同一可积性前提下，左端点、中点或每段内任取一个采样点也都适用。

<!-- bilingual-en:start -->
This is a way to use known integrability, not to infer it from one convenient sequence of sums. A function can give convergent right-endpoint sums and still fail the all-tags requirement; the [[黎曼和|Riemann-sum definition]] gives an explicit example. If the function or interval itself changes with $n$, the displayed fixed-function rule does not by itself justify the limit.
<!-- bilingual-en:end -->

这里是在利用已知的可积性，而不是从一列方便计算的和反推可积性。一个函数的右端点和可以收敛，却不满足所有采样方式的共同极限要求；[[黎曼和]]中给出了具体反例。如果函数或区间本身也随 $n$ 改变，上面针对固定函数的规则本身不能保证极限转换。

<!-- bilingual-en:start -->
## One sum, two useful coordinate choices
<!-- bilingual-en:end -->
*同一个和，可以选择两套坐标*

<!-- bilingual-en:start -->
Return to $A_n$. On $[2,5]$, take $f(x)=x^2$, $\Delta x=3/n$, and $x_i=2+3i/n$. The square function is continuous, and the exact finite-sum identity is
<!-- bilingual-en:end -->

回到 $A_n$。在 $[2,5]$ 上取 $f(x)=x^2$、$\Delta x=3/n$、$x_i=2+3i/n$。平方函数连续，而下面首先是有限和之间的精确等式：

$$A_n=\frac13\sum_{i=1}^n\left(2+\frac{3i}{n}\right)^2\frac3n
\longrightarrow\frac13\int_2^5x^2\,dx
=\frac13\left[\frac{x^3}{3}\right]_2^5=13.$$

<!-- bilingual-en:start -->
The bracket means the value at $5$ minus the value at $2$; [[Newton-Leibniz公式|endpoint evaluation]] applies because $x^3/3$ has derivative $x^2$. Alternatively, use $t_i=i/n$ on $[0,1]$ and the fixed function $g(t)=(2+3t)^2$. Now the original coefficient $1/n$ is already the width:
<!-- bilingual-en:end -->

方括号表示代入 $5$ 的值减去代入 $2$ 的值；因为 $x^3/3$ 的导数是 $x^2$，可用[[Newton-Leibniz公式]]作端点评价。另一种做法是在 $[0,1]$ 上取 $t_i=i/n$，把固定函数选为 $g(t)=(2+3t)^2$。此时原系数 $1/n$ 正好就是段宽：

$$A_n\longrightarrow\int_0^1(2+3t)^2\,dt
=\int_0^1(4+12t+9t^2)\,dt=4+6+3=13.$$

<!-- bilingual-en:start -->
Both choices describe the same finite sums. The corresponding integrals agree by [[定积分换元|substitution]] $x=2+3t$, with $dx=3\,dt$. The two descriptions are alternatives; the interval and function must be chosen together.
<!-- bilingual-en:end -->

两种坐标描述的是同一组有限和。对应的两个积分通过[[定积分换元]] $x=2+3t$、$dx=3\,dt$ 相连。它们是两套可选描述，区间和函数必须配套选择。

> [!warning] A missing width changes the limit · 漏掉段宽会改变极限
> <!-- bilingual-en:start -->
> On $[0,1]$, $\frac1n\sum_{i=1}^n(i/n)^2\to1/3$. Without the factor $1/n$, the sum is $n$ times as large and diverges to $+\infty$. Seeing inputs $i/n$ alone is not enough to recognise an integral with value $1/3$.
> <!-- bilingual-en:end -->
>
> 在 $[0,1]$ 上，$\frac1n\sum_{i=1}^n(i/n)^2\to1/3$。若去掉系数 $1/n$，和会扩大为原来的 $n$ 倍，并趋于 $+\infty$。仅看见输入 $i/n$，不能就把结果认作值为 $1/3$ 的积分。

## Compute an integral from a finite-sum identity
<!-- bilingual-en:end -->
*也可以用有限和恒等式计算积分*

<!-- bilingual-en:start -->
For a fixed real $b>0$, use right endpoints on $[0,b]$ for $f(x)=x^2$. The exact formula $\sum_{i=1}^n i^2=n(n+1)(2n+1)/6$ gives
<!-- bilingual-en:end -->

对固定实数 $b>0$，在 $[0,b]$ 上对 $f(x)=x^2$ 取右端点和。由精确公式 $\sum_{i=1}^n i^2=n(n+1)(2n+1)/6$，得到

$$\sum_{i=1}^n\left(\frac{ib}{n}\right)^2\frac bn
=\frac{b^3}{n^3}\frac{n(n+1)(2n+1)}6
=\frac{b^3}{6}\left(1+\frac1n\right)\left(2+\frac1n\right)
\longrightarrow\frac{b^3}{3}.$$

<!-- bilingual-en:start -->
The finite identity can be checked without using an integral: set $Q(n)=n(n+1)(2n+1)/6$. Then $Q(1)=1$ and, for integers $n\ge2$, $Q(n)-Q(n-1)=n^2$, so successive differences reproduce the sum. Since $x^2$ is continuous and hence integrable on $[0,b]$, the limit equals $\int_0^b x^2\,dx$. This derives the integral's value without first finding an antiderivative.
<!-- bilingual-en:end -->

有限和恒等式不必借助积分来验证：设 $Q(n)=n(n+1)(2n+1)/6$，则 $Q(1)=1$，且对整数 $n\ge2$ 有 $Q(n)-Q(n-1)=n^2$；逐项相加便还原平方和。又因为 $x^2$ 在 $[0,b]$ 上连续、从而可积，这个极限确实等于 $\int_0^b x^2\,dx$。这条路线不必先找原函数，也能得到积分值。
