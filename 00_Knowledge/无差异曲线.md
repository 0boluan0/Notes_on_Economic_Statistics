# Indifference curves
<!-- bilingual-en:end -->

*无差异曲线*

<!-- bilingual-en:start -->
An indifference curve collects the combinations of goods that a person regards as equally good. Moving from one bundle to another on that same curve changes the quantities consumed while keeping the preference ranking tied. With two goods, the horizontal and vertical coordinates are the quantities of the two goods; neither axis is utility.

An [[效用函数|ordinal utility function]] assigns equal scores exactly to bundles between which the person is indifferent. An indifference curve is therefore a [[水平集|level set]] of that function: it collects inputs producing the same output. The more general name **indifference set** also covers cases where the set is not a smooth curve.
<!-- bilingual-en:end -->

无差异曲线收集一个人认为一样好的各种商品组合。沿着同一条曲线从一个商品束移到另一个，消费数量改变了，偏好评价仍然相同。两种商品时，横、纵坐标分别是两种商品的数量，两个坐标轴都不是效用。

[[效用函数|序数效用函数]]恰好给无差异的商品束相同分数，因此无差异曲线就是它的[[水平集]]：输出值相同的输入集合。更一般的名称是**无差异集合**，也涵盖集合不是光滑曲线的情形。

<!-- bilingual-en:start -->
## Fix a bundle, then find everything tied with it
<!-- bilingual-en:end -->

*先选一个组合，再找所有与它一样好的组合*

<!-- bilingual-en:start -->
Let $X$ be the consumption set, let $u:X\to\mathbb R$ represent the person's preferences, and choose a reference bundle $x^0\in X$. The superscript $0$ is a label for the reference bundle, not an exponent. Its indifference set is
<!-- bilingual-en:end -->

$$
I(x^0)=\{x\in X:u(x)=u(x^0)\}.
$$

<!-- bilingual-en:start -->
Equivalently, if $k=u(x^0)$, write $I_k=\{x\in X:u(x)=k\}$. The reference bundle always belongs to its own set. A numerical label $k$ that the function never attains gives an empty level set, not an indifference curve through an existing bundle.

> [!example] Three bundles on the same curve
> On the positive quadrant $X=(0,\infty)^2$, take $u(x_1,x_2)=x_1x_2$. The bundles $(1,4)$, $(2,2)$ and $(4,1)$ all score $4$. The entire level-$4$ curve is $x_2=4/x_1$ with $x_1>0$. Each of its points represents a different combination tied in this model.
<!-- bilingual-en:end -->

$X$ 是消费集合，$u:X\to\mathbb R$ 表示偏好，$x^0\in X$ 是参照商品束；上标 $0$ 是标签，不是幂次。令 $k=u(x^0)$，也可写为 $I_k=\{x\in X:u(x)=k\}$。参照商品束必定在自己的无差异集合里；若一个数值 $k$ 从未被取到，所得水平集为空，不是穿过某个现有商品束的曲线。

> [!example] 同一条曲线上的三个组合
> 在正象限 $X=(0,\infty)^2$ 上取 $u(x_1,x_2)=x_1x_2$。$(1,4)$、$(2,2)$、$(4,1)$ 都得到 $4$；完整的水平为 $4$ 的曲线是 $x_2=4/x_1$、$x_1>0$。每个点都是该模型中被视为一样好的不同组合。

<!-- bilingual-en:start -->
## A curve and the region above a threshold
<!-- bilingual-en:end -->

*一条曲线与达到门槛的区域*

<!-- bilingual-en:start -->
The [[上轮廓集|upper contour set]] $\{x\in X:u(x)\ge k\}$ instead contains all bundles at least as good as level $k$. It includes the tied bundles, but also any strictly preferred ones. For the product example, $I_4$ satisfies $x_1x_2=4$, whereas the upper contour region satisfies $x_1x_2\ge4$.

This distinction matters when discussing convexity. The midpoint of $(1,4)$ and $(4,1)$ is $(5/2,5/2)$, with utility $25/4>4$. It lies in the upper contour region but not on the indifference curve. Thus the curve itself is not a [[凸集|convex set]], even though the product function's upper contour sets are convex. The latter property is [[拟凹函数|quasiconcavity]], whose product example is proved in [[凹性推出拟凹性|concavity and quasiconcavity]].
<!-- bilingual-en:end -->

[[上轮廓集]] $\{x\in X:u(x)\ge k\}$ 收集的是所有至少达到该效用水平的商品束，既包括无差异的组合，也包括严格更喜欢的组合。乘积例中的 $I_4$ 满足 $x_1x_2=4$，上轮廓区域则满足 $x_1x_2\ge4$。

谈凸性时，这一区别很关键：$(1,4)$ 和 $(4,1)$ 的中点是 $(5/2,5/2)$，效用为 $25/4>4$，因此属于上轮廓区域，却不在无差异曲线上。曲线本身不是[[凸集]]，即使该函数的上轮廓集是凸的。后一个性质才是[[拟凹函数|拟凹性]]，乘积例的完整证明见[[凹性推出拟凹性|凹性与拟凹性]]。

## Which features need extra assumptions?
<!-- bilingual-en:end -->

*哪些图形特征需要额外假设？*

<!-- bilingual-en:start -->
Different utility levels of one function cannot share an input: if $x$ belonged to both $I_k$ and $I_\ell$, then $u(x)=k$ and $u(x)=\ell$, forcing $k=\ell$. This is the precise sense in which different indifference sets do not cross. It does not require that one level set be connected or smooth.

> [!example] Equal preference need not look like a smooth downward curve
> On nonnegative quantities, $u(x_1,x_2)=\min\{x_1,x_2\}$ has a level-$1$ set consisting of $x_1=1,x_2\ge1$ together with $x_2=1,x_1\ge1$: an L with a corner. If $u=x_1-x_2$, more of good 1 helps while more of item 2 hurts, so a constant-utility line is upward-sloping. If $u$ is constant, the whole consumption set is one indifference set.

When a local indifference curve is differentiable and the relevant derivative is nonzero, its trade-off can be described by the [[边际替代率|marginal rate of substitution]]. Those conditions belong to the slope calculation, not to the definition of indifference.
<!-- bilingual-en:end -->

同一函数的两个不同效用水平不能共享一个输入：若 $x$ 同时属于 $I_k$ 与 $I_\ell$，便有 $u(x)=k=\ell$。这才是不同无差异集合“不相交”的精确含义，并不要求一个水平集连通或光滑。

> [!example] 无差异未必画成光滑下降曲线
> 在非负数量上，$u(x_1,x_2)=\min\{x_1,x_2\}$ 的水平为 $1$ 的集合由 $x_1=1,x_2\ge1$ 和 $x_2=1,x_1\ge1$ 两条射线组成，是带拐角的 L 形。若 $u=x_1-x_2$，第一种物品越多越好，第二种越多越差，等效用线便向上倾斜。若 $u$ 是常数，整个消费集合都是同一个无差异集合。

在局部曲线可微、相关偏导非零时，可以用[[边际替代率]]描述保持效用时的局部交换比率。这些条件用于斜率计算，不是无差异的定义条件。

## Changing the utility label
<!-- bilingual-en:end -->

*给同一条曲线换一个效用标签*

<!-- bilingual-en:start -->
For an attained label $k\in u(X)$, if $v=g\circ u$ with $g$ strictly increasing on the range of $u$, then $v(x)=g(k)$ if and only if $u(x)=k$. Rescaling therefore changes a curve's numerical label while leaving its input points unchanged. In the product example, $v=3u+7$ labels the same curve $19$ rather than $4$. Its meaning as a collection of equally preferred bundles stays fixed.
<!-- bilingual-en:end -->

对已取得的标签 $k\in u(X)$，若 $v=g\circ u$ 且 $g$ 在 $u$ 的值域上严格递增，则 $v(x)=g(k)$ 当且仅当 $u(x)=k$。改标只改变数值标签，不改变曲线由哪些输入点组成。乘积例改用 $v=3u+7$ 后，同一条曲线的标签从 $4$ 变成 $19$，“这些商品束一样好”的含义保持不变。
