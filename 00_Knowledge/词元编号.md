# Token ID
<!-- bilingual-en:end -->

*词元编号*

<!-- bilingual-en:start -->
A token ID is the integer assigned to an entry in one tokenizer’s vocabulary. Encoding text produces a sequence of these integers. Decoding a sequence reconstructs text according to the chosen encoding. A model embeds an ID by gathering the corresponding row of its input table.
<!-- bilingual-en:end -->

词元编号（token ID）是某套分词器词表给词元分配的整数。把文字编码后会得到一串编号。按同一套编码规则解码才能还原相应文字。模型读取编号对应的行，取出[[00_Knowledge/Token嵌入|词元嵌入向量]]。

<!-- bilingual-en:start -->
## Reading an ID in context
<!-- bilingual-en:end -->

*编号依赖词表*

<!-- bilingual-en:start -->
GPT-2 assigns ID 64 to the ASCII letter a, whose UTF-8 byte value is 97. The byte value specifies its text encoding, and the token ID addresses a vocabulary entry. Token IDs from another tokenizer need its own ID-to-piece mapping. A lossless tokenizer may need several IDs to reconstruct one character. See [[00_Knowledge/字节级分词覆盖|byte-level coverage]].
<!-- bilingual-en:end -->

字母 `a` 的 UTF-8 字节值是 97，而 GPT-2 给它的 token ID 是 64。前者由字符编码规定，后者用来索引词表。同一个整数放到另一套分词器中要按另一套映射读取。完整字符还可能需要连续几个编号才能还原，见[[00_Knowledge/字节级分词覆盖]]。
