# Adding an independent linear constraint to a consistent system reduces solution-set dimension by one
<!-- bilingual-en:end -->
*相容线性系统增加一条独立线性约束会使解集维数减少一*

<!-- bilingual-en:start -->
Let $A\in\mathbb R^{m\times n}$ and let $Ax=b$ be consistent, with $\operatorname{rank}(A)=r$. Its solution set has dimension $n-r$. If the new row $c^T$ is **outside the row space of $A$**, adding $c^Tx=d$ raises the rank to $r+1$ and leaves $n-r-1$ degrees of freedom. A differently written equation need not be independent.
<!-- bilingual-en:end -->

设 $A\in\mathbb R^{m\times n}$，$Ax=b$ 相容，且 $\operatorname{rank}(A)=r$，则解集维数为 $n-r$。如果新行 $c^T$ **不在 $A$ 的行空间中**，增加 $c^Tx=d$ 就使秩变为 $r+1$，剩余自由度为 $n-r-1$。写法不同的方程未必独立。

<!-- bilingual-en:start -->
To see why the dimension changes, use the [[特解加零空间|solution structure]] $x_p+N(A)$ and the [[秩零度定理|rank–nullity theorem]]. The extra independent row restricts one formerly free direction. It does not make an initially consistent system inconsistent: because the row space is $N(A)^\perp$, there is a $z\in N(A)$ with $c^Tz\ne0$. Thus $x_p+tz$ can satisfy the new equation for any real $d$ by choosing $t=(d-c^Tx_p)/(c^Tz)$.
<!-- bilingual-en:end -->

维数变化可由[[特解加零空间|解结构]] $x_p+N(A)$ 与[[秩零度定理]]看出：新增独立行限制了一个原来自由的方向。它不会使原本相容的系统变为矛盾：行空间就是 $N(A)^\perp$，所以存在 $z\in N(A)$ 满足 $c^Tz\ne0$。于是对任意实数 $d$，选择 $t=(d-c^Tx_p)/(c^Tz)$，就能让 $x_p+tz$ 满足新方程。

<!-- bilingual-en:start -->
If instead $c^T=\lambda^TA$, every old solution already has $c^Tx=\lambda^Tb$. The new equation is redundant when $d=\lambda^Tb$, and inconsistent when $d\ne\lambda^Tb$. In the inconsistent case the solution set is empty; $n-r$ is not a dimension formula for that empty set.
<!-- bilingual-en:end -->

若反而有 $c^T=\lambda^TA$，所有旧解早已满足 $c^Tx=\lambda^Tb$。当 $d=\lambda^Tb$ 时，新方程冗余；当 $d\ne\lambda^Tb$ 时，新方程矛盾。矛盾时解集为空，不能再把 $n-r$ 当作这个空集的维数。

<!-- bilingual-en:start -->
Starting with $x+y=1$: adding $2x+2y=2$ preserves the line; adding $x-y=0$ leaves the point $(1/2,1/2)$; adding $x+y=2$ leaves no solution. Count independent compatible information, not the number of written equations.
<!-- bilingual-en:end -->

从 $x+y=1$ 出发：加入 $2x+2y=2$ 保留原直线；加入 $x-y=0$ 只剩点 $(1/2,1/2)$；加入 $x+y=2$ 则无解。要数的是独立且相容的信息，而不是纸面上的方程条数。
