# Limit of a function
<!-- bilingual-en:end -->
*函数极限*

<!-- bilingual-en:start -->
A **limit** describes the output of a function when its input is sufficiently close to a chosen point. Think of $f(x)$ as a rule that takes an input $x$ and returns an output. The question is: as inputs approach $a$, do all nearby outputs settle arbitrarily close to one number $L$?
<!-- bilingual-en:end -->

**极限**描述输入足够接近某个位置时，函数输出会怎样。可以把 $f(x)$ 看成一条规则：输入 $x$，得到输出。要问的是：当输入靠近 $a$ 时，附近所有输出能不能都被限制在某个数 $L$ 的任意小范围内？

$$\lim_{x\to a}f(x)=L.$$

<!-- bilingual-en:start -->
Here $x\to a$ means that $x$ approaches $a$ through values in the function's domain; $L$ is the proposed limiting output. It is a statement about a whole neighbourhood, not a calculation at just one input.
<!-- bilingual-en:end -->

这里 $x\to a$ 表示 $x$ 从函数定义域中的取值靠近 $a$，$L$ 是候选的极限输出。这是关于整个邻近范围的陈述，不是只计算某一个输入。

> [!example] Inputs near one, outputs near two · 输入靠近一，输出靠近二
> <!-- bilingual-en:start -->
> For $f(x)=2x$, inputs $0.99$ and $1.01$ give $1.98$ and $2.02$. Inputs $0.999$ and $1.001$ give $1.998$ and $2.002$. These numbers suggest that the limit at $a=1$ is $L=2$. To establish it, we need a guarantee for every sufficiently close input, not just the four values we tried.
> <!-- bilingual-en:end -->
>
> 对 $f(x)=2x$，输入 $0.99$ 与 $1.01$ 得到 $1.98$ 与 $2.02$；输入 $0.999$ 与 $1.001$ 得到 $1.998$ 与 $2.002$。这些数字提示：在 $a=1$ 处，极限为 $L=2$。但要真正确定极限，必须保证所有足够近的输入都满足要求，而不只是刚才试过的四个值。

<!-- bilingual-en:start -->
## An output tolerance determines an input tolerance
<!-- bilingual-en:end -->
*先要求输出多准确，再决定输入要多接近*

<!-- bilingual-en:start -->
The symbols $\varepsilon$ (epsilon) and $\delta$ (delta) name two positive tolerances. The distance $|f(x)-L|$ measures output error; the distance $|x-a|$ measures how far the input is from $a$. Absolute value turns either a positive or a negative difference into a nonnegative distance.
<!-- bilingual-en:end -->

$\varepsilon$（epsilon）和 $\delta$（delta）是两个正的容差。$|f(x)-L|$ 衡量输出误差，$|x-a|$ 衡量输入离 $a$ 多远；绝对值把正差或负差都变成非负距离。

> [!abstract] The epsilon–delta definition · ε–δ 定义
> <!-- bilingual-en:start -->
> Let $f:S\to\mathbb R$, meaning that $S$ is its set of allowed inputs and its outputs are real numbers. Assume that $S$ has points other than $a$ arbitrarily close to $a$; this is what it means for $a$ to be a **cluster point** of $S$. A finite real number $L$ is the limit when, for every $\varepsilon>0$, some $\delta>0$ makes the following implication true for every $x\in S$:
> <!-- bilingual-en:end -->
>
> 设 $f:S\to\mathbb R$，即 $S$ 是允许的输入集合，输出是实数。还要假设 $S$ 中存在不同于 $a$、却可以任意靠近 $a$ 的点；这就是 $a$ 是 $S$ 的**聚点**。有限实数 $L$ 是极限，意味着对每一个 $\varepsilon>0$，都能找到某个 $\delta>0$，使所有 $x\in S$ 都满足：
>
> $$0<|x-a|<\delta\quad\Longrightarrow\quad |f(x)-L|<\varepsilon.$$
>
> <!-- bilingual-en:start -->
> Choose the output accuracy first. Then one input neighbourhood must work for every allowed input inside it, apart from $a$ itself. The chosen $\delta$ may depend on $\varepsilon$, but not on a particular $x$ picked afterwards.
> <!-- bilingual-en:end -->
>
> 先提出输出精度要求，再给出一个输入范围；除 $a$ 本身以外，这个范围内的所有合法输入都必须满足要求。选出的 $\delta$ 可以依赖 $\varepsilon$，但不能随着之后挑出的某个 $x$ 临时改变。

<!-- bilingual-en:start -->
For $f(x)=2x$ at $a=1$, output error is exactly twice input distance:
<!-- bilingual-en:end -->

对 $f(x)=2x$ 在 $a=1$ 附近的情况，输出误差恰好是输入距离的两倍：

$$|2x-2|=2|x-1|.$$

<!-- bilingual-en:start -->
If the requested output tolerance is $0.01$, choosing $\delta=0.005$ works. More generally, given any $\varepsilon>0$, choose $\delta=\varepsilon/2$. Then $0<|x-1|<\delta$ forces $|2x-2|<\varepsilon$. This establishes the limit for every requested accuracy.
<!-- bilingual-en:end -->

如果要求输出误差小于 $0.01$，取 $\delta=0.005$ 即可。一般地，给定任意 $\varepsilon>0$，取 $\delta=\varepsilon/2$，就能让 $0<|x-1|<\delta$ 保证 $|2x-2|<\varepsilon$。这样才覆盖了任意精度要求。

## The point value and the direction are separate questions
<!-- bilingual-en:end -->
*点值与趋近方向要分别判断*

<!-- bilingual-en:start -->
The condition $0<|x-a|$ deliberately excludes $x=a$. We could change only $f(1)$ to $100$, or leave it undefined, while keeping $f(x)=2x$ everywhere else; the limit at one would still be two. See [[点值不决定极限|why the value at a point does not determine its limit]]. [[一点连续|Continuity]] adds the extra requirement that the point value exists and agrees with the limit.
<!-- bilingual-en:end -->

条件 $0<|x-a|$ 特意排除了 $x=a$。如果只把 $f(1)$ 改成 $100$，或者干脆不定义它，其余位置仍取 $f(x)=2x$，在 $x=1$ 处的极限依旧是二。见[[点值不决定极限]]。[[一点连续|连续性]]还额外要求：点值存在，并且等于极限。

> [!warning] Approaching from one side may miss a problem · 只从一侧靠近可能漏掉问题
> <!-- bilingual-en:start -->
> For a function defined on both sides of $a$, the two sides must approach the same finite value. If $f(x)=-1$ for $x<0$ and $f(x)=1$ for $x>0$, the left side approaches $-1$ and the right side approaches $1$, so there is no two-sided limit at zero. The precise comparison is in [[双侧极限判定|the two-sided limit criterion]].
> <!-- bilingual-en:end -->
>
> 若函数在 $a$ 两侧都有定义，左右两侧必须趋向同一个有限值。例如 $x<0$ 时 $f(x)=-1$，$x>0$ 时 $f(x)=1$，则左侧趋于 $-1$、右侧趋于 $1$，在零处不存在双侧极限。具体判断见[[双侧极限判定]]。

<!-- bilingual-en:start -->
The domain matters: the definition only tests points where the function is defined. The cluster-point condition ensures that there really are nearby inputs to test. Limits with an infinite value or an input tending to infinity use the related but different definitions in [[无穷极限与无穷远极限|infinite limits and limits at infinity]].
<!-- bilingual-en:end -->

定义域也很重要：只检查函数有定义的点。聚点条件保证附近确实有输入可供检查。极限值无穷或输入趋于无穷时，使用相关但不同的定义，见[[无穷极限与无穷远极限]]。
