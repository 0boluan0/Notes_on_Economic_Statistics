# 最优解对应把每个参数映射到该参数下所有达到最优值的可行选择组成的集合
<!-- bilingual-en:start -->
*A solution correspondence maps each parameter to the set of all feasible choices that attain the optimal value at that parameter*
<!-- bilingual-en:end -->

> [!summary] 它是什么
> 给定
> $$
> v(\theta)=\sup_{x\in X(\theta)} f(x,\theta),
> $$
> 最优解对应（solution correspondence）定义为
> $$
> S(\theta)
> =\operatorname*{argmax}_{x\in X(\theta)} f(x,\theta)
> =\{x\in X(\theta):f(x,\theta)=v(\theta)\}.
> $$
> $S(\theta)$ 的值是一个集合，可以为空、单点或含有多个选择。
>
> <!-- bilingual-en:start -->
> Given $v(\theta)=\sup_{x\in X(\theta)}f(x,\theta)$, the solution correspondence is $S(\theta)=\arg\max_{x\in X(\theta)}f(x,\theta)=\{x\in X(\theta):f(x,\theta)=v(\theta)\}$. Its value is a set that may be empty, a singleton, or multivalued.
> <!-- bilingual-en:end -->

## 为什么叫“对应”而不默认是普通函数
<!-- bilingual-en:start -->
*Why it is a correspondence rather than automatically an ordinary function*
<!-- bilingual-en:end -->

参数不一定唯一决定一个最优选择。例如在 $[-1,1]$ 上最大化零函数，每个可行点都最优，所以 $S=[-1,1]$。若把这个集合强行写成某一条单值路径，会丢掉多解信息，并且人为选择出可能跳跃的分支。

<!-- bilingual-en:start -->
A parameter need not identify a unique optimizer. Maximising the zero function on $[-1,1]$ makes every feasible point optimal. Forcing this set into one selected path discards multiplicity and may create artificial jumps.
<!-- bilingual-en:end -->

一个最小的参数例子是
$$
\max_{x\in[-1,1]}\theta x.
$$
它的最优解对应为
$$
S(\theta)=
\begin{cases}
\{-1\},&\theta<0,\\
[-1,1],&\theta=0,\\
\{1\},&\theta>0.
\end{cases}
$$
零点的多值不是记号故障；它正确保留了该参数下的全部最优选择。

<!-- bilingual-en:start -->
For $\max_{x\in[-1,1]}\theta x$, the solution set is $\{-1\}$ for negative $\theta$, all of $[-1,1]$ at zero, and $\{1\}$ for positive $\theta$. The multivalued point is genuine information, not a notation failure.
<!-- bilingual-en:end -->

## 空集、单点与多点各自说明什么
<!-- bilingual-en:start -->
*What empty, singleton, and multivalued solution sets mean*
<!-- bilingual-en:end -->

- $S(\theta)=\varnothing$：上确界可能有限，但没有被取得；也可能根本没有可行点。
- $S(\theta)$ 是单点：该参数下的最优选择唯一。
- $S(\theta)$ 含多点：多个选择共享同一最优值；这不妨碍 [[值函数]] 本身是单值的。

<!-- bilingual-en:start -->
An empty solution set may reflect nonattainment or infeasibility. A singleton means a unique optimizer. A multivalued set means several choices share the same optimal value; the value function remains single-valued.
<!-- bilingual-en:end -->

非空性需要取得性定理，唯一性需要严格凹性等另外的结构。“值函数存在”不能代替“最优解对应非空”的证明。

<!-- bilingual-en:start -->
Nonemptiness requires an attainment result, and uniqueness requires separate structure such as strict concavity. Existence of a value does not prove that the solution correspondence is nonempty.
<!-- bilingual-en:end -->

> [!question]- 自检
> 在 $(0,1)$ 上最大化 $x$ 时，值函数和最优解对应分别是什么？
>
> <!-- bilingual-en:start -->
> When maximising $x$ over $(0,1)$, what are the optimal value and the solution correspondence?
> <!-- bilingual-en:end -->
>
> **答案：** 最优值是上确界 $1$，但该值不被取得，所以最优解对应为空集。
>
> <!-- bilingual-en:start -->
> **Answer:** The optimal value is the supremum one, but it is unattained, so the solution correspondence is empty.
> <!-- bilingual-en:end -->
