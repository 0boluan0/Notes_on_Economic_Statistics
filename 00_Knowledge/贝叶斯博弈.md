# 贝叶斯博弈由玩家、行动、收益参数、类型、收益函数与每个类型的事中信念构成
<!-- bilingual-en:start -->
*A Bayesian game consists of players, actions, payoff parameters, types, payoff functions, and each type's interim belief*
<!-- bilingual-en:end -->

**贝叶斯博弈**是一类不完全信息博弈：每名玩家知道自己的[[博弈类型|类型]]，该类型带有对未知收益参数与他人类型的[[事中信念]]，而收益函数说明行动组合在各个参数状态下产生什么收益。
<!-- bilingual-en:start -->
A **Bayesian game** is a game of incomplete information in which each player observes their own [[博弈类型|type]], that type carries an [[事中信念|interim belief]] about unknown payoff parameters and other players' types, and payoff functions assign consequences to actions in each parameter state.
<!-- bilingual-en:end -->

## 模型逐项写开

<!-- bilingual-en:start -->
*Writing Out the Model Component by Component*
<!-- bilingual-en:end -->

采用 MIT 14.126 的 interim 表述，一场贝叶斯博弈可写为

<!-- bilingual-en:start -->
Using the interim formulation from MIT 14.126, a Bayesian game can be written as
<!-- bilingual-en:end -->

$$
B=(N,A,\Theta,T,u,p).
$$

- $N$ 是玩家集合；
- $A=\prod_{i\in N}A_i$ 是行动组合集合；
- $\Theta$ 是影响收益的物理参数或 payoff parameters；
- $T=\prod_{i\in N}T_i$ 是类型组合集合，每名玩家 $i$ 观察自己的 $t_i$；
- $u_i:\Theta\times A\to\mathbb R$ 是玩家 $i$ 的收益函数；
- $p_i(\cdot\mid t_i)\in\Delta(\Theta\times T_{-i})$ 是类型 $t_i$ 对未知参数与他人类型的 interim belief。

<!-- bilingual-en:start -->
- $N$ is the set of players;
- $A=\prod_{i\in N}A_i$ is the set of action profiles;
- $\Theta$ is the set of physical parameters, or payoff parameters, that affect payoffs;
- $T=\prod_{i\in N}T_i$ is the set of type profiles, and each player $i$ observes their own $t_i$;
- $u_i:\Theta\times A\to\mathbb R$ is player $i$'s payoff function;
- $p_i(\cdot\mid t_i)\in\Delta(\Theta\times T_{-i})$ is type $t_i$'s interim belief about the unknown parameters and the other players' types.
<!-- bilingual-en:end -->

因此，玩家并非只对“对手选什么”不确定。他还可能不知道真实成本、质量或状态 $\theta$，并对他人掌握的信息持有更高阶信念。若教材把类型直接放进收益函数 $u_i(t,a)$，那是另一种常见但可转换的记法；[[类型与收益参数]]解释了何时这种合并只是记号简化。
<!-- bilingual-en:start -->
Uncertainty may concern not only an opponent's action but also costs, qualities, physical states, and what other players know. Some texts absorb the payoff parameter into notation such as $u_i(t,a)$; [[类型与收益参数|types and payoff parameters]] explains when that is merely a convenient special case.
<!-- bilingual-en:end -->

## 模型、策略与均衡是三层

<!-- bilingual-en:start -->
*The Model, Strategies, and Equilibrium Are Three Distinct Layers*
<!-- bilingual-en:end -->

模型说明对象和信念；[[贝叶斯策略]]再说明每种自身类型分别采取什么行动；[[贝叶斯纳什均衡]]最后要求每个类型都在自己的条件信念下作最佳回应。[[贝叶斯博弈不要求共同先验]]说明共同先验在这一表述中的位置，[[Harsanyi转换]]则说明何时可以把模型画成一次共享的 Nature 抽取。
<!-- bilingual-en:start -->
The model specifies objects and beliefs; a [[贝叶斯策略|Bayesian strategy]] prescribes an action for every own type; and [[贝叶斯纳什均衡|Bayesian Nash equilibrium]] imposes a best response for each type. [[贝叶斯博弈不要求共同先验|Why a common prior is not required]] locates that additional assumption, while the [[Harsanyi转换|Harsanyi transformation]] explains when a shared lottery can be drawn.
<!-- bilingual-en:end -->

> [!warning] 与后续信号博弈的边界
> 静态贝叶斯博弈允许行动依赖私人类型，但本卡不讨论行动发生后怎样更新信念。若行动本身会被观察并传递类型信息，还要进入[[信号博弈与PBE.canvas|信号博弈与 PBE 原子图]]，加入路径上的 Bayes 更新与序贯理性。
> <!-- bilingual-en:start -->
> **Boundary with Later Signaling Games.** A static Bayesian game allows actions to depend on private types, but it does not address how beliefs are updated after actions occur. If actions are observed and convey information about types, the analysis must move to the [[信号博弈与PBE.canvas|signaling-games and PBE atom map]] and add on-path Bayesian updating and sequential rationality.
> <!-- bilingual-en:end -->

> [!question]- 自检
> 在五元组 $(N,A,\Theta,T,u,p)$ 中，哪一个对象说明玩家 $i$ 在看到 $t_i$ 后如何判断未知状态与他人类型？为什么只写收益函数和行动集合还不构成完整的贝叶斯博弈？
>
> **答案：** $p_i(\cdot\mid t_i)$ 给出该类型的事中信念。只有收益函数和行动集合仍未说明玩家知道什么以及怎样理解未知量，因此缺少类型与信念结构。
> <!-- bilingual-en:start -->
> **Self-check.** In the tuple $(N,A,\Theta,T,u,p)$, which object specifies how player $i$ assesses the unknown state and the other players' types after observing $t_i$? Why do payoff functions and action sets alone not constitute a complete Bayesian game?
>
> **Answer:** $p_i(\cdot\mid t_i)$ gives that type's interim belief. Payoff functions and action sets alone do not specify what the players know or how they understand the unknown quantities, so the type and belief structure is still missing.
> <!-- bilingual-en:end -->
