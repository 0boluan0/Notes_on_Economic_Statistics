# Closed classes and irreducibility
<!-- bilingual-en:end -->
*闭集合、闭沟通类与全链不可约*

<!-- bilingual-en:start -->
“Once the system enters this group, it cannot leave” and “every state can reach every other” answer different questions. The first checks the group's exits; the second checks movement throughout the chosen state space. A chain can contain closed classes while still being reducible, and a closed set can contain several classes.
<!-- bilingual-en:end -->

“系统进入这一组后出不去”和“任意状态都能到达其他任意状态”回答的是两个问题。前者检查该组的出口，后者检查指定状态空间中的内部互达。一条链可以有闭类，同时仍然可约；一个闭集合也可以包含多个类。

<!-- bilingual-en:start -->
Use a fixed [[DTMC时间齐次转移核|time-homogeneous rule]] on a finite or countably infinite nonempty set $S$. A [[马氏链沟通类|communicating class]] is a maximal group of states that can reach one another by finite positive-probability routes, allowing zero steps for a state's self-accessibility. A **closed set** has no positive-probability exit. A [[闭沟通类|closed communicating class]] satisfies both requirements. An [[不可约链|irreducible chain]] has the entire $S$ as one communicating class. The word “class” must retain its mutual-reachability requirement.
<!-- bilingual-en:end -->

考虑有限或可数无限非空状态集 $S$ 上固定的[[DTMC时间齐次转移核|时间齐次规则]]。[[马氏链沟通类|沟通类]]是能沿有限正概率路线互达的最大状态组，允许零步自我可达；**闭集合**没有正概率出口。[[闭沟通类]]要同时满足这两个要求。[[不可约链]]则要求整个 $S$ 就是一个沟通类。不能在使用“类”时丢掉内部互达的要求。

> [!example] Two absorbing destinations · 两个吸收终点
> <!-- bilingual-en:start -->
> In state order $0,a,b$, let
> <!-- bilingual-en:end -->
>
> 按 $0,a,b$ 排列状态，令
>
> $$P=\begin{pmatrix}0&1/2&1/2\\0&1&0\\0&0&1\end{pmatrix}.$$
>
> <!-- bilingual-en:start -->
> Starting at 0, the chain chooses $a$ or $b$ with equal probabilities and then remains there. Each destination is an [[吸收状态|absorbing state]]. The classes are $\{0\}$, $\{a\}$ and $\{b\}$; only the last two are closed. State 0 cannot be revisited after departure, so it is [[常返与暂态|transient]]. There is no route from $a$ to $b$, and the full chain is reducible.
> <!-- bilingual-en:end -->
>
> 从 0 出发，链以相同概率选择 $a$ 或 $b$，然后永远留在选中的状态。两个终点都是[[吸收状态]]。类分别为 $\{0\}$、$\{a\}$、$\{b\}$，只有后两个闭。0 离开后不能再访问，所以是[[常返与暂态|暂态状态]]。$a$ 无法到达 $b$，整条链可约。

<!-- bilingual-en:start -->
The set $\{a,b\}$ is closed: neither of its states has an exit from the set. It is **not** a communicating class, because $a$ and $b$ cannot reach each other. Nor can one declare $\{0,a,b\}$ to be a communicating class merely because it is closed: the full state space is always closed, since there are no allowed states outside it. Closedness alone supplies no test of full-chain irreducibility.
<!-- bilingual-en:end -->

集合 $\{a,b\}$ 闭，因为其中两个状态都没有通往该集合之外的出口。但它**不是**沟通类，因为 $a,b$ 不能互达。同样，不能因为 $\{0,a,b\}$ 闭，就宣布它是沟通类：完整状态空间总是闭的，因为模型没有允许的空间外状态。仅有闭性，不能判断全链是否不可约。

<!-- bilingual-en:start -->
## Even one closed class is not enough
<!-- bilingual-en:end -->
*恰有一个闭类也不等于全链不可约*

<!-- bilingual-en:start -->
Remove destination $b$ and let $0\to a$ with probability one, with $a$ absorbing. The matrix in order $0,a$ is

$$Q=\begin{pmatrix}0&1\\0&1\end{pmatrix}.$$

There is exactly one closed class, $\{a\}$, but also the nonclosed class $\{0\}$. The full chain remains reducible because $a$ cannot reach 0. What one closed class does guarantee for a finite chain is [[Markov稳态唯一判据|a unique stationary probability distribution]]; here it is $(0,1)$. That is a different property from irreducibility.
<!-- bilingual-en:end -->

去掉终点 $b$，令 $0$ 以概率一跳到吸收状态 $a$，状态顺序为 $0,a$，得到上面的 $Q$。这条链恰有一个闭类 $\{a\}$，但还有非闭类 $\{0\}$。由于 $a$ 无法到达 0，整条链仍可约。在有限链中，恰有一个闭类确实保证[[Markov稳态唯一判据|平稳概率分布唯一]]，这里就是 $(0,1)$；但这是与不可约不同的性质。

<!-- bilingual-en:start -->
## Restricting the chain changes the question
<!-- bilingual-en:end -->
*限制状态空间以后，问题才改变*

<!-- bilingual-en:start -->
If $C$ is a closed communicating class, keep only states in $C$ and their original transition probabilities. Closedness preserves row sums of one, while communication gives positive routes between every pair inside $C$. Such routes cannot leave $C$ and return: any intermediate state on a route between class members would communicate with them and therefore belong to the same class. The restricted chain is consequently irreducible.
<!-- bilingual-en:end -->

若 $C$ 是闭沟通类，只保留 $C$ 内状态及原有转移概率。闭性保证行和仍为一，互通性保证类内任意两状态间都有正概率路线。这些路线不可能离开 $C$ 后再返回：同类成员间路线上的任何中间状态都与它们互通，因此本来就属于同一类。所以，限制后的链不可约。

<!-- bilingual-en:start -->
In the two-destination example, restricting to $\{a\}$ gives the one-state transition matrix $(1)$, an irreducible chain. Restricting instead to the closed set $\{a,b\}$ gives the two-state [[单位矩阵|identity matrix]] $I_2$, which is still reducible. Thus “restricted to a closed **class**” and “restricted to a closed **set**” have different implications. Simply starting inside a class does not change the definition of irreducibility for the original full state space.
<!-- bilingual-en:end -->

在双终点例中，限制到 $\{a\}$ 得到单状态转移矩阵 $(1)$，这是不可约链。若限制到闭集合 $\{a,b\}$，则得到二阶[[单位矩阵]] $I_2$，仍然可约。因此，“限制到一个闭**类**”与“限制到一个闭**集合**”结论不同。仅把初态选在某个类内，也不会改变原完整状态空间上的不可约定义。

<!-- bilingual-en:start -->
These distinctions do not require a finite state space. Under the finite-state hypothesis, the further [[有限链类分解|decomposition theorem]] guarantees eventual entry into a closed class and recurrence there. In an infinite chain, a closed irreducible class may allow escape towards new states within that class, so closedness must not be substituted for [[常返与暂态|recurrence]].
<!-- bilingual-en:end -->

上述概念区别不要求状态空间有限。在有限状态假设下，更进一步的[[有限链类分解|类分解定理]]保证最终进入某个闭类，并在其中常返。无限链的闭不可约类内部可能允许不断向新状态漂移，所以不能用闭性代替[[常返与暂态|常返性]]。
