# Bisection error bounds
<!-- bilingual-en:end -->

*二分误差界*

<!-- bilingual-en:start -->
A bisection error bound tells us how far the reported input can be from a root, using the interval still known to contain one. If a root lies between $1.4$ and $1.5$, the midpoint $1.45$ is at most $0.05$ away from it. This conclusion comes from geometry alone; we do not need to know the exact root or evaluate the function at $1.45$.
<!-- bilingual-en:end -->

二分误差界利用仍然确定含根的区间，告诉我们返回的输入位置最多会差多少。若根在 $1.4$ 与 $1.5$ 之间，中点 $1.45$ 到它的距离就不超过 $0.05$。这是区间几何直接给出的结论，不需要知道精确根，也不需要计算 $1.45$ 处的函数值。

<!-- bilingual-en:start -->
First recall why [[二分求根|bisection]] keeps a valid interval: continuity and reliable opposite endpoint signs guarantee a root, and each sign-based update preserves that guarantee. Below, **width** means the distance between the endpoints; **positional error** means distance from the returned input to a bracketed root. A [[求根残差|residual]] instead measures the remaining function-value defect.
<!-- bilingual-en:end -->

先回顾[[二分求根]]为何能保住有效区间：连续性与可靠的端点异号保证有根，每次按符号更新后仍有这个保证。下面的**宽度**是两端点之间的距离；**位置误差**是返回输入到被括住根的距离。[[求根残差|残差]]则衡量函数输出还差多少。

> [!important] Half the current width · 当前宽度的一半
> <!-- bilingual-en:start -->
> In exact arithmetic, provided that the continuity and sign-changing-bracket invariant of [[二分求根|bisection]] hold, the current interval contains at least one root. After $n$ completed halvings its width is $L_n=L_0/2^n$, and the returned midpoint is at most half that width, $L_0/2^{n+1}$, from a bracketed root. This is a **positional-error bound**, not a bound on the residual $|f(m_n)|$.
> <!-- bilingual-en:end -->
>
> 在精确算术中，只要 [[二分求根]] 的连续性与异号括区间不变量成立，当前区间就至少含一个根。完成 $n$ 次对半更新后，区间宽度为 $L_n=L_0/2^n$；返回其中点时，位置误差至多为半个当前宽度，即 $L_0/2^{n+1}$。这是**位置误差界**，不是对残差 $|f(m_n)|$ 的界。

<!-- bilingual-en:start -->
## Fix the Iteration Convention First
<!-- bilingual-en:end -->

## 先固定计数约定

<!-- bilingual-en:start -->
Let the initial bracket be $[a_0,b_0]$ with width $L_0=b_0-a_0>0$. Here $n$ counts **completed bracket updates**: $n=0$ still denotes the initial bracket; after $n$ updates the interval is $[a_n,b_n]$ and its midpoint is $m_n=(a_n+b_n)/2$. A text or program that calls the first midpoint evaluation “iteration 1” shifts the subscripts by one, so the counting convention must be stated before using the formula.
<!-- bilingual-en:end -->

令初始括区间为 $[a_0,b_0]$，初始宽度为

$$
L_0=b_0-a_0>0.
$$

本文约定 $n$ 表示**已经完成的区间更新次数**：$n=0$ 时仍是初始区间；完成 $n$ 次更新后得到 $[a_n,b_n]$，并准备返回其中点

$$
m_n=\frac{a_n+b_n}{2}.
$$

若代码或教材把第一次取中点记作“第 1 轮”，公式的下标会整体平移；先声明计数约定，才能避免差一轮错误。

> [!example] Updates and evaluated midpoints · 更新次数与求值次数
> <!-- bilingual-en:start -->
> For $f(x)=x^2-2$ on the initial bracket $[1,2]$, $m_0=3/2$ is the **first** midpoint evaluated and has the initial bound $1/2$. After using its sign, the new interval is $[1,3/2]$: one update is complete, so its midpoint $m_1=5/4$ has bound $1/4$. Evaluating $m_1$ is the **second** midpoint evaluation. In general, the $N$th evaluated midpoint is $m_{N-1}$ and has the pre-update bound $L_0/2^N$.
> <!-- bilingual-en:end -->
>
> 对 $f(x)=x^2-2$，初始区间为 $[1,2]$ 时，$m_0=3/2$ 是**第一次**求值的中点，其初始误差界为 $1/2$。利用它的符号后得到 $[1,3/2]$，此时完成一次更新，所以新中点 $m_1=5/4$ 的误差界为 $1/4$。给 $m_1$ 求值是**第二次**中点求值。一般来说，第 $N$ 次求值的中点是 $m_{N-1}$，更新前的误差界为 $L_0/2^N$。

<!-- bilingual-en:start -->
## The Width Recurrence Directly Certifies Positional Error
<!-- bilingual-en:end -->

## 宽度递推直接给出位置误差界

<!-- bilingual-en:start -->
In exact arithmetic, each update retains exactly one half of the current interval, so $L_{n+1}=L_n/2$ and hence $L_n=L_0/2^n$. The bracket invariant guarantees at least one root inside $[a_n,b_n]$. For any bracketed root $r_n$, the midpoint is no farther than half the interval width from any point in that interval, giving $|m_n-r_n|\le L_n/2=L_0/2^{n+1}$. If the current bracket contains a unique root, the same fixed symbol $r$ can be used throughout. With several roots, the statement certifies that a root remains enclosed; it does not predetermine which root the nested intervals will select. In floating-point arithmetic, adjacent representable endpoints may round their computed midpoint back to an endpoint. An implementation must then stop by an adjacent-float, tolerance, iteration-limit, or explicit stagnation condition instead of claiming another exact halving.
<!-- bilingual-en:end -->

在精确算术中，每次更新恰好保留当前区间的一半，所以

$$
L_{n+1}=\frac{L_n}{2},
\qquad
L_n=b_n-a_n=\frac{L_0}{2^n}.
$$

括区间不变量保证 $[a_n,b_n]$ 内至少有一个根。取其中任意一个被括住的根 $r_n$，由于中点到区间内任一点的距离都不超过半个区间宽度，

$$
\boxed{
|m_n-r_n|
\le \frac{L_n}{2}
=\frac{L_0}{2^{n+1}}
}.
$$

若当前括区间内根唯一，可以把 $r_n$ 写成同一个固定根 $r$。若区间内有多个根，结论只需要“至少一个根仍被括住”，不声称算法事先指定了最终会逼近哪一个根。

浮点实现还要多一道停滞检查：当 $a_n$ 与 $b_n$ 已是相邻可表示数时，计算出的中点可能舍入成某个端点，于是机器中的区间不再严格减半。此时应按相邻浮点数、`xtol`/`rtol`、最大迭代或明确的停滞状态退出，不能继续套用精确算术递推制造不存在的新精度。

<!-- bilingual-en:start -->
The symbol $r_n$ allows the statement to refer to any root in the current interval. The nested-interval proof in [[二分求根#为什么嵌套区间会逼近某个根|bisection]] also produces one fixed limiting root $r$ that lies in every retained interval, even when the initial bracket has several roots. Thus the same midpoint bound holds for that selected $r$; selecting it in advance is a separate requirement.
<!-- bilingual-en:end -->

符号 $r_n$ 允许结论指向当前区间内任意一个根。[[二分求根#为什么嵌套区间会逼近某个根|二分求根的嵌套区间证明]]还给出一个固定的极限根 $r$：即使最初有多个根，它也始终属于保留的每个区间。因此同一个中点误差界也适用于这个最终选中的 $r$；事先指定选哪一个，则是另外的要求。

<!-- bilingual-en:start -->
## Solve Backwards from a Target Positional Error
<!-- bilingual-en:end -->

## 由目标位置误差反推轮数

<!-- bilingual-en:start -->
To guarantee that the returned midpoint is within $\varepsilon_x>0$ of a bracketed root, require $L_0/2^{n+1}\le\varepsilon_x$. The minimum number of completed updates is therefore $n_{\min}=\max\{0,\lceil\log_2(L_0/(2\varepsilon_x))\rceil\}$. The outer maximum covers the case in which the initial midpoint is already accurate enough. If the goal is instead to reduce the full bracket width to $\delta>0$, use $n\ge\max\{0,\lceil\log_2(L_0/\delta)\rceil\}$. The first formula controls midpoint error; the second controls the entire remaining interval.
<!-- bilingual-en:end -->

若要求返回中点与区间内某个根的距离不超过 $\varepsilon_x>0$，只需令

$$
\frac{L_0}{2^{n+1}}\le\varepsilon_x.
$$

因此最少的完整更新次数为

$$
\boxed{
n_{\min}
=
\max\!\left\{
0,
\left\lceil
\log_2\!\left(\frac{L_0}{2\varepsilon_x}\right)
\right\rceil
\right\}.
}
$$

外层的 $\max\{0,\cdot\}$ 处理“初始中点已经足够精确”的情形。若目标改成把整个括区间宽度压到 $\delta>0$，对应公式是

$$
n\ge
\max\!\left\{0,
\left\lceil\log_2\!\left(\frac{L_0}{\delta}\right)\right\rceil
\right\}.
$$

这两个式子分别控制“中点的位置误差”和“整个剩余区间宽度”，不要混用。

<!-- bilingual-en:start -->
### Example: Bracketing $\sqrt2$ on $[1,2]$
<!-- bilingual-en:end -->

### 例：从 $[1,2]$ 括住 $\sqrt2$

<!-- bilingual-en:start -->
For $f(x)=x^2-2$ on $[1,2]$, $L_0=1$. Requiring midpoint error at most $10^{-6}$ gives $n_{\min}=\lceil\log_2(1/(2\times10^{-6}))\rceil=19$. After nineteen updates, $|m_{19}-r|\le2^{-20}\approx9.54\times10^{-7}$. This is a worst-case guarantee; an exact midpoint root permits earlier termination.
<!-- bilingual-en:end -->

对 $f(x)=x^2-2$，初始宽度 $L_0=1$。若要求中点位置误差不超过 $10^{-6}$，则

$$
n_{\min}
=
\left\lceil\log_2\frac{1}{2\times10^{-6}}\right\rceil
=19.
$$

完成 19 次更新后，

$$
|m_{19}-r|
\le\frac{1}{2^{20}}
\approx9.54\times10^{-7}.
$$

这是最坏情形保证；若某次中点恰好就是根，可以提前结束。

<!-- bilingual-en:start -->
“Minimum” here means the least integer for which this **worst-case width certificate** guarantees the tolerance. A particular function may reach an exact root or a smaller actual error earlier. The ceiling $\lceil t\rceil$ means rounding $t$ upward to an integer; $\log_2$ asks how many factors of two are needed. In the square-root example, nineteen updates use the signs at $m_0,\ldots,m_{18}$, then returning the new midpoint $m_{19}$ needs no additional function evaluation for the width certificate. Evaluating that returned point as well makes it the twentieth midpoint evaluation, in addition to the two endpoint evaluations.
<!-- bilingual-en:end -->

这里的“最少”指让这个**最坏情形宽度证书**保证容差的最小整数；具体函数可能更早命中精确根，或更早具有足够小的实际误差。上取整 $\lceil t\rceil$ 表示把 $t$ 向上取到整数，$\log_2$ 则计算需要多少个因子 $2$。在平方根例中，十九次更新使用 $m_0,\ldots,m_{18}$ 的符号，然后返回新中点 $m_{19}$；仅凭宽度证书无需再求一次函数值。若也给返回点求值，那就是第二十次中点求值，此外还有最初两次端点求值。

<!-- bilingual-en:start -->
## This Is Not a Residual Bound
<!-- bilingual-en:end -->

## 这不是残差界

<!-- bilingual-en:start -->
Bracket width directly controls distance in the independent variable, but it does not by itself control $|f(m_n)|$. In exact arithmetic, rescaling the equation to $g(x)=cf(x)$ with $c>0$ leaves the roots, endpoint-sign relation, and bisection path unchanged, while multiplying every residual by $c$. Thus the width formula yields no scale-free residual bound, and a small residual cannot be read directly as positional error. [[残差控制根误差|Residual Control of Root Error]] states the additional conditions needed to convert between the two. The positional certificate still relies on bisection's premises: continuity on the bracket, trustworthy endpoint signs, and preservation of the root-containing half. A shrinking interval around a discontinuity, a NaN, or a misclassified floating-point sign is not a root certificate.
<!-- bilingual-en:end -->

区间宽度直接约束自变量中的距离，却没有单独约束 $|f(m_n)|$。在精确算术中，把方程缩放成

$$
g(x)=c f(x),\qquad c>0,
$$

不会改变根、端点符号关系或二分所选的半区间，却把同一点的残差放大为 $|g(m_n)|=c|f(m_n)|$。因此，不能从 $L_n$ 的公式推出一个与函数尺度无关的残差界；反过来也不能把小残差直接当作位置误差。两者的转换条件由 [[残差控制根误差]] 单独说明。

这个位置证书仍依赖 [[二分求根]] 的前提：函数在括区间上连续，端点符号信息可靠，而且每轮确实保留了含根的一半。若函数跳跃、求值产生 NaN，或浮点舍入误判符号，单纯“宽度变小”不能证明靠近零点。

<!-- bilingual-en:start -->
## Certify the point actually returned
<!-- bilingual-en:end -->

## 给实际返回点计算证书

<!-- bilingual-en:start -->
The half-width bound is specifically for the **exact midpoint of the current bracket**. If a program returns an old evaluated point, an endpoint, or a rounded midpoint $\widehat m\in[a,b]$, use its actual worst-case distance to the endpoints:
<!-- bilingual-en:end -->

半宽度界专门适用于**当前括区间的精确中点**。若程序返回旧求值点、端点，或舍入后的中点 $\widehat m\in[a,b]$，应根据它到实际端点的最远距离计算：

$$
|\widehat m-r|\le\max\{\widehat m-a,\,b-\widehat m\}
\le\frac{b-a}{2}+\left|\widehat m-\frac{a+b}{2}\right|.
$$

<!-- bilingual-en:start -->
For example, the first evaluated point $3/2$ becomes an endpoint of $[1,3/2]$ after the update. If that point is returned, its bracket-only bound is $1/2$, not the new half-width $1/4$. Returning the new midpoint $5/4$ earns the $1/4$ bound. For a rigorous floating-point certificate, the distance calculations also need error control, such as outward rounding; ordinary subtraction can round a computed bound downward.
<!-- bilingual-en:end -->

例如，首次求值点 $3/2$ 更新后成了 $[1,3/2]$ 的端点。若返回它，仅凭括区间能给出的界为 $1/2$，不是新区间半宽 $1/4$；返回新中点 $5/4$ 才有 $1/4$ 的界。严格的浮点证书还需要控制距离计算本身的误差，例如使用向外舍入；普通减法计算出的上界也可能向下舍入。

<!-- bilingual-en:start -->
Under binary64 round-to-nearest, $a=1$ and $b=1+2^{-52}$ are adjacent representable numbers. The exact midpoint $1+2^{-53}$ is not representable and rounds to $1$ (ties to even). If that endpoint is returned, the available bracket-only bound is $2^{-52}$, not $2^{-53}$. A stagnation exit therefore does not, by itself, certify an arbitrarily smaller requested tolerance. See [[浮点舍入|floating-point rounding]] and [[数值迭代停止条件|stopping criteria]].
<!-- bilingual-en:end -->

在 binary64 的向最近值舍入中，$a=1$ 与 $b=1+2^{-52}$ 是相邻可表示数。精确中点 $1+2^{-53}$ 无法表示，在平局取偶规则下舍入到 $1$。若返回这个端点，仅凭括区间可给出的界是 $2^{-52}$，不是 $2^{-53}$。因此，“因停滞退出”本身并不能保证任意更小的请求容差；相关背景见[[浮点舍入]]与[[数值迭代停止条件]]。

> [!question]- Apply the bound · 应用误差界
> <!-- bilingual-en:start -->
> Starting from a valid bracket of width $8$, what is the worst-case positional error after ten updates if its midpoint is returned? Is this also a residual bound?
>
> Starting from a valid bracket of width $8$, the midpoint after ten updates has worst-case positional error $8/2^{11}=1/256\approx0.00390625$. This bounds distance to a bracketed root only; without function-scale or derivative information it is not a bound on $|f(m_{10})|$.
> <!-- bilingual-en:end -->
>
> 从宽度 $L_0=8$ 的有效括区间开始，完成 10 次更新后返回中点。最坏情形的位置误差是多少？这个数是否同时是残差上界？
>
> **答案：** $8/2^{11}=1/256\approx0.00390625$。它只界定中点到区间内某个根的距离；没有函数尺度或导数信息时，它不是 $|f(m_{10})|$ 的上界。
