# 解释交互模型应先写目标配置的完整预测，再构造目标对比，并用完整协方差传播不确定性
<!-- bilingual-en:start -->
*Interpret an interaction model by writing complete predictions at the target configurations, constructing the target contrast, and propagating uncertainty through the full covariance matrix*
<!-- bilingual-en:end -->

> [!summary] 不从回归表的某一行开始
> 交互模型的科学对象通常是某个组别均值、给定取值处的组差、斜率、斜率差或四格差异之差。先把完整模型代入目标配置，再做差或求导；最后对得到的系数组合计算区间。回归表中的交互系数只有在它恰好等于目标对比时才能直接回答问题。
> <!-- bilingual-en:start -->
> The scientific object in an interaction model is usually a group mean, a group difference at a chosen value, a slope, a slope difference, or a four-cell difference in differences. Substitute the target configurations into the complete model, then take the required difference or derivative and form an interval for the resulting coefficient combination. The interaction row answers the question directly only when it happens to equal that target contrast.
> <!-- bilingual-en:end -->

一个可复用的读取顺序是：

1. **定义编码与范围。** 写清每个指示变量何时等于 1、基准组是谁、连续变量单位，以及目标取值是否在共同支持内。
2. **重建完整预测。** 对相关组别和取值分别写 $\hat m(x,d)$；离散变量用有限差分，连续变量才用导数。
3. **构造目标对比。** 例如 $\hat m(10,1)-\hat m(10,0)$、两组斜率之差，或四格差异之差。
4. **传播不确定性。** 在线性模型中，目标对比的估计方差为 $a'\widehat Va$，标准误是 $\sqrt{a'\widehat Va}$；协方差口径必须与抽样和依赖结构匹配。
5. **最后命名结论。** 先称为模型内条件对比；只有额外识别条件成立时，才称为因果效应或效应异质性。
<!-- bilingual-en:start -->
1. **Define coding and support.** State when each indicator equals one, the reference group, continuous-variable units, and whether target values lie in common support.
2. **Reconstruct complete predictions.** Write $\hat m(x,d)$ for every relevant configuration; use finite differences for discrete variables and derivatives only for continuous variables.
3. **Construct the target contrast.** Examples include $\hat m(10,1)-\hat m(10,0)$, a difference between slopes, or a four-cell difference in differences.
4. **Propagate uncertainty.** In a linear model the estimated variance is $a'\widehat Va$ and the standard error is $\sqrt{a'\widehat Va}$, using a covariance estimator matched to sampling and dependence.
5. **Name the conclusion last.** Begin with a model-implied conditional contrast; call it a causal effect or effect heterogeneity only when separate identifying conditions hold.
<!-- bilingual-en:end -->

若模型是 logit 或 probit，同一流程仍成立，但“完整预测”必须在概率尺度重新计算。线性指数里的乘积项系数通常不等于概率交互效应，见[[交互系数不等于概率交互]]；不能把线性模型公式原封不动搬到概率尺度。
<!-- bilingual-en:start -->
The same workflow applies to logit or probit, but complete predictions must be recomputed on the probability scale. A product-term coefficient in the linear index generally differs from the probability interaction; see [[交互系数不等于概率交互|the nonlinear interaction boundary]]. Linear-model formulas cannot simply be relabelled as probability effects.
<!-- bilingual-en:end -->

> [!question]- 自检
> 为什么“交互系数显著”不是一份完整的交互分析？
>
> **答案：** 它只检验某个参数化中的斜率差或差异之差；还缺目标取值的完整预测、目标对比的区间、支持范围、协方差口径和因果资格。
