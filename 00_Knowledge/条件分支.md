# if、elif 与 else 按顺序只执行首个为真的分支
<!-- bilingual-en:start -->
*`if`, `elif`, and `else` execute only the first true branch in order*
<!-- bilingual-en:end -->

> [!summary] 原子控制流
> 一个 `if/elif/else` 语句从上到下依次求值条件，遇到首个真值后执行对应 suite，并跳过这条语句余下的条件与分支。若所有条件都为假，则执行 `else`；没有 `else` 时什么分支都不执行。条件会做真值测试，不要求表达式结果本身已经是 `bool`。
> <!-- bilingual-en:start -->
> An `if/elif/else` statement evaluates conditions from top to bottom. Once it finds the first true one, it executes that suite and skips every remaining condition and branch in the statement. If all conditions are false, the `else` suite runs; without `else`, no suite runs. Conditions use truth testing and need not already evaluate to an object of type `bool`.
> <!-- bilingual-en:end -->

```python
if score >= 70:
    grade = "distinction"
elif score >= 40:
    grade = "pass"
else:
    grade = "fail"
```

条件顺序有语义：较宽的条件若放在前面，会截获后面的较窄情况。多条独立 `if` 不是同一条分支链，每一条都会自行测试，因此可能执行多块代码。缩进决定 suite 的边界；视觉上靠近但缩进不同的语句不属于同一分支。
<!-- bilingual-en:start -->
Condition order is semantic: a broader earlier condition can capture cases intended for a narrower later one. Separate `if` statements are not one branch chain; each performs its own test, so several bodies may execute. Indentation defines suite boundaries, so visually adjacent statements at different indentation levels do not belong to the same branch.
<!-- bilingual-en:end -->

> [!question]- 回忆与应用
> 为什么 `score >= 40` 不能放在 `score >= 70` 前面而仍保留上例含义？
>
> **答案：** 70 分也满足 `score >= 40`；首个真分支会截获它，后面的 distinction 条件不再求值。
