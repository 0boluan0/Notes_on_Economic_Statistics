# Python 的 and 与 or 按从左到右短路并返回实际操作数
<!-- bilingual-en:start -->
*Python's `and` and `or` short-circuit from left to right and return actual operands*
<!-- bilingual-en:end -->

> [!summary] 原子求值规则
> `x and y` 先求 `x`：若 `x` 为假值就直接返回 `x`，否则才求值并返回 `y`。`x or y` 先求 `x`：若 `x` 为真值就直接返回 `x`，否则才求值并返回 `y`。因此 `and` 与 `or` 的结果不一定是 `bool`；`not x` 才总返回 `True` 或 `False`。
> <!-- bilingual-en:start -->
> `x and y` evaluates `x` first: if `x` is false, it returns `x`; otherwise it evaluates and returns `y`. `x or y` evaluates `x` first: if `x` is true, it returns `x`; otherwise it evaluates and returns `y`. Consequently, `and` and `or` do not necessarily return a `bool`; `not x` always returns `True` or `False`.
> <!-- bilingual-en:end -->

```python
items = []
first = items and items[0]   # returns []; items[0] is never evaluated

name = ""
shown = name or "anonymous" # returns "anonymous"
```

短路可以保护只在前提成立时才安全的操作，例如先确认容器非空再访问首项。它也意味着右侧函数的异常、I/O 或状态修改可能根本不发生；把关键副作用藏在 `and` 或 `or` 的右侧，会让副作用是否执行依赖左侧真值。真值测试不仅接受 `bool`：`None`、数值零与空容器通常为假，自定义对象还能用 `__bool__` 或 `__len__` 定义真值。
<!-- bilingual-en:start -->
Short-circuiting can guard an operation that is safe only after a precondition, such as checking that a container is nonempty before indexing it. It also means that an exception, I/O action, or state change in the right operand may never occur. Hiding an essential side effect there makes its execution depend on the left operand's truth value. Truth testing is not limited to `bool`: `None`, numeric zero, and empty containers are normally false, and user-defined objects can customize truth through `__bool__` or `__len__`.
<!-- bilingual-en:end -->

> [!question]- 回忆与应用
> `0 or 7` 与 `3 and "ok"` 分别得到什么？它们的结果一定是布尔值吗？
>
> **答案：** 分别得到 `7` 与 `"ok"`；`and`、`or` 返回最后实际求值的操作数，不保证返回布尔值。
