# 最坏情况复杂度是在同一规模的合法输入中取最大资源成本

<!-- bilingual-en:start -->
*Worst-case complexity takes the maximum resource cost over valid inputs of the same size*
<!-- bilingual-en:end -->

固定算法、[[算法成本模型]]与[[输入规模]]，设 $I_n$ 是规模为 $n$ 的合法输入集合，$T(x)$ 是输入 $x$ 上的成本。最坏情况复杂度是在 $I_n$ 中取最大成本；最大值存在时写为

<!-- bilingual-en:start -->
Fix an algorithm, [[算法成本模型|cost model]] and [[输入规模|size measure]]. Let $I_n$ contain the valid inputs of size $n$, and let $T(x)$ be the cost on input $x$. Worst-case complexity takes the largest cost over $I_n$, when that maximum exists:
<!-- bilingual-en:end -->

$$
T_{\mathrm{worst}}(n)=\max_{x\in I_n}T(x).
$$

因而 $T_{\mathrm{worst}}(n)=O(g(n))$ 给出对所有足够大规模、所有合法输入的统一上界。若要证明紧界 $\Theta(g(n))$，除上界外还需展示足够坏的输入族或其他下界论证。[[大O记号]]本身只是函数上界关系，并不自动意味着取过最坏情况。

<!-- bilingual-en:start -->
Thus $T_{\mathrm{worst}}(n)=O(g(n))$ is a uniform upper bound for every valid input of sufficiently large size. A tight $\Theta(g(n))$ result additionally requires a sufficiently costly input family or another lower-bound argument. [[大O记号|Big-O]] itself is a relation between functions; it does not automatically select the worst case.
<!-- bilingual-en:end -->

例如，逐项查找、找到即返回的线性搜索，在目标不存在时必须检查全部 $n$ 个元素。在访问与相等比较均为常数成本的模型下，其最坏时间为 $\Theta(n)$。能让程序尽早返回的输入不能用来证明这个最坏下界。

<!-- bilingual-en:start -->
For example, a linear search that returns on a match must examine all $n$ elements when the target is absent. With constant-cost access and equality tests, its worst-case time is $\Theta(n)$. An input that triggers an early return cannot establish this worst-case lower bound.
<!-- bilingual-en:end -->

若同规模输入的成本无上界，就不能假装有一个有限最大值；需要补充规模参数、限定输入域，或明确改用可能为无穷的上确界。

<!-- bilingual-en:start -->
If costs are unbounded among inputs of the same size, there is no finite maximum to report. Add size parameters, restrict the input domain, or explicitly use a possibly infinite supremum.
<!-- bilingual-en:end -->
