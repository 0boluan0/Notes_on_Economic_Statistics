# 排序结果必须同时满足有序与排列保持

<!-- bilingual-en:start -->
*A sort output must preserve both order and permutation*
<!-- bilingual-en:end -->

> [!summary] 原子定义
> 给定项目序列 $A$、排序键 $k$ 和次序关系，正确输出 $B$ 必须同时满足两件事：$B$ 是 $A$ 中项目的一个排列，而且 $k(B_1)\leq k(B_2)\leq\cdots\leq k(B_n)$。只做到“看起来有序”却丢失、复制或拆散项目，并不算排序正确。
>
> <!-- bilingual-en:start -->
> Given an item sequence $A$, a key $k$, and an ordering relation, a correct output $B$ must satisfy two conditions: $B$ is a permutation of the items in $A$, and $k(B_1)\leq k(B_2)\leq\cdots\leq k(B_n)$. An output that looks ordered but loses, duplicates, or separates items is not a correct sort.
> <!-- bilingual-en:end -->

## 自然解释

把学生记录按成绩排序时，算法比较的是成绩键，但姓名、学号等附属数据必须与原记录一起移动。验收时既要检查成绩不下降，也要检查输入中的每条记录恰好出现一次。

<!-- bilingual-en:start -->
When student records are sorted by grade, the algorithm compares grade keys, but names, identifiers, and other satellite data must move with their records. Verification must check both nondecreasing grades and one-for-one preservation of all input records.
<!-- bilingual-en:end -->

> [!warning] 边界
> 这个规格没有规定输出是否复用原容器，也没有规定相等键之间的次序。前者属于接口与空间语义，后者要另加[[稳定排序|稳定性]]要求。
>
> <!-- bilingual-en:start -->
> This specification does not say whether the output reuses the input container, nor how equal keys are ordered. The former is an interface and space question; the latter requires the additional condition of [[稳定排序|stability]].
> <!-- bilingual-en:end -->

> [!question]- 回忆与应用
> 一个函数返回了升序结果，但把两条同值记录合并成一条。它完成排序了吗？
>
> **答案：** 没有。它满足有序性，却破坏了排列保持；排序不能擅自去重。
