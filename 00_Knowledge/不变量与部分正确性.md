# 不变量必须结合退出条件推出后置条件才证明部分正确性
<!-- bilingual-en:start -->
*An invariant proves partial correctness only when combined with the exit condition to imply the postcondition*
<!-- bilingual-en:end -->

> [!summary] 原子程序
> 初始化与保持性只能保证不变量 $P$ 对每个可达状态成立。要证明部分正确性，还要取任意可达的终止状态 $r$，把不变量 $P(r)$ 与退出条件 $E(r)$ 合起来推出规格要求的后置条件 $R(r)$：
> $$P(r)\land E(r)\Rightarrow R(r).$$
> <!-- bilingual-en:start -->
> Initialization and preservation show only that an invariant $P$ holds at every reachable state. To prove partial correctness, take an arbitrary reachable terminal state $r$ and combine the invariant $P(r)$ with the exit condition $E(r)$ to derive the required postcondition $R(r)$:
> $$P(r)\land E(r)\Rightarrow R(r).$$
> <!-- bilingual-en:end -->

快速幂的不变量是 $yx^z=a^b$。程序退出时 $z=0$，所以 $yx^0=y=a^b$。不变量负责保留输入与当前寄存器之间的关系，退出条件负责把这条关系收束成最终答案。
<!-- bilingual-en:start -->
For fast exponentiation, the invariant is $yx^z=a^b$. At exit, $z=0$, so $yx^0=y=a^b$. The invariant preserves the relation between the input and current registers, while the exit condition specializes that relation to the final answer.
<!-- bilingual-en:end -->

## 边界
<!-- bilingual-en:start -->
*Boundary*
<!-- bilingual-en:end -->

- 不变量不必与后置条件相同，但必须强到足以在退出条件下推出后置条件；“变量始终是整数”常常是真的，却可能完全不足以证明结果正确。
- 这一步只证明“若停则正确”。它没有说明终止状态一定会到达；终止性仍需独立论证。
<!-- bilingual-en:start -->

**1.** An invariant need not equal the postcondition, but it must be strong enough to imply the postcondition under the exit condition. “The variable is always an integer” may be true yet far too weak to prove the result correct.<br>
**2.** This step proves only correctness if the process terminates. It does not show that a terminal state will be reached; termination remains a separate obligation.<br>
<!-- bilingual-en:end -->

> [!question]- 回忆与应用
> 某循环保持 $x+y=N$，退出条件是 $x=0$，规格要求退出时 $y=N$。若不变量已经正确初始化并被每步保持，这足以证明部分正确性吗？
>
> **答案：** 足以。任意可达终止状态同时满足 $x+y=N$ 与 $x=0$，代入即得 $y=N$；但仍未证明循环必定退出。
> <!-- bilingual-en:start -->
> A loop preserves $x+y=N$, exits when $x=0$, and requires $y=N$ upon exit. If the invariant is initialized and preserved, does this establish partial correctness?
>
> **Answer:** Yes. Every reachable terminal state satisfies both $x+y=N$ and $x=0$, hence $y=N$. This still does not prove that the loop terminates.
> <!-- bilingual-en:end -->
