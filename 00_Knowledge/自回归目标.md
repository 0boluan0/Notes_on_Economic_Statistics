# Decoder-only 自回归预训练以各有效目标位置的 next-token 负对数似然聚合为训练目标

<!-- bilingual-en:start -->
*Decoder-only autoregressive pretraining aggregates next-token negative log-likelihood terms from all valid target positions into its training objective*
<!-- bilingual-en:end -->

> [!summary] 它是什么
> 对 token 序列 $x_{1:T}$，decoder-only causal language model 把序列概率分解为
> $$
> p_\theta(x_{1:T})=\prod_{t=1}^{T}p_\theta(x_t\mid x_{<t}),
> $$
> 每个有效目标位置都贡献一项真实 next token 的负对数似然
> $$
> \ell_t(\theta)=-\log p_\theta(x_t\mid x_{<t}).
> $$
> 再按明确的有效位置与聚合口径组成整体目标。模型不是只在序列末尾猜一次；每个有效位置都产生一项训练信号。
>
> <!-- bilingual-en:start -->
> A decoder-only causal language model factorizes sequence probability into next-token conditionals. Every valid target position contributes one observed-token NLL term, and an explicit validity and reduction rule aggregates those terms into the training objective. Signal comes from every valid position, not only the end of a sequence.
> <!-- bilingual-en:end -->

## 从序列似然到逐位置目标

概率链式法则把整条序列写成条件概率的乘积。取对数后，最大化真实序列的对数似然等价于最小化各位置 NLL 的和。某个位置的真实 token 为 $v$ 时，该位置只贡献 $-\log p_\theta(v\mid x_{<t})$。

是否把 padding、文档边界后的首 token 或 prompt 区域计入目标，由有效位置规则决定。没有任何有效目标的样本不定义 token 平均损失，应跳过或在预处理时剔除。跨样本怎样归一化并不是无关实现细节，见 [[Token损失均值不等价]]。

<!-- bilingual-en:start -->
The chain rule turns sequence probability into a product, and the logarithm turns that product into a sum of position-wise NLL terms. A validity rule decides whether padding, document-boundary positions, or prompt regions contribute. Samples with no valid targets do not define a token mean. Cross-sample reduction is handled in [[Token损失均值不等价|the separate aggregation boundary]].
<!-- bilingual-en:end -->

## 目标直接奖励什么

对输出 logit 的局部梯度会提高真实 token 相对其他 token 的概率方向；共享参数完成一次更新后，不保证每个样本位置的真实 token 概率都单调上升。更重要的是，目标里没有独立的“事实正确”“有帮助”“安全”或“推理优美”奖励项。这些行为只能从训练分布的可预测结构间接形成，并必须另行评测。

两个有效位置上，模型给真实 token 的概率若为 $0.25$ 和 $0.50$，平均 NLL 为
$$
-\frac{\log0.25+\log0.50}{2}\approx1.040.
$$
若第一项提高到 $0.50$ 而第二项不变，平均降为 $0.693$，说明两个位置都进入目标。

## 适用范围

本原子只定义 decoder-only causal LM 的标准预训练目标。BERT 式 masked language modeling、encoder–decoder 条件生成与扩散语言模型使用不同条件结构或训练目标，不能无条件合并成“所有语言模型都做 next-token prediction”。在并行 decoder-only Transformer 中怎样由输入错位与可见性正确实现，另见 [[Transformer自回归约束]]。

> [!question]- 自检
> 某训练序列有 100 个 token，但其中只有 80 个位置被标为有效目标。这里的 next-token NLL 有多少个直接训练项？
>
> **答案：** 80 个。其余位置可以提供上下文，但其预测误差不直接进入这个目标。
