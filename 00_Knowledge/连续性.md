# Continuity
<!-- bilingual-en:end -->

*连续性*

<!-- bilingual-en:start -->
A continuous function lets us keep the output near its value at a point by keeping the input sufficiently near that point. For $f(x)=2x$, keeping the input within $0.05$ of $3$ keeps the output within $0.1$ of $6$. The allowed input neighbourhood may depend on the point and on how tightly we want to control the output.
<!-- bilingual-en:end -->

**连续性**表示：只要把输入限制在一个点附近足够小的范围里，就能让输出留在该点函数值附近。例如 $f(x)=2x$，让输入与 $3$ 的距离小于 $0.05$，就能让输出与 $6$ 的距离小于 $0.1$。允许的输入邻域可以依赖所在点，也可以依赖要求输出有多接近。

<!-- bilingual-en:start -->
Distances are one way to express “near”. More generally, a [[拓扑|topology]] specifies which sets are [[开集|open]], and an open neighbourhood of a point is an open set containing it. For a map $f:X\to Y$, $X$ is the domain of allowed inputs and $Y$ is the codomain in which outputs are viewed. Each space has its own specified topology.
<!-- bilingual-en:end -->

距离是表达“接近”的一种方式。更一般地，[[拓扑]]指定哪些集合是[[开集]]；一个点的开邻域就是包含它的开集。对映射 $f:X\to Y$，$X$ 是允许输入的定义域，$Y$ 是用来容纳输出的陪域。两个空间各自有指定的拓扑。

<!-- bilingual-en:start -->
## Pull an output region back to the inputs
<!-- bilingual-en:end -->

*把输出区域拉回输入端*

<!-- bilingual-en:start -->
Given a set $V\subseteq Y$, its **preimage** is the set of all inputs whose output lies in $V$:
$$f^{-1}(V)=\{x\in X:f(x)\in V\}.$$
This notation does not require an inverse function. For $f(x)=x^2$ on $\mathbb R$, the preimage of $(1,4)$ is $(-2,-1)\cup(1,2)$: inputs from either interval give an output between $1$ and $4$.
<!-- bilingual-en:end -->

给定 $V\subseteq Y$，它的**原像**是所有输出落入 $V$ 的输入组成的集合，上式就是这一定义。这个记号不要求存在反函数。例如 $\mathbb R$ 上的 $f(x)=x^2$，集合 $(1,4)$ 的原像为 $(-2,-1)\cup(1,2)$，因为两个区间中的输入都会得到介于 $1$ 与 $4$ 之间的输出。

> [!important] The open-preimage definition · 开集原像定义
> <!-- bilingual-en:start -->
> The map $f:X\to Y$ is **continuous** if $f^{-1}(V)$ is open in $X$ for every open set $V$ in $Y$. Every open output region must have an open set of qualifying inputs.
> <!-- bilingual-en:end -->
>
> 若 $Y$ 中每个开集 $V$ 的原像 $f^{-1}(V)$ 都在 $X$ 中开，就称 $f:X\to Y$ **连续**。每个开输出区域，都必须对应一个开的合格输入集合。

<!-- bilingual-en:start -->
Why does this capture local control? Take an input $x$ and an open neighbourhood $V$ of $f(x)$. Its preimage is then an open neighbourhood of $x$, and every input in it has output in $V$. Conversely, suppose that at each $x$ every open neighbourhood $V$ of $f(x)$ admits an open neighbourhood $U_x$ of $x$ with $f(U_x)\subseteq V$. For fixed open $V$, each $x\in f^{-1}(V)$ has such a neighbourhood inside the preimage. Their union is the whole preimage, so it is open. Thus the definition is exactly this local neighbourhood condition at every point.
<!-- bilingual-en:end -->

为什么这能表达局部控制？取输入点 $x$ 和 $f(x)$ 的开邻域 $V$。它的原像就是 $x$ 的一个开邻域，其中每个输入的输出都留在 $V$ 内。反过来，若每个 $x$ 对于 $f(x)$ 的每个开邻域 $V$，都能找到 $x$ 的开邻域 $U_x$，使 $f(U_x)\subseteq V$，那么对固定的开集 $V$，原像中每个点都有一个留在原像内的开邻域。把这些邻域取并就得到整个原像，所以原像开。这说明定义恰好等价于每个点处的这种局部邻域控制。

## Continuous examples and a jump
<!-- bilingual-en:end -->

*连续例子与跳跃例子*

<!-- bilingual-en:start -->
The identity map on one topological space is continuous because the preimage of each open set is that set itself. A constant map $f(x)=c$ is also continuous: the preimage of an open set is either $X$ or the empty set, according to whether it contains $c$. Both sets are open in every topology.
<!-- bilingual-en:end -->

同一个拓扑空间上的恒等映射连续，因为每个开集的原像就是它自身。常值映射 $f(x)=c$ 也连续：根据开集是否包含 $c$，它的原像不是整个 $X$ 就是空集，而这两者在每个拓扑中都开。

> [!example] A jump has a non-open preimage · 跳跃会留下不开的原像
> <!-- bilingual-en:start -->
> On the usual real line, let $h(x)=0$ for $x<0$ and $h(x)=1$ for $x\ge0$. The open output interval $(1/2,3/2)$ has preimage $[0,\infty)$. Every open interval around $0$ contains negative inputs, so this preimage is not open. The map fails continuity. Locally, no neighbourhood of input $0$ can keep every output near $h(0)=1$.
> <!-- bilingual-en:end -->
>
> 在通常实数线上，令 $x<0$ 时 $h(x)=0$，$x\ge0$ 时 $h(x)=1$。开输出区间 $(1/2,3/2)$ 的原像为 $[0,\infty)$。$0$ 周围每个开区间都含有负输入，因此这个原像不开，映射不连续。从局部看，无论把输入限制在 $0$ 周围多小的邻域，都不能使全部输出留在 $h(0)=1$ 附近。

<!-- bilingual-en:start -->
The definition concerns preimages. It does not require images of open sets to be open: the continuous constant function $\mathbb R\to\mathbb R$ sends the open domain $\mathbb R$ to a singleton, which is not open in the usual real line.
<!-- bilingual-en:end -->

定义检查的是原像，并不要求开集的像也开。例如连续的常值函数 $\mathbb R\to\mathbb R$ 把开的定义域 $\mathbb R$ 映成单点，而单点在通常实数线上不开。

## Keep the domain and its topology explicit
<!-- bilingual-en:end -->

*明确写出定义域及其拓扑*

<!-- bilingual-en:start -->
If inputs are restricted to a subset $S\subseteq X$, use its [[子空间拓扑|subspace topology]]: neighbourhoods are restricted to points still in $S$. At $0$ for a function on $[0,1]$, no negative inputs need to be tested. The codomain topology must also be specified; when the codomain is a subset of a larger space, its subspace topology is a common choice, not a consequence of restricting the domain.
<!-- bilingual-en:end -->

若输入限制为 $S\subseteq X$，便使用它的[[子空间拓扑]]：邻域只包含仍在 $S$ 中的点。对于定义在 $[0,1]$ 上的函数，检查 $0$ 处连续时不需要测试负输入。陪域的拓扑也要另行指定；若陪域是较大空间的子集，使用其子空间拓扑是常见选择，但不是限制定义域就自动作出的选择。

<!-- bilingual-en:start -->
In metric spaces, this definition is equivalent to the familiar $\varepsilon$–$\delta$ and sequence tests; [[连续性的等价判别|the equivalence card]] explains the quantifiers and proof. Continuity does not require a derivative: [[连续不必可导|a continuous function can have a corner]]. When studying whole sets, continuous maps also preserve [[连续像保持紧致|compactness]] and [[连续像保持连通|connectedness]].
<!-- bilingual-en:end -->

在度量空间中，这一定义与熟悉的 $\varepsilon$–$\delta$ 及序列判据等价；[[连续性的等价判别]]具体说明量词和证明。连续性不要求有导数：[[连续不必可导|连续函数也可以有尖角]]。研究整个集合时，连续映射还保留[[连续像保持紧致|紧致性]]与[[连续像保持连通|连通性]]。
