# SIGTERM允许程序处理终止请求而SIGKILL不执行程序清理
<!-- bilingual-en:start -->
*SIGTERM allows a program to handle a termination request; SIGKILL does not run application cleanup.*
<!-- bilingual-en:end -->

通常先采用程序支持的关闭入口或发送 `SIGTERM`，让它有机会保存状态、关闭连接和释放业务资源。但 `SIGTERM` 可以被处理或忽略，默认终止也不保证程序特有的清理完成；必须观察退出与任务状态。
<!-- bilingual-en:start -->
Normally prefer an application-supported shutdown path or `SIGTERM`, allowing the program an opportunity to save state and close resources. However, `SIGTERM` may be handled or ignored, and default termination does not guarantee application-specific cleanup. Observe both exit and task state.
<!-- bilingual-en:end -->

只有已确认目标、影响范围且需要升级时才考虑 `SIGKILL`。它不能被捕获、忽略或阻塞，程序自己的 handler、退出钩子和 shell trap 没有机会替它清理；内核释放进程资源不等于业务事务回滚。也不要把它表述成“发送后任何情形都瞬时完成”。
<!-- bilingual-en:start -->
Consider `SIGKILL` only after confirming the target, impact, and need to escalate. It cannot be caught, ignored, or blocked, and it cannot run the program's handlers, exit hooks, or shell traps. Kernel resource release is not application transaction rollback, nor should sending it be described as instantaneous completion in every situation.
<!-- bilingual-en:end -->

`SIGSTOP` 只是不可捕获的暂停信号，不是较温和的终止；`SIGQUIT` 通常还会请求 core dump，也不应把它当作无差别的优雅关闭替代品。选择依据是程序合同与观察结果，而不是只比较信号数字大小。
<!-- bilingual-en:start -->
`SIGSTOP` is an uncatchable stop, not a gentler termination. `SIGQUIT` normally requests a core dump and is not a generic graceful-shutdown substitute. Choose according to the application's contract and observations, not the relative sizes of signal numbers.
<!-- bilingual-en:end -->

## 来源与核验

[OpenBSD signal(3)](https://man.openbsd.org/signal.3)：核对 TERM、KILL、STOP、QUIT 默认动作与不可捕获例外；[sigaction(2)](https://man.openbsd.org/sigaction.2) 核对 KILL/STOP 不可阻塞及处理器条件。
<!-- bilingual-en:start -->
[OpenBSD signal(3)](https://man.openbsd.org/signal.3) supports TERM, KILL, STOP, and QUIT behavior; [sigaction(2)](https://man.openbsd.org/sigaction.2) supports unmaskable signals and handler conditions.
<!-- bilingual-en:end -->

[MIT Missing Semester 2020, Job Control](https://missing.csail.mit.edu/2020/command-line/#job-control)：支持先理解信号再终止的课堂语境；原文对 KILL 的“总是立即”描述不作为本卡保证。
<!-- bilingual-en:start -->
[MIT Missing Semester 2020: Job Control](https://missing.csail.mit.edu/2020/command-line/#job-control) supplies the classroom context. Its unconditional immediacy wording for KILL is not adopted as a guarantee.
<!-- bilingual-en:end -->
