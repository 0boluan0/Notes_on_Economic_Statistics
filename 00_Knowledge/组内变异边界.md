# 固定效应斜率只能由单位内部变化识别且不能估计时间不变回归量

<!-- bilingual-en:start -->
*A fixed-effects slope is identified only by within-unit variation and cannot estimate a time-invariant regressor*
<!-- bilingual-en:end -->

> [!summary] 原子命题
> FE 回归使用 $x_{it}-\bar x_i$。若 $x_{it}=x_i$ 对单位内所有时期不变，则
> $$x_{it}-\bar x_i=0,$$
> 它与单位效应完全共线，数据没有独立的组内变化来识别其系数。
>
> <!-- bilingual-en:start -->
> FE uses $x_{it}-\bar x_i$. If $x_{it}=x_i$ is constant within a unit, then $x_{it}-\bar x_i=0$. It is inseparable from the unit effect because the data contain no independent within variation for its coefficient.
> <!-- bilingual-en:end -->

对二元处理，真正提供斜率信息的是状态发生变化的 switchers；始终为 0 或始终为 1 的单位对该系数没有组内变异。对连续变量，若单位内变化极小，系数虽可计算，却可能由很少的有效变化支撑，并放大测量误差相对于真实信号的影响。
<!-- bilingual-en:start -->
For a binary treatment, switchers supply the slope information; always-zero and always-one units provide no within variation for that coefficient. For a continuous regressor with very little within variation, a numerical coefficient may exist but be supported by few effective changes, magnifying measurement error relative to signal.
<!-- bilingual-en:end -->

在非平衡面板中，若某单位在共同估计样本里只有 $T_i=1$，它的所有去均值变量都为 0，因此不为任何 within 斜率提供信息。软件仍可能把它计入单位数，但“被计数”不等于“参与斜率识别”。
<!-- bilingual-en:start -->
In an unbalanced panel, a unit with only $T_i=1$ in the common estimation sample has zero demeaned values for every variable and supplies no information for any within slope. Software may still count it as a panel unit, but being counted is not the same as identifying a slope.
<!-- bilingual-en:end -->

这不是要求改用 RE 的自动理由。若关注的回归量不随时间变化，研究者必须另找可信的 between design、工具、自然实验或有明确额外限制的 CRE/RE 结构；换估计器不能创造不存在的识别变异。二元面板中的条件似然、变化组和短 $T$ 非线性偏误分别保留在 [[条件固定效应Logit]]、[[条件Logit只用变化组]] 与 [[非线性固定效应偏误]]，不能从本卡直接外推。
<!-- bilingual-en:start -->
This is not an automatic instruction to use RE. A time-invariant regressor of interest requires a credible between design, an instrument, a natural experiment, or a CRE/RE structure with explicit additional restrictions. Changing estimators cannot create missing identifying variation. Conditional likelihood, outcome-switching groups, and short-$T$ nonlinear bias remain in their dedicated binary-panel atoms and cannot be inferred directly from this card.
<!-- bilingual-en:end -->

> [!question]- 回忆与应用
> 为什么固定性别编码会被单位 FE 删除，而“今年是否培训”可能保留？
>
> **答案：** 固定编码的组内偏离恒为 0；培训状态若在同一人跨期改变，就产生可用于斜率的组内偏离。
