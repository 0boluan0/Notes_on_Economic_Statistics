# 当前操作风险标准法使用 BI、BIC 与 ILM 而 BIA、TSA 和 AMA 是历史方法
*The current operational-risk standardised approach uses BI, BIC and ILM; BIA, TSA and AMA are historical methods*

> [!summary] 单一标准法替代旧菜单
> 当前 Basel 操作风险框架先以业务指标（BI）衡量规模，再按分档边际系数得到业务指标组成（BIC），并在适用规则下结合内部损失乘数（ILM）：$ORC=BIC\times ILM$，操作风险 RWA 为 $12.5\times ORC$。

BI 由利息、租赁、股息、服务和金融等组成项目按规则构造，不等于旧 BIA 里的“毛收入”原样换名。BIC 对不同 BI 档采用边际系数；ILM 通过损失组成（LC）与 BIC 的比值把十年内部损失经验引入资本，但框架允许国家裁量将 ILM 设为 1，实际采用方式须查本地规则。

Basel II 的基础指标法（BIA）、标准法/替代标准法（TSA/ASA）和高级计量法（AMA）应明确标为历史。不能说 BIA 必然最高、TSA 居中、AMA 最低；资本结果取决于业务结构、损失与模型，且当前改革正是为了提高简单性、可比性并取消 AMA。

## 边界

- BIC 与 ILM 是资本计量输入，不是对下一年操作损失的无偏预测。
- “当前 Basel 方法”不等于每个法域已经在同一天实施；须锁定本地生效日。
- 历史课程题仍可按 BIA/TSA/AMA 作答，但答案必须写明版本。

> [!question]- 自检
> 为什么不能把当前 BI 简单理解为旧 BIA 毛收入换了名字？
>
> **答案：** BI 按当前规则由多个组成项目构造并分档形成 BIC；定义、系数和后续 ILM 机制都不同。
