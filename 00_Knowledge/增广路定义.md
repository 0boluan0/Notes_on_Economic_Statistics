# 增广路是两端未匹配的交替路

<!-- bilingual-en:start -->
*An augmenting path is an alternating path whose endpoints are unmatched*
<!-- bilingual-en:end -->

> [!summary] 原子定义
> 相对于 matching $M$，alternating path 的边在“不属于 $M$”与“属于 $M$”之间交替。augmenting path 还要求两个端点都未被 $M$ 覆盖，因此它的第一条和最后一条边都不在 $M$ 中。
>
> <!-- bilingual-en:start -->
> Relative to a matching $M$, an alternating path alternates between edges outside and inside $M$. An augmenting path additionally has two endpoints that are uncovered by $M$, so both its first and last edges lie outside $M$.
> <!-- bilingual-en:end -->

“交替”只描述路径上的边怎样排列，并不单独保证翻转后仍是 matching，更不保证它变大。若端点原有的 matching edge 不在路径上，直接翻转可能制造端点冲突；若路径从未匹配点出发、以一条 matching edge 结束，翻转只把“未匹配”移到另一端而不增加边数；alternating cycle 的翻转也保持边数。只有两端都未匹配的 augmenting path 同时保证翻转合法且净增一条边。
<!-- bilingual-en:start -->
“Alternating” describes only the order of edges along a path. It does not by itself guarantee that flipping still yields a matching, let alone a larger one. If an endpoint's matching edge lies outside the path, a direct flip can create an endpoint conflict. If a path starts at an unmatched vertex and ends with a matching edge, the flip merely moves the unmatched endpoint without changing cardinality; flipping an alternating cycle also preserves cardinality. Requiring both endpoints to be unmatched is what makes the flip valid and increases the matching by one edge.
<!-- bilingual-en:end -->

例如已有边 $a-1\in M$，而 $b-1$ 与 $a-2$ 未选，且 $b$、$2$ 都未匹配。路径
$$
b-1-a-2
$$
依次经过非 matching、matching、非 matching 边，所以它是 augmenting path。
<!-- bilingual-en:start -->
For example, suppose $a-1\in M$, while $b-1$ and $a-2$ are unselected and both $b$ and $2$ are unmatched. The path shown above uses a non-matching, matching, and non-matching edge in sequence, so it is augmenting.
<!-- bilingual-en:end -->

> [!question]- 回忆与辨别
> 一条边型交替、但两端都已匹配的路径，能否仅凭“交替”断言翻转后 matching 变大？
>
> **答案：** 不能。还必须确认它是两端未匹配的增广路。
