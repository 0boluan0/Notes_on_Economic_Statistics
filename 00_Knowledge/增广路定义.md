# Augmenting paths
<!-- bilingual-en:end -->
*增广路*

<!-- bilingual-en:start -->
An **augmenting path** describes a chain of reassigned pairs that can add one more pair to a current [[匹配定义|matching]]: a set of selected edges with no shared endpoints. The chain starts and ends at vertices that currently have no selected edge. Between them, it alternates between an edge we would add and an edge we would remove. The word “augmenting” is relative to the **fixed current matching**, not to the graph alone.
<!-- bilingual-en:end -->
**增广路**描述一串连锁重配，使当前[[匹配定义|匹配]]有机会多选一对。匹配是一组端点互不重复的已选边；这串重配从一个尚未配对的顶点出发，到另一个尚未配对的顶点结束，中途在准备加入的边与准备撤下的边之间交替。“增广”总是相对于**当前固定的匹配**而言，不是图本身的性质。

<!-- bilingual-en:start -->
## A four-vertex reassignment
<!-- bilingual-en:end -->
*四个顶点上的重配*

<!-- bilingual-en:start -->
Use four distinct vertices named $a,b,1,2$; here $1,2$ are vertex labels. Starting from the matching $M=\{a-1\}$, we want to give the unmatched vertex $b$ a partner. Adding $b-1$ alone would use $1$ twice, so inspect a chain of changes:
<!-- bilingual-en:end -->
取四个不同顶点，名称为 $a,b,1,2$；其中 $1,2$ 只是顶点标签。从匹配 $M=\{a-1\}$ 出发，希望为尚未匹配的 $b$ 找到配对。只加入 $b-1$ 会重复使用顶点 $1$，所以需要查看一串连锁变化：

$$
b\;\xrightarrow{\notin M}\;1\;\xrightarrow{\in M}\;a\;\xrightarrow{\notin M}\;2.
$$

<!-- bilingual-en:start -->
For example, suppose $a-1\in M$, while $b-1$ and $a-2$ are unselected and both $b$ and $2$ are unmatched. The path shown above uses a non-matching, matching, and non-matching edge in sequence, so it is augmenting.
<!-- bilingual-en:end -->
例如已有边 $a-1\in M$，而 $b-1$ 与 $a-2$ 未选，且 $b$、$2$ 都未匹配。路径
$$
b-1-a-2
$$
依次经过非 matching、matching、非 matching 边，所以它是 augmenting path。

<!-- bilingual-en:start -->
The arrows indicate the order in which we read an **undirected** path, not directed edges. Removing $a-1$ and adding $b-1,a-2$ replaces one pair by two. The exact reason that this operation preserves a matching is proved in [[增广路对称差|augmenting-path flipping]].
<!-- bilingual-en:end -->
箭头表示阅读这条**无向**路径的次序，不表示原图是有向图。撤下 $a-1$，再加入 $b-1,a-2$，便把一对换成两对。为什么这一操作始终保持匹配性质，见[[增广路对称差|增广路翻转]]的完整证明。

<!-- bilingual-en:start -->
## The matching and the whole path must be specified
<!-- bilingual-en:end -->
*先固定匹配，再检查完整路径*

<!-- bilingual-en:start -->
Work in a finite [[图类型的建模边界|simple undirected graph]] $G=(V,E)$, with vertex set $V$, edge set $E$, and a fixed matching $M\subseteq E$. A vertex is **unmatched by $M$** when it is incident to no edge of $M$ anywhere in the graph. Checking only the edges displayed on a path is insufficient.

Use [[游走路径与环|path]] in its simple-path sense: a sequence $P=(v_0,\ldots,v_\ell)$ of distinct vertices, with each consecutive pair joined by an edge. We require $\ell\ge1$, where $\ell$ counts edges, so the two endpoints are distinct. An **$M$-alternating path** has consecutive edges alternately in $M$ and outside $M$. An **$M$-augmenting path** is such a path whose two endpoints are unmatched by $M$.
<!-- bilingual-en:end -->
本文在有限[[图类型的建模边界|简单无向图]] $G=(V,E)$ 中讨论：$V$ 是顶点集，$E$ 是边集，先固定一个匹配 $M\subseteq E$。顶点**未被 $M$ 匹配**，是指它在全图中不接触任何一条 $M$ 中的边；只检查路径上画出的边并不够。

[[游走路径与环|路径]]采用简单路径约定：$P=(v_0,\ldots,v_\ell)$ 的各顶点互不相同，每对相邻顶点之间都有边。这里要求 $\ell\ge1$，$\ell$ 统计边数，因此两个端点不同。若沿路的边依次在属于 $M$ 与不属于 $M$ 之间交替，就称为 **$M$-交替路**；若其两个端点还都未被 $M$ 匹配，就称为 **$M$-增广路**。

> [!important] Both endpoints are free / 两个端点都未匹配
> <!-- bilingual-en:start -->
> Relative to a matching $M$, an alternating path alternates between edges outside and inside $M$. An augmenting path additionally has two endpoints that are uncovered by $M$, so both its first and last edges lie outside $M$.
> <!-- bilingual-en:end -->
> 相对于 matching $M$，alternating path 的边在“不属于 $M$”与“属于 $M$”之间交替。augmenting path 还要求两个端点都未被 $M$ 覆盖，因此它的第一条和最后一条边都不在 $M$ 中。

<!-- bilingual-en:start -->
The first edge cannot belong to $M$, because its starting vertex is unmatched; the same argument applies to the last edge. Alternation therefore forces the pattern outside, inside, outside, …, inside, outside. If there are $k$ selected edges on the path, there are $k+1$ unselected edges, giving odd length $2k+1$, where $k\ge0$. Odd length alone does not establish either alternation or unmatched endpoints.
<!-- bilingual-en:end -->
第一条边不能属于 $M$，否则起点就已经匹配；最后一条边同理。因此边型必定为“未选、已选、未选、……、已选、未选”。若路径上有 $k$ 条已选边，就有 $k+1$ 条未选边，总长度为奇数 $2k+1$，其中 $k\ge0$。只知道长度为奇数，不能推出交替性，也不能推出端点未匹配。

<!-- bilingual-en:start -->
## Why alternation alone is not enough
<!-- bilingual-en:end -->
*交替性还缺少什么*

<!-- bilingual-en:start -->
“Alternating” describes only the order of edges along a path. It does not by itself guarantee that flipping still yields a matching, let alone a larger one. If an endpoint's matching edge lies outside the path, a direct flip can create an endpoint conflict. If a path starts at an unmatched vertex and ends with a matching edge, the flip merely moves the unmatched endpoint without changing cardinality; flipping an alternating cycle also preserves cardinality. Requiring both endpoints to be unmatched is what makes the flip valid and increases the matching by one edge.
<!-- bilingual-en:end -->
“交替”只描述路径上的边怎样排列，并不单独保证翻转后仍是 matching，更不保证它变大。若端点原有的 matching edge 不在路径上，直接翻转可能制造端点冲突；若路径从未匹配点出发、以一条 matching edge 结束，翻转只把“未匹配”移到另一端而不增加边数；alternating cycle 的翻转也保持边数。只有两端都未匹配的 augmenting path 同时保证翻转合法且净增一条边。

<!-- bilingual-en:start -->
For a concrete endpoint failure, add a fifth vertex $3$ and replace the current matching by $\{a-1,b-3\}$. The same path $b-1-a-2$ still alternates, but $b$ is now matched outside the path. Keeping $b-3$ while adding $b-1$ would create two selected edges at $b$. The path is not augmenting for this new matching.

By contrast, the short path $b-1-a$ for $M=\{a-1\}$ alternates and can be flipped legally to $\{b-1\}$, but the size remains one: it ends at the matched vertex $a$. Legal reassignment and increasing the number of pairs are separate checks.
<!-- bilingual-en:end -->
例如再加入第五个顶点 $3$，把当前匹配改成 $\{a-1,b-3\}$。同一条路径 $b-1-a-2$ 的边型仍然交替，但 $b$ 已被路径外的 $b-3$ 匹配。若保留 $b-3$ 又加入 $b-1$，顶点 $b$ 就会接触两条已选边，所以它相对于新匹配并不是增广路。

相反，对 $M=\{a-1\}$ 而言，较短路径 $b-1-a$ 可以合法翻转成 $\{b-1\}$，但大小仍为一，因为它结束于已匹配顶点 $a$。重配是否合法与配对数是否增加，是两项不同的检查。

<!-- bilingual-en:start -->
A single edge between two unmatched vertices is already an augmenting path ($k=0$). A lone vertex is not: it has no edge and does not have two distinct endpoints. An empty graph has no augmenting path, and a matching covering every vertex has none because no unmatched endpoints remain. A walk that repeats vertices is not accepted as an augmenting path merely because its edge labels alternate.

Nothing in this definition requires the graph to be [[二分图|bipartite]]. In a bipartite graph, each step changes side, so the odd length places the two endpoints on opposite sides. The definition still uses both endpoints' status in $M$.
<!-- bilingual-en:end -->
连接两个未匹配顶点的一条边，本身就是增广路，对应 $k=0$。只有一个顶点则不算：它没有边，也没有两个不同端点。空图没有增广路；覆盖全体顶点的匹配也没有增广路，因为已不存在未匹配端点。重复访问顶点的游走，不能仅凭边型交替就当作增广路。

这个定义不要求图是[[二分图]]。在二分图中，每走一步都会换侧，所以奇数长度使两端位于不同侧；是否增广仍要检查两个端点相对于 $M$ 的匹配状态。

> [!question]- Check the endpoints / 回忆与辨别
> <!-- bilingual-en:start -->
> If a path alternates but both endpoints are already matched, does alternation alone imply that its flip enlarges the matching? No: the augmenting-path condition requires two unmatched endpoints, in addition to the simple alternating path.
> <!-- bilingual-en:end -->
> 一条边型交替、但两端都已匹配的路径，能否仅凭“交替”断言翻转后 matching 变大？
>
> **答案：** 不能。还必须确认它是两端未匹配的增广路。
