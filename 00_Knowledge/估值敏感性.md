# 估值敏感性分析是在说明其余假设如何处理后检验选定输入变化对估值的影响
<!-- bilingual-en:start -->
Valuation sensitivity analysis tests how selected input changes affect value while specifying the treatment of all other assumptions.
<!-- bilingual-en:end -->

估值敏感性分析回答“哪个输入稍微改变，答案就变化很大”。先选定基准模型，再改变一个或几个输入，并说明其余输入是固定，还是按经济关系联动。否则，表里两个数可能并不是同一道问题的比较。
<!-- bilingual-en:start -->
Sensitivity analysis identifies inputs to which value responds strongly. Set a base model, vary selected inputs, and state whether others are held fixed or change through economic relationships. Otherwise, two table entries may not represent comparable questions.
<!-- bilingual-en:end -->

例如只检验 $TV_n=CF_{n+1}/(w-g)$ 的局部敏感性，固定第一笔现金为 50：
<!-- bilingual-en:start -->
For a local test of $TV_n=CF_{n+1}/(w-g)$, hold the first cash flow fixed at 50:
<!-- bilingual-en:end -->

| 稳定期资本成本 $w$ / Cost of capital | 永续增长率 $g$ / Growth | 第 $n$ 年末终值 / Terminal value |
|---|---|---:|
| 8% | 3% | 1000 |
| 9% | 3% | 833.33 |
| 8% | 4% | 1250 |

这是终值时点的比较，还没有加显性期或折回今天。增长从 3% 改成 4% 时仍固定现金为 50，仅展示公式对参数的反应；若更多增长需要更多投资，应按[[终值增长的再投资约束]]重算分子。利润率下降与营运资本增加等一组有联系的变化，则属于完整情景而非单参数测试。
<!-- bilingual-en:start -->
These are terminal-date values, before adding the explicit period or discounting to today. Holding cash at 50 while changing growth isolates the formula response. Growth requiring extra investment needs the numerator recalculated using [[终值增长的再投资约束|reinvestment consistency]]. A connected set of operating changes is a scenario rather than a single-input test.
<!-- bilingual-en:end -->

输出 833.33–1250 只表示所选假设范围内的结果，不是自动得到的概率区间或置信区间。应报告哪些假设最影响结论、有什么证据约束它们，再用[[反向估值]]检查市价需要怎样的条件；小数位数多不能弥补预测依据薄弱。
<!-- bilingual-en:start -->
The range 833.33–1250 reflects selected assumptions, not an automatic probability or confidence interval. Report the influential assumptions and their evidence, then use [[反向估值|reverse valuation]] to examine price-implied requirements. Decimal precision does not remedy weak forecasts.
<!-- bilingual-en:end -->
