# 插入排序维持已处理前缀有序且成本随逆序对增加

<!-- bilingual-en:start -->
*Insertion sort keeps the processed prefix sorted and its cost follows inversions*
<!-- bilingual-en:end -->

> [!summary] 原子不变量
> 第 $i$ 轮开始时，前 $i$ 个“已处理项目”已经有序；算法把下一个项目向左移过所有更大的前驱，插入正确位置。这里的前缀是最先读到的项目，不保证包含全局最小的 $i$ 个项目。
>
> <!-- bilingual-en:start -->
> At the start of pass $i$, the first $i$ processed items are sorted. The algorithm moves the next item left past every larger predecessor and inserts it in the correct position. This prefix contains the items seen first; it need not contain the globally smallest $i$ items.
> <!-- bilingual-en:end -->

## 自然解释

若输入有 $I$ 个逆序对，标准相邻交换或平移实现只为消除这些逆序做额外移动，工作量可写为 $O(n+I)$。有序输入为 $\Theta(n)$，逆序输入有 $I=n(n-1)/2$，于是最坏为 $\Theta(n^2)$。只移动严格更大的前驱时，它稳定且只需常数辅助空间。

<!-- bilingual-en:start -->
If the input has $I$ inversions, standard adjacent-swap or shifting insertion sort performs extra movement only to remove those inversions, for $O(n+I)$ work. Sorted input takes $\Theta(n)$; reverse input has $I=n(n-1)/2$, giving a $\Theta(n^2)$ worst case. If it moves only strictly greater predecessors, the algorithm is stable and uses constant auxiliary space.
<!-- bilingual-en:end -->

> [!warning] 边界
> 用二分查找寻找插入点可以减少键比较，却不能消除数组中为腾位置而进行的平方级平移。低常数和近有序优势解释了它常用于小子数组或混合算法基例，但不改变任意大输入上的平方最坏界。
>
> <!-- bilingual-en:start -->
> Binary search can reduce key comparisons when locating the insertion point, but it cannot remove the potentially quadratic array shifts needed to make space. Low constants and strong performance on nearly sorted data explain its use for small subarrays or hybrid base cases, without changing the quadratic worst case on arbitrary large inputs.
> <!-- bilingual-en:end -->

> [!question]- 回忆与应用
> selection sort 与 insertion sort 的“有序前缀”有什么关键不同？
>
> **答案：** selection sort 的前缀已是全局最小项目的最终位置；insertion sort 的前缀只是已处理项目内部有序，后缀仍可能出现更小项目。
