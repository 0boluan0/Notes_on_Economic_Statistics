# 固定头数和宽度时，稠密自注意力的成对运算量随序列长度平方增长
<!-- bilingual-en:start -->
*With fixed head count and width, dense self-attention's pairwise computation grows quadratically with sequence length*
<!-- bilingual-en:end -->

**稠密自注意力**让序列中每个 query 与全部 key 配对。若序列长度为 $n$，每头就有 $n^2$ 个 query–key 对；在头数和向量宽度固定时，点积分数与 value 聚合的运算量都随 $n^2$ 增长。

<!-- bilingual-en:start -->
**Dense self-attention** pairs every query with every key in the sequence. A sequence of length $n$ therefore has $n^2$ query–key pairs per head. With head count and vector widths fixed, both score computation and value aggregation grow quadratically with $n$.
<!-- bilingual-en:end -->

对一般 [[缩放点积注意力]]，$Q\in\mathbb R^{n_q\times d_k}$、$K\in\mathbb R^{n_k\times d_k}$、$V\in\mathbb R^{n_k\times d_v}$。按标准矩阵乘法计算时，核心成本为

$$
QK^\top:\quad O(n_qn_kd_k),
\qquad
AV:\quad O(n_qn_kd_v).
$$

因此一头为 $O(n_qn_k(d_k+d_v))$。[[自注意力]] 中 $n_q=n_k=n$；[[交叉注意力]] 则由两个序列长度的乘积决定。

<!-- bilingual-en:start -->
For general [[缩放点积注意力|scaled dot-product attention]], standard matrix multiplication gives the displayed costs for $QK^\top$ and $AV$. One head therefore costs $O(n_qn_k(d_k+d_v))$ for these operations. [[自注意力|Self-attention]] sets $n_q=n_k=n$; [[交叉注意力|cross-attention]] depends on the product of its two sequence lengths.
<!-- bilingual-en:end -->

例如长度从 $1{,}000$ 增至 $2{,}000$，每头的完整配对数从 $1{,}000{,}000$ 增至 $4{,}000{,}000$。若可跳过 [[因果注意力掩码|因果掩码]] 禁止的配对，有效配对数是 $n(n+1)/2$，仍是二次阶。

<!-- bilingual-en:start -->
Increasing sequence length from $1{,}000$ to $2{,}000$ raises the full pair count per head from one million to four million. Skipping pairs forbidden by a [[因果注意力掩码|causal attention mask]] leaves $n(n+1)/2$ pairs, which is still quadratic.
<!-- bilingual-en:end -->

这个命题只统计成对注意力运算。生成 Q/K/V 的投影、[[逐位置前馈网络]]、设备利用率和数据搬运还会影响总成本；不能据此保证端到端延迟恰好变为四倍。单个新 query 读取已有 key 的情形中 $n_q=1$，也应回到一般公式判断。完整分数矩阵是否需要常驻显存，则是 [[注意力计算与显存|另一个存储问题]]。

<!-- bilingual-en:start -->
This result counts pairwise attention operations. Q/K/V projections, [[逐位置前馈网络|position-wise feed-forward networks]], device utilization, and data movement also affect total cost, so end-to-end latency need not increase by exactly four. For a single new query reading existing keys, $n_q=1$ and the general formula applies. Whether the complete score matrix must reside in device memory is a [[注意力计算与显存|separate storage question]].
<!-- bilingual-en:end -->
