# 复制指针只会建立别名而字符串深拷贝需要独立存储和完整终止符
<!-- bilingual-en:start -->
*Copying a pointer creates an alias; a string deep copy needs independent storage and the complete terminator*
<!-- bilingual-en:end -->

> [!summary] 复制的对象决定结果
> `char *t = s;` 只复制指针值，`s` 与 `t` 成为指向同一字符序列的**别名（alias）**；经一个名字改写对象，另一个名字观察到同一变化。字符串深拷贝则要建立独立存储，复制首个 `\0` 之前的全部字节和终止符，并明确新分配由谁释放。
> <!-- bilingual-en:start -->
> `char *t = s;` copies only the pointer value, so `s` and `t` alias the same character sequence. A string deep copy must obtain independent storage, copy all bytes through the first `\0`, and state who releases the new allocation.
> <!-- bilingual-en:end -->

```c
#include <stdlib.h>
#include <string.h>

char *copy_string(const char *source) {
    size_t bytes = strlen(source) + 1;
    char *copy = malloc(bytes);
    if (copy == NULL) {
        return NULL;
    }
    memcpy(copy, source, bytes);
    return copy;
}
```

这个接口的前置条件是 `source` 非空且指向有效 C 字符串；否则 `strlen` 已经无权扫描。`bytes` 包含终止符，成功分配的新对象与现有对象互不重叠，所以 `memcpy` 可以复制恰好 `bytes` 个字符。返回非空时，调用者取得新分配的所有权并最终 `free` 一次；返回空时，没有新所有权需要接收。
<!-- bilingual-en:start -->
The precondition is that `source` is non-null and points to a valid C string; otherwise even `strlen` may not scan it. `bytes` includes the terminator, and the successful new allocation is disjoint from existing objects, so `memcpy` copies exactly that valid extent. A non-null result transfers ownership of the new allocation to the caller.
<!-- bilingual-en:end -->

`memcpy(dst, src, n)` 只复制 `n` 个字符表示单位，不知道字符串、容量或所有权。源和目标都必须在各自仍存活的对象内提供至少 `n` 个可访问字符，且复制区间不能重叠；可能重叠时用 `memmove`。它不会自动追加 `\0`，也不会分配或释放对象。这里能复制完整字符串，完全依赖调用者已经把 `n` 选为 `strlen(source)+1` 并分配同样容量。
<!-- bilingual-en:start -->
`memcpy(dst, src, n)` merely copies `n` character-sized units. Both live objects must provide that extent and the regions must not overlap; use `memmove` when overlap is possible. `memcpy` neither appends `\0` nor allocates or releases storage. This example works because `n` includes the terminator and the destination has exactly that capacity.
<!-- bilingual-en:end -->

> [!question]- 最小自检
> 为什么 `char *t = s; t[0] = 'X';` 不能证明已经复制了字符串？
>
> **答案：** 赋值只复制地址值，`t[0]` 写的是 `s` 也指向的同一对象；独立副本必须拥有另一段存储并复制内容与终止符。
