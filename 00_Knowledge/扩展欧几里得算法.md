# Extended Euclidean algorithm
<!-- bilingual-en:end -->

*扩展欧几里得算法*

<!-- bilingual-en:start -->
For integer inputs $a,b$ not both zero, the ordinary [[欧几里得算法|Euclidean algorithm]] tracks remainders; its extended version also tracks each remainder as an integer linear combination of the original inputs. It returns $g,s,t$ with $g=\gcd(a,b)=sa+tb$. MIT calls it the **Pulverizer**. For hand calculations, writing the division equations and then substituting backward performs the same task as tracking coefficients forward.
<!-- bilingual-en:end -->

对不全为零的整数输入 $a,b$，普通[[欧几里得算法]]只保留余数；扩展版本还保留“每个余数是原输入的哪种整数线性组合”。它返回 $g,s,t$，满足 $g=\gcd(a,b)=sa+tb$。MIT 课程把它称为 **Pulverizer**。实际手算可以先列除法式再反向代入，这与逐步记录系数做的是同一件事。

<!-- bilingual-en:start -->
The extra information answers a concrete question: after finding a gcd, which multiples of the original inputs actually add to it? [[Bézout等式|Bézout’s identity]] guarantees that such integer coefficients exist. Here we keep an explicit record of them, so the output is a checkable triple rather than only the gcd.
<!-- bilingual-en:end -->

这些额外信息回答一个具体问题：已经找到 gcd 后，原输入各乘哪个整数，才能相加得到它？[[Bézout等式]]保证这种整数系数存在；这里把它们明确记录下来，因此输出是一个能代回核验的三元组，而不只是 gcd。

<!-- bilingual-en:start -->
## Back-substitution and forward records
<!-- bilingual-en:end -->

## 从一个能复算的例子看更新规则

<!-- bilingual-en:start -->
For $a=26,b=7$, division gives $26=3\cdot7+5$, $7=1\cdot5+2$, $5=2\cdot2+1$, and $2=2\cdot1+0$. Substitute backward from the last nonzero remainder:
<!-- bilingual-en:end -->

以 $a=26,b=7$ 为例，先得到 $26=3\cdot7+5$、$7=1\cdot5+2$、$5=2\cdot2+1$、$2=2\cdot1+0$。从最后一个非零余数反代：

$$
\begin{aligned}
1&=5-2\cdot2\\
 &=5-2(7-5)=3\cdot5-2\cdot7\\
 &=3(26-3\cdot7)-2\cdot7=3\cdot26-11\cdot7.
\end{aligned}
$$

<!-- bilingual-en:start -->
Each substitution replaces a later remainder using an earlier division equation. Stop only when the expression uses the two original inputs. The final coefficient of $26$ is $3$, while that of $7$ is $-11$; the negative sign is part of the answer.
<!-- bilingual-en:end -->

每次反代都用较早的除法等式替换较晚的余数，直到表达式中只剩两个原输入。最终 $26$ 的系数是 $3$，$7$ 的系数是 $-11$；负号也是答案的一部分。

<!-- bilingual-en:start -->
For forward coefficient tracking, suppose $x=s_xa+t_xb$ and $y=s_ya+t_yb$. If the quotient is $q$, then the new remainder $r=x-qy$ has coefficients $(s_x-qs_y,\ t_x-qt_y)$. Initialize with $(1,0)$ and $(0,1)$, update remainders and coefficients together, and return the last nonzero row. For negative inputs, first take absolute values and adjust coefficient signs on return.
<!-- bilingual-en:end -->

若用系数表向前算，设 $x=s_xa+t_xb$、$y=s_ya+t_yb$，本轮商为 $q$，则新余数 $r=x-qy$ 的系数就是 $(s_x-qs_y,\ t_x-qt_y)$。初始系数为 $(1,0)$、$(0,1)$；每轮同时更新余数和这对系数，最后返回非零行。负输入先取绝对值，返回时调整对应系数的符号。

<!-- bilingual-en:start -->
For the same positive inputs, each row below records a value $r$ together with coefficients $(u,v)$ satisfying $r=u\cdot26+v\cdot7$. The quotient used to produce a new row belongs to the two preceding remainder rows; it is not a coefficient in the final answer.
<!-- bilingual-en:end -->

对同一组正输入，下表每行记录一个数 $r$ 及其系数 $(u,v)$，满足 $r=u\cdot26+v\cdot7$。产生新行时所用的商来自前两行余数相除，并不是最终答案中的系数。

<!-- bilingual-en:start -->
| Value $r$ | Coefficient of $26$ | Coefficient of $7$ | Construction |
|---|---|---|---|
| $26$ | $1$ | $0$ | Initial row |
| $7$ | $0$ | $1$ | Initial row |
| $5$ | $1$ | $-3$ | Row1 $-3$ Row2 |
| $2$ | $-1$ | $4$ | Row2 $-$ Row3 |
| $1$ | $3$ | $-11$ | Row3 $-2$ Row4 |
| $0$ | $-7$ | $26$ | Row4 $-2$ Row5 |
<!-- bilingual-en:end -->

| 数值 $r$ | $26$ 的系数 | $7$ 的系数 | 产生方式 |
|---|---|---|---|
| $26$ | $1$ | $0$ | 初始行 |
| $7$ | $0$ | $1$ | 初始行 |
| $5$ | $1$ | $-3$ | 第1行 $-3$ 第2行 |
| $2$ | $-1$ | $4$ | 第2行 $-$ 第3行 |
| $1$ | $3$ | $-11$ | 第3行 $-2$ 第4行 |
| $0$ | $-7$ | $26$ | 第4行 $-2$ 第5行 |

> [!important] The zero row signals the stop · 零行只是停止信号
> <!-- bilingual-en:start -->
> Return the preceding nonzero row: here $(g,s,t)=(1,3,-11)$. The last row instead represents $0=-7\cdot26+26\cdot7$, which is true but does not represent the gcd of these inputs.
> <!-- bilingual-en:end -->
>
> 返回前一条非零行，这里是 $(g,s,t)=(1,3,-11)$。最后一行表示 $0=-7\cdot26+26\cdot7$，这个等式虽然成立，却没有表示这组输入的 gcd。

## The general update and why it works
<!-- bilingual-en:end -->

*一般更新与正确性*

<!-- bilingual-en:start -->
For arbitrary integer inputs not both zero, put $A=|a|$, $B=|b|$. Initialize two triples $(x,u_x,v_x)=(A,1,0)$ and $(y,u_y,v_y)=(B,0,1)$. They state the invariant $x=u_xA+v_xB$, $y=u_yA+v_yB$. While $y>0$, use [[带余除法|division with remainder]] to find $q$ and $r=x-qy$, where $0\le r<y$, then update both triples simultaneously:
<!-- bilingual-en:end -->

对不全为零的任意整数输入，令 $A=|a|$、$B=|b|$，初始化两组三元组 $(x,u_x,v_x)=(A,1,0)$、$(y,u_y,v_y)=(B,0,1)$。它们表达不变量 $x=u_xA+v_xB$、$y=u_yA+v_yB$。只要 $y>0$，就用[[带余除法]]求商 $q$ 和余数 $r=x-qy$，其中 $0\le r<y$，再同时更新两个三元组：

$$
\begin{aligned}
(x,u_x,v_x)&\longleftarrow(y,u_y,v_y),\\
(y,u_y,v_y)&\longleftarrow(x-qy,\ u_x-qu_y,\ v_x-qv_y).
\end{aligned}
$$

<!-- bilingual-en:start -->
Every right-hand expression uses the old values. Save the new second triple before overwriting the first, or use simultaneous assignment. Substitution verifies preservation: $x-qy=(u_x-qu_y)A+(v_x-qv_y)B$. The copied first triple is already a valid representation. All entries remain integers.
<!-- bilingual-en:end -->

所有右侧表达式都使用更新前的值。应先存好新的第二组三元组再覆盖第一组，或者使用同时赋值。代入即验证保持性：$x-qy=(u_x-qu_y)A+(v_x-qv_y)B$；复制得到的第一组原本就是有效表示。所有数值和系数仍为整数。

<!-- bilingual-en:start -->
The remainder pair follows exactly the ordinary Euclidean algorithm, so its gcd stays equal to $\gcd(A,B)$ and its nonnegative second coordinate strictly decreases while positive. Thus it terminates. At exit $y=0$, the first value is $x=g$ and its coefficients satisfy $g=u_xA+v_xB$. This separates the two obligations: the coefficient equations explain the result, while remainder descent guarantees a result is eventually returned. Exact integer arithmetic is assumed.
<!-- bilingual-en:end -->

余数对完全遵循普通欧几里得算法，因此 gcd 始终等于 $\gcd(A,B)$，非负第二坐标只要为正就严格下降，所以过程终止。退出时 $y=0$，第一项 $x=g$，其系数满足 $g=u_xA+v_xB$。这里分开了两项责任：系数等式说明返回值为何正确，余数下降保证最终能够返回；计算采用精确整数运算。

## Return coefficients for the original inputs
<!-- bilingual-en:end -->

*返回原输入的系数*

<!-- bilingual-en:start -->
Let $\sigma(a)$ be $1$ for $a>0$, $-1$ for $a<0$, and $0$ for $a=0$, so $|a|=\sigma(a)a$. On return set $s=u_x\sigma(a)$ and $t=v_x\sigma(b)$. Then $sa+tb=g$. For example, the positive-input result $1=3\cdot26-11\cdot7$ yields $1=(-3)(-26)-11\cdot7$ for inputs $(-26,7)$. Always check against the original signed inputs.
<!-- bilingual-en:end -->

定义 $\sigma(a)$：$a>0$ 时为 $1$，$a<0$ 时为 $-1$，$a=0$ 时为 $0$，于是 $|a|=\sigma(a)a$。返回时取 $s=u_x\sigma(a)$、$t=v_x\sigma(b)$，就有 $sa+tb=g$。例如正输入结果 $1=3\cdot26-11\cdot7$，对输入 $(-26,7)$ 变成 $1=(-3)(-26)-11\cdot7$；始终使用原来的带符号输入验算。

<!-- bilingual-en:start -->
If $b=0$ and $a\ne0$, no division is performed: return $(|a|,\sigma(a),0)$. If $a=0$ and $b\ne0$, the first quotient is zero, so one update produces the nonzero first row; return $(|b|,0,\sigma(b))$. No ordering of input magnitudes is required: a smaller first value merely gives a zero first quotient. If both inputs are zero, explicitly return $(0,0,0)$ under the [[最大公因数|gcd zero-pair convention]]; there is then no last nonzero row, and no division should be attempted.
<!-- bilingual-en:end -->

若 $b=0$、$a\ne0$，无须除法，直接返回 $(|a|,\sigma(a),0)$。若 $a=0$、$b\ne0$，第一轮商为零，一次更新后非零数成为第一行，返回 $(|b|,0,\sigma(b))$。无须按绝对值大小排序输入：第一项较小时，只会使首轮商为零。若两输入都为零，依照[[最大公因数|gcd 双零约定]]明确返回 $(0,0,0)$；此时根本没有最后非零行，也不应尝试除法。

<!-- bilingual-en:start -->
The coefficients are not unique. Back-substitution and another correct implementation may return different pairs, so compare the identity rather than expecting a particular pair. For example, both $(3,-11)$ and $(10,-37)$ satisfy $26s+7t=1$.
<!-- bilingual-en:end -->

系数并不唯一。反代和另一种正确实现可能返回不同系数对，因此应核验等式，而不是强求某一对指定答案。例如 $(3,-11)$ 与 $(10,-37)$ 都满足 $26s+7t=1$。

<!-- bilingual-en:start -->
## Using the computed coefficient as an inverse
<!-- bilingual-en:end -->

*用计算出的系数求逆元*

<!-- bilingual-en:start -->
Use an integer modulus $n\ge2$ in a modular-inverse application. A [[模逆元|modular inverse]] is a residue class whose product with the given integer is congruent to one; it is not the ordinary reciprocal. When the input order is $(a,n)$ and $g=1$, take the coefficient of $a$ and reduce it to a representative between $0$ and $n-1$. In the example below the order is $(26,7)$, so the coefficient of $7$, not that of $26$, gives the inverse of $7$ modulo $26$.
<!-- bilingual-en:end -->

求模逆元时约定整数模数 $n\ge2$。[[模逆元]]是乘以给定整数后同余于一的同余类，并不是普通倒数。当输入顺序为 $(a,n)$ 且 $g=1$ 时，取 $a$ 的系数，再化为 $0$ 到 $n-1$ 之间的代表元。下面的例子使用顺序 $(26,7)$，因此求 $7$ 模 $26$ 的逆元要取 $7$ 的系数，而不是 $26$ 的系数。

<!-- bilingual-en:start -->
The direct check is to substitute the original inputs into $sa+tb=g$. Here, reducing modulo $26$ gives $-11\cdot7\equiv1$, so $15$ represents a [[模逆元|modular inverse]] of $7$. If the gcd is not $1$, the returned coefficient is not automatically an inverse; apply the [[模逆元存在条件|inverse-existence criterion]].
<!-- bilingual-en:end -->

用原始输入验算 $sa+tb=g$ 是最直接的检查。在这个例子中，模 $26$ 后 $-11\cdot7\equiv1$，所以 $7$ 的[[模逆元]]可取 $15$；若算出的 gcd 不是 $1$，就不能把返回的系数直接叫作逆元，须按[[模逆元存在条件]]判断。
