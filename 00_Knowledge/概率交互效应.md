# 概率交互效应衡量一个变量的概率效应如何随另一个变量的取值改变

<!-- bilingual-en:start -->
*A probability-scale interaction effect measures how one variable's effect on event probability changes with another variable's value*
<!-- bilingual-en:end -->

> [!summary] 它是什么
> 令 $p(x_1,x_2,z)=P(Y=1\mid x_1,x_2,z)$。若 $x_1,x_2$ 都连续，概率交互效应是
> $$
> \frac{\partial^2p}{\partial x_1\partial x_2},
> $$
> 即“$x_1$ 的概率边际效应随 $x_2$ 怎样变化”。若两者都是二元变量，则用四格预测概率的差异之差表达同一问题。
> <!-- bilingual-en:start -->
> Let $p(x_1,x_2,z)=P(Y=1\mid x_1,x_2,z)$. For two continuous variables, the probability-scale interaction is the cross-partial $\partial^2p/(\partial x_1\partial x_2)$: how the probability marginal effect of $x_1$ changes with $x_2$. For two binary variables, the same question is expressed as a difference in differences across four predicted probabilities.
> <!-- bilingual-en:end -->

对两个二元变量 $D_1,D_2$，更直接的概率尺度交互是四格差异之差：

<!-- bilingual-en:start -->
For two binary variables $D_1,D_2$, the more direct probability-scale interaction is the difference in differences across the four cells:
<!-- bilingual-en:end -->

$$
[p(1,1,z)-p(0,1,z)]-[p(1,0,z)-p(0,0,z)].
$$

四个概率都必须由同一模型、同一个 $z$ 重新预测。若要汇总到样本平均，应先逐观测计算四格对比，再明确按哪个样本或权重分布平均。

<!-- bilingual-en:start -->
All four probabilities must be predicted again from the same model at the same $z$. To summarize this interaction as a sample average, first compute the four-cell contrast for each observation and then state explicitly which sample or weighting distribution is used for the average.
<!-- bilingual-en:end -->

> [!example] 四格概率对比
> 假设同一个 $z$ 下四格预测概率依次为 $p_{00}=0.10$、$p_{10}=0.20$、$p_{01}=0.30$、$p_{11}=0.55$。$x_2=0$ 时 $x_1$ 的效应是 $0.10$，$x_2=1$ 时是 $0.25$，所以概率交互效应为 $0.25-0.10=0.15$。

<!-- bilingual-en:start -->
> [!example] Four-cell probability contrast
> Suppose the predicted probabilities at the same $z$ are $p_{00}=0.10$, $p_{10}=0.20$, $p_{01}=0.30$, and $p_{11}=0.55$. The effect of $x_1$ is $0.10$ when $x_2=0$ and $0.25$ when $x_2=1$, so the probability interaction is $0.25-0.10=0.15$.
<!-- bilingual-en:end -->

这个对比首先是模型内的条件概率关系。若 $x_1$ 或 $x_2$ 是处理，只有在相应干预定义、混杂控制和支持条件成立时，才可进一步解释为因果效应异质性。另一个独立边界是：线性指数中的交互系数不等于这个概率尺度对象，见 [[交互系数不等于概率交互]]。

<!-- bilingual-en:start -->
This contrast is first a relationship among model-implied conditional probabilities. If either variable is a treatment, it can be interpreted as causal effect heterogeneity only under the relevant intervention definition, confounding control, and support conditions. A separate boundary is that an interaction coefficient in the linear index is not this probability-scale object; see [[交互系数不等于概率交互|the interaction-coefficient boundary]].
<!-- bilingual-en:end -->
