# 信息集只要以严格正概率到达就属于路径上并须按 Bayes 法则更新，概率再小也不等于路径外
<!-- bilingual-en:start -->
*An information set reached with any strictly positive probability is on path and must be updated by Bayes' rule; an arbitrarily small probability is not the same as zero.*
<!-- bilingual-en:end -->

路径上与路径外的判准是到达概率是否严格为正，而不是概率是否“足够大”。若候选策略 $\sigma$ 使 $P_\sigma(I)>0$，则信息集 $I$ 内的信念必须满足：
<!-- bilingual-en:start -->
The on-path/off-path criterion is whether reach probability is strictly positive, not whether it is “large enough.” If candidate strategy $\sigma$ gives $P_\sigma(I)>0$, beliefs within information set $I$ must satisfy:
<!-- bilingual-en:end -->

$$
\mu(x\mid I)=\frac{P_\sigma(x)}{P_\sigma(I)}
\qquad (x\in I).
$$

## 判准是正还是零
<!-- bilingual-en:start -->
*The criterion is positive versus zero.*
<!-- bilingual-en:end -->

只要 $P_\sigma(I)=\varepsilon>0$，分母就非零，Bayes 条件概率有定义；无论 $\varepsilon$ 多小，都不能任意指定该处信念。只有 $P_\sigma(I)=0$ 时，直接的 Bayes 比值才成为 $0/0$，弱 PBE 才不由路径上 Bayes 法则唯一决定该处信念。
<!-- bilingual-en:start -->
As long as $P_\sigma(I)=\varepsilon>0$, the denominator is nonzero and the Bayesian conditional probability is defined. No matter how small $\varepsilon$ is, beliefs there cannot be assigned arbitrarily. Only when $P_\sigma(I)=0$ does the direct Bayes ratio become $0/0$, so on-path Bayes consistency in weak PBE no longer uniquely determines the belief.
<!-- bilingual-en:end -->

## 一个数值检查
<!-- bilingual-en:start -->
*A numerical check*
<!-- bilingual-en:end -->

若信息集 $I=\{x_1,x_2\}$ 的两个节点分别以 $0.009$ 与 $0.001$ 的概率到达，则 $P_\sigma(I)=0.01>0$，所以
<!-- bilingual-en:start -->
If the two nodes of information set $I=\{x_1,x_2\}$ are reached with probabilities $0.009$ and $0.001$, then $P_\sigma(I)=0.01>0$, so
<!-- bilingual-en:end -->

$$
\mu(x_1\mid I)=0.9,
\qquad
\mu(x_2\mid I)=0.1.
$$

这个信息集虽不常到达，仍是路径上的；把它当作路径外并任选信念会违反一致性。
<!-- bilingual-en:start -->
Although the information set is reached infrequently, it is still on path. Treating it as off path and choosing beliefs freely would violate consistency.
<!-- bilingual-en:end -->
