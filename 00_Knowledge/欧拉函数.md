# 欧拉函数计算一个完整余数系中与模数互素的余数个数
<!-- bilingual-en:start -->
*Euler's totient counts the residues in a complete residue system that are coprime to the modulus*
<!-- bilingual-en:end -->

对正整数 $n$，欧拉函数定义为
$$
\varphi(n)=\left|\{r\in\{0,1,\ldots,n-1\}:\gcd(r,n)=1\}\right|.
$$
当 $n\ge2$ 时，由 [[模逆元存在条件]]，它也就是模 $n$ 的可逆余数类个数。它计算的是个数，不是这些余数的和。
<!-- bilingual-en:start -->
For a positive integer $n$, the displayed count defines Euler's totient. For $n\ge2$, the [[模逆元存在条件|criterion for modular invertibility]] identifies it with the number of invertible residue classes. It counts the residues rather than adding their values.
<!-- bilingual-en:end -->

例如模 $12$ 的可逆余数只有 $1,5,7,11$，所以 $\varphi(12)=4$。若 $p$ 为素数，$1,\ldots,p-1$ 全与 $p$ 互素，因此 $\varphi(p)=p-1$。边界 $n=1$ 按同一定义得到 $\varphi(1)=1$，因为唯一余数为 $0$，且 $\gcd(0,1)=1$。
<!-- bilingual-en:start -->
Modulo twelve, the invertible residues are $1,5,7,11$, so $\varphi(12)=4$. For a prime $p$, every residue from one to $p-1$ is coprime to $p$, giving $\varphi(p)=p-1$. At the boundary $n=1$, the only residue is zero and $\gcd(0,1)=1$, so $\varphi(1)=1$.
<!-- bilingual-en:end -->

这个数在 [[欧拉定理]] 中成为一个可用的模幂周期：对与 $n$ 互素的底数，提升到 $\varphi(n)$ 次方回到余数 $1$；但它未必是最小的正周期。
<!-- bilingual-en:start -->
In [[欧拉定理|Euler's theorem]], the count supplies an exponent returning every coprime base to residue one. It need not be the smallest positive exponent doing so.
<!-- bilingual-en:end -->
