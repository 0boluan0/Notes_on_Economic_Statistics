# 生成器表达式立即求值最左可迭代表达式并按需计算其余部分
<!-- bilingual-en:start -->
*A generator expression evaluates its leftmost iterable immediately and computes the rest on demand*
<!-- bilingual-en:end -->

> [!summary] 原子时序
> 生成器表达式返回一个生成器迭代器，而不是立即装满结果的容器。创建时会先求值最左侧 **for** 的可迭代表达式并取得它的迭代器；结果表达式、筛选条件与后续 **for** 子句则在请求下一个值时才求值。

~~~python
def source():
    print("取得来源")
    return range(4)

def transform(x):
    print("计算", x)
    return x * x

values = (transform(x) for x in source() if x % 2 == 0)
# 此时已经打印“取得来源”，但尚未调用 transform

first = next(values)       # 现在才计算并得到 0
rest = list(values)        # 继续计算并得到 [4]
~~~

这条“最左边立即、其余按需”的边界解释了错误出现的时机：最左可迭代表达式不存在或不能迭代，创建生成器时就报错；变换表达式或后续子句中的错误，通常要到消费相应元素时才出现。

## 惰性不等于免费或可重复

生成器一次只产出当前需要的值，因而可以避免把全部结果同时存成列表；但计算本身没有消失，生成器还会保留完成迭代所需的状态和引用。它也是一次性迭代器：消费到末尾后再次遍历不会自动重算。

需要随机访问、反复遍历、固定快照或立刻发现全部错误时，应明确构造列表；数据量大、只顺序消费一次，或希望把多个处理阶段串成流水线时，生成器表达式更合适。

> [!question]- 自检
> 为什么“生成器是惰性的”仍不能推出创建表达式时绝不会报错？
>
> **答案：** 最左侧可迭代表达式及其 **iter()** 转换会立即执行；只有结果表达式、条件和后续子句延后。
