# 浮点加法不满足结合律因为中间结果分别舍入

<!-- bilingual-en:start -->
*Floating-point addition is non-associative because intermediate results are rounded*
<!-- bilingual-en:end -->

> [!summary] 原子命题
> 实数满足 $(a+b)+c=a+(b+c)$，但浮点求值在每个括号处产生并舍入中间结果，所以两种分组可能把不同信息先丢掉，最终值可以不同。改变求和顺序既可能改善精度，也可能使精度变差。
>
> <!-- bilingual-en:start -->
> Real addition satisfies $(a+b)+c=a+(b+c)$, but floating-point evaluation forms and rounds an intermediate result at each pair of parentheses. Different groupings can discard different information and produce different final values. Reordering a sum can improve accuracy or make it worse.
> <!-- bilingual-en:end -->

在常见 binary64 Python 环境中：

```python
a, b, c = 1e16, -1e16, 1.0
print((a + b) + c)  # 1.0
print(a + (b + c))  # 0.0
```

第一种先得到可精确表示的 0，再加 1；第二种先算 `-1e16 + 1.0`，其中 1 小于该尺度的间距而丢失，随后与 `1e16` 抵消为 0。
<!-- bilingual-en:start -->
The first grouping forms an exactly representable zero before adding 1. The second first computes `-1e16 + 1.0`; the increment is smaller than the spacing at that scale and is lost, after which cancellation with `1e16` yields zero.
<!-- bilingual-en:end -->

非结合性不等于“任何顺序都随意”或“结果随机”。给定格式、舍入模式与求值顺序，结果可以完全确定；正因为顺序有语义，重排表达式、并行归约、编译器快速数学优化或融合运算都必须在相应数值契约下评估。
<!-- bilingual-en:start -->
Non-associativity does not mean that every order is arbitrary or that results are random. Given a format, rounding mode, and evaluation order, a result can be deterministic. Precisely because order matters, expression reassociation, parallel reduction, fast-math optimization, and fused operations must be judged under an explicit numerical contract.
<!-- bilingual-en:end -->

> [!question]- 回忆与应用
> 并行计算把同一组数分块求和后再合并，为什么可能与单线程顺序求和不同？
>
> **答案：** 分块改变了括号和中间舍入位置；浮点加法不满足结合律，因此归约树不同可产生不同末位结果。
