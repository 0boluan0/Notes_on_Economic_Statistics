# Leading principal minors
<!-- bilingual-en:end -->
*顺序主子式*

<!-- bilingual-en:start -->
**Leading principal minors** are the determinants of a square matrix's successive upper-left square blocks. Start with its first entry, then enlarge to the first two rows and columns, then the first three, and continue to the whole matrix. The word “leading” refers to the current ordering of rows and columns; it does not mean sorting the resulting numbers.
<!-- bilingual-en:end -->

**顺序主子式**是方阵左上角一串逐步扩大的方形块的行列式。从第一个元素开始，再取前两行两列、前三行三列，直到整个矩阵。“顺序”指当前的行列排列，不是把算出的数值从小到大排序。

<!-- bilingual-en:start -->
A [[主子式|principal minor]] keeps the same index set for rows and columns. A leading principal minor restricts that set to the first $k$ indices, $\{1,\ldots,k\}$. The selected block is still a matrix; the [[行列式|determinant]] of that block is the scalar called the minor.
<!-- bilingual-en:end -->

[[主子式]]要求行与列保留同一个下标集；顺序主子式进一步要求这组下标必须是最前面的 $k$ 个，即 $\{1,\ldots,k\}$。选出的块仍是一张矩阵，取它的[[行列式]]以后，才得到称为主子式的标量。

> [!important] One initial block at each order · 每阶只取一个最前块
> <!-- bilingual-en:start -->
> Let $A$ be an $n\times n$ matrix with $n\ge1$ an integer. For each integer $1\le k\le n$, define its **leading principal minor of order $k$** by
> <!-- bilingual-en:end -->
>
> 设 $A$ 为 $n\times n$ 矩阵，$n\ge1$ 为整数。对每个整数 $1\le k\le n$，定义其 **$k$ 阶顺序主子式**为
>
> $$L_k=\det A_{1:k,1:k}.$$
>
> <!-- bilingual-en:start -->
> The notation $1:k$ means $1,2,\ldots,k$: retain the first $k$ rows and the first $k$ columns. There is one such choice at each order, hence $n$ choices in total. In particular, $L_1=a_{11}$ and $L_n=\det A$. The definition also applies to nonsymmetric matrices and complex entries; sign-based definiteness tests have additional assumptions.
> <!-- bilingual-en:end -->
>
> 记号 $1:k$ 表示 $1,2,\ldots,k$，即保留前 $k$ 行与前 $k$ 列。每阶恰好有一个这样的选择，因此合计 $n$ 个。特别地，$L_1=a_{11}$、$L_n=\det A$。定义同样适用于非对称矩阵与复数元素；按符号判断正定性的定理另有前提。

<!-- bilingual-en:start -->
## Grow the block, then take its determinant
<!-- bilingual-en:end -->
*先扩大方块，再计算行列式*

<!-- bilingual-en:start -->
Use the same matrix as in the principal-minor example:
<!-- bilingual-en:end -->

沿用主子式定义中的矩阵：

$$A=\begin{pmatrix}4&1&2\\1&5&3\\2&3&6\end{pmatrix}.$$

$$L_1=\det[4]=4,\qquad
L_2=\det\begin{pmatrix}4&1\\1&5\end{pmatrix}=19,\qquad
L_3=\det A=70.$$

<!-- bilingual-en:start -->
The second value is $4\cdot5-1\cdot1=19$. The last value is $4(30-9)-1(6-6)+2(3-10)=70$. Keeping indices $\{1,3\}$ gives another principal minor, $20$, but not $L_2$: it skips index $2$. Likewise, the principal minor on $\{2,3\}$ is $21$, not part of this leading sequence. Thus the complete principal-minor collection has seven selections here, while the leading collection has only three.
<!-- bilingual-en:end -->

第二个值为 $4\cdot5-1\cdot1=19$，最后一个值为 $4(30-9)-1(6-6)+2(3-10)=70$。保留下标 $\{1,3\}$ 得到另一个主子式 $20$，但它不是 $L_2$，因为跳过了下标 $2$。下标 $\{2,3\}$ 对应的主子式 $21$ 也不在这串顺序主子式中。因此，本例全部主子式有七个下标选择，顺序主子式只有三个。

<!-- bilingual-en:start -->
The count concerns positions, not different numerical values. For the [[单位矩阵|identity matrix]], all $L_k=1$, yet each order still supplies its own leading principal minor. If $n=1$, there is just $L_1=\det A$.
<!-- bilingual-en:end -->

数量计算的是位置选择，不是互不相同的数值。对[[单位矩阵]]，所有 $L_k$ 都等于 $1$，但每一阶仍有自己的顺序主子式。若 $n=1$，则只有 $L_1=\det A$。

<!-- bilingual-en:start -->
## Leading depends on the current order
<!-- bilingual-en:end -->
*“最前面”依赖当前排序*

<!-- bilingual-en:start -->
Reorder both the rows and the columns of the example as $3,2,1$. This gives
<!-- bilingual-en:end -->

把例子中的行与列都按 $3,2,1$ 重新排列，得到

$$B=\begin{pmatrix}6&3&2\\3&5&1\\2&1&4\end{pmatrix}.$$

<!-- bilingual-en:start -->
Its leading sequence is now $6,21,70$. The former non-leading principal minor on indices $\{2,3\}$ has become the second leading minor. Simultaneously relabelling rows and columns preserves the full collection of principal-minor values, but changes which subsets occur first. For the whole determinant, the row-permutation sign and the identical column-permutation sign cancel. Permuting only rows is a different operation and need not preserve this collection.
<!-- bilingual-en:end -->

新顺序主子式为 $6,21,70$。原来下标 $\{2,3\}$ 对应的非顺序主子式，现在成为二阶顺序主子式。行、列同步重编号会保留全部主子式的数值集合，却改变哪些下标排在最前；整个行列式中，行排列与相同列排列带来的两个符号相互抵消。只重排行而不对应重排列，是另一种操作，不保证保留这组主子式。

<!-- bilingual-en:start -->
## A definition is not yet a positivity test
<!-- bilingual-en:end -->
*定义与符号判据分开*

<!-- bilingual-en:start -->
For a [[实对称矩阵|real symmetric]] or [[Hermitian 矩阵|complex Hermitian]] matrix, [[Sylvester 正定判据|Sylvester's criterion]] says that **all** $L_k>0$ are equivalent to [[正定矩阵|positive definiteness]]. This is a theorem about the defined quantities, not part of their definition. The symmetry or Hermitian assumption and every order must be retained.
<!-- bilingual-en:end -->

对[[实对称矩阵]]或复 [[Hermitian 矩阵]]，[[Sylvester 正定判据]]说明**全部** $L_k>0$ 与[[正定矩阵|正定性]]等价。这是关于这些已定义数量的定理，不是定义的一部分；必须保留对称或 Hermitian 前提，并检查每一阶。

> [!warning] Nonnegative leading values are insufficient · 非负顺序主子式还不够
> <!-- bilingual-en:start -->
> Replacing all strict inequalities by $L_k\ge0$ does not establish [[半正定矩阵|positive semidefiniteness]]. For $A=\begin{pmatrix}0&0\\0&-1\end{pmatrix}$, the leading values are $0,0$, while the omitted first-order principal minor $a_{22}$ is $-1$. The complete explanation is in [[顺序主子式不推半正定|the leading-minor boundary]].
> <!-- bilingual-en:end -->
>
> 把严格不等号全部改成 $L_k\ge0$，并不能证明[[半正定矩阵|半正定]]。例如 $A=\begin{pmatrix}0&0\\0&-1\end{pmatrix}$ 的顺序主子式为 $0,0$，但漏查的一阶主子式 $a_{22}=-1$。完整解释见[[顺序主子式不推半正定]]。
