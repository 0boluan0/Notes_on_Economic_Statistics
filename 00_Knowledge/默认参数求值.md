# 默认参数在定义时只求值一次而可变默认对象会被后续省略实参的调用共享
<!-- bilingual-en:start -->
*Default parameters are evaluated once at definition time, so mutable defaults are shared by later calls that omit the argument*
<!-- bilingual-en:end -->

> [!summary] 原子求值时点
> 默认值表达式在执行 `def` 时从左到右求值一次，而不是每次调用重新求值。之后省略该实参的调用会把同一个预计算对象绑定给形参。不可变默认值通常不会暴露共享；若函数原地修改默认 list、dict 或自定义实例，后续调用会观察到之前留下的状态。
> <!-- bilingual-en:start -->
> Default expressions are evaluated once, from left to right, when `def` executes rather than on every call. Later calls that omit the argument bind the same precomputed object to the parameter. Sharing is usually harmless for immutable defaults, but mutating a default list, dictionary, or instance exposes state from earlier calls.
> <!-- bilingual-en:end -->

```python
def collect(value, bucket=None):
    if bucket is None:
        bucket = []
    bucket.append(value)
    return bucket
```

`None` 哨兵让每次省略实参的调用在函数体内新建容器；若 `None` 本身也是合法业务输入，则需要专用 sentinel 对象来区分“未传”和“显式传入 None”。可变默认值不是语法错误，也可有意用于缓存，但那会把共享状态写进接口，必须明确记录并审查并发、生命周期和可测试性。

> [!question]- 自检
> 为什么把 `bucket=[]` 换成 `bucket=None` 后，还必须在函数体内创建新列表？
>
> **答案：** `None` 只负责标记调用者省略了实参；真正的新容器必须在每次调用执行函数体时创建，才能避免跨调用共享。
