# Lower contour sets
<!-- bilingual-en:end -->

*下轮廓集*

<!-- bilingual-en:start -->
A **lower contour set** collects allowed inputs whose outputs stay within a chosen ceiling. For a function measuring cost, error or distance squared, it answers which choices keep that quantity no larger than the permitted amount. The members are inputs, and a choice exactly on the permitted limit still qualifies.
<!-- bilingual-en:end -->

**下轮廓集**收集输出不超过指定上限的允许输入。若函数表示成本、误差或距离平方，它就回答哪些选择使这个量不超过允许值。成员是输入，恰好达到允许上限的选择也合格。

> [!example] A disk includes its interior · 圆盘包含内部
> <!-- bilingual-en:start -->
> For $f(u,v)=u^2+v^2$ on $\mathbb R^2$, impose the ceiling $1$. The origin qualifies, as does $(3/5,4/5)$ because $9/25+16/25=1$. The point $(1,1)$ does not, since its output is $2$. All qualifying points together form the disk of radius one, including its circular edge.
> <!-- bilingual-en:end -->
>
> 对 $\mathbb R^2$ 上的 $f(u,v)=u^2+v^2$，上限取 $1$。原点合格；$(3/5,4/5)$ 也合格，因为 $9/25+16/25=1$；$(1,1)$ 的输出为 $2$，不合格。所有合格点组成半径为一的圆盘，并包含圆周。

<!-- bilingual-en:start -->
## Inputs below an output ceiling
<!-- bilingual-en:end -->

*输出不超过上限的输入*

<!-- bilingual-en:start -->
Let $f:U\to\mathbb R$, where $U\subseteq\mathbb R^n$ is the set of allowed inputs and the positive integer $n$ counts the coordinates. Fix a real threshold $k$. The symbol $C_k^-$ names the set below; its superscript labels the comparison direction, not the sign of any input coordinate. No continuity, derivative or convex-domain assumption is needed.
<!-- bilingual-en:end -->

设 $f:U\to\mathbb R$，其中 $U\subseteq\mathbb R^n$ 是允许输入的集合，正整数 $n$ 是坐标个数。固定实数门槛 $k$。$C_k^-$ 命名下面的集合，上标只标记比较方向，不限定输入坐标的正负。定义不要求连续、可导或定义域凸。

<!-- bilingual-en:start -->
The lower contour set, also called a sublevel set, is $C_k^-=\{x\in U:f(x)\le k\}$. The braces collect exactly the allowed inputs satisfying the weak inequality. An [[上轮廓集|upper contour set]] uses the opposite weak inequality.
<!-- bilingual-en:end -->

对 $f:U\to\mathbb R$，门槛 $k$ 的下轮廓集是 $C_k^-=\{x\in U:f(x)\le k\}$，也称 sublevel set。与[[上轮廓集]]不同，它保留函数值较低的一侧。

<!-- bilingual-en:start -->
The [[水平集|level set]] at $k$ includes only inputs with $f(x)=k$ and is contained in this lower set. By contrast, the function graph consists of pairs $(x,f(x))$ with an extra output coordinate. For the disk example, $(0,0)$ is an input in the lower set, while $(0,0,0)$ is its point on the graph. Changing $\le$ to $<$ gives a strict sublevel set; in this example it removes the circle.
<!-- bilingual-en:end -->

水平 $k$ 的[[水平集]]只保留 $f(x)=k$ 的输入，包含在下轮廓集中。函数图像则由多带一个输出坐标的 $(x,f(x))$ 组成。圆盘例子中，$(0,0)$ 是下轮廓集里的输入，$(0,0,0)$ 才是图像上的对应点。把 $\le$ 换成 $<$ 得到严格下水平集；在这个例子里，它会去掉圆周。

<!-- bilingual-en:start -->
A lower contour or sublevel set retains values at most at the threshold, including equality. For the sum of squares at threshold one, this is the closed disk, not just the circle. [[拟凸函数|Quasiconvexity]] requires every sublevel set to be convex.
<!-- bilingual-en:end -->

$f(x,y)=x^2+y^2$ 的 $C_1^-$ 是闭单位圆盘，包括边界；不是只指圆周。[[拟凸函数]]要求每个下轮廓集凸。

<!-- bilingual-en:start -->
## Keep the domain while solving
<!-- bilingual-en:end -->

*解不等式时保留定义域*

<!-- bilingual-en:start -->
For the sum of squares on the whole plane, $k<0$ gives an empty set because $u^2+v^2\ge0$. At $k=0$ only $(0,0)$ remains. At $k>0$ the inequality gives a disk of radius $\sqrt{k}$. If the domain is instead $U=\{(u,v):u>0,\ v>0\}$, keep only its intersection with that disk: neither axis nor the origin belongs, even if it satisfies the numerical inequality. Under that domain restriction, the zero-level lower set is empty.
<!-- bilingual-en:end -->

在整个平面的平方和例子中，$k<0$ 时为空，因为 $u^2+v^2\ge0$；$k=0$ 时只剩 $(0,0)$；$k>0$ 时得到半径 $\sqrt{k}$ 的圆盘。若定义域改为 $U=\{(u,v):u>0,\ v>0\}$，就只能保留圆盘与该域的交集：坐标轴与原点即使满足数值不等式，也不属于集合。这个定义域下，门槛为零的下轮廓集为空。

<!-- bilingual-en:start -->
“Lower” compares outputs, not the page or the input coordinates. For $g(u)=-u$ on $\mathbb R$ with ceiling $0$, the test $-u\le0$ gives $u\ge0$, the right-hand half-line. Always evaluate the function or solve its inequality before deciding which inputs qualify.
<!-- bilingual-en:end -->

“下”比较的是输出，不是图纸位置或输入坐标。对 $\mathbb R$ 上的 $g(u)=-u$，上限取 $0$，条件 $-u\le0$ 得到 $u\ge0$，反而是右侧半直线。应先计算函数值或解不等式，再判断哪些输入合格。

<!-- bilingual-en:start -->
## Increasing the ceiling admits more inputs
<!-- bilingual-en:end -->

*提高上限会放宽选择*

<!-- bilingual-en:start -->
For $k_1<k_2$, $C_{k_1}^-\subseteq C_{k_2}^-$: any input satisfying $f(x)\le k_1$ also satisfies $f(x)\le k_2$. The inclusion need not be strict. For $f\equiv c$ on $U$, the set is empty when $k<c$ and equals $U$ when $k\ge c$. An empty domain gives empty lower sets at every threshold.
<!-- bilingual-en:end -->

若 $k_1<k_2$，则 $C_{k_1}^-\subseteq C_{k_2}^-$，因为满足 $f(x)\le k_1$ 的输入也满足 $f(x)\le k_2$。包含关系不一定严格。对 $U$ 上的常数函数 $f\equiv c$，$k<c$ 时为空，$k\ge c$ 时等于整个 $U$；空定义域在每个门槛都给出空集。

<!-- bilingual-en:start -->
A [[凸集|convex set]] contains every segment joining its members. Requiring a convex domain and a convex lower contour set at every threshold defines [[拟凸函数|quasiconvexity]]; lower contour sets do not have convexity automatically. For $g(u)=-u^2$ on $\mathbb R$, the ceiling $-1$ gives $(-\infty,-1]\cup[1,\infty)$. Its members $-1$ and $1$ have midpoint $0$, which fails the ceiling, so this lower set is not convex.
<!-- bilingual-en:end -->

[[凸集]]包含其任意两点之间的整条线段。在凸定义域上，要求每个门槛的下轮廓集都凸，才定义了[[拟凸函数|拟凸性]]；下轮廓集本身并不自动凸。对 $\mathbb R$ 上的 $g(u)=-u^2$，上限 $-1$ 给出 $(-\infty,-1]\cup[1,\infty)$；两个成员 $-1$、$1$ 的中点 $0$ 不满足上限，所以这个下轮廓集不凸。

> [!warning] Including equality does not prove closedness · 包含等号不等于已经证明闭性
> <!-- bilingual-en:start -->
> A weak inequality alone does not guarantee a [[闭集|closed set]]. On the real line, closedness requires each point outside the set to have a small open interval staying outside it. On $\mathbb R$, let $h(u)=0$ for $u>0$ and $h(u)=1$ for $u\le0$. Then $\{u:h(u)\le0\}=(0,\infty)$. The point $0$ is outside this set, but every open interval around $0$ contains positive members of it, so the set is not closed. The disk above is closed because of that particular function and domain, not because every sublevel definition contains $\le$.
> <!-- bilingual-en:end -->
>
> 仅有弱不等式，不能保证集合是[[闭集]]。在实数线上，闭性要求每个集合外的点都有一个完全留在外部的小开区间。在 $\mathbb R$ 上定义 $h(u)=0$（$u>0$）以及 $h(u)=1$（$u\le0$），则 $\{u:h(u)\le0\}=(0,\infty)$。$0$ 在该集合外，但它周围每个开区间都包含属于集合的正数，所以集合不闭。前面的圆盘是闭的，依赖那个具体函数与定义域，而非所有定义中出现 $\le$ 的集合都闭。
