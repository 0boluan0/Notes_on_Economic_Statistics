# 因子数应由残差、随机参照、模型假设、理论与复现共同决定
<!-- bilingual-en:start -->
*The number of factors should be chosen using residuals, random-data benchmarks, model assumptions, theory, and replication together*
<!-- bilingual-en:end -->

> [!summary] 怎样选择
> 因子数 $m$ 决定模型愿意用多少个潜在方向解释共同协方差。少取会把系统结构留在残差中，多取会追逐抽样噪声、制造弱因子和不稳定命名。没有一个适用于所有数据的单一阈值。
> <!-- bilingual-en:start -->
> Too few factors leave systematic covariance unexplained; too many can fit sampling noise and create unstable factors. No universal cutoff determines the correct dimension.
> <!-- bilingual-en:end -->

## 不同证据回答不同问题

- **碎石图**寻找特征值曲线由结构转为平缓尾部的位置，但拐点可能模糊，读图带有判断。
- **平行分析**把观测特征值与具有相同样本量和变量数的随机数据特征值比较，问某个方向是否超过纯随机参照。模拟方式应与所用相关矩阵和提取口径匹配。
- **残差相关与拟合指标**检查 $m$ 个因子能否重构重要的共同协方差；整体指标良好也不能掩盖局部大残差。
- **极大似然检验和信息准则**只在相应分布、识别与大样本近似可信时才有其标称解释；统计上拒绝一个小模型，也不自动说明多出的因子有实质意义。
- **理论、可解释性与复现**要求每个保留因子有足够指标支撑，并能在新样本、不同合理方法或预先规定的模型中重现。

“特征值大于 1”与固定累计解释率都可以作为描述性线索，但不应单独决定因子数。前者受变量数、样本量与相关结构影响；后者更接近 PCA 的总方差口径，而因子模型关心的是共同协方差。

样本量是否足以恢复这套结构是另一项判断，不能用固定的“每变量若干样本”规则替代；详见 [[因子分析样本量边界]]。

> [!question]- 自检
> 平行分析建议 3 个因子，但第三因子只有两个很小且不稳定的载荷。能否仅凭“通过平行分析”就给它命名？
>
> **答案：** 不能。随机参照只是一类证据；还要检查残差改善、指标支撑、理论意义与新样本复现。

## 来源与核验

- [Horn (1965), *A rationale and test for the number of factors in factor analysis*](https://doi.org/10.1007/BF02289447)：核对平行分析的随机特征值参照。
- [Fabrigar et al. (1999), *Evaluating the use of exploratory factor analysis in psychological research*](https://doi.org/10.1037/1082-989X.4.3.272)：核对因子保留、提取、旋转与解释应作为连贯决策。
- [[因子分析样本量边界]]：集中说明为什么结构恢复难度不能由固定样本—变量倍数决定。
