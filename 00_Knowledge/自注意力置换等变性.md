# 没有位置与顺序约束的自注意力会随 token 排列等变
<!-- bilingual-en:start -->
*Self-attention without positional or ordering constraints is permutation equivariant*
<!-- bilingual-en:end -->

把 token 向量按行放入 $X$。若 [[自注意力]] 没有位置编码、位置偏置或掩码，各位置共享相同投影参数，且暂不使用随机 dropout，那么对任意 [[置换矩阵]] $P$，都有

$$
\operatorname{SA}(PX)=P\operatorname{SA}(X).
$$

这叫**置换等变**：输入换行，输出跟着以同样方式换行；它没有说输出矩阵逐项不变。

<!-- bilingual-en:start -->
Place token vectors in the rows of $X$. If [[自注意力|self-attention]] has no positional encoding, positional bias, or mask, uses the same projection parameters at every position, and excludes random dropout, then the displayed identity holds for every [[置换矩阵|permutation matrix]] $P$. This is **permutation equivariance**: reordering inputs reorders outputs in the same way. It does not mean that the output matrix remains entrywise unchanged.
<!-- bilingual-en:end -->

由 $Q=XW_Q$、$K=XW_K$、$V=XW_V$，重排后得到 $Q'=PQ$、$K'=PK$、$V'=PV$。令 $S=QK^\top/\sqrt{d_k}$；逐行 [[Softmax]] 对行列重排满足

$$
S'=PSP^\top,
\qquad
\operatorname{softmax}(PSP^\top)
=P\operatorname{softmax}(S)P^\top.
$$

因此

$$
\operatorname{SA}(PX)
=P\operatorname{softmax}(S)P^\top PV
=P\operatorname{SA}(X).
$$

<!-- bilingual-en:start -->
The shared projections give $Q'=PQ$, $K'=PK$, and $V'=PV$. The score matrix is therefore permuted on both axes. Row-wise [[Softmax|softmax]] respects these row and column permutations: each row still normalizes the same scores, merely reordered. Multiplying by the reordered values and using $P^\top P=I$ proves the result.
<!-- bilingual-en:end -->

例如将三个输入行“猫、追、狗”换成“狗、追、猫”，上述运算给“猫”和“狗”的输出只会跟着换行，“追”的输出保持原值。单靠这次运算不能因谁站在左边或右边而区分角色。[[位置编码]] 能把这些位置差别引入计算。

<!-- bilingual-en:start -->
For three illustrative input rows “cat, chases, dog,” swapping them to “dog, chases, cat” merely moves the output associated with each noun; the output for “chases” stays the same. This operation alone cannot assign different roles based on which noun is on the left or right. [[位置编码|Positional encoding]] can introduce those distinctions.
<!-- bilingual-en:end -->

固定的 [[因果注意力掩码]] 已把左右顺序写入可见性，因而不满足这里的前提。类似地，重排 token 而保持各槽位的位置向量不动，也不再是对完整输入做同一个排列。不能把本命题扩大成“所有 Transformer 都不识别顺序”。

<!-- bilingual-en:start -->
A fixed [[因果注意力掩码|causal attention mask]] encodes order through visibility and violates the assumptions here. Likewise, reordering tokens while leaving positional vectors in their original slots does not permute the complete input representation. The result does not imply that all Transformers are insensitive to order.
<!-- bilingual-en:end -->

## 来源与核验
<!-- bilingual-en:start -->
*Sources and verification*
<!-- bilingual-en:end -->

- [Lee et al. (2019), *Set Transformer*](https://proceedings.mlr.press/v97/lee19d/lee19d.pdf)，§2.1 Definition 1、§3.1 Property 1：支持置换等变的定义与 self-attention block 的相应性质。本卡在单头点积形式下直接展示推导，并明确位置、掩码和随机性的适用条件。
- [Vaswani et al. (2017), *Attention Is All You Need*](https://arxiv.org/html/1706.03762v7)，§3.2.1 Eq. 1：提供展开证明所用的注意力公式。

<!-- bilingual-en:start -->
- Lee et al., §2.1 Definition 1 and §3.1 Property 1, defines permutation equivariance and establishes it for set self-attention blocks. This card derives the single-head case with explicit assumptions about positions, masks, and randomness.
- Vaswani et al., §3.2.1 Equation 1, supplies the attention equation used in the derivation.
<!-- bilingual-en:end -->
