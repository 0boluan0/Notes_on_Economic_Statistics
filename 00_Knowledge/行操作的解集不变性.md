# 对增广矩阵同步施行可逆行操作不改变线性方程组的解集
<!-- bilingual-en:start -->
*Synchronized invertible row operations on an augmented matrix preserve the solution set of the linear system*
<!-- bilingual-en:end -->

> [!summary] 核心结论
> 每个初等行操作都等于左乘一个可逆初等矩阵 $E$。若同一个操作同时作用于系数矩阵和右端，则
> $$
> Ax=b\iff(EA)x=Eb.
> $$
> 因此，对增广矩阵 $[A\mid b]$ 同步施行有限次可逆行操作，所得方程组与原方程组有完全相同的解集。
> <!-- bilingual-en:start -->
> An elementary row operation is left multiplication by an invertible matrix $E$. Thus $Ax=b$ and $(EA)x=Eb$ have exactly the same solutions, provided the same operation is applied to both blocks of the augmented matrix.
> <!-- bilingual-en:end -->

证明只需要可逆性。若 $x$ 满足 $Ax=b$，左乘 $E$ 得 $(EA)x=Eb$；反过来，若 $(EA)x=Eb$，再左乘 $E^{-1}$ 就恢复 $Ax=b$。一串行操作的乘积仍可逆，所以结论可逐步重复使用。

## 必须同步变换右端

若只把 $A$ 变成 $EA$，却仍把右端留成原来的 $b$，一般得到的是另一个方程组。保持解集的对象是整个增广矩阵 $[A\mid b]$。当 $b=0$ 时右端始终为零，于是行操作也保持齐次系统的零空间；四个基本子空间各自怎样变化，见[[行操作与四个子空间]]。

> [!question]- 自检
> 为什么把某一行乘以 $0$ 不能用于等价变形？
>
> **答案：** 这个操作不可逆；被抹掉的方程无法恢复，解集可能因此扩大。
