# Topological order 是依赖偏序的 linear extension 且未必唯一
<!-- bilingual-en:start -->
*A topological order is a generally nonunique linear extension of dependency order*
<!-- bilingual-en:end -->

> [!summary] 原子区分
> 对 DAG 定义 $u\prec v$ 当且仅当存在一条从 $u$ 到 $v$ 的**正长度** directed path；这个 positive-reachability 关系是严格偏序。topological order 选择一条与这些约束相容的全线性顺序，因此是这个偏序的一种 **linear extension**。它通常不是图中唯一合法的时间线。
> <!-- bilingual-en:start -->
> Define $u\prec v$ in a DAG when a **positive-length** directed path runs from $u$ to $v$. This positive-reachability relation is a strict partial order. A topological order chooses a total linear order consistent with those constraints, so it is a **linear extension** of the dependency order. It is generally not a unique timeline dictated by the graph.
> <!-- bilingual-en:end -->

若两个顶点互不可达，依赖关系没有规定谁先；finite poset 存在把任一者排在另一者前的 linear extensions。Kahn algorithm 在同时出现多个 sources 时选择不同 source，常会生成不同 topological orders。相反，“两点之间没有 direct edge”不等于不可比：若有 path $u\leadsto v$，所有 topological orders 仍必须把 $u$ 放在 $v$ 前。
<!-- bilingual-en:start -->
If two vertices are mutually unreachable, precedence does not fix their relative order, and finite linear extensions can place either first. Different source choices in Kahn's algorithm commonly produce different orders. By contrast, absence of a direct edge does not imply incomparability: a path $u\leadsto v$ forces $u$ before $v$ in every topological order.
<!-- bilingual-en:end -->

一个 topological order 只保证**顺序合法**，不自动给出最大并行度、最短工期或资源最优 schedule。把本来不可比的任务强行排成先后，是线性展示的需要，不是新增的依赖边。
<!-- bilingual-en:start -->
A topological order guarantees legality, not maximum parallelism, minimum makespan, or resource-optimal scheduling. Ordering incomparable tasks is required by the linear display; it does not add a dependency edge.
<!-- bilingual-en:end -->

> [!question]- 自检
> DAG 只有 edges $A\to C$ 与 $B\to C$。列出两个合法 topological orders，并说明 $A,B$ 的关系。
>
> **答案：**$A,B,C$ 与 $B,A,C$ 都合法；$A,B$ 互不可达，所以偏序不比较它们，线性扩张可任选相对次序。
