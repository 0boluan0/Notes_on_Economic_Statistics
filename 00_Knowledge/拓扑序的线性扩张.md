# Topological orders as linear extensions
<!-- bilingual-en:end -->

*拓扑序作为依赖偏序的线性扩张*

<!-- bilingual-en:start -->
A dependency graph may tell us that two preparations must both precede a final task without saying which preparation comes first. A topological order fills that gap by choosing one list. The list respects every dependency, but some of its comparisons are choices made for the display rather than requirements already present in the graph. This is the meaning of a **linear extension**.
<!-- bilingual-en:end -->

依赖图可以要求两项准备都先于最后任务，却不规定两项准备谁先做。拓扑序选择一个列表，把这个空缺补上。列表遵守全部依赖，但其中某些先后比较只是线性展示所作的选择，并非图中原来已有的要求。这就是**线性扩张**的含义。

<!-- bilingual-en:start -->
Work with a finite [[有向无环图|DAG]], and fix the arrow meaning as “must precede.” A [[拓扑序|topological order]] contains each vertex exactly once and places the tail of every arrow before its head. For example, if the only arrows are $A\to C$ and $B\to C$, both $(A,B,C)$ and $(B,A,C)$ are valid: $C$ must come last, while the graph leaves the order of $A,B$ open.
<!-- bilingual-en:end -->

考虑有限[[有向无环图|DAG]]，固定箭头的含义为“必须在先”。[[拓扑序]]包含每个顶点恰好一次，并把每条箭头的起点排在终点前。若只有 $A\to C$、$B\to C$，那么 $(A,B,C)$、$(B,A,C)$ 都合法：$C$ 必须最后，图却没有规定 $A,B$ 的先后。

<!-- bilingual-en:start -->
## From arrows to all implied precedence constraints
<!-- bilingual-en:end -->

*从直接箭头到全部隐含的先后要求*

<!-- bilingual-en:start -->
Write $u\prec v$ when there is a **positive-length** [[游走路径与环|directed path]] from $u$ to $v$. Here $\prec$ means “is forced to precede,” and a path may contain more than one edge. For $A\to B\to C$, we have $A\prec C$ even if there is no direct arrow $A\to C$. The relation records reachability through the graph, not merely its edge list.
<!-- bilingual-en:end -->

若从 $u$ 到 $v$ 存在一条**正长度**的[[游走路径与环|有向路径]]，就记 $u\prec v$。符号 $\prec$ 表示“被要求排在前面”，路径可以包含不止一条边。例如 $A\to B\to C$ 中，即使没有直接箭头 $A\to C$，仍有 $A\prec C$。这个关系记录的是沿图的可达性，不只是直接边表。

<!-- bilingual-en:start -->
A **strict partial order** is a relation that is irreflexive—no element precedes itself—and transitive—$u\prec v$ and $v\prec w$ imply $u\prec w$. The DAG relation has both properties. Indeed, a directed walk in a DAG cannot repeat a vertex: a shortest portion between repeated occurrences would be a directed cycle. Consequently, there is no positive-length return to the starting vertex. Concatenating a path from $u$ to $v$ with one from $v$ to $w$ gives a positive-length directed walk, which in a DAG has no repeated vertex and is therefore a path. This proves transitivity.
<!-- bilingual-en:end -->

**严格偏序**是同时满足反自反性和传递性的关系：没有元素先于自己；若 $u\prec v$ 且 $v\prec w$，则 $u\prec w$。DAG 的上述关系满足两者。事实上，DAG 中的有向游走不能重复顶点，否则选取重复出现之间最短的一段，就得到有向环。因此不可能正长度地回到起点。把 $u$ 到 $v$ 的路径与 $v$ 到 $w$ 的路径连接起来，得到正长度有向游走；在 DAG 中它不重复顶点，仍是路径，故传递性成立。

<!-- bilingual-en:start -->
The word “strict” excludes the length-zero path from $u$ to itself. If instead we define $u\preceq v$ to mean $u=v$ or $u\prec v$, we obtain the corresponding reflexive, or non-strict, partial order. Two distinct vertices are **incomparable** when neither reaches the other. Absence of a direct edge is not enough to make them incomparable, as $A\to B\to C$ shows.
<!-- bilingual-en:end -->

“严格”排除了从 $u$ 到自身的零长度路径。若另定义 $u\preceq v$ 表示 $u=v$ 或 $u\prec v$，便得到对应的自反、非严格偏序。两个不同顶点若互相都不可达，就称它们**不可比**。没有直接边并不足以判定不可比，$A\to B\to C$ 正是反例。

<!-- bilingual-en:start -->
## Why a topological order is exactly a linear extension
<!-- bilingual-en:end -->

*为什么拓扑序恰好是线性扩张*

<!-- bilingual-en:start -->
A strict **linear order**, also called a strict total order, is a strict partial order in which every pair of distinct vertices is comparable: exactly one of them comes first. A linear extension of $\prec$ is such an order that preserves every required comparison $u\prec v$. For a finite set, write the chosen linear order as a list and let $\operatorname{pos}(v)$ be the position of $v$. Preservation means
<!-- bilingual-en:end -->

严格**线性序**也叫严格全序，它是在严格偏序的基础上，要求任意两个不同顶点都可比，因而其中恰有一个在前。$\prec$ 的线性扩张就是这样一个线性序，同时保留原来全部 $u\prec v$ 的要求。有限集合上的线性序可以写成列表，用 $\operatorname{pos}(v)$ 表示顶点 $v$ 的位置；保留原关系就是

$$u\prec v\quad\Longrightarrow\quad\operatorname{pos}(u)<\operatorname{pos}(v).$$

<!-- bilingual-en:start -->
In a topological order, positions increase along each edge, so they increase along every directed path. Hence the displayed requirement holds. Conversely, in a DAG every edge is a one-edge path, so a list satisfying this requirement places every edge forward and is topological. Thus the two descriptions pick out exactly the same lists. A list's extra comparisons do not add edges to the original graph.
<!-- bilingual-en:end -->

拓扑序的位置沿每条边增加，因此也沿每条有向路径增加，满足上式。反过来，DAG 的每条边都是一步路径，所以满足上式的列表必让每条边朝前，是拓扑序。因此两种表述选出的恰好是同一批列表。列表额外作出的比较并不会给原图添加边。

<!-- bilingual-en:start -->
The [[DAG 与拓扑序等价|finite-DAG ordering theorem]] guarantees that at least one extension exists. To see why an incomparable pair $u,v$ can appear in either relative order, temporarily add the edge $u\to v$. A new cycle would have to use this edge and then follow an old path from $v$ back to $u$, which incomparability excludes. The enlarged graph is still a DAG, so it has a topological order with $u$ before $v$; that order also respects the original graph. Adding $v\to u$ instead gives an order with $v$ before $u$. These are two possible constructions, not permission to interchange arbitrary positions in an already chosen list.
<!-- bilingual-en:end -->

[[DAG 与拓扑序等价|有限 DAG 的拓扑序定理]]保证至少存在一种线性扩张。若 $u,v$ 不可比，要说明二者可以有任一相对次序，可临时加入边 $u\to v$。新产生的环必使用这条边，再沿原有路径从 $v$ 回到 $u$，但不可比排除了这种路径。加边后仍是 DAG，因此有一种把 $u$ 排在 $v$ 前的拓扑序，它也遵守原图。改为加入 $v\to u$，就得到另一种相对次序。这是分别构造两种合法列表，不能理解为可以在任意现有列表中直接对调两个位置。

> [!warning] Swap adjacent incomparable vertices · 交换相邻的不可比项
> <!-- bilingual-en:start -->
> In a valid topological list, **two adjacent incomparable vertices may be swapped**. Only their relative order changes; every third vertex stays before both or after both, and there is no precedence constraint between the swapped pair. For nonadjacent vertices this argument fails. With the single edge $a\to c$, the list $(a,c,b)$ is valid and $a,b$ are incomparable, but swapping their positions gives $(b,c,a)$, which violates $a\to c$. A different valid list, $(b,a,c)$, puts $b$ before $a$ without violating that edge.
> <!-- bilingual-en:end -->
>
> 在合法拓扑列表中，**相邻且不可比的两个顶点可以互换**。只有二者的相对顺序改变；任何第三个顶点仍在二者都前面或都后面，而这两个顶点之间又没有先后约束。不相邻时，这个论证失效：只有一条边 $a\to c$ 时，$(a,c,b)$ 合法，$a,b$ 也不可比；直接交换二者位置却得到 $(b,c,a)$，违反 $a\to c$。另一份合法列表 $(b,a,c)$ 才是在不违反该边的情况下让 $b$ 先于 $a$。

<!-- bilingual-en:start -->
The [[Kahn 拓扑排序与环证书|Kahn algorithm]] makes such choices when more than one remaining vertex has no incoming edge. Different first choices give different lists, with all remaining dependencies still checked. Nonuniqueness is possible, not compulsory: the chain $A\to B\to C$ forces $(A,B,C)$. A singleton has one order; under the empty-graph convention, the empty list is the unique empty order.
<!-- bilingual-en:end -->

[[Kahn 拓扑排序与环证书|Kahn 算法]]在剩余图中有多个入度为零顶点时作出这类选择。不同的下一项选择给出不同列表，但剩余依赖仍须全部检查。非唯一是可能性，不是必然：链 $A\to B\to C$ 只允许 $(A,B,C)$。单点图有一个顺序；允许空图时，空列表就是唯一的空顺序。

## A legal list is not a complete schedule
<!-- bilingual-en:end -->

*合法列表还不是完整调度*

<!-- bilingual-en:start -->
For $A\to C$ and $B\to C$, suppose every task lasts one time unit and two workers are available. Executing the list $(A,B,C)$ one task at a time takes three units; doing $A,B$ together and then $C$ takes two. Both respect the same dependencies. A topological order alone specifies neither these starting times nor the resources. Conclusions about [[DAG 关键路径与最短工期|minimum completion time]] need their own duration and processor assumptions; a linear display does not assert that incomparable tasks must run sequentially.
<!-- bilingual-en:end -->

仍取 $A\to C$、$B\to C$，设每项任务耗时一个单位，且有两名工作人员。按列表 $(A,B,C)$ 一项一项做，要三个单位；同时做 $A,B$ 再做 $C$，只要两个单位，两者都遵守相同依赖。拓扑序本身既没有指定这些开始时间，也没有规定资源。关于[[DAG 关键路径与最短工期|最短完成时间]]的结论需要另加时长与处理器前提；线性展示不表示不可比任务必须串行执行。
