# 绝对误差与相对误差分别衡量量级和比例偏差

<!-- bilingual-en:start -->
*Absolute and relative error measure magnitude and proportional deviation*
<!-- bilingual-en:end -->

> [!summary] 原子区分
> 若真值或参考值为 $x$，近似值为 $\hat x$，绝对误差是 $|\hat x-x|$；当 $x\ne0$ 时，相对误差是 $|\hat x-x|/|x|$。前者保留原量纲，回答“差了多少单位”；后者无量纲，回答“相对参考尺度差了多大比例”。
>
> <!-- bilingual-en:start -->
> For a true or reference value $x$ and approximation $\hat x$, absolute error is $|\hat x-x|$. When $x\ne0$, relative error is $|\hat x-x|/|x|$. Absolute error retains the original units and asks how many units the result differs; relative error is dimensionless and asks how large the difference is relative to the reference scale.
> <!-- bilingual-en:end -->

同样的绝对误差在不同尺度上意义不同：预测 1,000,000 时误差 1 通常很小，预测 $10^{-9}$ 时误差 1 则极大。反过来，接近零时相对误差会变得不稳定或无定义；此时必须使用有物理或业务含义的绝对尺度，例如仪器分辨率、残差单位或允许的最小金额。
<!-- bilingual-en:start -->
The same absolute error can mean very different things at different scales: an error of 1 may be tiny against 1,000,000 but enormous against $10^{-9}$. Conversely, relative error becomes unstable or undefined near zero. A meaningful absolute scale—such as instrument resolution, residual units, or a minimum monetary increment—is then required.
<!-- bilingual-en:end -->

“相对误差更科学”并不是通则。选择哪一种取决于问题规格：若误差预算随量值成比例变化，用相对误差；若误差预算由固定单位界定，用绝对误差；跨尺度且可能接近零时，常需组合二者。
<!-- bilingual-en:start -->
Relative error is not universally more scientific. The problem specification decides: use relative error when the error budget scales with magnitude, absolute error when it is fixed in domain units, and often a combination when values span scales and may approach zero.
<!-- bilingual-en:end -->

> [!question]- 回忆与应用
> 参考值为 0 时，为什么不能只报告相对误差？
>
> **答案：** 分母为 0，相对误差无定义；必须根据问题的单位与允许偏差报告绝对误差或其他有定义的尺度。
