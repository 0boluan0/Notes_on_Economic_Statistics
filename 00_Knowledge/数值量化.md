# 数值量化把数值映射为有限个离散等级

<!-- bilingual-en:start -->
*Numerical quantization maps values to a finite set of discrete levels*
<!-- bilingual-en:end -->

数值量化是把输入数值映射为有限个可表示等级的操作。在模型推理中，用较少位数编码这些等级，可以缩小权重或中间数值的表示，同时引入近似误差。以下具体使用**均匀仿射整数量化**：离散等级等距排列，整数码通过 scale 和 zero-point 对应到实数；这不是所有低精度数值格式的统一公式。

<!-- bilingual-en:start -->
Numerical quantization maps input values to a finite set of representable levels. Encoding those levels with fewer bits can reduce the representation size of model weights or intermediate values while introducing approximation error. The construction below uses **uniform affine integer quantization**, whose equally spaced real levels correspond to integer codes through a scale and zero-point. It is not a universal formula for every low-precision format.
<!-- bilingual-en:end -->

## 编码和反量化

<!-- bilingual-en:start -->
*Encoding and dequantization*
<!-- bilingual-en:end -->

设使用 $b$ 位无符号整数码 $q\in\{0,\ldots,2^b-1\}$。$s>0$ 是相邻实数等级的距离，整数 $z$ 是实数零所对应的码；这里要求 $z$ 在合法码范围内。round 表示取最近整数，clip 把超出范围的数截到端点。编码和反量化分别为

<!-- bilingual-en:start -->
Use a $b$-bit unsigned code $q\in\{0,\ldots,2^b-1\}$. The scale $s>0$ is the distance between adjacent real levels, and integer $z$ is the code for real zero; assume $z$ is within the valid code range. Round selects a nearest integer, and clip saturates values at the endpoints. Encoding and dequantization are
<!-- bilingual-en:end -->

$$
q=\operatorname{clip}\!\left(
\operatorname{round}(x/s)+z,\ 0,\ 2^b-1\right),
\qquad
\widehat x=s(q-z).
$$

因此可表示实数的两端是 $-sz$ 与 $s(2^b-1-z)$。反量化得到的是近似值 $\widehat x$，不能从一个码恢复所有曾被映射到它的原数。实际实现还必须规定恰好位于两个等级中点时如何取整；下面的例子不含平局。

<!-- bilingual-en:start -->
The representable real endpoints are $-sz$ and $s(2^b-1-z)$. Dequantization returns an approximation $\widehat x$; one code cannot recover all original values mapped to it. An implementation must also specify how rounding ties are resolved. The example below contains no ties.
<!-- bilingual-en:end -->

## 从四个实数逐步重建

<!-- bilingual-en:start -->
*Reconstructing four values step by step*
<!-- bilingual-en:end -->

取 $b=3$、$s=0.5$、$z=2$。合法码为 $0,\ldots,7$，实数范围为 $[-1,2.5]$。对输入向量逐元素操作：

<!-- bilingual-en:start -->
Take $b=3$, $s=0.5$, and $z=2$. Valid codes are $0,\ldots,7$, representing real values from $-1$ to $2.5$. Apply each operation element by element:
<!-- bilingual-en:end -->

$$
\begin{aligned}
x&=(-0.8,\ 0.2,\ 1.3,\ 2.9),\\
x/s&=(-1.6,\ 0.4,\ 2.6,\ 5.8),\\
\operatorname{round}(x/s)&=(-2,\ 0,\ 3,\ 6),\\
\operatorname{round}(x/s)+z&=(0,\ 2,\ 5,\ 8),\\
q&=(0,\ 2,\ 5,\ 7),\\
\widehat x&=(-1,\ 0,\ 1.5,\ 2.5).
\end{aligned}
$$

码 $2$ 在这里表示实数 $0$，并不表示实数 $2$。前三个数发生最近等级舍入，最后一个数还越过最大等级而被截断。两类误差的区别见[[量化舍入与截断]]。

<!-- bilingual-en:start -->
Code $2$ represents real zero here, not real two. The first three values undergo nearest-level rounding; the last also exceeds the largest level and is clipped. Their error tradeoff is explained in [[量化舍入与截断|rounding and clipping in quantization]].
<!-- bilingual-en:end -->

“3 bit”只说明此例每个元素的码宽。scale、zero-point、打包与对齐也可能占空间；哪些元素共用参数由[[量化粒度]]规定，哪些模型张量使用该表示由[[量化对象]]规定。

<!-- bilingual-en:start -->
“Three bits” specifies the code width per element in this example. Scales, zero-points, packing, and alignment can also occupy space. [[量化粒度|Quantization granularity]] specifies which elements share parameters, while [[量化对象|quantization targets]] specify which model tensors use the representation.
<!-- bilingual-en:end -->
