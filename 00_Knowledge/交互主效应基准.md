# 含交互项时，主效应系数只描述另一变量取基准值时的简单效应
<!-- bilingual-en:start -->
*With an interaction, a main-effect coefficient describes a simple effect only at the other variable's reference value*
<!-- bilingual-en:end -->

> [!summary] “主效应”不是全局平均效应
> 在
> $$
> m(X,D)=\beta_0+\beta_XX+\beta_DD+\beta_{XD}XD
> $$
> 中，$\beta_X$ 是 $D=0$ 基准组的 $X$ 斜率，$\beta_D$ 是 $X=0$ 时从 $D=0$ 到 $D=1$ 的组差。只要 $\beta_{XD}\neq0$，$X$ 的斜率或 $D$ 的组差就会随另一变量改变。
> <!-- bilingual-en:start -->
> In $m(X,D)=\beta_0+\beta_XX+\beta_DD+\beta_{XD}XD$, $\beta_X$ is the $X$ slope in the $D=0$ reference group, and $\beta_D$ is the group difference at $X=0$. When $\beta_{XD}\neq0$, neither is a global effect because the relevant slope or group difference changes with the other variable.
> <!-- bilingual-en:end -->

因此“$\beta_D$ 不显著”只说明模型在 $X=0$ 这一参考点没有排除零组差；它不能推出所有 $X$ 上都没有组差。同理，$\beta_X$ 不显著不能推出比较组的斜率 $\beta_X+\beta_{XD}$ 为零。正确问题要在实质相关的取值处写成目标对比。
<!-- bilingual-en:start -->
Thus an insignificant $\beta_D$ says only that the model does not exclude a zero group difference at the reference point $X=0$; it does not establish zero differences for all $X$. Likewise, an insignificant $\beta_X$ does not imply that the comparison-group slope $\beta_X+\beta_{XD}$ is zero. The scientific question must be written as a contrast at substantively relevant values.
<!-- bilingual-en:end -->

若 $X=0$ 没有意义或远离数据，可令 $X_c=X-c$，其中 $c$ 是有意义的政策点或支持良好的值。保留完整低阶项时，这只把 $\beta_D$ 的解释移到 $X=c$，不改变拟合值和同一实质对比。中心化能改善参照点，却不会创造缺失的共同支持，见[[中心化共线性边界]]。
<!-- bilingual-en:start -->
If $X=0$ is meaningless or far from the data, set $X_c=X-c$ at a meaningful and well-supported value. With the complete lower-order hierarchy retained, this moves the interpretation of $\beta_D$ to $X=c$ without changing fitted values or the same substantive contrast. Centring improves the reference point but cannot create missing common support; see [[中心化共线性边界|the centring boundary]].
<!-- bilingual-en:end -->

对两个类别变量，主效应同样依赖另一因子的基准层。更换基准组后单个系数和 $p$ 值可以改变，因为被检验的简单效应变了；完整单元格均值和事先定义的对比并未改变，见[[基准组重编码]]。
<!-- bilingual-en:start -->
With two categorical variables, each main effect likewise refers to the other factor's reference level. Releveling can change a coefficient and its p-value because the tested simple effect changed. Complete cell means and a prespecified contrast remain the same; see [[基准组重编码|reference-group reparameterisation]].
<!-- bilingual-en:end -->

> [!question]- 自检
> 模型含 `female × experience`，`female` 系数为零。能否说所有经验水平都没有组差？
>
> **答案：** 不能。该系数只给经验为 0 时的组差；任意 $x$ 处的组差是 $\beta_{female}+x\beta_{female\times experience}$。
