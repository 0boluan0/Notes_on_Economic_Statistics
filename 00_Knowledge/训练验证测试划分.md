# 训练数据拟合候选流程，验证数据作选择，测试数据只在选择结束后估计最终泛化表现
<!-- bilingual-en:start -->
*Training data fit candidate procedures, validation data select among them, and test data estimate final generalisation only after selection ends*
<!-- bilingual-en:end -->

> [!summary] 三种角色
> **训练集**估计模型参数和所有从数据学习的变换；**验证集**比较变量、模型族、超参数、阈值与其他设计选择；**测试集**在这些选择冻结后，估计被选中整条流程在未见数据上的表现。名称描述的是信息角色，而不只是文件夹名称。
> <!-- bilingual-en:start -->
> The **training set** estimates model parameters and every data-fitted transformation. The **validation set** compares variables, model families, hyperparameters, thresholds, and other design choices. The **test set** estimates the selected full procedure's performance on unseen data after those choices are frozen. These names denote informational roles, not merely file names.
> <!-- bilingual-en:end -->

## 为什么验证与测试必须分开
<!-- bilingual-en:start -->
*Why validation and test must be separated*
<!-- bilingual-en:end -->

若在验证集上试很多方案并选择最小误差，获胜误差也会受这批数据的偶然噪声影响。测试集的作用是评估“包括选择规则在内的最终流程”，而不是再进行一轮选择。看到 test 结果后修改变量、特征工程或参数，再把同一结果称为 final test，就发生了[[测试集自适应复用]]；这批数据已经转为 validation。

<!-- bilingual-en:start -->
When many candidates are tried on a validation set, the winning error also benefits from accidental noise in those observations. A test set evaluates the final procedure, including its selection rule; it does not provide another tuning round. If variables, feature engineering, or parameters are changed after inspecting test results, [[测试集自适应复用|adaptive test-set reuse]] has occurred and those data now play a validation role.
<!-- bilingual-en:end -->

“只用一次”不是说世界上永远只能运行一次程序，而是说当前 test 的反馈不能再影响仍用它评价的方案。若必须继续开发，应把这次结果标作验证反馈，并使用新的未来数据、未触碰 holdout 或外层重采样作下一次诚实验收。

三种角色也不强迫一次固定的三分割。样本有限时，可以在 training portion 内做 K 折验证或 nested cross-validation；时间序列可用连续历史窗、validation period 与 final test period。无论实现怎样，信息方向必须保持：评价观测不能反过来参与它所评价的拟合或选择。

<!-- bilingual-en:start -->
“Use once” means that feedback from the current test may not influence a procedure still evaluated on that test. Continued development should reclassify the result as validation feedback and use fresh future data, an untouched holdout, or outer resampling for the next honest assessment. The roles need not require one fixed three-way split: K-fold or nested cross-validation can operate within training data, and time series can use ordered training, validation, and final periods. What must remain is the direction of information flow.
<!-- bilingual-en:end -->

> [!question]- 自检
> 研究者查看 test RMSE 后删掉一个变量，再重新报告同一个 test 上更低的 RMSE。为什么第二个数字不是独立测试结果？
>
> **答案：** test 反馈已经决定了变量选择，所以它参与了开发；第二个模型需要新的未参与选择的数据才能获得独立验收。

## 来源与核验

- scikit-learn, [Cross-validation: evaluating estimator performance](https://scikit-learn.org/stable/modules/cross_validation.html)：核验训练、调参验证与最终测试的角色，以及反复按测试表现调参造成的信息泄漏。
- Cawley and Talbot（2010），[On Over-fitting in Model Selection and Subsequent Selection Bias in Performance Evaluation](https://jmlr.csail.mit.edu/papers/volume11/cawley10a/cawley10a.pdf)：核验模型选择本身会过拟合有限验证证据，最终性能评价必须把选择视为拟合流程的一部分。
