# 多查询注意力让多个查询头共享同一组键和值

<!-- bilingual-en:start -->
*Multi-query attention lets multiple query heads share one set of keys and values*
<!-- bilingual-en:end -->

多查询注意力（multi-query attention，MQA）是一种保留多个 query 头、让所有 query 头共享一组 K/V 投影的注意力结构。相对于每头具有独立 Q/K/V 投影的标准[[多头注意力]]，它在键和值的投影上引入跨头共享；不同 query 仍各自计算匹配权重和读出。

<!-- bilingual-en:start -->
Multi-query attention (MQA) retains multiple query heads while sharing one K/V projection pair across them. Relative to standard [[多头注意力|multi-head attention]], with separate Q/K/V projections for each head, it shares the key and value projections while each query still computes its own attention weights and readout.
<!-- bilingual-en:end -->

## 共享哪些张量

<!-- bilingual-en:start -->
*Which tensors are shared*
<!-- bilingual-en:end -->

省略 batch，以 token 为行。设 query 来源为 $X_Q\in\mathbb R^{n_q\times d_{\mathrm{model}}}$，key/value 来源为 $X_M\in\mathbb R^{n_k\times d_{\mathrm{model}}}$。有 $H_q$ 个 query 头，每头 query/key 宽度为 $d_k$、value 宽度为 $d_v$。MQA 的投影与读取为

<!-- bilingual-en:start -->
Omit the batch dimension and place tokens in rows. Let $X_Q\in\mathbb R^{n_q\times d_{\mathrm{model}}}$ supply queries and $X_M\in\mathbb R^{n_k\times d_{\mathrm{model}}}$ supply keys and values. There are $H_q$ query heads, each with query/key width $d_k$ and value width $d_v$. MQA projects and reads as follows:
<!-- bilingual-en:end -->

$$
Q_h=X_QW_h^Q,\qquad K=X_MW^K,\qquad V=X_MW^V,
$$
$$
\mathrm{head}_h=\operatorname{Attention}(Q_h,K,V),
\qquad h=1,\ldots,H_q.
$$

这里 $W_h^Q,W^K\in\mathbb R^{d_{\mathrm{model}}\times d_k}$，$W^V\in\mathbb R^{d_{\mathrm{model}}\times d_v}$；Attention 使用[[缩放点积注意力]]，并沿用模型要求的可见性掩码。各头输出仍各有 $n_q\times d_v$ 个元素，拼接后乘 $W^O\in\mathbb R^{H_qd_v\times d_{\mathrm{model}}}$。K/V 的共享没有取消各头独立的 Softmax。

<!-- bilingual-en:start -->
Here $W_h^Q,W^K\in\mathbb R^{d_{\mathrm{model}}\times d_k}$ and $W^V\in\mathbb R^{d_{\mathrm{model}}\times d_v}$. Attention means [[缩放点积注意力|scaled dot-product attention]], using the model's visibility mask. Each head still produces an $n_q\times d_v$ output; concatenation is followed by $W^O\in\mathbb R^{H_qd_v\times d_{\mathrm{model}}}$. Sharing K/V does not remove the separate Softmax computation for each head.
<!-- bilingual-en:end -->

## 同一组键值可以得到不同读出

<!-- bilingual-en:start -->
*Shared keys and values can produce different readouts*
<!-- bilingual-en:end -->

考虑投影后的一次读取，两个候选都可见，$d_k=d_v=1$。取共享的 $K=(0,1)^\top$、$V=(2,4)^\top$，两个 query 分别为 $q_1=0$、$q_2=\ln3$。第一个头的分数为 $(0,0)$，第二个为 $(0,\ln3)$，所以

<!-- bilingual-en:start -->
Consider one read after projection, with two visible candidates and $d_k=d_v=1$. Share $K=(0,1)^\top$ and $V=(2,4)^\top$, and take queries $q_1=0$ and $q_2=\ln3$. The first head has scores $(0,0)$, while the second has $(0,\ln3)$, giving
<!-- bilingual-en:end -->

$$
A_1=(1/2,1/2),\quad o_1=3;
\qquad
A_2=(1/4,3/4),\quad o_2=3.5.
$$

两个头共享 K/V，读出仍不同。若此小例再取 $W^O=I_2$，最终输出就是拼接行 $(3,3.5)$。这些数值用于重建运算，不代表实际模型的测量结果。

<!-- bilingual-en:start -->
The heads share K/V but return different readouts. If this example additionally uses $W^O=I_2$, the final output is the concatenated row $(3,3.5)$. These constructed values explain the computation; they are not model measurements.
<!-- bilingual-en:end -->

共享减少了需要保存的不同 K/V 头，但[[KV共享非等价改写|把已有独立头改成共享头一般会改变模型输出]]。希望保留多组 K/V 时，可使用[[分组查询注意力]]。

<!-- bilingual-en:start -->
Sharing reduces the number of distinct K/V heads to retain, but [[KV共享非等价改写|converting independent heads to shared heads generally changes model outputs]]. [[分组查询注意力|Grouped-query attention]] retains several K/V groups.
<!-- bilingual-en:end -->
