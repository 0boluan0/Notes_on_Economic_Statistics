# Python 的常见序列共享长度、索引、切片、迭代与成员测试接口
<!-- bilingual-en:start -->
*Common Python sequences share length, indexing, slicing, iteration, and membership-test operations*
<!-- bilingual-en:end -->

> [!summary] 原子接口
> **str**、**tuple** 与 **list** 都按位置组织有限元素，并支持 **len(s)**、整数索引、切片、从左到右迭代以及 **x in s**。共同接口说明“可以怎样读取”，并不保证对象具有相同的可变性、拼接结果类型或切片身份。

索引从 0 开始，负索引从末尾回数。切片 **s[start:stop:step]** 使用半开边界：包含 **start**，排除 **stop**；省略边界时由步长方向决定默认端点。半开区间使相邻切片 **s[:k]** 与 **s[k:]** 无重叠地拼回原序列的值。

~~~python
s = "abcd"
s[0]      # "a"
s[-1]     # "d"
s[1:3]    # "bc"
~~~

## 切片的值语义不承诺新身份

对 **list**，普通切片会创建新的外层列表，因此 **a[:] is a** 为 **False**；其中的元素引用仍然只是浅复制。共同序列接口却不承诺所有类型都产生新对象：不可变的 **tuple** 或 **str** 在完整切片时可以复用原对象。判断共享关系要看具体类型和操作文档，不能从 **[:]** 的写法推断身份。

> [!question]- 自检
> 为什么“支持切片”不能推出“可以对切片位置原地赋值”？
>
> **答案：** 切片读取属于序列接口；切片赋值只属于可变序列。字符串和元组能读取切片，却不能改写其槽位。
