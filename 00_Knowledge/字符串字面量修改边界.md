# 字符串字面量创建静态数组但任何修改尝试都是未定义行为
<!-- bilingual-en:start -->
*A string literal creates a static array, but any attempt to modify it has undefined behaviour*
<!-- bilingual-en:end -->

> [!summary] 两种初始化不是同一对象
> 在 C11 中，普通字符串字面量形成一个具有静态存储期、元素类型为 `char` 的数组，并自动追加数值为零的终止字节；但程序若试图修改这个字面量数组，行为未定义。`const char *view = "cat";` 保存的是指向字面量首元素的只读访问路径；`char copy[] = "cat";` 则创建另一个可修改数组并逐元素复制字面量。
> <!-- bilingual-en:start -->
> In C11, an ordinary string literal forms an array of `char` with static storage duration and an appended zero byte, but any attempt to modify that literal array has undefined behaviour. `const char *view = "cat";` points at the literal; `char copy[] = "cat";` creates a separate modifiable array initialised from it.
> <!-- bilingual-en:end -->

```c
void literal_copy_example(void) {
    const char *view = "cat";
    char copy[] = "cat";

    copy[0] = 'b';     // 有定义：copy 变成 "bat"
    (void) view;
    (void) copy;
    // view[0] = 'b';  // 若取消注释：约束违反，const 路径不允许写
}
```

历史上的 C 允许写 `char *p = "cat";`，因为字面量数组的元素类型并未写成 `const char`；这不代表 `p[0] = 'b'` 可用，修改尝试仍是未定义行为。用 `const char *` 能让编译器在常见写法处直接阻止误写，并把接口意图说清。
<!-- bilingual-en:start -->
Historical C permits `char *p = "cat";` because the literal array is not typed as `const char[]`; that does not make `p[0] = 'b'` valid. Using `const char *` lets the type system block ordinary accidental writes and communicates the intended access.
<!-- bilingual-en:end -->

字面量数组是否与另一处相同文本共用存储由实现决定，所以不能靠 `"cat" == "cat"` 判断文本内容，也不能向 `free` 传入字面量地址：它不是由内存管理函数返回的分配。比较内容用 `strcmp`；需要独立、可修改且由调用者管理的副本时，必须另建数组或执行深拷贝。
<!-- bilingual-en:start -->
The implementation may merge identical literal arrays, so `"cat" == "cat"` is not a content comparison. A literal address must not be passed to `free`, because it was not returned by an allocation function. Use `strcmp` for content and create a separate array or deep copy when modifiable owned storage is required.
<!-- bilingual-en:end -->

字面量中可以显式嵌入 `\0`。`"a\0b"` 的数组仍包含 `a`、零、`b` 和最后追加的零，但从首元素开始的 C 字符串只到第一个零；字面量数组的总大小与字符串长度因此可能不止差 1。
<!-- bilingual-en:start -->
A literal may contain an embedded `\0`. The array for `"a\0b"` contains `a`, zero, `b`, and the appended final zero, but the C string beginning at its first element ends at the first zero. Array size and string length can therefore differ by more than one.
<!-- bilingual-en:end -->

> [!question]- 最小自检
> `const char *p = "hi";` 与 `char a[] = "hi";` 的存储和可修改性有何不同？
>
> **答案：** `p` 指向静态字面量数组，不能修改也不能释放；`a` 是自己的三元素数组副本，`a[0]`、`a[1]` 可修改。
