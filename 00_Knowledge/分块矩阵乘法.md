# Block matrix multiplication
<!-- bilingual-en:end -->
*分块矩阵乘法*

<!-- bilingual-en:start -->
A **block** is a rectangular group of entries inside a matrix. Drawing cuts between rows or columns lets us organize [[矩阵乘法|ordinary matrix multiplication]] into products of these smaller matrices. The answer is the same as multiplying all entries at once. The useful rule is still “row times column”, but now each object in that calculation is a whole block.
<!-- bilingual-en:end -->

**块**是矩阵内部一组排成矩形的元素。在行或列之间画分割线，就能把[[矩阵乘法|普通矩阵乘法]]整理成这些小矩阵之间的乘法。结果与逐元素直接计算完全相同。规则仍然是“行乘列”，只不过参与计算的每个对象现在是一整个块。

> [!example] Split the shared dimension as 1 + 2 · 把共同维度切成 1 + 2
> <!-- bilingual-en:start -->
> A $2\times3$ matrix can multiply a $3\times2$ matrix. Cut the three columns of $A$ after its first column, and cut the three rows of $B$ after its first row:
> <!-- bilingual-en:end -->
>
> 一个 $2\times3$ 矩阵可以乘一个 $3\times2$ 矩阵。把 $A$ 的三列在第一列后切开，同时把 $B$ 的三行在第一行后切开：
>
> $$A=\left[\begin{array}{c|cc}1&2&3\\4&5&6\end{array}\right]
> =[\,A_1\mid A_2\,],\qquad
> B=\left[\begin{array}{cc}7&8\\\hline 9&10\\11&12\end{array}\right]
> =\begin{bmatrix}B_1\\B_2\end{bmatrix}.$$
>
> <!-- bilingual-en:start -->
> $A_1$ has size $2\times1$ and $B_1$ has size $1\times2$; $A_2$ has size $2\times2$ and $B_2$ has size $2\times2$. The inner sizes match pair by pair. Both block products therefore have size $2\times2$, so we can add them:
> <!-- bilingual-en:end -->
>
> $A_1$ 是 $2\times1$，$B_1$ 是 $1\times2$；$A_2$ 是 $2\times2$，$B_2$ 也是 $2\times2$。配对相乘时，内侧尺寸分别相符。两个块乘积都为 $2\times2$，因此可以相加：
>
> $$AB=A_1B_1+A_2B_2
> =\begin{pmatrix}7&8\\28&32\end{pmatrix}
> +\begin{pmatrix}51&56\\111&122\end{pmatrix}
> =\begin{pmatrix}58&64\\139&154\end{pmatrix}.$$
>
> <!-- bilingual-en:start -->
> For the upper-left entry, this groups $1\cdot7+2\cdot9+3\cdot11$ as $7+(18+33)=58$. The cut only groups terms in the original sum; it adds or removes none.
> <!-- bilingual-en:end -->
>
> 对左上角，这只是把 $1\cdot7+2\cdot9+3\cdot11$ 分成 $7+(18+33)=58$。分块只改变原来求和中各项的分组，没有增减任何一项。

<!-- bilingual-en:start -->
## Match every inner cut, not just the total size
<!-- bilingual-en:end -->
*不只总尺寸相同，每一道内侧分割也要匹配*

<!-- bilingual-en:start -->
Suppose block row $i$ of $A$ has height $m_i$, block column $k$ of $A$ has width $n_k$, and block column $j$ of $B$ has width $p_j$. To pair the blocks, block row $k$ of $B$ must have height $n_k$. Thus
<!-- bilingual-en:end -->

设 $A$ 的第 $i$ 个块行高为 $m_i$，第 $k$ 个块列宽为 $n_k$，而 $B$ 的第 $j$ 个块列宽为 $p_j$。为了配对相乘，$B$ 的第 $k$ 个块行高必须也是 $n_k$。因此

$$A_{ik}:m_i\times n_k,\qquad B_{kj}:n_k\times p_j.$$

<!-- bilingual-en:start -->
Here $i,j,k$ label blocks, not individual entries. Each product $A_{ik}B_{kj}$ has the same outer size $m_i\times p_j$, regardless of $k$. Summing over all shared block groups gives the output block in position $(i,j)$:
<!-- bilingual-en:end -->

这里 $i,j,k$ 标记的是块，不是单个元素。无论 $k$ 取哪一组，乘积 $A_{ik}B_{kj}$ 的外侧尺寸都是 $m_i\times p_j$。把所有共同块组的贡献相加，就得到结果的第 $(i,j)$ 块：

$$(AB)_{ij}=\sum_{k=1}^{q}A_{ik}B_{kj},$$

<!-- bilingual-en:start -->
where $q$ is the number of column blocks of $A$, also the number of row blocks of $B$. The blocks may be rectangular and unequal in size, as the example shows. Entries may be real or complex.
<!-- bilingual-en:end -->

其中 $q$ 是 $A$ 的块列数，也等于 $B$ 的块行数。如上例所示，各块可以是矩形，大小也可以不相等；元素可以是实数或复数。

> [!warning] A valid whole product can have incompatible cuts · 整体可乘，切法却未必相容
> <!-- bilingual-en:start -->
> If $A$ is cut into column widths $1+2$ but $B$ into row heights $2+1$, the whole $2\times3$ by $3\times2$ product still exists. However, its first proposed block pair would be $2\times1$ times $2\times2$, which is undefined. Redraw the cuts so the paired inner sizes agree; the total inner size $3$ alone is not enough for that block layout.
> <!-- bilingual-en:end -->
>
> 如果 $A$ 按列宽 $1+2$ 切，而 $B$ 按行高 $2+1$ 切，整个 $2\times3$ 乘 $3\times2$ 仍然有定义。但第一对拟相乘的块会变成 $2\times1$ 乘 $2\times2$，无法相乘。必须重新分割，使每一对块的内侧尺寸相同；仅仅总内侧尺寸都为 $3$，不足以保证这种分块写法成立。

## The familiar two-by-two block layout
<!-- bilingual-en:end -->
*常见的两行两列分块布局*

<!-- bilingual-en:start -->
If both matrices are cut into two block rows and two block columns with matching inner cuts, the same rule becomes
<!-- bilingual-en:end -->

若两个矩阵都切成两个块行、两个块列，并且内侧分割匹配，同一规则就写成

$$\begin{pmatrix}A_{11}&A_{12}\\A_{21}&A_{22}\end{pmatrix}
\begin{pmatrix}B_{11}&B_{12}\\B_{21}&B_{22}\end{pmatrix}
=\begin{pmatrix}
A_{11}B_{11}+A_{12}B_{21}&A_{11}B_{12}+A_{12}B_{22}\\
A_{21}B_{11}+A_{22}B_{21}&A_{21}B_{12}+A_{22}B_{22}
\end{pmatrix}.$$

<!-- bilingual-en:start -->
For example, the top-right block pairs the first block row of $A$ with the second block column of $B$. Every term keeps $A$'s block on the left and $B$'s on the right: blocks are themselves matrices, so their order cannot generally be exchanged. The proof is the same grouping of a finite shared-index sum used in the numerical example, applied to every entry of every output block.
<!-- bilingual-en:end -->

例如右上块配对的是 $A$ 的第一个块行和 $B$ 的第二个块列。每一项都把 $A$ 的块放左边、$B$ 的块放右边；块本身仍是矩阵，通常不能交换顺序。一般证明与数值例子相同：把普通元素公式中共同指标的有限求和分组，并对每个输出块内的每个元素这样处理。
