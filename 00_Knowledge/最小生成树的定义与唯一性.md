# 最小生成树最小化 spanning tree 总权重但解未必唯一
<!-- bilingual-en:start -->
*A minimum spanning tree minimizes total spanning-tree weight but need not be unique*
<!-- bilingual-en:end -->

> [!summary] 原子定义
> 设 $G=(V,E)$ 是 finite connected weighted undirected graph。对 spanning tree $T$，定义
> $$w(T)=\sum_{e\in E(T)}w(e).$$
> **minimum spanning tree（MST）** 是使 $w(T)$ 达到最小的 spanning tree。finite connected graph 的 spanning trees 是非空有限集，所以至少有一个 MST，但可能有多个。
> <!-- bilingual-en:start -->
> Let $G=(V,E)$ be a finite connected weighted undirected graph. The weight of a spanning tree is $w(T)=\sum_{e\in E(T)}w(e)$. A **minimum spanning tree (MST)** minimizes this total. The set of spanning trees is finite and nonempty, so an MST exists, but it need not be unique.
> <!-- bilingual-en:end -->

MST 优化的是整棵 tree 的边权总和，不是从某个根到其他点的 path weights，也不是让每条被选边分别最小。cut/exchange 论证之所以必要，正是因为局部选边必须证明能扩展为一个全局最优 spanning tree。
<!-- bilingual-en:start -->
An MST minimizes the total weight of the whole tree, not root-to-vertex path weights and not each chosen edge separately. Cut and exchange arguments are needed to prove that a local edge choice can extend to a globally optimal spanning tree.
<!-- bilingual-en:end -->

所有 edge weights 互异是 MST 唯一的**充分条件**，不是必要条件。triangle 的权重为 $1,1,2$ 时虽然有并列，唯一 MST 仍由两条权重 $1$ 的边组成；三条边都为 $1$ 时才有三棵等权 MST。仅看到 tie 不能宣布“不唯一”，必须实际给出另一棵同权 spanning tree 或相应交换。
<!-- bilingual-en:start -->
Distinct edge weights are sufficient, not necessary, for uniqueness. A triangle weighted $1,1,2$ has a unique MST despite a tie; a triangle weighted $1,1,1$ has three. A tie alone does not prove nonuniqueness.
<!-- bilingual-en:end -->

若原图 disconnected，就不存在 spanning tree，因而这里的 MST 问题没有可行解；可以另求每个 component 的 minimum spanning forest，但那是扩展后的问题。
<!-- bilingual-en:start -->
A disconnected graph has no spanning tree, so this MST problem has no feasible solution. One may instead define a minimum spanning forest component by component, but that is an extended problem.
<!-- bilingual-en:end -->

> [!question]- 自检
> 两棵 spanning trees 的每条边都各有优劣，应该比较什么量来判断哪棵是 MST？
>
> **答案：**比较各自全部被选边的权重总和 $w(T)$；不能逐边配对，也不能只比较最大或最小那一条边。
