# 有限极限可用唯一点值补成连续
<!-- bilingual-en:start -->
*A finite limit determines the unique continuous extension*
<!-- bilingual-en:end -->

> [!summary] 原子命题
> 若有限双侧极限 $\lim_{x\to a}f(x)=L$ 存在，则令 $f(a)=L$ 可使函数在 $a$ 连续，而且 $L$ 是唯一能实现连续的点值。
> <!-- bilingual-en:start -->
> If the finite two-sided limit $\lim_{x\to a}f(x)=L$ exists, defining $f(a)=L$ makes the function continuous at $a$, and $L$ is the only point value that can do so.
> <!-- bilingual-en:end -->

## 边界
<!-- bilingual-en:start -->
*Boundary condition*
<!-- bilingual-en:end -->

本库把“原先未定义”和“原先点值不等于极限”都视为可去间断；两者都可通过把点值改为 $L$ 修复。
<!-- bilingual-en:start -->
This vault treats both an undefined point and a point value unequal to the limit as removable discontinuities; both are repaired by setting the point value to $L$.
<!-- bilingual-en:end -->

## 最小例子
<!-- bilingual-en:start -->
*Minimal example*
<!-- bilingual-en:end -->

$f(x)=(x^2-1)/(x-1)$ 在 $x=1$ 的极限为 $2$。定义 $f(1)=2$ 后，它在 $1$ 连续；任何其他点值都不行。
<!-- bilingual-en:start -->
For $f(x)=(x^2-1)/(x-1)$, the limit at $x=1$ is $2$. Defining $f(1)=2$ makes the function continuous there; no other point value works.
<!-- bilingual-en:end -->

> [!question]- 自检
> 若 $\lim_{x\to a}f(x)=L\in\mathbb R$，应把 $f(a)$ 定义为什么才能补成连续？有几种选择？
> <!-- bilingual-en:start -->
> If $\lim_{x\to a}f(x)=L\in\mathbb R$, how must $f(a)$ be defined to obtain continuity, and how many choices are there?
> <!-- bilingual-en:end -->
>
> **答案：** 必须且只能定义为 $f(a)=L$。
> <!-- bilingual-en:start -->
> **Answer:** It must be defined as $f(a)=L$, and that choice is unique.
> <!-- bilingual-en:end -->
