# Changing the bases of a linear map
<!-- bilingual-en:end -->
*一般线性映射的换基*

<!-- bilingual-en:start -->
A linear map can keep doing exactly the same thing while we change how its inputs and outputs are described. To find its new matrix, first translate the new input coordinates into the old ones, apply the old matrix, then translate the output back into the new output coordinates. Input and output may belong to different spaces, so these two translations need not use the same matrix.
<!-- bilingual-en:end -->

线性映射的实际作用可以完全不变，而输入、输出的描述方式发生改变。要找新矩阵，就先把新输入坐标译成旧输入坐标，使用旧矩阵，再把结果译成新输出坐标。输入、输出可以属于不同空间，所以两端的转换未必要用同一张矩阵。

<!-- bilingual-en:start -->
For instance, the rule $T(a,b)=(a+b,b,a-b)$ takes two input coefficients to three output coefficients in standard coordinates. Its matrix is $3\times2$. A new input basis needs a $2\times2$ conversion, while a new output basis needs a $3\times3$ conversion. We will calculate this example after fixing the directions of those conversions.
<!-- bilingual-en:end -->

例如，规则 $T(a,b)=(a+b,b,a-b)$ 在标准坐标中把两个输入系数送到三个输出系数，矩阵为 $3\times2$。改变输入基需要 $2\times2$ 转换，改变输出基则需要 $3\times3$ 转换。下面先确定两端方向，再把这个例子算完。

<!-- bilingual-en:start -->
## Read the columns before using an inverse
<!-- bilingual-en:end -->
*先读列的含义，再决定哪里用逆*

<!-- bilingual-en:start -->
Let $T:V\to W$ be a [[线性映射|linear map]] between finite-dimensional [[向量空间|vector spaces]] over the same field $\mathbb F$. The input dimension is $n$ and the output dimension is $m$. Choose old ordered [[基|bases]] $\mathcal B=(v_1,\ldots,v_n)$ and $\mathcal C=(w_1,\ldots,w_m)$, and new ordered bases $\mathcal B'=(v'_1,\ldots,v'_n)$ and $\mathcal C'=(w'_1,\ldots,w'_m)$. Set
<!-- bilingual-en:end -->

设 $T:V\to W$ 是同一域 $\mathbb F$ 上有限维[[向量空间]]之间的[[线性映射]]。输入维数为 $n$，输出维数为 $m$。旧有序[[基]]为 $\mathcal B=(v_1,\ldots,v_n)$、$\mathcal C=(w_1,\ldots,w_m)$，新有序基为 $\mathcal B'=(v'_1,\ldots,v'_n)$、$\mathcal C'=(w'_1,\ldots,w'_m)$。记

$$A=[T]_{\mathcal C\leftarrow\mathcal B},\qquad
P=\bigl([v'_1]_{\mathcal B}\ \cdots\ [v'_n]_{\mathcal B}\bigr),\qquad
Q=\bigl([w'_1]_{\mathcal C}\ \cdots\ [w'_m]_{\mathcal C}\bigr).$$

<!-- bilingual-en:start -->
The bracket $[x]_{\mathcal B}$ is the coefficient column of $x$ in $\mathcal B$; $A$ is its [[线性映射与矩阵表示|representing matrix]], with $[T(x)]_{\mathcal C}=A[x]_{\mathcal B}$. The columns of $P$ are **new input basis vectors in old input coordinates**; those of $Q$ use the same convention on the output side. By the [[换基矩阵的方向|coordinate-conversion rule]],
<!-- bilingual-en:end -->

$[x]_{\mathcal B}$ 表示 $x$ 在 $\mathcal B$ 下的系数列；$A$ 是相应[[线性映射与矩阵表示|表示矩阵]]，满足 $[T(x)]_{\mathcal C}=A[x]_{\mathcal B}$。$P$ 的列是**新输入基向量的旧输入坐标**；$Q$ 在输出端采用同样约定。由[[换基矩阵的方向|坐标转换规则]]，

$$[x]_{\mathcal B}=P[x]_{\mathcal B'},\qquad
[y]_{\mathcal C}=Q[y]_{\mathcal C'}.$$

<!-- bilingual-en:start -->
Both $P$ and $Q$ are invertible: coordinates in either basis describe every vector uniquely, so translating back reverses the translation. The [[逆矩阵|inverse]] $Q^{-1}$ therefore converts old output coordinates to new output coordinates. It is $Q^{-1}$, rather than $Q$, that we need after applying $A$.
<!-- bilingual-en:end -->

$P,Q$ 都可逆，因为两套基坐标都能唯一描述每个向量，反向转换会撤销原转换。因此，[[逆矩阵]] $Q^{-1}$ 把旧输出坐标变成新输出坐标。应用 $A$ 之后，需要的正是 $Q^{-1}$，而不是 $Q$。

> [!important] Follow the three-step path · 沿三步路径读公式
> $$[x]_{\mathcal B'}\xrightarrow{\ P\ }[x]_{\mathcal B}
> \xrightarrow{\ A\ }[T(x)]_{\mathcal C}
> \xrightarrow{\ Q^{-1}\ }[T(x)]_{\mathcal C'},
> \qquad
> A'=[T]_{\mathcal C'\leftarrow\mathcal B'}=Q^{-1}AP.$$
>
> <!-- bilingual-en:start -->
> The prime on $A'$ names the new matrix; it is not a derivative. The sizes are $P:n\times n$, $A:m\times n$, and $Q:m\times m$, so $A'$ remains $m\times n$. The original map $T$ need not be invertible, and $A$ need not be square.
> <!-- bilingual-en:end -->
>
> $A'$ 的撇号表示新矩阵，不是求导。尺寸依次为 $P:n\times n$、$A:m\times n$、$Q:m\times m$，所以 $A'$ 仍为 $m\times n$。原映射 $T$ 不必可逆，$A$ 也不必是方阵。

<!-- bilingual-en:start -->
This path is also a proof: for every $x$, substitute $[x]_{\mathcal B}=P[x]_{\mathcal B'}$ into the old representation, then multiply its output coordinates by $Q^{-1}$. The result holds for every new input coordinate column, so [[表示矩阵的列|uniqueness of the matrix representation]] gives $A'=Q^{-1}AP$. Equivalently, this is [[复合映射的表示矩阵|composition of three coordinate maps]] with matching bases at each join.
<!-- bilingual-en:end -->

这条路径本身就是证明：对每个 $x$，把 $[x]_{\mathcal B}=P[x]_{\mathcal B'}$ 代入旧表示，再在输出坐标左侧乘 $Q^{-1}$。结果对每个新输入坐标列成立，因此由[[表示矩阵的列|表示矩阵的唯一性]]，得到 $A'=Q^{-1}AP$。也可以把它读成[[复合映射的表示矩阵|三个坐标映射的复合]]，每个连接处的基都恰好匹配。

<!-- bilingual-en:start -->
## A rectangular example, decoded at both ends
<!-- bilingual-en:end -->
*两端都还原检查的矩形例子*

<!-- bilingual-en:start -->
Return to $T:\mathbb R^2\to\mathbb R^3$, $T(a,b)=(a+b,b,a-b)$, with old standard bases. Choose new input basis $((1,0),(1,1))$ and new output basis $((1,0,0),(1,1,0),(0,0,1))$. Placing their old coordinates in columns gives
<!-- bilingual-en:end -->

回到 $T:\mathbb R^2\to\mathbb R^3$，$T(a,b)=(a+b,b,a-b)$，旧基均为标准基。选新输入基 $((1,0),(1,1))$，新输出基 $((1,0,0),(1,1,0),(0,0,1))$。把它们的旧坐标排成列，得到

$$A=\begin{pmatrix}1&1\\0&1\\1&-1\end{pmatrix},\quad
P=\begin{pmatrix}1&1\\0&1\end{pmatrix},\quad
Q=\begin{pmatrix}1&1&0\\0&1&0\\0&0&1\end{pmatrix},\quad
Q^{-1}=\begin{pmatrix}1&-1&0\\0&1&0\\0&0&1\end{pmatrix}.$$

$$AP=\begin{pmatrix}1&2\\0&1\\1&0\end{pmatrix},\qquad
A'=Q^{-1}AP=\begin{pmatrix}1&1\\0&1\\1&0\end{pmatrix}.$$

<!-- bilingual-en:start -->
Take new input coordinates $(1,2)^T$, where superscript $T$ denotes [[矩阵转置|transpose]] and turns the listed row into a column. They describe the actual vector $1(1,0)+2(1,1)=(3,2)$, not $(1,2)$ in standard coordinates. The map sends $(3,2)$ to $(5,2,1)$. The new matrix gives
<!-- bilingual-en:end -->

取新输入坐标 $(1,2)^T$，其中上标 $T$ 表示[[矩阵转置|转置]]，把所列的一行变成一列。它描述的实际向量是 $1(1,0)+2(1,1)=(3,2)$，不是标准坐标中的 $(1,2)$。映射把 $(3,2)$ 送到 $(5,2,1)$，而新矩阵给出

$$A'\begin{pmatrix}1\\2\end{pmatrix}=\begin{pmatrix}3\\2\\1\end{pmatrix}.$$

<!-- bilingual-en:start -->
Decode these **new output coordinates**: $3(1,0,0)+2(1,1,0)+1(0,0,1)=(5,2,1)$. Thus the new matrix describes exactly the same output. Each column can be checked in the same way by applying $T$ to the corresponding new input basis vector.
<!-- bilingual-en:end -->

把这些**新输出坐标**还原：$3(1,0,0)+2(1,1,0)+1(0,0,1)=(5,2,1)$。因此，新矩阵描述的确实是同一个输出。也可以逐列检查：把 $T$ 应用于相应的新输入基向量，再求其新输出坐标。

## One-sided changes and the similarity special case
<!-- bilingual-en:end -->
*只改一端，以及相似变换的特例*

<!-- bilingual-en:start -->
If only the input basis changes, then $Q=I_m$ and the new matrix is $AP$. If only the output basis changes, then $P=I_n$ and it is $Q^{-1}A$. Here $I_k$ is the $k\times k$ [[单位矩阵|identity matrix]]. These simplifications follow from the coordinate meanings, not from memorizing that “a change of basis uses an inverse.”
<!-- bilingual-en:end -->

若只改输入基，则 $Q=I_m$，新矩阵为 $AP$；若只改输出基，则 $P=I_n$，新矩阵为 $Q^{-1}A$。其中 $I_k$ 是 $k\times k$ 的[[单位矩阵]]。这些化简来自坐标的含义，不是靠背诵“换基要乘逆矩阵”。

<!-- bilingual-en:start -->
For an operator $T:V\to V$, suppose the old input and output use the same basis, and the new input and output also use the same basis. Then $P=Q$, and the formula becomes the [[相似矩阵|similarity]] $A'=P^{-1}AP$. Independent input/output changes need not be a similarity and need not preserve the numerical matrix's [[特征对|eigenvalues]] (multipliers of nonzero eigenvectors) or [[迹与特征值总和|trace]] (the sum of diagonal entries). For example, take $A=I_2$, $P=\begin{pmatrix}2&0\\0&1\end{pmatrix}$ and $Q=I_2$. Then $A'=P$, whose eigenvalues are $2,1$ and trace is $3$, whereas $I_2$ has eigenvalues $1,1$ and trace $2$. The abstract identity map is unchanged; its input and output coordinate conventions now differ.
<!-- bilingual-en:end -->

对算子 $T:V\to V$，若旧输入、输出使用同一组基，新输入、输出也使用同一组基，就有 $P=Q$，公式化为[[相似矩阵|相似变换]] $A'=P^{-1}AP$。两端独立换基一般不是相似变换，也不保证数值矩阵的[[特征对|特征值]]（非零特征向量的倍数）或[[迹与特征值总和|迹]]（对角元之和）保持。例如，取 $A=I_2$、$P=\begin{pmatrix}2&0\\0&1\end{pmatrix}$、$Q=I_2$，则 $A'=P$，特征值为 $2,1$、迹为 $3$；$I_2$ 的特征值却为 $1,1$、迹为 $2$。抽象恒等映射没有改变，改变的是输入与输出使用了不同坐标约定。

<!-- bilingual-en:start -->
Conversely, any invertible $n\times n$ matrix $P$ can be read as new input basis vectors in the old input coordinates, and any invertible $m\times m$ matrix $Q$ can do the same on the output side. Its columns are [[线性无关|linearly independent]] and [[张成|span]] the coordinate space, so they really specify a basis. Thus arbitrary invertible left and right factors can be interpreted as **some** two-sided change of coordinates. For prescribed new bases, however, the factors must match those bases and the stated directions; the algebraic shape alone does not verify that match. [[对角化与行化简|Row reduction and diagonalization]] distinguish other uses of left multiplication from synchronized change of basis.
<!-- bilingual-en:end -->

反过来，任意可逆 $n\times n$ 矩阵 $P$ 都可以解释为新输入基向量的旧输入坐标；任意可逆 $m\times m$ 矩阵 $Q$ 在输出端同样如此。它们的列[[线性无关]]并[[张成]]坐标空间，所以确实指定了一组基。因此，任意可逆左右因子都能解释为**某种**双边坐标变换。但若新基已指定，因子就必须与这些基及约定方向相符；单看代数形状不能验证这种匹配。[[对角化与行化简]]进一步区分左乘的其他用途与两端同步换基。
