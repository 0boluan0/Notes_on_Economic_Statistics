# Division rule of counting
<!-- bilingual-en:end -->

*除法法则*

<!-- bilingual-en:start -->
Choose an unordered pair from Ana, Ben and Cara. Writing the selected names in order gives six descriptions, but only three pairs:
<!-- bilingual-en:end -->

从 Ana、Ben、Cara 中选一个无序二人组。按顺序写名字会得到六份描述，却只有三个二人组：

$$
(A,B),(B,A)\longmapsto\{A,B\},\qquad
(A,C),(C,A)\longmapsto\{A,C\},\qquad
(B,C),(C,B)\longmapsto\{B,C\}.
$$

<!-- bilingual-en:start -->
Here $A,B,C$ abbreviate the names. Every pair appears **exactly twice**, so dividing the six descriptions by two gives $6/2=3$ objects. The **division rule** works when an easier count represents every target object the same positive number of times. The denominator comes from that common multiplicity, not from the fact that a problem “has symmetry.”
<!-- bilingual-en:end -->

这里 $A,B,C$ 是人名缩写。每个二人组都**恰好出现两次**，因此六份描述除以二，得到 $6/2=3$ 个对象。**除法法则**适用于这样的情况：容易数的描述把每个目标对象都重复了相同的正整数次。分母来自这个共同重数，不能仅因题目“有对称性”就猜一个数去除。

<!-- bilingual-en:start -->
Let $D$ be the finite set of descriptions and $T$ the finite set of target objects. A function $f:D\to T$ tells us which object each description represents. For a target $t$, the **fibre** or **preimage set**
<!-- bilingual-en:end -->

令 $D$ 是有限的描述集合，$T$ 是有限的目标对象集合。函数 $f:D\to T$ 指明每份描述代表哪个对象。对目标 $t$，它的**纤维**，也叫**原像集合**，是

$$
f^{-1}(t)=\{d\in D:f(d)=t\}.
$$

<!-- bilingual-en:start -->
This means “all descriptions representing $t$”; it does not assert that an inverse function exists. Suppose every target has exactly $r$ descriptions, where $r\ge1$ is an integer. This also ensures that every target is reached: the map is surjective.
<!-- bilingual-en:end -->

这表示“所有代表 $t$ 的描述”，并不是说 $f$ 有逆函数。设每个目标都恰有 $r$ 份描述，其中 $r\ge1$ 是整数。这也保证每个目标都能被描述到，即映射是满射。

> [!important] Count the same multiplicity for every target · 每个目标的重数相同
> $$
> |D|=r|T|,\qquad |T|=\frac{|D|}{r}.
> $$
>
> <!-- bilingual-en:start -->
> Here vertical bars mean the size of a finite set. The fibres partition $D$: every description represents exactly one target. By the [[加法法则|sum rule]], their sizes add to $|D|$. If every size is $r$, the sum is $r|T|$. When $r=1$, this is [[双射计数|counting by bijection]].
> <!-- bilingual-en:end -->
>
> 竖线表示有限集合的大小。每份描述只代表一个目标，所以各个纤维把 $D$ 分成互不重叠的部分。由[[加法法则]]，各纤维大小之和就是 $|D|$；每份都是 $r$，总和便是 $r|T|$。当 $r=1$ 时，就回到[[双射计数]]。

<!-- bilingual-en:start -->
For $n$ distinct objects and an integer $k$ with $0\le k\le n$, count ordered lists of $k$ distinct objects first. The [[乘法法则|product rule]] gives $n(n-1)\cdots(n-k+1)$ lists. Every unordered $k$-element subset has exactly $k!$ orderings, where the factorial $k!$ counts the [[排列|permutations]] of its members. Thus the [[组合数|binomial coefficient]] satisfies
<!-- bilingual-en:end -->

对 $n$ 个不同对象和满足 $0\le k\le n$ 的整数 $k$，先数无重复的有序 $k$ 元列表。[[乘法法则]]给出 $n(n-1)\cdots(n-k+1)$ 个列表。每个无序 $k$ 元子集都恰好有 $k!$ 种排列；阶乘 $k!$ 计算这些成员的[[排列]]数。因此[[组合数]]满足

$$
\binom nk=\frac{n(n-1)\cdots(n-k+1)}{k!}.
$$

<!-- bilingual-en:start -->
At $k=0$, the numerator is an empty product, equal to $1$, and $0!=1$. The one empty list represents the one empty subset. Outside $0\le k\le n$, this displayed factorial-based construction is not the formula to apply; use the counting conventions in the binomial-coefficient card.
<!-- bilingual-en:end -->

$k=0$ 时，分子是空乘积，值为 $1$，且 $0!=1$：一个空列表代表一个空子集。超出 $0\le k\le n$ 后，不应继续套用这里的阶乘构造，应按组合数卡片中的计数约定处理。

## Check the fibres before dividing
<!-- bilingual-en:end -->

## 关键边界

<!-- bilingual-en:start -->
Checking one typical target, or observing that most targets have $r$ descriptions, does not prove a common multiplicity. If the fibre sizes vary, the valid identity is $|D|=\sum_{t\in T}|f^{-1}(t)|$. One can split targets into classes of equal fibre size, assign suitable weights, or redesign the descriptions; division by an unverified constant is not justified.
<!-- bilingual-en:end -->

检查一个“典型对象”，或发现大多数对象有 $r$ 份描述，都不能证明重数一致。纤维大小不同时，正确的关系是 $|D|=\sum_{t\in T}|f^{-1}(t)|$。可以按纤维大小分类、设计合适权重，或重新设计描述方式；不能除以未经证明的常数。

> [!example] Circular arrangements · 圆形排列
> <!-- bilingual-en:start -->
> Seat $n\ge1$ distinct people around a circle, identifying only rotations, with no additional identification by reflection. A linear list records a starting position and clockwise order. Each circular arrangement has exactly $n$ such lists, one for each starting person, so the count is $n!/n=(n-1)!$.
>
> With repeated symbols, rotation classes can have different sizes. Among length-four binary strings, $0000$ has one distinct rotation, $0101$ has two, and $0001$ has four. Therefore dividing all $16$ strings by $4$ is not justified. The object and the equivalence rule must be fixed before counting representations.
> <!-- bilingual-en:end -->
>
> 让 $n\ge1$ 个不同的人围成一圈，只按旋转等价归并，不另外按反射归并。线性列表记录起点及顺时针顺序；每个圆形排列恰有 $n$ 份列表，分别从每个人开始，因此数量为 $n!/n=(n-1)!$。
>
> 如果符号会重复，旋转类别的大小可能不同。四位二进制串中，$0000$ 只有一种不同的旋转，$0101$ 有两种，$0001$ 有四种，因此不能把全部 $16$ 个串直接除以 $4$。必须先说清什么算一个对象、哪些表示视为相同，再数表示重数。
