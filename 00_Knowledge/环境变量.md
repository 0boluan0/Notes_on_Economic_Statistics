# 环境变量是进程环境中的名称与字符串值条目
<!-- bilingual-en:start -->
*An environment variable is a name–string-value entry in a process's environment.*
<!-- bilingual-en:end -->

环境由 `name=value` 字符串组成；进程启动时可接收这些条目，运行中也可修改自己的环境，程序按自己的约定读取它们。例如 `PATH` 参与[[Shell命令查找]]，locale 变量影响支持本地化的程序。它不是机器上所有程序实时共享的一张配置表，也不等于 shell 的全部变量、函数和选项。
<!-- bilingual-en:start -->
The environment consists of `name=value` strings. A process can receive entries at startup and modify its own environment while running; each program interprets them according to its own conventions. For example, `PATH` participates in [[Shell命令查找|command lookup]], while locale variables affect locale-aware programs. It is neither a live configuration table shared by every process nor the shell's entire collection of variables, functions, and options.
<!-- bilingual-en:end -->

Shell 中新赋值的普通变量与供子程序继承的环境变量须区分；后者通过[[环境变量导出]]形成。子进程修改自己的环境，不会因此改写父 shell；已有的其他进程也不会自动同步。
<!-- bilingual-en:start -->
Distinguish an ordinary variable assigned in a shell from one passed to child programs through [[环境变量导出|export]]. A child changing its own environment does not thereby update its parent shell or other existing processes.
<!-- bilingual-en:end -->

`SHELL` 通常记录用户的登录 shell 路径，不证明当前正在执行哪一种解释器；从 Zsh 启动 Bash 后，它可能仍指向 Zsh。跨机器差异诊断应核对实际解释器、启动方式及需要的变量，而不是把整份环境中的秘密打印到日志。
<!-- bilingual-en:start -->
`SHELL` normally records the user's login-shell path, not proof of the currently executing interpreter. It may still name Zsh after Bash is launched from Zsh. Diagnose differences by checking the actual interpreter, invocation mode, and relevant variables without dumping secrets from the entire environment into logs.
<!-- bilingual-en:end -->

## 来源与核验

[GNU Bash Manual §3.7.4, Environment](https://www.gnu.org/software/bash/manual/html_node/Environment.html)：支持名称—值环境、导出与子命令继承；同时核对本机 `bash(1)` 的 ENVIRONMENT、COMMAND EXECUTION ENVIRONMENT 段。
<!-- bilingual-en:start -->
[GNU Bash Manual §3.7.4: Environment](https://www.gnu.org/software/bash/manual/html_node/Environment.html) supports name–value environments, export, and inheritance by child commands; the installed `bash(1)` sections on environments were also inspected.
<!-- bilingual-en:end -->

本机 macOS `environ(7)` 的 DESCRIPTION、SHELL、PATH 与 locale 条目：支持环境字符串形式及登录 shell 路径的含义；`setenv(3)` 的 DESCRIPTION 支持运行中增加或改变环境条目。不把平台示例默认值推广到所有系统。
<!-- bilingual-en:start -->
The installed macOS `environ(7)` entries for DESCRIPTION, SHELL, PATH, and locale support the representation and login-shell meaning. The DESCRIPTION in `setenv(3)` supports adding or changing entries while running. Platform-specific default values are not generalized.
<!-- bilingual-en:end -->
