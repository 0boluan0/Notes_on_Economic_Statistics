# D1 比直观准则更严格，因为它允许的离轨类型支持更小，并要求同一个接收者混合最佳反应同时阻止所有类型偏离
<!-- bilingual-en:start -->
*D1 is more restrictive than the Intuitive Criterion because it permits a smaller off-path type support and requires one receiver mixed best response to deter every sender type simultaneously*
<!-- bilingual-en:end -->

> [!summary] “更强”来自两道不同的收紧
> [[D1准则]]先比[[直观准则]]删除更多缺乏相对偏离动机的类型，再把逐类型分别设想的最不利回应改成一项必须同时阻止所有类型偏离的共同回应。因此通过 D1 比通过直观准则更难。
> <!-- bilingual-en:start -->
> D1 first removes more types whose relative deviation incentives are weak, and then replaces type-by-type worst-case receiver responses with one common response that must deter every type. Passing D1 is therefore harder than passing the Intuitive Criterion.
> <!-- bilingual-en:end -->

第一道收紧发生在 belief 支持上。若离轨信号 $s$ 对类型 $\theta$ 被均衡支配，则

$$
D_\theta(s,\sigma)=D_\theta^0(s,\sigma)=\varnothing,
$$

所以 D1 的保留集合满足

$$
\Theta_{D1}(s,\sigma)\subseteq\Theta_{IC}(s,\sigma).
$$

接收者在 D1 下可赋正概率的类型不会比直观准则更多。
<!-- bilingual-en:start -->
The first tightening concerns belief support. An equilibrium-dominated type has empty strict-deviation and indifference sets, which implies $\Theta_{D1}(s,\sigma)\subseteq\Theta_{IC}(s,\sigma)$. D1 never permits a larger type support at the off-path signal.
<!-- bilingual-en:end -->

第二道收紧发生在阻止偏离的量词上。直观准则允许每个发送者类型分别面对对自己最不利的允许纯最佳反应；D1 则要求找到同一个

$$
\alpha\in MBR(\Theta_{D1}(s,\sigma),s)
$$

使 $u_1(\theta,s,\alpha)\le u_1(\theta,\sigma)$ 对所有 $\theta$ 同时成立。分别存在的回应不一定能合成一个共同回应，因此 D1 还能排除一部分已通过直观准则的 PBE。
<!-- bilingual-en:start -->
The second tightening concerns quantifiers. The Intuitive Criterion lets each type consider its own worst admissible pure best response. D1 instead requires one $\alpha$ to satisfy every type's no-deviation inequality at once. Responses that exist separately need not yield one common deterrent response.
<!-- bilingual-en:end -->

> [!question]- 可核验自检
> 对每个类型分别都能找到一个允许的接收者回应阻止其偏离，但不存在同一个回应同时阻止所有类型。该 PBE 能否通过 D1？
>
> **答案：** 不能。D1 的共同回应条件要求同一项 $\alpha$ 同时满足所有类型的不偏离不等式。
> <!-- bilingual-en:start -->
> No. D1 requires one common response to satisfy every type's no-deviation inequality simultaneously.
> <!-- bilingual-en:end -->
