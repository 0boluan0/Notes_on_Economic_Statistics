# 稳定排序保持相等键元素的输入相对顺序

<!-- bilingual-en:start -->
*Stable sorting preserves the input order of equal-key items*
<!-- bilingual-en:end -->

> [!summary] 原子定义
> 若两个项目的排序键相等，而且前者在输入中先出现，稳定排序保证前者在输出中仍先出现。稳定性约束的是“相等键项目的相对顺序”，不是所有项目的位置都不变。
>
> <!-- bilingual-en:start -->
> If two items have equal sort keys and one precedes the other in the input, a stable sort keeps that order in the output. Stability constrains the relative order of equal-key items; it does not keep every item in its original position.
> <!-- bilingual-en:end -->

## 自然解释

先按年龄稳定排序，再按年级稳定排序，最终可得到“年级为主键、年龄为次键”的顺序：第二次排序遇到同年级记录时，会保留第一次排序建立的年龄次序。

<!-- bilingual-en:start -->
If records are stably sorted first by age and then by grade, the final order uses grade as the primary key and age as the secondary key. The second sort preserves the age order whenever grade keys tie.
<!-- bilingual-en:end -->

> [!warning] 边界
> 稳定不推出原地、低内存或某个时间复杂度；这些是独立性质。稳定性还取决于具体实现的相等键处理规则，不能只凭算法家族名称判断。
>
> <!-- bilingual-en:start -->
> Stability implies neither in-place execution, low memory use, nor any time bound; those are independent properties. Stability can also depend on the implementation's tie rule, so an algorithm-family name alone may be insufficient.
> <!-- bilingual-en:end -->

> [!question]- 回忆与应用
> 把 `(Alice, 80)`、`(Bob, 80)` 按分数稳定排序后，谁必须在前？
>
> **答案：** Alice，因为两人的键相等，而 Alice 在输入中先出现。
