# 协整分析应按整合阶数确定项秩动态和稳定性逐层诊断
<!-- bilingual-en:start -->
*Cointegration analysis should diagnose integration order, deterministic terms, rank, dynamics, and stability in layers*
<!-- bilingual-en:end -->

> [!summary] 原子边界
> 可靠的协整分析不是“跑一次检验看星号”，而是一条有依赖顺序的诊断链：先定义长期问题和样本，再确认整合阶数与确定性项，随后识别关系数，最后估计动态、验证稳定性并限制解释。

最小可复核流程是：

1. **问题与数据：** 写清变量定义、频率、样本窗口、制度变化和理论候选关系；
2. **单变量诊断：** 画水平与差分，组合 ADF/PP/KPSS、季节性和断点证据，排除未经处理的 $I(2)$；
3. **方法选择：** 单一理论关系可用 EG/PO；多变量、未知秩用 Johansen，并先选水平 VAR 滞后与确定性项；
4. **长期结构：** 报告秩、归一化、限制及其不确定性，不把统计组合直接命名为因果均衡；
5. **短期动态：** 估计 ECM/VECM，解释 $\alpha$ 符号、差分滞后、弱外生与 Granger 限制；
6. **验收：** 检查残差自相关、异方差、非正态异常值、系统稳定性、参数/关系断点和替代规格；
7. **预测与解释：** 与纯差分、水平 VAR 或其他合理模型做样本外比较，并把结论限定在识别和稳定性支持的范围内。

任何上游层失败，都应回退修正，而不是用下游更复杂的检验掩盖。

> [!question]- 自检
> Johansen 选出秩 1 后，下一步是否只需报告归一化后的 $\beta$？
>
> **答案：** 不是。还要估计并解释 $\alpha$ 与短期动态，检查残差和稳定性，并说明经济解释的识别边界。

- [Johansen (1988)](https://doi.org/10.1016/0165-1889(88)90041-3)：核对系统秩与 VECM 推断链。
