# 分类器以及标准化、插补、特征选择、正则化与调参都必须只在训练折拟合，再由独立验证或测试数据估计泛化表现
<!-- bilingual-en:start -->
*The classifier, scaling, imputation, feature selection, regularisation, and tuning must all be fitted within training folds before generalisation performance is estimated on independent validation or test data*
<!-- bilingual-en:end -->

> [!summary] 怎样验证
> 这是 [[验证管线隔离]] 在分类问题中的专门应用。一个 classification pipeline 不只包含最后的 LDA 或 QDA 公式；任何从数据学习数值或选择方案的步骤都属于拟合。验证折只能接收训练折已经确定的变换和模型，再用于产生未见预测；若先看全数据再做特征选择或 covariance regularisation，随后标成“交叉验证”的分数仍然泄漏。
> <!-- bilingual-en:start -->
> This is the classification-specific application of [[验证管线隔离|validation-pipeline isolation]]. A classification pipeline includes every data-dependent transformation and choice, not only the final LDA or QDA formula. Validation observations must receive a pipeline fitted entirely on the training fold. Feature selection or covariance regularisation performed on all data leaks validation information even if cross-validation follows.
> <!-- bilingual-en:end -->

## 每个验证折都要重走完整训练流程

对第 $b$ 个 train/validation split，应按以下边界运行：

1. 只在 training fold 估计缺失值填补量、中心、尺度、类均值和 covariance。
2. 只在 training fold 选择变量、降维方向、LDA/QDA 版本、正则强度和其他超参数。
3. 把已经固定的变换应用到 validation fold，不用 validation 的均值或标签重新拟合。
4. 在 validation fold 产生类别、得分或概率，并按事先规定的 [[分类评估口径]] 汇总。

若类别先验来自外部部署知识，它可以作为事前固定输入；若由当前样本估计，则也只能从 training fold 得到。分类阈值若由数据选择，同样属于训练或 inner-validation，而不是测试后调整。

## resubstitution、jackknife 与最终测试不是同一证据

用同一训练数据拟合并分类自身称为 resubstitution。它复用了拟合数据，不能提供独立的泛化误差估计，通常会比新数据表现乐观；“通常”不表示每个有限样本的训练误差必然严格更小。

逐次留出一个观测再重拟合是 leave-one-out cross-validation，也常在本课程中称 jackknife classification。它只有在每一次留出时都重新执行完整 pipeline 才有效：若变量早已用全数据挑好，或 covariance shrinkage 早已看过所有标签，留出最后一个 classifier 仍不能消除泄漏。LOOCV 也不自动保证低方差或完全无偏。

调参时应把选择与评价再分开：内层 validation 选择模型，外层 held-out fold 估计所选流程的表现；一个最终 test set 应在所有选择完成后只用于最终检查。所有候选必须在同一组未见 cases 和同一指标上比较。

## split 还必须尊重数据生成方式

随机逐行切分默认观测可按该方式交换。时间序列、同一人的重复测量、家庭或学校等群组数据若被拆到两侧，训练集可能通过相邻时间或同组对象间接见到验证信息。此时应使用时间、群组或其他与部署预测单位一致的 split。stratification 可以维持各折类别比例，却不能修复这些依赖或已经发生的 preprocessing leakage。

> [!question]- 自检
> 研究者先在全体数据上选出与标签相关性最高的 20 个变量，再对这 20 个变量做五折 LDA cross-validation。为什么五折分数仍然不独立？
>
> **答案：** 每个 validation fold 的标签已经参与全数据变量选择，因而影响了进入 LDA 的特征集合。正确做法是在每个 training fold 内重新选择 20 个变量，再把该选择应用到相应 validation fold。

## 来源与核验

- [scikit-learn, Common pitfalls: data leakage](https://scikit-learn.org/stable/common_pitfalls.html#data-leakage)：核对先切分、所有 `fit` 只用训练数据，以及 pipeline 对标准化、插补、PCA 和特征选择泄漏的防护。
- [scikit-learn, Cross-validation: evaluating estimator performance](https://scikit-learn.org/stable/modules/cross_validation.html)：核对训练/验证分离、group-aware 与 time-aware split，以及交叉验证的适用边界。
- [Penn State STAT 505, Lesson 10.4](https://online.stat.psu.edu/stat505/Lesson10)：核对 resubstitution、set-aside 与逐一留出 cross-validation 在判别分析中的区别。
- [[PCA验证与泄漏]]：复用 PCA 中心、尺度、方向和成分数必须在训练折拟合的专属边界；本卡把同一原则扩展到完整 classification pipeline。
