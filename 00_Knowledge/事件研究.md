# 金融事件研究通过比较事件窗实际收益与正常收益反事实来估计价格反应
<!-- bilingual-en:start -->
*A financial event study estimates a price reaction by comparing event-window returns with a normal-return counterfactual*
<!-- bilingual-en:end -->

> [!summary] 原子定义
> 金融事件研究是一种用证券价格数据衡量事件窗内模型相对价格反应的方法：先用事件之外的数据建立“若事件未带来额外信息时”的正常收益基准，再比较事件窗中的实际收益与该基准。只有在额外识别条件成立时，这种价格反应才能进一步解释为目标事件的因果经济影响。
> <!-- bilingual-en:start -->
> A financial event study uses security prices to measure a model-relative price reaction within an event window. It first estimates a normal-return benchmark from data outside the event, then compares realised event-window returns with that counterfactual. Only under additional identification conditions can the reaction be interpreted as the event's causal economic impact.
> <!-- bilingual-en:end -->

最小流程是：定义事件与事件日，确定样本、估计窗和事件窗，估计正常收益，计算 [[异常收益]]，必要时汇总为 [[累计异常收益]]，最后进行统计推断。各步骤的选择必须在看见目标回报前冻结，见 [[事件研究设计]]。
<!-- bilingual-en:start -->
The minimal workflow is to define the event and event date, choose the sample, estimation window, and event window, estimate normal returns, compute [[异常收益|abnormal returns]], aggregate them into [[累计异常收益|cumulative abnormal returns]] when needed, and conduct inference. These choices should be fixed before observing the target returns; see [[事件研究设计|event-study design]].
<!-- bilingual-en:end -->

例如，若公告日股票实际回报为 4%，而估计窗拟合的市场模型给出 1% 的正常收益，则该日 AR 为 3%。这个数字回答“相对所选模型，窗口内价格怎样反应”；它本身尚未证明全部 3% 由公告因果造成，也未单独检验整个市场是否有效。
<!-- bilingual-en:start -->
For example, if a stock returns 4% on the announcement day while a market model fitted in the estimation window implies a 1% normal return, the day's AR is 3%. This answers how price moved relative to the selected model in the window. It does not by itself establish that the announcement caused the entire 3%, nor does it alone test the efficiency of the whole market.
<!-- bilingual-en:end -->

因此，事件研究是测量框架，不是自动成立的因果设计。事件是否意外、是否提前泄漏、窗口内有无并发消息、多个事件是否相关以及价格能否被及时观察，都决定结果可以解释到哪一步。
<!-- bilingual-en:start -->
An event study is therefore a measurement framework, not an automatically valid causal design. Whether the event was unexpected or leaked, whether concurrent news entered the window, whether events are dependent, and whether prices were observed promptly all limit interpretation.
<!-- bilingual-en:end -->

> [!question]- 自检
> 一项研究只比较公告日前后原始回报，没有正常收益基准，是否已经完成金融事件研究？
>
> **答案：** 没有。它描述了回报变化，但还没有构造未发生额外事件影响时的正常收益反事实，因此无法得到模型相对异常收益。
