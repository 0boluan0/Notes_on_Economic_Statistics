# 簇数是建模分辨率而非数据自动给出的真值，树切、elbow、silhouette、gap 与用途必须共同判断
<!-- bilingual-en:start -->
*The number of clusters is a modelling resolution rather than a truth automatically returned by the data; tree cuts, elbow, silhouette, gap, and purpose must be judged together*
<!-- bilingual-en:end -->

> [!summary] 原子选择原则
> 同一总体可以在粗粒度上分成两类，也可以在细粒度上分出多个亚型。$K$ 决定分析要保留的分辨率；任何指标都只在自己的表示、算法和参考准则下推荐候选 $K$，不能无条件揭示唯一真实数量。
> <!-- bilingual-en:start -->
> The same population may form two broad groups at one resolution and several subtypes at another. $K$ fixes the resolution retained by the analysis. Every criterion recommends candidate values only under its representation, algorithm, and reference principle; none unconditionally reveals one true number.
> <!-- bilingual-en:end -->

## 常见方法加入的是不同额外原则

- **树状图切割：** 从一棵由特定 metric 和 linkage 生成的树上选一层。大合并高度或可见断层提示某个切法，却不脱离这棵树而成立。
- **elbow：** K-means 的 WCSS 随 $K$ 必然不增，$K=n$ 时可降到 0。elbow 寻找边际下降明显放缓的位置；若曲线平滑或有多个转折，它没有唯一答案。
- **[[轮廓系数|silhouette]]：** 在既定 dissimilarity 下平衡簇内紧密与簇间分离，但偏好某类几何，也不能评价 $K=1$。
- **gap statistic：** 把观测到的组内离散与一个“没有簇”的参考分布比较。常写为

$$
\operatorname{Gap}(K)=E^*\!\left[\log W_K^*\right]-\log W_K.
$$

它的结论依赖参考分布、候选范围、离散度和聚类算法；这些选择改变，gap 推荐的 $K$ 也可能改变。

领域约束还可能比内部曲线更重要：可执行的客户策略只容纳四组，生物亚型必须能在独立样本复现，教学分组则要满足人数下限。这些约束不是“污染统计”，而是在说明聚类要服务什么决定。

## 比较候选时要锁定完整流程

若每个 $K$ 都偷偷换一种标准化、变量集合或随机起点，指标差异混合了多个变化。应先定义候选流程，对每个 $K$ 使用一致的预处理和足够的 [[K-means多启动|优化启动]]，再把内部指标、[[聚类验证|稳定性与外部证据]]及实际可解释性并列。没有任何候选满足用途，也应允许得出“当前数据不支持可靠分组”。

> [!question]- 自检
> K-means 的 WCSS 在 $K=2,3,4,5$ 时不断下降。为什么不能直接选 WCSS 最低的 $K=5$？
>
> **答案：** 因为增加中心不会提高最小 WCSS，极端到每点一簇时可为 0。必须用复杂度、稳定性、外部效用或其他准则判断下降是否值得，而不是把单调下降本身当作选择规则。

## 来源与核验

- Tibshirani, Walther & Hastie (2001), [*Estimating the Number of Clusters in a Data Set via the Gap Statistic*](https://doi.org/10.1111/1467-9868.00293)：核对 gap 的参考分布思想和一标准误选择规则。
- [scikit-learn, selecting $K$ with silhouette analysis](https://scikit-learn.org/stable/auto_examples/cluster/plot_kmeans_silhouette_analysis.html)：核对 silhouette 用于比较候选 $K$ 的官方示例与轮廓宽度检查。
- [Penn State STAT 505, Lesson 14](https://online.stat.psu.edu/stat505/Lesson14)：核对树切和 K-means 中 $K$ 必须由分析者与领域描述共同选择的课程口径。
- Schubert (2023), [*Stop using the elbow criterion for k-means*](https://arxiv.org/abs/2212.12189)：核对 WCSS 单调性与 elbow 缺少自动唯一解释的边界。
