# D1准则比较使各类型愿意偏离的接收者混合最佳反应集合，并把离轨信念集中在偏离动机更强的类型上
<!-- bilingual-en:start -->
*The D1 criterion compares the sets of receiver mixed best responses that make each type willing to deviate and concentrates off-path beliefs on types with stronger deviation incentives*
<!-- bilingual-en:end -->

D1 是 Banks–Sobel 信号博弈精炼中的一项严格离轨信念限制。它不只问某类型是否可能从离轨信号获益，还比较不同类型在多大范围的理性接收者回应下愿意偏离。若类型 $\theta$ 愿意偏离所需的每一种回应都会使另一类型 $\theta'$ 严格愿意偏离，观察到该信号后就不应把正概率放在 $\theta$ 上。
<!-- bilingual-en:start -->
D1 is a stringent off-path belief restriction associated with the Banks–Sobel refinement of signaling games. It asks not only whether a type can gain from an off-path signal, but also compares the ranges of rational receiver responses under which different types would deviate. If every response that makes type $\theta$ willing to deviate makes another type $\theta'$ strictly willing to deviate, the receiver should assign no positive probability to $\theta$ after observing that signal.
<!-- bilingual-en:end -->

## 接收者混合最佳反应的可行集合
<!-- bilingual-en:start -->
*The Feasible Set of Receiver Mixed Best Responses*
<!-- bilingual-en:end -->

固定信号 $s$。令 $MBR(\widetilde\Theta,s)$ 表示接收者对某份支持包含于 $\widetilde\Theta$ 的 belief 作出的混合最佳反应集合。每个 $\alpha\in MBR(\widetilde\Theta,s)$ 必须是同一份 belief 下的混合最佳反应，而不是把针对不同 beliefs 的纯最佳反应任意混在一起。
<!-- bilingual-en:start -->
Fix a signal $s$. Let $MBR(\widetilde\Theta,s)$ denote the receiver's mixed best responses to some belief supported on $\widetilde\Theta$. Each $\alpha\in MBR(\widetilde\Theta,s)$ must be a mixed best response to one common belief; it is not an arbitrary mixture of pure best responses generated by different beliefs.
<!-- bilingual-en:end -->

## 严格偏离集与无差异集
<!-- bilingual-en:start -->
*Strict-Deviation and Indifference Sets*
<!-- bilingual-en:end -->

固定 PBE 策略组合 $\sigma$。对发送者类型 $\theta$，定义
<!-- bilingual-en:start -->
Fix a PBE strategy profile $\sigma$. For sender type $\theta$, define
<!-- bilingual-en:end -->

$$
D_\theta(s,\sigma)
=
\left\{
\alpha\in MBR(\Theta,s):
u_1(\theta,s,\alpha)>u_1(\theta,\sigma)
\right\},
$$

$$
D_\theta^0(s,\sigma)
=
\left\{
\alpha\in MBR(\Theta,s):
u_1(\theta,s,\alpha)=u_1(\theta,\sigma)
\right\}.
$$

$D_\theta$ 收集使类型 $\theta$ 严格偏好离轨信号 $s$ 的接收者回应，$D_\theta^0$ 收集使其恰好无差异的回应。若存在另一类型 $\theta'$ 使
<!-- bilingual-en:start -->
$D_\theta$ collects receiver responses under which type $\theta$ strictly prefers the off-path signal $s$, while $D_\theta^0$ collects responses under which it is exactly indifferent. If another type $\theta'$ satisfies
<!-- bilingual-en:end -->

$$
D_\theta(s,\sigma)\cup D_\theta^0(s,\sigma)
\subseteq
D_{\theta'}(s,\sigma),
$$

那么凡是足以让 $\theta$ 弱愿意偏离的理性回应，都会让 $\theta'$ 严格愿意偏离；D1 因而从离轨 posterior 的可能支持中删除 $\theta$。
<!-- bilingual-en:start -->
then every rational response sufficient to make $\theta$ weakly willing to deviate makes $\theta'$ strictly willing to deviate. D1 therefore removes $\theta$ from the possible support of the off-path posterior.
<!-- bilingual-en:end -->

本卡沿用 MIT 2024 Lecture 3 的弱包含写法；另一种严格包含写法及两者唯一发生分歧的情形见 [[D1包含口径]]。
<!-- bilingual-en:start -->
This card follows the weak-inclusion formulation in MIT's 2024 Lecture 3. See [[D1包含口径|the D1 inclusion convention]] for the strict-inclusion alternative and the one case in which the two formulations differ.
<!-- bilingual-en:end -->

## D1保留的类型与正式通过条件
<!-- bilingual-en:start -->
*D1-Surviving Types and the Formal Test*
<!-- bilingual-en:end -->

定义未被上述比较删除的类型集合
<!-- bilingual-en:start -->
Define the set of types not eliminated by the comparison above as
<!-- bilingual-en:end -->

$$
\Theta_{D1}(s,\sigma)
=
\left\{
\theta\in\Theta:
\text{for every }\theta'\ne\theta,
\ D_\theta(s,\sigma)\cup D_\theta^0(s,\sigma)
\nsubseteq D_{\theta'}(s,\sigma)
\right\}.
$$

一份 PBE 通过 D1，当且仅当对每个信号 $s$，存在一项共同的接收者混合回应
<!-- bilingual-en:start -->
A PBE passes D1 if and only if, for every signal $s$, there exists one common receiver mixed response
<!-- bilingual-en:end -->

$$
\alpha\in MBR\bigl(\Theta_{D1}(s,\sigma),s\bigr)
$$

使所有类型的偏离都被同时阻止：
<!-- bilingual-en:start -->
that simultaneously deters every sender type:
<!-- bilingual-en:end -->

$$
u_1(\theta,s,\alpha)
\le
u_1(\theta,\sigma)
\qquad\text{for every }\theta\in\Theta.
$$

这项定义为何比 [[直观准则]] 更严格，是另一条可单独使用的比较结论，见 [[D1强于直观准则]]。
<!-- bilingual-en:start -->
Why this definition is more restrictive than the [[直观准则|Intuitive Criterion]] is a separate comparison result; see [[D1强于直观准则|why D1 is more restrictive than the Intuitive Criterion]].
<!-- bilingual-en:end -->

> [!question]- 可核验自检
> 若所有能让类型 $\theta$ 弱愿意偏离的理性接收者回应，也都会让另一类型 $\theta'$ 严格愿意偏离，D1 会在观察到该离轨信号后保留哪一个类型？
>
> **答案：** 删除 $\theta$，保留偏离动机更强的候选类型 $\theta'$；随后仍须找到同一个接收者混合最佳反应阻止所有类型偏离。
> <!-- bilingual-en:start -->
> D1 deletes $\theta$ from the posterior support and retains the type with the stronger deviation incentive. One common receiver mixed best response must still deter every type.
> <!-- bilingual-en:end -->
