# Zero probability and impossibility
<!-- bilingual-en:end -->
*零概率与不可能*

<!-- bilingual-en:start -->
An event has **probability zero** when the model assigns it the number $0$. An **impossible event**, in the set-theoretic sense used here, contains no outcome at all. These are different statements: the first concerns the probability assignment, and the second concerns which outcomes belong to the event.
<!-- bilingual-en:end -->

事件的**概率为零**，表示模型给它分配了数值 $0$。这里从集合意义上说的**不可能事件**，则是一个结果也不包含的事件。这两句话不同：前者谈概率怎样分配，后者谈事件包含哪些结果。

<!-- bilingual-en:start -->
In a [[概率空间|probability space]], $\Omega$ is the set of possible outcomes, an event $A$ is a measurable subset of $\Omega$, and $P(A)$ is its probability. An empty event is written $\varnothing$. For a six-sided die, “the face is $7$” is empty because $7$ is absent from the sample space. The [[概率三公理|probability axioms]] imply $P(\varnothing)=0$, but they do not imply that every event assigned zero must be empty.
<!-- bilingual-en:end -->

在[[概率空间]]中，$\Omega$ 是可能结果的集合，事件 $A$ 是其中可测的子集，$P(A)$ 是它的概率。空事件记作 $\varnothing$。对于六面骰子，“点数是 $7$”就是空事件，因为样本空间里没有 $7$。[[概率三公理]]能推出 $P(\varnothing)=0$，却不能推出被赋予零概率的事件一定为空。

> [!example] A specified point in a uniform interval · 均匀区间内一个指定的点
> <!-- bilingual-en:start -->
> Consider the mathematical model that selects a real number $X$ uniformly from $[0,1]$. Its [[连续均匀分布|uniform distribution]] assigns an interval its length. The event $X=1/2$ contains the allowed outcome $1/2$, so it is nonempty. Nevertheless, it has probability zero.
> <!-- bilingual-en:end -->
>
> 考虑一个数学模型：在 $[0,1]$ 内均匀选取实数 $X$。它的[[连续均匀分布]]把区间的长度作为概率。事件 $X=1/2$ 包含允许出现的结果 $1/2$，所以不为空；但它的概率仍然为零。
>
> <!-- bilingual-en:start -->
> To see why, surround $1/2$ by the interval $[1/2-\varepsilon,1/2+\varepsilon]$, where $0<\varepsilon<1/2$. The point event is contained in that interval, whose probability is $2\varepsilon$. Thus
> <!-- bilingual-en:end -->
>
> 为了看清原因，用区间 $[1/2-\varepsilon,1/2+\varepsilon]$ 包住 $1/2$，其中 $0<\varepsilon<1/2$。单点事件包含在这个区间里，而区间概率为 $2\varepsilon$，因此
>
> $$0\le P(X=1/2)\le 2\varepsilon.$$
>
> <!-- bilingual-en:start -->
> We can make the positive number $\varepsilon$ as small as we wish. No positive probability can stay below every such bound, so $P(X=1/2)=0$ exactly. The same argument applies to every fixed point of $[0,1]$, using one-sided intervals at the endpoints.
> <!-- bilingual-en:end -->
>
> 正数 $\varepsilon$ 可以任意小，没有任何正概率能始终小于所有这样的上界，所以 $P(X=1/2)$ 恰好等于 $0$。同样的论证适用于 $[0,1]$ 内每个预先指定的点；在端点处使用单侧区间即可。

<!-- bilingual-en:start -->
## But some value must be selected
<!-- bilingual-en:end -->
*可最终总要选到一个值*

<!-- bilingual-en:start -->
The statement “$X$ equals this specified number” has probability zero. The different statement “$X$ equals some number in $[0,1]$” has probability one. Every trial produces a value in the interval; no one fixed value carries a positive share of the probability.
<!-- bilingual-en:end -->

“$X$ 等于这个预先指定的数”的概率为零。“$X$ 等于 $[0,1]$ 内某个数”则是另一个事件，概率为一。每次试验都会得到区间内的一个值，但没有哪一个固定值单独占有一份正概率。

<!-- bilingual-en:start -->
Why can we not add all the zero point probabilities? The additivity axiom covers finite or **countably infinite** collections: events that can be put in a list $A_1,A_2,A_3,\ldots$. The real points in $[0,1]$ form an **uncountable** set, meaning that no such list includes them all. Applying countable additivity to this uncountable collection would exceed what the axiom says.
<!-- bilingual-en:end -->

为什么不能把所有单点的零概率加起来？可加性公理适用于有限或**可数无穷**个事件，也就是能排成 $A_1,A_2,A_3,\ldots$ 列表的事件。$[0,1]$ 内的实数点是**不可数**的，意思是这样的列表无法把它们全部列出。对这组不可数的单点套用可数可加性，超出了公理的适用范围。

> [!abstract] The implication has one direction · 推论只有一个方向
> $$A=\varnothing\ \Longrightarrow\ P(A)=0,$$
> $$P(A)=0\ \not\Longrightarrow\ A=\varnothing.$$
>
> <!-- bilingual-en:start -->
> Zero probability is exactly zero, not a hidden small positive number. What it does not establish is that the event has no outcomes. For the same reason, probability one need not mean that every outcome belongs to the event: in the uniform model, $X\ne1/2$ has probability one while the excluded point still exists.
> <!-- bilingual-en:end -->
>
> 零概率就是严格的零，不是暗藏着一个很小的正数。它不能证明的是“事件中没有结果”。同理，概率为一也未必表示每个结果都属于该事件：在上述均匀模型中，$X\ne1/2$ 的概率为一，但被排除的那个点仍然存在。
