# 浮点等号判断精确数值相等而不是近似数学相等

<!-- bilingual-en:start -->
*Floating-point equality tests exact numeric equality rather than approximate mathematical equality*
<!-- bilingual-en:end -->

> [!summary] 原子边界
> Python 的浮点 `==` 问的是两个运行时数值是否按 Python 的相等语义相等；它不会推断两个近似值是否代表同一个理想实数。经过不同舍入路径得到的理论等值可能不相等，而两个不同来源的实数也可能舍入成同一个浮点值。
>
> <!-- bilingual-en:start -->
> Python's floating-point `==` asks whether two runtime numeric values are equal under Python's equality semantics. It does not infer whether two approximations represent the same ideal real number. Theoretically equal results reached through different rounding paths may compare unequal, while distinct real inputs can round to the same float and compare equal.
> <!-- bilingual-en:end -->

因此选择比较方式应从契约出发：

- 若要验证精确往返、缓存键、离散协议值或已证明可精确表示的结果，`==` 可能正是正确问题；例如对有限 `x` 检查 `float.fromhex(x.hex()) == x`。
- 若要判断测量、数值算法或近似变换是否达到允许误差，应使用有来源的误差界、区间、残差或容差比较。

<!-- bilingual-en:start -->
- For exact round trips, cache keys, discrete protocol values, or results proved exactly representable, `==` may ask exactly the right question—for example, checking `float.fromhex(x.hex()) == x` for finite `x`.
- For measurements, numerical algorithms, or approximate transformations, use a justified error bound, interval, residual, or tolerance comparison.
<!-- bilingual-en:end -->

`==` 也不是位模式比较：`0.0 == -0.0` 为真，尽管符号位不同；NaN 则不等于自身。需要检查 NaN、符号零或原始编码时，应使用专门接口，而不是从普通等号反推位级身份。
<!-- bilingual-en:start -->
Nor is `==` a bit-pattern comparison: `0.0 == -0.0` is true despite different sign bits, while NaN is unequal to itself. Inspect NaN, signed zero, or raw encodings with dedicated interfaces rather than inferring bit identity from ordinary equality.
<!-- bilingual-en:end -->

> [!question]- 回忆与应用
> 为什么“浮点运算后 `a == b` 为真”仍不能证明两个理想实数输入完全相同？
>
> **答案：** 不同理想值可能舍入到同一个可表示浮点值；等号只看到舍入后的运行时数值。

## 来源与核验

- Python Software Foundation, [PEP 485](https://peps.python.org/pep-0485/)：核验精确相等只适合特定情形，以及近似比较的动机与用途。
- Python Software Foundation, [*Floating-Point Arithmetic: Issues and Limitations*](https://docs.python.org/3/tutorial/floatingpoint.html)：核验多个十进制字符串可映射到同一浮点值及精确十六进制往返。
- Python Software Foundation, [`math.nan`](https://docs.python.org/3/library/math.html#math.nan)：核验 NaN 不等于自身；IEEE 754 signed zero 语义由标准规定。
