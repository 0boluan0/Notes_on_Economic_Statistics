# 指针算术只在同一数组对象及其 one-past 边界内定义
<!-- bilingual-en:start -->
*Pointer arithmetic is defined only within one array object and its one-past boundary*
<!-- bilingual-en:end -->

> [!summary] 合法区域
> 若 `p` 指向数组对象的第 `i` 个元素，`p + n`、`p - n` 只有在结果仍指向该数组某个元素或末尾后一位（one-past）时才有定义。可以形成和比较 one-past 指针来结束遍历，但不能解引用它；继续算到更远的位置本身就已越出语言定义，不是等到读写时才出错。
> <!-- bilingual-en:start -->
> If `p` points to element `i` of an array, `p + n` or `p - n` is defined only when the result points to another element of that same array or one-past it. A one-past pointer may mark the end of traversal but may not be dereferenced; forming a result beyond that region is already undefined.
> <!-- bilingual-en:end -->

```c
#include <stdio.h>

void print_array(void) {
    int a[4] = {10, 20, 30, 40};
    for (int *p = a; p != a + 4; ++p) {
        printf("%d\n", *p);
    }
}
```

`a + 4` 只作为终点哨兵；循环体运行时 `p` 始终指向真实元素。加一移动的是“一个所指类型的元素”：`int *` 加一跨过一个 `int`，`char *` 加一跨过一个字节。标准 C 不定义 `void *` 的算术；把它当字节指针相加是某些编译器扩展，需要先显式选择 `unsigned char *` 或其他实际元素类型。
<!-- bilingual-en:start -->
`a + 4` is only an end sentinel, and the loop body dereferences real elements. Adding one advances by one pointed-to element: one `int` for `int *`, one byte for `char *`. Standard C defines no arithmetic on `void *`; byte-wise traversal requires a character pointer type rather than relying on a compiler extension.
<!-- bilingual-en:end -->

两个指针相减也要求它们指向同一数组的元素或末尾后一位，结果类型是 `ptrdiff_t`，表示元素下标之差。不能用两个独立分配得到的地址做减法来推断“相隔多少字节”；关系运算的顺序推理同样不能跨无关对象推广。单独一个非数组对象在这些算术规则中按长度为 1 的数组处理，因此最多形成它的 one-past 指针。
<!-- bilingual-en:start -->
Pointer subtraction likewise requires two positions within the same array or its one-past boundary and yields a `ptrdiff_t` element difference. Subtracting pointers from unrelated allocations does not measure their byte separation. A non-array object is treated as an array of length one for these arithmetic rules.
<!-- bilingual-en:end -->

还要把**顺序比较**与**相等比较**分开。`<`、`>`、`<=`、`>=` 对同一数组内的位置给出顺序；标准还专门规定了同一结构体或联合体成员的若干情形，除此以外拿无关对象地址排序是未定义行为。`==`、`!=` 在满足指针类型约束时可以比较无关对象指针，并按标准的相等规则产生结果，但这不会创造一个可移植的地址先后次序，也不能让跨对象相减变得合法。
<!-- bilingual-en:start -->
Relational ordering and equality are different operations. `<`, `>`, `<=`, and `>=` order positions within one array, with additional rules for certain members of the same aggregate; ordering unrelated object pointers is otherwise undefined. `==` and `!=` may compare unrelated object pointers when the pointer-type constraints are met and use the standard equality rules, but they create neither a portable address ordering nor permission to subtract across objects.
<!-- bilingual-en:end -->

> [!question]- 最小自检
> `int *end = a + 4;` 之后，`end - a` 与 `*end` 分别怎样？
>
> **答案：** 两者位于同一数组边界内，所以 `end - a` 定义为 4；`end` 是 one-past，不能解引用。
