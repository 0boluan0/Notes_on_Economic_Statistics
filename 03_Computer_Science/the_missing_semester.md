# basic shell operations

1. date: show the current date and time
2. echo: repeat the word i said
3. echo $PATH: show the list of directories where the shell looks for executable programs显示shell查找可执行文件时会搜索的目录列表
4. man: show how to use the command
5. which: show where the program is
6. pwd: print working directory
7. mkdir: make directory
8. cd: change directory 
9. .:current directory
10. ..:parent directory
11. ls: list the files in this current directory
12. cat : print the context of the file in terminal
13.  sort: 字典序排序这个文件的内容
14. head : 输出头多少行: head -n?  文件名
15. tail: 尾 同理
16. grep: search IN files  grep 你要找的 你要在哪找  或者 grep -r 你要找的 这将会在整个文件夹的内容中寻找你要的
17. Sed 有自己的编程语言,但是一般不用,就让他进行一些替换和查找工作
18. ~: bring to the home directory
19. -: cd - back to the previous directory
20. mv: 既可以转移文件也可以重命名文件vv
21. cp: copy 需要两个参数,复制的东西和复制到的地点
22. rm: remove
23. rmdir: remove a directory , but only work when the directory is empty
24. man: show the menu page of the function  
25. | : pipe 用左边的输出当作右边的输入.
