# basic shell operations

1. date: show the current date and time
2. echo: repeat the word i said
3. echo $PATH: show the list of directories where the shell looks for executable programs显示shell查找可执行文件时会搜索的目录列表
4. man: show how to use the command
5. which: show where the program is
6. pwd: print working directory
7. mkdir: make directory
8. cd: change directory 
9. .:current directory
10. ..:parent directory
11. ls: list the files in this current directory
12. ~: bring to the home directory
13. -: cd - back to the previous directory
14. mv: 既可以转移文件也可以重命名文件vv
15. cp: copy 需要两个参数,复制的东西和复制到的地点
16. rm: remove
17. rmdir: remove a directory , but only work when the directory is empty
18. man: show the menu page of the function  
19. | : pipe 用左边的输出当作右边的输入.
