# basic shell operations

1. date: show the current date and time
2. echo: repeat the word i said
3. echo $PATH: show the list of directories where the shell looks for executable programs显示shell查找可执行文件时会搜索的目录列表
4. which: show where the program is
5. pwd: print working directory
6. mkdir: make directory
7. cd: change directory 
8. .:current directory
9. ..:parent directory
10. ls: list the files in this current directory
11. ~: bring to the home directory
12. -: cd - back to the previous directory
13. mv: 既可以转移文件也可以重命名文件vv
14. cp: copy 需要两个参数,复制的东西和复制到的地点
15. rm: remove
16. rmdir: remove a directory , but only work when the directory is empty
17. man: show the menu page of the function  
18. | : pipe 用左边的输出当作右边的输.
