# The Missing Semester - Shell 基础操作

## 项目简介

这是一个全面的 Shell 基础操作学习资源，基于哈佛大学 CS 课程 "The Missing Semester of Your CS Education" 的内容整理和扩充。笔记涵盖了从基础命令到高级编程技巧的完整内容，适合初学者系统学习和日常参考。

## 文件位置

本笔记文件位于 `03_Computer_Science/99_Miscellaneous/` 目录下，文件名：`the_missing_semester.md`。

## 项目结构

笔记采用清晰的章节结构，便于学习和查找：

| 章节 | 内容 |
|------|------|
| **一、Shell 简介** | 介绍 Shell 的基本概念、常见类型和作用 |
| **二、文件与目录管理** | 文件和目录操作的核心命令（pwd, cd, ls, mkdir, rmdir, rm, cp, mv, chmod, chown） |
| **三、文件内容查看与处理** | 文本处理工具详解（cat, head, tail, sort, grep, sed, awk） |
| **四、系统与信息查询** | 系统查询和信息获取命令（date, echo, man, which, whoami, id, who, uptime） |
| **五、核心概念详细解释** | 文件权限系统、环境变量、进程管理基础等核心概念 |
| **六、高级操作与概念** | 管道、重定向、通配符、环境变量等高级功能 |
| **七、常用快捷键** | 整理了 Shell 中常用的快捷键 |
| **八、常见问题与解决方案** | 实际使用中遇到的问题和解决方法 |
| **九、Shell 脚本基础** | Shell 脚本的编写、执行和调试方法 |
| **十、Shell 语法详细介绍** | 变量、字符串操作、数组、条件判断、循环结构等详细语法 |
| **十一、高级 Shell 编程技巧** | 输入输出处理、错误处理、正则表达式等高级编程技巧 |

## 使用方法

### 阅读方式
1. 直接在 GitHub 或支持 Markdown 的编辑器中查看
2. 使用 Obsidian 等笔记工具打开（建议使用 Obsidian 以获得最佳阅读体验）
3. 打印为 PDF 文档学习

### 代码示例
所有代码示例均可直接在终端中运行：
```bash
# 复制示例代码到终端
bash -c '示例代码'
# 或保存为脚本文件
echo '示例代码' > script.sh
chmod +x script.sh
./script.sh
```

## 学习建议

1. **从基础开始**：按章节顺序学习，先掌握基础命令
2. **多动手实践**：每个命令都要实际操作，加深理解
3. **阅读示例代码**：仔细阅读和理解每个示例的作用
4. **解决实际问题**：尝试使用学到的知识解决实际问题
5. **查阅文档**：学会使用 `man` 命令查找命令手册
