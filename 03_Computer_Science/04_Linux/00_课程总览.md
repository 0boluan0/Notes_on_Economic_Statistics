# Linux 入门短课
<!-- bilingual-en:start -->
*Getting Started with Linux*
<!-- bilingual-en:end -->

这门短课从日常应用出发，依次介绍 Linux 的背景、发行版与安装，再进入桌面环境、命令行、Vim、桌面定制和 Linux 手机。下方按课件原顺序提供阅读入口。
<!-- bilingual-en:start -->
This mini-course starts with everyday applications, then covers Linux's background, distributions and installation, followed by desktop environments, the command line, Vim, desktop customisation and Linux phones. The links below follow the order of the slides.
<!-- bilingual-en:end -->
