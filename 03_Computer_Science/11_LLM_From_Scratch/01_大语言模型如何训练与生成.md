## 1.1–1.2 What the model predicts
<!-- bilingual-en:end -->

*给定上文，模型在预测什么*

<!-- bilingual-en:start -->
A large language model (LLM) has learned parameters that map a sequence of tokens to scores for possible continuations. In a GPT-style causal language model, the scores at one position correspond to the next token. Normalizing the scores gives a conditional probability distribution over the vocabulary.
<!-- bilingual-en:end -->

大语言模型（large language model, LLM）用训练得到的参数处理词元序列。在 GPT 这类因果语言模型（causal language model）中，某个位置的输出是词表中各候选下一词元的原始分数（logits）。把分数归一化，就得到“给定这段上文，下一个词元是什么”的条件概率。

$$p_\theta(u_{t+1}=v\mid u_0,\ldots,u_t).$$

<!-- bilingual-en:start -->
Here $u_0,\ldots,u_t$ is the available prefix, $v$ is a candidate token ID and $\theta$ denotes the model parameters. Holding the prefix fixed, the probabilities across candidate IDs sum to one. A single forward pass can score every position of a known sequence. During generation the distribution at the last position determines the next choice.
<!-- bilingual-en:end -->

从条件线的右边读起，模型已经读到 $u_t$。左边的 $v$ 是某个候选词元编号，$\theta$ 是这一套模型参数（parameters）。固定上文，所有候选的概率加起来为 1。训练时，整段已知文本的多个位置可以一起打分。生成时，先使用最后一个位置的分布。

<!-- bilingual-en:start -->
Parameter count describes the size of the learned model. A training-token count describes how much text the training procedure consumes. A context length describes how many positions a computation can use together. Each quantity measures a different part of the process. See [[00_Knowledge/语言模型输出头|the language model output head]].
<!-- bilingual-en:end -->

参数量数的是模型要保存、学习的数。训练数据规模数训练过程使用的词元量。上下文长度（context length）限制一次输入可以容纳的位置数。论文里的“更大的模型”“更多训练数据”和“更长上下文”对应三个不同的量。可回查[[00_Knowledge/语言模型输出头|语言模型输出头]]。

## 1.3 Where a training target comes from
<!-- bilingual-en:end -->

*预训练、监督微调和奖励信号*

<!-- bilingual-en:start -->
In pretraining, ordinary text supplies both inputs and targets. Use a prefix as input and the next observed token as the target. The loss compares the model’s distribution with that observed ID. A gradient-based optimizer uses many such comparisons to update shared parameters. This is self-supervised learning. The resulting pretrained model provides a starting point for later adaptation.
<!-- bilingual-en:end -->

预训练（pretraining）能使用普通文本，因为一段文字本身就能出题和给答案。把前缀作为输入，把原文紧接着的词元作为目标（target）。在一个位置，模型给真实词元的概率越高，该位置的训练损失（loss）越小，优化器（optimizer）利用梯度（gradient）更新共享参数。这种从数据自身取得监督信号的方式叫自监督学习（self-supervised learning）。预训练后的权重可作为后续训练的起点，即基座模型（base model）。

<!-- bilingual-en:start -->
Instruction tuning is one form of supervised fine-tuning (SFT). An instruction and its context lead to a reference response. For example, the prompt can request a polite rewrite of a particular email, while the demonstration supplies the desired wording. In the usual response-supervised setup, next-token training on the reference response reinforces the demonstrated behavior. Classification fine-tuning instead uses task labels, such as a spam label. See [[00_Knowledge/SFT目标|the SFT objective]].
<!-- bilingual-en:end -->

指令微调（instruction tuning）是监督微调（supervised fine-tuning, SFT）的一种。输入可以是“请把下面这封邮件改得更礼貌”加邮件全文，参考回答则是一封具体的改写稿。训练时可以在回答位置逐词元学习示范写法。做分类微调（classification fine-tuning）时，样本也可以是邮件与“垃圾邮件”等类别标签。这里区分的是监督信号来自哪里。见[[00_Knowledge/SFT目标|监督微调的目标]]。

<!-- bilingual-en:start -->
For the later paper-reading route, the corresponding distinction in reinforcement learning (RL) is that a policy produces a response and receives a reward signal that evaluates it. A demonstrated answer and an evaluated sampled answer play different roles. Keep this distinction available when reading about post-training.
<!-- bilingual-en:end -->

以后读智能体记忆（agent memory）论文时，可以先辨认学习信号的来源。SFT 学给定的示范回答。强化学习（reinforcement learning, RL）可以让策略（policy）先采样回答，再用奖励（reward）评价它。两者都可能更新模型参数，决定训练目标的数据来源不同。

## 1.4–1.6 How a prompt becomes a continuation
<!-- bilingual-en:end -->

*固定参数怎样完成不同任务*

<!-- bilingual-en:start -->
GPT stands for Generative Pre-trained Transformer. The GPT architecture in this course uses the decoder-only part of the Transformer family. A causal visibility rule lets an output at position $t$ depend on the prefix through $t$. A translation request and a question-answering request give the same weights different conditioning text. Examples included in a prompt can specify a task pattern during inference (in-context learning).
<!-- bilingual-en:end -->

GPT 是生成式预训练 Transformer（Generative Pre-trained Transformer）。本书构建的是仅解码器架构（decoder-only architecture），每个位置按因果可见性使用截至当前位置的输入。同一组权重看到“把它译成英文”和“解释它的意思”，会因条件不同而给出不同的续写分布。提示（prompt）还可以包含几组示范，使模型在当前上下文中延续给定格式，这叫上下文学习（in-context learning）。

<!-- bilingual-en:start -->
Autoregressive generation repeatedly evaluates a prefix, selects a token using a decoding rule, appends it, and evaluates the longer prefix. Greedy decoding picks the largest probability, while sampling draws from the distribution. In ordinary inference the prefix grows with each step while the learned weights stay fixed.
<!-- bilingual-en:end -->

自回归生成（autoregressive generation）根据已有前缀算出分布，选一个词元，接到末尾，再用更长的前缀往下生成。贪心解码（greedy decoding）取概率最大的候选，采样（sampling）按分布抽取。推理（inference）期间，这种逐步变化发生在输入上下文里，既有权重保持固定。

## 1.7 Building a model from scratch
<!-- bilingual-en:end -->

*从零构建时，各步骤各创造了什么*

<!-- bilingual-en:start -->
An architecture specifies operations and parameter shapes. Initialization gives those parameters starting values. Training data, an objective and an optimizer then turn those initial values into learned weights. Running the resulting model uses the learned mapping. The book builds text inputs in Chapter 2, assembles the network in later chapters, then trains it. Preparing the inputs yields batches ready for the training loop.
<!-- bilingual-en:end -->

从零构建时，模型架构（architecture）先规定有哪些运算、需要哪些形状的参数。初始化（initialization）给参数起始值。再引入数据、目标函数（objective）和优化器，才把初始值训练成有用的权重。第二章先把一篇原文变成模型可以读取的输入，并给每个位置配上对应的目标。
