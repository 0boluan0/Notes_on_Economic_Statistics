Week by week

The main topic of each week and the assessment it prepares you for.

Week1

Data, data types and reproducible workflows

What data is, how it is structured and typed, the international standards behind data types, and working reproducibly with Git and GitHub.

Prepares you for  Problem Set 1 Project

Week2

Collecting data from the web

Getting data from files, APIs and web pages, and the legal and ethical checks that come before any collection.

Prepares you for  Project Problem Set 1

Week3

Representing data in NumPy and pandas

How arrays and data frames store numbers, text and dates, and how to choose types and indexes deliberately.

Prepares you for  Problem Set 1 Project

Week4

Cleaning and preprocessing data

Finding and fixing data quality problems, building a reproducible cleaning workflow, and justifying every decision.

Prepares you for  Project

Week5

Relational and non-relational databases

Building databases, carrying out create, read, update and delete operations, and joining sources on common keys.

Prepares you for  Problem Set 2 Project

Week6

Reading week

No teaching. Time to consolidate Weeks 1 to 5 before the visualisation half of the module begins.

Week7

Exploratory data analysis and effective visualisation

A repeatable way to explore a dataset, and the principles of visual perception behind a good chart.

Prepares you for  Project

Week8

Statistical graphics and graphical diagnostics

Showing distributions, relationships, uncertainty and model assumptions, and stating insights with evidence.

Prepares you for  Project

Week9

Visualising and communicating model performance

Reading model evaluation plots and explaining a model's performance.

Prepares you for  Project

Week10

Dimensionality reduction for visualisation

Seeing structure in high-dimensional data.

Prepares you for  Project

Week11

Graph data and communicating decisions

Visualising networks, and turning an analysis into a clear recommendation for a named audience.

Prepares you for  Project

After Week 11: submit your project
The coursework project is due at 12:00 on the Monday immediately after Week 11. Submit your GitHub repository, your report and your AI-use statement.

Dates are by teaching week. Full details are in each assessment brief on Moodle.
