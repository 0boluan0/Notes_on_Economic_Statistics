# FlashAttention：分块如何保持精确？

← [[dao2022FlashAttentionFastMemoryEfficient|返回论文脉络]] · [[FlashAttention 原文.pdf#page=5|本段原文：Algorithm 1，p.5]]

这部分要解释两件事：如何在没有完整权重矩阵的情况下得到原来的输出，以及训练反向传播为什么也可以省下中间矩阵。

## 先解决“每块分母不同”

逐块读入数据时，一个 query 还没有见过所有 key。新的分数到来后，Softmax 的分母会变化，旧块对输出的贡献也必须相应调整。

已有原子 [[在线Softmax合并]] 正好回答这个问题：每块保留最大分数 $m$、指数和 $\ell$、未归一化的 value 加权和 $u$；把新旧两块换到同一个最大值，再合并。需要直觉时，可先看 [[在线Softmax合并#三个位置的手算|三个位置的手算]]：正确合并得到 6，简单平均两块输出却得到 5。

读回论文时有一个记号差异：原子用 $u$ 表示未归一化加权和，Algorithm 1 保存的是已归一化输出 $O$。对单行来说，两者通过

$$
u=\ell O
$$

联系起来。因此，Algorithm 1 第 12 行中的 $\ell_i O_i$ 是把旧输出恢复成可合并的加权和；重标定、加入新块后，再除以新的 $\ell_i$。向量形式使用对角矩阵，就是对每个 query 行分别做这件事。

## 按这个问题去读 Algorithm 1

| 原文位置 | 在解决什么 | 读完应看到的作用 |
| --- | --- | --- |
| 第 1–4 行 | 片上空间放不下整个矩阵 | 按 SRAM 容量划分块，初始化输出与归一化统计量 |
| 第 5–9 行 | 如何使用已经搬进来的数据 | 外层加载一块 $K,V$，内层遍历 $Q$ 块，在片上计算局部分数 |
| 第 10–12 行 | 新块会改变整行分母 | 更新最大值与指数和，重标定旧输出并合入新贡献 |
| 第 13–16 行 | 下次继续计算要留下什么 | 保存累计状态，继续遍历，最终得到完整输出 |

处理完的分数块可以释放；完整的 $S$、$P$ 不必在 HBM 中落地。dense 版本仍会处理所有需要的 query–key 块对。**分块改变了执行和存储方式，保持了同一个注意力目标。** [[FlashAttention 原文.pdf#page=5|对照 Algorithm 1 与 Theorem 1]]

## 为什么反向传播要重新计算？

如果训练时为了求梯度而保留完整 $S$、$P$，前向省下的空间又会被占用。论文改为保留输入、输出和归一化统计量，在反向传播时按需重新计算相应分数与权重块。

这增加了一些运算，却避免了大矩阵的存储和往返。收益最终取决于“多算一些”与“少搬一些”在具体硬件上的代价；[[FlashAttention - 证据与贡献边界#哪些证据分别回答什么|Figure 2 的实验]]用实际耗时检验了这个判断。

## 与已有原子如何分工？

[[在线Softmax合并]] 保留可以复用于其他分块场景的合并规则；这份笔记解释该规则在论文算法中的记号、循环和用途。[[FlashAttention]] 则提供整个算法的可复用定义与适用边界。

这里的“精确”指相同输入、缩放和掩码下的数学运算等价；浮点运算顺序变化仍可能带来舍入差异。论文 §3.3 的 block-sparse 扩展进一步省略某些块，应与 dense 主算法分别理解。
