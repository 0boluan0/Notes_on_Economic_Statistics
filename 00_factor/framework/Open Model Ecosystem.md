# Open Model Ecosystem

Open Model Ecosystem 解释开放权重、开放技术报告和闭源 API 路线如何共同塑造 LLM 行业竞争。

## 核心直觉
开放模型降低部署和研究门槛，闭源模型保持产品体验和前沿能力竞争；企业选择时还要考虑成本、安全、合规和可控性。

## 什么时候用

- 选择自托管、开放权重模型或闭源 API 时。
- 比较模型能力之外的许可证、数据治理、部署、供应商锁定和总成本时。

## 关键假设

- “开放”要拆成权重、代码、数据、训练细节和许可证，而不是单一标签。
- 评测结果能代表目标语言、任务、硬件和吞吐约束。

## 失败模式

- 只比较 benchmark 会忽略推理运维、安全补丁、许可证限制和数据外泄风险。
- 开放权重不等于可商用、可复现或低成本；需逐项核验发布条款。
