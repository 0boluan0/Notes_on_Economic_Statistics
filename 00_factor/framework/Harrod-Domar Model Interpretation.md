# Harrod-Domar Model Interpretation

## 什么时候用

当题目强调发展中国家资本短缺、储蓄率、投资率、资本产出比，或要求解释“刃锋问题”时，用这张框架卡。

## 为什么这样看

模型把增长限制在固定比例生产结构里：资本和劳动不能顺畅替代。因此资本充分利用增长率和劳动充分就业增长率必须精确匹配。

## 题型识别

- “保证增长率”：写 $G_W=Vs$。
- “自然增长率”：写 $G_N=n$。
- “均衡增长条件”：写 $Vs=n$。
- “刃锋问题”：说明 $Vs$ 和 $n$ 稍有偏离，经济就偏离充分利用或充分就业。
- “与 Solow 比较”：强调 Solow 允许资本和劳动替代，因此稳态更稳定。

## 边界条件

- 固定资本产出比。
- 储蓄全部转化为投资。
- 没有技术进步。
- 资本和劳动不可替代。

## 失败模式

- 把 $G_W$ 误解成现实必然增长率。
- 忽略自然增长率，导致只谈资本不谈就业。
- 用 Harrod-Domar 解释长期技术进步，这超出模型能力。
