# NSFR（净稳定资金比率）

## 诊断目的

衡量银行在1年期压力情景下，可用的稳定资金是否足以支持其资产和表外业务所需的稳定资金，约束银行的期限错配风险。

## 计算方法

$\text{NSFR} = \frac{\text{可得稳定资金（ASF）}}{\text{所需稳定资金（RSF）}} \geq 100\%$

### ASF 因子（负债与资本）

| 资金来源 | ASF 因子 | 说明 |
|----------|----------|------|
| 普通股、留存收益 | 100% | 最稳定的资金 |
| 优先股、次级债 | 100% | 次级资本工具 |
| 零售存款（稳定） | 95% | 相对稳定 |
| 零售存款（不稳定） | 90% | 可能较快流失 |
| 批发性融资（<1年） | 50% | 期限错配风险高 |
| 无日期批发性融资 | 0% | 最不稳定 |

### RSF 因子（资产）

| 资产类别 | RSF 因子 | 说明 |
|----------|----------|------|
| 现金、短期政府债 | 0% | 无稳定资金需求 |
| 1年期以内贷款 | 85% | 需要稳定资金支持 |
| 1-5年期贷款 | 50% | 部分期限匹配 |
| >5年期贷款 | 100% | 完全需要稳定资金 |
| 住房按揭 | 65% | 相对稳定 |

## 判断标准

| NSFR水平 | 评价 | 风险含义 |
|----------|------|----------|
| > 125% | 优秀 | 期限匹配良好 |
| 100.1-125% | 健康 | 基本满足要求 |
| 90-100% | 关注 | 存在期限错配 |
| < 90% | 危险 | 严重期限错配 |

## 常见问题与对策

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| NSFR低于100% | 长期资产过多、短期负债依赖度高 | 增发长期债、吸收稳定存款、减少长期资产 |
| 长期贷款占比过高 | 业务结构偏重长期信贷 | 发展短期资产业务、证券化部分长期资产 |
| 批发性融资波动大 | 市场流动性依赖度高 | 增加零售存款比重、建立应急融资渠道 |
