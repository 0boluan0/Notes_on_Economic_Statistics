# DID Diagnostics

## 诊断清单
- 平行趋势：处理前事件研究系数接近 0。
- 预期效应：政策前窗口无显著提前反应。
- 溢出效应：对照组不被间接受到处理影响。
- 组成变化：样本进入/退出或权重变化可控。

## 稳健性与替代规格
- 不同前后窗口、不同对照组。
- 加入控制变量与趋势项。
- 使用分组/加权 DID 或异质处理效应分解。

## 典型问题与排错
- 前趋势不平行：缩小窗口、改对照组、加趋势项，或更换识别策略。
- 处理时间错位：避免简单 TWFE，改用分期估计。
- 处理溢出：扩大处理范围或重定义对照组。

## 复现规范
- 固定样本口径、时间窗口、处理定义。
- 明确聚类维度与标准误计算方式。
