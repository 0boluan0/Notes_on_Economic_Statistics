# 判定系数（R²）

## 诊断目的

衡量回归模型对因变量变异的解释程度，评估模型的拟合优度和预测能力。

## 计算方法

$$R^2 = \frac{\text{ESS}}{\text{TSS}} = 1 - \frac{\text{RSS}}{\text{TSS}} = 1 - \frac{\sum e_i^2}{\sum (y_i - \bar{y})^2}$$

其中：
- TSS（总平方和）：$\sum (y_i - \bar{y})^2$，因变量的总变异
- ESS（回归平方和）：$\sum (\hat{y}_i - \bar{y})^2$，模型解释的变异
- RSS（残差平方和）：$\sum e_i^2$，模型未解释的变异

### 调整后判定系数（Adjusted R²）

$$\bar{R}^2 = 1 - \frac{RSS/(n-k-1)}{TSS/(n-1)} = 1 - (1-R^2)\frac{n-1}{n-k-1}$$

其中：
- n：样本容量
- k：解释变量个数

## 判断标准

| R²值范围 | 解释程度 | 评价 |
|----------|----------|------|
| 0.8-1.0 | 80-100% | 极好拟合 |
| 0.6-0.8 | 60-80% | 良好拟合 |
| 0.4-0.6 | 40-60% | 中等拟合 |
| 0.2-0.4 | 20-40% | 较差拟合 |
| 0-0.2 | 0-20% | 很差拟合 |

### 注意事项

- **时间序列数据**：R²通常较高，但不一定代表模型良好
- **横截面数据**：R²普遍较低，0.3-0.5可能是正常水平
- **R²与变量数量**：增加解释变量会提高R²，但不一定改善模型
- **伪高R²**：可能由数据挖掘、过拟合、多重共线性导致

## 常见问题与对策

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| R²过高但模型不稳定 | 过拟合、多重共线性 | 减少变量、使用正则化、检查VIF |
| R²过低但F检验显著 | 随机误差太大 | 增加样本、改进模型设定 |
| R²增加但Adjusted R²下降 | 增加了无关变量 | 删除不显著的变量 |
| R²无法用于比较不同模型 | 因变量尺度不同 | 使用标准化R²或信息准则（AIC/BIC） |
