# Endogeneity Diagnosis

## 诊断目标

判断解释变量是否可能与误差项相关，并决定采用控制变量、工具变量、面板方法或准实验设计。

## 先判来源

| 来源 | 典型问题 |
| --- | --- |
| 遗漏变量 | 未观测能力、地区特质、企业管理质量 |
| 联立性 | 价格和数量同时由供需决定 |
| 测量误差 | 解释变量含报告误差或代理误差 |
| 样本选择 | 样本进入机制与结果相关 |

## 诊断流程

### Step 1：用理论先判断

内生性不能只靠统计检验发现。先问：是否存在同时影响 $X$ 和 $Y$、但没进模型的因素？

### Step 2：做可用检验

- OLS vs IV 差异：[[Hausman Test]] / Durbin-Wu-Hausman。
- 工具变量强度：第一阶段 F 统计量。
- 工具变量外生性：Sargan/Hansen 过度识别检验。

### Step 3：选择处理方式

| 情况 | 方法 |
| --- | --- |
| 有强且外生的工具变量 | [[2SLS]] |
| 不随时间变化的遗漏变量 | [[Fixed Effects Model]] |
| 政策冲击有处理组和对照组 | [[DID]] |
| 阈值规则分配处理 | RDD |
| 只是标准误问题 | 不要误用 IV，改稳健标准误 |

## 常见错误

- 把异方差、自相关误判为内生性。
- 使用弱工具变量，结果比 OLS 更糟。
- 只报告 Hausman 显著，不解释内生性的经济机制。
- 工具变量相关但不外生。
