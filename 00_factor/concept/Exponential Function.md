# Exponential Function

指数函数以变量为指数。对 $a>0$，$a\ne1$，

$$
\frac{d}{dx}a^x=a^x\ln a.
$$

自然指数函数 $e^x$ 是唯一满足 $f'=f$ 且 $f(0)=1$ 的指数函数。

## 最小例子

$(2^x)'=2^x\ln2$，而 $(e^x)'=e^x$。
