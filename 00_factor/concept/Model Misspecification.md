# Model Misspecification

## 它是什么
- 「Model Misspecification」是指模型形式与真实数据生成过程不一致。

## 最小可检索信息
- 定义：模型形式与真实数据生成过程不一致。
- 符号/公式：无固定符号。
- 最小例子：遗漏关键变量导致系数偏误。
