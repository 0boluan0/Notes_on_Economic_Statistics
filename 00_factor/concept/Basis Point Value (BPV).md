# Basis Point Value (BPV)

## 它是什么
- 「Basis Point Value (BPV)」是指利率上升1个基点时债券价格的变化量（又称DV01）。

## 最小可检索信息
- 定义：利率上升1个基点时债券价格的变化量（又称DV01）。
- 符号/公式：$\mathrm{BPV}\approx -P\,D\,0.0001$。
- 最小例子：价格98、修正久期7的债券，BPV约0.0686。
