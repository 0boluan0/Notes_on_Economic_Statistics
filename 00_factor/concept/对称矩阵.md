对称矩阵（Symmetric Matrix）是满足转置等于自身的方阵：Aᵀ = A。

## 定义

对于n×n矩阵A，如果对于所有i, j都有：
a_ij = a_ji

则A是对称矩阵。

### 等价定义

Aᵀ = A

## 性质

### 基本性质

1. **对称矩阵一定是方阵**
2. **转置保持对称性**：(Aᵀ)ᵀ = A
3. **和保持对称性**：若A、B对称，则A + B对称
4. **数乘保持对称性**：若A对称，则cA对称

### 特征值性质

1. **特征值全为实数**
2. **对应不同特征值的特征向量正交**
3. **可正交对角化**：A = QΛQᵀ

其中：
- Q是正交矩阵（Qᵀ = Q⁻¹）
- Λ是对角矩阵，包含实特征值

### 构造对称矩阵

任何矩阵A乘以其转置都是对称矩阵：
- AᵀA是对称矩阵
- AAᵀ是对称矩阵

## 对称矩阵的分解

### 谱分解（Spectral Decomposition）

A = λ₁v₁v₁ᵀ + λ₂v₂v₂ᵀ + ... + λₙvₙvₙᵀ

其中λᵢ是特征值，vᵢ是对应的归一化特征向量。

### Cholesky分解

对于正定对称矩阵A，存在下三角矩阵L使得：
A = LLᵀ

### 特征分解

A = QΛQᵀ

## 特殊对称矩阵

### 正定矩阵

对于任意非零向量x，都有xᵀAx > 0。

- 特征值全为正
- 可进行Cholesky分解
- 是可逆矩阵

### 半正定矩阵

对于任意向量x，都有xᵀAx ≥ 0。

- 特征值非负
- 行列式非负

### 负定矩阵

对于任意非零向量x，都有xᵀAx < 0。

- 特征值全为负
- 奇数阶行列式为负

### 反对称矩阵

满足Aᵀ = -A。

- 主对角线元素为零
- 特征值成对出现（λ和-λ）

## 应用

### 二次型

对称矩阵自然地对应二次型：
Q(x) = xᵀAx

### 几何

- 描述二次曲面
- 惯性张量
- 应力应变张量

### 优化

- 梯度矩阵（Hessian矩阵）是对称的
- 正定保证局部极小值

### 统计

- 协方差矩阵是对称正定矩阵
- 相关矩阵
