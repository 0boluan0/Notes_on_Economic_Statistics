# Present Value

## 它是什么
- 「Present Value」是指未来现金流折算到当前的价值。

## 最小可检索信息
- 定义：未来现金流折算到当前的价值。
- 符号/公式：$PV=\frac{CF_t}{(1+r)^t}。$
- 最小例子：一年后100元在5%折现下的现值约95.24。
