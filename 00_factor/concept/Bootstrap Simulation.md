# Bootstrap Simulation

## 它是什么
- 「Bootstrap Simulation」是指通过对样本进行有放回重抽样来近似统计量分布的方法。

## 最小可检索信息
- 定义：通过对样本进行有放回重抽样来近似统计量分布的方法。
- 符号/公式：从样本 $\{$x_i$\}$ 抽取 $B$ 次重样本并计算统计量 $T^*$。
- 最小例子：用bootstrap估计均值的95%置信区间。
