怀特检验（White Test）是怀特提出的用于检验异方差的一般性检验方法，不需要假设异方差的具体形式。

## 检验思想

检验残差平方是否与解释变量、其平方项及交叉乘积项相关，从而判断是否存在异方差。

## 检验形式

### 1. 完整怀特检验

#### 辅助回归

将残差平方对解释变量、其平方项、交叉乘积项回归：

$\hat{\epsilon}_i^2 = \alpha_0 + \alpha_1 x_{1i} + \alpha_2 x_{2i} + \dots + \alpha_k x_{ki} + \beta_1 x_{1i}^2 + \beta_2 x_{2i}^2 + \dots + \beta_k x_{ki}^2 + \gamma_1 x_{1i}x_{2i} + \gamma_2 x_{1i}x_{3i} + \dots + \mu_i$

#### 原假设

$H_0$: $\alpha_1 = \alpha_2 = \dots = \alpha_k = \beta_1 = \beta_2 = \dots = \beta_k = \gamma_1 = \gamma_2 = \dots = 0$

即不存在异方差。

#### 统计量

$LM = n \cdot R^2$

其中：
- $n$是样本量
- $R^2$是辅助回归的决定系数（未修正）

#### 分布

$LM \sim \chi^2(k')$

其中$k'$是辅助回归中解释变量个数（不包括常数项）。

### 2. 简化怀特检验

#### 问题

完整怀特检验中，交叉乘积项太多：
- 变量多时自由度损失太大
- 估计效率低

#### 解决方法

只对解释变量及其平方项回归：

$\hat{\epsilon}_i^2 = \alpha_0 + \alpha_1 x_{1i} + \alpha_2 x_{2i} + \dots + \alpha_k x_{ki} + \beta_1 x_{1i}^2 + \beta_2 x_{2i}^2 + \dots + \beta_k x_{ki}^2 + \mu_i$

#### 原假设

$H_0$: $\alpha_1 = \alpha_2 = \dots = \alpha_k = \beta_1 = \beta_2 = \dots = \beta_k = 0$

#### 统计量

$LM = n \cdot R^2 \sim \chi^2(2k)$

其中$2k$是$k$个解释变量加$k$个平方项。

## 检验步骤

### 标准流程

1. **估计原模型**
   - 用OLS估计原始回归模型
   - 得到残差$\hat{\epsilon}_i$

2. **计算残差平方**
   - 计算$\hat{\epsilon}_i^2$

3. **构建辅助回归**
   - 选择完整形式或简化形式
   - 进行回归

4. **计算统计量**
   - $LM = n \cdot R^2$

5. **进行检验**
   - 与$\chi^2$临界值比较
   - 或计算p值

### 判断标准

- 若$LM > \chi^2_{\alpha}(k')$，拒绝原假设，存在异方差
- 若$LM \leq \chi^2_{\alpha}(k')$，不能拒绝原假设，不存在异方差

## 与布鲁什-帕甘检验的比较

| 特征 | 怀特检验 | 布鲁什-帕甘检验 |
|------|----------|----------------|
| 异方差形式 | 不假设具体形式 | 假设方差与解释变量相关 |
| 辅助回归 | 包含平方项和交叉项 | 不包含平方项和交叉项 |
| 自由度 | 通常较大 | 较小 |
| 一般性 | 更一般 | 特定形式 |
| 计算复杂度 | 较高 | 较低 |

## 优点

### 1. 一般性

- 不需要假设异方差的具体形式
- 可以检测多种类型的异方差
- 比BP检验更全面

### 2. 易于实施

- 只需要残差平方的回归
- 统计量计算简单
- 大多数软件都有内置功能

### 3. 稳健性

- 对异方差形式稳健
- 适用于各种情况

## 缺点

### 1. 自由度损失

- 完整检验中自由度损失大
- 变量多时检验能力下降
- 简化形式部分缓解

### 2. 检验能力

- 大样本下检验能力更强
- 小样本下检验能力较弱
- 样本量很重要

### 3. 多重共线性

- 辅助回归中可能存在多重共线性
- 影响估计效果
- 但不影响检验渐近性质

## 扩展

### 1. 怀特检验与HC标准误

怀特检验的结果可以用于计算怀特异方差一致标准误（HC标准误）。

### 2. 特定异方差形式

如果怀疑特定形式的异方差：
- 可以使用更针对性的检验
- 如BP检验
- 可能更有效

### 3. 面板数据

面板数据中也有相应的怀特检验形式。

## 实践应用

### 1. 诊断

- 作为异方差的诊断工具
- 通常是第一步检查

### 2. 后续处理

检验发现异方差后：
- 使用稳健标准误
- 使用WLS或FGLS
- 变量变换

### 3. 报告

在实证研究中：
- 报告怀特检验结果
- 说明异方差处理方法
- 确保结论稳健
