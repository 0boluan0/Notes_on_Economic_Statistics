奇异矩阵（Singular Matrix）是不可逆的方阵，其行列式为零。

## 定义

n×n方阵A是奇异矩阵，当且仅当满足以下等价条件之一：

1. det(A) = 0
2. A不可逆（不存在A⁻¹）
3. rank(A) < n
4. A的列向量线性相关
5. A的行向量线性相关
6. 存在非零向量x，使得Ax = 0

## 等价条件

### 行列式条件

det(A) = 0

### 秩的条件

rank(A) < n

其中n是矩阵的阶数。

### 线性相关性

A的列向量（或行向量）线性相关，意味着至少有一个列向量可以表示为其他列向量的线性组合。

### 零空间条件

存在非零向量x∈N(A)，使得Ax = 0。

## 与非奇异矩阵的对比

| 性质 | 奇异矩阵 | 非奇异矩阵 |
|------|----------|------------|
| 可逆性 | 不可逆 | 可逆 |
| 行列式 | det(A) = 0 | det(A) ≠ 0 |
| 秩 | rank(A) < n | rank(A) = n |
| 零空间 | 维数 > 0 | 只有零向量 |
| 线性相关性 | 列（行）线性相关 | 列（行）线性无关 |

## 几何解释

### 线性变换

奇异矩阵对应的线性变换将空间"压缩"到低维空间：

- 在R²中：将整个平面压缩为一条直线或原点
R³中：将整个空间压缩为一个平面、直线或原点

### 零空间

奇异矩阵的零空间包含非零向量，这些向量被映射为零向量。

## 求解线性方程组

### 齐次方程组Ax = 0

- 有非零解
- 解空间的维数 = n - rank(A)
- 存在无穷多解

### 非齐次方程组Ax = b

- 可能无解
- 如果有解，有无穷多解（特解 + 零空间的任意线性组合）
- 解的存在性取决于b是否属于A的列空间

## 例子

### 对角矩阵

diag(1, 2, 0)是奇异矩阵，因为包含零对角元。

### 行相同的矩阵

[[1, 2],
 [1, 2]]

是奇异矩阵，因为两行相同，行列式为0。

### 列线性相关的矩阵

[[1, 2],
 [2, 4]]

是奇异矩阵，因为第二列是第一列的2倍。

## 性质

1. 奇异矩阵的行列式为零
2. 奇异矩阵的特征值至少有一个为零
3. 奇异矩阵至少有一个特征值为零
4. 奇异矩阵的秩小于阶数

## 在实际计算中

### 数值判断

在实际计算中，由于浮点误差，判断矩阵是否奇异通常使用：

- 检查最小奇异值是否接近零
- 检查条件数是否过大
-条件数 = 最大奇异值 / 最小奇异值

### 避免

许多算法需要矩阵非奇异，因此需要：
- 检查矩阵条件数
- 使用正则化方法
- 使用伪逆（Moore-Penrose逆）
