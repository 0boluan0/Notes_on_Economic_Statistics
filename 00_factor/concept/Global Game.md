# Global Game

## 一句话记忆

全局博弈是私人信号彼此相关的贝叶斯博弈：知道自己的信号，也会改变对别人信号的判断。

## 它是什么

Global Game 在不完全信息中加入相关信号。玩家观察到自己的私人信号后，会据此推断其他玩家可能观察到什么。

## 解决什么判断

- 为什么自己的类型会影响对别人类型的 belief。
- 为什么协调问题在小噪声下可能出现唯一阈值策略。
- 招标、攻击、挤兑等战略互补问题如何被不完全信息筛选。

## 最小例子

政府招标中，公司观察到自己的成本估计后，也会推断竞争对手的成本估计大概在哪个范围。

## 易混点

- 普通贝叶斯博弈的类型可能独立；全局博弈强调信号相关。
- 不确定性不一定增加均衡数量，有时反而筛选出更确定的阈值结果。
