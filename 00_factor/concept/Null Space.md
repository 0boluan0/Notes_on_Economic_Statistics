零空间（Null Space）又称核（Kernel），是矩阵A的所有满足齐次方程Ax = 0的解向量x构成的集合。

## 定义

对于m×n矩阵A，零空间定义为：
N(A) = {x∈Rⁿ : Ax = 0}

零空间是Rⁿ的子空间。

## 求解零空间

### 步骤

1. **构造增广矩阵**：将A与零向量拼接为[A|0]
2. **高斯消元**：将矩阵化为行阶梯形式（REF）或简化行阶梯形式（RREF）
3. **识别主列和自由列**：
   - 主列（Pivot Columns）：包含主元的列
   - 自由列（Free Columns）：不包含主元的列
4. **求特解**：对每个自由列赋值1，其他自由列赋值0，求出对应主列的值
5. **通解**：所有特解的线性组合

### 自由变量个数

对于m×n矩阵，若rank(A) = r，则：
- 自由变量个数 = n - r
- 零空间的维数 = n - r

## 几何意义

### R²情况

- 满秩矩阵（r=2）：零空间只包含原点{0}
- 奇异矩阵（r=1）：零空间是一条过原点的直线
- 零矩阵（r=0）：零空间是整个平面R²

### R³情况

- 满秩矩阵（r=3）：零空间只包含原点{0}
- 亏秩矩阵（r=2）：零空间是一条过原点的直线
- 亏秩矩阵（r=1）：零空间是过原点的平面
- 零矩阵（r=0）：零空间是整个空间R³

## 与列空间的关系

### 秩-零化度定理

对于m×n矩阵A：
rank(A) + nullity(A) = n

其中：
- rank(A) = 列空间的维数 = r
- nullity(A) = 零空间的维数 = n - r

### Ax = b的解

当b∈C(A)时，方程Ax = b的解为：
x = x_p + x_n

其中：
- x_p是特解
- x_n∈N(A)是零空间中的任意向量

## 重要性质

1. 零空间总是包含零向量0
2. 如果零空间只有零向量，则A是列满秩的
3. 可逆矩阵的零空间只有零向量
4. 奇异矩阵的零空间维数大于0
