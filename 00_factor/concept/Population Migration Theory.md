# Population Migration Theory

## 它是什么
- 「Population Migration Theory」是指解释人口迁移动因与规律的理论（如推拉因素、人力资本等）。

## 最小可检索信息
- 定义：解释人口迁移动因与规律的理论（如推拉因素、人力资本等）。
- 符号/公式：无固定符号。
- 最小例子：收入差距与就业机会推动劳动力迁移。
