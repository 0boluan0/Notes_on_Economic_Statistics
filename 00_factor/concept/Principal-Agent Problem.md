# Principal-Agent Problem

## 它是什么
- 「Principal-Agent Problem」是指委托人无法完全观察代理人行为导致的激励与信息不对称问题。

## 最小可检索信息
- 定义：委托人无法完全观察代理人行为导致的激励与信息不对称问题。
- 符号/公式：无固定符号。
- 最小例子：股东与经理人的目标不一致。
