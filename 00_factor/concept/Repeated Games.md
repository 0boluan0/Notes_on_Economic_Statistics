# Repeated Games

## 一句话记忆

重复博弈是同一个阶段博弈多次发生，使今天的行动影响未来惩罚或合作的博弈。

## 它是什么

Repeated game 把一次性博弈放进多期互动中。玩家可以根据历史行动调整当前策略。

## 解决什么判断

- 为什么一次性囚徒困境难以合作。
- 为什么没有确定终点时合作可能维持。
- 未来惩罚如何改变今天的偏离激励。

## 最小例子

两家公司反复定价。如果今天降价会引发未来长期价格战，那么厂商可能选择维持高价。

## 易混点

- 有确定最后一期的有限重复囚徒困境，逆向归纳通常会推回每期背叛。
- 没有确定终点或无限重复时，未来惩罚才可能支撑合作。
- 重复博弈的策略依赖历史，不只是每期重复同一个行动。
