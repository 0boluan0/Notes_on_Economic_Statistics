向量空间（Vector Space）也称线性空间，是线性代数中的基本概念，指对加法和数乘两种运算封闭的集合。

## 定义

一个向量空间V是域F（通常指实数域R或复数域C）上的集合，满足以下条件：

### 封闭性

1. **加法封闭**：对任意u, v∈V，有u + v∈V
2. **数乘封闭**：对任意u∈V，标量α∈F，有αu∈V

### 公理要求

对任意u, v, w∈V和标量α, β∈F：

1. **加法结合律**：(u + v) + w = u + (v + w)
2. **加法交换律**：u + v = v + u
3. **加法单位元**：存在零向量0∈V，使得u + 0 = u
4. **加法逆元**：对每个u∈V，存在-u∈V，使得u + (-u) = 0
5. **数乘分配律**：α(u + v) = αu + αv
6. **标量分配律**：(α + β)u = αu + βu
7. **数乘结合律**：α(βu) = (αβ)u
8. **数乘单位元**：1u = u

## 常见向量空间

### Rⁿ空间

Rⁿ表示所有n维实数向量的集合：
- R²：二维平面
- R³：三维空间

### 函数空间

所有定义在某个区间上的实值函数集合，对函数的加法和数乘封闭。

## 相关概念

### 线性组合

给定向量v₁, v₂, ..., vₖ和标量c₁, c₂, ..., cₖ，表达式：
c₁v₁ + c₂v₂ + ... + cₖvₖ

称为这些向量的线性组合。

### 基和维数

向量空间的基是线性无关且能生成整个空间的向量集合。基中向量的个数称为维数。

## 性质

1. 零向量0是唯一的
2. 每个向量u的负向量(-u)是唯一的
3. 对任意标量α，α·0 = 0
4. 对任意向量u，0·u = 0
5. 若αu = 0，则α = 0或u = 0
