单位根检验（Unit Root Test）用于检验时间序列是否包含单位根，即是否为非平稳过程。

## 基本思想

检验时间序列是否为I(1)过程（一阶单整）。若存在单位根，则序列非平稳；若不存在单位根，则序列平稳。

## 主要检验方法

### 1. DF检验（Dickey-Fuller Test）

**模型形式：**

1. 无趋势无截距：Δy_t = φy_{t-1} + ε_t
2. 有截距无趋势：Δy_t = α + φy_{t-1} + ε_t
3. 有截距有趋势：Δy_t = α + βt + φy_{t-1} + ε_t

**原假设H₀**：φ = 0（存在单位根，非平稳）
**备择假设H₁**：φ < 0（不存在单位根，平稳）

**临界值**：使用DF分布表（非标准t分布）

### 2. ADF检验（Augmented Dickey-Fuller Test）

**模型形式：**

$$\Delta y_t = \alpha + \beta t + \phi y_{t-1} + \sum_{i=1}^{p} \gamma_i \Delta y_{t-i} + \varepsilon_t$$

**与DF的区别**：增加了滞后差分项Δy_{t-i}以消除误差项自相关

**滞后阶数选择**：使用信息准则（AIC, BIC）

### 3. PP检验（Phillips-Perron Test）

**特点：**
- 非参数方法，考虑误差项的异方差和自相关
- 使用修正的t统计量

### 4. KPSS检验

**与ADF/PP相反：**
- 原假设H₀：序列是平稳的
- 备择假设H₁：序列非平稳

## 检验步骤

1. **选择检验模型**：根据图形决定是否包含截距和趋势
2. **选择滞后阶数**：使用信息准则
3. **计算检验统计量**：估计模型得到t统计量
4. **比较临界值**：若t统计量 < 临界值，拒绝存在单位根的假设
5. **判断平稳性**：拒绝H₀意味着序列平稳

## 单整阶数I(d)

- I(0)：平稳序列
- I(1)：一阶差分后平稳（Δy_t平稳）
- I(d)：d阶差分后平稳

## 注意事项

1. **检验结果对模型设定敏感**：截距和趋势项的选择影响结果
2. **样本量要求**：小样本下检验功效较低
3. **结构突变**：存在结构突变时，传统检验可能失效
