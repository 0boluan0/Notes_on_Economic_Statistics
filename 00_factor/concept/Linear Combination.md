# Linear Combination

>[!note] 它是什么
> - 「Linear Combination」是指向量的加权和。
>
>[!note] 最小可检索信息
> - 定义：向量的加权和。
> - 符号/公式：$\sum_i a_i v_i$。
> - 最小例子：$2v_1-3v_2$。
>
