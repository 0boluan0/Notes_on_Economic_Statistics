# Bertrand 竞争

## 定义

Bertrand 竞争是静态的寡头竞争模型，厂商针对价格进行竞争。低价者获得所有市场份额。

## 模型设定

- n 个厂商同时选择价格 $p_i$
- 产品同质
- 边际成本 c 相同
- 市场需求：Q = D(p)

## 纳什均衡

在基本模型中：

$ p_1^* = p_2^* = ... = p_n^* = c $

所有厂商的价格都等于边际成本，获得零利润。

## Bertrand 悖论

即使是双寡头（n = 2），只要产品同质，结果也是完全竞争价格。这与直觉矛盾——两个厂商无法获得垄断利润。

### 悖论的解决方法

1. **产能限制**：如果产能有限，可能获得正利润
2. **产品差异化**：通过品牌、质量等差异化产品
3. **重复博弈**：长期关系可能促成合谋
4. **价格刚性**：存在价格调整成本

## 性质

1. **赢家通吃**：价格最低的厂商获得所有需求

2. **激烈竞争**：哪怕极小的价格优势也能赢得所有市场

3. **不稳定**：均衡对参数变化非常敏感

## 与古诺竞争的比较

| 特征 | Bertrand | Cournot |
|------|----------|---------|
| 竞争变量 | 价格 | 产量 |
| 均衡价格 | 边际成本 | 高于边际成本 |
| 均衡利润 | 零 | 正值 |
| 竞争强度 | 更强 | 较弱 |
