# Off-path Belief

## 一句话记忆

路径外 belief 是到达概率为 0 的信息集上，玩家对历史或类型的概率判断。

## 它是什么

在候选均衡策略下，某些信息集不会发生。若意外到达这些信息集，接收者仍必须有 belief 才能选择行动。

## 解决什么判断

- pooling equilibrium 中偏离信号会被如何解释。
- 路径外行动能否阻止发送者偏离。
- PBE 为什么不能只检查均衡路径。

## 最小例子

若 weak 和 strong 都选择 Quiche，则 Beer 是路径外信号。接收者看到 Beer 后认为发送者是 weak 的概率，就是 off-path belief。

## 易混点

- 路径外 belief 可以指定，不代表随便指定后就一定是 PBE。
- 指定后的 belief 必须让接收者行动最优，并且能阻止发送者偏离。
