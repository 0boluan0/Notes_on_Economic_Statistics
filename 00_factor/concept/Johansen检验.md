Johansen检验是Johansen提出的基于向量自回归模型（VAR）的协整检验方法，可以同时检验多个协整关系并估计协整向量。

## 基本思想

### VAR模型表示

对于$k$个I(1)变量向量$y_t$：

$\Delta y_t = \Pi y_{t-1} + \sum_{i=1}^{p-1} \Gamma_i \Delta y_{t-i} + \epsilon_t$

其中：
- $\Pi$是$k \times k$的长期影响矩阵
- $\Gamma_i$是短期动态系数矩阵
- $\epsilon_t$是$k \times 1$的误差项向量

### 协整关系的秩

协整关系的个数等于矩阵$\Pi$的秩r：
- $r = 0$：无协整关系
- $0 < r < k$：存在r个协整关系
- $r = k$：全部变量平稳（无单位根）

### 矩阵分解

当$\text{rank}(\Pi) = r$时，可分解为：
$\Pi = \alpha \beta'$

其中：
- $\alpha$是$k \times r$的调整系数矩阵
- $\beta$是$k \times r$的协整向量矩阵
- $\beta'$是$r \times k$的矩阵

协整关系：$\beta' y_t = 0$（r个方程）

## 检验统计量

### 1. Trace检验（迹检验）

#### 原假设

$H_0: \text{rank}(\Pi) = r$
$H_1: \text{rank}(\Pi) > r$

#### 统计量

$\text{Trace}_r = -T \sum_{i=r+1}^k \ln(1 - \hat{\lambda}_i)$

其中：
- $T$是样本量
- $\hat{\lambda}_i$是第$i$大的特征值（从大到小）
- $k$是变量个数
- $r$是假设的协整关系个数

#### 检验步骤

1. 从$r = 0$开始
2. 计算Trace统计量
3. 与临界值比较
4. 若拒绝，r = 1，重复
5. 直到不能拒绝

#### 结果

最大的r使得不能拒绝原假设。

### 2. 最大特征值检验

#### 原假设

$H_0: \text{rank}(\Pi) = r$
$H_1: \text{rank}(\Pi) = r+1$

#### 统计量

$\text{Max-Eig}_r = -T \ln(1 - \hat{\lambda}_{r+1})$

其中$\hat{\lambda}_{r+1}$是第$(r+1)$大的特征值。

#### 检验步骤

1. 从$r = 0$开始
2. 计算Max-Eig统计量
3. 与临界值比较
4. 若拒绝，r = 1，重复
5. 直到不能拒绝

## 两种统计量的比较

| 特征 | Trace检验 | Max-Eig检验 |
|------|----------|--------------|
| 原假设 | 最多r个协整关系 | 恰好r个协整关系 |
| 备择假设 | 至少r+1个协整关系 | 恰好r+1个协整关系 |
| 检验顺序 | 从0往上累加 | 逐个检验 |
| 灵敏性 | 对总体偏离更灵敏 | 对局部偏离更灵敏 |

## Johansen检验步骤

### 1. 确定VAR滞后阶数

使用信息准则（AIC、BIC）确定最优滞后阶数p。

### 2. 估计VAR模型

估计未受限的VAR(p)模型：
$y_t = A_1 y_{t-1} + \dots + A_p y_{t-p} + \epsilon_t$

### 3. 构建VECM形式

转换为VECM形式：
$\Delta y_t = \Pi y_{t-1} + \sum_{i=1}^{p-1} \Gamma_i \Delta y_{t-i} + \epsilon_t$

### 4. 检验协整关系

#### 从r = k开始

1. 计算特征值$\hat{\lambda}_i$
2. 计算Trace和Max-Eig统计量
3. 与临界值比较
4. 逐次检验

#### 确定协整关系个数

找到最大的r使得检验不显著。

### 5. 估计协整向量和调整系数

基于确定的r，估计：
- $\beta$：协整向量矩阵
- $\alpha$：调整系数矩阵

## 检验形式

### 1. 无趋势、无截距

数据无确定性趋势。

### 2. 协整方程有截距，数据无趋势

$\beta' y_t = \mu + \epsilon_t$

### 3. 协整方程有截距，数据有线性趋势

$\beta' y_t = \mu + \delta t + \epsilon_t$

### 4. 协整方程和数据都有趋势

更一般的形式。

## 协整向量的识别

### 矩阵的随意性

$\Pi = \alpha \beta'$，但$\alpha$和$\beta$的分解不唯一：
- 对于任意$r \times r$可逆矩阵$F$：
- $\alpha F (F^{-1}\beta') = \alpha \beta'$

### 标准化

需要施加约束来唯一确定协整向量：

#### 方法1：标准化第一个变量

令$\beta$的第一个元素为1：$\beta_{11} = 1$。

#### 方法2：标准化协整向量

$\beta$的每个向量标准化。

#### 方法3：施加理论约束

基于经济理论施加约束。

## 特征值和协整关系

### 特征值的含义

$\hat{\lambda}_i$反映第$i$个协整关系的强度：
- $\hat{\lambda}_i$越大：协整关系越强
- $\hat{\lambda}_i$接近0：协整关系弱

### 协整关系的强度

$\hat{\lambda}_i$可用于判断协整关系的经济重要性。

## 临界值

### 分布

Johansen检验统计量不服从标准分布：
- 分布取决于k、r、检验形式
- 使用模拟或渐近理论得到

### 临界值表

查Johansen检验临界值表：
- 根据k、r、检验形式、显著性水平
- 大多数软件自动计算

## 优点

### 1. 多变量

可以处理多个变量的协整关系。

### 2. 多个协整关系

可以识别和估计多个协整关系。

### 3. 系统方法

基于最大似然估计，系统性强。

### 4. 同时估计

同时估计协整向量和调整系数。

## 局限性

### 1. 计算复杂

计算复杂，对大k较慢。

### 2. 小样本性质

小样本下检验能力较弱。

### 3. 灵敏性

对模型设定和检验形式敏感。

## 与EG两步检验的比较

| 特征 | EG两步检验 | Johansen检验 |
|------|------------|-------------|
| 变量数 | 适合两个变量 | 适合多个变量 |
| 协整关系 | 只能检验整体 | 可识别多个 |
| 估计方法 | OLS | 最大似然 |
| 系统性 | 两步独立 | 系统估计 |
| 计算复杂度 | 简单 | 复杂 |

## 应用

### 1. 宏观经济

检验多个宏观变量之间的协整关系：
- 消费、收入、财富
- 利率、汇率、通胀

### 2. 金融市场

检验多个金融市场的协整：
- 不同市场指数
- 相关资产价格

### 3. 国际贸易

检验贸易变量的长期关系：
- 进出口、汇率、收入

## 实践建议

### 1. 先检验单位根

确认变量都是I(1)过程。

### 2. 选择滞后阶数

使用信息准则选择VAR滞后阶数。

### 3. 选择检验形式

根据数据特征选择合适的检验形式。

### 4. 比较统计量

Trace和Max-Eig可能给出不同结果，需要谨慎判断。

### 5. 经济理论基础

协整向量应有经济理论支持。
