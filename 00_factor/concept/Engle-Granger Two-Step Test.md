EG两步检验法（Engle-Granger Two-Step Test）是Engle和Granger提出的检验协整关系的两步方法，基于残差平稳性检验协整关系。

## 基本思想

### 协整定义

对于两个I(1)过程$y_t$和$x_t$：

如果存在$\beta$使得线性组合平稳：
$\epsilon_t = y_t - \beta x_t \sim I(0)$

则$y_t$和$x_t$协整，协整系数为$\beta$。

### 检验思路

1. 先估计协整系数$\beta$
2. 再检验残差$\epsilon_t$是否平稳
3. 若残差平稳，则存在协整关系

## EG两步检验法步骤

### 第一步：估计协整关系

#### 回归方程

$y_t = \alpha + \beta x_t + \epsilon_t$

使用OLS估计，得到：
- $\hat{\alpha}$：截距估计量
- $\hat{\beta}$：协整系数估计量
- $\hat{\epsilon}_t$：残差序列

#### 经济含义

这是长期均衡关系的估计。

### 第二步：检验残差平稳性

#### 对残差进行单位根检验

检验残差序列$\hat{\epsilon}_t$是否平稳：
- 使用ADF检验或PP检验
- 检验$\hat{\epsilon}_t$是否有单位根

#### 注意事项

**关键问题**：临界值不能使用标准ADF或PP检验临界值表！

原因：
- 残差是估计得到的，不是观测值
- 协整系数的估计影响残差分布
- 需要使用麦金农（MacKinnon）临界值

#### 临界值调整

使用麦金农计算的临界值：
- 考虑残差估计的影响
- 临界值绝对值更大
- 更严格（更难拒绝原假设）

## 检验结果解释

### 原假设和备择假设

- $H_0$：残差存在单位根（非平稳），不存在协整关系
- $H_1$：残差平稳，存在协整关系

### 判断标准

#### 拒绝原假设

- 残差ADF/PP检验统计量 < 临界值（负值更负）
- 结论：存在协整关系
- $\hat{\beta}$是协整系数的一致估计

#### 不能拒绝原假设

- 残差ADF/PP检验统计量 > 临界值
- 结论：不存在协整关系
- 回归结果是伪回归

## 例子

### 实际步骤

#### 数据：价格和数量

1. **第一步：估计长期关系**

$Q_t = \alpha + \beta P_t + \epsilon_t$

OLS估计得$\hat{\beta} = 0.5$。

2. **第二步：检验残差**

对$\hat{\epsilon}_t$进行ADF检验：
- 得到t统计量：-3.5
- 查麦金农临界值（显著性5%）：-3.34

3. **判断**

- -3.5 < -3.34
- 拒绝原假设
- 结论：存在协整关系

### 经济解释

价格和数量存在长期均衡关系：
- $\beta = 0.5$表示长期需求弹性
- 系统偏离后会向均衡调整

## 多变量EG两步检验

### 第一步：估计协整关系

对于多个变量：

$y_t = \beta_0 + \beta_1 x_{1t} + \dots + \beta_k x_{kt} + \epsilon_t$

### 第二步：检验残差平稳性

对残差进行ADF/PP检验。

## 局限性

### 1. 只能识别整体协整

EG两步法只能检验是否存在协整关系：
- 不能识别有多少个协整关系
- 不能确定具体的协整向量

### 2. 标准化问题

协整向量标准化：
- $y_t = \beta x_t + \epsilon_t$
- $x_t = \beta^{-1} y_t - \beta^{-1}\epsilon_t$

两种表示都有效，但系数含义不同。

### 3. 对称性

EG检验对回归方程的选择敏感：
- $y$对$x$回归 vs $x$对$y$回归
- 结果可能不同

### 4. 大样本要求

需要较大样本量才可靠。

## 与Johansen检验的比较

| 特征 | EG两步检验 | Johansen检验 |
|------|------------|-------------|
| 检验对象 | 整体协整关系 | 具体协整关系 |
| 协整向量 | 只能得到一个 | 可得到多个 |
| 系统方法 | 两步法 | 最大似然法 |
| 计算复杂度 | 简单 | 复杂 |
| 适用变量 | 两个或多个 | 多个变量 |

## 临界值

### 麦金农临界值

必须使用麦金农计算的临界值：
- 考虑协整系数估计
- 考虑外生变量个数
- 考虑协整关系个数

### 软件实现

大多数软件自动使用正确临界值：
- EViews
- Stata
- R（urca包）
- Python（statsmodels）

## 应用

### 1. 双变量协整检验

最适合检验两个变量之间的协整关系。

### 2. 长期关系估计

得到长期均衡关系的估计。

### 3. ECM构建

EG检验后可构建ECM。

## 扩展

### 1. 含外生变量

可以在协整关系中包含外生变量：
$y_t = \alpha + \beta x_t + \gamma z_t + \epsilon_t$

### 2. 结构断点

考虑结构断点的EG检验。

### 3. 非线性协整

非线性协整关系的检验。

## 实践建议

### 1. 先检验单位根

在EG检验前确认变量是I(1)过程。

### 2. 回归方程选择

基于经济理论选择因变量。

### 3. 检查残差

检查残差性质：
- 滞后阶数
- 异方差

### 4. 报告完整

在实证研究中：
- 报告第一步估计结果
- 报告第二步检验统计量
- 说明临界值来源
