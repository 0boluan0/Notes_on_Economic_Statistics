简约式方程（Reduced Form Equation）是联立方程系统中将所有内生变量都表示为外生变量的函数，体现系统的最终解。

## 定义

### 基本概念

在联立方程系统中，通过代数运算将每个内生变量表示为外生变量的函数，得到的方程称为简约式方程。

### 一般形式

对于 $m$ 个内生变量 $y_1, y_2, \ldots, y_m$ 和 $k$ 个外生变量 $x_1, x_2, \ldots, x_k$：

$y_i = \pi_{i0} + \pi_{i1}x_1 + \pi_{i2}x_2 + \dots + \pi_{ik}x_k + \nu_i$

其中：
- $\pi_{ij}$是简约参数
- $\nu_i$ 是简约误差项

## 例子：供求模型

### 结构方程

1. 需求：$Q_d = \beta_0 + \beta_1 P + \beta_2 Y + \epsilon_d$
2. 供给：$Q_s = \alpha_0 + \alpha_1 P + \alpha_2 W + \epsilon_s$
3. 均衡：$Q_d = Q_s = Q$

### 推导简约式

#### 均衡条件

$\beta_0 + \beta_1 P + \beta_2 Y + \epsilon_d = \alpha_0 + \alpha_1 P + \alpha_2 W + \epsilon_s$

#### 解均衡价格

$(\beta_1 - \alpha_1)P = \alpha_0 - \beta_0 + \alpha_2 W - \beta_2 Y + \epsilon_s - \epsilon_d$

$P = \frac{\alpha_0 - \beta_0 + \alpha_2 W - \beta_2 Y + \epsilon_s - \epsilon_d}{\beta_1 - \alpha_1}$

整理为简约式：

$P = \pi_0 + \pi_1 Y + \pi_2 W + \nu_P$

其中：
- $\pi_0 = \frac{\alpha_0 - \beta_0}{\beta_1 - \alpha_1}$
- $\pi_1 = \frac{-\beta_2}{\beta_1 - \alpha_1}$
- $\pi_2 = \frac{\alpha_2}{\beta_1 - \alpha_1}$
- $\nu_P = \frac{\epsilon_s - \epsilon_d}{\beta_1 - \alpha_1}$

#### 解均衡数量

代入需求方程：

$Q = \beta_0 + \beta_1(\pi_0 + \pi_1 Y + \pi_2 W + \nu_P) + \beta_2 Y + \epsilon_d$

简化为简约式：

$Q = \lambda_0 + \lambda_1 Y + \lambda_2 W + \nu_Q$

## 特征

### 1. 只含外生变量

- 解释变量全为外生
- 无内生变量作解释变量
- 误差项与新解释变量不相关

### 2. 可用OLS估计

由于外生性，每个简约式方程可用OLS估计。

### 3. 参数无直接经济含义

- 简约参数$\pi_{ij}$是结构参数的复杂函数
- 不直接反映经济学理论参数
- 例如：不直接是需求或供给弹性

### 4. 体现最终结果

- 反映外生变量对内生变量的最终影响
- 包含系统的所有传导路径
- 综合效果

## 简约参数 vs 结构参数

### 关系

简约参数是结构参数的非线性函数：
$\pi = f(\beta, \alpha)$

其中$\beta$和$\alpha$是结构参数。

### 恢复结构参数

从简约参数恢复结构参数：
$\beta = g(\pi)$

这需要：
1. 简约参数可识别
2. 有足够信息
3. 满足识别条件

## 估计

### OLS估计

每个简约式方程可用OLS估计：

1. 估计价格方程：$P = \pi_0 + \pi_1 Y + \pi_2 W + \nu_P$
2. 估计数量方程：$Q = \lambda_0 + \lambda_1 Y + \lambda_2 W + \nu_Q$

### 得到简约参数

OLS 估计得到 $\hat{\pi}_{ij}$。

### 恢复结构参数

从 $\hat{\pi}_{ij}$ 计算结构参数估计量 $\hat{\beta}$ 和 $\hat{\alpha}$。

## 与结构方程的关系

| 特征 | 结构方程 | 简约方程 |
|------|----------|------------|
| 解释变量 | 包含内生变量 | 只含外生变量 |
| 参数含义 | 结构参数，有经济含义 | 简约参数，无直接经济含义 |
| 可估计性 | 不能直接OLS估计 | 可用OLS估计 |
| 经济关系 | 体现经济理论 | 体现最终影响 |
| 内生性 | 存在内生性问题 | 无内生性问题 |

## 识别

### 从简约式识别结构参数

要识别结构参数，需要：

1. **足够的简约参数**
   - 简约参数个数 ≥ 结构参数个数
   - 信息充分

2. **独立的方程**
   - 简约参数的不同组合
   - 可以解出结构参数

3. **满足识别条件**
   - 阶条件
   - 秩条件

### 识别类型

1. **不可识别**
   - 简约参数不足以确定结构参数
   - 无解或多解

2. **恰好识别**
   - 可唯一确定结构参数
   - 恰好一个解

3. **过度识别**
   - 结构参数可确定，但简约参数有约束
   - 多个等价解

## 应用

### 1. 政策分析

- 外生变量（政策变量）对内生变量的最终影响
- 例如：税收对价格和数量的影响

### 2. 预测

- 预测内生变量值
- 基于外生变量预测

### 3. 脉冲响应

- 外生冲击的传导路径
- 动态系统中的应用

## 误差项性质

### 简约误差项

\nu_i是结构误差项的线性组合：
$\nu_i = \sum_j c_j \epsilon_j$

### 性质

1. **期望为0**：E(\nu_i) = 0
2. **可能相关**：不同简约式的误差项可能相关
3. **方差**：是结构误差项方差-协方差矩阵的函数

## 注意事项

### 1. 参数解释

不能直接从简约参数得出经济结论。

### 2. 识别问题

确保结构参数可识别。

### 3. 外生变量

正确识别外生变量对估计至关重要。
