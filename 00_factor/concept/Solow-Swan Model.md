# Solow-Swan Model

## 一句话记忆

Solow-Swan Model 是 [[Solow Model]] 的常见全称入口。

## 它是什么

课程里把 Solow Model、Solow Growth Model、Solow-Swan Model 通常当作同一组外生增长模型来用。正式复习入口放在 [[Solow Model]]。

## 解决什么判断

- 看到 “Solow-Swan” 时，不要另起一套模型。
- 需要公式、稳态和比较静态时，回到 [[Solow Model]] 与 [[Solow Steady State Calculation]]。
