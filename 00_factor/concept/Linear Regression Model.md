# Linear Regression Model

>[!note] 它是什么
> - 「Linear Regression Model」是指用线性关系描述因变量与自变量的模型。
>
>[!note] 最小可检索信息
> - 定义：用线性关系描述因变量与自变量的模型。
> - 符号/公式：$y=X\beta+\varepsilon。$
> - 最小例子：工资对教育年限的线性回归。
>
