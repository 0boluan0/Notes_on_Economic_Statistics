索罗增长模型（Solow Growth Model）又称新古典增长模型，由罗伯特·索罗提出，是现代经济增长理论的核心模型，强调资本积累、人口增长和技术进步的作用。

## 基本假设

### 经济结构

1. **单一部门**
   - 生产出的商品可用于投资或消费
   - 无专门的投资品部门

2. **封闭经济**
   - 无国际贸易
   - 无政府干预

3. **规模报酬不变**
   - $F(\lambda N, \lambda K) = \lambda F(N, K)$

### 外生变量

1. **人口增长率$n$**：外生给定
2. **折旧率$\delta$**：外生给定
3. **技术进步率$g$**：先假设为0，后引入

### 储蓄行为

储蓄函数：$S = sY$

其中$s$是储蓄率，外生给定。

## 生产函数

### 一般形式

$Y = F(N, K)$

满足规模报酬不变。

### 人均形式

设$\lambda = \frac{1}{N}$，则：
$\frac{Y}{N} = F(1, \frac{K}{N})$

定义人均变量：
- 人均产量：$y = \frac{Y}{N}$
- 人均资本：$k = \frac{K}{N}$

得：$y = f(k)$

## 资本积累方程

### 资本变动

$\dot{K} = I - \delta K = sY - \delta K$

### 人均资本变动

$k = \frac{K}{N}$，对时间求导：
$\dot{k} = \frac{\dot{K}}{N} - nk$

代入$\frac{\dot{K}}{N} = sy - \delta k$，得：

$$\dot{k} = sf(k) - (n + \delta)k$$

这是索罗模型的核心方程。

### 经济含义

- $sf(k)$：人均投资（储蓄）
- $(n + \delta)k$：盈亏平衡投资
  - 拉平人口增长的投资：$nk$
  - 补偿折旧的投资：$\delta k$

## 稳态分析

### 稳态定义

人均资本不再变化的状态：$\dot{k} = 0$

即：$sf(k^*) = (n + \delta)k^*$

### 稳态值

在稳态点$k^*$：
- 人均资本$k^*$保持不变
- 人均产出$y^* = f(k^*)$保持不变
- 总产出$Y$以速率$n$增长
- 总资本$K$以速率$n$增长

### 收敛性

- 若$k < k^*$，则$sf(k) > (n + \delta)k$，资本积累
- 若$k > k^*$，则$sf(k) < (n + \delta)k$，资本减少
- 经济收敛到稳态$k^*$

## 比较静态分析

### 储蓄率提高



1. **对稳态水平的影响**
   - 储蓄率$s$上升，投资曲线$sf(k)$上移
   - 新稳态$k'$更高
   - 人均产出提高

2. **对增长率的影响**
   - 短期：增长率上升
   - 长期：增长率回到$n$
   - 储蓄率提高只影响水平，不影响长期增长率

### 人口增长率提高

1. **对稳态水平的影响**
   - 人口增长率$n$上升，盈亏平衡投资线$(n + \delta)k$变陡
   - 新稳态$k'$更低
   - 人均产出下降

2. **经济含义**
   - 人口增长稀释人均资本
   - 稳态人均收入降低

## 结论

### 长期增长

**无技术进步时**：
- 人均产出和人均资本长期不变
- 只有总产出以人口增长率$n$增长

**有技术进步时**：
- 引入技术进步率$g$
- 人均产出长期以速率$g$增长
- 总产出以速率$n + g$增长

### 增长源泉

1. **资本积累**
   - 提高稳态产出水平
   - 不改变长期增长率

2. **技术进步**
   - 唯一驱动长期增长的因素
   - 人均收入持续增长

## 例子：柯布-道格拉斯生产函数

### 生产函数

$Y = K^\alpha N^{1-\alpha}$

### 人均形式

$y = k^\alpha$

### 稳态

由$s k^\alpha = (n + \delta)k$，得：

$k^* = [\frac{s}{n + \delta}]^{\frac{1}{1-\alpha}}$

$y^* = [\frac{s}{n + \delta}]^{\frac{\alpha}{1-\alpha}}$

### 含义

- 储蓄率$s$越高，稳态人均资本和产出越高
- 人口增长率$n$和折旧率$\delta$越高，稳态水平越低

## 与哈罗德-多玛模型比较

| 特征 | 哈罗德-多玛模型 | 索罗模型 |
|------|----------------|----------|
| 要素替代 | 不可替代 | 可替代 |
| 生产函数 | 固定系数 | 连续函数 |
| 刃锋问题 | 存在 | 不存在 |
| 稳态存在 | 困难 | 稳定收敛 |
| 技术进步 | 无 | 可引入 |

## 局限性

1. **外生技术进步**
   - 技术进步外生化
   - 未解释技术进步的来源

2. **储蓄率外生**
   - 储蓄率不随收入变化
   - 与现实不符

3. **规模报酬不变**
   - 长期可能不是完全准确

## 历史意义

1. **解决刃锋问题**
   - 要素可替代
   - 稳态稳定

2. **强调技术进步**
   - 唯一长期增长源泉

3. **增长收敛**
   - 预测落后国家赶超发达国家
