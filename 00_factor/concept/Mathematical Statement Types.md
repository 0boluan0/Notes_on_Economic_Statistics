# Mathematical Statement Types

数学中的 **proposition** 是具有确定真值的陈述。**axiom** 是理论中不由更早结论证明的出发假设；**theorem** 是已被证明的重要命题；**lemma** 是通常为证明其他结论服务的定理；**corollary** 是从已有定理很快推出的结论。

这些名称描述陈述在论证中的角色，不改变“必须明确假设与结论”的要求。同一个结果在不同文本中可能被称为 theorem 或 lemma。
