# Type (Game Theory)

## 一句话记忆

类型是玩家自己知道、别人未必知道的私人信息状态。

## 它是什么

在贝叶斯博弈中，类型 $t_i$ 可以表示玩家的成本、偏好、能力、收益函数或信号。

## 解决什么判断

- 题目中的不确定性是不是私人信息。
- 策略是否需要写成“每种类型下做什么”。
- 对手的行动能否透露类型。

## 最小例子

Beer-Quiche 博弈中，玩家 $A$ 可以是 weak 或 strong。weak/strong 就是玩家 $A$ 的类型。

## 易混点

- 类型不是行动；Beer/Quiche 是行动，weak/strong 是类型。
- 同一自然人不同类型不是现实中的不同人，但解题时可拆成类型代理人。
