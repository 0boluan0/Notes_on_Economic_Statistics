# Average Value of a Function

可积函数 $f$ 在 $[a,b]$ 上的平均值为

$$
f_{\mathrm{avg}}=\frac{1}{b-a}\int_a^bf(x)\,dx.
$$

它是与 $f$ 具有相同区间总累计量的常数高度。

## 最小例子

$f(x)=x$ 在 $[0,2]$ 上的平均值为 $1$。
