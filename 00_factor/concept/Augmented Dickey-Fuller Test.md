ADF检验（Augmented Dickey-Fuller Test）是DF检验的扩展版本，通过在检验回归中加入滞后项来处理误差项的自相关问题。

## 为什么需要ADF检验

### DF检验的问题

基本DF检验假设误差项是白噪声（iid），但实际上：
- 误差项通常存在自相关
- 白噪声假设经常被违反
- 影响检验的有效性

### ADF检验的改进

在DF检验中加入滞后项：
- 消除误差项的自相关
- 提高检验的有效性
- 更符合实际数据特性

## ADF检验的三种形式

### 1. 无常数项和趋势项

$\Delta y_t = \gamma y_{t-1} + \sum_{i=1}^k \alpha_i \Delta y_{t-i} + \epsilon_t$

原假设：$H_0: \gamma = 0$（存在单位根）
备择假设：$H_1: \gamma < 0$（平稳）

### 2. 有常数项，无趋势项

$\Delta y_t = \alpha + \gamma y_{t-1} + \sum_{i=1}^k \alpha_i \Delta y_{t-i} + \epsilon_t$

原假设：$H_0: \gamma = 0$
备择假设：$H_1: \gamma < 0$

### 3. 有常数项和趋势项

$\Delta y_t = \alpha + \beta t + \gamma y_{t-1} + \sum_{i=1}^k \alpha_i \Delta y_{t-i} + \epsilon_t$

原假设：$H_0: \gamma = 0$
备择假设：$H_1: \gamma < 0$

其中：
- $k$是滞后阶数
- $\alpha_i$是滞后差分项的系数
- $\epsilon_t$是白噪声

## 滞后阶数的选择

### 信息准则

使用信息准则确定最优滞后阶数：

1. **AIC（赤池信息准则）**

$AIC(k) = \ln\left(\frac{\text{SSR}}{T}\right) + \frac{2k}{T}$

选择使AIC最小的k。

2. **BIC（贝叶斯信息准则）**

$BIC(k) = \ln\left(\frac{\text{SSR}}{T}\right) + \frac{k \ln T}{T}$

选择使BIC最小的k。

### 滞后阶数原则

- 不能太少：无法消除自相关
- 不能太多：损失过多自由度
- 根据样本量调整

## 检验步骤

### 标准流程

1. **选择检验形式**
   - 根据数据图形判断
   - 考虑是否包含趋势

2. **选择滞后阶数**
   - 使用AIC或BIC
   - 从较大的k开始向下搜索

3. **估计ADF回归**
   - OLS估计ADF方程
   - 得到$\hat{\gamma}$及其标准误

4. **计算t统计量**
   - $t = \frac{\hat{\gamma}}{SE(\hat{\gamma})}$

5. **比较临界值**
   - 使用ADF临界值表
   - 非标准t分布临界值

6. **做出判断**
   - 若t统计量 < 临界值，拒绝原假设（平稳）
   - 若t统计量 > 临界值，不能拒绝原假设（非平稳）

## 统计量的分布

### τ分布

ADF检验的统计量服从τ分布，而非标准t分布。

### 原因

- 在单位根假设下，$y_{t-1}$是随机游走
- 与普通回归变量性质不同
- 统计量分布左偏

### 临界值

- 查ADF检验临界值表
- 根据检验形式、样本量、显著性水平查表
- 临界值为负值

## 与DF检验的比较

| 特征 | DF检验 | ADF检验 |
|------|--------|----------|
| 误差项假设 | 白噪声 | 允许自相关 |
| 滞后项 | 无 | 有$\Delta y_{t-i}$ |
| 适用性 | 理想情况 | 实际数据 |
| 检验能力 | 自相关时低 | 更强 |

## 选择检验形式

### 决策过程

1. **观察数据图形**
   - 有明显趋势→用趋势项形式
   - 非零均值→用常数项形式
   - 零均值无趋势→用无常数项形式

2. **从一般到特殊**
   - 先用包含趋势项的形式
   - 若趋势项不显著，去掉趋势项
   - 若常数项不显著，去掉常数项

### 策略

- 开始：含趋势和常数项
- 逐步简化：检验系数显著性
- 最终：使用最合适的简化形式

## PP检验与ADF检验

### 相似性

都是单位根检验，都需要处理自相关。

### 区别

| 特征 | ADF检验 | PP检验 |
|------|----------|---------|
| 处理方法 | 加入滞后项 | 调整统计量标准误 |
| 自相关处理 | 参数化 | 非参数化 |
| 滞后阶数 | 需要选择 | 不需要选择 |

## 应用

### 1. 时间序列分析

- 检验序列平稳性
- 决定建模方法

### 2. 协整检验

- 检验残差平稳性
- EG两步检验法

### 3. 预测建模

- 确定数据性质
- 选择合适模型

## 注意事项

### 1. 滞后阶数

合理选择滞后阶数至关重要。

### 2. 检验形式

正确选择检验形式影响检验结果。

### 3. 样本量

小样本下检验能力较弱。

### 4. 结构断点

数据存在结构断点时需要特殊处理。
