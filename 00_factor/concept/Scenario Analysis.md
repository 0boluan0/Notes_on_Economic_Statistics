# Scenario Analysis

>[!note] 它是什么
> - 「Scenario Analysis」是指在设定的宏观或市场情景下评估损益或风险。
>
>[!note] 最小可检索信息
> - 定义：在设定的宏观或市场情景下评估损益或风险。
> - 符号/公式：无固定符号。
> - 最小例子：利率上升200bp情景下的组合损失。
>
