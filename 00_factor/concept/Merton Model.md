# Merton Model

## 它是什么
- 「Merton Model」是指结构性信用风险模型，将股权视为资产对债务的看涨期权。

## 最小可检索信息
- 定义：结构性信用风险模型，将股权视为资产对债务的看涨期权。
- 符号/公式：$PD=N(-d_2)，d_{1,2}=\frac{\ln(V/D)+(\mu\pm\tfrac12\sigma^2)T}{\sigma\sqrt{T}}。$
- 最小例子：资产价值低于债务面值时公司违约。
