# ARCH LM Test

## 它是什么
- 「ARCH LM Test」是指检验残差中是否存在ARCH型条件异方差的LM检验。

## 最小可检索信息
- 定义：检验残差中是否存在ARCH型条件异方差的LM检验。
- 符号/公式：$LR=nR^2 服从 \chi^2(q) 近似分布。$
- 最小例子：对收益率残差平方做滞后回归并检验系数显著性。
