# 公共资源

## 定义

公共资源（Common Resources）是指具有**非排他性**（non-excludable）但**竞争性**（rivalrous）的物品或资源。

## 核心特征

### 1. 非排他性
- 难以或无法将某些人排除在使用之外
- 难以实施产权保护

### 2. 竞争性
- 一个人使用会减少其他人可用的数量或质量
- 边际使用成本为正

## 物品四象限分类

| 特征 | 排他性 | 非排他性 |
|------|--------|-----------|
| 竞争性 | 私人物品 | 俱乐部物品 |
| 非竞争性 | 公共资源 | 公共物品 |

## 典型例子

### 1. 海洋渔业
- **非排他性**：难以阻止渔船捕鱼
- **竞争性**：一条船捕鱼减少了其他船可捕的数量

### 2. 公共牧场
- **非排他性**：难以禁止牲畜吃草
- **竞争性**：过度放牧导致草场退化

### 3. 地下水
- **非排他性**：难以阻止打井
- **竞争性**：过度抽取导致水位下降

### 4. 森林
- **非排他性**：难以阻止砍伐
- **竞争性**：过度砍伐导致森林消失

### 5. 公共道路
- **非排他性**：难以禁止使用
- **竞争性**：拥挤时相互妨碍

## 公地悲剧（Tragedy of the Commons）

### 定义
由于个人理性导致集体非理性的现象，公共资源被过度使用最终枯竭。

### 机制
1. **个人理性**：每个用户最大化自身收益
2. **忽略外部成本**：不考虑自己的使用对他人的影响
3. **过度使用**：每个人都想"多占一点"
4. **资源枯竭**：集体过度使用导致资源崩溃

### 数学模型

设 n 个人共同使用资源：
- 个人使用量：x_i
- 总使用量：X = Σx_i
- 个人收益：B_i(x_i)
- 社会成本：C(X)

个人最优：max B_i(x_i) - x_i C(X) / n
社会最优：max ΣB_i(x_i) - C(X)

结果：x_i(个人) > x_i(社会)

## 解决方案

### 1. 产权界定（科斯式方法）
- 私有化公共资源
- 明确产权归属
- 允许市场交易

### 2. 政府管制
- **数量管制**：设定使用配额
- **技术管制**：规定使用方式
- **准入管制**：限制使用者数量

### 3. 社区管理
- 建立使用者组织
- 制定共同规则
- 相互监督和执行

### 4. 税收和补贴
- 对使用征税（反映社会成本）
- 对减量使用补贴

### 5. 私人所有与社区所有
- 私有产权：激励有效使用
- 社区产权：自主管理规则

## 奥斯特罗姆模型（Ostrom's Model）

Elinor Ostrom 研究表明，社区自主管理可以避免公地悲剧：

### 成功条件
1. **清晰的边界**：资源边界和使用者边界明确
2. **集体选择**：使用者参与制定规则
3. **监督机制**：有效的监督和制裁
4. **冲突解决**：低成本的冲突解决机制
5. **多层级组织**：多层级的治理结构

## 应用案例

### 1. 海洋渔业管理
- 捕捞配额制度（ITQ）
- 季季管制
- 海洋保护区

### 2. 水资源管理
- 用水权交易
- 灌溉系统
- 流域综合管理

### 3. 气候变化
- 碳排放配额
- 碳市场交易
- 跨国合作

## 与其他物品的比较

| 特征 | 私人物品 | 俱乐部物品 | 公共物品 | 公共资源 |
|------|---------|-----------|---------|---------|
| 排他性 | 有 | 有 | 无 | 无 |
| 竞争性 | 有 | 无 | 无 | 有 |
| 主要问题 | 垄断、垄断 | 自然垄断 | 搭便车 | 公地悲剧 |
| 解决方向 | 反垄断 | 定价管制 | 税收 | 产权或管制 |

## 政策启示

1. **产权清晰是关键**：明确产权是避免公地悲剧的第一步
2. **社区自治有效**：本地社区往往比中央政府更了解情况
3. **多手段结合**：产权 + 管制 + 税收
4. **国际协作**：跨国资源需要国际制度安排
