# Context Window

Context Window 是模型一次输入和生成中可使用的最大 token 范围。

## 最小定义
上下文窗口包括提示词、历史对话、检索材料和生成内容。

## 最小例子
128K context 模型理论上能读入一本较长文档，但是否真正利用仍需评测。
