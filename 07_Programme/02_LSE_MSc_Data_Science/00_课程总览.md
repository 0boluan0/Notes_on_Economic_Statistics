## 二、怎样读“往年评价”

公开逐课评价非常稀少。LSE 当前的 Course Survey 仪表盘及原始评论只向院系管理层、项目主任和任课教师开放，普通学生无法公开检索；但旧版 Calendar 的个别 2015/16 Course Guide 仍公开了 2011/12–2013/14 匿名调查汇总。因此本文严格分开四类证据：

- **学生评价**：可核验的往届学生主观反馈。
- **学生作品**：能证明实际做过什么，但不能推出“课好不好”。
- **课程材料／教师自述**：能判断内容、深度与教学设计，不代表学生口碑。
- **客观信号**：往年人数、考核方式、先修要求与 controlled access；它们不是评分。

历史调查统一使用 `1 = 最好、5 = 最差`。目前只在仍有一定课程连续性的 MA407 与 ST405 旧页面找到完整汇总；它们没有原始文字评论，而且教师、编程语言和 syllabus 都可能已经变化，只用于判断历史上曾出现的满意度方向。

### 项目整体的往届反馈

LSE 2024/25 Change Makers 调查访问了 Statistics 系近期毕业、处于职业早期的 data-related MSc 校友。公开海报没有披露样本量或各项目人数，所以不能据此给课程打分，但它给出了目前最有用的项目级信号：

- **强项**：machine learning 与 statistical inference 的学术训练较强。
- **缺口**：production-grade tools、messy data、data engineering、ethical AI 与面向非技术受众的沟通不足；受访者也提到 R 较多，而 API、cloud、Power BI 等接触有限。
- **一位 MSc Data Science 校友的具体意见**：Python 教学没有充分覆盖 OOP、testing 与 networking，入职前后仍需自学基础库和工程技能。
- **校友建议**：根据职业目标选课，主动补 programming／AWS，并用 side projects 建立真实作品。

另一位 2023/24 在读 MSc Data Science 学生在 LSE 学生博客中肯定课程对新技术的覆盖、统计理论基础、教师 office hours 和 Capstone 的真实项目经验。它是明确的本项目学生体验，但由学校平台发布，存在正向筛选偏差。StudentCrowd 另有一条自称 MSc Data Science 学生的匿名混合评价：教师整体不错，但认为每门课可覆盖更多材料、每周一次 lecture 不够；页面却把评价归在 BSc 条目下，因此只记为低可信线索。

已登录的小红书补上了此前缺失的强烈负面样本。一名有连续在读细节的 2025/26 学生在 2026 年 2 月和 5 月两次劝退：主要批评就业导向与项目专属支持有限、课程偏理论、行业活动少、Capstone 合作方质量下降、domain knowledge 需要自行补齐，并认为考试很难。该作者明显非常不满，不能代表整届；他所称“往届只有 25–30 人”也与官方 2024 intake 48 人不一致，人数说法不采信。作为对照，另一名 2025/26 学生记录过三份作业同周截止、压力拉满，却也明确表示喜欢上课、图书馆、写代码的日常。这说明“负担重”较一致，但价值判断并不一致。

2018 届 MSc Data Science 校友 Michal Heydel 的公开回顾更具体：他认为项目在理论与实践之间平衡良好，称工作中会使用约 90% 的所学知识，并把与 Facebook Research 合作的 Capstone 视为接触真实问题的重要经历。他也把项目与自己毕业后的 data scientist 工作直接联系起来。这仍是校方挑选的单个成功案例，不能代表就业分布。

LSE 当前的 Statistics Student Blogs 还提供了来自印度、中国、巴基斯坦等国际学生的在读视角。Stuti Subramani 把 Machine Learning 与 Distributed Computing for Big Data 两门模块合称为“有挑战但令人兴奋”，说教师回复及时、office hours 能帮助解决备考和 dissertation 疑问；Yibei Chu 则写到 Spark seminar、课前预习难点、一次集中 90 分钟以上不容易，以及多门 Statistics 课程采用小组项目。另有学生把整个 MSc Data Science 明确形容为 demanding、适应期可能 overwhelming。正面信号集中在同伴、导师和机会，几乎没有逐课批评，因此应按“校方托管、正向筛选”阅读，而不是当作独立口碑平台。

独立公开职业档案补上了更真实的负担描述。2024/25 MSc Data Science 毕业生 Eleni Ierodiakonou 把这一年称为“最具挑战、也最具转变性”的阶段之一，提到复杂 coursework、demanding projects，以及起初令人不知从何下手的高预期。Barath Raaj 同样把课程概括为 challenging coursework 加 hands-on projects。Aditya Tamilisetti 肯定同伴、faculty 和基础设施，但也把一年形容为 power-packed，并说自己在 KPMG Capstone 中一度感到完全迷失，最后仍获 distinction。这些是公开 LinkedIn 自述，存在毕业庆祝帖的正向呈现偏差，却比校方宣传更能显示实际压力。

### 能对应到具体课程的反馈

目前最有价值的跨课程直接证据是一位 QuantNet 已验证的 2025 届 LSE Statistics 硕士毕业生评价。该生修过 **ST418、ST429、ST451、ST455**，给同系项目的课程与教师 5/5，认为课程强度高、每周 problem sheets 很重要、教师专业且 office hours 易接触；他特别把 **ST455 Reinforcement Learning** 列为最喜欢的课之一。样本只有 1 人，且不是 MSc Data Science 本项目，所以只能作为这四门重叠课程的弱证据，不能泛化成全体口碑。

另一位匿名 Reddit 用户自称读过 LSE 数学类硕士并实际修过 ST455，称它是自己硕士阶段“by far the most useful”课程；其同一条回复只说“听说”ST451 是好课。前者是匿名但直接的第二个 ST455 正面样本，后者只是二手传闻，证据等级更低。

本轮已用每个课程代码与全名逐项检索 LSE 页面、公开课程站、GitHub、Reddit、QuantNet、StudentCrowd 和 RateMyProfessors。Reddit 结果绝大多数只是申请者／offer holder 讨论，没有修课经历，因此没有纳入“往年评价”。下文写“未找到可靠逐课评价”，表示已搜索但没有足以归因到该课的第一手公开证据，不表示这门课没有口碑。

## 三、必修课

### [ST443 Machine Learning and Data Mining](https://www.lse.ac.uk/resources/calendar2026-2027/courseGuides/ST/2026_ST443.htm)

- **学期**：Autumn Term。
- **内容**：回归与分类、交叉验证、正则化、树模型、bagging、random forest、boosting、SVM、PCA、聚类。
- **基础**：扎实的线性代数、微积分和概率。
- **考核**：Spring Term 120 分钟考试 100%；5 份 formative problem sets 不计分。
- **2025/26 客观信号**：86 人，平均班级约 22 人；高需求 controlled access，但本项目必修生优先。
- **往年评价证据**：找到往届 MSc Data Science 学生仓库与公开项目。一个真实小组项目比较 kNN、LDA、QDA、logistic regression，并亲自实现 LASSO／Elastic Net 的 coordinate descent，能确认理论与编码并行。另有在读学生把 Machine Learning 与 ST446 合称为“有挑战但令人兴奋”，这是直接体验，但无法把总体评价完全拆给其中一门，且由校方托管页面发布。

### [ST445 Managing and Visualising Data](https://www.lse.ac.uk/resources/calendar2026-2027/courseGuides/ST/2026_ST445.htm)

- **学期**：Autumn Term。
- **内容**：NumPy、Pandas、SQL 与数据库、Matplotlib、Seaborn、模型评估可视化、降维与图数据展示。
- **考核**：project 70% + 两份 problem sets 共 30%。
- **2025/26 客观信号**：113 人，平均班级约 28 人；高需求 controlled access，本项目必修生优先。
- **往年评价证据**：有完整公开课程网站和学生作品。一个真实小组项目整合伦敦交通、犯罪等数据，使用交互图、线性回归和 SARIMA；LSE 的 GitHub 教学案例还记录了 GitHub Classroom 作业与反馈。这些能证明实践型教学设计，但不是满意度评价。

### [ST447 Data Analysis and Statistical Methods](https://www.lse.ac.uk/resources/calendar2026-2027/courseGuides/ST/2026_ST447.htm)

- **学期**：Autumn Term。
- **内容**：估计与检验、线性／逻辑回归、Monte Carlo、bootstrap、EM、permutation、local fitting、因果推断、false discovery rate；使用 R。
- **基础**：微积分、线性代数、概率与统计。
- **考核**：January 120 分钟考试 85% + project 15%。
- **2025/26 客观信号**：66 人，平均班级约 22 人；不是 controlled access。2026/27 convenor 已由上一学年的 Sara Geneletti Inchauste 更换为 Qiwei Yao，旧评价即使找到也不能完全代表新版本。
- **往年评价证据**：公开学生项目显示，个人作业曾要求用 R、logistic regression 和统计检验比较两个驾驶考试中心的通过率；未找到可验证的逐课满意度评价。

### [ST498 Capstone Project](https://www.lse.ac.uk/resources/calendar2026-2027/courseGuides/ST/2026_ST498.htm)

- **周期**：Autumn、Winter、Spring Term 延续至 8 月。
- **形式**：小组为外部合作方解决真实数据问题，通常每周或隔周与合作方会面。
- **考核**：group project 80% + individual contribution 20%。
- **2025/26 客观信号**：54 人。
- **往年评价证据**：LSE 教学案例公布了匿名学生反馈：学生认为项目把理论用于真实环境，并提升 teamwork、leadership 与 presentation；合作方导师被形容为易接触且支持充分。校方称正式与非正式反馈都很正面，但这是学校筛选后公开的引语，不能视作完整调查分布。
- **独立校友补充**：Barath Raaj 把 ADIA Capstone 与 challenging coursework、hands-on projects 一并列为成长经历；Aditya Tamilisetti 说 KPMG Capstone 是全年最难的部分之一，过程中一度感到完全迷失，最终获得 distinction。它们同时显示 Capstone 可能很有成就感，也可能在问题定义和推进阶段造成明显压力。
- **可核验的往届成果**：2022/23 一组学生用 LSE 年度调查的 Likert 量表和自由文本分析学生满意度与学习结果，并在公开履历中称项目获得 MSc Data Science 最佳 Capstone 的 Winton Prize。这能证明 ST498 确实可能接触校级真实数据与决策者；作者同时明确写明项目受 NDA 约束，未公开报告，所以不能从中提取逐课评价或具体结论。
- **当前项目形态**：项目通常在 11 月至 8 月运行，2 月和 4 月反馈展示、6 月交草稿、8 月交最终成果；近期主题包括海洋透明度预测、数字心理健康推荐、能源价差尾部风险、ghost-job 检测和公交改道识别。

## 七、选课时真正要注意的事

1. **Autumn Term 已经很重**：ST443、ST445、ST447 三门必修都在 AT，Capstone 也开始。再选 AT 课会提高第一学期密度。
2. **Winter Term 热门课可能同时挤在一起**：ST446、ST451、ST455、ST456 都是 controlled access，且多有小组项目。不能只按名字选，要等 9 月课表和申请规则。
3. **人数不是口碑**：ST456 的 120 人说明需求高；ST405 的 4 人、ST459 的 3 人说明小众或门槛高。都不能直接说明教学质量。
4. **先修条件可能直接排除课程**：尤其 ST405、ST429、ST458、ST459。正式选前应让 programme director 确认本科课程是否算 equivalent prerequisites。
5. **评价年代要对齐教师和 syllabus**：ST447 已换 convenor；ST444 刚从停开恢复；ST449 旧版内容有变化。旧评价只能作为历史线索。
6. **不要等到开学后才补环境**：官方 Q&A 明确把 Python、R、Linux、LaTeX 列为入学前实用准备；课程本身不会替你补齐 OOP、testing、API 与 cloud 工程基础。

## 八、按方向形成候选池（不是最终选课）

- **数据工程／生产系统**：ST446；若算法基础薄弱，再看 MA407 或 ST444。
- **通用机器学习研究**：ST451、ST455、ST456、ST457。
- **NLP／文本与 LLM**：MY459；若更偏深度模型，再配 ST456。
- **经典统计与时间序列**：ST405、ST411、ST418。
- **量化金融／风险**：ST429、ST436；ST458 必须先解决先修问题。
- **编程起步**：MY470；已有扎实 Python 时优先把名额留给更进阶课程。
- **前沿小众方向**：ST459，但先修门槛和极小班规模都要求慎重确认。

校友调查显示，这个项目最需要自行补齐的是 production engineering 和非技术沟通。因此，若目标是 data scientist／ML engineer，ST446 与 ST498 的现实工作流价值较高，但 OOP、testing、API、cloud 仍不能假设由任一门课完整覆盖。

### 与你既有研究走廊最相关的五门课

本地现有研究草案把 **statistical/probabilistic ML** 作为主线，把 **relational/graph modelling** 作为备线，并考虑 time series 与 temporal graph 的交叉。它是个人方向材料，**不是正式选课记录**；截至本次本地检索，仍未找到三门选修已经提交或获批的证据。

| 课程 | 对研究走廊的作用 | 真实负担／风险 |
|---|---|---|
| ST451 | 主线最直接：Bayesian inference、variational inference、MCMC、HMM、Gaussian processes | 10 份 problem sets；exam 50% + project 50%；需求非常高 |
| ST418 | time-series／forecasting 主线：ARMA、GARCH、多变量与高维时序、factor models | 100% 闭卷考试；2026/27 更换 convenor；controlled-access 日期字段矛盾 |
| ST457 | graph 备线最直接：spectral methods、embeddings、GNN、graph kernels 与 generative graph models | 10 份 problem sets；80% 小组研究项目；目前非 controlled |
| ST456 | 提供通用深度模型能力，可支撑 temporal graph 或生成模型 | 8 份 problem sets；80% 小组项目；120 人、名额极紧；与 ST457 同在 WT 且项目负担重 |
| ST446 | 补项目校友最常提到的 production／cloud／data-engineering 缺口 | 两份计分 problem sets + 60% 小组项目；研究主线不如前三门直接 |

如果以 PhD 写作样本为第一目标，ST451、ST418、ST457 的学术叙事最连贯；如果以就业工程能力为第一目标，ST446 应进入前三候选。两种组合都必须等 2026-09-09 课表后再检查时间冲突，不能现在写成最终推荐。
