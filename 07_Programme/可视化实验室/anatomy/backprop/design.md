# 前向与反向传播：计算实验台

Figure，单个 tanh 隐藏单元，三个可训练参数。底座上的五个运算盒保存前向值；点击读数或运算盒，检查相邻面板中的当前运算与缓存。反向沿相同依赖读取局部导数，读数表示损失的敏感度。参数更新独立执行。

学习顺序：先计算一个结果 → 只改变一个权重并沿曲线追踪变化 → 在固定前向值上逐段累计敏感度 → 对照饱和区与零权重 → 更新后重新计算。主场景先显示因果曲线；逐项核算、Anatomy 装置、分支与矩阵形式放在可展开区域。

画面使用 Anatomy 的投影、实体与明暗库。计算由现有 LabMath 的 backprop 模型提供，影片和交互共享同一个模型、场景与时间线。数值读数保留在仪表和紧邻的计算面板中。这个装置是计算过程的教学模型；部件形状不表示神经元的物理形状。

部件清单：底板、四只脚、两根支撑轨、两根止挡（9）；五个运算盒各含底座、外壳、内嵌面板、显示屏边框、读数窗、左右刻度轨、零位标记、滑块、滑块手柄、背部插座（55）；四个连接条（4）；一块铭牌（1）。共69个实体，螺丝端点和刻度附着于对应表面。

验收：前向每一步的输入可追溯；反向的上游梯度、本地导数、乘积同时可读；更新前后分开；显示舍入不参与计算；有限差分独立验证全部参数；边界情境有具体数值解释；键盘、窄屏、减弱动画、离线 iframe、Obsidian 内实际操作。影片按实际中文讲解时长连续渲染同一 SVG 场景，共 20 段、约 386 秒；全部数值与交互共用模型。普通与饱和情境保持 tanh 的相同坐标尺度。

局部改动另有放大图，横纵轴使用相同的单位长度，蓝色表示输入改动、绿色表示输出响应；普通与饱和情境的激活改动沿用相同尺度。反向用同一个微小改动 ε 连接本地响应与最终损失，明确标注局部近似；橙色读数注明所求导的变量。配音使用晓晓神经语音，运动起止取自逐句时间戳。
