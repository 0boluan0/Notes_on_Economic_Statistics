# 可视化实验室：建设与验收范围

本区域是全库共用的图形、动态演示和交互实验资料区。知识原子继续拥有定义与命题；实验拥有可视化机制、可操作的参数、观察任务与来源核验。一个实验可以由多个知识原子引用，尚无原子的主题也可先有独立实验入口。

## 当前建设范围

首组覆盖数学统计基础、机器学习主干、神经网络与主要深度学习分支。以实际可视化机制划分实验，不按文件数量或生成量判断完成。

| 组 | 实验编号 | 覆盖问题 |
|---|---|---|
| 数学与统计基础 | tangent, linear, projection, gradient, sampling, confidence, testing, bayes, regression, overfit, pca, bootstrap | 局部变化、线性几何、优化、抽样、推断、先验更新、共线性、泛化、表示与重抽样 |
| 机器学习 | knn, logistic, svm, tree, ensemble, boosting, kmeans, gmm, kde, modelselection, metrics, likelihood | 局部预测、分类、间隔、划分、集成、逐步拟合、聚类、潜变量、密度、选择偏差、评估与似然 |
| 神经网络 | activations, neuron, mlp, backprop, initialization, optimizers, regularization, normalization, convolution, pooling, residual, attention | 激活、表达、链式法则、信号与梯度、优化器、正则化、归一化、卷积与空间、跳跃连接、注意力 |
| 深度学习分支 | positional, gnn, embeddings, autoencoder, vae, gan, flow, diffusion, rl-bellman, rl-policy, double-descent, fairness | 位置、图与对称性、相似性、编码与重构、潜变量、对抗、密度变换、去噪、序贯决策、泛化现象与评价边界 |

覆盖盘点又识别出12个需要独立图形机制的缺口，补入本轮：

| 补充组 | 实验编号 | 原因 |
|---|---|---|
| 表示、概率与评估基础 | svd, biasvariance, kernel, entropy, softmax, calibration | 奇异方向、真实偏差方差分解、核方法、信息量、概率归一化与概率可靠性不能由相邻主题代替 |
| 序列、局部变化与推断 | rnn, lstm, contrastive, jacobian, uncertainty, causal | 循环记忆、门控、对比目标、多元局部变换、两类不确定性及关联/干预需要单独解释 |

本轮实现60项实验、183个步骤、79个知识原子的精确关联。数值、来源、图形修订、浏览器交互和代表性Obsidian路径均有独立记录；范围与平台边界以这些记录为准。未来主题仍需按同一流程继续扩展，不能由实验数量推断已经覆盖整个领域。

## 每个实验的分轮检查

1. **数学与来源**：重新打开支持资料，核对公式、定义、假设、极端参数和数据含义；与独立计算比对。
2. **图形机制**：以实际渲染图检查坐标、尺度、标注、颜色和比较关系，识别掩盖机制的构图并修改。
3. **学习路径**：核对观察问题、默认情境、预设、操作步骤、提示、解释和边界是否相互一致；需要时改写或重排。
4. **交互与宿主**：操作每个参数和预设，核对响应、重置、导出、键盘、窄屏、离线和 Obsidian 内表现。
5. **交叉复核**：用未参与原实现的检查重新审阅，每项重要修改重新运行受影响核验，记录实际发现和改动。

每张图的审查必须有实际结果；不能把生成一次、代码通过、单张首页截图、重复执行同一检查或仅有文件存在视为充分验收。

## 运行约定

- `assets/content*.js` / 分组内容文件是教学内容来源；`assets/catalog.json` 由构建过程生成，插件从此 JSON 读取目录，并读取固定的离线 HTML。
- 插件只读取本区域的固定离线包，以脚本可用、与 Obsidian 主界面隔离的 iframe 承载实验。
- 学习记录与个人掌握状态不写入共享实验；所有样本均明确标为模型生成数据。
- 留存正式源码、单一当前离线包、可运行伴读代码及核验记录；清理失败试装、过时产物、临时环境和重复截图。
