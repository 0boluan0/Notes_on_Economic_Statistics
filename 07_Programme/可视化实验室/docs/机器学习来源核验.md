# 机器学习实验：来源、边界与迭代核验

本记录覆盖 `knn`、`logistic`、`svm`、`tree`、`ensemble`、`boosting`、`kmeans`、`gmm`、`kde`、`modelselection`、`metrics`、`likelihood`。2026-10-06 已重开下列原始论文、NIST 与维护者官方文档，逐项核对公式、术语、实现范围和挑战答案。教学文字与数值实现独立编写；引用章节说明依据，不表示调用了相应 Python 软件。

<!-- bilingual-en:start -->
This record covers twelve classical ML experiments. Original papers, NIST material and official maintainer documentation were reopened on 6 October 2026. Equations, terminology, implementation boundaries and worked exercises were checked. The teaching prose and numerical implementations are original; citations do not imply use of the referenced Python software.

## 逐项来源与限定

| 实验 | 重开的权威来源及准确位置 | 所支持的内容 | 实现限定及独立核算 |
|---|---|---|---|
| KNN | [scikit-learn Nearest Neighbors](https://scikit-learn.org/stable/modules/neighbors.html)，§1.6.2；§1.6 开头的等距 warning | k 个邻居的分类投票；第 k 与 k+1 等距时需处理次序 | 二维穷举、均匀投票；加权距离自行计算。等票选 1、等距按原序号；热图是 28×28 网格。比例不是自动校准后验。 |
| Logistic | [Linear Models](https://scikit-learn.org/stable/modules/linear_model.html#logistic-regression)，§1.1.11.1 Binary Case | sigmoid、Bernoulli 负对数似然 | 手调 w、b，无训练求解器。`softplus(z)−yz` 稳定求损失；固定 b 扫描 w。阈值改变决策而不改变概率或损失。 |
| SVM | [Support Vector Machines](https://scikit-learn.org/stable/modules/svm.html)，§1.4.7.1；LinearSVC primal formulation | 线性软间隔目标与 hinge | 使用 ½‖w‖²+C∑hinge，截距不惩罚；手动参数，未求最优 SVM。‖w‖=0 时几何间隔未定义，数值目标仍定义。任意间隔内点不自动命名支持向量。 |
| CART | [Decision Trees](https://scikit-learn.org/stable/modules/tree.html)，§1.10.7、§1.10.7.1 | 递归阈值划分、加权不纯度、Gini 与叶内类别频率 | 穷举两轴相邻中点，仅接收严格正增益；最小叶样本数、深度上限，无剪枝。对称 XOR 零增益停滞由四点构造独立证明。Gini impurity 不等于收入不平等的 Gini coefficient。 |
| Ensemble | [Ensemble Methods](https://scikit-learn.org/stable/modules/ensemble.html)，§1.11.2、§1.11.3 | 平均集成、随机化与减少成员相关性的动机 | 实际生成等相关 Gaussian 成员误差；不训练 bagging 或随机森林。方差 σ²[ρ+(1−ρ)/m] 来自协方差展开，不宣称所有实际集成都满足等相关。 |
| Boosting | [Ensemble Methods](https://scikit-learn.org/stable/modules/ensemble.html)，§1.11.1.2.3–§1.11.1.2.5；[Decision Trees](https://scikit-learn.org/stable/modules/tree.html)，§1.10.7.2 | 加法预测、拟合负梯度、平方损失均值初值、收缩、回归叶均值 | 每轮实际拟合一维残差最小二乘树桩，最小叶 3、0<η≤1；250 点独立验证。不是 AdaBoost，也不展示任意损失的线搜索。 |
| K-means | [Clustering](https://scikit-learn.org/stable/modules/clustering.html#k-means)，§2.3.2、Lloyd algorithm | WCSS、最近中心分配、均值更新、局部结果与初值 | 步数 0 已含初始分配；每轮更新均值再重分配。集中初始化取最左 k 点，分散初始化为确定性最远点，未称 k-means++。空簇保留旧中心并记录。 |
| GMM / EM | [Gaussian mixture models](https://scikit-learn.org/stable/modules/mixture.html)，§2.1.1、Estimation algorithm expectation-maximization、Singularities | 分量软分配、EM 与初始化、自由协方差奇异风险 | 只估计两均值和一权重，共同 σ 固定；责任度及 M 步独立推导并复算。对数似然不降不保证全局最优；相同初值的对称驻点不会自行分离。未实现自由方差坍缩。 |
| KDE | [Density Estimation](https://scikit-learn.org/stable/modules/density.html)，§2.8.2 | 核平均与带宽平滑 | 直接求和一维 Gaussian 核，尺度因子 1/(nh)。第二图仅前 5 核，部分和面积 5/n；第一图为完整 KDE。有限画幅数值积分不冒充整个实线积分。 |
| Model selection | [Cawley & Talbot (2010)](https://jmlr.csail.mit.edu/papers/volume11/cawley10a/cawley10a.pdf)，摘要、§5.1、§5.3；[官方 nested CV 示例](https://scikit-learn.org/stable/auto_examples/model_selection/plot_nested_cross_validation_iris.html)，开头说明 | 有限选择准则也会被过拟合，完整选择流程需外部评价 | 独立正态 Xⱼ、Y 及固定候选 aXⱼ，所有真实风险恰为 1+a²。每轮择优后生成 400 点全新测试。没有实际拟合、CV 或嵌套 CV；共享验证 Y，不假定候选分数独立。 |
| Metrics | [Metrics and scoring](https://scikit-learn.org/stable/modules/model_evaluation.html)，Classification metrics 中 confusion matrix、precision/recall、ROC、average precision 各节 | 条件分母、阈值曲线、AP 召回增量加权定义 | 按同分组更新，ROC 梯形积分，AP 不作 PR 梯形积分。无预测正类 precision=null；PR (0,1) 是作图约定。sigmoid 转换的是排序分数，未宣称校准。 |
| Likelihood | [NIST/SEMATECH Maximum Likelihood](https://www.itl.nist.gov/div898/handbook/eda/section3/eda3652.htm)，§1.3.6.5.2 | 固定数据、独立似然乘积、最大化定义 | Bernoulli s/n、已知 σ Gaussian 样本均值均由目标求导或平方和分解独立推导。全成功/失败边界 MLE 合法；矛盾候选 log likelihood=−∞。峰值归一化不等于参数密度。 |

## 数学核验与教学修订

第一轮先固定每个图的数学对象及条件：给所有随机实验设置可复现种子；把手动几何、真实训练、机制模拟、固定规则选择区分清楚；每项提供 4 组预设与 3 道有提示和解答的预测/应用题。页面文案不写入个人进度。

<!-- bilingual-en:start -->
The first pass fixed each plot's mathematical object and assumptions. Random experiments have reproducible seeds. Manual geometry, trained models, mechanism simulations and fixed-rule selection are labelled explicitly. Each experiment has four presets and three worked prediction or application exercises, with no personal learning state.
<!-- bilingual-en:end -->

第二轮使用独立小例子和恒等式检查实现。可运行 `node tests/ml.test.js`（在实验室根目录），覆盖 12 模型所有数值控件上下界与每个枚举选项，以及全部 60 个默认/预设配置。当前一次完整运行通过；332,175 个断言主要是逐点有限性和范围检查，不能误称为同样数量的独立概念验证。

<!-- bilingual-en:start -->
The second pass checked independent small examples and mathematical identities. Run `node tests/ml.test.js` from the lab directory. It covers all numerical control boundaries, categorical options and sixty default/preset configurations. The latest run passed. Most of the 332,175 assertions are pointwise finiteness and range checks, not independent conceptual tests.
<!-- bilingual-en:end -->

| 实验 | 有意义的独立核验 |
|---|---|
| KNN | 三点投票、距离尺度改变邻居、固定等距次序。 |
| Logistic | w=b=0 的损失 log 2；softplus(1000) 有限；改阈值概率不变。 |
| SVM | w=b=0、48 点、C=2 得目标 96；C 增量等于 hinge 和。 |
| CART | 可完全分开的四点根增益 0.5；对称 XOR 根增益 0；最小叶约束；严格对称数据模式在 n=30/100/150 均停为一叶。 |
| Ensemble | ρ=0 理论 σ²/m；ρ=1 时各成员平均与同一共享噪声一致；经验方差有 Monte Carlo 容差。 |
| Boosting | 40 轮 η=1 的训练 MSE 不增；0 轮为训练均值；改步数不更换训练数据。 |
| K-means | 四点两簇已知中心与 SSE=4；迭代不增；重复初始中心触发空簇策略。 |
| GMM | 多种 σ 下对数似然不降；重合初值保留对称；重合分量密度等于单 Gaussian。 |
| KDE | 密度数值积分约为 1；改变 h 保持样本；前 5 核部分和逐点等于五条贡献之和。 |
| Selection | 所有候选风险 2；80 候选与 2 候选共用前缀、同一次验证最小值不增；全新测试均值接近真实风险。 |
| Metrics | 完美、反向和完全同分的手算 ROC/AP；阈值 1 没有预测正类；改阈值 AUC 不变。 |
| Likelihood | Bernoulli 全成功/失败边界及 −∞；MLE s/n；Gaussian MLE 为样本均值。 |

第三轮回看教学信息。发现最初 K-means 的“前 k 点”因合成数据轮流取三个团，实际很分散，遂改成“最左 k 点”以形成真实集中初始化。核对并修正 SVM 的措辞为 hinge 损失求和，避免把它误写为平方损失；将 m<0 的计数直接命名为负函数间隔样本数，避免零法向时把落在边界上的点误算成“全部分类正确”。对 EM 统一采用“似然不降、可能局部驻点”的限定，不把官方文档的简化收敛表述外推成无条件全局保证。

<!-- bilingual-en:start -->
The third pass reviewed pedagogy. The original first-k-points initialization was accidentally dispersed because the generator alternated among clusters; it was replaced with the leftmost k points. SVM wording was corrected to a sum of hinge losses. EM statements consistently distinguish nondecreasing likelihood and possible stationary points from global optimality.
<!-- bilingual-en:end -->

## 知识原子映射

`ml-atom-map.json` 的每个目标均先按文件名检索，再打开正文核对；`support` 逐项解释相同公式、决策规则或边界的关系。脚本仅写入已经人工判断的目标并检查文件存在。未修改原子，也未复制其个人属性。

<!-- bilingual-en:start -->
Every destination in `ml-atom-map.json` was searched by filename and its body read. Each support field states the exact shared equation, decision rule or boundary. Scripts only serialize reviewed choices and verify existence. The atoms and their metadata were not edited.
<!-- bilingual-en:end -->

CART 当前没有相应决策树/Gini impurity 原子，映射明确留空：`基尼系数.md` 属收入不平等，不是分类不纯度，不能因同名硬连。KNN 与 `聚类尺度.md` 只复用缩放即距离加权的恒等式；SVM 与 `梯度与水平集.md` 只复用法向几何，并未借此声称原子定义了 SVM。未把初始 overfit 页面映射到 MSE 偏差方差分解；独立分解实验由后续建设处理。

<!-- bilingual-en:start -->
CART has no exact decision-tree or Gini-impurity atom yet, so its mapping is empty. The existing Gini-coefficient note concerns inequality and must not be conflated with classification impurity. KNN links only the shared rescaling identity; SVM links only normal-vector geometry. The original overfitting page is not used as a substitute for an actual bias–variance decomposition.
<!-- bilingual-en:end -->
