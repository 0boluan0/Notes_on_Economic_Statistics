# 表示、生成与决策：来源与逐模型核验

核验日期：2026-10-06。对应 `assets/advanced-math.js`、`assets/advanced-content.js` 与 `tests/advanced.test.js`，共 12 个实验、33 张计算图。每个实验有 4 个可运行预设及 3 个带提示和推导答案的挑战。这里记录实际执行的来源、数学和教学审阅；浏览器逐图视觉审阅另由集成记录补充，不用数值测试代替视觉验收。

## 第一轮：重新打开来源并限定模型责任

| 实验 | 实际重开的主来源与位置 | 采用的论点及演示边界 |
| --- | --- | --- |
| positional | [Vaswani et al.](https://arxiv.org/html/1706.03762v7)，§3.5 | 原始固定 sin/cos 位置编码；范数、相对内积由三角恒等式独立推导。底数 10、100 为教学变体；没有声称长序列泛化保证。 |
| gnn | [Kipf & Welling](https://arxiv.org/pdf/1609.02907)，§2 Eq. (2)、§2.2 | 对称度归一化和自环。实验将可训练 W 设为单位、激活设为恒等；邻居平均及残差是显式比较项。 |
| embeddings | [Mikolov et al.](https://arxiv.org/pdf/1301.3781)，§4.1；[CMU Lecture 24](https://stat.cmu.edu/~cshalizi/dm/20/lectures/24/lecture-24.html)，§4 | 词向量使用余弦的实际背景，以及距离和长度归一化。合成二维几何不宣称完成词向量学习或语义评价。 |
| autoencoder | [Deep Learning Ch.14](https://www.deeplearningbook.org/contents/autoencoders.html)，§14.1 | 线性解码、平方误差的 PCA 子空间关系；非线性和过容量情况不直接继承结论。 |
| vae | [Kingma & Welling](https://arxiv.org/pdf/1312.6114)，§2.2、§2.4、Appendix B | Gaussian 重参数化、变分下界和 KL；本页一维线性似然可精确积分，不以单样本估计替代期望。 |
| gan | [Goodfellow et al.](https://arxiv.org/pdf/1406.2661)，§3 Eq. (1) 及非饱和替代段落 | 两种生成器目标的梯度差异；固定判别器轨迹不代表 GAN 交替训练成功。 |
| flow | [Rezende & Mohamed](https://arxiv.org/pdf/1505.05770)，§3 | 可逆映射的 Jacobian 换元。本页 tanh 单调映射为独立构造，没有训练步骤。 |
| diffusion | [Ho et al.](https://arxiv.org/pdf/2006.11239)，§2 Eqs. (2)、(4)、(6)–(7) | 前向 Gaussian 加噪。本文演示的 x₀\|xₜ 后验由另行指定的 Gaussian 数据先验推导，和论文 xₜ₋₁\|xₜ,x₀ 有明确区别。 |
| rl-bellman | [Sutton & Barto 作者教材草稿](https://web.stanford.edu/class/psych209/Readings/SuttonBartoIPRLBook2ndEd.pdf)，Ch.3、§4.4 Eq. (4.10) | 已知有限 MDP 的 Bellman 备份；三状态奖励和回路为本项目独立构造。 |
| rl-policy | [Sutton et al., NIPS 1999](https://proceedings.neurips.cc/paper/1999/file/464d828b85b0bed98e80ade0a5c43b0f-Paper.pdf)，§1 Theorem 1、start-state formulation、Appendix Eq. (7) | 指定初始状态的折扣访问权重；直接微分本模型回报，和访问权重形式独立对照。 |
| double-descent | [Belkin et al.](https://arxiv.org/pdf/1812.11118)，§2 Random Fourier features、Appendix C.1 | 固定随机特征与欠定最小范数拟合。当前实数余弦特征、五维合成回归和论文复特征/MNIST 不同，风险曲线全部现场求解。 |
| fairness | [Hardt, Price & Srebro](https://arxiv.org/pdf/1610.02413)，§2 Definition 2.1、§2.1 | 二元 equalized odds 对应相同 TPR/FPR。PPV 与基准率关系另由 Bayes 公式推导，不套用范围更广的校准不可能定理。 |

PDF 只暂存于系统临时目录用于文字核对，没有把原论文新增为 vault 内的永久 PDF。官方 RL 教材链接读取失败后，Bellman 使用可读取的作者草稿，策略梯度另读 NeurIPS 原论文；没有把未打开的失效镜像登记为已核验来源。

## 第二轮：推导、反例与教学修订

| 实验 | 实际核验与边界 | 由此落实的教学内容 |
| --- | --- | --- |
| positional | 每个频率对平方和 1；任意共同平移不改变内积；单频随 Δ 周期变化 | 明确圆图只显示第一频率，热图只覆盖位置 0–31；拒绝“距离越远相似度越低”的暗示。 |
| gnn | mean 行和为 1，按度数加权总量守恒；symmetric 保持 √degree；无自环星形的奇偶两周期 | 四个预设包含周期反例；非正则图两种归一化的极限不能混说成同一常数。 |
| embeddings | 内积和余弦缩放差异、余弦定理、零向量分母 | 零向量显示未定义；将代数正交与非零方向的 90° 含义区分。 |
| autoencoder | L=E‖x‖²+(g²−2g)E(uᵀx)²；PCA 弃置特征值乘 79/80 | 所有重构误差按每点两坐标平方和；g=0 与 g=2 等误差挑战；总体等方差不等于样本特征值相等。 |
| vae | Gaussian KL 非负；μ、logvar 两个梯度经数值微分核对；ε 不影响解析目标 | 单个展示样本与期望目标分开；β=1 才对应标准负 ELBO（去常数）。 |
| gan | 对两个稳定 softplus 目标作中心差分；k=0 和负斜率纳入检查 | 判别器冻结意味着可越过真实参考点；损失大不保证生成参数梯度大。 |
| flow | 导数严格正、二分逆往返、6000 分段 Simpson 独立积分约为 1 | 明示有限 z 区间漏掉尾部及梯形误差；不把网格积分偏差隐藏成精确归一化。 |
| diffusion | 条件方差=先验方差−cov²/边际方差；噪声条件均值=−√(1−ᾱ)score | 解析参照不能逐样本还原实际噪声；条件方差不随当前观测值改变只属 Gaussian 特例。 |
| rl-bellman | 精确固定点、同步初始两轮 1→1.6、残差/(1−γ) 误差界 | 奖励在动作时收到；到 S₁ 的奖励需要一次折扣；不把 value iteration 叫作 Q-learning。 |
| rl-policy | 解析 J 直接微分、中心差分、折扣访问形式三者一致 | 展示精确梯度而非 REINFORCE 样本；重复访问权重不可遗漏，sigmoid 饱和不等于最优。 |
| double-descent | 训练正规方程、岭惩罚最优性、宽矩阵插值及系数位于行空间；无噪声真函数恢复 | 横轴不含截距，插值位置 m=n−1；λ=0 全系数最小范数与 λ>0 不惩罚截距的选择约定明确。 |
| fairness | 每组四格总量 1；条件率恢复、零预测 PPV=null | 相同 TPR/FPR 不等于相同 PPV；TPR/FPR 为零的例外独立演示，组别不代表真实人群。 |

## 第三轮：计算图、预设和控件契约

## 第五轮：其他作者的独立反例审阅

另一位审阅者对前六个实验另跑了 66 项代数/数值核验，计算通过，但在 embeddings 文字和指标上找出两项问题。已修改并补回归断言：

1. “只有单位长度时余弦与内积相同”错误地把充分条件写成必要条件。反例包括长度乘积为 1，以及任意非零长度的正交向量；现改为“都单位化时必相同，一般不能互换”。
2. 任一向量为零时，原夹角指标仍显示构造参数。现和余弦指标一样显示“零向量：未定义”，方向控件只用来构造非零向量。

修改后再次通过全部 advanced 测试。该轮真实发现和修改的是条件措辞与未定义边界，不能以其替代整库屏幕交互验收。
