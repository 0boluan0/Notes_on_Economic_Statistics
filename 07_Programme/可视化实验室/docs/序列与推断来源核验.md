## 数学推导与边界审查

- **RNN**：从末端令敏感度为1，按 `s_t=s_(t+1) a φ′(z_(t+1))` 反传；共享权重梯度为所有时间使用的贡献之和。线性无输入情形分别核对 `h_T=a^T h₀`、初态敏感度及损失对a的闭式导数。
- **LSTM**：初态明确 `h₀=o tanh(c₀)`，不能把它当常量漏导。完整递归为 `dc_t=f dc_(t−1)+i(1−g_t²)r dh_(t−1)`；直通路径仅 `f^t`。r=0两者重合；门也依赖状态的一般LSTM还含额外项，未被本简化模型覆盖。
- **InfoNCE**：数值实现减最大分数后指数归一化；损失用log-sum-exp。自由Query梯度与每度角度导数分别检验，角度链式因子含π/180。重复的正负向量构成不可区分边界，低温不会消除。
- **Jacobian**：仿射项是 `F(a)+J(a)(x−a)`。沿单位方向，各分量二阶余项分别受 `|α|h²/2` 和 `|β|h²` 控制，因此所绘保守范数上界为 `½√(α²+4β²)h²`。实际对角方向可有更紧上界；显示上界不是伪造误差曲线。
- **Gaussian后验**：精度为先验精度加设计信息；新观测方差严格是潜在函数方差加σ²。逐点95%边界与联合二维95%椭圆不同；后者半径平方是 `−2log(.05)`。增加n使用同一个固定样本池前缀，保证“增加资料”确实是嵌套数据。
- **SCM**：完整枚举8个Z/T/Y联合格。外生Uniform彼此独立，处理倾向在[.1,.9]、结果概率在[.05,.85]；已给定Z是充分共同原因。观察量用 `P(Z|T)`，干预量用总体 `P(Z)`，两者的混合权重不能互换。

## 独立验收与重跑

从实验室目录运行，无第三方Node依赖：

```sh
node tests/sequential.test.js
```

需要额外NumPy交叉核对时，指定已有Python环境：

```sh
LAB_NUMPY_PYTHON=/absolute/path/to/python node tests/sequential.test.js
```

本轮98个默认/控件边界/预设情境通过；还有独立函数扰动、闭式、矩阵恒等式、60个SCM参数组合核验。15318项数学及结构检查与67020项图形坐标检查分开计数，不能把坐标数量当作独立数学命题。4个极端/一般Gaussian后验同时经NumPy线性方程求解通过。执行时间、来源SHA-256和计数在 `tests/sequential-report.json`。

独立方法：

- RNN用单独的标量前向递归扰动共享权重、初态和每个输入，检验反传梯度。
- LSTM用前向递归重新计算扰动初态后的细胞/隐藏输出，不调用被测梯度；另检验r=0、f=1、候选反馈为0/非0的闭式边界。
- InfoNCE分别扰动自由二维向量和角度，核对两种不同单位的梯度；核对重复候选、相反候选、增加负样本的单调性。
- Jacobian逐列扰动真实F；全部网格坐标与余项上界逐点核验。
- Bayesian后验另用逐观察Gaussian条件更新算法计算均值/协方差，区别于实现中的批量2×2逆；可选NumPy独立solve再交叉确认。联合椭圆每点检查Mahalanobis半径。
- SCM从联合格重新恢复条件均值与分层概率；独立加权结果与干预结构的闭式τ比较。

原子映射保存在 `sequential-atom-map.json`；只关联已读过核心定义和适用边界的目标，不借相似标题扩大它们的数学职责。
