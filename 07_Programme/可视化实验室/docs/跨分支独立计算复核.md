# ML 与神经网络分支的独立计算复核

2026-10-06：由 advanced 分支作者独立读取其他作者的 ML/DL 实现，并以 NumPy 从导出观测重新计算定义性结果。测试代码 `tests/cross_review_ml_dl.py`；结果 `tests/cross-review-ml-dl-report.json` 记录源文件 SHA-256、具体断言名与通过情况。

实际运行结果：36 个配置、12 个模型、542 项断言通过。这里的独立性是重新实现模型定义与最优性条件，未复用 JavaScript 的拟合函数或梯度 helper，也没有照抄浏览器 PRNG。生成样本作为输入数据读入后，重新计算以下结果。

| 模型 | 独立参照与边界 |
| --- | --- |
| tree | 递归枚举所有允许的独特中点阈值，重算加权 Gini 和最佳增益；检查每片叶的停止原因和 minleaf；严格对称 XOR 不分裂。 |
| boosting | 对每轮残差穷举最小叶数约束下的树桩 SSE，重新累加 shrinkage 预测并检查每轮训练风险。包括零轮、学习率 1、噪声上界。 |
| kmeans | 从原始中心逐轮重新求距离、分配和簇均值；检查 SSE 与最终分配；包括集中初始化、5 簇、零轮。 |
| gmm | 从两个 Gaussian 分量对数密度用 logaddexp 重算似然和责任度，检查每次 M 步均值/权重和似然单调；包括重合初值与窄方差。 |
| metrics | 混淆计数逐项重算；AUC 用正负样本两两比较，而非原实现的曲线梯形；AP 独立按唯一阈值积分；无正预测保留 precision=null。 |
| likelihood | Gaussian 相对似然用已知 n(μ−均值)² 分解重算；Bernoulli 内点/边界 MLE 及不可能观测的 −∞ 标志。 |
| initialization | 原始 W 和输入矩阵进行 NumPy 前向传播与完整反向矩阵乘积；独立区分中心方差和二阶矩，包括深 20 层小尺度。 |
| regularization | 枚举全部 16 个 Bernoulli 掩码，精确求概率、均值、方差、期望损失；逐行重算实际模拟输出；包括 dropout=0 和 0.8。 |
| normalization | 按真实统计轴重算均值、总体方差、epsilon 标准化和 γ/β；核对标准化方差精确为 var/(var+ε)，含零方差组和 γ=0。 |
| convolution | NumPy 补零后逐窗口求不翻核互相关；核对输出形状、选定位置与九项乘积，包括 stride=2/padding=1。 |
| pooling | 逐窗口重算 max/mean；检查 mean 局部梯度，max 梯度位于最大值集合且为有效凸权重；包括并列最大值。 |
| attention | 独立矩阵 QKᵀ、允许集合 masked softmax、AV；检查所有屏蔽位置精确为零及权重和为 1；包括因果第一行和零分数。 |

人工阅读另外找出两项教学问题，并向 DL 作者报告，由其在所拥有文件中修复：

- Dropout 的真实分布只有有限个输出值。连续密度直方图可能遮蔽离散概率质量的含义，建议显示合并相同输出后的精确/经验 PMF。
- Max pooling 并列点的准确说法是普通导数不存在、次梯度不唯一；不能把它描述成多个普通导数。
