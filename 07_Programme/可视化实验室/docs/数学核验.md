# 数学核验

此记录覆盖首批 12 个数学与统计实验的计算正确性，以及可复算的 Python 教学伴读。原始数据全部是合成数据；没有读取或生成个人学习状态。

## 独立性与证据

网页内核是 `assets/math.js`；核验程序是 `tests/independent_numerics.py`。后者通过 Node 调用网页，读取输出中的原始样本、设计矩阵、预测、区间和特征值，再用 **NumPy/SciPy** 复算。它没有调用网页内部求解器作为正确答案，也没有复制网页伪随机数发生器。

分布参考来自 SciPy 的 Normal/Beta CDF、SF、PPF 与 Gamma PDF；线性代数参考来自 NumPy 的 SVD 最小二乘和对称矩阵特征分解。固定随机结果的性质与参数比较另外用重复运行核对。

本次执行覆盖 **49 个实验案例、95 个辅助函数案例**，包含全部 12 个默认场景与下表的关键边界。`tests/independent-report.json` 保存执行时间、软件版本、内核 SHA-256、各实验案例数以及通过状态。报告中的大量断言主要逐点检查图表坐标，不能把坐标数量解读为同样数量的独立数学命题。

## 数值容差与边界的处理

普通计算通常使用绝对容差 $2\times10^{-10}$、相对容差 $2\times10^{-9}$；分布尾概率、Beta 分位数和病态高阶拟合有单独明确容差，见测试代码。高阶插值中的大系数会放大舍入误差；核验同时比较预测与误差，不只看系数。正态极端尾概率使用 SciPy SF/CDF，避免用 `1-CDF` 人为把小概率抵消为零。

- Cauchy 的样本均值总能在有限样本中算出一个数，这不使总体均值或方差变为已定义。
- 置信区间中的 95% 属于重复抽样程序；Beta 可信区间中的 95% 是给定模型、先验、数据后的后验概率。
- Ridge 使用平方和损失，截距不惩罚。网页条件数针对 `XᵀX`；Python 附件的 `conditionNumber` 针对 `X`，已经在附件说明平方关系。
- 欠定未惩罚拟合明确采用最小范数解并标出非唯一；数值秩不足时不伪造唯一系数。矩阵奇异也不伪造有限逆矩阵。
- PCA 特征向量的符号任意，等特征值时方向不唯一。样本总体各向同性也不要求有限样本的两个特征值完全相同。
- PCA 每观测重建平方误差为 $\frac1n\sum_i\|z_i-\hat z_i\|^2$。样本协方差分母为 $n-1$，故一维重建误差等于 $(n-1)\lambda_2/n$。
- Bootstrap 的精确条件 SE 是 $s\sqrt{n-1}/n$；它与 $s/\sqrt n$ 的差异既有有限样本定义差异，也有有限重抽样次数的模拟波动。

## 数学与机器学习基础6项交叉核验

`tests/independent_foundations.py` 对另一个实现者编写的 `foundations-math.js` 进行了独立核验。运行：

```sh
python tests/independent_foundations.py
```

使用与本页原有Python环境相同的NumPy/SciPy依赖。29个默认/极端情境、326项科学检查通过（包含极小正奇异值和极近但不相等的奇异值）；计数、时间和实现SHA-256见 `tests/independent-foundations-report.json`。

- SVD：NumPy LAPACK奇异值、左右正交性、实际Frobenius/谱误差、秩约束和尾部奇异值误差。
- 偏差—方差：独立Legendre设计与增广SVD重算首个真实拟合；从全部重复结果核对经验均值、方差、偏差平方和新响应风险。
- 核岭：独立Gram计算与NumPy线性系统求解；linear/poly2另在显式有限特征空间做primal岭回归，核对预测和RKHS范数。
- 熵：SciPy熵/KL交叉核对，包括正质量对零支持、确定分布和bits/nats。
- Softmax：SciPy稳定Softmax/log-sum-exp、完整Jacobian和交叉熵梯度，核对温度及共同平移。
- 校准：按原始概率独立分箱，重算空箱、ECE、实际/条件期望Brier与阈值准确率。

语义复查读取了全部关联原子的定义、条件与边界。发现SVD构造中原先使用数值容差决定精确秩与重根，作者已改为已知奇异值严格大于0/严格相等，并加入极小正值情境。熵页通往“KL参考约束”的关系仅是离散概率比公式的应用桥接，不把该策略优化原子当作通用KL定义。
