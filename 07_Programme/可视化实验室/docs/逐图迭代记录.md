## 数学统计基础组

独立 NumPy/SciPy 计算与公式边界核验已完成。随后进行了全组实际渲染审查，并对以下问题修改后重看；最终集成后的控件、窄屏与离线回归另见交互报告。

| 实验 | 实际渲染检查与迭代 |
|---|---|
| tangent | 初版全局坐标掩盖差商逼近；改为围绕当前点的局部窗口，并增添前向与中心差分误差的双对数图。第二次渲染确认切线/割线分离、两种误差阶数可辨；零附近误差断线并解释精度下限。 |
| linear | 核对网格、单位正方形、两列向量与等比例坐标；添加面积淡填充和基向量箭头，让面积与方向有直接视觉对象。奇异与反向预设由参数检查覆盖。 |
| projection | 初始30°几乎与向量同向，残差太短；默认改60°，添加三个向量箭头及端点名称。再次渲染确认残差从投影端点连到原向量，等比例轴保留直角关系。 |
| gradient | 检查所有等高线、轨迹与完整损失图；明确轨迹视窗截断而损失包含全部步。新增用户主动启动的逐步播放与单步前进，以对应真实迭代。 |
| sampling | 分别检查均值分布和独立运行均值路径；保留精确Gamma/正态密度的不同标签，确认两图横轴一个为统计量、一个为样本量。重尾裁切由图下注释和原始导出区分。 |
| confidence | 初版100条区间过密；按条数提高图高，再次完整渲染确认覆盖与未覆盖线分离。覆盖指标使用全部重复，图题说明只画前100次。 |
| testing | 初版只有密度与阈值线，难以看见概率；加指定备择下拒绝域面积，并另画H₀下p值双尾面积。再次渲染确认两幅图分别回答功效与p值，数值由完整CDF计算。 |
| bayes | 检查先验/后验密度与相对似然两图；密度和峰值归一似然使用不同纵轴及明确说明，不能读作相同归一方式。无观测与端点预设由数值检查覆盖。 |
| regression | 完整检查系数、拟合值与响应、残差三图。把系数坐标标为β₁/β₂，避免1.5被误读成第三个系数；保留OLS/ridge的轻微错位便于重合时辨认。 |
| overfit | 仅有拟合曲线不能直接比较复杂度；添加同一数据上1–15次实际重拟合的训练/验证误差图。再次渲染检查当前次数标记、对数误差轴、验证含义和截断下限。 |
| pca | 完整查看主轴、重构、得分三图；检查等比例坐标保留几何、重构误差与分析尺度一致，得分图的PC1/PC2轴不冒充原坐标。 |
| bootstrap | 检查条件重抽均值分布与原样本散点；区间端点、样本均值有分开的线型，原始样本与重抽分布使用不同横轴。有限样本SE修正与覆盖边界已独立核对。 |

## 机器学习组的首轮图形复核

已逐项看过 KNN、logistic、SVM、CART、平均集成、boosting、K-means、GMM、KDE、验证集选择、ROC/PR/混淆矩阵、似然的全部默认图。发现并交回修订：KNN/CART的观测颜色与概率底图未对齐；CART默认XOR不适合初次看划分；K-means中心与普通样本难区分；KDE单核除以n后过小，需另画核贡献的部分和；GMM责任度端点贴边。

其他图已核对坐标、模拟对象和教学边界：手工logistic/SVM没有被写成最优训练结果；平均集成是相关误差机制，不冒充随机森林实现；验证选择模拟所有候选具有相同真实风险；混淆矩阵列为真实类别、行为预测类别；PR使用AP定义并区分梯形面积。

本记录继续随集成审查更新；尚未写入完成记录的组不能据此视为已经完成逐图验收。

## 后续分组的实际修订

全60项默认图已在本地浏览器逐项渲染检查，随后对发现的问题改图并重新查看。以下记录具体变化，不把程序坐标断言的数量当作视觉质量分数。

- **机器学习12项复查**：KNN查询点使用菱形并突出参与投票的邻居；CART初始使用AND分布，另保留贪心方法在对称XOR停住的反例；聚类中心与样本区分；KDE显式标注前5个核的贡献及部分和；GMM责任度纵轴保留端点空间。
- **神经网络12项复查**：ReLU导数在零点断开；MLP合成输出线加粗，神经元查询点用菱形；Dropout从连续密度直方图改为精确与经验离散概率质量对比；卷积/池化被选窗口加白色描边；注意力选行与输出向量有明确视觉标记。反向传播由数值节点链继续重做到带参数分支和局部导数的同图反传，详见本轮重做。
- **高级分支12项复查**：图神经网络节点放大并区分所选节点；Bellman图标注真实奖励、转移概率和自环；经验双降添加独立验证风险窗口，避免训练误差极小值压平风险形状；嵌入的零向量角度保持未定义，删除“点积与余弦相等当且仅当都为单位向量”的错误绝对化表述。
- **基础补充6项复查**：SVD基向量箭头与标签加粗，秩一重构与原映射区分；保留零奇异值而不人为抬高；偏差方差图中平均拟合与真实函数用不同颜色和线型；信息量图保留无穷值标签；核、Softmax、校准图检查归一化对象与评估口径。
- **序列与推断6项复查**：RNN、LSTM、InfoNCE、局部Jacobian、不确定性、混杂的全部默认图检查。LSTM明确直接记忆路径与完整总导数，并加入非零反馈情境；InfoNCE去掉重复的Query图例；Jacobian保留局部扰动与绝对坐标的区别。
