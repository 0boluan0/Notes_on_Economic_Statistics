| 实验 | 实际重开的来源及位置 | 核对结论与限定 |
|---|---|---|
| SVD | [LAPACK Users’ Guide](https://www.netlib.org/lapack/lug/node32.html)；[Murray et al., Randomized Numerical Linear Algebra: A Perspective on the Field With an Eye to Software](https://www.netlib.org/utk/people/JackDongarra/PAPERS/rand-templates.pdf)，§4.1.1，式 (4.2)–(4.6)，印刷 pp.65–66 / PDF pp.72–73；[MIT 18.06 Lecture 29](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/resources/lecture-29-singular-value-decomposition/) | 核对分解、秩一展开、截断谱/Frobenius 误差。示例从两旋转和非负伸缩实际构造矩阵；仅覆盖非负行列式的实 2×2 族。重复奇异值下共同换基不改变 A 的等式直接乘矩阵验证。 |
| Bias/variance | [Stanford CS229 main notes](https://cs229.stanford.edu/notes2022fall/main_notes.pdf)，§8.1.1，印刷 pp.110–111 / PDF pp.111–112 | 核对训练随机性与独立测试噪声分解。此处条件于固定训练设计，只重复抽响应噪声并实际重新拟合。分母 R 的有限集合分解来自展开平方和；新响应独立噪声均值为零，因此交叉项消失。未把示意 U 形当无条件定理。 |
| Kernel | [同一 CS229 原讲义](https://cs229.stanford.edu/notes2022fall/main_notes.pdf)，§5.1–5.4，印刷 pp.49–59；[scikit-learn KRR](https://scikit-learn.org/stable/modules/kernel_ridge.html)，§1.3 | 核对特征内积与 Gram 半正定、平方损失加核空间范数惩罚。独立推导 sum-loss 口径的 (K+λI)α=y；用实际 Cholesky 求解，λ严格正，无显式求逆。线性/二次核的常数特征也受罚。 |
| Entropy | [Dive into Deep Learning, Information Theory](https://d2l.ai/chapter_appendix-mathematics-for-deep-learning/information-theory.html)，§22.11.2.2、§22.11.4.1–4.2、§22.11.5.1–5.2 | 核对离散熵、交叉熵、KL 方向与支持零的无穷边界。原网页示例代码的 `abs`/`nansum` 不作为数值规范；本实现逐项明确区分 P=0 与 P>0,Q=0，不用绝对值修复 KL，不平滑零支持。 |

| Calibration | [scikit-learn Calibration](https://scikit-learn.org/stable/modules/calibration.html)，§1.16.1–1.16.2；[Guo et al. 2017](https://proceedings.mlr.press/v70/guo17a/guo17a.pdf)，§2 式 (2)–(3)、§4.2 式 (9) | 核对可靠性图、箱计数的重要性、有限分箱 ECE、温度缩放动机。本页用正类概率/正类频率，明确区别于原论文 top-label correctness/confidence。人工指定映射，不拟合温度或其他校准器。已知 p 下 Brier 分解独立展开 Bernoulli 期望。 |

## 三轮数学与教学核验

第一轮确定图形要回答的对象：SVD 是实际矩阵映射；偏差方差的随机对象是重新训练流程；核回归必须求解；熵保留无穷；Softmax 必须有三类耦合；校准保留已知风险与随机标签的区别。未创建个人学习记录或评价个人掌握情况。

<!-- bilingual-en:start -->
The first pass fixed each mathematical object: actual matrix maps, repeated training, a solved kernel model, genuine infinite divergences, coupled multiclass probabilities and a distinction between known risk and random labels. No personal learning records were created.
<!-- bilingual-en:end -->

第二轮运行 `node tests/foundations.test.js`，涵盖 30 个默认/预设配置、所有控件极值和枚举选项。最新运行通过，126,822 个断言多数是图点范围/有限性检查；独立概念检查列在下表，不以逐点数量夸大验证力度。

<!-- bilingual-en:start -->
The second pass runs `node tests/foundations.test.js`, covering thirty default/preset configurations and every control boundary or categorical option. The latest run passed. Most of its 126,822 assertions check plotted-point ranges or finiteness; the substantive independent checks are listed below.
<!-- bilingual-en:end -->

| 实验 | 独立验算 |
|---|---|
| SVD | 以 AᵀA 的二维特征值核对 σ²；UᵀU=VᵀV=I；三种 k、σ₂=0、σ₁=0、重奇异值共同旋转；实际元素误差对照尾部平方和。 |
| Bias/variance | 预测 1,2,3 对真值 2 的 MSE=2/3；常数拟合等于样本均值，经验方差对照 σ²/n；无噪声低次拟合方差消失但偏差保留；R 扩大保留前缀；每点平方和恒等式。 |
| Kernel | Cholesky 解手算 2×2 系统；线性核与独立手算的二维 primal ridge 对照；两点 RBF 的逆矩阵解析解；poly2 与 (1,√2x,x²) 内积相等；50 点系统残差检查。 |
