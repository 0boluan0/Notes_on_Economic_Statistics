# 神经网络 12 实验：来源、数学与逐图核验

本页记录 `dl-math.js` 与 `dl-content.js` 的可复核模型及实际审查发现。实验均为明确写出的合成模型。手工权重、随机初始化、单步结构不能用来宣称训练效果或实际任务性能。核验日期：2026-10-06。

## 来源重开与适用边界

以下链接均已重新打开，核对具体段落或公式。PDF 页码指文件页序。

| 实验 | 实际核对资料 | 支持内容与实验边界 |
|---|---|---|
| activations / neuron / mlp | [D2L §5.1.1–5.1.2](https://d2l.ai/chapter_multilayer-perceptrons/mlp.html) | 仿射层、非线性、Sigmoid/tanh/ReLU及导数。输入增益的链式因子、三ReLU帐篷构造由实验直接推导；不把显式构造称为训练。 |
| backprop | [D2L §5.3](https://d2l.ai/chapter_multilayer-perceptrons/backprop.html) | 缓存前向中间量，按计算图反向使用链式法则。标量平方损失梯度与中心差分独立推导。 |

| optimizers | [Adam，Algorithm 1，PDF p.2](https://arxiv.org/pdf/1412.6980) | 一二阶矩指数平均、偏差修正、根号外epsilon。GD和未归一化动量在同一二次目标上直接计算；同学习率不构成公平调参后的优劣比较。 |
| regularization | [Dropout，§4及Fig.2](https://www.jmlr.org/papers/volume15/srivastava14a/srivastava14a.pdf) | 独立保留掩码及训练/推理缩放。原论文p是保留率，本页p是丢弃率。倒置缩放下固定线性读出的均值、方差和平方损失分解由本实验推导；不将一般网络Dropout等同普通L2。 |
| normalization | [BatchNorm §3，Algorithms 1–2](https://proceedings.mlr.press/v37/ioffe15.pdf)、[LayerNorm §3，式3](https://arxiv.org/pdf/1607.06450) | BN训练态跨样本统计与LN样本内跨特征统计；方差分母N、epsilon和仿射参数。当前批次统计不冒充BN推理时的运行统计；本页各特征使用共同gamma/beta以隔离统计轴。 |
| convolution | [D2L §7.2.1/7.2.6](https://d2l.ai/chapter_convolutional-neural-networks/conv-layer.html)、[§7.3.1–7.3.2](https://d2l.ai/chapter_convolutional-neural-networks/padding-and-strides.html) | 实现互相关而不翻转核；步幅、补零与空间尺寸。3×3核固定且单通道。 |
| pooling | [D2L §7.5.1](https://d2l.ai/chapter_convolutional-neural-networks/pooling.html) | 最大/平均窗口聚合；局部位移敏感度不等于全局平移不变。并列最大值处选择首个行优先位置为一个次梯度，非唯一导数。 |
| residual | [ResNet §3.1–3.2，式1](https://arxiv.org/pdf/1512.03385) | 恒等捷径相加。原论文完整块含其他层及相加后激活；本实验只研究标量相加子模块的复合与雅可比乘积，不复现完整架构。 |
| attention | [Attention Is All You Need §3.2.1，式1；§3.2.3](https://papers.nips.cc/paper_files/paper/2017/file/3f5ee243547dee91fbd053c1c4a845aa-Paper.pdf) | 缩放点积、Key轴Softmax、Value读取和解码掩码。额外温度与强度为明确扩展；四个二维向量无语言语义。 |

## 第1轮：公式、边界与教学一致性

- 激活图原始采样可能跨过不在网格上的ReLU拐点。已在跨零段显式断开导数曲线；数学导数不存在时不报0或1。
- 注意力分数图保留有限原始分数，以“×”表示被屏蔽位置；权重图该位置严格为0，避免把原始分数误作有效权重。
- He与Xavier注明分布版本、近似分析假设、二阶矩/方差区别；实际有限网络的幅度衰减不被人为修成理论平线。
- Dropout引用位置从不支持定义的相关工作/特征分析段落改为§4与Fig.2，明确原文保留率和界面丢弃率的记号差异。
- 残差文案明确展示相加子模块，不能把标量共享系数链称为完整ResNet。
- 每项有4个预设、3道含提示和推导的练习。12个主公式已用本地KaTeX严格解析；控件与参数schema逐项对齐。

## 独立数学验收与重跑

从本目录运行：

```sh
node tests/dl.test.js
```

测试在264个默认、边界、枚举、预设情境中检查12个实验；详细计数、时间和模型SHA-256保存在 `tests/dl-report.json`。当次共有6996项数学/结构检查和162311项图形坐标检查。大批坐标检查只用于有限性、边界与色标一致性，不代表同等数量的独立科学结论。

| 实验 | 独立依据 |
|---|---|
| activations / neuron | 直接标量扰动核对导数、Sigmoid对称性、零权重和明确边界 |
| mlp | 三ReLU帐篷闭式解；3/5/7单元线性激活整体抵消 |
| backprop | 对x、w、b、v直接扰动标量损失，不通过被测梯度表达式 |
| initialization | 独立完整前向复合后的输入扰动，核对反传；直接重算矩统计与公共随机抽样尺度 |
| optimizers | GD/Adam第一步闭式、动量0重合、每一步真实二次目标 |
| regularization | 穷举16个掩码的概率、期望、方差与期望损失；每次模拟输出从掩码重算 |
| normalization | 逐组独立均值/方差、epsilon后的方差、BN平移不变及gamma0退化 |
| convolution | 从未填充的原始矩阵独立索引36种图案/核/步幅/补零组合，核对尺寸和逐项乘积 |
| pooling | 36种最大/平均、尺寸、步幅、图案组合；窗口、梯度支持及总和 |
| residual | 线性链闭式aⁿ/(1+a)ⁿ，非线性复合有限差分，恒等和抵消边界 |
| attention | 每行和、掩码零值、均匀极限、Value线性缩放、凸组合边界 |

原子关联写入 `dl-atom-map.json`。逐个读过目标的定义和边界才建立关系；不存在精确适用原子的实验保持空数组，未以标题相近的卷积或初始化原子代替神经网络概念。

## 第3轮：独立实现者交叉复核

数值核心代理重新检查初始化、Dropout、归一化、卷积、池化、注意力及反向梯度。已落实两项精确性改进：Dropout第2图改为PMF，按整数贡献(5,3,−2,4)合并相同输出，避免浮点键误分组；并列最大池化明确为“普通导数不存在，次梯度不唯一”。测试另检验PMF总质量、经验计数、均值和方差。更新后的计数以dl-report.json为准。
