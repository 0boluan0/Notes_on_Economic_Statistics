# 可视化实验室

把需要图形、动态过程和可操作例子的知识放在一起。先提出预测，改变一个条件，再用公式和数值检查观察结果。

当前收录 **60 个实验**，各自有独立入口，可从多个知识原子双链引用。知识原子负责定义与命题，实验负责看见机制、比较条件和检验理解。

全部 60 个实验均附有原生播放的动画。打开下方任一实验笔记，先看动画，再用“影片参数与延伸对照”载入影片所用的模型与数据亲手操作。

## 怎么使用

1. 先读每个实验的问题，写下预测。
2. 一次只改变一个参数，比较图、数值和假设。
3. 使用预设观察边界，展开“检验理解”中的推导。
4. 从“来源与双链”回到知识点；需要保留结果时导出 SVG、CSV 或 JSON。
