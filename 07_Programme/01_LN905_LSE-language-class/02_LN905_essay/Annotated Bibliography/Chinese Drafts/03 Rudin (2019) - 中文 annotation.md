# Rudin (2019)：中文 annotation

> [!cite] Reference
> Rudin, C. (2019). Stop explaining black box machine learning models for high stakes decisions and use interpretable models instead. *Nature Machine Intelligence, 1*, 206–215. https://doi.org/10.1038/s42256-019-0048-x

## 中文底稿

可解释机器学习研究者 Cynthia Rudin（2019）在 *Nature Machine Intelligence* 发表的文章面向机器学习研究者、高风险决策领域的实务人员和政策制定者，主张不应在高风险场景中先部署黑箱模型，再依赖事后方法解释其预测。她区分了内生可解释模型与事后解释，并通过信用评分、医疗和刑事司法等案例指出，事后解释本身只是对原模型的近似，可能不忠实、具有误导性或受到操纵。文章的核心论点是，准确率与可解释性之间不存在普遍且不可避免的取舍；在采用黑箱前，应先证明其预测提升具有实质意义，并且不存在性能相近的可解释替代方案。该文的主要优势是清楚揭示了事后解释的忠实度问题，并为高风险模型选择提出了明确的举证责任。然而，它是一篇立场鲜明的理论和评论性文章，而不是专门针对消费者信用评分的统一实证比较，因此无法量化不同模型在具体信用数据上的性能差异。在我的论文中，这篇文章将构成反对以少量准确率提升交换透明度的核心理论依据，并用于限定 Lessmann 等人（2015）和 Khandani 等人（2010）所报告的预测与经济收益。
