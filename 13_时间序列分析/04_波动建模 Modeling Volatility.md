## 1.2 经济学领域的特征事实

 1.  许多宏观经济序列具有明显的趋势（例如美国实际GDP呈上升趋势）； 
 2. **许多时间序列的波动性并不恒定**，会随着时间发生变化。例如，美国实际GDP增速的波动在1984年左右明显下降，在2007年出现了一个大的负向波动尖峰，随后波动性有所稳定 。这表明方差存在结构性变化; 
 3. 序列受到冲击后的影响可能具有高度**持久性**（persistence），即冲击的影响在序列中持续很长时间； 
 4. 有些金融序列表现出类似随机游走的行为，没有均值回归趋势，例如汇率呈长时间升值或贬值的漫步状（见随机游走模型）； 
 5. 一些序列与其他序列存在共移动现象，例如短期和长期利率常常一起变动，体现**共同趋势**和**协整**关系； 
 6. 某些序列存在**结构性突变**，例如金融危机后油价出现跳变。

## 2.1 初步分析

为了刻画波动群聚现象,可以引入一个状态变量:

>[!note] 状态变量 State Variable
>状态变量使得方差可以随状态变化。例如，假设模型：$$y_{t+1} = \epsilon_{t+1} x_t$$其中$y_{t+1}$是我们关心的变量（已经去除均值，使其均值为0，以专注于波动部分），$\epsilon_{t+1}$是均值为0、方差为$\sigma^2$的**白噪声**（white noise），而$x_t$是第$t$期的某个状态变量。这样，条件方差就是：$$\operatorname{Var}(y_{t+1} \mid \mathcal{F}_t) = \sigma^2 x_t^2.$$

通过这种方式，如果$x_t$随时间变化，那么$y$的条件方差也会随之变化。当$x_t$较大时，$\sigma^2 x_t^2$也较大，表示波动性提高；当$x_t$较小时，波动性降低。这为捕捉非恒定方差提供了一个思路。

**2. ARCH 和 GARCH 模型**

ARCH模型由Robert Engle于1982年提出，用于捕捉上述波动性聚集特征；随后Tim Bollerslev在1986年将其推广为GARCH模型。它们的核心思想是：让**条件方差**随时间演化，具体地依赖于过去误差的大小，从而解释**条件异方差**现象。在介绍模型之前，我们先进行一个**初步分析**，以直观理解ARCH模型的构造思路。

• **2.1 初步分析：刻画时间变动的方差**

经典线性模型通常假定残差的方差为常数，但正如前述Stylized Fact所示，经济序列的波动性常随时间变化。为了捕捉这一点，可考虑一种简单形式：假设我们将序列的**均值**部分处理完毕（例如通过对原序列去均值或拟合ARMA模型得到残差），关注均值为0的残差序列${y_t}$。如果希望让下一期的方差取决于已知的信息，我们可以假设：

$$y_{t+1} = \varepsilon_{t+1},x_t,$$

其中$\varepsilon_{t+1}$是均值0、方差$\sigma^2$的白噪声（即$\varepsilon_{t+1}\sim WN(0,\sigma^2)$），$x_t$是$t$期已知的某种状态变量。那么在$t$期可获得的信息集$\mathcal{F}_t$下，$y_{t+1}$的条件方差为$$\mathrm{Var}(y_{t+1} \mid \mathcal{F}_t) = \sigma^2 x_t^2.$$

通过这种设定，我们就允许了方差随着$x_t$的数值而变化。如果我们选择合适的状态变量$x_t$来代表$t$期的波动状态，就能让未来的方差依赖于当前的波动程度。这正是ARCH模型的思想雏形：利用上一期的信息来决定本期的方差。基于对金融数据的观察，一个合理的选择是令$x_t^2$等于第$t$期的实际波动水平。例如，可以令$x_t^2$取为上一期残差的平方，这样$x_t$本身就代表$t$期波动的规模。这样一来，如果上一期出现了大的冲击（$\varepsilon_t$较大），则$x_t^2$大，对应地预测下一期$y_{t+1}$的方差也大；反之亦然。这种机制便可以生成波动性聚集现象：高波动之后仍然高波动，低波动之后仍然低波动 。

• **2.2 ARCH模型（自回归条件异方差模型）**

Engle (1982) 提出的ARCH模型，全称为“**自回归条件异方差**”模型（Autoregressive Conditional Heteroskedasticity），其基本形式是在误差项的方差中引入滞后项，使方差**自回归**地依赖于过去的误差平方。最简单的ARCH(1)模型可以写作：

$$\begin{cases}

\varepsilon_t = \nu_t \sqrt{h_t}, \

h_t = \alpha_0 + \alpha_1 \varepsilon_{t-1}^2,

\end{cases}$$

其中${\varepsilon_t}$是我们感兴趣序列的残差或创新，${\nu_t}$是平均为0、方差为1的独立同分布随机噪声（通常假定$\nu_t \sim i.i.d.(0,1)$），$h_t$表示$\varepsilon_t$在$t$期的条件方差（即$h_t = \mathrm{Var}(\varepsilon_t \mid \mathcal{F}_{t-1})$），$\alpha_0$和$\alpha_1$为待估计的非负常数。其中要求$\alpha_0 > 0$，$0 \le \alpha_1 < 1$。$\alpha_0$为_**_常数项_**_，$\alpha_1$为对上一期冲击平方的敏感程度。可以看到，$h_t$（当期方差）等于一个常数加上前一期残差平方的线性函数，这就是让方差对过去的信息产生依赖。更一般地，**ARCH(q)**模型将方差对$q$期内的滞后残差平方作线性回归：_

_$$h_t ;=; \alpha_0 + \alpha_1 \varepsilon_{t-1}^2 + \alpha_2 \varepsilon_{t-2}^2 + \cdots + \alpha_q \varepsilon_{t-q}^2,$$

其中$q$为滞后阶数，要求$\alpha_0>0,; \alpha_i \ge 0$。这样的结构确保了$h_t$为正值且随残差历史变化。

**ARCH(1)模型性质推导：以上ARCH(1)模型刻画了条件方差的一阶自回归**行为。由于$\varepsilon_t = \nu_t \sqrt{h_t}$，而$\nu_t$是均值0、方差1的白噪声，可知$\varepsilon_t$条件均值为0，**无条件均值**也是0。并且$\mathbb{E}[\varepsilon_t \mid \mathcal{F}_{t-1}] = 0$，同时因为$\varepsilon_t$由$\nu_t$乘以上一期的信息的函数得到，不难验证${\varepsilon_t}$构成一个**鞅差序列**（martingale difference sequence，简称m.d.s.） 。这意味着$\varepsilon_t$序列虽然具有**异方差性**，但在时间上不相关，即**序列无自相关**（序列相关性全由均值模型捕捉，残差不再呈现线性相关）。换言之，ARCH模型下$\varepsilon_t$序列可能方差波动，但均值上类似白噪声。

由于限制$0 \le \alpha_1 < 1$，ARCH(1)模型是**均方稳定**（方差平稳）的，其长期平均方差是有限值。具体计算如下：取无条件期望$E$于$h_t$公式两边，由于$\nu_t$独立且均值1，我们有 $E[\varepsilon_{t-1}^2] = E[h_{t-1}]$。令无条件方差为$\bar{h} = E[h_t] = E[\varepsilon_t^2]$，对ARCH(1)模型，有

$$\bar{h} = E[h_t] = E[\alpha_0 + \alpha_1 \varepsilon_{t-1}^2] = \alpha_0 + \alpha_1 E[\varepsilon_{t-1}^2] = \alpha_0 + \alpha_1 \bar{h}.$$

解此方程可得$\bar{h} = \frac{\alpha_0}{1-\alpha_1}$ 。因此无条件方差为$\alpha_0/(1-\alpha_1)$，这表明只有当$\alpha_1 < 1$时$\bar{h}$才是有限的，符合我们之前要求的平稳条件。进一步，如果$\alpha_1$较接近1，则$\bar{h}$会很大，表示波动性“记忆”很强，冲击的影响持续时间长。

ARCH(1)模型的**条件方差**为$\mathbb{E}(\varepsilon_t^2 \mid \mathcal{F}_{t-1}) = h_t = \alpha_0 + \alpha_1 \varepsilon_{t-1}^2$ 。因此，当上一期残差$\varepsilon_{t-1}$绝对值很大（意味着上一期发生了大的波动冲击），则当前期的条件方差$h_t$会相应变大，这正是**波动性聚集**的数学表达。如果$\varepsilon_{t-1}^2$很大，意味着$t-1$期波动剧烈，则$t$期的方差预测也变大，导致$t$期极有可能继续出现大波动 。反之亦然。如果多个连续时期没有大的$\varepsilon_t$出现，那么$h_t$将一直保持在较低水平，波动性保持低迷。这与我们观察到的高波动期和低波动期集群出现的现象相符。

ARCH模型本身并未规定$\varepsilon_t$序列的分布形状，只要满足零均值和单位方差的独立同分布即可。在许多应用中，我们常假定$\nu_t$服从标准正态分布以方便估计和推导，但在金融数据中$\nu_t$也可以服从厚尾的$t$分布等，以更好地捕捉极端值出现的频率。稍后在MLE部分会讨论基于分布假设的估计方法。

**联合均值-方差模型：实际应用中，我们通常将上述条件均值模型**（如ARMA）和**条件方差模型**（如ARCH）结合起来对序列进行建模 。具体做法是，先为序列$y_t$建立一个均值方程，比如ARMA($p,q$)模型：

$$y_t = a_0 + \sum_{i=1}^{p} a_i,y_{t-i} + \sum_{j=1}^{q} b_j,\varepsilon_{t-j} + \varepsilon_t,$$

然后对残差$\varepsilon_t$再建立一个ARCH模型以捕捉其方差的动态：

$$h_t = \alpha_0 + \sum_{i=1}^{m} \alpha_i,\varepsilon_{t-i}^2,$$

其中$\varepsilon_t$是均值方程的残差或创新项。通过这种组合，我们就得到了一个**均值-方差联合模型**：均值方程解释线性相关结构，方差方程解释波动聚集等二阶特征。例如，一个AR(1)-ARCH(1)模型就可以同时拟合自相关和波动性变化两种现象。

• **2.3 GARCH模型（广义ARCH模型）**

ARCH模型虽然能够捕捉波动聚集，但在实践中有一个不足：为了体现长延迟的波动效应，ARCH模型可能需要较高的滞后阶数$q$。这会引入大量参数，不利于模型的简洁和估计精度。为此，Bollerslev (1986) 提出了**GARCH**（Generalized ARCH，广义自回归条件异方差）模型，将ARCH扩展为允许方差方程中含有方差滞后项，从而以更少的参数捕捉更长久的波动影响。**GARCH(p,q)模型通常表示为：**

$$\begin{cases}
\varepsilon_t = \nu_t \sqrt{h_t}, \
h_t = \alpha_0 + \sum_{i=1}^{q} \alpha_i\varepsilon_{t-i}^2 + \sum_{j=1}^{p} \beta_j h_{t-j}
\end{cases}$$

**其中$h_t$依赖于$q$阶误差平方**和$p$阶**自身滞后**。要求参数满足$\alpha_0>0$，$\alpha_i \ge 0$ ( $i=1,\ldots,q$)，$\beta_j \ge 0$ ( $j=1,\ldots,p$ )，且保证平稳性的约束$\sum_{i=1}^q \alpha_i + \sum_{j=1}^p \beta_j < 1$ 。当$p=0$时，GARCH(p,q)退化为ARCH(q)模型 ；而一般地，加入$\beta_j$项可以理解为让过去的波动水平也会传递影响到未来，从而像ARMA模型相对于AR模型一样，GARCH模型通常能够用更少的滞后项达到与高阶ARCH模型同样的效果 。因此，GARCH模型在刻画长记忆的波动性时更**参数节省**（parsimonious）。

**GARCH(1,1)模型**是应用最广泛的一种规格，其形式为：

$$h_t = \alpha_0 + \alpha_1,\varepsilon_{t-1}^2 + \beta_1,h_{t-1}.$$

这表示当前波动水平由一个常数项、上期的残差平方以及上期的波动水平线性决定。其中$\alpha_1$反映新的**短期冲击**对当前波动的直接影响程度，而$\beta_1$反映前期波动的**持久性**影响。如果$\alpha_1 + \beta_1$之和越接近1，则表示波动的**持续性**越强：过去的冲击会长时间地影响未来的方差。例如，当$\alpha_1 + \beta_1$接近1时，模型表现出**长记忆性质**，即**波动持续**（volatility persistence）特征；极端地，如果$\alpha_1+\beta_1 = 1$，则模型称为**IGARCH**（见后文扩展模型部分），此时过去的冲击对未来方差的影响永不衰减（方差的无条件分布方差发散）。

类似地，可以推导GARCH(1,1)模型的无条件方差：令$\bar{h}=E[h_t]$，则

$$\bar{h} = E[\alpha_0 + \alpha_1 \varepsilon_{t-1}^2 + \beta_1 h_{t-1}] = \alpha_0 + \alpha_1 E[\varepsilon_{t-1}^2] + \beta_1 E[h_{t-1}] = \alpha_0 + (\alpha_1 + \beta_1)\bar{h}.$$

因为$E[\varepsilon_{t-1}^2] = E[h_{t-1}] = \bar{h}$。解得$\bar{h} = \frac{\alpha_0}{1-\alpha_1 - \beta_1}$，只要$\alpha_1+\beta_1<1$，$\bar{h}$是有限的，模型是方差平稳的。这个$\bar{h}$正是GARCH(1,1)模型下**长期平均方差**或称**无条件方差**。当$\alpha_1+\beta_1<1$时，$\bar{h}$存在且有限；当$\alpha_1+\beta_1$非常接近1时，$\bar{h}$非常大（或者需要很长样本才能估计准确），体现出波动方差的强烈持续性。

**模型特性总结：ARCH/GARCH模型成功地解释了金融序列的二阶依赖结构——虽然收益序列${y_t}$经均值校正后可以是白噪声，但平方序列${\varepsilon_t^2}$通常表现出显著的自相关**。也就是说，原序列可能没有线性的自相关，但其波动幅度大小有相关性。ARCH/GARCH通过引入$\varepsilon_{t-i}^2$和$h_{t-j}$等项在方差方程中，恰当地模拟了这种相关性：$\varepsilon_t^2$的自相关实际上反映在$h_t$的动态方程中犹如AR(或ARMA)过程 。因此，ARCH/GARCH模型刻画了**条件异方差**（conditional heteroskedasticity）并生成**波动性簇集**。特别地，对于GARCH(1,1)，$\alpha_1$控制了当期波动对最近一次新冲击的敏感度，$\beta_1$控制了过去波动对当前的延续性影响。

  

**3. 检测 ARCH/GARCH 效应**

在对时间序列进行建模时，我们首先常用ARMA模型拟合均值部分，然后需要判断残差序列中是否存在ARCH/GARCH效应（即条件异方差）。**检验ARCH效应**的经典方法是Engle (1982)提出的**ARCH-LM检验**（Lagrange Multiplier Test for ARCH）。其基本思想是：如果残差存在ARCH效应，那么残差的平方序列将表现出自相关性；反之，如无ARCH效应，残差平方不应显示系统性的相关结构。具体步骤如下 ：

1. **拟合均值模型，获取残差：** 对原序列${y_t}$先拟合一个“最佳”的均值模型（例如ARMA模型），得到残差序列${\hat{\varepsilon}_t}$。这样可以确保我们检验ARCH效应时，剔除了均值结构对序列的影响。残差$\hat{\varepsilon}_t$应当近似为零均值、无自相关的序列，如果均值模型足够好。

2. **构造辅助回归：** 考察残差的平方序列$\hat{\varepsilon}_t^2$。以$\hat{\varepsilon}t^2$为因变量，回归在一个常数和其自身的$q$阶滞后$\hat{\varepsilon}{t-1}^2, \hat{\varepsilon}_{t-2}^2, \dots, \hat{\varepsilon}_{t-q}^2$上：_

_$$\hat{\varepsilon}t^2 = \alpha_0 + \alpha_1,\hat{\varepsilon}{t-1}^2 + \alpha_2,\hat{\varepsilon}_{t-2}^2 + \cdots + \alpha_q,\hat{\varepsilon}_{t-q}^2 + \eta_t.$$

这里$q$是检验滞后阶数，可以选取一个适当的值（例如5或10）以检测多期滞后的ARCH效应，$\eta_t$是回归残差。

3. **检验统计量：** 在原假设（$H_0$）为“无ARCH效应”的情况下，理论上上述回归中的滞后平方项系数$\alpha_1, \dots, \alpha_q$应为0，即残差平方不显示显著的相关性。此时回归的解释力度很低，$R^2$接近0。Engle建议使用 $L = T \cdot R^2$ 作为检验统计量，其中$T$为样本容量。若$H_0$为真，$L$大样本下服从$\chi^2_q$（自由度$q$的卡方分布） 。我们将$L$与卡方临界值比较：若$L$过大（p值很小），则拒绝$H_0$，说明存在ARCH效应；否则无法拒绝$H_0$，认为残差中没有显著的ARCH特征。

  

直观解释是：如果序列没有ARCH效应，那么残差平方系列就像白噪声一样，没有系统性的滞后相关，回归中所有$\alpha_i$应当不显著；而如果ARCH效应存在，那么$\hat{\varepsilon}_t^2$会部分可由过去的$\hat{\varepsilon}^2$解释，导致回归的$R^2$明显大于0，$L$统计量显著。需要注意的是，这个检验要求先有一个合理的均值模型，否则均值未捕捉的结构也可能使$\hat{\varepsilon}_t^2$相关，从而混淆ARCH的判定。

  

除了ARCH-LM检验，判断ARCH效应还可以借助**残差平方的自相关图**或者Ljung-Box Q统计量对$\hat{\varepsilon}_t^2$进行检验。如果残差平方的自相关在若干滞后显著不为零，也提示存在ARCH效应。总的来说，这些方法都是在检验${\hat{\varepsilon}_t^2}$是否呈现类似AR模型的行为。如果是，则进一步建模波动性是有必要的。

  

**4. 极大似然估计（MLE）**

一旦我们确定序列存在ARCH/GARCH效应，就需要估计相应模型的参数。ARCH/GARCH模型通常通过**极大似然估计**（Maximum Likelihood Estimation, MLE）来估计参数。MLE需要我们对$\varepsilon_t$的分布做一个假定。在ARCH/GARCH文献中，常见的假定是**条件正态**或**条件$t$分布**。为简单起见，我们以正态分布为例说明MLE过程。

  

假设我们的观察序列满足：$y_t = \mu_t + \varepsilon_t$，其中$\mu_t$是条件均值（可能包含一些回归项，例如$\mu_t = \beta’ x_t$，$x_t$为外生变量向量或ARMA项），$\varepsilon_t$服从均值0、方差$h_t$的正态分布。$\varepsilon_t$进一步满足GARCH方差方程的约束，如$h_t = \alpha_0 + \alpha_1 \varepsilon_{t-1}^2 + \beta_1 h_{t-1}$等（更一般的GARCH(p,q)形式）。此外，我们假设$\nu_t = \varepsilon_t/\sqrt{h_t}$为i.i.d.标准正态（或$t$分布）序列 。在此假定下，可以写出样本的**条件似然函数**：对每一期$t$，给定历史信息$\mathcal{F}_{t-1}$，$\varepsilon_t$的条件密度为_

_$$f(\varepsilon_t \mid \mathcal{F}_{t-1}) = \frac{1}{\sqrt{2\pi h_t}} \exp!\Big(-\frac{\varepsilon_t^2}{2h_t}\Big),$$

因为$\varepsilon_t \sim N(0, h_t)$条件于过去。于是整个样本的**似然函数**（对参数$\Theta = {\alpha_i, \beta_j, \text{以及均值方程参数}}$)为各期条件密度的乘积：

$$L(\Theta) = \prod_{t=1}^T \frac{1}{\sqrt{2\pi,h_t}} \exp!\Big(-\frac{\varepsilon_t^2}{2h_t}\Big).$$

为了方便优化，我们取对数得到**对数似然函数**：

$$\ln L(\Theta) = -\frac{T}{2}\ln(2\pi);-;\frac{1}{2}\sum_{t=1}^T \ln h_t ;-; \frac{1}{2}\sum_{t=1}^T \frac{\varepsilon_t^2}{h_t},.$$

这里$h_t$是参数$\Theta$的函数（通过方差方程确定），$\varepsilon_t$也与参数相关（因为$\varepsilon_t = y_t - \mu_t$，而$\mu_t$可能由参数确定）。因此，上式是关于参数$\Theta$的一个复杂的非线性函数。求解MLE即是最大化$\ln L(\Theta)$，通常需要借助数值优化算法迭代求解参数，使对数似然达到最大。实践中，软件会使用如BFGS、EM等算法来寻找MLE估计值$\hat{\Theta}$。

  

需要注意的是，如果我们假定了错误的分布形式（例如真实$\nu_t$是厚尾$t$分布，但我们假定正态），那么此时得到的仍然是所谓**QMLE（准极大似然估计）** 。在一定条件下（例如模型结构正确），QMLE仍具有一致性和渐近正态性，但标准误计算需要作稳健性校正。因此，在实证中，如果怀疑$\varepsilon_t$分布厚尾（金融数据常如此），可以直接假定$t$分布并引入自由度参数估计，或使用正态QMLE但报告**Newey-West**等稳健标准误。

  

**5. 模型拟合优度评估：AIC 和 SBC**

在估计了ARCH/GARCH模型后，可能需要在不同模型之间进行比较和选择，例如选择GARCH(1,1)还是GARCH(2,1)，或者比较ARCH和GARCH模型。为了评估模型拟合优度同时考虑模型复杂度，我们通常使用信息准则，例如**赤池信息准则**（AIC）和**贝叶斯信息准则**（BIC，也称Schwarz Bayesian Criterion，SBC）。信息准则给出了在拟合likelihood和模型简洁之间折衷的评价指标：

• AIC 定义为：$\displaystyle \text{AIC} = -2\ln L_{\text{max}} + 2k$，其中$L_{\text{max}}$是模型最大化后的似然值，$k$是模型中估计参数的个数 。$-2\ln L$衡量了模型残差的不可解释程度（越小表示模型拟合越好），而$2k$是对模型复杂度的惩罚（参数越多惩罚越大）。

• BIC 定义为：$\displaystyle \text{BIC} = -2\ln L_{\text{max}} + k \ln T$，其中$T$为样本容量 。相比AIC，BIC对参数个数的惩罚更严厉（乘以$\ln T$因子），在大样本下倾向于选择更简洁的模型。

  

一般来说，对于给定数据集，**AIC或BIC值越小的模型表示综合表现越优** 。我们可以计算不同阶数的ARCH/GARCH模型的AIC和BIC值，选择其中最小者作为最佳模型。例如，在实证中可能逐渐增加ARCH滞后阶数$q$或增加GARCH滞后阶数$p$，计算各模型的信息准则。如果发现增加某个滞后显著降低AIC/BIC，则表明该项有价值；否则可以避免过度扩展模型。这类似于ARMA建模中根据信息准则选择阶数的过程。

  

**6. 模型诊断**

和ARMA模型拟合一样，ARCH/GARCH模型在估计后需要进行**适合度诊断**（model adequacy checking），以确保残差的行为与模型假定一致。诊断主要检查两方面：

1. **标准化残差的独立性：** 计算**标准化残差** $s_t = \frac{\hat{\varepsilon}_t}{\sqrt{\hat{h}_t}}$，其中$\hat{\varepsilon}_t$是模型估计后的残差，$\hat{h}_t$是对应的拟合条件方差。理论上，如果均值模型和波动模型都正确，那么$s_t$应当是一个i.i.d.标准正态序列（在假定正态创新的情形下）。我们可以首先检验$s_t$是否表现为白噪声序列，没有自相关。例如使用Ljung-Box Q统计量检验$s_t$在若干滞后的自相关是否显著 。若标准化残差仍存在自相关，说明均值模型可能遗漏了结构；若存在异方差，说明方差模型未捕捉完全。

2. **标准化残差平方的独立性：** 接着检验${s_t^2}$是否还存在条件异方差。如果ARCH/GARCH模型充分拟合了波动性，那么标准化后的$s_t^2$不应再有显著的自相关。可以对$s_t^2$重复进行Engle的ARCH效应LM检验 。若检验显示拒绝无ARCH假设，意味着原模型的方差方程阶数可能不足，仍有未建模的波动模式，需要考虑更高阶或不同类型的模型。

  

通过以上两步，如果标准化残差序列$s_t$通过了白噪声检验，且$s_t^2$没有ARCH效应残留，那么我们认为当前模型是**充分的**。否则，需返回模型建立步骤，对均值方程或方差方程进行修正，例如增加ARMA项或者提高ARCH/GARCH阶数，或者考虑模型的扩展形式（如引入杠杆效应的模型，见后文）。在第10部分NYSH指数的实证中，我们将看到模型诊断的实际应用。

  

**7. 预测**

建立了合适的GARCH模型后，我们可以对未来时期的序列进行预测，包括**均值预测**和**方差预测**。需要注意的是，在存在条件异方差的情况下，均值的预测和传统ARMA模型并无二致，但区间预测的宽度将受条件方差影响。下面详细说明：

• **均值的一步预测：** 假设我们在$t$时刻已经估计了模型，预测$t+1$期的$y_{t+1}$。对于均值，$y_{t+1}$的最佳预测是$\hat{y}_{t+1|t} = E_t[y_{t+1}]$。在ARMA-GARCH模型下，由于$\varepsilon_{t+1}$条件于信息集$\mathcal{F}_t$的期望为0（$s_t$是鞅差），均值部分的预测仍遵循ARMA模型的结果。例如，如果均值方程是AR(2)，那么$E_t[y_{t+1}]$按照AR(2)递推计算即可。总之，有条件异方差并不改变均值预测公式，因为我们假设已经充分利用了均值动态结构 。

• **方差的一步预测：** 有了GARCH模型，我们可以预测下一期的波动水平，即计算$h_{t+1|t} = E_t[h_{t+1}]$（下标$t+1|t$表示在$t$期基于信息$\mathcal{F}_t$对$t+1$期的预测）。以GARCH(1,1)为例，根据模型：_

_$$h_{t+1} = \alpha_0 + \alpha_1 \varepsilon_t^2 + \beta_1 h_t,$$

在$t$时刻已知$\varepsilon_t$和$h_t$，则**一步前方差预测**为：

$$\hat{h}_{t+1|t} = \alpha_0 + \alpha_1 \varepsilon_t^2 + \beta_1 h_t.$$_

_这实际上就是把当期已发生的冲击$\varepsilon_t^2$代入，对下一期进行更新。如果我们关心下一期预测的95%置信区间，可以写为：_

_$$\hat{y}_{t+1|t} ;\pm; 1.96 \sqrt{\hat{h}_{t+1|t}},. $$_

_与固定方差情形不同的是，这个区间的宽度$\sqrt{\hat{h}_{t+1|t}}$是动态变化的：在高波动时期，$\hat{h}_{t+1|t}$较大，置信区间更宽；在低波动时期，置信区间更窄 。因此，GARCH模型能够提供随市场状况变化的风险度量。

• **多步方差预测：** 我们还可以预测更远期的波动性。对于GARCH模型，多步预测需要递推计算。例如对于GARCH(1,1)，二步预测$h_{t+2|t} = E_t[h_{t+2}]$可通过条件期望递推：

首先注意$\nu_t$是i.i.d.且$E[\nu_{t+2}^2]=1$，因此$E_t[\varepsilon_{t+2}^2] = E_t[h_{t+2}]$（因为$\varepsilon_{t+2}^2 = h_{t+2}\nu_{t+2}^2$，取条件期望$\nu_{t+2}^2$给1） 。利用GARCH(1,1)方程递推：

$\begin{aligned} E_t[h_{t+2}] &= E_t[\alpha_0 + \alpha_1 \varepsilon_{t+1}^2 + \beta_1 h_{t+1}] \\ &= \alpha_0 + \alpha_1 E_t[\varepsilon_{t+1}^2] + \beta_1 E_t[h_{t+1}] \\ &= \alpha_0 + \alpha_1 E_t[h_{t+1}] + \beta_1 E_t[h_{t+1}] \quad (\text{因为 }E_t[\varepsilon_{t+1}^2]=E_t[h_{t+1}])\\ &= \alpha_0 + (\alpha_1 + \beta_1) \hat{h}{t+1|t}\,. \end{aligned}$

_其中$\hat{h}_{t+1|t}$是我们已计算的一步预测。继续递推$j$步，我们可以得到一个通用公式：对于$GARCH(1,1)$，**$j$步前方差预测**为 ：

$$\hat{h}_{t+j|t} ;=; \alpha_0 \Big[1 + (\alpha_1+\beta_1) + (\alpha_1+\beta_1)^2 + \cdots + (\alpha_1+\beta_1)^{j-1}\Big] + (\alpha_1+\beta_1)^j h_t.$$
_这个公式的推导可以通过数学归纳得到：每向前一步，预测方差是前一步预测的$(\alpha_1+\beta_1)$倍，加上一个$\alpha_0$常数项。括号中的求和是一个_**_几何级数_**_，在$(\alpha_1+\beta_1) \neq 1$时，其和等于$\frac{(\alpha_1+\beta_1)^j - 1}{\alpha_1+\beta_1 - 1}$。由此可以分析极限情形：如果$\alpha_1+\beta_1<1$，则当预测步数$j \to \infty$时，$(\alpha_1+\beta_1)^j \to 0$，几何和部分趋近于$\frac{1}{1-(\alpha_1+\beta_1)}$，从而_

_$$\lim_{j\to\infty} \hat{h}_{t+j|t} = \alpha_0 \frac{1}{1-\alpha_1-\beta_1},. $$_

_这正是无条件方差$\bar{h}$。也就是说，在一个均值回归的波动模型中，长时期之后的方差预测将回归到长期水平$\bar{h}$_ _。相反，如果$\alpha_1+\beta_1=1$（边界情况，IGARCH），则$\hat{h}_{t+j|t} = \alpha_0 j + h_t$ ，它会随着步数线性增长，长程方差发散；如果$\alpha_1+\beta_1>1$（不平稳情况），预测方差会指数发散。这些性质与AR(1)过程的均值预测类似：当AR系数小于1时，均值预测趋向于长期均值；系数等于1则随机游走，无长期均值；大于1则发散。因此，**GARCH模型的平稳性对于长程预测非常关键**。通常要求估计结果满足$\alpha_1+\beta_1<1$，以确保风险不会无限增加。

  

**8. 扩展模型**

基本的ARCH/GARCH模型可以解释许多金融数据的波动行为，但实际中仍有一些现象需要模型扩展来捕捉。本节介绍几种重要的扩展，包括**积分GARCH**（IGARCH）、**含均值波动效应的ARCH**（ARCH-M）、**阈值GARCH**（TARCH），和**指数GARCH**（EGARCH）模型等。除此之外，我们也简要提及方差方程中引入外生变量以及杠杆效应检验的方法。

• **8.1 IGARCH模型：波动性的单位根过程**

金融时间序列中经常观察到$\alpha_1+\beta_1$非常接近1的情况，意味着波动性具有很强的持久性，仿佛一个近似单位根过程。**积分GARCH (IGARCH)****模型指的就是$\alpha_1+\beta_1=1$的特殊情况** **。以GARCH(1,1)为例，如果$\alpha_1+\beta_1=1$，方差方程变为：**

**$$h_t = \alpha_0 + \alpha_1 \varepsilon_{t-1}^2 + (1-\alpha_1) h_{t-1},$$**

**其中我们用$\beta_1 = 1-\alpha_1$表示。可以发现，当$\alpha_1 + \beta_1 = 1$时，上述长程方差公式中的分母变为0，无条件方差****发散无穷**，即**序列方差不平稳**。 直观理解是，每期的新冲击都会永久地影响未来的波动水平而不衰减，这在某些高频金融数据中近似成立（被称为“长期记忆”或“长程依赖”）。在这种模型下，$j$步前的方差预测不收敛于常数，而是：

$$E_t[h_{t+j}] = j,\alpha_0 + h_t,$$

即随着预测步数线性增长 。因此，IGARCH模型适用于**超高持久性**的波动情况。需要强调的是，IGARCH严格来说并非平稳过程，它通常被当作一种近似方便，因为在有限样本内如果$\alpha_1+\beta_1$估计非常接近1，可以近似当作1处理，以避免负的$\alpha_0/(1-\alpha_1-\beta_1)$出现。

从理论上，若$\beta_1 < 1$，我们可以将一般GARCH(1,1)模型改写为**无限ARCH表示**：

$$h_t = \alpha_0/(1-\beta_1) + (1-\beta_1)\sum_{i=0}^{\infty} \beta_1^i \varepsilon_{t-1-i}^2,,$$

这是利用拉格算子技巧推导的，将$h_t$表达成对过去所有误差平方的加权和，权重按几何级数衰减 。可以看到，当$\beta_1$不太接近1时，误差很久远之后的影响会衰减得很小；但当$\beta_1 \approx 1$时，衰减非常慢，甚至$\beta_1=1$时完全不衰减（对应IGARCH）。因此，IGARCH实际上是让历史冲击的影响长期存在的一种极端假设。

• **8.2 ARCH-M 模型：波动性对均值的反馈**

以上讨论中，波动性被当作仅影响风险、不直接影响序列均值。然而，在金融经济理论中，经常假设**风险与收益相关**：更高的不确定性可能要求更高的风险溢价作为补偿。为了捕捉“**波动性影响均值**”这一效应，Engle、Lilien和Robins (1987) 提出了ARCH-M（ARCH in Mean）模型。ARCH-M允许序列的均值包含其条件方差（或标准差）项，即把波动性引入均值方程。典型的ARCH-M模型形式为：

**$$\begin{cases} 
y_t = \mu_t + \varepsilon_t  \\
\mu_t = \beta + \delta h_t
\end{cases}$$

**其中$\varepsilon_t$仍满足ARCH/GARCH形式的方差方程，$\delta$为待估参数** **。当$\delta>0$时，表示条件方差越大（风险越高），平均回报$\mu_t$越高，符合风险溢价理论。例如，在利率或资产收益率模型中，$\delta>0$意味着波动率上升会提高下一期的预期收益。这一模型结构经常用于宏观金融中对****风险溢酬**（risk premium）的研究。如果估计发现$\delta$不显著，则表示风险对均值没有直接影响。

需要注意的是，在ARCH-M模型里，$h_t$进入了均值方程，使得$y_t$的条件均值和方差发生了**联动**：这会带来一些推导和估计上的复杂性，但可以通过MLE一并估计$\delta$和其他ARCH参数。实践中，有时也用$\sqrt{h_t}$（条件标准差）而非$h_t$进入均值，以保证量纲一致和线性近似的有效性。

• **8.3 方差方程中的外生变量**

有些情况下，我们怀疑某些特定事件或外生因素会显著影响波动性，此时可以在方差方程中加入**外生解释变量**（explanatory variables）。例如，为研究重大事件对市场波动的影响，我们可以在$h_t$方程中添加一个哑变量。假设想检验**“9.11事件”**对股市波动的影响，可以构造哑变量$D_t$：当$t$对应日期在2001年9月11日及之后时$D_t=1$，否则$D_t=0$。将其纳入方差方程：**

**$$h_t = \alpha_0 + \alpha_1 \varepsilon_{t-1}^2 + \beta_1 h_{t-1} + \gamma,D_t.$$**

**如果估计得到$\gamma > 0$且具有统计显著性，就可以认为9.11事件导致了显著更高的市场波动** **。通过这种方式，我们能够评估特定政策、事件冲击等对金融市场波动率的影响。在宏观经济中，也可以加入如货币政策虚拟变量、战争冲突指标等来解释波动变化。这类模型本质上是让$h_t$对一些**可观测的外生因素**做出响应，提高了模型解释力。

• **8.4 TARCH模型：波动性的非对称效应（阈值GARCH）**

金融市场的另一个著名现象是**杠杆效应**（leverage effect）：坏消息（如股价大跌）的冲击往往比好消息（如股价大涨）对未来波动性的影响更大。这意味着序列的波动性对正负方向的冲击反应不对称。为捕捉这种**非对称性**，Zakoian (1994) 和 Glosten, Jagannathan & Runkle (1993) 等提出了**TARCH/THRESHOLD GARCH**模型（又称**TGARCH**）。**TARCH(1,1)**模型在GARCH(1,1)的基础上添加一个针对负向残差的额外项：

$$h_t = \alpha_0 + \alpha_1 \varepsilon_{t-1}^2 + \lambda_1,d_{t-1},\varepsilon_{t-1}^2 + \beta_1 h_{t-1},$$

其中$d_{t-1}$是阈值哑变量，当$\varepsilon_{t-1}<0$时$d_{t-1}=1$，否则$d_{t-1}=0$ 。这样，当上一期为负向冲击时，$\lambda_1,d_{t-1},\varepsilon_{t-1}^2 = \lambda_1 \varepsilon_{t-1}^2$会附加到方差中；若为正向冲击，该项为0。**如果估计发现$\lambda_1 > 0$**，则意味着在$\varepsilon_{t-1}$大小相同时，负冲击会比正冲击引起更高的条件方差 。这正体现了杠杆效应：利空导致未来波动增加更显著，因为公司价值下降会提高财务杠杆，从而放大风险。

TARCH模型简单直观，在实证中常用于检测**非对称ARCH效应**。可以通过检验$\lambda_1$的显著性来判断是否存在杠杆效应。如果$\lambda_1$显著大于0，则表明负面消息对波动性的影响大于正面消息。如果$\lambda_1$不显著，则说明未发现显著的波动性非对称现象。

• **8.5 EGARCH模型：指数形式的非对称GARCH**

另一种捕捉非对称效应的著名模型是Nelson (1991)提出的**EGARCH（Exponential GARCH）**。与前述模型都保证$h_t$为正不同，EGARCH通过对数变换直接建模$\ln h_t$，这样即使回归系数为负，指数后$h_t$仍为正值，不需非负约束。一个典型的EGARCH(1,1)模型形式为：

$$\ln h_t = \alpha_0 + \lambda_1\Big|\frac{\varepsilon_{t-1}}{\sqrt{h_{t-1}}}\Big| + \alpha_1 \frac{\varepsilon_{t-1}}{\sqrt{h_{t-1}}} + \beta_1 \ln h_{t-1},. $$

这里$\frac{\varepsilon_{t-1}}{\sqrt{h_{t-1}}}$是标准化的残差，用以衡量上一期冲击的“大小”和“方向”。绝对值项$\Big|\frac{\varepsilon_{t-1}}{\sqrt{h_{t-1}}}\Big|$反映冲击的幅度，无论正负都增加波动，系数$\lambda_1$应为正；而非绝对值项$\frac{\varepsilon_{t-1}}{\sqrt{h_{t-1}}}$反映冲击的方向，系数$\alpha_1$抓取非对称效应 。如果$\alpha_1 < 0$，表示负冲击（$\varepsilon_{t-1}$为负）会使$\ln h_t$减少，即$h_t$相对乘数缩小，翻译过来就是**负冲击增加方差**（因为$\ln h_t$减少意味着$h_t$成倍增加）——注意这里有负号关系，需要仔细理解：实际上在EGARCH中常设定公式略有不同以直接体现负冲击效应为正的情况，但关键是$\alpha_1$的符号指示了方向效应。由于以对数表示方差，$\alpha_1$可以取负值，模型依然保持$h_t>0$，这突破了一般GARCH必须$\alpha_i \ge 0$的限制 。**EGARCH的优点**在于可以方便地表示非对称效应且不需非负约束，但缺点是解释直观性略差，因为影响是通过对数线性。

在EGARCH模型中，杠杆效应的存在可通过检验**$\alpha_1 \neq 0$**来判断 。一般地，$\alpha_1<0$表明负冲击增大未来波动性（符合杠杆效应），$\alpha_1>0$则反之（不常见）。Nelson原文中定义的参数可能有所不同，但思路类似。

• **8.6 杠杆效应的检验：** 对于一般的非对称模型，可以通过参数显著性检验来判定杠杆效应（如上所述TARCH检验$\lambda_1>0$，EGARCH检验$\alpha_1<0$）。除此之外，还有一种模型外部的检验思路： 先用**对称的ARCH/GARCH模型**（不包含杠杆项）拟合残差和方差，然后构造标准化残差$s_t = \frac{\hat{\varepsilon}_t}{\sqrt{\hat{h}t}}$序列，再检验$s_t$与其自身滞后项之间的相关关系是否呈现不对称模式。例如可以检验回归_

_$$s_t^2 = \gamma_0 + \gamma_1 s{t-1} + \gamma_2 s_{t-1}^2 + \cdots + \gamma_p s_{t-p} + \eta_t$$

中，是否存在由$s_{t-1}$（未平方的滞后）引入的不对称关系。如果$\gamma_1$显著不为0，则意味着残差的正负对下一期的平方有影响，从而提示应引入杠杆效应模型。简单来说，这是先假定无杠杆，事后检查标准化残差是否仍残留非对称结构的一种方法。

  

**9. 多元GARCH模型**

以上讨论的ARCH/GARCH模型都针对单一时间序列的波动情况。然而，在金融实践中，我们常常需要同时建模多个相关资产的波动，例如股票投资组合中多只股票的收益率，就需要考虑它们各自的波动率以及相互之间的相关性随时间的变化。这就需要**多元GARCH模型**（Multivariate GARCH）。

  

多元GARCH模型的目标是对**条件协方差矩阵**进行建模。以二维案例为例，设$(\varepsilon_{1t}, \varepsilon_{2t})’$是两个相关序列在$t$期的残差向量，我们可以定义条件协方差矩阵为：

$$H_t = \begin{pmatrix} h_{11,t} & h_{12,t} \ h_{21,t} & h_{22,t} \end{pmatrix},$$

其中$h_{11,t} = \mathrm{Var}(\varepsilon_{1t} \mid \mathcal{F}_{t-1})$，$h_{22,t}$同理，$h_{12,t}=h_{21,t} = \mathrm{Cov}(\varepsilon_{1t}, \varepsilon_{2t} \mid \mathcal{F}_{t-1})$。多元GARCH需要给出$H_t$随$t$的演化方程。在最一般的_**_VECH模型_**_（逐元素模型，由Bollerslev, Engle, Wooldridge 1988提出）中，$H_t$的每个元素都被表示成其自身滞后项和误差乘积项的线性函数。例如，一个VECH(1,1)模型可以写作：_

_$$\text{vech}(H_t) = C + A,\text{vech}(\varepsilon_{t-1}\varepsilon_{t-1}’) + B,\text{vech}(H_{t-1}),$$

其中$\text{vech}$操作表示将矩阵的上三角元素折叠成向量，$C, A, B$是参数矩阵。 直观解释就是：每个方差项和协方差项都对自身的过去值以及上期残差的组合有线性依赖关系。这是对GARCH单变量概念的逐元素推广。

  

**多元GARCH的挑战**在于参数过多和正定性约束：对于$n$元序列，$H_t$是$n\times n$矩阵，有$\frac{n(n+1)}{2}$个不同元素。如果每个元素都各有自己的参数，模型会非常庞大。例如$n=3$时就有6个方差/协方差元素需要建模。此外，要确保$H_t$始终是正定矩阵（以保证协方差有效），对参数矩阵的取值会有复杂的限制 。一般VECH模型无法自动保证正定性，除非参数满足一定条件。

  

为克服这些困难，研究者提出了多种约束形式的多元GARCH模型：

• **对角VECH模型（Diagonal VECH）**：这是对一般VECH的一个简单约束，即只允许协方差方程中出现“自身项”和“自身残差”，不引入交叉项。比如$h_{12,t}$的方程不包含$\varepsilon_{1,t-1}\varepsilon_{2,t-1}$项，而只依赖自身过去。这种约束大幅减少参数数量，但也限制了**波动溢出**（volatility spillover）的捕捉（波动溢出指一个变量的波动冲击传递影响另一变量的波动 ）。对角VECH确保正定性依然复杂。

• **BEKK模型**：由Baba-Engle-Kraft-Kroner (1991) 提出。BEKK模型将$H_t$分解表示为：

$$H_t = C’C + A’ \varepsilon_{t-1}\varepsilon_{t-1}’ A + B’ H_{t-1} B,$$

其中$C$是上三角矩阵（保证$C’C$正定），$A$和$B$是矩阵 。这种表示方式**自动保证$H_t$正定**，因为可以看作协方差矩阵每期由一个常数正定矩阵$C’C$、残差项$A’ \varepsilon_{t-1}\varepsilon_{t-1}‘A$以及过去协方差$B’H_{t-1}B$加总而成。BEKK模型的参数还是很多（矩阵$A$和$B$各含$n^2$参数），但通常可以采用对角或缩减形式降低参数。BEKK常用于双变量或小维度情形。

• **常数条件相关模型（CCC）**：由Bollerslev (1990) 提出。该模型做出了一个强假设：各变量间的**条件相关系数**保持不变。具体地，CCC模型假定在任何$t$时刻，协方差$h_{12,t}$与各自方差的相关比恒定：

$$\rho_{12} = \frac{h_{12,t}}{\sqrt{h_{11,t} h_{22,t}}},$$

其中$\rho_{12}$是一个不随时间变动的常数相关参数 。如此一来，我们只需建模各单变量的$h_{11,t}$、$h_{22,t}$（可以分别用GARCH模型），而协方差通过上式由相关系数$\rho_{12}$和单变量方差决定。这大大减少了需要估计的参数数目（主要减少了协方差项参数），并且只要单变量方差是正的且相关矩阵正定（如相关系数在$[-1,1]$范围内），整个$H_t$天然正定。CCC模型适用于相关性近似恒定的资产组合，例如一些汇率之间短期内相关性可能固定。

CCC模型的缺陷是相关系数常数的假设在某些情况下不合理，例如在市场危机时资产间相关性往往升高，这违背常相关假设。因此Engle (2002) 等提出**动态条件相关（DCC）**模型作为改进，让相关系数也随时间演化，但方式比全参数VECH简单得多。DCC模型通常分两步估计：先估计单变量GARCH得到标准化残差，再估计相关矩阵的动态。这超出了本讲义范围，但值得了解其存在。

• **波动溢出与冲击响应：** 多元GARCH的重要用武之地在于分析市场之间的波动传染和溢出效应。例如，一个市场的波动冲击是否会增加另一个市场的波动。在多元框架下，我们可以定义**波动脉冲响应函数**（volatility impulse response function）来度量这一点 。举例来说，考虑两变量模型，我们可以模拟在$T$期对变量1施加一个单位标准差冲击$\varepsilon_{1,T}=1$（而$\varepsilon_{2,T}=0$），然后根据估计的模型生成未来$i$期的方差预测$E^*_T[h_{11,T+i}]$（有冲击的情形）和$E_T[h_{11,T+i}]$（无特殊冲击的基准情形），两者差值便是冲击在$i$期后对变量1自身方差的影响。同理可以看对变量2方差的影响。这种分析可以帮助我们理解市场间风险传递的速度和持续时间。

  

综上，多元GARCH模型为研究**多资产风险管理**和**市场联动**提供了有力工具。然而，由于模型复杂度高，在实际应用时需要在灵活性和可估计性之间权衡，选择恰当的约束形式。常用做法是根据数据特点，先尝试简单模型（如CCC或对角BEKK），再视需要放宽假设。

  

**10. NYSE U.S. 100指数波动性的实例分析**

最后，我们通过一个实际案例来应用上述方法：分析纽约证券交易所美国100股票指数（NYSE U.S. 100 Index）的波动性。 该指数由100只美国股票构成，我们使用其对数收益率（log return）作为研究对象，数据频率为每日，样本期从2000年1月4日到2012年7月16日，总计3270个观测值 。这个样本涵盖了2004-2006年波动较低的时期和2008-2009年金融危机波动剧烈的时期 。以下是分析步骤和结果：

• **数据特征与预处理：** 先绘制了收益率序列的时间图（讲义Figure 3.3）以直观查看波动行为。图中可以看到，在2004-2006年期间曲线较为平缓，没有大的尖峰，而在2008-2009年期间波动显著放大，出现多个异常高波动日。这与我们的预期一致：金融危机期间市场剧烈波动，之后波动性逐渐回落。序列均值接近于0，具备金融资产收益的一般特征。

• **均值模型拟合：** 我们采用Box-Jenkins方法对收益率序列建立ARMA模型。通过检验自相关函数（ACF）和偏自相关函数（PACF），以及使用信息准则挑选，我们发现AIC准则选择了一个AR(2)模型作为最佳均值模型 。也就是说，收益率的均值方程可以用过去两天的收益解释（$y_t = a_0 + a_1 y_{t-1} + a_2 y_{t-2} + \varepsilon_t$）。估计结果显示AR(2)模型**是恰当的**，残差经Ljung-Box Q检验在合理滞后下没有显著自相关 。因此，我们认为均值部分的动态已捕捉充分。

• **ARCH效应检验：** 接下来对AR(2)模型的残差${\hat{\varepsilon}_t}$进行ARCH效应检验。我们计算残差的平方序列$\hat{\varepsilon}_t^2$并使用Engle的LM检验 。结果显示拒绝“无ARCH效应”的假设，即残差平方存在显著的自相关，提示**存在ARCH/GARCH效应** 。这一发现并不意外，因为我们知道金融收益率通常具有波动集群现象。因此，有必要为残差建立一个条件方差模型。

• **波动性模型拟合：** 基于检验结果，我们为残差序列拟合一个GARCH模型。考虑到简单起见以及之前理论部分所述的常用模型，我们尝试了**GARCH(1,1)**形式。最终拟合的是**AR(2)-GARCH(1,1)**联合模型 ：均值方程为AR(2)，方差方程为GARCH(1,1)。估计得到的参数（未在讲义文字中给出）满足显著性和稳定性要求，具体数值可以从图表中获取（此处略）。

• **模型诊断：** 针对拟合的AR(2)-GARCH(1,1)模型，我们按前述方法计算**标准化残差** $s_t = \hat{\varepsilon}_t/\sqrt{\hat{h}_t}$ 并进行检验 。结果显示：标准化残差序列$s_t$在各滞后下均未表现出显著的自相关，表明均值模型充分；而$s_t^2$也未表现出显著的ARCH效应残留，表明GARCH(1,1)已成功捕捉了波动性 。因此，我们认为AR(2)-GARCH(1,1)模型是对该收益率序列的一个**有效模型**：它解释了线性相关结构，也解释了波动性的时间依赖结构。

• **杠杆效应分析：** 由于股票市场常被报道存在杠杆效应，我们进一步检验模型残差中是否存在**非对称效应**。具体地，可以检验负收益冲击是否比正收益冲击带来更高的未来方差。讲义中提到，通过对标准化残差或直接采用TARCH/EGARCH模型来检验。在本案例中，我们首先进行了形式检验，结果**显示确实存在杠杆效应**，即负向冲击对波动的影响显著大于正向冲击 。鉴于此，我们尝试扩展我们的波动模型以纳入杠杆效应，例如采用TARCH或EGARCH模型。

• **进一步模型尝试：** 首先尝试**TARCH(1,1)模型（在均值方程仍为AR(2)的前提下），在方差方程中加入$\lambda_1 d_{t-1}\varepsilon_{t-1}^2$项。然而，估计结果发现其中一个参数估计为负值** （可能是$\lambda_1$出现负值或其他参数异常），这不符合TARCH模型对参数的期望范围（理论上$\lambda_1 \ge 0$才有经济意义）。该结果表明TARCH模型在本数据上的适用性存疑，可能因为样本中波动非对称性没有很好地被这种简单阈值形式捕捉，或者估计不稳定。

随后，我们又尝试了**EGARCH(1,1)**模型，希望通过对数方差形式捕获非对称效应。然而对拟合的EGARCH模型进行诊断检查后发现，其残差仍存在某些问题，模型未能通过充分性检验 。这意味着EGARCH模型在此数据上可能不如简单的GARCH模型表现好，可能原因包括EGARCH引入了额外复杂性但未显著提升拟合。

• **最终模型与结论：** 鉴于TARCH和EGARCH模型在该数据上的不理想表现，我们最终保留了**对称的AR(2)-GARCH(1,1)**模型作为最佳模型。这一模型已经通过了严格的诊断，没有遗漏的线性相关或ARCH效应。虽然存在杠杆效应的统计迹象，但简单引入杠杆项并未改善模型拟合，这可能提示需要更丰富的数据或不同的非对称模型才能更好地量化杠杆效应。在当前情况下，**对称GARCH模型已经足够解释波动行为**。

  

通过本案例，我们展示了从识别ARCH效应、建立GARCH模型到诊断和改进的整个过程。结果表明，ARCH/GARCH模型在实证金融中确实有效：例如金融危机导致的高波动被模型刻画为条件方差的上升；模型也为我们提供了时间可变的置信区间宽度，有助于风险管理。

  

**11. 总结**

本讲义中，我们详细介绍了**波动性聚集**这一金融时间序列的典型现象及其建模方法。**ARCH/GARCH模型**及其各种扩展作为度量和预测条件异方差的主要工具，能够有效捕捉金融数据中方差的动态特征。总结如下：

• 金融市场中的**条件异方差**（波动率变化）是常见现象，简单的恒定方差假设往往不成立，需使用ARCH/GARCH类模型予以建模。

• **ARCH模型**通过让当前方差依赖于过去误差平方，解释了波动性聚集。**GARCH模型**进一步加入方差的滞后项，以更精简的参数描绘长期波动记忆，大幅提升模型的灵活性和拟合效果。

• 我们讨论了模型的建立步骤，包括识别ARCH效应（Engle的LM检验）、使用MLE估计参数、以及借助AIC/BIC选择最佳模型阶数。模型建成后，需要通过检查标准化残差和其平方的自相关来进行诊断，确保模型充分刻画了一阶和二阶特征。

• 基于GARCH模型的**波动性预测**可以提供动态的预测区间宽度，为投资组合风险管理和金融决策提供了更科学的依据。

• 针对实际需求，ARCH/GARCH模型有多种**扩展**：IGARCH用于高持久性情形，ARCH-M将风险引入均值方程，加入外生变量可以量化特定事件对波动的影响，TARCH和EGARCH捕捉波动性的非对称“杠杆效应”。这些扩展模型丰富了ARCH/GARCH族，使其能够适应不同的复杂场景。

• **多元GARCH模型**拓展到多维情形，可同时拟合多个资产的条件协方差矩阵，对于研究市场间的风险传染和投资组合风险至关重要。虽然多元模型复杂度高，但通过结构约束（如BEKK、CCC等）可在一定程度上化解计算难题，并提炼出有经济意义的结论。

• 通过NYSE U.S. 100指数的实证例子，我们看到ARCH/GARCH建模流程在现实数据中取得成功，验证了波动模型的重要性。该案例也提醒我们模型选择需结合诊断测试，有时简单的模型可能胜过过度复杂的模型。

总而言之，**ARCH/GARCH模型族**为分析和预测金融市场波动提供了基本框架和有力工具。在风险管理、资产定价、衍生品估值等领域，合理地建模和预测波动性是核心环节。本讲的内容为后续更高级的金融计量模型奠定了基础。在今后的学习中，可以进一步探索例如长记忆FIGARCH模型、更一般的波动因子模型以及高频数据的波动测度等主题，不断加深对金融市场波动规律的理解。

**第4讲：波动性建模 (Lecture 4: Modeling Volatility)**

**2. ARCH and GARCH Modelling（ARCH与GARCH建模）**

  

在这一节中，我们将介绍ARCH模型和GARCH模型，以捕捉金融时间序列中的波动性变化和聚集性特征。在介绍具体模型之前，先进行一些初步分析。

  

**初步分析**

  

**注释1：** 正如经验事实2所强调的，假设方差恒定（**同方差性**，homoskedasticity）在很多情况下并不合理。也就是说，我们经常观察到波动性随时间变化，而非固定一个水平。那么如何刻画随时间变化的方差呢？一种简单的尝试是引入一个**状态变量**（state variable）使得方差可以随状态变化。例如，假设模型：

$$y_{t+1} = \epsilon_{t+1} x_t,$$

其中$y_{t+1}$是我们关心的变量（已经去除均值，使其均值为0，以专注于波动部分），$\epsilon_{t+1}$是均值为0、方差为$\sigma^2$的**白噪声**（white noise），而$x_t$是第$t$期的某个状态变量。这样，条件方差就是：

$$\operatorname{Var}(y_{t+1} \mid \mathcal{F}_t) = \sigma^2 x_t^2.$$

通过这种方式，如果$x_t$随时间变化，那么$y$的条件方差也会随之变化。当$x_t$较大时，$\sigma^2 x_t^2$也较大，表示波动性提高；当$x_t$较小时，波动性降低。这为捕捉非恒定方差提供了一个思路。

  

**注释2：** 从实际数据的图形中可以看出，金融时间序列的波动性往往是聚集发生的，即高波动时期往往持续紧随高波动，低波动时期持续紧随低波动。因此，上述模型尝试中选择什么作为状态变量$x_t$很关键。经验上，为了捕捉**波动聚集性**，我们可以令状态变量的平方$x_t^2$代表第$t$期的波动程度。例如，可以用上一期变量波动的某种度量作为状态，从而使“最近时期波动大”这个信息传递到下一期的方差中去。这暗示我们或许可以用上一期残差的平方来代表当期的波动水平，并让它影响下一期的条件方差——这一想法正是ARCH模型的核心。

  

**注释3：** 从宏观经济数据来看，波动性也会经历阶段性的变化。例如，从图3.2可以看到，美国宏观经济波动自20世纪80年代以后有所降低。这一时期经济波动的下降在经济学上被称为**“大缓和”**（Great Moderation）。“大缓和”指的是美国自20世纪80年代以来经历的一段宏观经济波动显著减弱的时期。有关这一现象的详细综述，可参见Stock和Watson（2002年NBER宏观经济年刊）的研究。在“大缓和”期间，GDP增长率等宏观指标的波动幅度较此前几十年明显缩小，这对经济决策和政策制定产生了重要影响。

  

**注释4：** 相反地，从图3.3（金融市场数据）可以看到，在2008-2010年金融危机期间，金融市场波动性显著提高。在这段时间里，股票等资产的价格波动剧烈，条件方差显著增大。这强调了重大事件（如金融危机）对波动性的冲击作用。

  

**ARCH模型**

  

为了正式建模波动性，Engle（1982）提出了自回归条件异方差模型，即ARCH模型。我们先从最简单的ARCH(1)模型讲起，这其实是一般ARCH模型的特例。

  

**ARCH(1)模型定义：**

$$\epsilon_t = \nu_t \sqrt{\alpha_0 + \alpha_1 \epsilon_{t-1}^2},$$

其中${\nu_t}$是一列独立同分布（i.i.d.）的随机变量，满足$\mathbb{E}(\nu_t)=0,\ \operatorname{Var}(\nu_t)=1$。$\alpha_0$和$\alpha_1$为常数参数，且$\alpha_0 > 0$确保是正的，$0 \leq \alpha_1 < 1$保证平稳性。这里$\epsilon_t$可以看作我们感兴趣序列（例如资产回报率）的均值已滤除后的**随机扰动**（即残差）。模型表示此残差的方差并不恒定，而是由上一期残差的平方$\epsilon_{t-1}^2$决定。

  

**解释：** 在ARCH(1)中，$\epsilon_t$的条件方差为$\alpha_0 + \alpha_1 \epsilon_{t-1}^2$。也就是说，如果上一期出现了较大的扰动（无论正负，关键是$\epsilon_{t-1}^2$大），那么下一期$\epsilon_t$的方差将变大；反之，如果上一期扰动很小，那么下一期的方差也会相应较小。这精确地捕捉了波动聚集性的特征：剧烈波动之后往往还是剧烈波动，平稳时期则倾向于继续平稳。

  

ARCH(1)模型需要$\alpha_1 < 1$才能满足**平稳**（stationary），这意味着波动不会无限发散。可以证明在该条件下，$\epsilon_t$的无条件方差是有限且恒定的。具体而言，由于$\epsilon_t$均值为0且过程平稳，我们有：

$$\mathbb{E}(\epsilon_t^2) = \frac{\alpha_0}{1 - \alpha_1}.$$

这个公式给出了ARCH(1)序列的长期方差水平。当$\alpha_1$较大时，无条件方差会变得很大，表示序列波动剧烈；当$\alpha_1$趋近于1时，无条件方差趋向无限大（因为分母$1-\alpha_1$趋近0），这暗示如果$\alpha_1$太接近1，模型的波动性将非常持久以致无界。

  

值得注意的是，${\epsilon_t}$在ARCH模型下构成一个**鞅差序列**（martingale difference sequence，简称m.d.s.），这意味着$\mathbb{E}(\epsilon_t \mid \mathcal{F}_{t-1})=0$且序列没有自相关性（尽管方差不恒定，但由于条件均值为0且独立同分布扰动的作用，$\epsilon_t$本身不相关）。换言之，ARCH模型产生的残差序列在均值上表现为白噪声。

  

**结合均值模型：** 实际中，我们通常将条件均值模型和条件方差模型结合起来使用。也就是说，我们可以同时建模序列的平均水平和波动性。例如，可以将一个ARMA模型用于均值，ARCH模型用于方差，组合形成**均值-方差联合模型**。形式上，可以写为：

• **条件均值方程：**

$$y_t = a_0 + \sum_{i=1}^{p} a_i y_{t-i} + \sum_{j=0}^{q} b_j \epsilon_{t-j},$$

这部分是一个ARMA$(p,q)$模型，描述$y_t$的均值动态（其中$\epsilon_t$是均值方程的残差）。

• **条件方差方程：**

$$\epsilon_t = \nu_t \sqrt{\alpha_0 + \sum_{i=1}^{m} \alpha_i \epsilon_{t-i}^2},$$

这部分是一个ARCH($m$)模型，描述$\epsilon_t$的方差随时间的变化。

  

在这种模型中，$y_t$的波动来源于随机冲击$\epsilon_t$，而$\epsilon_t$的方差又依赖于过去残差的大小。通过这样的组合，我们既模拟了数据的均值结构，也模拟了波动性结构。例如，$y_t$可以是资产收益率的序列，我们用AR部分描述其平均数的演化，用ARCH部分描述其波动性的集群特征。

  

**GARCH模型**

  

随着ARCH模型在实践中的应用，人们发现某些情况下需要较高阶的ARCH才能充分描述波动性，但高阶模型会引入大量参数。类似于从AR模型推广到更简洁的ARMA模型的思路，Bollerslev（1986）将ARCH模型推广为更一般的**广义ARCH模型**，简称**GARCH模型**。GARCH模型在保持对条件异方差性建模能力的同时，用更少的参数捕捉长期的波动影响。

  

**GARCH(p,q)模型定义：**

\begin{aligned} \epsilon_t &= \nu_t \sqrt{h_t},\\ h_t &= \alpha_0 + \sum_{i=1}^{q} \alpha_i\,\epsilon_{t-i}^2 + \sum_{j=1}^{p} \beta_j\,h_{t-j}, \end{aligned}

其中${\nu_t}$为均值0、方差1的i.i.d.序列（同ARCH模型），$h_t$表示$\epsilon_t$在$t$时刻的条件方差（即波动性）。参数需要满足$\alpha_0>0$，$\alpha_i \ge 0$（$i=1,\dots,q$），$\beta_j \ge 0$（$j=1,\dots,p$），并且保证稳定性：$\sum_{i=1}^{q} \alpha_i + \sum_{j=1}^{p} \beta_j < 1$。这个约束类似于AR(1)模型中系数和小于1以确保平稳，它保证了波动性不会发散。

  

**说明：** GARCH$(p,q)$模型可以看作是ARCH模型的延展：它不仅让当前方差取决于过去残差的平方（ARCH项），还让当前方差取决于过去的方差水平（GARCH项，相当于“滞后”的$h$）。当$p=0$时，GARCH$(0,q)$就退化为ARCH($q$)模型。因此，GARCH模型提供了在相对低阶的情况下捕捉长期记忆（持久性）波动的能力。与同样刻画长记忆的高阶ARCH模型相比，GARCH模型往往可以用更少的参数达到类似的效果，因而通常更**简洁**（parsimonious）。

  

和ARCH一样，GARCH模型下${\epsilon_t}$也是**鞅差序列**，因此$\epsilon_t$序列本身均值为0且不存在线性自相关（尽管$\epsilon_t^2$可能自相关，因为方差在演化）。GARCH模型的条件方差表达式为：

$$\mathbb{E}(\epsilon_t^2 \mid \mathcal{F}_{t-1}) = h_t = \alpha_0 + \sum_{i=1}^{q} \alpha_i \epsilon_{t-i}^2 + \sum_{j=1}^{p} \beta_j h_{t-j}.$$

这个公式直接体现了当前条件方差由过去$q$期的冲击大小（$\epsilon^2$）和过去$p$期的条件方差决定。由于我们要求$\sum \alpha_i + \sum \beta_j < 1$，该过程是平稳的，因而$\epsilon_t$存在有限的长期方差。可以推导出无条件方差为：

$$\mathbb{E}(\epsilon_t^2) = \frac{\alpha_0}{1 - \sum_{i=1}^{q}\alpha_i - \sum_{j=1}^{p}\beta_j}.$$

这一结果与ARCH(1)情形类似：分母中的$(1-\sum \alpha_i - \sum \beta_j)$表示波动性衰减的速度，越接近1则分母越小，无条件方差越大。

  

**举例：** 最常用的是GARCH(1,1)模型，其形式为：

$$h_t = \alpha_0 + \alpha_1 \epsilon_{t-1}^2 + \beta_1 h_{t-1}.$$

它表明“昨日”的波动信息（$\epsilon_{t-1}^2$）和“昨日”的波动水平（$h_{t-1}$）共同决定了今天的波动水平$h_t$。如果$\alpha_1$和$\beta_1$都比较大，那么昨日的冲击和波动对今天都有很强的影响，体现出波动的高持久性。

  

**波动性的预测**

  

有了GARCH模型，我们可以对未来的波动性进行动态预测。假设我们估计出了GARCH模型的参数并得到了当前的条件方差$h_t$，那么可以计算一步或多步向前的波动性预测。

• **一步ahead预测：** 以GARCH(1,1)为例，一步向前（$t+1$）的条件方差预测为：

$$\mathbb{E}_t[h_{t+1}] = \alpha_0 + \alpha_1 \epsilon_{t}^2 + \beta_1 h_t.$$

这里下标$t$表示以$t$期的信息进行预测。因为在$t$时刻，$\epsilon_t$已知（通过观测得到当前残差），$h_t$也已知，所以可以直接代入得到$h_{t+1}$的预测值。

• **多步ahead预测：** 对于更远的$j$步预测（$t+j$期的条件方差），需要递归计算。一般地，可以证明：

$$\mathbb{E}_t[h_{t+j}] = \alpha_0 \left[1 + (\alpha_1+\beta_1) + (\alpha_1+\beta_1)^2 + \cdots + (\alpha_1+\beta_1)^{,j-1}\right] + (\alpha_1+\beta_1)^j,h_t.$$

这个结果展示了未来$j$期的波动性是当前波动$h_t$按照系数$(\alpha_1+\beta_1)$逐步衰减加上一个常数项累积的结果。括号中的级数其实是一个等比数列的求和。如果$\alpha_1 + \beta_1 < 1$，则当预测步数$j \to \infty$时，前面的求和部分趋于$\frac{1}{1-(\alpha_1+\beta_1)}$，因此：

$$\lim_{j\to\infty}\mathbb{E}_t[h_{t+j}] = \frac{\alpha_0}{,1 - (\alpha_1+\beta_1),},$$

这正是模型的无条件方差水平。也就是说，当$\alpha_1+\beta_1<1$时，远期的波动性预测会收敛到一个稳定值，表示即使当前有冲击影响，经过足够长时间，波动性会回归到长期平均水平$\alpha_0/(1-\alpha_1-\beta_1)$。

如果$\alpha_1 + \beta_1$非常接近1，那么波动性的衰减就会非常慢，预测将长时间保持较高的值；如果$\alpha_1 + \beta_1 = 1$，上述公式中的求和不收敛，意味着预测的方差会随着$j$线性增长。此时模型称为**IGARCH**（积分GARCH）过程，我们将在“模型扩展”部分详细讨论。在这种情况下，波动性**没有均值回复**（mean-reverting）的特征，震荡的影响会永久持续在未来的波动预测中。

  

需要指出，当存在条件异方差性时，预测区间的计算需要考虑变动的方差。例如，对于有条件方差$h_{t+1}$的一步预测，未来$y_{t+1}$的置信区间可以写为：

$$\mathbb{E}_t[y_{t+1}] \pm 1.96 \sqrt{h_{t+1}},. $$

这与简单恒定方差情形（$\pm1.96\sigma$）不同，因为现在未来误差的标准差本身是动态变化的$h_{t+1}^{1/2}$。因此，应用ARCH/GARCH模型可以改善我们对未来区间范围的估计，使之随波动性变化而调整，更加准确地反映不确定性。

  

以上讨论的预测公式不仅适用于GARCH(1,1)，对于一般的GARCH(p,q)模型，可以采用类似的递推方法得到多步预测。原理是在已知当前条件方差的情况下，不断对方差方程迭代，以获得未来各期的$\mathbb{E}[h]$值。

  

**3. Some Extensions（模型扩展）**

  

基本的ARCH/GARCH模型可以解释许多金融时间序列中的波动现象，但实际应用中人们对其进行了多方面的扩展。本节介绍几种常见的扩展，包括针对高度持久波动的IGARCH模型、引入均值方程反馈的ARCH-M模型、含有外生变量的GARCH模型、捕捉波动非对称性的TARCH和EGARCH模型，以及多元情形下的GARCH模型。

  

**IGARCH模型**

  

金融时间序列的一个典型特征是波动性的**高度持久**（persistent）。实证中，对许多资产回报率拟合GARCH(1,1)模型时，常常发现估计得到的$\hat{\alpha}_1 + \hat{\beta}_1$非常接近1。这意味着波动冲击的影响在模型中衰减得极其缓慢。极端情况下，如果$\alpha_1 + \beta_1 = 1$，我们就得到所谓的**积分GARCH模型**（Integrated GARCH，简称IGARCH）。IGARCH(1,1)实际上就是$\alpha_1 + \beta_1 = 1$的GARCH(1,1)模型。

  

在IGARCH(1,1)模型中，波动性的长期均值不存在，因为$\alpha_1+\beta_1=1$使得前述无条件方差公式分母为0，无条件方差趋于无穷大。这意味着方差冲击没有均值回复：一个冲击来了以后，其对未来方差的影响会**永久持续**下去（当然影响程度会逐渐衰减到一个常数水平，但不会消失）。具体来说，IGARCH下$j$步的波动性预测为：

$$\mathbb{E}_t[h_{t+j}] = j,\alpha_0 + h_t,$$

可以看到它随预测步数$j$呈线性增长，因为没有$(\alpha_1+\beta_1)<1$的收敛因子。

  

IGARCH模型常用于描述那些观察到近似单位根行为的波动性过程。当估计发现$\alpha_1+\beta_1$非常接近1时，我们可以使用IGARCH作为近似模型。这并不意味着真实的波动方差真的无限大，而是说在实际可观测的范围内，方差变化看起来没有回归均值的趋势，需要很长的时间才能回归。因此，IGARCH提供了一种处理“超高持久性”波动的方法。

  

**注：** 尽管IGARCH理论上无条件方差发散，但在有限样本中它依然可以用来预测短期和中期的波动性。只是要注意，它暗示了波动性的记忆非常长，模型对过去冲击异常敏感。

  

**ARCH-M模型**

  

**ARCH-M**（ARCH in Mean）模型是另一种扩展，它允许**均值**中包含波动性的影响。具体来说，ARCH-M模型在均值方程中引入了由条件方差决定的项，通常用于研究**风险溢价**（risk premium）效应。

  

ARCH-M模型的一般形式为：

\begin{aligned} y_t &= \mu_t + \epsilon_t,\\ \mu_t &= \beta + \delta\,h_t, \end{aligned}

其中$\epsilon_t$仍然是波动性$h_t$驱动的异方差扰动（例如服从某个GARCH过程），而$\mu_t$是条件均值，包含一个常数项$\beta$和一项$\delta,h_t$。参数$\delta > 0$意味着条件方差越大，条件均值$\mu_t$越高。

  

**经济意义：** 如果以资产收益率为例，$h_t$代表时期$t$的风险（波动性）水平，那么$\delta>0$表示**高风险伴随高预期收益**。这正是风险溢价的概念：投资者要求对承受更高的不确定性（风险）给予补偿，因此资产的期望收益中包含一项随风险增大而升高的溢价。比如，在股票市场中，当市场波动剧烈时（风险上升），投资者可能预期更高的回报率来补偿风险，于是模型均值部分会提高。

  

ARCH-M模型最早应用于宏观和金融领域，例如解释利率和通货膨胀等宏观变量关系，或者解释股票收益中风险和收益的权衡关系。在模型估计中，可以检验$\delta$是否显著为正，从而判断风险溢价效应的存在与强度。

  

**示例说明：** 假设某股票收益的ARCH-M模型估计得到$\delta=0.5$，意味着当条件方差$h_t$增加一个单位时，日收益的条件均值将增加0.5个百分点。这说明高波动时期该股票的预期回报会上升。当然，在实际数据中，风险溢价效应是否显著需要通过统计检验确定。

  

**带有解释变量的波动模型**

  

在有些情况下，我们希望在条件方差方程中纳入其他**外生解释变量**（exogenous variables）或哑变量，以捕捉特定事件或因素对波动性的影响。基本的ARCH/GARCH模型只利用了自身过去的信息来解释波动性，但现实中某些已知事件（政策变化、经济发布、突发事件等）可能会导致波动性跳变，我们可以通过在方差方程中加入相应的变量来反映这些影响。

  

**示例：** 我们想检验**“9·11事件”**（2001年9月11日的恐怖袭击）是否显著提高了美国股市的波动性。为此，可在GARCH方差方程中加入一个对应该事件的哑变量$D_t$。模型可以设定为：

$$h_t = \alpha_0 + \alpha_1 \epsilon_{t-1}^2 + \beta_1 h_{t-1} + \gamma D_t,$$

其中$D_t$是在2001年9月11日之前$D_t=0$，在2001年9月11日及之后$D_t=1$的哑变量。这里我们使用了一个GARCH(1,1)结构并叠加事件哑变量。

  

在这个模型中，如果估计得到$\gamma > 0$且在统计上显著，那么可以认为“9·11事件”之后的时期波动性平均水平较事件前有显著提高，即恐怖袭击增加了股市波动。如果$\gamma$不显著，则表明该事件对长期波动水平的影响不明显。

  

**拓展：** 类似地，我们可以引入其他形式的解释变量。例如，使用宏观经济指标（如利率、交易量）作为方差方程的额外解释变量，以检测这些因素与波动性的关系。需要注意，加入解释变量需要确保模型依然满足方差的非负性和稳定性等条件，一般来说线性加即可，但参数要通过检验确认其显著性和合理性。

  

**带非对称效应的模型：TARCH 和 EGARCH**

  

金融市场中还有一个著名的经验现象——**杠杆效应**（leverage effect），这表现为**波动性的非对称性**：坏消息（例如股价大跌，负回报）对未来波动性的影响往往比好消息（股价大涨，正回报）更显著。换言之，对于许多股票，当前收益与未来波动率之间存在强烈的负相关：当股价下跌时，往往预示着未来波动加剧；而股价上涨则预示波动相对温和。这种不对称被称为“杠杆效应”，因为一种解释是：当公司股价下跌时，公司的股权价值减少，相对于债务的比率降低，从而**财务杠杆率**（debt-to-equity ratio）上升。这使得股票对于持有者来说变得更风险（公司负债相对于资产增多使股票更脆弱），因而股价下跌往往带来未来更高的波动。简单而言，**负向冲击放大未来风险**的效应称为杠杆效应。

  

为捕捉这种非对称性，人们提出了在GARCH模型中加入机制，使正负残差对方差的影响不同。常用的非对称波动模型包括**门限GARCH模型**（Threshold GARCH，简称TARCH或有时记作TGARCH）和**指数GARCH模型**（Exponential GARCH，简称EGARCH）。

  

**TARCH模型：** TARCH通过在方差方程中引入一个针对负残差的指示变量来实现非对称效应。以TARCH(1,1)为例，其形式可写为：

$$h_t = \alpha_0 + \alpha_1 \epsilon_{t-1}^2 + \lambda_1,d_{t-1},\epsilon_{t-1}^2 + \beta_1 h_{t-1},$$

其中$d_{t-1}$是一个哑变量，当$\epsilon_{t-1} < 0$时$d_{t-1}=1$，当$\epsilon_{t-1} \ge 0$时$d_{t-1}=0$。也就是说，$\epsilon_{t-1}^2$项会根据$\epsilon_{t-1}$的符号被赋予不同的系数：如果前一期是负冲击，则方差方程中实际影响是$(\alpha_1+\lambda_1)\epsilon_{t-1}^2$；如果前一期是正冲击，则影响是$\alpha_1 \epsilon_{t-1}^2$（因为这时$d_{t-1}=0$，额外项不起作用）。

  

**解释：** 当$\lambda_1 > 0$时，负向冲击对下一期波动性的影响系数为$\alpha_1 + \lambda_1$，比正向冲击的$\alpha_1$更大。因此负向冲击会引起更高的条件方差，这就捕捉了杠杆效应。例如，假设$\alpha_1=0.1$，$\lambda_1=0.3$，前一期$\epsilon_{t-1}=-2$（一个较大的负冲击，对应$\epsilon_{t-1}^2=4$），则$\epsilon_{t-1}^2$项对$h_t$的贡献是$(0.1+0.3)\times4=1.6$；如果相同大小的正冲击$\epsilon_{t-1}=+2$（$\epsilon_{t-1}^2=4$），则贡献为$0.1\times4=0.4$。其余相同情况下，负冲击导致的本期方差比正冲击大得多。这正体现了“坏消息”导致更大波动的效果。TARCH模型通过$\lambda_1$参数的显著性和符号可以检验杠杆效应是否存在：$\lambda_1>0$且显著表示存在杠杆效应。

  

**EGARCH模型：** 指数GARCH模型采用对数形式的方差方程，形式例如EGARCH(1,1)：

$$\ln h_t = \alpha_0 + \alpha_1 \left(\frac{\epsilon_{t-1}}{\sqrt{h_{t-1}}}\right) + \lambda_1 \left|\frac{\epsilon_{t-1}}{\sqrt{h_{t-1}}}\right| + \beta_1 \ln h_{t-1}.$$

这里，引入$\frac{\epsilon_{t-1}}{\sqrt{h_{t-1}}}$作为标准化的残差（通常称为_z-score_，表示上一期残差相对于其标准差的大小和方向），这样做有两个好处：其一，使用$\ln h_t$确保了预测的$h_t$永远为正（因为指数的输出总是正的），不需要像标准GARCH那样对参数非负作约束；其二，通过$\alpha_1$乘以标准化残差和$\lambda_1$乘以残差的绝对值，相当于把残差的符号和幅度分离来影响$\ln h_t$，从而实现非对称效果。

  

**解释：** 在EGARCH模型中，$\lambda_1$对应$|\epsilon_{t-1}/\sqrt{h_{t-1}}|$，表示无论正负，残差的绝对大小都会提高未来波动（这是对称的幅度效应）；而$\alpha_1$对应$\epsilon_{t-1}/\sqrt{h_{t-1}}$，这项可以为正或负，如果$\alpha_1$为负值，则当$\epsilon_{t-1}$为负时，这一项为负乘以负得到正，因而增加$\ln h_t$，而当$\epsilon_{t-1}$为正时，这一项为正乘以负得到负，从而减少$\ln h_t$。如此就实现了**负冲击放大波动、正冲击相对减弱波动**的非对称影响。因此，在EGARCH中，如果估计发现$\alpha_1 < 0$且显著，就意味着显著的杠杆效应存在。

  

EGARCH模型的另一个特点是，由于$\ln h_t$可以为负，参数$\alpha_1$和$\lambda_1$本身不需要限制为非负。甚至$\alpha_1$可以为负来体现负相关效应。这与标准GARCH/TARCH模型要求参数非负以确保$h_t$为正形成对比。在EGARCH中，$h_t = \exp(\ln h_t)$总是正的，因此模型在参数约束上更灵活。此外，通过对残差进行标准化处理，EGARCH模型在刻画大残差事件（如极端冲击）对波动的影响时也更为方便。

  

**杠杆效应的检验：** 我们可以通过检验上述模型中的参数来判断杠杆效应是否存在——例如，TARCH模型检验$\lambda_1$是否大于0显著，EGARCH模型检验$\alpha_1$是否不为0（特别是是否为负显著）。除了直接估计模型检验参数外，还有一种更直接的检验方法：先假定没有杠杆效应，估计一个不含非对称项的ARCH/GARCH模型，然后对其残差进行后验检验。具体步骤如下：

1. 先对序列拟合一个不包含杠杆效应的对称ARCH/GARCH模型，得到残差$\hat{\epsilon}_t$和相应的条件方差估计$\hat{h}_t$。

2. 计算标准化残差序列：$$s_t = \frac{\hat{\epsilon}_t}{\sqrt{\hat{h}_t}},. $$ 在模型正确且无杠杆效应的情况下，理想的$s_t$应当类似于独立同分布的白噪声序列。

3. 构造回归：$$s_t^2 = a_0 + a_1 s_{t-1} + a_2 s_{t-2} + \cdots + a_p s_{t-p} + \eta_t,$$ 然后检验回归中$lags$系数的联合显著性（即检验命题$a_1 = a_2 = \dots = a_p = 0$是否成立）。

4. 如果拒绝该原假设（即发现一些$a_i$显著不为0），则说明标准化残差的平方存在自相关。这通常意味着原模型未能捕捉全部波动模式，很可能是因为存在杠杆效应等非对称性尚未建模。如果原模型已经是对称的ARCH/GARCH，没有其它原因导致残差平方相关，那么残差平方相关性可以视为杠杆效应的迹象之一——特别是负残差往往导致下一期残差平方偏大，会产生这种相关性。

  

需要注意，这种方法其实检测的是是否有**残差平方的动态相关**未被模型解释。这可能是由于杠杆效应，也可能是模型阶数不足等原因。因此，实际检验杠杆效应时通常结合经济含义和专门设计的检验（例如针对负残差的显著性检验）综合判断。但上述基于标准化残差的回归检验提供了一种简单可行的方法去发现ARCH/GARCH模型中遗漏的模式。

  

**多元GARCH模型**

  

目前讨论的ARCH/GARCH模型都集中在单变量时间序列上。但在现实中，我们经常需要同时研究多个相关资产或经济变量的波动。例如，在投资组合选择中，我们不仅关心单个资产的波动率，还关心资产之间的相关性以及由此带来的**波动外溢**（volatility spillover）效应。这就需要**多元GARCH模型**来同时估计多个变量的条件协方差结构。

  

**动机：** 当我们有多维数据时，可以尝试分别对每个序列拟合单变量GARCH模型来得到各自的$h_{it}$（第$i$个序列的条件方差）。然而，这无法直接给出序列之间的协方差或相关性的信息。而投资组合风险取决于不同资产收益之间的协动关系，因此我们需要模型来估计**条件协方差矩阵**（conditional covariance matrix）。多元GARCH模型的目标正是同时建模$\mathbf{H}_t = \operatorname{Cov}(\boldsymbol{\epsilon}_t \mid \mathcal{F}_{t-1})$，其中$\boldsymbol{\epsilon}_t$是包含多个变量残差的向量。

  

**特点：** 在多元GARCH模型中，不同序列在同一时期的冲击可以是相关的。这意味在模型中允许$\epsilon_{it}$和$\epsilon_{jt}$之间（$i\neq j$）存在**同时相关**（contemporaneous correlation）。同时，不同序列的波动性可以相互影响：一个变量的波动冲击可能会影响另一个相关变量的未来波动，这就是**波动溢出**现象。例如，一个短期利率的冲击可能提高长期利率的未来波动；股票市场的巨震可能影响债券市场的波动等。多元GARCH模型可以捕捉这些复杂的动态相关结构。

  

**二维案例：** 为简单说明多元GARCH的构造，考虑双变量（二维）情形$(\epsilon_{1t}, \epsilon_{2t})$。我们可以设：

$$\epsilon_{1t} = \nu_{1t}\sqrt{h_{1t}},$$

$$\epsilon_{2t} = \nu_{2t}\sqrt{h_{2t}},$$

其中$\nu_t = (\nu_{1t}, \nu_{2t})’$服从均值为0协方差矩阵为$\Sigma$的i.i.d.分布。假设$\Sigma = \begin{pmatrix}1 & \rho \ \rho & 1\end{pmatrix}$，其中$\rho$表示两变量同时冲击的相关系数（即$\operatorname{Corr}(\nu_{1t},\nu_{2t})=\rho$）。这个设定意味着在每一期内，两系列残差可能同时受到相关的影响。例如，若$\rho$接近1，表示每期中两个市场几乎总是同向波动；$\rho$接近-1表示当一个市场正向冲击时另一个往往负向冲击。不过，一般$\rho$在[-1,1]之间适中值，表示同时相关性。

  

在此基础上，我们还需要描述$h_{1t}, h_{2t}$和两者之间协方差$h_{12,t}$（或相关系数）的演化关系。其中一个最一般的方法称为**VECH模型**（vech是向量化的意思）。VECH模型直接对**协方差矩阵的下三角元素**建模，将它们拉成一个向量，然后像单变量GARCH那样写出它关于过去残差和过去协方差的方程。具体形式比较复杂（可参考教材公式3.42-3.44），但思想上类似：每个方差$h_{ii,t}$和协方差$h_{ij,t}$都由自己的常数项、过去残差乘积项和过去协方差项线性生成。

  

**VECH模型的问题：** 完全一般的VECH模型在实践中面临两大困难：

• **参数过多：** 随着变量维度增加，协方差矩阵的元素数量增多，参数急剧上升。例如，对于$n$维序列，协方差矩阵有$\frac{n(n+1)}{2}$个不同元素，每个都可能需要自己的参数，估计非常困难，而且容易过拟合。

• **正定性难保证：** 协方差矩阵$\mathbf{H}_t$必须是正定矩阵（positive definite）才能是有效的协方差。但简单地对每个元素独立建模可能无法确保组合起来的矩阵仍然是正定的——有时会出现模型给出的某些$\mathbf{H}_t$不满足正定性条件，使得其不是合法的协方差矩阵。这在数值优化中也会带来麻烦。

  

为解决上述问题，研究者提出了一些简化方案：

• **对角VECH模型（Diagonal vech）：** 这是针对参数过多问题的一种约束形式。它假定协方差矩阵各元素的演进只和各自对应的过去值有关，忽略掉不同位置之间的交叉影响。例如，$h_{12,t}$的演化可能只依赖于过去的$h_{12,t-1}$和$\epsilon_{1,t-1}\epsilon_{2,t-1}$，而不引入其它复杂交叉项。这样可以大幅减少参数数量，代价是模型结构收紧了。

• **BEKK模型：** BEKK模型（Engle和合作作者于1991年提出的一种参数化方案）通过特定的矩阵分解形式来保证正定性，同时也在一定程度上减少参数。一个双变量BEKK(1,1)模型可以表示为：

$$\mathbf{H}_t = C’C + A’,\boldsymbol{\epsilon}_{t-1}\boldsymbol{\epsilon}_{t-1}’,A + B’,\mathbf{H}_{t-1},B,$$

其中$C$、$A$、$B$都是矩阵（$C$通常是上三角矩阵，以减少重复参数），$\boldsymbol{\epsilon}_{t-1}\boldsymbol{\epsilon}_{t-1}’$是前一期残差的外积矩阵。可以看出，这个形式类似于GARCH(1,1)的矩阵版：$C’C$提供了常数项，$A’$项提供了由残差外积得来的“新信息”项，$B’$项提供了由过去协方差矩阵得来的持久项。通过$C’C$结构，$\mathbf{H}_t$天然正定（因为无论$A$、$B$如何，$C’C$始终正定，加上另外两项协方差形式仍保持正定）。同时，由于$A$、$B$是矩阵而不是完全自由的协方差元素，参数数量比完全VECH模型少得多。但仍然，BEKK模型的参数数量随着维度增长也会变得相当大（近似于$O(n^2)$级别参数），计算复杂度较高。

  

**常数相关模型CCC：** 另一种广受欢迎的多元GARCH简化是由Bollerslev提出的**常数条件相关模型**（Constant Conditional Correlation，简称CCC模型）。该模型假设变量之间的相关系数是常数不变的，而各变量自己的方差服从标准的单变量GARCH动态。换言之，它将条件协方差矩阵$\mathbf{H}_t$拆分为：_

_$$\mathbf{H}t = D_t , \mathbf{P} , D_t,$$_

_其中$D_t$是对角矩阵，包含每个变量的条件标准差（即$D{ii,t} = \sqrt{h_{ii,t}}$），$\mathbf{P}$是一个**常数**相关矩阵（元素为$\rho_{ij}$，固定不随时间变）。在这种结构下，$h_{ii,t}$可以用GARCH(或ARCH)方程各自拟合，而协方差由公式$h_{ij,t} = \rho_{ij} \sqrt{h_{ii,t} h_{jj,t}}$给出。例如双变量情况下：

$$h_{12,t} = \rho_{12} \sqrt{h_{11,t}; h_{22,t}},. $$

  

**CCC模型的优点：** 它极大减少了参数维度，因为相关系数固定，一个$n$维系列只需要估计$\frac{n(n-1)}{2}$个相关参数（而且这些可以通过历史数据直接估计，也可在模型估计中同时进行），其余都是各维自己的GARCH参数。这样估计会容易很多，而且由于协方差矩阵在每期是通过固定相关系数计算得到的，保证了正定性（相关矩阵$\mathbf{P}$本身是固定且在估计时可确保为正定，如通过Cholesky分解参数化）。**使用场景：** 当相信变量间相关结构相对稳定时，CCC模型是一个合理的选择。然而，在某些应用中，假设相关系数恒定可能过于严格，因为金融市场的不同时期资产间相关性可能发生变化。所以在实践中，如果发现相关性并非常数，就需要进一步扩展模型。

  

**DCC模型：** 针对CCC模型的局限，Engle等提出了**动态条件相关模型**（Dynamic Conditional Correlation, DCC），它允许相关矩阵随时间演化，但方式比一般VECH模型受限得多，从而在保证模型可估计性的同时增加了灵活性。DCC模型超出了本讲讨论范围，但提及其概念：它通常分两步估计，先估各变量方差，再估相关动态，使之类似于ARMA模型，以捕捉相关性的变化。

  

**波动性脉冲响应函数：** 在多元情形下，我们关心的问题之一是**一个变量的冲击对另一变量未来波动的影响**。这类似于VAR模型里讨论冲击对均值的影响（脉冲响应函数），这里是针对波动的。考虑一个简单的双变量模型，上文提到的一般VECH模型（或BEKK模型）的某种参数化。假设我们的双变量条件方差方程可以展开写出，如对$h_{11,t}$而言（$h_{11,t}$是第一个变量的条件方差）：

\begin{aligned} \mathbb{E}t[h{11,t+1}] &= c_{10} \;+\; \alpha_{11}\,\epsilon_{1t}^2 \;+\; \alpha_{12}\,\epsilon_{1t}\epsilon_{2t} \;+\; \alpha_{13}\,\epsilon_{2t}^2 \\ &\quad+\; \beta_{11}\,h_{11,t} \;+\; \beta_{12}\,h_{12,t} \;+\; \beta_{13}\,h_{22,t}\,, \end{aligned}

其中$c_{10}$是常数项，$\alpha_{11}, \alpha_{12}, \alpha_{13}$表示前一期自己和他人残差对本期方差的影响系数，$\beta_{11}, \beta_{12}, \beta_{13}$表示过去协方差矩阵各元素的影响系数。这个具体形式只是举例说明双变量情况下$h_{11}$可能依赖于$\epsilon_{1t}^2$（自身冲击平方）、$\epsilon_{1t}\epsilon_{2t}$（两变量共同冲击项）和$\epsilon_{2t}^2$（另一变量冲击平方），以及过去的$h_{11}, h_{12}, h_{22}$。给定这种模型结构，我们可以类似单变量情况递归计算多步预测，比如：$\mathbb{E}_t[h_{11,t+2}]$可以用$\mathbb{E}_t[h_{11,t+1}]$、$\mathbb{E}_t[h_{12,t+1}]$等求出，依此类推得到$j$步预测。

  

**脉冲响应**指我们让某个变量在当前受到一个特定冲击，然后观察相对于没有冲击时，未来各期波动预测值的变化。形式上，令$T$为冲击发生时刻，我们可以定义**波动性脉冲响应函数**为：

$$\text{VIRF}_{j}(T) = \mathbb{E}_T^*!\left[h_{11,,T+j}\right] - \mathbb{E}_T!\left[h_{11,,T+j}\right],$$

其中$\mathbb{E}_T^*$表示在$T$时刻给予系统一个单位冲击后所做的预测，而$\mathbb{E}_T$是不施加冲击时的预测。差值就衡量了该冲击对第一个变量$j$期后波动的影响程度。例如，如果我们想看第二个变量当期一个单位正向冲击对第一个变量未来波动的影响，就可以把$\epsilon_{2,T}$在$T$期提高1个单位，然后比较第一个变量此后的方差预测与无冲击时的差异。这个函数可以随着$j$变化绘制出来，形象地展现冲击影响波动的持久性和大小。

  

波动性脉冲响应分析在研究市场之间风险传染（contagion）、资产间风险溢出等问题时很有用。通过它我们可以定量回答例如：“某市场的一次巨震，会导致另一市场波动上升多久、多大？”这些问题。不过需要注意，多元GARCH模型比较复杂，计算脉冲响应也需要对模型有明确的参数化和估计，实证分析中实施有一定难度。

  

**4. Estimating the NYSE U.S. 100 Index（对NYSE美国100指数的估计）**

  

下面通过一个实证例子来说明ARCH/GARCH建模的实际应用步骤。我们以NYSE美国100股票指数（日频）为对象，从数据的描述、模型选择到诊断检验，演示如何建立一个合理的波动性模型。

  

**数据描述**

  

我们使用的数据是纽约证券交易所（NYSE）美国100指数的对数差分（即对数收益率），采样频率为**日频**。样本区间从2000年1月4日到2012年7月16日，总共3270个观测值。由于采用对数差分，数据序列近似可看作收益率的时间序列。

  

这个时间段涵盖了一些波动性高低变化的子时期：例如**2004-2006年**期间市场相对平稳，波动性较小；而**2008-2009年**金融危机期间市场剧烈波动，波动性显著增大。图3.3给出了这一路径的时间序列图，可以清楚地看到在2008年前后波动性的陡升。总体来说，这套数据非常适合用来检验ARCH/GARCH模型对波动聚集性的捕捉能力。

  

在建模之前，我们通常会先绘制数据图表并做初步的统计分析。图形显示该收益率序列均值大致为零，但波动程度随时间而变：特别是2008年附近的波峰波谷格外明显。这符合我们对金融时间序列的预期，也提示我们很可能在模型中需要考虑条件异方差性。

  

**条件均值和条件方差的建模过程**

  

下面我们按照Box-Jenkins建模策略，对NYSE美国100指数的收益率序列进行均值和方差建模。主要步骤包括：识别均值模型、检验ARCH效应、拟合GARCH模型以及诊断和改进模型（例如考虑杠杆效应）。

1. **均值模型选择：** 首先对序列的均值部分进行建模。通过对自相关函数（ACF）和偏自相关函数（PACF）的观察，并结合信息准则（如AIC），我们发现AR(2)模型是一个合适的选择。AIC准则在多种候选模型中选择了滞后2的自回归模型。这意味着收益率$y_t$可以用前两日的收益率来解释：

$$y_t = \phi_0 + \phi_1 y_{t-1} + \phi_2 y_{t-2} + \epsilon_t.$$

拟合结果显示$\phi_1, \phi_2$估计值显著，模型通过了Ljung-Box等检验，证明残差中已无显著的线性自相关——因此AR(2)均值模型是**充分且合理**的。

2. **ARCH效应检验：** 在得到均值模型的残差$\hat{\epsilon}_t$后，我们需要检验残差序列中是否存在ARCH效应，也就是条件异方差性。常用的方法是对**残差的平方**应用Lagrange乘数检验（ARCH效应的LM检验，由Engle提出）。具体做法是检验$\hat{\epsilon}_t^2$是否存在自相关，例如构造$\hat{\epsilon}_t^2$对其滞后项的回归，看滞后项是否整体显著。结果表明，该序列的残差平方存在显著的自相关关系（LM检验显著），这强烈表明**ARCH效应存在**。换句话说，残差的波动性不是白噪声型的，而是有集群现象需要模型来描述。

3. **拟合ARCH/GARCH模型：** 鉴于检测到了ARCH效应，我们接下来为残差的方差建立模型。结合常识和便利性，我们选用**GARCH(1,1)**来拟合残差的条件方差，同时保留前面估计的AR(2)作为均值方程。也就是拟合一个AR(2)-GARCH(1,1)联合模型。通过极大似然估计，我们得到了模型参数，发现$\alpha_1$和$\beta_1$都显著为正，且$\alpha_1 + \beta_1$接近1但略小于1（满足稳定性条件）。这表明市场波动具有很高的持久性但仍是均值回复的。模型中常数项$\alpha_0$则很小，意味着即使没有最近的波动冲击，基本的波动水平也很低。总的来说，这个拟合的GARCH(1,1)模型能够刻画出我们在图形中观察到的波动集群特征。

4. **模型诊断：** 估计完AR(2)-GARCH(1,1)模型后，我们需要对模型的残差做进一步诊断，检查是否还存在未捕捉的模式。为此，我们计算**标准化残差**：

$$s_t = \frac{\hat{\epsilon}_t}{\sqrt{\hat{h}_t}},$$

其中$\hat{\epsilon}_t$是模型的残差，$\hat{h}_t$是根据模型计算的$t$期条件方差。标准化残差理论上应该近似服从i.i.d.标准正态（如果模型完美拟合）。我们对$s_t$进行了检验，结果显示它在自相关检验上没有显著序列相关，表明**均值方程残差已无线性相关**，在ARCH效应检验上也无剩余的GARCH效应。这说明我们的模型已经充分解释了数据中的线性和条件异方差特征，模型是**充分的**。

5. **杠杆效应检验与模型改进尝试：** 虽然AR(2)-GARCH(1,1)模型通过了一般性的诊断检验，我们还关心是否存在波动的非对称性（杠杆效应），因为股票市场常见这种现象。我们对标准化残差进行了杠杆效应检验（例如基于前述的方法或其他如Engle-Ng签效应检验）。结果**提示存在杠杆效应**，也就是说，数据中负向冲击对未来波动的影响比正向冲击更大。然而，当我们尝试在模型中加入杠杆效应时遇到了一些问题：首先，尝试拟合**TARCH模型**（在方差方程加入$\lambda_1 d_{t-1}\epsilon_{t-1}^2$项）时，估计得到的$\lambda_1$竟然为**负值**。按理论我们预期$\lambda_1>0$以体现负冲击放大效应，但这里却出现负值（且该参数估计不显著），这可能暗示我们的数据并非以简单的TARCH形式表现杠杆效应，或者样本中没有足够信息支持正的$\lambda_1$。无论如何，一个负的$\lambda_1$在TARCH模型中是不合理的（因为会意味着正冲击比负冲击引起更高波动，违背杠杆效应假设），因此TARCH模型在此数据上**并不适用**。其次，我们尝试了**EGARCH模型**来捕捉非对称性。然而拟合的EGARCH(1,1)模型在对标准化残差进行诊断时发现仍有一些模式未解释充分（例如残差分布偏厚尾，或某些高阶相关尚存），表明EGARCH拟合可能也不够完善。综合考虑下，我们没有在最终模型中加入复杂的非对称结构，而是保留了相对简单的对称GARCH模型。尽管检测暗示存在杠杆效应，但也许由于样本或模型设定限制，我们未能找到一个显著优于对称GARCH的非对称模型。实际分析中，研究者可能会进一步尝试不同形式（例如更高阶的模型或不同分布假设）来捕捉非对称性，这超出了本次分析的范围。

  

**小结：** 通过以上步骤，我们确定了NYSE美国100指数收益率的一个合理模型：均值方程为AR(2)，方差方程为GARCH(1,1)。这个模型很好地解释了序列的线性动态和条件异方差性，虽然存在杠杆效应的迹象，但简单扩展后效果不佳。在实践中，这个模型可以用于预测未来波动率并计算风险度量（如VaR），也为进一步研究波动性（比如外生变量对波动的影响）奠定了基础。

  

**5. Summary and Conclusions（总结与结论）**

• **条件异方差性是金融时间序列的重要特征。** 金融市场数据经常呈现**条件异方差性**（conditional heteroskedasticity），即波动性会随着时间变化并表现出集群现象。理解和建模这种特征对于风险管理、资产定价等金融问题非常重要。

• **ARCH/GARCH模型是分析波动性的主要工具。** Engle提出的ARCH模型及Bollerslev推广的GARCH模型提供了刻画条件方差动态的框架。通过这些模型及其扩展（如IGARCH、ARCH-M、TARCH、EGARCH等），我们能够捉住数据中的波动聚集和非对称效应。它们已经成为金融计量中分析波动的**标准方法**。

• **模型建立遵循系统的方法。** 本讲通过对NYSE股票指数的实证分析，展示了建立ARCH/GARCH模型的一般步骤：先拟合均值模型，再检验和建模方差的ARCH效应，最后进行诊断和必要的改进。结果强调，在应用这些模型时，需要注意模型假设是否满足（如残差的独立性、分布假设等），并根据数据特征考虑合适的扩展（比如检查杠杆效应，考虑多元模型等）。

  

总之，波动性建模极大地丰富了我们对时间序列的分析能力。从只关注均值到同时关注方差，ARCH/GARCH模型帮助我们理解了金融市场的一个核心性质——风险的动态性，并为实践中的风险预测和管理提供了有力工具。
