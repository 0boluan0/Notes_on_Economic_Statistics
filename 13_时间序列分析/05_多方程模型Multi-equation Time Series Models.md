## 1.1 干预分析

>[!note] 干预分析
>
为正式检验金属探测安检政策的效果，我们建立一个包含干预变量的时间序列模型。例如，用 $y_t$ 表示$t$期发生的劫机事件数量，引入干预哑变量$z_t$来表示政策实施：1973年第一季度（含）之后 $z_t=1$，之前 $z_t=0$。一个简单的干预模型可以写作：
> 
> $$
> 
> y_t = a_0 + a_1 y_{t-1} + c_0 z_t + \varepsilon_t,\quad |a_1|<1。
> 
> $$
> 
> 这里，$a_0$ 是常数项，$a_1$ 是劫机次数的**AR(1)系数**（表示过去劫机次数对当前的影响），$c_0$ 是干预效应系数，$\varepsilon_t$ 是白噪声误差项。模型中包含一个滞后项$y_{t-1}$，假定序列在没有干预时服从AR(1)动态，并以$c_0 z_t$项刻画政策干预的即时影响。

• 如果没有干预（$z_t=0$），模型退化为 $y_t = a_0 + a_1 y_{t-1} + \varepsilon_t$，是一个均值为 $a_0/(1-a_1)$ 的稳定AR(1)过程。

• 干预后（$z_t=1$），$c_0$ 捕捉了政策对劫机数量的直接影响：$c_0$为负意味着政策使劫机次数立即降低，为正则表示提高。

**模型求解与长期水平变化**

为了量化干预效应，我们可以**求解**上述方程，表示出 $y_t$ 关于冲击和干预项的无限滞后表示形式。因为这是一个AR(1)过程（$|a_1|<1$保证平稳），我们可以向前迭代展开：

通过递归替换 $y_{t-1}$，得到：

$$
y_t = \frac{a_0}{1 - a_1} + c_0 \sum_{i=0}^{\infty} a_1^i  z_{t-i} + \sum_{i=0}^{\infty} a_1^i  \varepsilon_{t-i} 。
$$

上述展开由三部分组成：

• 第一项 $\frac{a_0}{1 - a_1}$ 是没有干预和无扰动时序列的**稳态均值**（漂移项贡献的长期水平）。
• 第二项表示干预哑变量对 $y_t$ 的累积影响：当前以及之前各期$z$的效应经过系数$c_0$和AR系数$a_1$的滞后传播累积到本期。由于$z_t$在1973Q1之后为1，在此之前为0，这一项会体现政策使序列水平改变的贡献。
• 第三项是误差项$\varepsilon$的影响经由AR(1)滞后传递的累积，对应序列自身的随机波动。

**长期均值的变化：** 没有干预时，系列的长期均值为 $\frac{a_0}{1 - a_1}$。当干预施行后，由于 $z_t$ 从0变为1 且持续为1，序列将收敛到新的均值。可以将上式取 $t \to \infty$ 且假定$\varepsilon$均值为0，则长期均值 $y_{\infty}$ 满足：

$$
y_{\infty} = \frac{a_0}{1 - a_1} + c_0 \sum_{i=0}^{\infty} a_1^i \cdot 1 = \frac{a_0}{1-a_1} + \frac{c_0}{1 - a_1} = \frac{a_0 + c_0}{1 - a_1}。
$$

  

可以看出，干预使序列的漂移项从 $a_0$ 变为 $a_0 + c_0$，从而将**长期均值**提高（或降低）了 $\frac{c_0}{1 - a_1}$。这个长期效应就是干预的永久影响。当 $c_0<0$ 时，新的长期均值低于原先，说明政策永久性地减少了劫机事件发生的平均水平；$c_0>0$ 则反之。这个结果直观：$c_0$ 是干预导致的瞬时变动，而 $\frac{c_0}{1 - a_1}$ 表示经过AR(1)动态放大后，干预对平稳均值的总改变量。

## 1.2 脉冲响应函数 IRF Impulse Response Analysis

>[!note] 脉冲响应函数
>即干预发生后各期对 $y$ 的影响路径。这里的“冲击”指的是干预变量$z_t$从0跳变为1的变化，相当于一次永久性的干预。
> 
> 对于任意$j \ge 0$，我们可以计算**脉冲响应**：干预在$t$期发生对未来第$j$期 ($t+j$) 的影响大小。由于模型是线性的，冲击响应等于对 $z_t$ 求偏导：
> 
> $$
> \frac{\partial y_{t+j}}{\partial z_t} = c_0  a_1^j, \qquad j = 0,1,2,\dots
> $$
> 
> 该公式表明：在干预发生的当期（$j=0$），$y_t$对$z_t$的立即反应为$c_0$（这正是回归中的$c_0$系数）。随后每一时期的影响按因子$a_1$衰减：$j=1$ 时影响为 $c_0 a_1$，$j=2$ 时为 $c_0 a_1^2$，以此类推。因为 $|a_1|<1$，干预对 $y$ 的边际影响会几何级数地减弱，但**不会消失**——这是由于$z_t$的变化是永久性的：干预实施后$z_{t+j}$在之后各期都保持1。因此，$y$ 水平永久地移至新的轨道上（相对于未干预的情形）。

那么按照这个定义,我们也可以定义**累计冲击响应函数**，表示干预发生后直到第$j$期末总的影响积累。由于干预在$t$期后一直“在位”，累计影响等于将各期的边际影响相加：

$$
I_t(j) = \sum_{i=0}^{j} \frac{\partial y_{t+i}}{\partial z_t} = c_0 [1 + a_1 + a_1^2 + \cdots + a_1^j]。
$$

这是一个**部分和**，随着$j$增大逐渐逼近$c_0/(1 - a_1)$，与前述长期效应相符。当$j \to \infty$时，$I_t(j)$的极限即为干预的长期总影响 $\frac{c_0}{1 - a_1}$。图形上看，$I_t(j)$曲线会逐渐趋于平稳，水平线对应长期效应值。

## 1.3 干预效应的识别与估计步骤

1. **样本分段检验：** 先对干预发生前和发生后的数据分别拟合合适的ARIMA模型，并比较估计的模型参数是否存在显著差异。例如，在劫机案例中，可以分别用1973年前的数据和1973年后的数据估计AR(1)模型，检查$a_1$等系数有无明显变化。这可以帮助确认干预可能影响了数据生成过程。

2. **构建全样本初始模型：** 使用包含整个样本期的所有数据，先不考虑干预项，尝试识别一个适合的ARIMA模型作为**基准模型**。比如，用1968–1978年的劫机数据拟合一个ARIMA模型（也可能需要差分使其平稳），以确保对干预效应以外的动态有正确建模。

3. **加入干预项并估计：** 在基准模型中加入干预哑变量（或相应的干预函数）$z_t$，估计**干预模型**的参数，包括$c_0$。此时检验：

• 干预系数$c_0$是否显著，显著则意味着干预有统计学上的显著影响。

• 其它模型系数在加入干预后是否依然合理。

• 干预模型的残差是否近似白噪声（无自相关）。

4. **模型诊断与比较：** 对比包含干预项的模型与不含干预项的基准模型，或者与其他可能的备选模型，使用信息准则（AIC、SBC/BIC）来评估优劣。理想情况下，含干预模型应当有更低的信息准则值、残差更随机，以及**优于**不包含干预的模型。

# 3. 自回归分布滞后ADL  Autoregressive Distributed Lag

## 3.1 ADL的定义

我们考虑如下的一般模型形式：
$$
 y_t = a_0 + A(L)y_{t-1} + C(L)z_t + B(L)\epsilon_t 
$$
 
 其中 $A(L)$、$C(L)$ 和 $B(L)$ 分别是在滞后算子 $L$ 上的多项式。更具体地：
 
 • $A(L)$ 表示 $y$ 的自回归部分，如 $A(L)y_{t-1} = a_1 y_{t-1} + a_2 y_{t-2} + \cdots + a_p y_{t-p}$（这里为了方便，$A(L)$ 不写常数1项，只表示滞后项的和）。
 
 • $C(L)$ 表示 $z$ 对 $y$ 的**传递函数**（transfer function），可写作 $C(L) = c_0 + c_1 L + c_2 L^2 + \cdots + c_r L^r$，意味着 $z_t$ 的当期值和多个滞后值共同作用于 $y_t$。
 
 • $B(L)$ 表示 $\epsilon_t$ 的移动平均(MA)部分，如 $B(L)\epsilon_t = \epsilon_t + b_1 \epsilon_{t-1} + \cdots + b_q \epsilon_{t-q}$。很多情况下我们可以假定 $B(L)=1$（即噪声项为白噪声，无MA结构），以简化分析。

>[!note] 自回归分布滞后模型
>
> **自回归分布滞后模型**（Autoregressive Distributed Lag Model, 简称 **ADL 模型**）就是干预模型的自然延伸。在 ADL 模型中，$z_t$ 可以是随机的外生变量序列.在上面的模型的基础上当我们忽略$B(L)$（设$B(L)=1$）时，就得到**自回归分布滞后（ADL）模型**：
$$y_t = a_0 + A(L)y_{t-1} + C(L) z_t + \varepsilon_t$$

• $C(L)$ 被称为**传递函数**（transfer function），因为它描述了外生变量$z_t$的变动如何通过不同滞后传递到内生变量$y_t$上。例如，如果 $C(L) = c_0 + c_1L + c_2L^2$，说明$z_t$对$y_t$有当期效应$c_0$，对下一期$y$有滞后一阶效应$c_1$，对再下一期有滞后两期效应$c_2$，以此类推。

• $C(L)$ 多项式的系数${c_i}$称为**传递函数权重**。它们刻画了$z$的一个单位变化对$y$在不同滞后期的影响强度。

• 由于$z_t$影响被分布在多个时滞上，因此此类模型也常被称为“**分布滞后模型**”。

>[!note] leading indicator
>在传递函数$C(L)$中，**$c_0$系数的重要性**值得注意：
> 
> • 如果 $c_0 \neq 0$，则$z_t$对$y_t$有**当期直接影响**。$z_t$的变动立即反映在同时期的$y_t$上。
> 
> • 如果 $c_0 = 0$，意味着**无当期效应**，$z_t$的变化不会直接影响当期$y_t$，最早的影响要经过至少1期滞后才能体现。在这种情况下，我们称$z_t$为**领先指标**（leading indicator），因为$z_t$的变化领先于$y_t$的变化。例如，如果经济指标$X$在时间上领先于$Y$，那么当前$Y$主要受之前的$X$影响，而当前$X$对当前$Y$没有直接影响。

## 3.2 ADL的模型性质

考虑一个简单情形来探究ADL模型的统计性质和如何识别滞后效应：**AR(1)过程 + 延迟$d$期的单一滞后效应**。具体模型：

$$
y_t = a_1 y_{t-1} + c_d z_{t-d} + \varepsilon_t, \tag{ADL(1, d)}
$$

其中 $z_t$ 是外生的白噪声过程（均值0，方差$\sigma_z^2$），$\varepsilon_t$是白噪声误差（与$z_t$独立），$d \ge 0$为整数，表示$z$对$y$影响的延迟长度。

这个模型意味着：$z$对$y$的**唯一影响**发生在滞后$d$期处，而且影响强度为$c_d$。例如若$d=2$，则$z_{t-2}$影响$y_t$，$z_{t-1}$和$z_t$对$y_t$无直接作用。

为了刻画$y$与$z$之间的动态相关关系，我们引入:
>[!note] 交叉相关函数(Cross-correlation function, CCF)：
> 
> $$
> \rho_{yz}(i) = \frac{\mathrm{cov}(y_t; z_{t-i})}{\sigma_y\sigma_z}
> $$
> 
> 其中$\sigma_y$和$\sigma_z$分别是$y$和$z$的标准差。$\rho_{yz}(i)$描述了$y_t$与$z$在领先/滞后$i$期时的线性相关强度。当我们绘制$\rho_{yz}(i)$随$i$变化的图（$i$可以取负值表示$y$落后于$z$的情形），就得到**交叉相关图**或**交叉相关函数图 (CCF图)**。 

对于模型ADL(1,d)，我们可以根据模型结构推导出理论上的协方差$\mathrm{cov}(y_t, z_{t-i})$。因为$z$是白噪声且独立于$y$的冲击，利用滞后运算展开$y_t$：
(使用的是:$\frac{1}{1 - a_1 L} = 1 + a_1 L + a_1^2 L^2 + a_1^3 L^3 + \cdots \quad \text{当 } |a_1| < 1$)

$$y_t = \frac{c_d z_{t-d}}{1 - a_1 L} + \frac{\varepsilon_t}{1 - a_1 L} \Rightarrow y_t = c_d[z_{t-d} + a_1 z_{t-d-1} + a_1^2 z_{t-d-2} + \cdots] + \text{其他噪声项}$$

由此可见，$y_t$涉及到$z$的滞后$d, d+1, d+2,\dots$期。进一步考虑协方差：

• 对于$i < d$：$z_{t-i}$是发生在$y_t$影响之前的$z$，$y_t$不包含如此“晚近”的$z$项（因为$y_t$最早只包括到$z_{t-d}$）。由于$z$和$\varepsilon$独立，且$z$是白噪声不自相关，可知 $\mathrm{cov}(y_t,; z_{t-i})=0$，因此$\rho_{yz}(i)=0$。换言之，在干预生效延迟$d$期之前，$y$与$z$毫无线性关联。

• 对于$i = d$：$\mathrm{cov}(y_t, z_{t-d})$ 由 $y_t$中的 $c_d z_{t-d}$ 项贡献，其协方差为 $c_d \mathrm{cov}(z_{t-d}, z_{t-d}) = c_d \sigma_z^2$。同时$y_t$中的其它项（如误差项和不同滞后的$z$）要么与$z_{t-d}$独立，要么不包含$z_{t-d}$。所以 $\mathrm{cov}(y_t, z_{t-d}) = c_d \sigma_z^2$，因而 $\rho_{yz}(d) = \frac{c_d \sigma_z^2}{\sigma_y \sigma_z}$。在数值上，如果$c_d\neq0$，我们会在滞后$d$处观察到一个显著**峰值**相关。

• 对于$i = d+1$：$y_t$包含 $c_d a_1 z_{t-d-1}$ 项，与 $z_{t-(d+1)} = z_{t-d-1}$ 完全同步。该协方差为 $c_d a_1 \sigma_z^2$。但同时$y_t$中也有 $c_d z_{t-d}$项，它与$z_{t-d-1}$不相关（因不同期的$z$不相关）。所以 $\mathrm{cov}(y_t, z_{t-d-1}) = c_d a_1 \sigma_z^2$。因此$\rho_{yz}(d+1) = \frac{c_d a_1 \sigma_z^2}{\sigma_y \sigma_z}$。

• 推广$i \ge d$：对一般 $i = d + k$（$k \ge 0$），$y_t$中与$z_{t-i}$同步的那一项是 $c_d a_1^{,k} z_{t-d-k}$（因为$y_t$包含$z_{t-d-k}$乘以$a_1^k c_d$）。于是：
$$
\mathrm{cov}(y_t, z_{t-i}) = c_d a_1^{,k} \sigma_z^2 \qquad \text{当 } i \ge d,
$$
即 $i=d+k$ 时协方差为 $c_d a_1^k \sigma_z^2$。转化为相关系数，
$$

\rho_{yz}(i) = \frac{c_d a_1^{,i-d} \sigma_z^2}{\sigma_y \sigma_z}, \qquad i \ge d。

$$

综合以上分析，可以总结ADL(1,d)模型下 $y$与$z$的交叉协方差（和相关）特征：

• **对于 $i < d$：** $E[y_t z_{t-i}] = 0$，因此 $\rho_{yz}(i) = 0$（在交叉相关图上，干预滞后之前所有点相关为零）。

• **对于 $i \ge d$：** $E[y_t z_{t-i}] = c_d a_1^{,i-d}  \sigma_z^2$。特别地，$i=d$ 时 $E[y_t z_{t-d}] = c_d \sigma_z^2$ 是第一个非零协方差；$i=d+1$ 时 $E[y_t z_{t-d-1}] = c_d a_1 \sigma_z^2$；随着滞后$i$增加，协方差按比率$a_1$几何衰减。

对应的CCF图像特征为：在滞后$d$之前相关为零，滞后$d$处出现**尖刺**（正或负，取决于$c_d$符号），随后相关系数按指数规律衰减。如果观测数据的样本交叉相关图呈现这种形状，我们可以推断$z$对$y$的主要影响开始于某个延迟$d$，并随后按AR(1)过程衰减，从而帮助我们识别$C(L)$和$A(L)$的大致形式。

## 3.3 外生输入序列存在自相关的情况

前述分析假定$z_t$是白噪声（无序列相关）的外生过程，这简化了$C(L)$的识别。然而，在现实中，外生变量$z_t$本身往往具有动态结构，而非独立同分布。例如，$z_t$可能是另一经济变量（如利率、收入等），它本身可以用AR或其它模型描述。

因此，一般的**传递函数模型**会包含对$z_t$动态的建模：

$$
\begin{aligned}
y_t &= a_0 + A(L)y_{t-1} + C(L)z_t + \varepsilon_t\\
z_t &= D(L)z_{t-1} + \varepsilon_{zt}
\end{aligned}
$$

这里 $D(L)$ 是$z_t$自身的滞后多项式，$\varepsilon_{zt}$是$z_t$过程的白噪声冲击。也就是说，我们将 $z_t$ 建模为一个ARMA过程（或近似如此）。

在这个框架下，我们可以考虑**三类脉冲响应函数**来全面理解系统动态：

1. **$z$序列自身的冲击响应：** $z_t$受到它自己的冲击$\varepsilon^z_t$时，如何通过(6)式在未来演化。这由$D(L)$决定，通常就是$z_t$的ACF/PACF性质。
2. **$y$序列自身的冲击响应：** $y_t$受到它自身的误差冲击$\varepsilon_t$时，通过(5)式$A(L)$的传递对未来$y$的影响（这类似于我们之前ARIMA模型中的IRF）。
3. **$z$序列冲击对$y$的响应：** 这是关键，我们关心外生变量的变动如何传递到内生变量。由于$z_t$本身有动态，我们需要综合(5)和(6)来分析**$z$的冲击传递到$y$**的过程。

具体来说，考虑第3种冲击：令$t$期发生$z$序列的一个冲击$\varepsilon_{zt}$（大小为1的单位冲击），并观察$y_t$随后各期的变化。因为$z_t$满足(6)，我们可以将(6)代入(5)，消除$z_t$：

$$
y_t = a_0 + A(L)y_{t-1} + \frac{C(L)}{1 - D(L)L}\varepsilon_{zt} + \varepsilon_t。
$$

## 3.4 识别与估计

上面的那个模型有识别问题,具体一点来讲,就是不能唯一确定值.

>[!quote] 不能识别的具体分析
> 回到前面简单的例子，如果我们不知道结构，只凭数据去拟合模型：
> 
> $$
> 
> y_t = a_1 y_{t-1} + c_1 z_t + \epsilon_t, \qquad
> 
> z_t = d_1 z_{t-1} + \epsilon^z_t,
> 
> $$
> 
> 我们发现观测到的 $y_t$ 实际满足：
> 
> $$
> 
> y_t = a_1 y_{t-1} + c_1(d_1 z_{t-1} + \epsilon^z_t) + \epsilon_t = a_1 y_{t-1} + c_1 d_1 z_{t-1} + c_1 \epsilon^z_t + \epsilon_t,.
> 
> $$
> 
> 那么关于 $z$ 的影响项，我们既可以将其解释为“$z_t$ 对 $y_t$ 有当期影响 $c_1$，同时 $z_{t-1}$ 对 $y_t$ 有影响 $c_1 d_1$”（对应于原结构参数），也可以等价地解释为“$z_t$ 对 $y_t$ 没有直接影响（$c_1=0$），而是 $z_{t-1}$ 对 $y_t$ 有影响 $c_1 d_1$”（把 $c_1 d_1$ 看作新的滞后影响系数）。这就导致了**传递函数 $C(L)$ 无法唯一确定**：数据上看，你很难区分是 $c_1$ 作用于当期，还是 $c_1 d_1$ 作用于滞后一期，因为两种解释都符合观测。这就是所谓的识别问题。

有两种方法解决:

方法1：不预设传递函数结构，直接在多元模型中确定滞后。内容略.
$$
y_t = a_0 + \sum_{i=1}^{p} a_iy_{t-i} + \sum_{i=0}^{n} c_i z_{t-i} + \epsilon_t
$$

方法2：预滤波法（预白化法）识别传递函数。 这是前面推导中启发的方法：我们先估计并得到 $z_t$ 的模型 $D(L)$，然后用 $(1 - \hat{D}(L)L)$ 滤波（预白化）$y_t$ 和 $z_t$，以去除 $z$ 的自相关结构，使之接近白噪声。具体步骤如下：

## 4.1 VAR定义

==是用来处理内生性问题的工具==
>[!note] VAR
> 考虑一个二元系统（bivariate VAR）：
> $$
> \begin{aligned}
> y_t &= b_{10} - b_{12} z_t + \gamma_{11} y_{t-1} + \gamma_{12} z_{t-1} + \varepsilon_{yt}  \\
> z_t &= b_{20} - b_{21} y_t + \gamma_{21} y_{t-1} + \gamma_{22} z_{t-1} + \varepsilon_{zt} 
> \end{aligned}
> $$
> 其中：
> - $y_t$、$z_t$：两个**内生变量**
> - $\varepsilon_{yt}$,$\varepsilon_{zt}$：白噪声扰动项
> - $b_{12}$, $b_{21}$：**即时交叉依赖**（contemporaneous interaction）
> 
> 我们将系统写成如下矩阵形式==结构VAR==：
> $$
> \begin{bmatrix} 1 & b_{12} \\ b_{21} & 1 \end{bmatrix} \begin{bmatrix} y_t \\ z_t \end{bmatrix} \begin{bmatrix} b_{10} \\ b_{20} \end{bmatrix} + \begin{bmatrix} \gamma_{11} & \gamma_{12} \\ \gamma_{21} & \gamma_{22} \end{bmatrix} \begin{bmatrix} y_{t-1} \\ z_{t-1} \end{bmatrix} + \begin{bmatrix} \varepsilon_{yt} \\ \varepsilon_{zt} \end{bmatrix}
> $$
> 记作：
> $$B x_t = \Gamma_0 + \Gamma_1 x_{t-1} + \varepsilon_t$$
> 我们乘以 $B^{-1}$,==这个叫做同期变换,该是白噪声还是白噪声,不影响的==，得到==简约VAR==：
> $$x_t = A_0 + A_1 x_{t-1} + e_t $$
> 其中：
> - $A_0 = B^{-1} \Gamma_0$
> - $A_1 = B^{-1} \Gamma_1$
> - $e_t = B^{-1} \varepsilon_t$ 

==简约VAR中的$e_{t}$依旧是白噪声,并且消除了内生性.那就意味着可以直接用OLS估计.但是扰动项出现了同期相关==

由于$\text{Cov}(e_{1t}, e_{2t}) = \mathbb{E}[e_{1t} e_{2t}] = \mathbb{E} \left[ \frac{(\varepsilon_{yt} - b_{12} \varepsilon_{zt})(\varepsilon_{zt} - b_{21} \varepsilon_{yt})} {(1 - b_{12}b_{21})^2} \right]$
展开乘法期望后，注意 $\varepsilon_{yt}, \varepsilon_{zt}$ 是**独立白噪声** ⇒ 所有交叉项消掉，只剩下：$\text{Cov}(e_{1t}, e_{2t}) = \frac{ - b_{21} \sigma_y^2 + b_{12} \sigma_z^2 } {(1 - b_{12}b_{21})^2}$.

>[!note] ##  **方差-协方差矩阵** $\Sigma = \mathbb{E}[e_t e_t’]$
> 
> $\Sigma = \begin{bmatrix} \text{Var}(e_{1t}) & \text{Cov}(e_{1t}, e_{2t}) \\ \text{Cov}(e_{1t}, e_{2t}) & \text{Var}(e_{2t}) \end{bmatrix}$
> 

## 4.2 VAR稳定性和平稳性

使用迭代法得到:$x_t = \left( I + A_1 + A_1^2 + \dots + A_1^n \right) A_0 + \sum_{i=0}^n A_1^i e_{t-i} + A_1^{n+1} x_{t-n-1}$.

>[!note] VAR的稳定性
>要让 VAR 模型在长期不爆炸（即收敛），我们要求：
> 
> $\boxed{ \lim_{n \to \infty} A_1^n = 0 } \Rightarrow \text{所有特征值（eigenvalues）都在单位圆内}$
> 
> 对二维 VAR，稳定性等价于这个多项式的根都在单位圆外：
> 
> $I - A_1 L = \begin{bmatrix} 1 - a_{11}L & -a_{12}L \\ -a_{21}L & 1 - a_{22}L \end{bmatrix}$
> 
> 求其行列式：
> 
> $\det(I - A_1 L) = (1 - a_{11}L)(1 - a_{22}L) - a_{12}a_{21}L^2$
> 
> 如果这个方程的根（特征根）都小于 1 ⇒ 模型稳定。

==在VAR中,如果稳定,就一定弱平稳==

当$n \to \infty$，如果$A_1^{n+1} \to 0$（这正是$A_1$特征值小于1的要求），则无穷求和收敛，我们得到：

$$

\mathbf{x}_t = \mu + \sum_{i=0}^{\infty} A_1^i, e_{t-i}，

$$

其中 $\displaystyle \mu = (I - A_1)^{-1} A_0$ 是VAR过程的**无条件均值**（平稳均值）。换句话说，在稳定条件下，VAR模型是**协方差平稳过程**，其均值为$\mu$，方差有限且时间不变，并且可以表示为白噪声$e_t$的无限响应之和。

>[!note] 协方差矩阵（Wold 表达式）：
> 
> $x_t = \mu + \sum_{i=0}^\infty A_1^i e_{t-i}$
> 那么：
> $\begin{aligned} \text{Cov}(x_t) &= \mathbb{E}[(x_t - \mu)(x_t - \mu)’] = \sum_{i=0}^{\infty} A_1^i \Sigma (A_1^i)’ \\ &= \boxed{ (I - A_1)^{-1} \Sigma [(I - A_1)^{-1}]’ } \end{aligned}$
> 这里 $\Sigma = \text{Cov}(e_t)$，即 reduced form 误差的协方差矩阵。

# 断点1

**第5讲：多方程时间序列模型**
  
**VAR模型的估计**

  

标准形式的VAR模型没有当期相互作用项，因而不存在内生性问题，可以采用逐方程OLS估计各个方程的参数。这等价于多元OLS，因为每个方程都有相同的解释变量集（都包括所有变量的滞后），故OLS对每个方程的估计实际上也是整个系统的最大似然估计（在误差正态假定下）。

  

**参数数量：** VAR模型的一个现实挑战在于参数数目众多。例如，一个包含$n$个变量、滞后阶数为$p$的VAR，**每个方程**有 $np + 1$ 个系数（$p$阶每个变量各有一个系数，共$n p$，再加一个常数项），整个系统有 $n(np+1) = np^2 + n$ 个参数需要估计。随着$n$和$p$增加，参数规模呈平方增长，样本容量可能难以支撑，导致估计不精确。

  

**策略：** Sims（1980）的主张是尽量包含可能相关的变量，并选取足够的滞后，以充分捕捉变量间的相互影响。虽然这会带来很多不显著的系数，但**宁滥勿缺**：宁可过度参数化也不要一开始就施加零限制，因为任意的限制可能错过真正的重要动态关系。如果有大量不显著系数，可以通过统计检验或信息准则做适当简化，但起点通常是先估计完整VAR。

  

**优点：** VAR模型非常适合**预测**。由于它不需要结构性假定，只需根据历史数据拟合，就可以用于多步预测。实践证明，在宏观经济预测中，适当调整后的VAR往往能取得较好的预测性能。

  

**VAR模型的识别问题**

  

尽管VAR的估计相对简单，我们面临一个新的问题：从估计得到的简约形式$(A_0, A_1, \Sigma)$，我们能否**恢复原本的结构模型**（即$B, \Gamma_0, \Gamma_1$等）？一般地，**无法唯一确定**，除非我们对结构形式施加额外限制。

  

回顾之前二维VAR(1)结构模型有10个原始参数：$b_{10}, b_{20}, b_{12}, b_{21}, \gamma_{11}, \gamma_{12}, \gamma_{21}, \gamma_{22}$以及两个结构冲击标准差（或方差）$\sigma_y, \sigma_z$。而简约VAR估计提供的信息有：6个$A$系数（$a_{10}, a_{20}$和$A_1$的4个元素）以及3个协方差矩阵元素（$\mathrm{Var}(e_{1t}),\mathrm{Var}(e_{2t}),\mathrm{Cov}(e_{1t},e_{2t})$）。总共9个独立信息。但原始结构参数有10个未知数，因此**欠识别（欠识别）**：方程少于未知数。

  

这一现象可以用计量经济学经典的识别概念解释：

• **未辨识(Under-identified)：** 自由参数比独立方程多，无穷多组解满足条件。比如 $x + y = 0$ 只有一条方程，对$(x,y)$有无穷多个解（$y=-x$）。

• **正辨识(Exactly identified)：** 方程数恰好等于未知数数，可以求出唯一解。比如两条线性独立方程 $x+y=0$, $2x+y=2$ 求出唯一解 $x=2, y=-2$。

• **过度辨识(Over-identified)：** 方程数多于未知数数，通常无解，需用最小二乘或GMM寻找近似解。例如 $x+y=0,,2x+2y=0,,2x+y=2$ 三条方程对两个未知数无严格解，只能最小化误差。

  

在VAR识别中，如果我们希望识别唯一的结构模型，需要对结构模型施加足够多的**约束**，使得未知参数数目等于可独立求解的方程数。在二维VAR(1)的例子中，我们需要至少1个额外限制条件。

  

**Sims (1980)方案 – 递归识别:**

  

Sims提出的一个自然方案是**递归结构**（Cholesky分解思想）：假设结构同时关系是三角形式。例如，在二维情况下，强制 $b_{21} = 0$，即第二个方程（$z_t$方程）中不含$y_t$的当期项。这意味着我们假定**$y_t$对当期$z_t$没有直接影响**，或者说第二个变量（$z$）对第一变量（$y$）**具有当期影响优先权**。这样的假设在有些经济情景可以自洽（比如认为某一变量调整更慢当期不受另一变量当期冲击）。

  

在$b_{21}=0$限制下，我们的结构模型变为：

  

$$

\begin{cases}

y_t = b_{10} + b_{12} z_t + \gamma_{11} y_{t-1} + \gamma_{12} z_{t-1} + \varepsilon^y_t, \

z_t = b_{20} ;; + \gamma_{21} y_{t-1} + \gamma_{22} z_{t-1} + \varepsilon^z_t.

\end{cases}

$$

  

这样**原始结构参数数降为9个**（因为$b_{21}$被设为0）。而简约形式提供9个信息，因此可以完全识别。

  

实际上，可以通过匹配简约形式方程系数和误差协方差来解出这些参数：

• 由简约VAR系数和结构系数的关系：

$$

\begin{aligned}

a_{10} &= b_{10} + b_{12} b_{20},\

a_{11} &= \gamma_{11}, \

a_{12} &= \gamma_{12} - b_{12}\gamma_{22},\

a_{20} &= b_{20}, \

a_{21} &= \gamma_{21}, \

a_{22} &= \gamma_{22},

\end{aligned}

$$

可以逐步解出 $b_{20}=a_{20}, \gamma_{21}=a_{21}, \gamma_{22}=a_{22}, \gamma_{11}=a_{11}, b_{12}$ 等参数（略去具体推导）。尤其重要的是，$b_{12}$可以从协方差矩阵求得：

• 通过结构误差与简约误差的关系：

$$

\begin{cases}

e_{1t} = \varepsilon^y_t - b_{12}\varepsilon^z_t,\

e_{2t} = \varepsilon^z_t,

\end{cases}

$$

可知 $e_{2t}$就是$\varepsilon^z_t$本身，故 $\mathrm{Var}(e_{2t}) = \sigma_z^2$。而 $e_{1t} = \varepsilon^y_t - b_{12}\varepsilon^z_t$，因此：

$$

\mathrm{Var}(e_{1t}) = \sigma_y^2 + b_{12}^2 \sigma_z^2,

$$

$$

\mathrm{Cov}(e_{1t}, e_{2t}) = -b_{12}\sigma_z^2。

$$

由估计的$\Sigma$矩阵我们知道$\mathrm{Var}(e_{1t}), \mathrm{Var}(e_{2t}), \mathrm{Cov}(e_{1t}, e_{2t})$这三者的数值。将上面三式联立，我们可以解得：

• $\sigma_z^2 = \mathrm{Var}(e_{2t})$；

• $b_{12} = -,\frac{\mathrm{Cov}(e_{1t}, e_{2t})}{\sigma_z^2}$；

• $\sigma_y^2 = \mathrm{Var}(e_{1t}) - b_{12}^2 \sigma_z^2$。

这样结构冲击方差和$b_{12}$都能确定。

  

以上方法实质上对误差协方差矩阵$\Sigma$做了**Cholesky分解**：将$\Sigma$分解为$PP’$形式，其中$P$是下三角矩阵，$P = \begin{pmatrix} \sigma_{y} & 0 \ b_{12}\sigma_{z} & \sigma_{z} \end{pmatrix}$。这个$P$矩阵就是$B^{-1}$，对应$b_{21}=0$的结构。递归假定一般需要对变量排序，使前面的变量方程不包含后面变量的当期值，从而施加$n(n-1)/2$个零限制（对于$n$维系统）。在二维例子中$n(n-1)/2 = 1$，正好$b_{21}=0$。

  

**含义：** 这种递归识别假设**变量的一个先后顺序**。在我们的例子中，假设$y$当期受到$z$冲击的影响，但$z$当期不受$y$冲击影响（因为$y$在第二方程中不出现）。根据不同问题，这可能对应某种经济逻辑，例如假设第二个变量（如货币供应）政策执行很快不会被当季产出影响，但产出当季会受货币冲击。

  

**脉冲响应函数 (IRF) 在 VAR 中的应用**

  

拿到识别后的结构模型，我们就可以更有意义地分析**冲击响应**。虽然简约VAR可以直接生成自身的冲击响应（即$e_t$冲击的响应），但由于$e_t$成分相关且非结构意义，不方便解释经济含义。因此我们倾向于分析**结构冲击**（如$\varepsilon^y_t, \varepsilon^z_t$）对变量的动态影响，需要利用识别得到的关系。

  

在平稳VAR模型中，我们有简约形式的VMA表示：

  

$$

\mathbf{x}_t = \mu + \sum_{i=0}^{\infty} \Phi(i),e_{t-i},

$$

  

其中$\Phi(0) = I$（冲击对自身的即时影响矩阵即单位阵），$\Phi(1)=A_1, \Phi(2)=A_1^2$, … 一般$\Phi(i) = A_1^i$。**但是**，$e_{t-i}$并非结构冲击。如果想用结构冲击表示，可以利用 $e_t = B^{-1}\varepsilon_t$，也即 $\varepsilon_t = B e_t$。代入上式：

  

$$

\mathbf{x}_t = \mu + \sum_{i=0}^{\infty} \Phi(i), B^{-1}, \varepsilon_{t-i}。

$$

  

定义 $\Psi(i) = \Phi(i),B^{-1} = A_1^i B^{-1}$，则：

  

$$

\mathbf{x}_t = \mu + \sum_{i=0}^{\infty} \Psi(i),\varepsilon_{t-i}，

$$

  

这就是使用**结构冲击**的VMA表示。矩阵$\Psi(i)$的元素 $\psi_{jk}(i)$ 就表示**第$k$个结构冲击在滞后$i$期对第$j$个变量的影响**。这组${\psi_{jk}(i)}$就是VAR的**冲击响应函数**(Impulse Response Functions)。对于二维例子：

• $\psi_{11}(i)$：$y$对自身冲击$\varepsilon^y$在$i$期后的响应，

• $\psi_{12}(i)$：$y$对$z$的冲击$\varepsilon^z$在$i$期后的响应，

• $\psi_{21}(i)$：$z$对$y$冲击在$i$期后的响应，

• $\psi_{22}(i)$：$z$对自身冲击在$i$期后的响应。

  

特别地，$\Psi(0) = B^{-1}$，其元素$\psi_{jk}(0)$被称为**冲击乘数**或**即刻影响系数**：$\psi_{jk}(0)$表示第$k$个冲击对第$j$个变量的当期影响（$i=0$即时刻）。

  

**分析冲击响应的意义：** IRF让我们可以“隔离”每一个结构冲击对系统演变的影响路径。例如，在一个经济VAR模型里，我们可以看**货币政策冲击**对GDP和价格的反应轨迹，或者**油价冲击**对通胀和产出的影响。这些函数经常以图形方式展示，横轴是时间滞后，纵轴是冲击造成的偏离（通常以单位冲击导致变量变化的单位来衡量）。

  

**识别对IRF的影响：** 上述过程强调了一点：**必须识别结构冲击才能解释IRF**。不同的识别方案（即不同的$B$矩阵假设）会导致不同的$\Psi(i)$。例如，在递归方案下我们得到一种IRF次序，如果换另一种（如$b_{12}=0$而$b_{21}$自由），IRF将不同。这会影响对经济问题的解释。例如，在旅游业和恐怖袭击的VAR中，如果我们假设“恐怖袭击对当期旅游没有直接影响”，那$B$矩阵就是另一种三角形式，得到的IRF解释就相反。通常没有先验哪种更正确，所以**IRF存在识别不唯一的问题**。学者在报告VAR结果时，会注明冲击的识别假设（如“基于Cholesky排序IRF”）。

  

Sims本人提出VAR是为了避免“随意的限制”，但做IRF分析时我们又不得不施加某种限制来分解冲击，这似乎与初衷矛盾。这正是VAR方法的一个争议点：**VAR建模简单，但冲击分析需要结构信息**，否则只能分析“混合冲击”（$e_t$）的效果而无清晰含义。

  

**冲击响应的区间估计**

  

IRF本质上是由VAR参数计算而来，因此它也存在统计不确定性（估计误差）。我们需要为IRF提供**置信区间**或标准误差，才能判断冲击效果是否显著以及显著性随滞后如何变化。

  

**Delta方法近似：** 假设我们有一个VAR(1)模型 $y_t = \alpha + \beta y_{t-1} + \varepsilon_t$，估计得到系数$\hat\beta$，标准误差$s.e.(\hat\beta)$. 则IRF为 $\phi(i) = \beta^i$，其估计为 $\hat\phi(i) = \hat\beta^i$。

• 例如估计$\hat\beta = 0.6$，标准误约0.15。那么$\hat\phi(1)=0.6$，$\hat\phi(2)=0.36$, $\hat\phi(3)=0.216$等。

• 由于$\hat\phi(i)$是$\hat\beta$的函数，我们可以用Delta方法近似其方差。Delta方法：若 $\sqrt{T}(\hat\beta - \beta) \xrightarrow{d} N(0, \sigma^2)$，则对于平滑函数$g(\beta)$，

$$

\sqrt{T}(g(\hat\beta) - g(\beta)) \xrightarrow{d} N(0, [g’(\beta)]^2 \sigma^2).

$$

在这里 $g(x) = x^i$，所以 $g’(\beta) = i \beta^{,i-1}$。

• 因此 $\mathrm{Var}(\hat\phi(i)) \approx [i \beta^{,i-1}]^2 \mathrm{Var}(\hat\beta)$。带入$\hat\beta$近似$\beta$，计算各期置信区间。例如：

• $i=1$时 $g’(0.6) = 1 \cdot (0.6)^0 = 1$，故$\hat\phi(1)=0.6$的标准误约$0.15$，95%置信区间约 $0.6 \pm 1.96*0.15 = [0.31,;0.89]$。

• $i=2$时 $g’(0.6) = 2 \cdot 0.6^{1} = 1.2$，标准误约 $1.2 \times 0.15 = 0.18$，$\hat\phi(2)=0.36$的95%区间约 $0.36 \pm 1.96*0.18 = [0.01,;0.71]$。

• 可以看到随$i$增加，不确定性在扩大（区间变宽），因为IRF涉及幂函数，对参数误差较敏感。

• 需要注意的是，**当模型阶数较高时**，$\phi(i)$是多参数的复杂函数（例如AR(p)的IRF要用多项式求特征根再计算），Delta方法推导复杂且近似精度可能不高。

  

**Bootstrap法：** 由于IRF对系数是非线性映射，使用非参数Bootstrap更直接有效：

1. 用原始样本估计VAR模型，保存估计的系数${\hat A_i}$和残差${ \hat e_t }$。

2. **残差重抽样：** 从估计的残差序列${ \hat e_t }$中有放回地随机抽取，与原始$X$初值结合，生成一个**模拟样本**序列${ x_t^* }$：即 $x_t^* = \hat A_0 + \hat A_1 x_{t-1}^* + \cdots + \hat A_p x_{t-p}^* + e_t^_$，其中每期$e_t^_$从${\hat e_t}$中随机选取（或者对VAR情况，可以抽取整段向量残差）。

3. 对模拟样本估计VAR，得到一组新的系数${\hat A_i^_}$，从而计算一条新的IRF曲线$\phi^__k(i)$（对于每种冲击$k$）。

4. 重复步骤2-3共$B$次（例如$B=1000$次），将得到$B$组IRF模拟轨迹。

5. 对于每个滞后$i$和每种冲击$k$，取这$B$个$\phi^*_k(i)$值的2.5%和97.5%分位数，形成95%置信区间。

  

这种Bootstrap法可适用于更复杂的VAR且不依赖正态性假设。其思想是通过模拟反复逼近IRF的分布。对于VAR，也可以在抽取残差时考虑维持残差协方差结构的方法（如同时抽取多个变量残差的块）以更好地反映相关性。

  

**结论：** 给IRF提供置信区间能让我们判断哪些响应显著异于零。例如，如果某冲击对某变量的IRF在大部分滞后期零线之外，则说明冲击的影响统计上显著。如果零线始终在置信区间内，则认为冲击没有显著影响该变量。

  

**预测误差方差分解**

  

除了直接观察IRF，VAR模型还有一个常用工具来**量化变量之间的相对影响**：**预测误差方差分解** (Forecast Error Variance Decomposition, FEVD)，简称**方差分解**。

  

**定义：** 考虑对序列$\mathbf{x}_t$进行$n$步预测：$\hat{\mathbf{x}}_{t+n|t} = E[\mathbf{x}_{t+n} | \mathcal{F}_t]$，其中$\mathcal{F}_t$是$t$时刻的信息集（包含所有变量直到$t$）。VAR模型提供了一个递推预测公式：

• 一步预测：$E[\mathbf{x}_{t+1}|\mathcal{F}_t] = A_0 + A_1 \mathbf{x}_t$。

• 多步预测可以通过不断代入得到：$E[\mathbf{x}_{t+n}|\mathcal{F}_t] = A_0 + A_1 E[\mathbf{x}_{t+n-1}|\mathcal{F}_t] + \cdots + A_1^{n-1} E[\mathbf{x}_{t+1}|\mathcal{F}_t] + A_1^n \mathbf{x}_t$。

  

利用矩阵等比求和公式，上式可简化为：

  

$$

E[\mathbf{x}_{t+n}|\mathcal{F}_t] = \Big(I + A_1 + \cdots + A_1^{n-1}\Big)A_0 + A_1^n, \mathbf{x}_t。

$$

  

**预测误差**即实际值减去预测值：$\mathbf{u}_{t+n} = \mathbf{x}_{t+n} - E[\mathbf{x}_{t+n}|\mathcal{F}t]$。利用VAR动态，可将这一误差表示成未来冲击的组合：

$$
\begin{aligned}
\mathbf{u}{t+n} &= \mathbf{x}_{t+n} - \Big(\sum_{i=0}^{n-1}A_1^i\Big)A_0 - A_1^n \mathbf{x}_t \
&= e_{t+n} + A_1 e_{t+n-1} + \cdots + A_1^{,n-1} e_{t+1}
\end{aligned}
$$

  

也就是预测误差等于从$t+1$到$t+n$这$n$期发生的VAR冲击，经VAR系统传递后累积的结果。进一步用结构冲击表示：

$$

\mathbf{u}_{t+n} = \sum_{i=0}^{n-1} A_1^i e_{t+n-i} = \sum_{i=0}^{n-1} A_1^i B^{-1} \varepsilon_{t+n-i} = \sum_{i=0}^{n-1} \Psi(i), \varepsilon_{t+n-i}。

$$

  

因此预测误差中包含了各个结构冲击在这$n$步内的影响。**预测误差方差**则可写为：

$$

\mathrm{Var}(\mathbf{u}_{t+n}) = \sum_{i=0}^{n-1} \Psi(i) ,\Omega, [\Psi(i)]’,

$$

  

其中$\Omega = \mathrm{Var}(\varepsilon_t)$是结构冲击协方差矩阵（通常假定$\Omega=I$或对冲击正交化处理）。由于不同期的$\varepsilon$不相关，交叉项不出现。

  

方差分解关注单个变量。例如，对第一个变量$y_t$的$n$步预测误差，其方差由各冲击贡献可分解为：

• 来自$y$自身冲击的部分，

• 来自$z$冲击的部分，

• 以及若更多变量类似。

  

具体地，对于$y$分量，第1行方差为：

$$
\mathrm{Var}(u^y_{t+n}) = \sigma_y^2 \sum_{i=0}^{n-1} [\psi_{11}(i)]^2 + \sigma_z^2 \sum_{i=0}^{n-1} [\psi_{12}(i)]^2 + \cdots
$$

  

其中$\psi_{1k}(i)$是$\Psi(i)$矩阵的第(1,k)元素，对应第$k$个冲击对$y$在$i$期的影响。上式表明：$y$的$n$步预测误差方差等于 $y$冲击在各期造成的方差贡献之和（第一项）加上 $z$冲击造成的贡献之和（第二项），若有更多变量则继续加。将其中某一项除以总方差就得到**比例**。

  

因此，我们定义**方差分解比例**：如$\theta_{y\leftarrow z}(n) = \frac{\sigma_z^2 \sum_{i=0}^{n-1} [\psi_{12}(i)]^2}{\mathrm{Var}(u^y_{t+n})}$，表示在$n$期预测误差中，有多大比例的方差归因于来自$z$的冲击。类似$\theta_{y\leftarrow y}(n)$表示$y$自身冲击贡献的比例，两者相加为1（两变量情况）。

  

**经济解读：** 方差分解回答的是：“在$n$期预测范围内，影响$y$变量波动的不确定性来源中，有多少%来自它自身的冲击？有多少%可归因于其它变量的冲击？” 如果发现$\theta_{y\leftarrow z}(n)$较大，说明$z$的创新对预测$y$有相当作用——换言之，$z$的波动在相当程度上解释了$y$的未来波动。这通常印证了一种因果影响。

  

**注意：** 进行方差分解分析时，我们需要**结构冲击已正交化**（通常假定结构冲击互不相关且方差标准化为1）。若直接用简约VAR残差（通常相关）做方差分解，会出现相互贡献无法明确的情况。所以方差分解和IRF一样，需要先识别$B$矩阵以正交化冲击。所幸，一旦IRF确定，按上式计算方差分解很直接。

  

**格兰杰因果检验**

  

VAR模型提供了一个天然框架来检验**Granger因果关系**。**Granger因果**（又译“格兰杰致因”）严格定义为：在满足平稳性的前提下，如果在包含过去所有变量信息的条件下，加入变量$X$过去的信息能够提高对$Y$未来的预测，则称$X$ Granger导致 $Y$。反之，如果剔除$X$不会损失对$Y$的预测能力，则$X$不 Granger致因 $Y$。

  

形式化定义：$X$不格兰杰致因$Y$当且仅当对于任意将来集合$A$：

$$
P(Y_{t+1} \in A \mid \mathcal{F}_t) = P(Y_{t+1} \in A \mid \mathcal{F}_t^{-X})
$$
_其中$\mathcal{F}t$是包含$X$的历史信息${X{t-i},Y_{t-i},\dots}$的信息集，而$\mathcal{F}_t^{-X}$是不包含$X$历史的信息集。如果两者预测分布无差别，则$X$对$Y$没有格兰杰因果影响。

  

在VAR模型中，这一定义有了方便的线性检验条件。对于二维VAR($p$)：

$$

\begin{cases}

y_t = a_{10} + \sum_{i=1}^p a_{1i} y_{t-i} + \sum_{i=1}^p a_{1,i+p} z_{t-i} + e_{1t},\

z_t = a_{20} + \sum_{i=1}^p a_{2i} y_{t-i} + \sum_{i=1}^p a_{2,i+p} z_{t-i} + e_{2t},

\end{cases}

$$

  

其中$a_{2,1\dots p}$是一阶到$p$阶的$y$滞后对$z$方程的系数。如果$y$不 Granger 导致 $z$，理论上应有 $a_{21}=a_{22}=\cdots=a_{2p}=0$，即$z$方程中不出现$y$滞后（或者出现但系数全部为0）。因此，检验$y$是否Granger致因$z$可以通过线性假设检验：

$$

H_0: a_{21} = a_{22} = \cdots = a_{2p} = 0,

$$

对比备择$H_1$其中至少有一个不为0。

  

实际操作中，我们可以用F检验或似然比检验(LR test)来检验该组零限制。若拒绝$H_0$，则认为$y$格兰杰导致$z$。类似地，检验$z$是否致因$y$对应$y$方程中$z$滞后系数的联合显著性。

  

**注意**：Granger因果不代表真正经济因果，只是预测意义上的。一种变量Granger导致另一种，意味着在统计预测上前者含有后者未来的信息。要推断真正因果关系，还需理论支持和其它检验（例如控制混杂因素）。

  

**结构化VAR (SVAR)**

  

正如前面所述，VAR模型的一个弱点是缺乏结构含义——模型本身并未嵌入经济理论，只是在数据上捕捉相关。因此在解释冲击时需要人为假定识别。**结构化VAR**(Structural VAR, SVAR)是在VAR基础上引入额外的经济结构限制，以识别**结构性冲击**并赋予经济含义的一类模型。

  

**Sims (1980) VAR 方法的优点：**

1. 对所有变量平等对待，不预先划定谁是外生或内生，避免了偏颇。

2. 不需要对同时关系做过多主观假设，因此避免了经典宏观计量模型中被诟病的“难以令人信服的识别限制”。

3. 模型形式简单，易于用于**预测**，实践中VAR常取得不错的预测效果。

  

**VAR方法的缺陷：**

1. 当我们需要解释VAR结果时，比如分析一个冲击的影响路径，必须重新引入某些结构假设来识别冲击，否则冲击项本身是混杂的。这种分析的美感在一定程度上被削弱，因为不同识别方案可能导致不同结论。

2. VAR模型本身缺乏理论内容，仅仅是统计关联。因而批评者认为它**“没有经济含义”**，比如VAR冲击往往是统计残差，对应的经济含义不明确（除非我们人为赋予，比如称第一个冲击为“供给冲击”、第二个为“需求冲击”，这需要结构假定）。

  

为克服这些缺点，**结构化VAR**试图将一些**经济理论**融入VAR的识别过程中。方法上，就是对结构形式$B$矩阵施加一定的限制，使其**刚好识别或过度识别**，然后估计这一结构模型（通常采用似然估计）。这些限制可以来自：

• Cholesky递归（即某种变量排序假定），这是最简单的SVAR实现，但如前所述缺乏理论基础，仅仅是一种计算方便的标尺。

• **即时因果顺序假定：** 研究者根据理论判断哪些变量的当期反应是有限的。Cholesky是假定一个递阶的零限制，更一般地，可以设置$B$矩阵中若干元素为0或其它值，使其合计达到$n(n-1)/2$个独立限制。例如三变量的系统需要3个限制，研究者可以据理论指定比如“货币政策冲击不直接影响当季GDP和价格”（两个0限制），以及“供给冲击不直接影响当季货币量”（一个0限制），如此就可以识别结构冲击。

• **长期限制：** Blanchard和Quah（1989）等提出，可以对冲击对变量的长期影响施加约束（例如要求某冲击对GDP的长期影响为0，则意味着冲击是纯周期性的不会改变趋势水平）。通过限制IRF的极限值等，也可以达到识别目的。

• **信号限制：** 近年流行的方法，对冲击响应的方向、形状施加不严的限制。如“技术冲击应使劳动生产率在一段时期内上升”，或者“货币政策紧缩应导致通胀下降”。这种不需要精确数值，只需约束正负或大小顺序的识别，称为**符号限制**(Sign Restrictions)，由例如 Uhlig (2005) 等发展 。

• **代理变量法：** 利用额外的外生信息（如政策利率高频波动、新闻文本等）作为冲击的仪器，来帮助识别。这称为**代理SVAR**或**外生冲击SVAR**，Caldara和Herbst (2019) 对此有研究 。



无论采用何种方式，本质都是**提供足够的有效限制**来识别结构冲击。识别后的VAR，我们便称为结构VAR，可以进行有经济含义的冲击分析和政策模拟。需要强调：**识别所需的是限制的数量而非类型**——只要独立限制数达到，就能解出结构参数。理论可以告诉我们应该用何种限制，但在计量上并不区分你用的是零限制、长期限制还是其他，只要数量够，模型就是可识别甚至过度识别（过度识别时可通过检验评估限制的合理性）。

  

现代的结构VAR应用很广泛，上述提及的符号限制SVAR、代理SVAR等都是热门方向。例如，Antolín-Díaz 和 Rubio-Ramírez (2018) 利用叙事资料对SVAR冲击加符号约束 ；Mian等(2017)使用跨国数据构建SVAR研究债务和经济波动 。这些拓展使VAR分析更贴近政策和理论需求。

  

**总结与结论**

• **干预分析**：提供了一种评估**特定政策或事件**影响时间序列的方法。通过在模型中加入干预变量（如哑变量），我们能够定量检验干预是否显著改变了序列的均值水平或动态结构，并计算其短期冲击和长期效应。

• **传递函数分析**：当干预序列本身是随机过程时（即外生变量非固定0/1，而是一般时间序列），可以采用**传递函数或ADL模型**。这类模型用滞后分布描述外生变量对内生变量的影响路径。如果外生变量有自身动态，需要联合建模。传递函数模型通过交叉相关等工具可以识别滞后效应结构，但其局限在于通常假定无反馈、参数较多。

• **VAR模型**：由Sims(1980)提出，**向量自回归**模型是多元时间序列分析的重要工具。VAR对所有变量对称处理，用各自的滞后解释自身，从而捕捉变量间的内在互动而不需预先的因果顺序假定。VAR易于估计和预测，但简约形式下冲击没有直接经济意义。

• **结构VAR**：为赋予VAR经济解释，需要对简约模型施加识别限制。递归（Cholesky）分解是一种简单方式，但更一般的结构VAR会利用经济理论（如当期零限制、长期约束、符号约束、外生事件等）来识别**结构冲击**。结构VAR综合了理论和数据，在政策分析中极为有用。冲击响应函数(IRF)和预测误差方差分解(FEVD)是VAR分析的核心工具：前者描绘冲击影响随时间的传播路径，后者量化各冲击对变量波动的相对贡献。

总之，多元时间序列模型拓展了单变量分析的范围，使我们能够分析**变量之间的动态关系和相互影响**。通过干预分析可以衡量政策的效果，通过ADL模型可以刻画外生变量的传导效应，而VAR模型及其结构化拓展则为我们提供了发现经济变量内在联系、检验因果关系和进行情景模拟的一套强大框架。掌握这些方法，对于深入理解经济系统运行和评估政策冲击具有重要意义。

**VAR 分析**

  

**VAR 模型简介**

  

**模型设定：** 考虑一个简单的双变量VAR系统，包括内生变量 $y_t$ 和 $z_t$。最一般的一阶 VAR 模型（每个变量滞后一阶）可以用如下的联立方程表示：

  

$$

\begin{aligned}

y_t &= b_{10} ;-; b_{12},z_t ;+; \gamma_{11},y_{t-1} + \gamma_{12},z_{t-1} + \epsilon_{y,t}, \tag{7}\[6pt]

z_t &= b_{20} ;-; b_{21},y_t ;+; \gamma_{21},y_{t-1} + \gamma_{22},z_{t-1} + \epsilon_{z,t}, \tag{8}

\end{aligned}

$$

  

其中 $b_{10}, b_{20}$ 是常数项，$\gamma_{11},\gamma_{12},\gamma_{21},\gamma_{22}$ 是滞后系数。假设 $y_t$ 和 $z_t$ 均为平稳序列，$\epsilon_{y,t}$ 和 $\epsilon_{z,t}$ 是零均值的白噪声过程，标准差分别为 $\sigma_y$ 和 $\sigma_z$，并且假定 ${\epsilon_{y,t}}$ 和 ${\epsilon_{z,t}}$ 相互独立（即协方差为0）。

  

这个系统事实上是一个简化的同时方程模型：注意在方程(7)的右侧含有当期的 $z_t$，在方程(8)的右侧含有当期的 $y_t$。也就是说，$y_t$ 和 $z_t$ **同时**出现在对方的方程中，表示它们在同一期内互相影响。这一特征也带来了估计上的挑战：如果我们直接对每个方程用普通最小二乘（OLS）估计，估计量将是不一致的。这是因为，在(7)式中，$z_t$ 与 $\epsilon_{y,t}$ 显然相关（由于$z_t$本身由(8)决定，包含$\epsilon_{z,t}$，而$\epsilon_{z,t}$虽然独立于$\epsilon_{y,t}$，但$z_t$也受$y_t$影响而$y_t$的误差$\epsilon_{y,t}$会通过联立关系影响$z_t$）；同理，在(8)式中，$y_t$ 与 $\epsilon_{z,t}$相关。这种相互关系导致所谓**内生性**问题，直接用 OLS 分别估计将会产生有偏、不一致的系数估计。

  

**化为标准 VAR：** 为了解决同时性导致的内生性问题，我们可以将上述联立方程组整理为**矩阵形式**，将当期变量都移到等式左侧：

  

**$$**

**\begin{pmatrix}1 & -,b_{12}\[6pt] -,b_{21} & 1\end{pmatrix}**

**\begin{pmatrix}y_t\[6pt] z_t\end{pmatrix}**

  

\begin{pmatrix}b_{10}\[6pt] b_{20}\end{pmatrix}

+

\begin{pmatrix}\gamma_{11} & \gamma_{12}\[6pt] \gamma_{21} & \gamma_{22}\end{pmatrix}

\begin{pmatrix}y_{t-1}\[6pt] z_{t-1}\end{pmatrix}

+

\begin{pmatrix}\epsilon_{y,t}\[6pt] \epsilon_{z,t}\end{pmatrix}.

$$

  

写成简洁的矩阵符号，即：

  

$$

B,x_t = \Gamma_0 + \Gamma_1,x_{t-1} + \epsilon_t,

$$

  

其中

$$

B = \begin{pmatrix}1 & -,b_{12}\ -,b_{21} & 1\end{pmatrix}, \qquad

x_t = \begin{pmatrix}y_t\ z_t\end{pmatrix}, \qquad

\Gamma_0 = \begin{pmatrix}b_{10}\ b_{20}\end{pmatrix}, \qquad

\Gamma_1 = \begin{pmatrix}\gamma_{11} & \gamma_{12}\ \gamma_{21} & \gamma_{22}\end{pmatrix}, \qquad

\epsilon_t = \begin{pmatrix}\epsilon_{y,t}\ \epsilon_{z,t}\end{pmatrix}.

$$

  

矩阵 $B$ 包含了联立方程中的当期系数（在本例中对角为1，非对角为$-b_{12},-b_{21}$）。如果矩阵 $B$ 是非奇异的（其行列式 $|B| = 1 - b_{12}b_{21} \neq 0$），我们就可以左乘 $B^{-1}$，将上述方程化简为：

  

$$

x_t = A_0 + A_1,x_{t-1} + e_t, \tag{9}

$$

  

其中

$$A_0 = B^{-1}\Gamma_0,\qquad A_1 = B^{-1}\Gamma_1,\qquad e_t = B^{-1}\epsilon_t.$$

  

化简后的 (9) 式就是标准形式的 VAR(1) 模型：$x_t$ 关于自身滞后 $x_{t-1}$ 的向量自回归，其中 **右侧不再有当期的交叉项**（$y_t$ 方程右侧无 $z_t$，$z_t$ 方程右侧无 $y_t$），内生性问题因此消除。对于具体元素形式，(9)式对应的两个标量方程为：

  

$$

\begin{aligned}

y_t &= a_{10} + a_{11} y_{t-1} + a_{12} z_{t-1} + e_{1,t},\[6pt]

z_t &= a_{20} + a_{21} y_{t-1} + a_{22} z_{t-1} + e_{2,t},

\end{aligned}

$$

  

其中 $e_{1,t}, e_{2,t}$ 是变换后的误差项。

  

**注：** 完成这个变换的关键在于将**结构形式** (7)-(8) 转换为**降低形式** (9)，这样每个方程的右侧只包含滞后项，没有当期的内生解释变量，从而避免了内生性。对于本例，我们从结构VAR（包含 $b_{12}, b_{21}$ 的联立形式）转为减少式VAR（标准VAR形式）。这个转换相当于找到合适的工具变量或采用类似二阶段最小二乘的方法解决了同时性问题，但用矩阵表示更加简洁。

  

**关于误差项：** 变换后的误差 $e_t = B^{-1}\epsilon_t$ 仍然是白噪声过程，只是因为 $B^{-1}$ 对原误差的线性组合引入了相关性，其两个分量之间一般不再独立。利用上面的 $B^{-1}$，我们可以明确地写出：

  

$$

\begin{aligned}

e_{1,t} &= \frac{1}{,1 - b_{12}b_{21},}\Big(\epsilon_{y,t} - b_{12},\epsilon_{z,t}\Big),\[6pt]

e_{2,t} &= \frac{1}{,1 - b_{12}b_{21},}\Big(\epsilon_{z,t} - b_{21},\epsilon_{y,t}\Big).

\end{aligned}

$$

  

由于 $E(\epsilon_{y,t}\epsilon_{z,t})=0$（原误差独立），我们可以计算新的误差项的方差和协方差：

• $\displaystyle \operatorname{Var}(e_{1,t}) = \frac{1}{(1 - b_{12}b_{21})^2}E\big[(\epsilon_{y,t} - b_{12}\epsilon_{z,t})^2\big] = \frac{\sigma_y^2 + b_{12}^2 \sigma_z^2}{(1 - b_{12}b_{21})^2}$,

• $\displaystyle \operatorname{Var}(e_{2,t}) = \frac{\sigma_z^2 + b_{21}^2 \sigma_y^2}{(1 - b_{12}b_{21})^2}$,

• $\displaystyle \operatorname{Cov}(e_{1,t},,e_{2,t}) = \frac{-,b_{12}\sigma_z^2 - b_{21}\sigma_y^2}{(1 - b_{12}b_{21})^2}$.

  

特别地，当 $b_{12}$ 和 $b_{21}$ 都不为0时，$e_{1,t}$ 和 $e_{2,t}$ 之间的协方差不为零，即新误差项相关。我们可以将新的误差协方差矩阵记为：

  

$$

\Sigma = E(e_t e_t’) =

\begin{pmatrix}\operatorname{Var}(e_{1,t}) & \operatorname{Cov}(e_{1,t}, e_{2,t})\

\operatorname{Cov}(e_{1,t}, e_{2,t}) & \operatorname{Var}(e_{2,t})\end{pmatrix},.

$$

  

如果代入上面的计算结果，$\Sigma$ 的非对角元素一般不为零。这个结果也符合直觉：原结构模型中 $\epsilon_{y,t}$ 和 $\epsilon_{z,t}$ 虽独立，但在减少式中，我们往往无法将两者对应的一阶冲击彻底区分开，故减少式误差带有相关性。

  

**平稳性与稳定性：** 对于标准形式的 VAR，我们可以分析其平稳条件和性质。以 (9) 式为基础，向前迭代 $n$ 步，我们有：

  

$$

x_t = A_0 + A_1 x_{t-1} + e_t,

$$

  

代入 $x_{t-1}$ 得 $x_t = A_0 + A_1(A_0 + A_1 x_{t-2} + e_{t-1}) + e_t = (I + A_1)A_0 + A_1^2 x_{t-2} + A_1 e_{t-1} + e_t$。继续迭代 $n$ 次，可以得到：

  

$$

x_t = \Big(I + A_1 + A_1^2 + \cdots + A_1^n\Big) A_0 ;+; \sum_{i=0}^{n} A_1^i, e_{t-i} ;+; A_1^{,n+1}, x_{t-n-1},.

$$

  

当 $n \to \infty$ 时，如果 $A_1^{,n+1} \to 0$（即 $A_1$ 的高幂趋于零矩阵），则上述展开中最后一项消失，我们得到序列的无限移动平均表示。这导致**稳定性**与**平稳性**条件：VAR 模型稳定的充要条件是矩阵 $A_1$ 的**特征值**绝对值都小于1。这等价于要求特征多项式 $\det(I - A_1 z) = 0$ 的根都在单位圆之外。在本例的2元情况下，特征多项式可以表示为 $(1 - a_{11}z)(1 - a_{22}z) - a_{12}a_{21}z^2 = 0$，要求其根均满足 $|z|>1$。当这一稳定性条件满足时，如果忽略初始条件影响，$x_t$ 将是**协方差平稳**的。

  

当VAR稳定平稳时，我们可以将 $n \to \infty$，得到：

  

$$

x_t = \mu + \sum_{i=0}^{\infty} A_1^i, e_{t-i}, \tag{10}

$$

  

其中 $\displaystyle \mu = (I - A_1)^{-1} A_0$ 是序列的无条件均值向量。类似地，我们可以计算平稳分布下 $x_t$ 的协方差。利用 (10) 式，将 $x_t - \mu$ 表示为无限阶 MA 形式，并利用白噪声 $e_t$ 的协方差矩阵 $\Sigma$，有：

  

$$

\begin{aligned}

\operatorname{Var}(x_t) &= E\Big[(x_t - \mu)(x_t - \mu)’\Big]

= E\Big[\sum_{i=0}^{\infty} A_1^i e_{t-i} ;\Big(\sum_{j=0}^{\infty} A_1^j e_{t-j}\Big)’\Big] \[6pt]

&= \sum_{i=0}^{\infty} \sum_{j=0}^{\infty} A_1^i, E(e_{t-i} e_{t-j}’), (A_1^j)’

= \sum_{i=0}^{\infty} A_1^i, \Sigma, (A_1^i)’ ,.

\end{aligned}

$$

  

因为 $e_{t-i}$ 与 $e_{t-j}$ 独立（$i\neq j$ 时协方差为0），上述双重求和中只有 $i=j$ 的项起作用，简化得 $\sum_{i=0}^{\infty} A_1^i \Sigma (A_1^i)’$。这是一个李雅普诺夫方程的解，其闭式解可以写为：

  

$$

\operatorname{Var}(x_t) = (I - A_1)^{-1},\Sigma, \big[(I - A_1)^{-1}\big]’,.

$$

  

对于2元VAR，这相当于求矩阵$(I - A_1)$的逆，再乘以$\Sigma$和其转置逆。总之，在稳定条件下，我们能够求得平稳分布的均值和协方差。

  

**估计：** 标准形式的 VAR 模型 (9) 不存在右侧当期内生变量，因此不存在同时方程的内生性问题，我们可以对每个方程直接应用 OLS 进行估计。事实上，在(VAR)模型中，每个方程都有相同的一组右侧解释变量（都是 $x_{t-1}$ 的各分量），因此可以逐方程分开估计且不会损失效率（当误差 $e_t$ 存在相关时，用似然估计和逐方程OLS是等价的，因为右侧变量相同且协方差结构相同）。对于一个包含 $n$ 个变量、滞后阶为 $p$ 的 VAR(p) 模型来说，每个方程需要估计 $n p$ 个滞后系数加1个常数，总参数数为 $n + n^2 p$。例如，在2变量1滞后的例子中，参数总数为 $2 + 2^2*1 = 6$（对应$a_{10}, a_{20}, a_{11}, a_{12}, a_{21}, a_{22}$六个参数）。

  

显然，随着 $n$ 和 $p$ 增加，参数数量会迅速上升，这可能导致某些系数估计不精确（大样本方差大）。不过，Sims 倡导VAR的初衷之一就是尽量不对模型做先验限制，而让数据自己揭示变量关系。因此VAR模型往往是“参数冗余”的（over-parameterized）：许多系数估计可能不显著，但这样做可以确保我们不遗漏潜在的重要关系。**宁可冗余，不可遗漏**，因为如果在没有充分理由的情况下对模型加约束（例如强制某些滞后系数为0），可能会丢失变量间的重要信息。实际应用中，我们通常根据信息准则（如 AIC、BIC）选择 VAR 模型的滞后长度 $p$，同时纳入经济直觉决定纳入哪些变量 $n$。在估计得到模型后，VAR 模型可用于多步预测（由于形式和 AR 类似，可以递归地进行滚动预测）。

  

**识别问题：** 完成 VAR 模型估计后，一个进一步的问题是：我们能否从减少式的 VAR 模型(9)重新推导出原始的结构方程(7)和(8)？换言之，我们能否通过估计出的 $A_0, A_1$ 以及误差协方差 $\Sigma$ 来识别结构模型中 $B, \Gamma_0, \Gamma_1$ 等原始参数？

  

一般而言，在没有额外信息的情况下，答案是否定的。**欠识别：** 以2元1滞后的情形为例，我们通过估计(9)可以得到 6 个系数估计值（$a_{10}, a_{20}, a_{11}, a_{12}, a_{21}, a_{22}$）以及误差协方差矩阵中的3个独立元素（$var(e_{1}), var(e_{2}), cov(e_1,e_2)$）。总共可识别 9 个组合量。而结构模型(7)-(8)包含 10 个原始参数（$b_{10}, b_{20}, b_{12}, b_{21}, \gamma_{11}, \gamma_{12}, \gamma_{21}, \gamma_{22}$ 共8个，以及 $\sigma_y^2, \sigma_z^2$ 两个原始误差方差）。显然方程数量小于未知数数量——缺少一个等式，因此**原始结构是未辨识的**，即存在无穷多组结构参数可以产生相同的减少式。

  

这一点可以用简单的线性代数类比说明**识别的概念**：

• **欠识别（自由度过多）**：例如解方程组 $x + y = 0$。未知数两个，方程一个，因此有无穷多解（$y=-x$）。结构模型参数多于我们能从减少式获取的信息，自然无法唯一确定。

• **刚好识别**：例如方程组 $\begin{cases}x + y = 0,\ 2x + y = 2.\end{cases}$ 两个未知两方程，有唯一解 $x=2, y=-2$。刚好识别意味着可根据数据唯一解出结构参数。

• **过度识别（方程过多）**：例如方程组 $\begin{cases}x + y = 0,\ 2x + y = 2,\ 3x + 4y = 4.\end{cases}$ 理论上如果三方程无矛盾就会没有解（一致性条件不满足），实际经济模型中过度识别通常意味着有多余的约束，对应的估计需要用广义矩（GMM）或极大似然等方法来在误差意义下“折中”满足所有约束。

  

在VAR情形下，我们处于**欠识别**状态，因为减少式提供的信息不足以倒推结构。要想从中识别原始的结构参数，**除非我们对结构模型施加额外的限制**，即利用经济理论或其他信息增加一些方程，使问题达到（或超过）刚好识别的程度。

  

**结构VAR的识别：递归法 (Cholesky分解)**

  

Sims (1980) 提出了一个简单可行的识别策略，被称为**递归结构**假定，即通过**变量排序**来实现识别。在二元例子中，这相当于对矩阵 $B$ 施加一个约束：假定 $b_{21} = 0$ 或 $b_{12} = 0$ 二者择一。两者分别对应两种变量排序。为了便于说明，我们采用 Sims 原始例子，假设 **$b_{21}=0$**。这意味着在结构方程(8)中，$z_t$ 方程右边不含 $y_t$ 项，也就是**$y_t$ 的当期变化不会对当期 $z_t$ 产生直接影响**；换言之，在同一期内，$z$ 被视为“先行”的变量，$y$ 则“后反应”。（这样的假定在一些场景有自然解释，例如假设“当季的经济活动冲击不会立即影响当季的货币供给”，或“恐怖事件对当月旅游业没有直接当月影响”等。）

  

在 $b_{21}=0$ 的约束下，我们的结构矩阵 $B$ 简化为上三角矩阵 $\begin{pmatrix}1 & -,b_{12}\[4pt]0 & 1\end{pmatrix}$。此时：

• 结构方程(7)变为 $y_t = b_{10} - b_{12} z_t + \gamma_{11}y_{t-1} + \gamma_{12}z_{t-1} + \epsilon_{y,t}$（不变）。

• 结构方程(8)变为 $z_t = b_{20} + \gamma_{21}y_{t-1} + \gamma_{22}z_{t-1} + \epsilon_{z,t}$（因为 $-b_{21}y_t$ 项消失）。

  

对于新的结构误差与减少式误差的关系，我们现在有：

$$

\begin{aligned}

e_{1,t} &= \epsilon_{y,t} - b_{12},\epsilon_{z,t},\tag{11}\[6pt]

e_{2,t} &= \epsilon_{z,t},\tag{12}

\end{aligned}

$$

（因为此时 $1 - b_{12}b_{21}=1$）。因此新的误差统计特性为：

• $\operatorname{Var}(e_{2,t}) = \operatorname{Var}(\epsilon_{z,t}) = \sigma_z^2$，

• $\operatorname{Cov}(e_{1,t}, e_{2,t}) = \operatorname{Cov}(\epsilon_{y,t} - b_{12}\epsilon_{z,t}, \epsilon_{z,t}) = -,b_{12},\sigma_z^2$，

• $\operatorname{Var}(e_{1,t}) = \operatorname{Var}(\epsilon_{y,t} - b_{12}\epsilon_{z,t}) = \sigma_y^2 + b_{12}^2 \sigma_z^2$（此时$e_{1,t}$和$e_{2,t}$独立性已打破，但仍可通过这三个矩求解）。

  

现在我们有了 3 个方程（关于 $var(e_1), var(e_2), cov(e_1,e_2)$）来求解 3 个未知数 $b_{12}, \sigma_y^2, \sigma_z^2$：

• 由 $var(e_{2,t}) = \sigma_z^2$，直接得到 $\sigma_z^2 = var(e_{2,t})$（这在估计VAR后是已知量）；

• 由 $cov(e_{1,t}, e_{2,t}) = -b_{12} \sigma_z^2$，代入已知 $\sigma_z^2$，可解出 $b_{12} = -,\frac{cov(e_1,e_2)}{\sigma_z^2}$；

• 然后由 $var(e_{1,t}) = \sigma_y^2 + b_{12}^2 \sigma_z^2$，代入 $\sigma_z^2$ 和求得的 $b_{12}$，解出 $\sigma_y^2$。

  

这样，结构模型中 $b_{12}$ 以及误差方差 $\sigma_y^2,\sigma_z^2$ 都可以识别了。

  

接下来，我们还可以利用减少式和结构式系数的关系来识别滞后项参数。由之前比较 (13) 式和 (9) 式可得（写出那些关系式）：

  

$$

\begin{aligned}

a_{10} &= b_{10} - b_{12},b_{20},\[6pt]

a_{11} &= \gamma_{11} - b_{12},\gamma_{21},\[6pt]

a_{12} &= \gamma_{12} - b_{12},\gamma_{22},\[6pt]

a_{20} &= b_{20},\[6pt]

a_{21} &= \gamma_{21},\[6pt]

a_{22} &= \gamma_{22}.

\end{aligned}

$$

  

这些关系大部分是一一对应的，因此利用减少式中估计得到的 $a_{ij}$ 以及刚才求出的 $b_{12}, b_{20}$ 等，我们可以解出所有的结构参数：

• 直接从 $a_{20}$ 得到 $b_{20} = a_{20}$；

• 将 $b_{12}, b_{20}$ 代入 $a_{10}$ 的公式解出 $b_{10} = a_{10} + b_{12} b_{20}$；

• 由 $a_{21} = \gamma_{21}$ 得 $\gamma_{21}=a_{21}$，由 $a_{22}=\gamma_{22}$ 得 $\gamma_{22}=a_{22}$；

• 利用 $a_{11} = \gamma_{11} - b_{12} \gamma_{21}$ 解出 $\gamma_{11} = a_{11} + b_{12} \gamma_{21}$；

• 利用 $a_{12} = \gamma_{12} - b_{12} \gamma_{22}$ 解出 $\gamma_{12} = a_{12} + b_{12} \gamma_{22}$。

  

这样，原始结构模型(7)-(8)中的所有系数 $b_{10}, b_{20}, b_{12}, \gamma_{11}, \gamma_{12}, \gamma_{21}, \gamma_{22}$ 也全部识别出来了。我们通过给 $B$ 矩阵添加了 $b_{21}=0$ 这一条约束，使得原本欠识别的系统刚好识别。有趣的是，这种识别方法在数学上等价于对白噪声协方差矩阵 $\Sigma$ 做 **Cholesky 分解**（Cholesky decomposition）：对一个正定矩阵进行下三角和上三角分解会产生 $n(n-1)/2$ 个零限制（对于2元情形就是1个零，上述$b_{21}=0$），从而实现刚好识别。Cholesky 分解在VAR分析中广泛用来得到一种基于递归排序的结构冲击识别方法。

  

**脉冲响应函数的计算与解释**

  

一旦VAR模型估计完成且我们选择了一种识别方案（例如上述递归法确定了 $B$），我们就可以分析系统中各个结构性冲击对变量的动态影响，即**脉冲响应函数 (Impulse Response Function, IRF)**。根据之前推导，平稳VAR可以改写为**向量移动平均 (VMA) 表示**。对于减少式(10)我们已有 $x_t = \mu + \sum_{i=0}^\infty A_1^i e_{t-i}$，如果进一步将 $e_{t-i}$ 用原始结构冲击 $\epsilon_{t-i}$ 表示（$e_t = B^{-1}\epsilon_t$），则：

  

$$

x_t = \mu + \sum_{i=0}^{\infty} A_1^i B^{-1}, \epsilon_{t-i},.

$$

  

我们可以定义 $\Phi(i) = A_1^i B^{-1}$ 为冲击响应系数矩阵，那么：

  

$$

x_t = \mu + \sum_{i=0}^{\infty} \Phi(i), \epsilon_{t-i},. \tag{14}

$$

  

这里，$\epsilon_{t} = (\epsilon_{y,t}, \epsilon_{z,t})’$ 表示原始结构模型中的两类**结构性冲击**（如 $\epsilon_{y,t}$ 可理解为影响 $y$ 的“$y$-冲击”，$\epsilon_{z,t}$ 为影响 $z$ 的“$z$-冲击”）。式(14)表明，当前的状态 $x_t$ 可以表示成过去各期结构冲击经过传递后累积的结果，其中 $\Phi(i)$ 是冲击传递的脉冲响应矩阵，其元素 $\phi_{jk}(i)$ 表示第 $k$ 个结构冲击发生后第 $i$ 期对第 $j$ 个变量的影响（冲击-响应）。

  

**冲击的即时影响（乘数）：** 在 $\Phi(0) = B^{-1}$ 矩阵中，$\phi_{jk}(0)$ 代表冲击 $k$ 对变量 $j$ 的**当期（即时）影响**，通常称为**影响乘数**(impact multiplier)。对于我们的二元例子，$\phi_{11}(0)$ 是单位 $y$-冲击对 $y$ 当期的影响，$\phi_{12}(0)$ 是单位 $z$-冲击对 $y$ 当期的影响，$\phi_{21}(0)$ 是单位 $y$-冲击对 $z$ 当期的影响，$\phi_{22}(0)$ 是单位 $z$-冲击对 $z$ 当期的影响。根据我们的识别假定$b_{21}=0$，可知 $B^{-1} = \begin{pmatrix}1 & b_{12}\0 & 1\end{pmatrix}/(1)$，因此 $\phi_{21}(0) = -b_{21}/(1-b_{12}b_{21}) = 0$，这就体现了我们假定的冲击排序：$y$ 的冲击当期对 $z$ 无影响，而 $z$ 的冲击当期对 $y$ 有影响 $-b_{12}$。

  

**脉冲响应函数：** 对于任意 $i\ge0$，矩阵 $\Phi(i)$ 的各元素 $\phi_{jk}(i)$ 就是通常所说的脉冲响应函数：即假定在 $t$ 时刻对第 $k$ 个变量施加一个单位冲击（$\epsilon_{k,t}=1$，其他冲击为0），则第 $j$ 个变量在未来第 $i$ 期（也就是 $t+i$ 时刻）相对于基准的变化为 $\phi_{jk}(i)$。将 $i$ 从0绘制到若干期，就得到一条冲击-响应路径，形象地描述这一冲击的动态影响过程。

  

**示例解释：** 在我们的例子中，有四种可能的冲击-变量组合的 IRF：

• ${\phi_{11}(i)}_{i\ge0}$：$y$ 受到自身冲击后的响应（$y$ 对 $y$ 的IRF）；

• ${\phi_{12}(i)}_{i\ge0}$：$y$ 受到 $z$ 冲击后的响应；

• ${\phi_{21}(i)}_{i\ge0}$：$z$ 受到 $y$ 冲击后的响应；

• ${\phi_{22}(i)}_{i\ge0}$：$z$ 受到自身冲击后的响应。

  

在递归排序假定下，$\phi_{21}(0)=0$，意味着 $y$ 的冲击不会立刻影响 $z$，而 $\phi_{12}(0) \neq 0$，意味着 $z$ 的冲击会立刻影响 $y$。不同的冲击分解方式会改变这些即时关系，但总体上，IRF 提供了一个对于每种冲击的传导机制的全貌。

  

**多重分解的任意性（备注2 & 3）：** 值得注意的是，要想得到结构冲击的脉冲响应，必须先对减少式VAR进行**识别**（例如我们用了Cholesky分解假定 $b_{21}=0$）。然而，识别并不唯一。上面的识别假定等价于一种**冲击排序**（shock ordering）：我们假定冲击 $\epsilon_{y}$ “排在第一位”，$\epsilon_{z}$“排在第二位”（因为 $z$ 冲击可以即时影响 $y$，而 $y$ 冲击当期对 $z$ 无影响）。如果我们采取另一种排序，例如**假定 $b_{12}=0$ 而 $b_{21}\neq0$**（意味着当期$y$不受$z$冲击，但$z$受$y$冲击），那么冲击的即时影响关系就相反，得到的脉冲响应函数也会不同。在有些情形下，我们可以根据理论对冲击排序作出选择：例如在旅游和恐怖袭击的例子中，也许我们有理由假定“恐怖袭击的冲击不会立即影响当月的旅游人数”，从而将旅游作为先行变量，将恐怖事件冲击放在后面。然而，更多时候，我们缺乏先验知识来确定哪种分解更合理。这时，**任意选择一种递归排序虽然提供了方便的计算途径，但冲击缺乏明确的经济含义**。这与 Sims 当初反对“难以令人信服的识别限制”的初衷相悖——如果我们又随意地给VAR加上一个结构，那么VAR的“无先验”优势会被削弱。因此，解读VAR的冲击效应时需要谨慎，通常会在不同识别假定下进行稳健性检验。

  

**脉冲响应的区间估计**

  

上面讨论了如何计算IRF，但由于IRF本质上是模型参数（如 $a_{ij}$）的函数，我们还需要评估其不确定性，即计算脉冲响应函数的置信区间。这里可以采用**Delta 方法**或**自助法（bootstrap）**。

  

**Delta 方法（Delta Method）：** 假设我们估计得到VAR模型参数的估计量 $\hat{\beta}$，且 $\sqrt{T}(\hat{\beta} - \beta) \xrightarrow{d} N(0, \sigma^2)$（大样本近似正态分布，$\sigma^2$为渐近方差）。对于某个参数的函数 $g(\beta)$，Delta方法告诉我们：

  

$$

\sqrt{T}\big(g(\hat{\beta}) - g(\beta)\big) \xrightarrow{d} N\Big(0,; [g’(\beta)]^2,\sigma^2\Big),

$$

  

其中 $g’(\beta)$ 是函数 $g$ 对参数 $\beta$ 的导数。在当前情形下，$g(x)$ 可以取为 $\phi(i)$（例如 $\phi(i) = x^i$ 的形式，对应 AR(1)过程的IRF），这样 $g’(\beta) = i,\beta^{,i-1}$。这意味着IRF在第 $i$ 期的估计量 $\hat{\phi}(i)$ 的方差可以通过已知的系数估计方差推算出来。举个具体例子：

  

假设我们估计得到一个 AR(1) 模型 $y_t = 0.6,y_{t-1} + \hat{\epsilon}_t$，估计系数 $0.6$ 的标准误约为 $0.15$（因为t值4.0，即0.6/4）。那么 $\phi(i) = 0.6^i$。当 $i=0$ 时，$\hat{\phi}(0)=1$（冲击即时影响固定为1）；当 $i=1$ 时，$\hat{\phi}(1)=0.6$，它的标准误可以近似为 $|g’(0.6)| \cdot 0.15 = |1 \cdot 0.6^0| \cdot 0.15 = 0.15$；当 $i=2$ 时，$\hat{\phi}(2)=0.36$，其标准误 $\approx |2 \cdot 0.6^1| \cdot 0.15 = 2 \cdot 0.6 \cdot 0.15 = 0.18$；依此类推，可以计算渐进置信区间。例如，$i=1$ 时 $\phi(1)$ 的95%置信区间约为 $[0.6 \pm 1.96 \times 0.15] = [0.30, 0.90]$；$i=2$ 时为 $[0.36 \pm 1.96 \times 0.18] \approx [0.01, 0.71]$。需要注意的是，随着 $i$ 增大，虽然点估计 $\phi(i)$ 趋近0，但其标准误可能并不单调减少，Delta方法估计出的区间可能会变宽（因为乘上了导数 $i \beta^{i-1}$ 的因子）。因此，教材上一些简单“形状”图示（如假定IRF按指数规律衰减到0就置信区间收敛）的直觉可能有误导，正确的方法应该基于Delta方法或更严谨的手段计算区间。

  

**注：** 当模型有多个参数（例如 AR(p) 有多个滞后系数）时，$\phi(i)$ 是多参数的复杂函数，Delta 方法计算会变得复杂且可能不够准确。此外，当模型较复杂或样本量有限时，渐近正态近似可能不佳。此时通常采用 **蒙特卡罗抽样 / Bootstrap** 方法来计算IRF的不确定性。

  

**自助法（Bootstrap）构造IRF置信区间：** Bootstrap 的思想是通过反复模拟采样来近似估计统计量的分布。针对时间序列模型，我们可采用时间序列残差重抽样的方法：

  

构造IRF的Bootstrap步骤如下（以 AR(p) 模型为例）：

1. **估计模型：** 先用原始样本估计 VAR/AR 模型，得到系数估计值 $\hat{a}_i$（$i=0,1,\dots,p$）以及保存残差序列 ${\hat{\epsilon}_t}_{t=1,\dots,T}$。

2. **生成模拟样本：** 在残差序列中采用有放回抽样，随机抽取长度为 $T$ 的残差序列 ${\hat{\epsilon}^__t}$。然后使用估计的模型系数和抽样残差，构造一个人工的时间序列 ${y^t}$：从初始值开始递推 $y^_t = \hat{a}_0 + \hat{a}_1 y^_{t-1} + \cdots + \hat{a}_p y^*_{t-p} + \hat{\epsilon}^*_t$，生成与原始序列长度相同的模拟序列。

3. **重新估计模型：** 对生成的模拟序列 ${y^__t}$ 估计同样形式的模型（AR(p)或VAR(p)），得到一组新的系数估计 ${\hat{a}_i^_}$。根据这组估计计算所需的脉冲响应函数 $\hat{\phi}^*(i)$（这相当于一次蒙特卡罗试验）。

4. **重复模拟：** 重复第2-3步 $B$次（例如 $B=1000$次），将得到$B$组脉冲响应函数模拟结果 ${\hat{\phi}^{*(b)}(i)}_{b=1,\dots,B}$。对这 $B$ 个值，从小到大排序后，取第2.5百分位和97.5百分位作为 $\phi(i)$ 的经验95%置信区间。

  

对于VAR模型，操作基本类似，不同之处在于残差为向量。在抽取时，我们一般**整块抽取**每期的残差向量$(\hat{\epsilon}_{y,t}, \hat{\epsilon}_{z,t}, \dots)$，以保持各变量残差间的相关结构（即抽样单位是一个时期的残差向量，而不是各变量分开抽）。然后用这些抽样得到的残差向量驱动估计VAR模型生成模拟序列（需给定初始的起始值，可以用原样本的前$p$期数据）。对每个模拟样本重新估计VAR并计算IRF，同样通过重复模拟获取分位数形成置信区间。

  

Bootstrap 方法不依赖大样本正态性假定，通常能更准确地反映有限样本下IRF的不确定性。实践中，报告VAR脉冲响应时常会给出bootstrap置信带以评估显著性。

  

**方差分解 (Variance Decomposition)**

  

除了脉冲响应函数之外，VAR模型分析中另一个有用的工具是**预测误差方差分解**（Forecast Error Variance Decomposition，简称方差分解）。它能够揭示VAR系统中各个**冲击**对某一变量波动的相对贡献比例。具体来说，我们关注在不同的预测期限下，一定比例的预测误差是由自身冲击引起的，多少比例由其他变量的冲击引起的。

  

考虑利用估计的 VAR 模型对序列进行 $n$ 步ahead预测。在时点 $t$，对 $t+1$ 期的最佳预测是 $E_t[x_{t+1}] = A_0 + A_1 x_t$。更一般地，对 $t+n$ 期的预测可以递推得到：

  

$$

E_t[x_{t+n}] = (I + A_1 + A_1^2 + \cdots + A_1^{,n-1}),A_0 + A_1^n, x_t,.

$$

  

因此 $n$ 步预测误差为：

  

$$

x_{t+n} - E_t[x_{t+n}] = e_{t+n} + A_1 e_{t+n-1} + \cdots + A_1^{,n-1} e_{t+1},.

$$

  

利用之前的VMA表示(14)，这个误差项可以进一步改写为结构冲击的线性组合：

  

$$

\text{预测误差}_{t,n} = \sum_{i=0}^{n-1} \Phi(i), \epsilon_{t+n-i},,

$$

  

其中 $\Phi(i) = A_1^i B^{-1}$ 为脉冲响应系数矩阵。该和式表明，$n$步预测误差是未来$n$期内发生的各结构冲击叠加产生的效果。

  

以我们关心的某一个变量（比如 $y$）为例，提取上述误差中该变量的分量。$y$的$n$步预测误差可以表示为：

  

$$

\underbrace{\phi_{11}(0)\epsilon_{y,t+n} + \phi_{11}(1)\epsilon_{y,t+n-1} + \cdots + \phi_{11}(n-1)\epsilon_{y,t+1}}_{\text{$y$自身冲击导致的部分}} ;+; \underbrace{\phi_{12}(0)\epsilon_{z,t+n} + \phi_{12}(1)\epsilon_{z,t+n-1} + \cdots + \phi_{12}(n-1)\epsilon_{z,t+1}}_{\text{$z$冲击导致的部分}} ;+; \cdots

$$

  

（如果有更多变量则继续分项）。由于不同结构冲击彼此独立，我们可以计算 $y$ 变量 $n$步预测误差的方差：

  

$$

\begin{aligned}

\sigma_y^2(n) &= \operatorname{Var}\big(y_{t+n} - E_t[y_{t+n}]\big) \[6pt]

&= \sigma_y^2\Big(\phi_{11}(0)^2 + \phi_{11}(1)^2 + \cdots + \phi_{11}(n-1)^2\Big);+; \sigma_z^2\Big(\phi_{12}(0)^2 + \phi_{12}(1)^2 + \cdots + \phi_{12}(n-1)^2\Big);+; \cdots,

\end{aligned}

$$

  

其中 $\sigma_y^2$、$\sigma_z^2$ 是 $y$ 和 $z$ 结构冲击的方差。本例中只有两个变量，上式就包含两个部分：第一项是 $y$ 冲击导致的误差方差之和，第二项是 $z$ 冲击导致的误差方差之和。我们可以定义：

• **自因方差贡献（own shock contribution）：** 例如 $y$ 冲击引起的部分占 $y$ 总预测误差方差的比例为

$$\frac{\sigma_y^2\sum_{i=0}^{n-1}\phi_{11}(i)^2}{\sigma_y^2(n)},;$$

• **跨因方差贡献（cross shock contribution）：** $z$ 冲击引起的部分占比为

$$\frac{\sigma_z^2\sum_{i=0}^{n-1}\phi_{12}(i)^2}{\sigma_y^2(n)},.$$

  

这样，方差分解告诉我们：在 $n$ 步预测范围内，$y$ 变量的波动有多少百分比归因于源自自身的冲击，有多少百分比归因于 $z$ 的冲击（以及其他变量冲击，如有）。

  

**备注：** 在实际计算方差分解时，需要用到结构冲击的方差 $\sigma_y^2, \sigma_z^2$ 以及冲击响应系数 $\phi_{jk}(i)$，这意味着**必须基于某种结构识别（如Cholesky）**。如果我们直接用减少式残差（它们是相关的）来做分解，则无法得到干净的解释。通常大家使用递归识别法先将残差正交化，然后做方差分解。在报告结果时，常根据不同预测期给出分解表格，例如1期ahead预测误差方差100%来自自身冲击，因为没有时间给其他冲击发挥影响；随着期限延长，可能逐渐有相当比例归因于其他变量的冲击，从而说明变量之间的传导重要性。

  

**VAR模型中的假设检验**

  

VAR模型的建立需要确定包含的变量数量 $n$ 以及滞后阶数 $p$。这些模型选择过程可以视为对模型限制进行假设检验或信息准则比较：

• **滞后长度选择：** 我们可以构造似然比（LR）检验来判断增加滞后是否显著改进模型拟合。例如，检验 $p=1$ 对比 $p=2$，或者检验滞后$p$是否显著；亦或者在确定变量集合 $n$ 时，检验加入某些变量是否显著降低残差方差。一般地，如果我们想检验“添加某组参数是否为0”的限制，可以用两个模型的对数似然来构造LR统计量。对于比较嵌套的两个VAR模型（如一个8变量VAR与一个包含这8变量外加额外4变量的VAR），LR统计量形式为：

$$

LR = T\Big(\ln|\Sigma_{\text{small}}| - \ln|\Sigma_{\text{large}}|\Big),,

$$

其中 $|\Sigma|$ 表示残差协方差矩阵的行列式（多元回归中对数行列式相当于对数似然的某种度量），“small”和“large”分别指小模型和大模型。该统计量在大样本下服从卡方 ($\chi^2$) 分布，其自由度等于所施加的限制数目（也就是大模型参数数减小模型参数数）。例如，若我们要检验8变量VAR是否可以扩展为12变量VAR，那么原假设 H0: “新增4个变量的影响全部为0”，对应的限制个数等于新增参数个数。

• **信息准则选择：** 除了逐对检验，我们也可以直接依据信息准则选择模型，例如AIC或BIC（SBC）。对于VAR模型，AIC和BIC通常定义为：

$$

\text{AIC} = T \ln|\Sigma| + 2N,\qquad

\text{BIC} = T \ln|\Sigma| + N \ln T,

$$

其中 $N$ 是模型中估计的参数总数（包括各方程的截距和系数），$|\Sigma|$是估计的残差协方差矩阵行列式。给定若干候选模型（不同的 $p$ 或不同的变量组合），一般选择AIC/BIC值最小的模型。

• **因果关系检验（Granger Causality）：** VAR模型提供了检验变量间**格兰杰因果关系**的便利框架。形式定义为：若包含变量 $X$ 的过去信息能够提高对变量 $Y$ 未来的预测，那么称 $X$ Granger成因于（Granger-cause） $Y$。数学表述为，对于任意事件集 $A$，

$$

P{Y_{t+1}\in A \mid \mathcal{F}_t} \neq P{Y_{t+1}\in A \mid \mathcal{F}_{-X,t}},,

$$

其中 $\mathcal{F}_t$ 表示所有变量（包括 $X$）在$t$及之前的信息集合，$\mathcal{F}_{-X,t}$ 表示排除了 $X$ 的信息集合。如果两者不相等，则说明知道 $X$ 的历史会改变 $Y$ 的预测分布，$X$ 对 $Y$ 存在格兰杰因果。反之若相等，则 $X$ 对 $Y$ 没有增益预测能力，被称为“不格兰杰成因”。

在VAR模型中，这个概念可简化为对滞后系数的检验。例如，对于二元VAR(p)，如果我们想检验“$y$ 是否格兰杰导致 $z$”，只需检验 $z_t$ 方程中 $y$ 的所有滞后系数是否同时为0。具体来说，$z_t$ 方程可表示为 $z_t = a_{20} + \sum_{i=1}^p a_{21,i} y_{t-i} + \sum_{i=1}^p a_{22,i} z_{t-i} + e_{2,t}$。$y$ 不格兰杰成因 $z$ 当且仅当 $a_{21,1} = a_{21,2} = \cdots = a_{21,p} = 0$。因此，可以通过对这些系数的联合零假设进行F检验或似然比检验来判断。如果拒绝假设，则认为 $y$ 的滞后总体上显著影响 $z$，即 $y$ 格兰杰致因 $z$；若不拒绝，则 $y$ 在有 $z$ 自身滞后作为控制后对 $z$ 没有预测力。

  

**结构性VAR模型 (Structural VAR)**

  

前文所述的Sims (1980) VAR模型有一些优点和缺点，总结如下：

  

**VAR模型的优点：**

1. 所有变量被平等对待，全部视为内生变量放在系统中，模型中没有人为指定的外生变量。这样可以全面捕捉变量之间的双向关系，避免遗漏反馈。

2. 模型建立时**不依赖**于任何“不可信的识别限制”，只需根据统计准则选定滞后阶数和变量集即可，无需对结构作过多主观假设。这使模型在数据说明力上比较“客观”。

3. VAR模型已被证明是一种**优秀的预测工具**。由于其形式灵活且参数众多，往往可以拟合复杂的动态模式，在宏观经济预测中表现良好。

  

**VAR模型的缺陷：**

1. 在分析冲击响应时，如果完全不加结构假定，冲击项 $e_t$ 彼此相关，我们难以解读其中哪一个冲击对应什么经济含义。因此必须施加一些结构性限制才能得到有意义的脉冲响应。然而一旦加了结构假定，又可能丧失VAR原本的对称之美。这种两难使得VAR在构造脉冲响应函数时其方法的“美感”有所减损。

2. 由于VAR模型在建立时几乎未引入任何经济理论约束，它纯粹从统计相关性出发，**缺乏经济内容**。因此，尽管它可以刻画变量间相互作用和预测，它很难解释冲击的本质或提供经济机制的洞见。例如，我们可以看到某冲击影响了通胀，但这个冲击究竟代表需求侧还是供给侧的因素，VAR本身无法识别。

  

为克服这些不足，引入了**结构性VAR（Structural VAR, SVAR）**的概念。结构性VAR在估计之前或之后，对VAR系统添加一些基于理论的约束，以标识具有明确经济含义的结构冲击。

  

**Cholesky分解的再讨论：** 前面我们使用 Cholesky 分解（递归排序）实现了结构识别（在二元例子中假定 $b_{21}=0$）。这是最简单的SVAR识别方法。在一般 $n$ 元VAR中，Cholesky 分解相当于假定**误差协方差矩阵 $\Sigma$ 为对角矩阵**的一个下三角乘积，将 $n(n-1)/2$ 个非对角元素都置为0。换言之，我们对 $B$ 矩阵施加 $n(n-1)/2$ 个约束，使之成为下三角矩阵。例如，如果 $n=4$，就需要施加 $4*3/2 = 6$ 个当期零限制，让第1个变量当期不受其他3个影响、第2个不受后2个影响、第3个不受第4个影响，从而刚好识别。Cholesky 分解的优点是方便，它提供了一种机械的冲击正交化方法。但它的缺点也显而易见：**强加的限制可能缺乏经济学基础，得到的冲击往往难以诠释。**就像前述例子，我们假设 $y$ 冲击不立即影响 $z$，这也许只是为了数学需要，并没有根据明确的理论。

  

**其它结构识别方法：** Sims (1986) 和 Bernanke (1986) 等人提出，可以依据经济理论来为VAR的结构冲击建模。基本思想是利用经济学模型所蕴含的约束来识别结构冲击之间的关系。我们关心的是要施加足够（数量上）的约束来识别模型，但可以选择那些更有经济意义的约束，而不一定采用Cholesky的递减排序。比如，我们可以根据经济理论指定某些长周期约束（冲击对某变量长期无影响），或约束某些冲击引起的反应符号（正或负），又或者利用自然实验等找到“代理变量冲击”（proxy shocks）等方法。不同的方法对应不同的文献流派，如**长期约束识别**（如Blanchard-Quah 1989，用单位根流程分解需求和供给冲击）、**符号约束**（Antolin-Díaz & Rubio-Ramírez 2018, 使用冲击对某些变量方向的理论预期）、**代理VAR**（使用外生信息作为冲击的替代，如Caldara & Herbst 2019）等等。

  

无论采取何种具体方法，识别的关键在于提供**足够数量**的独立约束，使得结构模型未知参数等式的数量不少于未知数。对 $n$ 元VAR，需要 $n(n-1)/2$ 个附加限制才能达到刚好识别。如果提供更多的限制，则为过度识别，可以用统计检验检验约束的一致性。结构性VAR通过引入这些限制，使VAR模型的冲击具备明确的经济含义。例如，我们可以将冲击解读为“货币政策冲击”、“需求冲击”、“供给冲击”等，而不仅仅是纯统计的$e_{1,t}, e_{2,t}, \dots$。**需要强调的是，结构识别的重点在于约束的数量足够，而具体选取哪些限制可以有多种方案。**理论上任何一组独立的 $n(n-1)/2$ 个限制都可以达成识别，但不同选择决定了冲击的经济解释力。因此，研究者应基于理论和经验判断，尽量选择那些有坚实经济基础的约束，以确保识别出的冲击和反应模式符合实际。

  

近年来，结构性VAR仍是宏观计量的重要工具，许多改进和应用不断涌现，包括使用叙事法和代理变量识别货币政策冲击、使用FAVAR（因子扩展VAR）纳入更多信息、以及时变参数的TV-VAR来捕捉结构变化等。
