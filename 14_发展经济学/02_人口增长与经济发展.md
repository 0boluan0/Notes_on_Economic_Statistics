# 2. 马尔萨斯人口陷阱

#考点 要会推导移动的过程

![[Pasted image 20250320080254.png]]
## 2.1 两个假设

1. 假设社会中,存在一个刚好可以维持个人生存的生存工资.如果一个人的工资低于生存工资.则无法生活,假设收入高于生产工资,多余的部分就会养小孩,人口就回增加
2. 收入(粮食)的多寡受到自然资源的约束.尤其是土地资源的不变,会导致投资的边际收益下降.因此收入的增长是有限的.

## 2.2 论点

人口数量几何式增长
食物供应算术级增长.

## 2.3 模型解读

在马尔萨斯模型（Malthusian Model）中，假设**技术水平**和**自然资源**相对稳定或增长缓慢，当人均收入（或人均产量）提高时，会刺激人口增长率上升；但随着人口不断增加，可用资源的人均占有量下降，又会导致人均收入回落到某个较低的水平，最终形成“陷阱”——也就是**人口增长抵消了收入增长**。

• **关键假设：**

1. 经济中的生产主要依赖有限的土地或资源；
2. 随着人口增加，人均可获得的资源减少，边际产量下降；
3. 当人均收入较高时，人口出生率上升、死亡率下降，人口增长率变高；当人均收入下降时，人口出生率下降、死亡率上升，人口增长率降低甚至为负。

• **结果：**

如果技术进步不足以抵消人口增长对资源的“稀释”效应，最终会使人均收入徘徊在维持生存的“**subsistence**（生存线）”附近，这就是“马尔萨斯陷阱”。

从图中可以看到，横轴是“人均收入”$\frac{Y}{P}$，纵轴是“增长率”（左侧的实线一般表示“人口增长率”$\frac{\Delta P}{P}$，也可能还标有“累计收入增长率”或其他曲线）。图上有若干标注点（如$B$、$C$等），以及几个不同的人均收入水平（$Y_1$, $Y_2$, $Y_3$, $Y_4$）。

1. **纵轴：人口增长率**（或出生率减去死亡率）

• 当人均收入较低时，营养、医疗等条件差，出生率可能较低、死亡率较高，所以$$ \frac{\Delta P}{P} \leq 0 $$或接近0。

• 随着人均收入上升，人们的生活条件改善，人口增长率会随之提高（出生率上升、死亡率下降），在图中呈现出先上升再下降的“倒U形”或类似曲线。

2. **横轴：人均收入**$\frac{Y}{P}$

• 从左到右表示人均收入由低到高。

• 在马尔萨斯模型中，人均收入越高，短期内会刺激更高的人口增长率，但如果人口增加过多，资源被摊薄，人均收入又会回落。

3. **倒U形曲线：人口增长率随人均收入变化的关系**

• 该曲线可能在较低收入段时增长率很低或为负；

• 在中间某点达到最大值（图中往往标注为$B$）；

• 再往右走，随着人均收入继续升高，人口增长率可能下降，出现“富裕后生育意愿反而减少”的情况（如现代一些发达经济体中出现的低生育率）。

**三、图中关键点的含义**

根据图示（可能各教材标注不同），我们常见的分析方式是：

1. **点$A$**：

• 可能是人口增长率为0的起点，表示在人均收入$\frac{Y}{P}$低于$A$时，人口无法维持再生产，增长率可能是负的（人口逐渐减少）。

• 如果在图中未标出$A$，则可能是图形最左端与坐标轴的交点，含义相似。

2. **点$B$**：

• 通常表示人口增长率的峰值（最大值）。当人均收入从$A$到$B$的过程中，人口增长率不断上升。到$B$时达最大。

• 若人均收入继续增加，人口增长率会从峰值开始回落。

3. **点$C$**：

• 在很多教材中，$C$对应一个较高的人均收入水平，此时人口增长率再次回到0或更低。

• 这意味着当人均收入足够高时，可能由于生育意愿降低（或其他社会经济因素），人口增长率开始下降甚至为负。

4. **不同人均收入水平$Y_1, Y_2, Y_3, Y_4$**：

• 图中往往用$Y_1 < Y_2 < Y_3 < Y_4$标示，代表不同的阶段性收入水平。

• 如果经济处在$Y_2$水平时，对应的人口增长率可能在$B$点附近；若经济能跳到$Y_4$，则人口增长率位于“后端”，可能较低或为负。

**直观解释：** 当人均收入由$Y_1$升到$Y_2$时，人口增长率会提高，从而带来更多的人口；但人口增加后，又会把人均收入拉回到某个较低的水平（例如回到$Y_1$附近），形成“陷阱”。只有当技术进步或制度变化足以使人均收入突破这个陷阱区间（如达到$Y_3$或更高），才有可能稳定在一个更高的人均收入与较低人口增长率的平衡状态。

**马尔萨斯陷阱的含义**

1. **自发调节**



2. **技术进步的作用**

如果出现足以抵消人口增长的技术进步，才能逐步提高人均收入，并把人口增长率控制在适度水平。否则经济可能长期停留在“低收入—高人口增长—低收入”之间的循环。

3. **现代意义**

马尔萨斯陷阱在现代发达经济体中似乎不再明显，但在一些低收入国家或历史发展阶段，确实能观察到类似特征：缺乏技术或制度变革时，收入一旦提高就被快速增长的人口所消耗。

级差地租（Differential Rent）最早由古典经济学家李嘉图（David Ricardo）提出，用于解释为什么在同一市场中，不同地块（或不同质量的资源）会产生不同的地租。其核心观点是：**地租来自于土地肥力（或资源禀赋）的差异**，市场最终由“边际地块”——即肥力最差、刚好能覆盖成本而无剩余的土地——来决定粮食（或其他农产品）的市场价格。更肥沃的土地由于生产成本更低，在相同的市场价格下就能获得超额收益，这部分超额收益便是级差地租
1. **横轴：粮食产量**（从左到右依次增大），记作$Q$。
2. **纵轴：粮食价格**（从下到上依次增大），记作$P$。
3. **两条需求曲线：$d_0$ 与 $d_1$**
	• $d_0$是初始需求曲线；
	• $d_1$是需求增长后的新需求曲线（右移或上移）。
4. **供给曲线：呈阶梯状或分段水平的“粮食供给曲线”**
	• 反映了不同等级（肥力）的土地在不同价格水平下愿意供应的粮食总量。
	• 越肥沃的土地所需的市场价格越低即可投入生产，越贫瘠的土地需要更高的市场价格才能盈利而被开垦。
5. **价格水平：$P_0$ 与 $P_1$**
	• $P_0$为初始均衡价格，对应需求曲线$d_0$；
	• $P_1$为需求增加后形成的新均衡价格，对应需求曲线$d_1$。
6. **产量水平：$Q_0$ 与 $Q_1$**
	• $Q_0$为初始均衡产量；
	• $Q_1$为需求增长后对应的均衡产量。

> 从图上可以看到：当需求从$d_0$上升到$d_1$时，均衡价格从$P_0$上升到$P_1$，产量从$Q_0$上升到$Q_1$。

供给曲线为何呈“阶梯”形

在古典级差地租理论中，假设有若干块不同肥力的土地，分别记为$L_1, L_2, L_3, \dots$，其单位产出成本从低到高排列：
$$
c_1 < c_2 < c_3 < \dots
$$
• **最好土地**（如$L_1$）成本最低，只要市场价格$P \geq c_1$，就会投入生产。
• **次好土地**（如$L_2$）需要更高的市场价格$P \geq c_2$才能盈利，否则无法投入生产。
• 依此类推，越往后的土地肥力越差，需要的价格阈值越高。

因此，当市场价格提升到某个区间时，就会把新的、较差的土地吸引进来参与生产，导致供给量出现“跳增”。从宏观角度看，粮食供给曲线就呈现出一种“阶梯”或分段的特征：
• **第一段水平**：在价格$[c_1, c_2)$之间，仅$L_1$供应粮食；
• **第二段水平**：在价格$[c_2, c_3)$之间，$L_1$和$L_2$都供应粮食；
• **……**

**从需求变动看地租如何产生**
1. **初始均衡：需求曲线$d_0$与供给曲线交于$(Q_0, P_0)$**
	• 此时，可能只有肥沃的土地（成本低于$P_0$）在生产；
	• 边际土地的成本$=P_0$，该地块获得的地租为0；
	• 肥沃土地（成本$<P_0$）则获得**级差地租**：
$$
\text{Rent}_i = P_0 - c_i,\quad c_i < P_0.
$$
2. **需求上升：需求曲线从$d_0$移至$d_1$**
	• 为满足更多需求，市场需要产出更多粮食$Q_1$，这就需要开垦新的、较差的土地；
	• 这些新土地的单位成本可能是$c_j > c_i$，最终推高均衡价格至$P_1$；
	• **结果**：
	1. **所有肥沃土地**的地租增加为：$$\text{Rent}_i’ = P_1 - c_i \quad (\text{相比原来增加 }(P_1 - P_0)).$$
	2. **刚投入生产的边际土地**成本$=c_j$满足$P_1=c_j$，其租金为0。
	3. **供给量**从$Q_0$增至$Q_1$。

因此，**级差地租**本质上是由更肥沃土地和边际土地之间的成本差异造成的，**市场价格由边际土地决定**，而肥沃土地享受“差额收益”。
