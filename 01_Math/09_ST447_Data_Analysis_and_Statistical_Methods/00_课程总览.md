## 1. Represent values

表示值

<!-- bilingual-en:start -->
Assignment gives a value a usable name. Its type determines which operations have a meaning; an atomic vector carries a common type across all its entries.
<!-- bilingual-en:end -->

赋值使值有可使用的名称；类型决定哪些操作具有意义。原子向量把共同类型延伸到全部元素。

## 2. Select and transform

选择与变换

<!-- bilingual-en:start -->
Position indices specify where to look; logical masks specify which conditions to satisfy. After selection, vector arithmetic pairs entries, so inspect the intended pairing when lengths differ.
<!-- bilingual-en:end -->

位置索引指定取值位置，逻辑掩码指定条件。选择后，向量算术按位置配对；长度不同时要明确这种配对是否符合意图。

## 3. Import and interpret columns

导入并解释列

<!-- bilingual-en:start -->
Import settings determine which fields become names and which remain data. A selected column may be numerical or categorical; preserve that meaning when changing its representation.
<!-- bilingual-en:end -->

导入设置决定哪些字段成为名称、哪些仍为数据。选出的列可能是数值，也可能是类别；改变表示方式时要保留这种含义。

## 4. Describe distributions

描述分布

<!-- bilingual-en:start -->
A categorical comparison needs a stated denominator. A numerical comparison needs suitable intervals and scales. The chart should answer the same question as the table or summary it represents.
<!-- bilingual-en:end -->

类别比较需要明确分母，数值比较需要合适的区间与尺度。图形应回答与其所表示的表格、摘要一致的问题。

![[R 列联表条件比例]]

## 5. Preserve meaning and the analysis

保留含义与分析过程

<!-- bilingual-en:start -->
When exporting, distinguish category labels from internal codes. Then keep the intended commands and their inputs so the saved work can be interpreted and rerun.
<!-- bilingual-en:end -->

导出时区分类别标签和内部编码，再保留预期命令及其输入，使保存的工作可以被解释和重跑。
