# DPDE 资料索引

DPDE 是 **Dynamic Programming and Differential Equations（动态规划与微分方程）**。2026 syllabus 将这一单元表述为 *Mathematical Methods for Macroeconomics*。

## 目标

学习求解动态问题所需的数学工具，重点放在应用和直观推导。课程覆盖增长、商业周期、货币经济学与搜寻模型中常见的动态优化和动态方程系统。

## 三次课

### Lecture 1 — Dynamic Optimisation

- 基本消费—储蓄问题
- Direct approach、Euler equation、transversality condition
- Continuous time、Hamiltonian、Maximum Principle

### Lecture 2 — Dynamic Systems

- Difference and differential equations
- States and controls、steady state、stability
- Phase diagrams、Blanchard–Kahn method、linearisation

### Lecture 3 — Dynamic Programming

- Backward induction、value function
- Bellman equation、Principle of Optimality
- HJB equation、reinforcement learning
