# Bayesian Battle of the Sexes

[[03_策略式博弈#咖啡厅还是酒吧|性别博弈（咖啡厅还是酒吧）]]

## 基本信息

Players. M.Phil. student 1, and two types of M.Phil. student 2 ($2_l$ and $2_h$). Actions. Each of the players can choose between Cafe and Pub. Payoffs. The payoffs are given in the below matrices, each of which occurs with probability $1/2$.

**Type $2_l$:**

|      | Cafe | Pub |
| --- | --- | --- |
| Cafe | $(4, 3)$ | $(1, 1)$ |
| Pub | $(0, 0)$ | $(3, 4)$ |

**Type $2_h$:**

|      | Cafe | Pub |
| --- | --- | --- |
| Cafe | $(4, 0)$ | $(1, 4)$ |
| Pub | $(0, 3)$ | $(3, 1)$ |


在性别博弈的基础上，女性被分为了两种类型，一种喜欢男性，一种厌恶男性。男性并不知道女性的类型，女性自己知道自己的类型。

## 求解纳什均衡

将两种类型的女性分开来看，认做是两种人，那么就可以写成：

Players. Three players $i \in N = \{1, 2_l, 2_h\}$. Strategies. For each $i \in N$, $s_i \in \{\text{Cafe}, \text{Pub}\}$. Write $s_1 \in \{C, P\}$ and $s_{2j} \in \{C_j, P_j\}$. Payoffs are represented in the following matrix (entries are $(u_1, u_{2_l}, u_{2_h})$):

| $s_1$ \ $s_{2_l}, s_{2_h}$ | $C_l, C_h$  | $C_l, P_h$             | $P_l, C_h$             | $P_l, P_h$  |
| -------------------------- | ----------- | ---------------------- | ---------------------- | ----------- |
| $C$                        | $(4, 3, 0)$ | $(\tfrac{5}{2}, 3, 4)$ | $(\tfrac{5}{2}, 1, 0)$ | $(1, 1, 4)$ |
| $P$                        | $(0, 0, 3)$ | $(\tfrac{3}{2}, 0, 1)$ | $(\tfrac{3}{2}, 4, 3)$ | $(3, 4, 1)$ |


特别的，由于女性知道自己的类型，所以可以根据类型来设定策略。由于男性不知道女性的类型，所以应该求解平均值。

### 纯策略的纳什均衡

由划线法可以得到纯策略的纳什均衡。纯策略的纳什均衡意味着三个人（女性看作两个人）都得到最优。

### 混合策略的纳什均衡

不要求会算，但是要求会验证。

在验证时，对男性则每个对应的期望都应算，乘 $1/2$；对女性则按原先的算法正常计算。

To check these mixed equilibria, recall the requirement for indifference.

- Consider $\{(\tfrac{1}{3}, \tfrac{2}{3}),\; P_l,\; (\tfrac{2}{3}, \tfrac{1}{3})\}$. Looking at the payoff matrix above, what is player 1’s payoff?
- From $C$, player 1 receives $\tfrac{2}{3} \times \tfrac{5}{2} + \tfrac{1}{3} \times 1 = 2$. From $P$, player 1 receives $\tfrac{2}{3} \times \tfrac{3}{2} + \tfrac{1}{3} \times 3 = 2$.
- Indifferent, and prepared to mix... what about player $2_l$?
- From $C_l$ receives $\tfrac{1}{3} \times 3 + 0 = 1$. From $P_l$ receives $\tfrac{1}{3} \times 1 + \tfrac{2}{3} \times 4 = 3$. So will choose $P_l$.
- Player $2_h$ gets $0 + \tfrac{2}{3} \times 3 = 2$ from $C_h$, and $\tfrac{1}{3} \times 4 + \tfrac{2}{3} \times 1 = 2$ from $P_h$. Indifferent, so can mix.

It is straightforward to confirm the other mixed equilibrium, and prove that there are no other equilibria, pure or mixed (left as an exercise!).

# 贝叶斯博弈

## 五元素

相较于普通的博弈的三个要素，贝叶斯博弈有五个元素，分别是：

### player

这里的这个 player 没有把不同类型的人分开，类型的分类会归后面一项来区分。

### type

同一个 player 的不同回报，每种回报认定为一个 type。

### action

每个人能够选择的行为。

特别的，对于有不同 type 的 player，不同 type 的可选范围一定要相同。如果存在不一样的可选范围，那么仅靠看对方的选择，另一方就能得到关于该方的 type 信息，违背了基本假定。

### belief

一方对另一方 type 的分布的预设，仅反映这一方的一厢情愿，不是对方的真的 type 分布情况。

### payoff

不仅与行动策略组合（strategy profile）有关，也和类型组合有关，就是题目表格里的数字。

## 将五元素转化为 3 要素

### player

新的 player 的定义从自然人扩展到了每个自然人的每个类型单算为一个 player。

### strategy

由于 player 的变化，strategy 也相应扩展为每个自然人的每个类型的策略选择。

### payoff

不变。

## 案例：noisy battle of sexes

|      | Cafe                 | Pub                         |
| ---- | -------------------- | --------------------------- |
| Cafe | $(4+\varepsilon, 3)$ | $(1+\varepsilon, 1+\delta)$ |
| Pub  | $(0, 0)$             | $(3, 4+\delta)$             |



二者都加入了一个扰动，但是二者的扰动都只有自己知道，对方只知道分布而不知道值。

- $S_1$ 的类型空间：$\varepsilon \in [0, a]$（可视作区间上的点）。
- $S_2$ 的类型空间：$\delta \in [0, a]$（可视作区间上的点）。

![[Pasted image 20240408163433.png]]

列出对 2 的收益：

- 去 Cafe 的收益：$\Pr(S_1(\varepsilon)=C)\times 3 + \Pr(S_1(\varepsilon)=P)\times 0$.
- 去 Pub 的收益：$\Pr(S_1(\varepsilon)=C)\times (1+\delta) + \Pr(S_1(\varepsilon)=P)\times (4+\delta)$.

![[Pasted image 20240408163547.png]]

==推论：对于 1 和 2 而言存在且仅存在一个临界值，在这个值的一边该 player 选某一选择，在另一边该 player 选另一个选择==

例如对 $S_1$：

$$
S_1(\varepsilon)=
\begin{cases}
\text{Pub}, & 0 \le \varepsilon < \varepsilon^*, \\
\text{Cafe}, & \varepsilon^* < \varepsilon \le a.
\end{cases}
$$

（在 $\varepsilon=\varepsilon^*$ 处无差异。）

![[Pasted image 20240408163758.png]]

由于对方知道我的分布，那么上面的收益可以写成：

- Cafe：$(1-\varepsilon^*/a)\times 3 + (\varepsilon^*/a)\times 0$.
- Pub：$(1-\varepsilon^*/a)\times (1+\delta) + (\varepsilon^*/a)\times (4+\delta)$.

两式子联立就能得出两个临界点的关系：

$$
\overline{\delta}=\overline{\varepsilon}=\frac{2a}{6+a}.
$$

纯策略的纳什均衡有两个。

# Global Game

## 分析

global game 相较于 Bayesian game，自身的扰动和对方的扰动密切相关。

- Bayesian：$\varepsilon$ 和 $\delta$ 的分布相互独立。
- Global game：二者相关。

知道了自己的也就大概知道对方的。

## eg：政府工作招标

两家公司去前期勘查，得出一项工程的大概成本，这个成本就是我的 type。当知道这个成本的时候我就知道了对方估计的成本的大概区间。

所以我的策略应给是比别人低，但只能低一丁点。

- 一级密封拍卖：所有人出价，密封到一个密封袋里，投标，价低者得。
- 二级密封拍卖：基本和一级一样，只不过最后胜者得到的是比他高一级的投标者的出价。

但是，无论是一级还是二级拍卖，获胜者一般相同，且政府的期望成本一样。

## 辨析：Global Game 和 Bayesian Game

关键在 belief：Bayesian 与自己的类型无关，Global 和自己的类型有关。

# Coordinated Attack

## 基本信息

Players. The players are two generals, labelled $i \in N = \{1, 2\}$. Strategies. For each $i \in N$, $s_i \in S_i = \{A, R\}$. Payoffs are represented in the following matrix:

|      | A | R |
| --- | --- | --- |
| A | $(v-c, v-c)$ | $(-c, 0)$ |
| R | $(0, -c)$ | $(0, 0)$ |

选择 attack 或 run，attack 相当于要花费成本，而 run 不用花费成本。

## 求解纳什均衡

### 纯策略的纳什均衡

$AA$、$RR$ 划线即可。

### 混合策略的纳什均衡

Suppose player 1 (row) plays $A$ with probability $x$. Player 2’s payoffs are:

- If player 2 plays $A$: $x(v-c) + (1-x)(-c) = xv - c$.
- If player 2 plays $R$: $0$.

Player 2 should play $A$ when $xv > c \Leftrightarrow x > c/v$.

- Mixed Nash: $x^* = c/v$ if $0 < c < v$.
- Possible equilibria: $x^* \in \{0, c/v, 1\}$.
- Multiple equilibria if $0 \le c \le v$.

![[Pasted image 20240411195529.png]]

混合策略的纳什均衡：选择进攻的概率为 $c/v$。当成本越大时越不想进攻。

## 变体：correlated types

使进攻成功的收益是固定的，为 10，而进攻的成本不确定。

现在两方都派人去打探，一般可能获得真实的 $c$ 值，一般可能性获得真实值 $\pm 1$ 的错误值。其中 $+1$、$-1$ 各占一半。一人打探为真，另一人只能打探为假。

1. One player is told $\tilde{c} = c$, the other is told either $\tilde{c} = c + 1$ or $\tilde{c} = c - 1$.
2. So one player is told the truth, whereas the other is just one step away.
3. Players do not know whether their signal is accurate or not; their types are:

$$
\tilde{c}=
\begin{cases}
 c-1 & \text{w.p. } \tfrac{1}{4}, \\
 c & \text{w.p. } \tfrac{1}{2}, \\
 c+1 & \text{w.p. } \tfrac{1}{4}.
\end{cases}
$$

### 分析

> 以我收到 5 的信号为例

分情况讨论，一种情况我收到的是真实值，另一种情况我收到的是假的值。讨论后有：无论哪种情况都是：对手 $1/2$ 取 4，对手 $1/2$ 取 6。

那么此时，由于上面分析过的，如果对手有大于 $c/v$ 的概率选择 attack，我就应该选择 attack。

### 结论

我得到的信号为 0 时，我应进攻。

我收到信号为 0，则我对信号的期望是 0，那此时我的对手的信号为 -1 或 1。当对手收到的信号是 -1，他一定会进攻，因为进攻严格占优策略。后边就不用讨论了，因为对手收到 -1 的概率是 $1/2$。即对手选择进攻的概率大于 $1/2$。

由上方的逻辑类推，如果收到的信号为 1、2、3、4，我都应该进攻。

反着推，当我收到的信号为 10 时，一定跑。

由此类推 9、8、7、6 都要跑。

5 是一个中间值，比较模糊。进攻和不进攻无差异。

==不确定性却带来了结果的确定性==

为什么会造成这样的结果？

策略有互补性，信号也有协同的机制。二者共同决定了在某些参数范围内会存在一定的确定性。
