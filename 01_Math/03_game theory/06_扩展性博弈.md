# Entry Deterrence

## 基本内容

Players. The entrant ($E$) and the incumbent ($I$). So $N=\{E, I\}$. Strategies. $E$ can choose to **Enter** or **Stay Out**. $I$ can choose **Fight** or **Truce** after entry. Payoffs (profits) and timing are represented in the game tree:

动态博弈：你能看到对方的选择后再作出选择，画出来是博弈树的形式。对 $I$ 而言，只有 $E$ 选择 Enter 后他的选择才有意义。

## 扩展性博弈

在策略式博弈的描述基础上增加 **History**，History 必须发生，但是不用走到底。

History 可分为空集、非 terminal 的 history 和 terminal。

- terminal：一个走到头的 history。
- player function：对非 terminal 的 history 定义下一步由谁行动。
- payoff：只对 terminal history 定义。只有走到最后的才能谈 payoff。
- 一个完备的 strategy，即使不会发生也要讲清楚。

对 Entry Deterrence：

- $H = \{(), (\text{Stay Out}), (\text{Enter}), (\text{Enter, Fight}), (\text{Enter, Truce})\}$
- $Z = \{(\text{Stay Out}), (\text{Enter, Fight}), (\text{Enter, Truce})\}$
- $P(())=E$ 且 $P(\text{Enter})=I$
- Payoffs defined on $Z$，例如 $u_E(\text{Stay Out})=0$ 且 $u_I(\text{Stay Out})=2$

Definition 20. The strategic-form of the extensive-form game
$G = (N, H, P, \{u_i\}_{i\in N})$ is
$\Gamma = (N, \{S_i\}_{i\in N}, \{v_i\}_{i\in N})$ where:

1. $S_i$ is the set of strategies in $G$ for $i \in N$.
2. $v_i(s) = u_i(z(s))$, where $z(\cdot)$ is the outcome, and $s \in S = \prod_{i\in N} S_i$.

Entry Deterrence 的策略式博弈（payoff 顺序为 $(E, I)$）：

| $E$ \ $I$ | Fight | Truce |
| --- | --- | --- |
| Stay Out | $(0, 2)$ | $(0, 2)$ |
| Enter | $(-1, -1)$ | $(1, 1)$ |

- Pure：$(\text{Stay Out}, \text{Fight})$ 和 $(\text{Enter}, \text{Truce})$。

# 逆向归纳  backward induction

## 思想

从后往前归纳，类似剪枝。从博弈的所有结局出发，找出此时做决定的人的最佳对策。得到该最佳决策后后退一步，继续分析上一个人的最佳决策，直到最初的位置，最终找到均衡。

==弱占优可视为 backward induction 的一种应用：在可决策节点选择对自身更优的分支；非决策节点的分支选择不影响既定路径==

### 案例信息

这是一个 centipede game。Applying backward induction，唯一能 survive 的策略组合是 $\{(\text{Stop}, \text{Stop}), (\text{Stop}, \text{Stop})\}$。

最上方的长条图是扩展性博弈的描述。只要两人有一个说 Stop 就停。

==注意：在描述 1 和 2 的策略选择时，不能只说单独一个 Stop 或 Pass，无论后面的是否发生，都应该说完。例如如果二者有任何一个人选 Stop 就结束了，但还是要说这个人的策略是 Stop, Stop 或 Stop, Pass，即便后者不可能发生。==

对最后的选择者 2，他选 Pass 得 3，选 Stop 得 4，所以选 Stop。1 推测 2 会 Stop，于是 1 也选 Stop。用这个方法往前类推，唯一的均衡只能是 1 在一开始就选 Stop。

# 信息集 information set

## 信息集概念

[博弈论](https://zh.wikipedia.org/wiki/%E5%8D%9A%E5%BC%88%E8%AE%BA "博弈论")中，**信息集**是指对于特定的参与者，建立基于其所观察到的所有博弈中可能发生的行动的集合。如果博弈是[完美信息](https://zh.wikipedia.org/wiki/%E5%AE%8C%E7%BE%8E%E4%BF%A1%E6%81%AF "完美信息")的，每个信息集只能有一个参与者，并显示博弈所处的阶段。否则，有的参与者可能不知道博弈的状态以及自己周围的形势。

# Extensive-Form Games

在原先扩展性博弈的基础上增加 nature，意为老天爷。老天爷不是人，扮演随机选择。

Definition 21. An extensive-form game consists of:

1. **Players.** A set of players with typical member $i \in N$.
2. **Histories.** A set of histories with typical member $h \in H$. $h$ is a sequence of actions by individual players. $\emptyset \in H$ is the start of the game. If $h \in H$ but there is no $(h, a) \in H$ where $a$ is an action for some player, then $h$ is terminal. Denote the set of terminal histories as $Z \subset H$.
3. **Player Function.** A function $P : H \setminus Z \to N \cup \{c\}$, assigning a player or “chance” (nature) to each non-terminal history.
4. **Nature.** For each $h \in H$ such that $P(h) = c$, $f(a\mid h)$ is the probability that $(h, a) \in H$ occurs.
5. **Information.** For each player $i \in N$ an information partition $\mathcal{I}_i$ of $\{h \in H : P(h) = i\}$. $(h, a) \in H \Leftrightarrow (h', a) \in H$ for all histories $h, h' \in H$ in the information set $I_i \in \mathcal{I}_i$.
6. **Payoffs.** vNM payoffs for each $i \in N$ are defined over terminal histories, $u_i : Z \to \mathbb{R}$.

Anything with these features can be written as an extensive-form game:

\[
G = \langle N, H, P, f, \{\mathcal{I}_i\}_{i\in N}, \{u_i\}_{i\in N} \rangle.
\]

# 子博弈精炼纳什均衡 Subgame Perfect Nash equilibrium

## 子博弈 sub-game

从一个扩展性博弈的==单点信息集==出发，往下的所有博弈过程，且==不切割任何一个信息集==。

一个扩展性博弈一定有它自己作为自己的 subgame。

## 子博弈精炼均衡 subgame-perfect equilibrium

一个博弈的均衡同时也是其所有子博弈的均衡，这就是子博弈精炼均衡。

可以使用剪枝 backward induction 快速求解。请注意逆向归纳和子博弈完美之间的联系。事实上，在完美信息泛型博弈中，子博弈的完美性与逆向归纳法一致。

# 恐吓 Entry Deterrence with an Explicit Threat

## 内容

在 [[06_扩展性博弈#entry Deterrence|Entry Deterrence]] 的基础上，$I$ 方增加一个对 $E$ 方的恐吓。此处认为恐吓是有成本的，不管最后选择如何，这个成本 $I$ 方必须承担。

![[Pasted image 20240417210200.png]]

## 分析

这种无差别的恐吓是无效的。对 $E$ 的恐吓只会徒增成本，而不会对对方选择造成影响。

对应的策略式博弈（payoff 顺序为 $(E, I)$）：

| $I$ \ $E$ | Enter | Stay Out |
| --- | --- | --- |
| Silent, Truce (ST) | $(1, 1)$ | $(0, 2)$ |
| Silent, Fight (SF) | $(-1, -1)$ | $(0, 2)$ |
| Threat, Truce (ThT) | $(1-c, 1)$ | $(0, 2-c)$ |
| Threat, Fight (ThF) | $(-1-c, -1)$ | $(0, 2-c)$ |

![[Pasted image 20240418081825.png]]

## 有效的恐吓

![[Pasted image 20240418081616.png]]

去掉两个 $c$，只保留 threat 后 truce 的 $-c$，且要保证 $c$ 足够大（大于 2），以使得当 $I$ 面临 threat 后的选择时策略改变。这对 $E$ 构成威胁，倒逼 $E$ 不敢在 $I$ 选择 threat 后选择 enter。

eg：破釜沉舟。
