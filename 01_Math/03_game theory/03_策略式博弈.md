# [[Prisoner's Dilemma|囚徒困境]]（The Prisoners' Dilemma）

[[strategic-form Games|策略式表达]]：
- 玩家（[[player|Player]]）：两名囚徒。
- [[strategies|策略]]（Strategy）：每个囚徒有两个选择，\(C\)（合作）与 \(D\)（不合作）。
- 收益（[[payoffs|Payoff]]）：由下方收益矩阵给出。

|       | C     | D     |
|-------|-------|-------|
| **C** | -1,-1 | -9,0  |
| **D** | 0,-9  | -6,-6 |

## 关键定义（Key Definitions）

>[!note] 定义 1（策略式博弈, Strategic-form Game）
>
> 策略式博弈由三部分构成：
>
> - 玩家集合（players）\(N\)
> - 策略集合（strategy sets）\(\{S_i\}_{i\in N}\)
> - 收益函数（payoff functions）\(\{u_i\}_{i\in N}\)
>
>[!note] 定义 2（严格占优, Strict Dominance）
>
> 对玩家 \(i\) 而言，若对任意 \(s_{-i}\in S_{-i}\) 都有
>
> \[
> u_i(s_i,s_{-i}) > u_i(s_i',s_{-i}),
> \]
>
> 则称策略 \(s_i\) 严格占优（strictly dominates）策略 \(s_i'\)。
>
> 注：将 \(>\) 换成 \(\ge\) 即得到弱占优（weak dominance）。
>
>[!note] 定义 3（严格劣势策略, Strictly Dominated Strategy）
>
> 若存在策略 \(s_i\in S_i\) 严格占优 \(s_i'\in S_i\)，则 \(s_i'\) 为严格劣势策略（strictly dominated strategy）。
>
>[!note] 定义 4（严格优势策略, Strictly Dominant Strategy）
>
> 若策略 \(s_i\) 严格占优玩家 \(i\) 的所有其他可选策略，则 \(s_i\) 为严格优势策略（strictly dominant strategy）。
>
>[!note] 定义 5（优势策略均衡, Dominant-strategy Equilibrium）
>
> 若存在 \(s^*\in S\)，使得对任意玩家 \(i\in N\) 与任意 \(s_i\in S_i\) 都有
>
> \[
> u_i(s_i^*,s_{-i}^*) \ge u_i(s_i,s_{-i}^*),
> \]
>
> 则 \(s^*\) 称为优势策略均衡（dominant-strategy equilibrium）。
>
>[!note] 定义 6（严格劣势策略迭代删除, IDSDS）
>
> 设 \(A = \times_{i\in N} A_i \subseteq S\)。若可构造序列 \(A_i^0=S_i,\dots,A_i^T=A_i\)，并且每一步只删除当前博弈中的严格劣势策略，最终得到不再含严格劣势策略的集合 \(A\)，则称该过程为严格劣势策略迭代删除（iterated deletion of strictly dominated strategies, IDSDS）。
>
>[!note] 定义 7a（纳什均衡, Nash Equilibrium）
>
> 若策略组合 \(s^*\in S\) 满足对每个 \(i\in N\)：
>
> \[
> u_i(s_i^*,s_{-i}^*) \ge u_i(s_i,s_{-i}^*), \quad \forall s_i\in S_i,
> \]
>
> 则 \(s^*\) 为纳什均衡（Nash equilibrium）。
>
>[!note] 定义 7b（纳什均衡的最优反应刻画, Best-response Characterization）
>
> 当且仅当对所有 \(i\in N\) 都有
>
> \[
> s_i^* \in B_i(s_{-i}^*),
> \]
>
> 策略组合 \(s^*\in S\) 才是纳什均衡。
>
>[!note] 定义 8（最优反应函数, Best-reply Function）
>
> 对玩家 \(i\in N\)，最优反应函数 \(B_i\) 是集合值函数（set-valued function）：
>
> \[
> B_i(s_{-i}) = \{s_i\in S_i \mid u_i(s_i,s_{-i}) \ge u_i(s_i',s_{-i}),\ \forall s_i'\in S_i\}.
> \]
>
>[!note] 定义 9（可理性化, Rationalisability）
>
> 在博弈 \(G=\langle N,\{S_i\}_{i\in N},\{u_i\}_{i\in N}\rangle\) 中，若对每个 \(j\in N\) 都存在集合 \(R_j\subseteq S_j\)，使得：
>
> 1. \(s_i\in R_i\)
> 2. 任意 \(s_j\in R_j\) 都是某个信念下的最优反应，且该信念支持集属于 \(R_{-j}=\times_{k\ne j}R_k\)
>
> 则称策略 \(s_i\) 为可理性化策略（rationalisable strategy）。
>

## 如何走出囚徒困境

### 两个犯人先后审问

后一个人可以根据前一个人的回答来选择自己的回答，他具有优势，由于该优势的存在，前一个人只能选择出卖，故依旧落入囚徒困境

### [[Repeated Games|重复博弈]]

例如：可口可乐公司和百事可乐公司的价格战
与经典的囚徒困境不同的是，这里不仅要考虑定价策略对当日的影响，更要考虑价格策略对后面的影响，此时细分为了两种情况分情况讨论

#### 有尽头的重复博弈

那么就存在最后一天，这个最后一天的时候就属于经典的囚徒困境，这一天二者都选择低价，然后由于这一天的影响，向前倒退的每一天都要低价，以此类推，那么每一天都要低价。囚徒困境并未被破除。

#### 没有尽头的重复博弈（不知道什么时候是尽头）

此时二者为了更长远的利益，将不会率先降价，囚徒困境得以破除。实现双赢。

### 黑社会组织

如果二者的选择变为甲/乙在“坦白/抵赖”上的博弈（见图中的结局矩阵）：

那么博弈的规则就会被打破，可以跳出囚徒困境。

## **Crazy Eddie 和 Newmarket 的博弈**：一种特殊的垄断

### 情况描述

* 美国两家销售音响电子产品的商家 Crazy Eddie 与 Newmarket&[[Lewis Dual Sector Model|Lewis]] 的竞争。
* Crazy Eddie 承诺：“不可能有人卖得比我们更低！”
* Newmarket&[[Lewis Dual Sector Model|Lewis]] 推出低价保证：“假如你在别处以更低的价格买到同样商品，我们双倍返还差价！”

### 分析

乍一看是囚徒困境，但是仔细分析，是什么导致了囚徒困境？是不向对方商量的直接降价拉走了本属于对方的客源，另一方只能一起降价以应对客源的流失。

但是在本情况下，当Crazy Eddie降级后，newmarket的顾客不会流失，甚至会第一时间向Newmarket汇报对方降价。囚徒困境赖以成立的条件失效了，囚徒困境不会发生，这甚至会成为一种新形式的垄断。

### 其他相似情形

#### 电商对价格的影响

* 对于完全竞争市场中的小件物品，电商降低了其价格。
	eg：发卡
* 对于大宗的且生产商不多的商品，电商一方面降低了同行互看价格的难度，另一方面又形成了如上例子中的特殊垄断，应辩证看待。
	eg： 冰箱
#### 钻石

早期的钻石贵，因为其开采量少，而且开采难度高，而后南非发现了新的钻石矿，大量职业淘钻人前去挖矿，导致价格暴跌，同时影响买家对市场的信息，购买量也减少，而后戴尔比思公司出现，垄断了南非的大部分钻石矿，钻石价格稳定。近年来新的钻石矿在加拿大被发现，同时各个钻石珠宝制造商有打价格战的倾向，故而钻石价格又一次持续走低。

#### 链家平台
主打真房源，因外先前的安居客上大量的中介依靠不合常理的超低价吸引买方与其建立联系，而后介绍其真正出售的房源，逼迫普通卖家与他们不得不使用同样的招数来吸引买方。


# 纯策略的纳什均衡

## 介绍

### 引入
（行玩家：T/B；列玩家：L/M/R）

|       | L   | M   | R    |
|-------|-----|-----|------|
| **T** | 4,3 | 6,7 | 0,4  |
| **B** | 5,5 | 5,-1 | -4,-2 |

注意到在先前的连续剔除严格劣势选择后，这个收益矩阵（payoff matrix）变成：

|       | L   | M    |
| ----- | --- | ---- |
| **T** | 4,3 | 6,7  |
| **B** | 5,5 | 5,-1 |

但是在此时，无法继续删除严格劣势策略。也就是说，单靠“迭代删除”已不能继续缩小策略空间。

在这四个候选策略中，\(TL\) 不会稳定出现：固定一方策略时，另一方都存在更优偏离。此时应改用前文“定义 7a（纳什均衡, Nash equilibrium）”来判断。

结论表述：若在某个策略组合上，任何单个玩家在他人策略不变时都无法通过单独偏离提高收益，则该组合是纳什均衡。

## 如何找出纳什均衡

### 样例

#### 咖啡厅还是酒吧

玩家（Players）：两名学生（行/列玩家）。
[[strategies|策略]]（Strategies）：Cafe 或 Pub。

|          | Cafe | Pub |
| -------- | ---- | --- |
| **Cafe** | 4,3  | 1,1 |
| **Pub**  | 0,0  | 4,3 |

俩人一个喜欢咖啡厅，一个喜欢酒吧，但是俩人更喜欢去同一个地方而不是分开。

没有严格劣势策略

#### 打猎打兔子还是鹿

玩家（Players）：猎人 1 和 2（行/列玩家）。[[strategies|策略]]（Strategies）：Rabbit（R）或 Stag（S）。

|       | R   | S   |
| ----- | --- | --- |
| **R** | 3,3 | 4,0 |
| **S** | 0,4 | 5,5 |

打兔子只要一个人就行，但是打鹿需要两个人合作，只去一个就空手而归。

#### 鹰鸽博弈
Hawk-Dove（经典生物学博弈）：两名玩家要么争斗（Hawk），要么让步（Dove）。Hawk 对 Dove 获得资源价值 $v$，Dove 收益为 0。两个 Dove 平分 $v$。两个 Hawk 打斗，各有胜率，失败者付出成本 $c$，且 $v < c$（因此 $v-c<0$）。

一般形式：

|          | Hawk                          | Dove                      |
| -------- | ----------------------------- | ------------------------- |
| **Hawk** | $\frac{v-c}{2},\frac{v-c}{2}$ | $v,0$                     |
| **Dove** | $0,v$                         | $\frac{v}{2},\frac{v}{2}$ |

数值例（$v=4,\ c=6$）：

|        | Hawk   | Dove |
|--------|--------|------|
| **Hawk** | -1,-1 | 4,0  |
| **Dove** | 0,4   | 2,2  |

存在两个非对称纳什均衡：{Hawk, Dove} 与 {Dove, Hawk}。

思考：如果V和C的值互换，结果会怎样？
如果 (v) 与 (c) 的取值关系互换，博弈结构可能转为囚徒困境，这说明参数关系会显著影响均衡结果。

两个人摆硬币，如果同面则B赢，异面则A赢（行玩家为A）。

|       | H     | T     |
|-------|-------|-------|
| **H** | -1,1  | 1,-1  |
| **T** | 1,-1  | -1,1  |

没有纯策略的纳什均衡

## [[Best-Reply Function|最优反应函数]]（[[Best-Reply Function|Best]]-reply functions）

定义 8（[[Best-Reply Function|最优反应函数]], [[Best-Reply Function|best-reply function]]）：
对玩家 $i \in N$，[[Best-Reply Function|最优反应函数]] $B_i$ 是一个集合值函数（set-valued function），满足：
$$
B_i(s_{-i}) = \{ s_i \in S_i \mid u_i(s_i, s_{-i}) \ge u_i(s_i', s_{-i}),\ \forall s_i' \in S_i \}.
$$

讨论当对面选择一个特定的策略时，我应该选择怎样的函数来应对？

## [[Rationalisability|可理性化]]（[[Rationalisability|Rationalisability]]）

在博弈论中，一个策略如果是可理性化的，那么在给定其他玩家的策略和游戏的结构下，该策略是最优的或合理的。
玩家A的可理性化策略1可推知玩家二需要选择策略1，玩家二的可理性化策略1可以推知玩家1的策略2，这样就成为了一个可理性化策略的回环。
如果玩家1的一个策略跟玩家2的一个策略组成了一个双向的箭头，那么就意味着这个策略组合是纳什均衡。
纳什均衡一定是可理性化闭环的，但是可理性化闭环的不一定是纳什均衡的。
令 $R=\times_{i\in N}R_i$，其中 $R_i$ 是玩家 $i\in N$ 的可理性化策略集合（rationalisable [[strategies|strategies]] set）；$Z$ 是纳什均衡集合（[[Nash Equilibrium|Nash]] equilibria set）；$A$ 是严格劣势策略迭代删除后幸存的集合（iterated deletion survivors）。则有
$$
Z \subseteq R \subseteq A \subseteq S.
$$
混合策略允许选择多个策略的分布

# 混合策略扩展中的定义
[[03_策略式博弈#关键定义（Key Definitions）|先前的定义]]
10. 定义 10（混合扩展博弈, mixed extension）：
博弈 $G=\langle N,\{S_i\}_{i\in N},\{u_i\}_{i\in N}\rangle$ 的混合扩展（mixed extension）为博弈 $\[[Gamma|Gamma]]$，其中：
1. $\[[Gamma|Gamma]]=\langle N,\{\[[Delta|Delta]](S_i)\}_{i\in N},\{U_i\}_{i\in N}\rangle$；
2. $\[[Delta|Delta]](S_i)$ 是 $S_i$ 上的概率分布集合，且 $\[[Delta|Delta]](S)=\times_{i\in N}\[[Delta|Delta]](S_i)$；
3. $U_i:\[[Delta|Delta]](S)\to\mathbb{R}$ 是 vNM 期望效用函数（vNM expected utility function），对每个 $\sigma \in \[[Delta|Delta]](S)$ 赋予其在 $u_i$ 下、由 $\sigma$ 诱导的彩票（lottery）期望值。
4. 定义 11a（[[Mixed Strategy Nash Equilibrium|混合策略纳什均衡]], mixed-strategy [[Nash Equilibrium|Nash]] equilibrium）：
若 $\sigma^* \in \[[Delta|Delta]](S)$ 满足
$$
U_i(\sigma_i^*, \sigma_{-i}^*) \ge U_i(\sigma_i, \sigma_{-i}^*) \quad \forall \sigma_i \in \[[Delta|Delta]](S_i),\ \forall i\in N.
$$
定义 11b：当且仅当对所有 $i \in N$ 都有 $\sigma_i^* \in B_i(\sigma_{-i}^*)$ 时，$\sigma^* \in \[[Delta|Delta]](S)$ 是纳什均衡（[[Nash Equilibrium|Nash]] equilibrium）。

# 混合策略中的纳什均衡
回到[[03_策略式博弈#matching pennies|match pennies]]。
此时没有纯策略的纳什均衡。如果可以选择策略的概率分布而非纯策略呢？

设玩家2的混合策略为 $\sigma_2=(q,1-q)$。则
$$
U_1(H,q)=(1-q)-q=1-2q,\qquad
U_1(T,q)=q-(1-q)=2q-1.
$$
因此：$q<\tfrac12$ 时选 $H$，$q>\tfrac12$ 时选 $T$，$q=\tfrac12$ 时无差异（任意 $p$）。

# 引申

1. 如若某一个混合策略是最优反应，则其中包含的所有策略都应该是最优反应。这也就意味着选择任何一个纯策略都是一样的效用。
	以[[03_策略式博弈#matching pennies|match pennies]]为例。
	现在假设行玩家（row [[player|player]]）以概率 $x$ 选 H、以概率 $1-x$ 选 T。沿用简写记号（abusing notation）：
	$$
	U_C(H)=x\cdot 1+(1-x)\cdot(-1)=2x-1,\qquad
	U_C(T)=x\cdot(-1)+(1-x)\cdot 1=1-2x.
	$$

	这就得出了第二种找纳什均衡的方法。
2. [[03_策略式博弈#咖啡厅还是酒吧|性别博弈（咖啡厅还是酒吧）]]。
		玩家（Players）：M.Phil. 学生 1（行）与 2（列）。纯策略（Pure [[strategies|strategies]]）：Cafe / Pub。
		混合策略（Mixed [[strategies|strategies]]）：行玩家选 Cafe 的概率为 $x\in[0,1]$，列玩家选 Cafe 的概率为 $y\in[0,1]$。
	收益矩阵与期望收益：

|               | Cafe (y) | Pub (1-y) | Expected |
| ------------- | -------- | --------- | -------- |
| **Cafe (x)**  | 4,3      | 1,1       | 4y+(1-y) |
| **Pub (1-x)** | 0,0      | 4,3       | 3(1-y)   |

列玩家选 $y=1$ 当且仅当 $3x > x + 4(1-x)$，即 $6x>4 \Rightarrow x>2/3$。
行玩家选 $x=1$ 当且仅当 $4y+(1-y) > 3(1-y)$，即 $6y>2 \Rightarrow y>1/3$。

## 一种不同的情况
考虑下列博弈（与后续课程中的一个例子相似）：

# 混合策略中的严格优势与严格劣势

## 1)

无论别人选什么纯策略我都存在A优于B，那么无论别人选什么混合策略我都是A优于B

## 2)

 如果一个策略不能被纯策略严格占优但是可以被一个混合策略严格占优，那么它就是严格劣势的。
在下列博弈中，不存在任一策略被另一纯策略严格占优（strictly dominated）：

|       | L    | M    | R    |
| ----- | ---- | ---- | ---- |
| **T** | 4,10 | 3,0  | 1,3  |
| **B** | 0,0  | 2,10 | 10,3 |


其中R不是严格劣势策略
但是LM各二分之一的策略严格优于R，所以R还是一个严格劣势策略，R被剔除。
列玩家收益随 $x$ 的变化（$x$ 为行玩家在 $T$ 上的权重）：

|             | L    | M    | R    |
| ----------- | ---- | ---- | ---- |
| **T (x)**   | 4,10 | 3,0  | 1,3  |
| **B (1-x)** | 0,0  | 2,10 | 10,3 |

因此列玩家对 L/M/R 的期望收益分别为：$10x,\ 10(1-x),\ 3$。

## 3)

但是占优于一个混合策略的纯策略不能说明什么问题。

|       | L    | M    | R   |
| ----- | ---- | ---- | --- |
| **T** | 3,10 | 0,0  | 1,7 |
| **B** | 0,0  | 3,10 | 1,7 |

要点：
- 每个策略的计分列收益，$x$ 是每行附加到 $T$ 上的权重。
- 无论是纯策略 L 还是纯策略 M 都不是严格由 R 主导的。
- 将概率为 $1/2$ 的策略 L 和 M 各得 5，这是严格由 R 主导的。
- 纳什：$\{T,L\},\ \{B,M\},\ \{x\in[3/10,\ 10/7],\ R\}$。

## 延伸到三人的博弈

一个人选行，一个人选列，一个人选格子

三个“格子”分别对应第三人选 $X,Y,Z$ 时的 2×2 [[Subgame|子博弈]]：

**X**

|       | L   | R   |
|-------|-----|-----|
| **U** | 0   | 2   |
| **D** | 0   | 3   |

**Y**

|       | L   | R   |
|-------|-----|-----|
| **U** | 3   | 0   |
| **D** | 2   | 0   |

**Z**

|       | L   | R   |
|-------|-----|-----|
| **U** | 2   | 0   |
| **D** | 0   | 2   |

假设行以 $p$ 的概率选 $U$，列以 $q$ 的概率选 $L$。要让 $Z$ 严格劣势，必须存在一种混合策略 $\sigma_M$ 对所有 $p,q$ 都严格更好。特别是，当 $p=q=1$ 和 $p=q=0$ 时，$\sigma_M$ 必须比 $Z$ 做得更好。于是：
$$
3\sigma_M(X)+2[1-\sigma_M(X)-\sigma_M(Y)]>2,\qquad
3\sigma_M(Y)+2[1-\sigma_M(X)-\sigma_M(Y)]>2.
$$

显然陷入了矛盾，无法确定选什么
