# 1.8.5 Unstacking Game Score

## Official exercise

Suppose that there is a game that entails unstacking a tower of \(n \) blocks. A move entails splitting a stack of \(k \) blocks into two stacks of \(a \) and \(k-a \) blocks. Also define the score for a move to be the product of the number of blocks in the created substacks (e.g. \(k(a-k)\)). The overall score for the game is the sum of the scores accumulated over all the moves.
Which of the following is true about the overall score?

Exercise 1

[ ] The score-maximizing strategy is to always split a stack in half.

[ ] The overall score is the same however you unstack the blocks.

[ ] The overall score for a \(n \)-stack game is \(\frac{n(n-1)}{2} \).

[ ] The base case is a 2-block stack, which takes one split to unstack.

## Official answers and feedback

> [!answer]- Q1 — official answer
> **Answer:** The overall score is the same however you unstack the blocks.; The overall score for a \(n \)-stack game is \(\frac{n(n-1)}{2} \).
