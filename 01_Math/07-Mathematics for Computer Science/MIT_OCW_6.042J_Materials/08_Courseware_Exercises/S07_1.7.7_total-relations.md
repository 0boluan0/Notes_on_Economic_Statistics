## Official exercise

A relation \(R\) from a set \(A\) to a set \(B\) is **total** iff (check all that apply):

Exercise 1

[ ] \( R(A) = B \)

[ ] \(R^{-1}(B) = A\)

[ ] \(|A|=|B|\)

[ ] \(R\) is (\(\geq 1)\)-out

[ ] \(R^{-1}(B) = B\)

[ ] \(R^{-1}(A) = A\)

## Official answers and feedback

> [!answer]- Q1 — official answer
> **Answer:** \(R^{-1}(B) = A\); \(R\) is (\(\geq 1)\)-out
