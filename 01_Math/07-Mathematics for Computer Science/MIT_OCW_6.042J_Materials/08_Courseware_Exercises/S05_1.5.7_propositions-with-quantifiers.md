## Official exercise

Determine which propositions are true when the variables range over:

1. the nonnegative integers.

   Exercise 1

   [ ] 
   \(\forall x \exists y. 2x-y = 0\)

   [ ] 
   \(\forall x \exists y. x-2y = 0\)

   [ ] 
   \(\forall x. x < 10 \text{ IMPLIES } [\forall y. y < x
   \text{ IMPLIES } y < 9]\)

   [ ] 
   \(\forall x \exists y. [y >x
   \text{ AND } \exists z. y+z = 100]\)
2. the integers.

   Exercise 2

   [ ] 
   \(\forall x \exists y. 2x-y = 0\)

   [ ] 
   \(\forall x \exists y. x-2y = 0\)

   [ ] 
   \(\forall x. x < 10 \text{ IMPLIES } [\forall y. y < x
   \text{ IMPLIES } y < 9]\)

   [ ] 
   \(\forall x \exists y. [y >x
   \text{ AND } \exists z. y+z = 100]\)
3. the real numbers.

   Exercise 3

   [ ] 
   \(\forall x \exists y. 2x-y = 0\)

   [ ] 
   \(\forall x \exists y. x-2y = 0\)

   [ ] 
   \(\forall x. x < 10 \text{ IMPLIES } [\forall y. y < x
   \text{ IMPLIES } y < 9]\)

   [ ] 
   \(\forall x \exists y. [y >x
   \text{ AND } \exists z. y+z = 100]\)

## Official answers and feedback

> [!answer]- Q1 — official answer
> **Answer:** \(\forall x \exists y. 2x-y = 0\); \(\forall x. x < 10 \text{ IMPLIES } [\forall y. y < x \text{ IMPLIES } y < 9]\)
>
> **Official feedback:**
> Counterexample for 2: Let \(x = 1\).
> 
> Counterexample for 4: Let \(x = 100\).

> [!answer]- Q2 — official answer
> **Answer:** \(\forall x \exists y. 2x-y = 0\); \(\forall x. x < 10 \text{ IMPLIES } [\forall y. y < x \text{ IMPLIES } y < 9]\); \(\forall x \exists y. [y >x \text{ AND } \exists z. y+z = 100]\)
>
> **Official feedback:**
> Counterexample for 2: Let \(x = 1\).

> [!answer]- Q3 — official answer
> **Answer:** \(\forall x \exists y. 2x-y = 0\); \(\forall x \exists y. x-2y = 0\); \(\forall x \exists y. [y >x \text{ AND } \exists z. y+z = 100]\)
>
> **Official feedback:**
> Counterexample for 3: Let \(x = 9.5\).
