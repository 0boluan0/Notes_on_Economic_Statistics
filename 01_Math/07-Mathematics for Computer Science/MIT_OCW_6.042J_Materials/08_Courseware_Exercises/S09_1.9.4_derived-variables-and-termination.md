## Official exercise

1. For state machines, a *derived variable* is a \_\_\_\_\_, of real variables, that assigns a "value" to each state.

   Exercise 1

   [Choose one: derivative | sum | function | rule]
2. Which of the following is a derived variable for the diagonal robot on the grid example?

   Exercise 2

   [Choose one: x+y (mod 2) | x | y | there are no derived variables]
3. A derived variable is a *constant* iff it is both \_\_\_\_\_increasing and \_\_\_\_\_ decreasing.

   Exercise 3

   [Choose one: strictly, strictly | strictly, weakly | weakly, weakly | weakly, strictly]
4. Termination of a state machine is guaranteed if it has a derived variable on \(\mathbb{N} \) that is \_\_\_\_\_ decreasing in any \_\_\_\_\_.

   Exercise 4

   [Choose one: weakly, well ordered set | strictly, well ordered set | weakly, finite set | strictly, finite set]

## Official answers and feedback

> [!answer]- Q1 — official answer
> **Answer:** function

> [!answer]- Q2 — official answer
> **Answer:** x+y (mod 2)

> [!answer]- Q3 — official answer
> **Answer:** weakly, weakly

> [!answer]- Q4 — official answer
> **Answer:** strictly, well ordered set
