# 1.2.6 A Bogus Proof by Cases

> 题目、正确答案与反馈均从 MIT OCW 官方离线课程包提取；动态作答控件已转换为静态 Markdown。

## Official exercise

Which step(s) contain the logical error?

**Bogus Claim**: For any integer \(a\), \(\;\;\;2a^2 > a\).

Exercise 1

[ ] This proof is by case analysis.

[ ]  There are two cases: 

**Case 1**: *\(a\) is positive.*

**Case 2**: *\(a\) is negative.*

[ ]  One of these cases must always hold, because an integer is either positive or negative.

[ ] **Case 1**: Suppose \(a\) is positive.

[ ]  Since \(a\) is an integer, we must have that \(a\geq 1\).

[ ]  Hence, \(2a^2 = 2a\cdot a \geq 2a\cdot 1 > a\).

[ ]  This implies the claim holds in Case 1.

[ ] **Case 2**: Suppose \(a\) is negative.

[ ]  Since \(a\) is an integer, we must have that \(a\leq -1\).

[ ]  Hence, \(2a^2 \geq 2\cdot (-1\cdot -1) = 2 > -1 \geq a\).

[ ]  This implies the claim holds in Case 2.

[ ]  The claim therefore holds in both cases. \(\blacksquare\)

## Official answers and feedback

> [!answer]- Q1 — official answer
> **Answer:** One of these cases must always hold, because an integer is either positive or negative.
>
> **Official feedback:**
> Explanation
> 
> These two cases are NOT exhaustive, they leave out the case where \(a=0\), in which case \(2a^2=2\cdot 0^2=0=a\).
> 
> Line 2 is not logically erranous because saying "There are two cases" implies the existence of **at least** two cases.
> 
> Line 3 claims that those are the ONLY two cases, and is therefore incorrect.
> 
> You should note that this proof can easily be modified to prove the correct claim that for any integer \(a\), \(2a^2 \geq a\)
